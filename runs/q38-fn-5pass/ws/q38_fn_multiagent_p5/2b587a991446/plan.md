The ordered-pair configuration graph is too large to search directly, so use a structural characterization: a swap is possible iff the graph contains at least one cycle, and an optimal solution can be viewed as moving both pieces along shortest paths to one “passing” cycle, performing the swap there, and then moving along shortest paths to the targets. Compute distances from S and T. Then minimize over possible passing cycles: if both pieces use the same cyclic vertex v, the cost is `2*(distS[v]+distT[v])` plus a local detour cost (2 normally, 4 if v is S or T); if they use two distinct vertices x,y on a cycle C, the cost is `|C| + 2*(distS[x]+distT[y])` (or the symmetric choice). The main algorithmic task is to find the best such cycle efficiently, using biconnected components / BFS-tree fundamental cycles with LCA path-minimum queries.
