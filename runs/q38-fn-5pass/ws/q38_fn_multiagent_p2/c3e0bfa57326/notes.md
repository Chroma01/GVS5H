- **Operation interpretation:** A balanced substring is exactly a consecutive block of sibling subtrees under some parent, or under the artificial root for the whole forest. The given reversal-with-parenthesis-swap is the mirror of that forest: it reverses the block and mirrors every subtree inside it.
- **Invariant:** Mirroring preserves the unordered rooted tree/forest. Each node keeps the same multiset of unordered child types, only their order and internal orientations may change.
- **Reachability:** Mirroring a single subtree is directly allowed. Two adjacent siblings X and Y can be swapped while restoring their internal ordered forms by: mirror XY, then mirror the first resulting subtree, then mirror the second resulting subtree. These adjacent swaps generate all permutations of children at every node. Operations inside a child do not affect its position among siblings. Therefore every ordered embedding of the fixed unordered tree/forest is reachable, and no other string is reachable.
- **Counting formula:** For a node with degree d and child unordered-type multiplicities c_1, ..., c_k, the number of distinct orders of its child types is d! / product(c_i!). Choices at different nodes are independent. Multiplying this local multinomial factor over every original node occurrence, and finally over the artificial root, gives the total number of distinct strings.
- **Why product over original nodes is enough:** If a subtree type appears multiple times, each occurrence contributes its own descendant factors. The parent multinomial divides by permutations of identical unordered child types. This is equivalent to the recursive formula F(type) = multinomial * product(F(child_type)^count), but avoids explicitly computing powers.
- **Canonical unordered types:** Parse S bottom-up using a stack. Each completed node has a list of child unordered-type IDs. Sorting this list and interning the tuple gives a canonical ID for the node's unordered type. Leaves correspond to the empty tuple.
- **Implementation details:** Precompute factorials and inverse factorials modulo 998244353. Cache the local multinomial factor for each canonical type. Multiply the answer by the cached factor whenever a node is completed, and once more for the root children list. Use dict.get with a None sentinel because the leaf type ID is 0.
- **Complexity:** There are O(N) nodes and total child-list length O(N). Sorting and interning take O(N log N) time and O(N) memory.
- **Edge cases:** Leaves and the empty forest have factor 1. N is far below the modulus, so factorial inverses exist. The artificial root is handled by the same multinomial computation as a normal node.
