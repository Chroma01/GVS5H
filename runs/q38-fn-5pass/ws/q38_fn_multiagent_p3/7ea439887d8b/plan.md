Model the process as a shortest-path problem on an expanded state graph with two states per vertex: `(vertex, parity)`, where `parity = 0` means the original edge directions are active and `parity = 1` means all edges have been reversed an odd number of times. Moving along an active edge costs 1 and keeps the same parity, while reversing all edges toggles parity and costs `X`. Run Dijkstra from `(1, 0)` because all edge costs are positive, and take the minimum distance to `(N, 0)` and `(N, 1)`. Use 64-bit integers for distances since the answer can exceed 32-bit range.
