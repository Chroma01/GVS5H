Model the process as a shortest-path problem on an expanded graph with states `(vertex, flipped_state)`, where `flipped_state` is 0 for original edge directions and 1 for reversed directions. Moving along an edge costs 1 and changes only the vertex, while reversing all edges costs X and changes only the flipped state at the same vertex. Use Dijkstra because all costs are nonnegative and the expanded graph has at most `2N` states and roughly `2M + 2N` transitions. The answer is the minimum distance to either `(N, 0)` or `(N, 1)` since reaching vertex N ends the process regardless of current orientation. Use 64-bit integers or Python arbitrary-precision integers because costs can exceed 32-bit range.
