- **Reduction:** Removing all occurrences of x is equivalent to setting them to 0, but subarrays consisting solely of x's (sum 0) are invalid. The true answer for x is `M` if `M > 0` else `max_nonx`, where `M` is the standard max subarray sum after zeroing x, and `max_nonx` is the maximum element not equal to x. This works because if `M > 0`, the maximizing subarray must contain a non-x; if `M <= 0`, all non-x are negative and the best valid subarray is the largest single non-x element.
- **Only negative x:** Setting a non-negative x to 0 cannot increase any subarray sum, so only negative values need to be processed.
- **Data structure:** Iterative segment tree storing `(sum, pref, suff, best)` for standard max subarray. Padding leaves use sentinel `NEG = -10**15` with `sum=0`, `pref=suff=best=NEG`. Real leaves store the value. When zeroing x, set its leaves to `0` (`sum=pref=suff=best=0`). Merge: `sum = L.sum + R.sum`; `pref = max(L.pref, L.sum + R.pref)`; `suff = max(R.suff, R.sum + L.suff)`; `best = max(L.best, R.best, L.suff + R.pref)`.
- **Complexity:** O(n log n) time, O(n) space. Each negative occurrence is deactivated and restored once, so at most 2n point updates, each O(log n). Grouping indices by value via dict.
- **Edge cases:** If all elements equal a negative x, operation is disallowed; skip that x (check `len(indices) == n`). No-op answer is the initial root best (Kadane). `max_nonx` computed from top two overall maximums: if overall max != x, use it; else use second max. Ensure `max2` is initialized to `-10**18`. n=1 handled correctly.
- **Validation:** Example 1 gives 7. Example 2 gives 10. Brute-force checks on random small arrays confirm correctness.
