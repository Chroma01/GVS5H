- **Core reduction:** By linearity of summation, the required answer is the sum over all unordered cell pairs of their Manhattan distance multiplied by the number of valid arrangements containing both cells. For a grid with N = m * n cells, every fixed pair is contained in exactly C(N - 2, k - 2) arrangements, independent of the pair's location.
- **Full-grid Manhattan sum:** Manhattan distance separates into row and column contributions. For rows, each unordered pair of distinct rows at distance d contributes d * n * n cell pairs, giving n^2 * S(m). For columns, the contribution is m^2 * S(n). Here S(L) = sum_{1 <= i < j <= L} (j - i) = L * (L - 1) * (L + 1) / 6.
- **Combination modulo:** MOD = 10^9 + 7 is prime, and N <= 10^5 < MOD, so factorials and inverse factorials up to N - 2 can be precomputed safely. The implementation caches fact and invfact on the class and extends them as needed. _comb returns 0 for invalid ranges.
- **Edge cases:** k = 2 gives multiplier C(N - 2, 0) = 1. k = N also gives multiplier C(N - 2, N - 2) = 1. One-dimensional grids have one of S(m), S(n) equal to zero. If N < 2 or k < 2, return 0. Pieces are identical, so arrangements are subsets of cells, not permutations; no extra factorial factor for labeling pieces is needed.
- **Complexity:** The factorial cache uses O(N) time and O(N) memory, where N = m * n <= 10^5. The distance computation itself is O(1) after the combination helper.
- **Validation:** For m = 2, n = 2, k = 2: S(2) = 1, total distance = 2^2 * 1 + 2^2 * 1 = 8, multiplier C(2, 0) = 1, answer 8. For m = 1, n = 4, k = 3: total distance = S(4) = 10, multiplier C(2, 1) = 2, answer 20.
