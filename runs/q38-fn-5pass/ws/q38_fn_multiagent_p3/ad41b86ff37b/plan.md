A snowflake is determined by its center c and x adjacent middle vertices. For a middle vertex m adjacent to c, the number of possible leaves is exactly deg(m)-1, because all neighbors except c can be kept as leaves while extra vertices are deleted. For fixed c, sort these capacities in nonincreasing order. If x middle vertices are chosen, the maximum common y is the x-th largest capacity, so the largest snowflake centered at c with x middles has 1+x(y+1) vertices. Maximizing this quantity over all centers and x with y>=1 gives the maximum number of vertices to keep; the answer is N minus that maximum.
