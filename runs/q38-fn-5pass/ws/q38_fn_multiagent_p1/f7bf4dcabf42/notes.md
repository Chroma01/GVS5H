- **State representation:** For a processed prefix T of the unknown string, let dp[j] be the LCS length between T and S[:j]. The row dp[0..N] is nondecreasing and adjacent differences are only 0 or 1. Encode the row by an N-bit mask where bit j-1 equals dp[j] - dp[j-1]. Then dp[j] is the popcount of the low j bits of the mask, and the final LCS length is popcount(mask). Every mask corresponds to a valid monotone row.
- **Transition rule:** Given a mask and a character c, reconstruct the old row from the mask. The new row for T+c is computed by the standard LCS row recurrence: new[0] = 0, and for j=1..N, new[j] = max(old[j], new[j-1], old[j-1] + 1 if c == S[j-1]). Encode the differences of the new row into the next mask. This transition is deterministic for each character.
- **Precomputation:** Precompute next_state[mask][c] for all 2^N masks and all 26 lowercase letters. With N <= 10 this is at most 1024 states, so the precomputation is tiny.
- **Counting DP:** Let cur[mask] be the number of length-t strings whose LCS DP row is mask. Initially cur[0] = 1. For each of the M appended characters, add cur[mask] to ndp[next_state[mask][c]] for every character c, modulo 998244353. Since both addends are kept below MOD, one conditional subtraction after each addition is sufficient.
- **Answer extraction:** After M steps, sum cur[mask] into ans[popcount(mask)]. The required answers are ans[0] through ans[N].
- **Complexity:** Precomputation is O(2^N * 26 * N). The counting DP is O(M * 2^N * 26). Memory is O(2^N * 26 + 2^N * N). For N <= 10 and M <= 100 this is easily fast enough.
- **Correctness and edge cases:** Repeated characters in S are handled naturally by the LCS recurrence. Some masks may be unreachable, but transitions are still well-defined and harmless. The LCS length cannot decrease when appending a character because new[j] always includes old[j]. The k=0 answer corresponds to strings avoiding all characters that appear in S, which the automaton reproduces. If M were 0, the code would output 1 for k=0, though constraints have M >= 1.
- **Implementation details:** Bit j-1 corresponds to S[j-1]. Rows are precomputed from masks to avoid repeated bit extraction during transition construction. Python's int.bit_count is used for popcount. Input is read with sys.stdin.read().split(), and output is printed space-separated.
