Reduce each query to finding the maximal interval a slime can absorb. Build a max Cartesian tree so each node's subtree is the interval where it is the maximum. A node can start absorbing iff it has an immediate neighbor strictly smaller than itself; if so, its initial reachable sum is its whole subtree sum, otherwise just its own value. Then propagate upward: while the current sum exceeds the parent's value, replace it with the parent's subtree sum. This gives all answers in O(N) after building the tree and computing subtree sums.
