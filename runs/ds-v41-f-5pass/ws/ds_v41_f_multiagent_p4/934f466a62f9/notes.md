- **Goal:** maximize sum over K disjoint pairs of max(Xa+Xb, Ya+Yb, Za+Zb); T<=1000, sum N<=1e5.
- **Core reduction (exact):** OPT = max "even assignment": pick M=2K distinct items, give each a color in {0,1,2} with ALL THREE color counts even, value = sum of assigned coordinate. => pair: color each pair by a winning dim (color both members the same) gives even, value=price, so OPT<=best_even. <=: within each even color class pair items arbitrarily; price >= assigned dim sum, so best_even<=OPT. Hence equality.
- **Upper bound V:** sort by m_i=max(X,Y,Z); top-M items `sel`, rest `unsel`; V=sum m_i. Any even assignment value<=V. Color each selected item by argmax (tie: x>=y, x>=z ->x; elif y>=z ->y; else z). If all counts even -> answer V (=best_even).
- **Parity fix:** else exactly two colors a,b odd; c=third. Start from greedy coloring. Any even assignment differs from greedy by ops with total parity {a,b}; op cost>=0 always (swap cost m_i-coord_v(j)>=0 since sel items have max m).
- **Key lemma:** min penalty = V-best_even and equals min over {one e1 op} or {one disjoint e2+e3 op pair}, where e1={a,b}, e2={a,c}, e3={b,c} (types XOR: e2 xor e3 = e1). Proof: decompose assignment vs greedy into item-disjoint recolor/swap ops whose types XOR to e1; if an e1-type op exists pick it, else there is an e2 and an e3 op (they are disjoint by decomposition). Costs only add, so min is attained by <=2 ops.
- **Op costs:** recolor sel_u i->v: m_i-coord_v(i). swap drop sel_u add unsel j colored v: m_i-coord_v(j) minimized = (min m over sel_u)-(max coord_v over unsel). e1 ops: recolor a->b, b->a, swap a->b, b->a. e3 ops B1..B4: recolor b->c, recolor c->b, swap b->c, swap c->b. e2 ops: recolor a->c, recolor c->a, swap a->c, swap c->a.
- **Combining (16 e2 x e3 cases):** sel_a only touched by e2, sel_b only by e3 -> those combinations are free (use global bestB). Conflicts only on sel_c items and unsel items; each op uses at most one sel_c and/or one unsel, so "best/second-best excluding one id" suffices. Cases: (recolor_c p)+(recolor_c avoid p), (recolor_c p)+(swap_c min-m avoiding p), (swap_a j)+(swap_b/b4 swap avoiding j), (swap_c p,j)+(recolor_c q!=p), (swap_c)+(swap_b avoiding j), (swap_c)+(swap_c p!=q and j!=j' handled by separable tmp1(exclude-p m sums)+tmp2(exclude-j coord sums)). Always-feasible fallback: e1 recolor (sel_a always nonempty), so answer finite.
- **Implementation:** one sort by -m; O(N) passes plus a few O(s)-sorts of extreme lists; sum N<=1e5 ok. Use integer INF=1<<60 (avoid float, answer up to ~1e14).
- **Validation:** `python3 sol.py stress` runs exhaustive binary {0,1} for N=2..5 all K, exhaustive ternary {0,1,2} N=3, then 4000 random cases (modes equal/tiny/zero/1e9/color-spread/small-with-ties, duplicated cakes) vs bitmask-DP brute. `python3 sol.py perf` runs T=1000, N=100 each (sum 1e5).
- **Known-good outputs:** Sample1 -> 12; Sample2 -> 209, 333. Hand-traced parity/swap examples (e.g. three (10,0,0) + (0,10,0) + (9,9,9) -> 39; three (10,0,0)+(0,0,7) -> 30) match.
- **Tie handling:** duplicate values are disambiguated by item id, so second-best exclusion always returns a different item with correct value; recoloring a tied item costs 0 and is captured.
