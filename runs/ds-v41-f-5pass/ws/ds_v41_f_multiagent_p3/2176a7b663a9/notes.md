- **Model:** Edge i-j iff intervals disjoint, i.e. `R_i < L_j` or `R_j < L_i`. Define strict partial order `i << j` iff `R_i < L_j`. G is exactly the comparability graph of this interval order (edges = comparable pairs).
- **Induced-path bound:** Interval orders are (2+2)-free. If some poset's comparability graph had an induced P5, orienting its edges forces relations `1<2, 3<2, 3<4, 5<4` with no others, which contains a 2+2 (`{1<2}` vs `{5<4}`). Hence no induced P5, so no induced P6+ either (drop an endpoint). Minimum-weight path uses only induced paths (positive weights, chords shortcut). So only lengths 1, 2, 3 edges matter.
- **Length 1:** `s,t` disjoint -> `W_s+W_t`, always optimal for that case.
- **Length 2 (`s-k-t`, s,t overlap):** `k` must be disjoint from both. A single k cannot be left of one and right of the other (that forces `L_k > R_k`, impossible). So `k` is left of both (`R_k < min(L_s,L_t)`) or right of both (`L_k > max(R_s,R_t)`).
- **Length 3 (`s-a-b-t`):** classify a vs s and b vs t. Same-side cases (both left / both right) are always dominated: the leftmost (resp. rightmost) of `{a,b}` is disjoint from both s and t, so a 2-edge path is cheaper. Only cross cases survive: (a left of s, b right of t) or (a right of s, b left of t). In these, `a-b` is automatically an edge (`a << b` resp. `b << a`), and a,b are forced distinct and distinct from s,t by overlap.
- **Answer (s,t overlap):** `W_s+W_t + min(ml, mr, c1, c2)`, else -1. `ml`=min W with `R<min(L_s,L_t)`; `mr`=min W with `L>max(R_s,R_t)`; `c1`=min W(`R<L_s`)+min W(`L>R_t`); `c2`=min W(`L>R_s`)+min W(`R<L_t`). Every term is a realizable path weight, and every induced optimum appears among them, so min is exact.
- **Data structures:** sort by R -> prefix minima (`minR_lt(x)` = `prefMin[bisect_left(Rs,x)-1]`); sort by L -> suffix minima (`minL_gt(x)` = `suffMin[bisect_right(Ls,x)]`). O(log N) per lookup, O((N+Q) log N) total.
- **Disproven / dropped:** the plan's 2D-dominance RMQ for same-side 4-vertex paths is unnecessary (those paths are strictly dominated by a cheaper common-neighbour path). Offline Fenwick fallback not needed.
- **Pitfalls handled:** strict `<`/`>` in all disjointness tests and in the bisect calls; intermediates can never coincide with s or t (guaranteed by overlap); coordinates up to 2N fit naturally; -1 only when no candidate exists, which equals disconnectedness given the induced-path bound.
