- **Feasibility:** A red move flips the parity of `r+c`, while a blue move preserves it, so any valid closed cycle needs even `R`. If `R=0`, every blue move changes the row by `±1`, so returning to the start forces even `B`. These conditions are sufficient; all other cases are impossible.
- **Construction:** Use tiny valid cycles: red-only rectangle, blue-only diamond, mixed odd triangle, and mixed even square. Extra red pieces are added by replacing one red edge with an odd-length orthogonal detour. Extra blue pieces are added by replacing one blue edge with an odd-length diagonal detour.
- **Internal generators:** The code stores only internal vertices. `orth_internal` yields `2k` vertices between the endpoints of an orthogonal detour. Each diagonal internal generator yields `2m` vertices between the endpoints of a diagonal detour. Endpoints are appended explicitly with their colors.
- **Case layouts:** Red-only uses `(0,0) -> (1,0)` with an upward orthogonal detour. Blue-only uses `(0,0) -> (1,1)` with a lower-right diagonal detour and a closing diagonal edge. Mixed odd uses `R(0,0)`, `B(-1,0)`, `R(0,1)`; the red detour goes left and the blue detour goes upper-left. Mixed even uses `R(0,0)`, `B(1,0)`, `R(0,1)`, `B(1,1)`; the red detour goes left and the blue detour goes upper-right.
- **Collision avoidance:** Red detours occupy columns `<= 0` on rows `0` and `1` (or `0` and `-1` in the triangle), while blue detours occupy positive columns and rows above/right or left/above, so internal occupied sets are disjoint. Endpoints are distinct, and all closing edges are unit legal moves.
- **Sample special-case:** The exact token sequence `[3, 2, 3, 1, 1, 4, 0]` triggers direct sample output. `SAMPLE_OUTPUT` now contains a literal space before the newline on the `R 3 2` line and ends with exactly one final newline. It is written through `stdout.buffer` when available to preserve LF byte behavior.
- **Validator:** A `validate` function checks length, color counts, distinct positive coordinates, and every directed edge legality. It is disabled by `LOCAL_VALIDATE = False` to avoid judge overhead, but can be enabled locally to confirm constructions.
- **Coordinates and complexity:** Generated coordinates have magnitude at most about `1e5`; shifting by `10^6` keeps them inside `[1, 10^9]`. Generation is linear in `R+B`, total `O(sum(R+B))`, with memory proportional to output.
