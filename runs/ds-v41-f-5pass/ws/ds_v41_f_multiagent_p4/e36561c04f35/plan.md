Model the process as deleting a sequence of monochromatic prefix blocks, where adjacent swaps are used only to bring selected equal-valued elements into the current prefix. The key is to derive the minimum of swaps + deletions over all possible deletion orders and block partitions, rather than assuming all equal values must be merged. Because T is large but total N is bounded, each test case must be processed in O(N log N) or O(N). A worker should first brute-force small cases to identify the optimal structural invariant, then turn it into a fast greedy/DP/data-structure solution. Finally, implement with fast input/output and validate against samples plus randomized brute force.
