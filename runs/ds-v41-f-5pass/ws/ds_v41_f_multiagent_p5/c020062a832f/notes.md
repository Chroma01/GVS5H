- **Problem:** For each k in 0..M-1, output inversion count of B where B_i = (A_i + k) mod M. N, M up to 2e5.
- **Core idea (incremental max-to-min):** Compute inversions once at k=0 with a Fenwick tree. Then step k -> k+1, noting only the element value v = M-1-k changes role: it is the current maximum (B value M-1) at shift k and becomes the minimum (B value 0) at shift k+1. All other relative orders are unchanged, so only pairs involving value v flip.
- **Delta formula:** Let c = count[v], p = sum of 0-based indices of elements equal to v, N = total length. The change in inversion count is `delta = 2*p - c*(N-1)`. Derivation: pairs (i in S before j not in S, i<j) each lose one inversion; pairs (i not in S before j in S, i<j) each gain one inversion; pairs within S stay non-inversions (equal values both before and after). Within-S pair terms cancel, leaving the clean formula.
- **Fenwick for k=0:** Iterate A left to right; for each x, inversions added = (inserted count) - query(x+1) where query is prefix sum of values <= x (value v stored at index v+1). Then add(1) at v+1.
- **Answer assembly:** out[0]=inv; for k in 0..M-2 compute v=M-1-k, cur += 2*sum_pos[v]-count[v]*(N-1), out[k+1]=cur. Precompute count and sum_pos while reading A.
- **Verified:** Matches all three provided samples exactly (delta formula checked by hand on samples 1 and 3, sample 2 fully reproduced 7,3,3,1,1,5). Outputs fit in 64-bit; Python ints are unbounded so no overflow concern.
- **Edge cases:** M=1 -> all A_i=0, loop range(0) runs zero times, single answer 0. N=1 -> inv=0 and every delta is 0 (sum_pos[v]=0 when present, count=0 when absent), all outputs 0. Values guaranteed in [0, M-1] by constraints.
- **Complexity:** O((N + M) log M) time for the Fenwick build plus O(M) delta sweep; O(N + M) memory. Comfortably within limits.
- **Rejected alternatives:** Sqrt/block decomposition, 2D offline interval aggregation, and wrapped/unwrapped threshold sweeps all work but are heavier; the difference-array/prefix-sum reduction over values collapses to exactly the same O(1)-per-k delta derived here, which is simplest and proven correct.
