- **Approach:** Simulate Santa's path once. For every horizontal move, store the inclusive x-interval in a dictionary keyed by the fixed y-coordinate; for every vertical move, store the inclusive y-interval keyed by the fixed x-coordinate. After all moves, sort intervals for each line and merge intervals that overlap or are adjacent (`next_start <= current_end + 1`). Adjacent merging is safe because all houses have integer coordinates, so there is no integer point between `end` and `end + 1`.
- **Counting:** For each house `(hx, hy)`, first test horizontal coverage by looking up `hy` in the horizontal dictionary. The merged line is stored as two sorted tuples `(starts, ends)`. Use `bisect_right(starts, hx) - 1` to find the last interval whose start is not greater than `hx`; the house is covered if that interval's end is at least `hx`. If horizontal coverage is found, count the house and skip the vertical test. Otherwise test vertical coverage symmetrically with key `hx` and variable `hy`. This counts houses at horizontal/vertical intersections exactly once.
- **Complexity:** Simulation is O(M). Sorting all interval lists costs O(M log M) in total. Each house performs at most two binary searches, so counting is O(N log M). Memory is O(N + M) for houses and merged intervals.
- **Implementation details:** Use `sys.stdin.buffer.read().split()` for fast parsing and set the token list to `None` after building the path to reduce memory. Directions are compared as bytes. Store merged intervals as tuples of starts and ends to avoid list over-allocation. Final coordinates can be as large as about `2e14`, which Python integers handle naturally.
- **Edge cases:** Endpoints are inclusive. Negative coordinates and large coordinates are handled by Python integers. Houses may lie at turn points or intersections of horizontal and vertical path parts; the skip-after-horizontal logic prevents double counting. If a line has only one interval, it is stored directly without sorting. If there are no horizontal or vertical groups, lookups simply miss.
- **Verification:** Sample 1 produces final position `(2, 3)` and count `2`. Sample 2 produces final position `(3000000000, 0)` and count `0`, confirming large-coordinate handling.
