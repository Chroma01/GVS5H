The task is to answer many 2D prefix queries of the sum of absolute differences between A[1..X] and B[1..Y]. Direct per-query computation is too slow because X,Y can be up to 1e5. Use sqrt decomposition over the original indices: precompute contributions between whole index blocks, then handle each query's two partial tails with efficient prefix value queries. This keeps preprocessing near O(N sqrt N) and each query near O(sqrt N log N), which is feasible for N=1e5 and K=1e4. Care is needed with 64-bit arithmetic and with combining full-block and partial-tail contributions without double counting.
