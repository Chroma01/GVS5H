- **Model:** cost of an operation = total weight (sum of C) of indices equal to 1 after the flip. Total = sum over i of C_i * (number of operations after which i is 1). Since C_i >= 1, never flip a same-0 index; flip each index the minimum number of times for its required parity.
- **Classification:** D = {A=1,B=0} (one removal flip); U = {A=0,B=1} (one addition flip); E = {A=B=1} (flip 0 or 2 times); Z = {A=B=0} (never touched).
- **Optimal order within a chosen E-subset X:** all removals (D∪X) first, then all additions (U∪X). Adjacent add-then-remove exchange strictly lowers cost by C_add + C_remove (adds first makes the toggled index and others 1 during an extra step). Removals in descending C, additions in ascending C.
- **Cost decomposition:** with T = D∪X, P = U∪X, m=|T|, a=|P|, M=m+a: total = costR(T) + costS(P) + M * (sum of C over E\X). costR = sum over i in T of C_i*(rank_desc(i)-1) = sum over pairs in T of min(C_i,C_j). costS = sum_{i in P} C_i + sum over pairs in P of min(C_i,C_j). Hence both pair-sums use the same insertion delta; costS adds an extra own-C term.
- **Prefix optimality:** for any non-empty X, if it contains f and omits e with C_e > C_f, swapping strictly improves. Proof tightened: Δ(costR+costS) <= (C_e-C_f)*(M-1) because each pair-min is 1-Lipschitz and the element touches |T|-1, |P|-1 partners plus the +C_e own term, while M is unchanged (|X| fixed) and the M*(sum) term drops by exactly M*(C_e-C_f). Since M-1 < M, net < 0. So optimal X is a top-k prefix of E sorted descending; enumerate k = 0..|E|. (Earlier note claimed increase <= (C_e-C_f)*(|D|+|U|+|X|); that bound is wrong, but the vs-M comparison still holds.)
- **Insertion deltas (Fenwick over compressed C, combined count+sum trees):** inserting c into R adds c*#{R elements >= c} + sum{C_g in R : C_g < c}. Inserting c into S adds c*(#{S elements > c} + 1) + sum{C_g in S : C_g <= c} (the +1 accounts for c's own contribution to the sum-of-C term). Totals are insertion-order invariant.
- **Queries:** R uses prefix j-1 (elements < c); #{>=c} = totalR - count. S uses prefix j (elements <= c); #{>c} = totalS - count.
- **Algorithm:** init R=D, S=U; M=|D|+|U|; Esum=sum(E); best = costR+costS+M*Esum. Then iterate E descending: insert into both R and S, M+=2, Esum-=c, update best. O(N log N).
- **Edge cases:** A==B already gives 0 (k=0 with M=0). Empty D/U/E handled; if allc empty, m=0 and loops don't run. Python big ints (answers up to ~1e17).
- **Verification:** `brute` is an exact Dijkstra over all 2^N bitmask states with edge weight = weight-after-flip; it explores every flip sequence. `python sol.py verify` runs 5000 random cases (N<=7, with heavy C ties and mixed parities, both C ranges) comparing brute vs solve; no mismatches are expected and the sampled samples/hand-cases agree. Sample 1 -> 16, sample 2 -> 0, verified by hand; sample 3 trusted to the algorithm.
- **Hand-checked cases (all match brute):** N=1 D-only -> 0; N=1 U-only -> C; swap D/U costs pick remove-first; case D=[1,1], E=[1000000] where toggling the huge E is strictly optimal (2000001 -> 1000003); tie cases where k=0 and k=1 tie.
