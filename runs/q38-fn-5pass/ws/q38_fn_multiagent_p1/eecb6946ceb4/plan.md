Count each fine triplet by its middle element B. For a fixed B, valid pairs (A,C) are exactly unordered pairs of distinct elements in S with A+C=2B. Build a 0/1 indicator array f over [0, max(S)] and compute its self-convolution g = f*f; then g[2B] is the number of ordered pairs (A,C) in S^2 summing to 2B. For each B in S, subtract the single pair (B,B) and divide by 2 to get the number of triplets centered at B. Sum this over all B in S, using FFT/NTT so the convolution is near-linear in max(S), which is required for values up to 1e6.
