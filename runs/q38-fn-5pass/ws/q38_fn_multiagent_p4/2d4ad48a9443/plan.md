The minimum operations for a subarray is the sum of the differences between each element and the running maximum from the subarray's left. For a fixed left index, the running maximum changes only at the chain of next strictly greater elements to the right, so precompute that chain with a monotonic stack and prefix sums. Build binary lifting over the chain to compute the cost of any subarray in O(log n) by adding full constant-maximum segments plus one partial segment. Use a two-pointer scan over left endpoints: because moving the left endpoint right cannot increase the cost, the farthest valid right endpoint is monotonic. For each left, advance the right pointer while the cost of [left, right+1] is at most k, then add all valid endings.
