For a fixed observer height \(h\), building \(i\) is visible exactly when \((H_i-h)/X_i\) is strictly larger than all previous \((H_j-h)/X_j\). Thus each building defines a line \(L_i(h)=(H_i-h)/X_i\), and the answer is the largest \(h\) where a new line is not above the upper envelope of earlier lines. The slopes \(-1/X_i\) are strictly increasing, so this upper envelope can be maintained as a monotone convex hull of lines. When inserting a line, remove hull lines whose intersection with the new line is not to the right of the previous hull intersection; the intersection with the remaining last hull line is the blocking height for this building. Track the maximum blocking height exactly as a rational number; if it is negative or no blocker exists, output \(-1\), otherwise output that value.
