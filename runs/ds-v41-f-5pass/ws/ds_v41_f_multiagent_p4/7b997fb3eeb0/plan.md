Reduce each query to finding the largest K such that K pairs can be formed from the sorted subarray. For a fixed K, the optimal choice is the K smallest elements as tops and the K largest as bottoms, giving the condition 2*A[L+i] <= A[R-K+1+i] for all i. This is equivalent to max_{p in [L, L+K-1]} D[p] + K <= R-L+1, where D[p] = lower_bound(A, 2*A[p]) - p. Precompute D for all indices, build a range-maximum query structure, and binary search K per query. Complexity is O(N log N + Q log N).
