- **Approach:** For each length-x window, the minimum operations to make it constant is the sum of absolute deviations to a median. Compute all window costs with sliding Fenwick trees over compressed values, then choose k non-overlapping windows via dynamic programming.
- **Median cost:** Use the lower median rank `(x + 1) // 2`. Fenwick binary lifting finds the largest prefix with count strictly less than this rank, giving the median and the count/sum of strictly smaller values. The cost formula `total - med*x + 2*(med*cnt_less - sum_less)` handles duplicates and negative values.
- **Sliding structure:** Coordinate-compress all values. Maintain count and sum Fenwick trees for the current window. Slide by removing the outgoing value and adding the incoming value in logarithmic time, while updating the window sum.
- **Interval DP:** A window starting at `i` occupies `[i, i+x-1]`; the next selected start must be at least `i+x`. `dp[i]` stores the minimum cost for the current number of selected windows ending at start `i`. The transition uses a running prefix minimum of the previous dp over starts `<= i-x`, giving O(k*m) where `m = n-x+1`.
- **At least k:** Window costs are nonnegative and selected windows are disjoint, so the minimum for at least k equals the minimum for exactly k. Any solution with more than k windows contains a non-overlapping subset of k windows with no larger cost.
- **Verification:** Sample 1 returns 8, corresponding to starts 1 and 5. Sample 2 returns 3, corresponding to starts 1 and 3. Additional edge cases checked include all-equal windows, negative values, duplicates, even window sizes, adjacent non-overlapping windows, k=1, exact partition when k*x=n, x=n, and a single unique value. No failures found.
- **Complexity:** Time is n log n for compression and sliding median queries plus k*n for DP. Memory is O(n). The sentinel `10**30` is safely above the maximum possible total cost under the constraints.
