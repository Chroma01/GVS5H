An optimal sequence can be transformed so that every 1→0 flip happens before every 0→1 flip; only positions with A_i = B_i = 1 may be flipped twice (off then on), and positions with A_i = B_i = 0 are never flipped. Thus the path is V-shaped: choose a set X of common 1s to keep on, turn off all other initial 1s, then turn on all final 1s not in X. For fixed X, the down phase is ordered by decreasing C and the up phase by increasing C. An exchange argument shows that if two common 1s have costs c_i < c_j, keeping i and removing j is never worse, so the optimal X is a prefix of common 1s sorted by C. We can evaluate all prefixes incrementally with Fenwick trees maintaining the down/up cost as common bits are moved from kept to removed.
