- **Operation model:** Both operations are the reversible block swap `0^X 1^Y <-> 1^Y 0^X`. The oriented rewrite `0^X 1^Y -> 1^Y 0^X` terminates because it increases inversions, and redexes cannot overlap, but the final solution uses a complete invariant instead of explicitly computing normal forms.
- **Invariant:** For a binary string, record two ordered sequences: the 0-based indices of all `1` characters modulo `X`, and the 0-based indices of all `0` characters modulo `Y`. During a swap, the `Y` ones move by exactly `X` positions, so their residues modulo `X` and their relative order are unchanged. The `X` zeros move by exactly `Y` positions, so their residues modulo `Y` and their relative order are unchanged. Therefore equality of both sequences is necessary.
- **Completeness sketch:** Interpret a string as a monotone lattice path where `0` is an east step and `1` is a north step. The `1`-residue sequence fixes, for each one-index, the x-coordinate where the path crosses that horizontal line modulo `X`. The `0`-residue sequence fixes, for each zero-index, the y-coordinate where the path crosses that vertical line modulo `Y`. Two paths with the same two sequences differ by directed regions whose horizontal widths are multiples of `X` and vertical heights are multiples of `Y`. Such regions can be tiled by `X` by `Y` rectangles, and each rectangle corresponds exactly to one allowed block swap. Hence the two ordered residue sequences are also sufficient.
- **Implementation:** Build the two residue sequences for `S`. Then scan `T` left to right while maintaining how many ones and zeros have been seen. For each `1` in `T`, compare `index % X` with the next stored one-residue; for each `0`, compare `index % Y` with the next stored zero-residue. At the end, also require that both consumed lengths match. This gives O(N) time and O(N) worst-case memory, storing only the invariant sequences for `S`.
- **Edge cases:** If `X = 1`, the one-residue sequence is just a sequence of zeros, so the check effectively compares the number of ones. Similarly, if `Y = 1`, the zero-residue sequence effectively compares the number of zeros. If `X + Y > N`, no operation is possible; the invariant remains injective by the rectangle-tiling argument, and the implementation naturally distinguishes different strings. Count mismatches are caught by the length checks.
- **Verification:** The provided samples are handled correctly. An exhaustive BFS verification for all binary strings with `N <= 7` and all `1 <= X, Y <= N` compares actual reachability with equality of the two residue sequences and finds no counterexample.
