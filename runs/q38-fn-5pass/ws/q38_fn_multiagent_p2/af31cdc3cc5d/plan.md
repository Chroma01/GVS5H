Model the deletions as a non-crossing matching of original positions: each removed pair is an edge, and if N is odd the single remaining element cannot be crossed by any edge. For any even-length contiguous block, the maximum score equals the sum of its largest half minus the sum of its smallest half; the upper bound is immediate, and a binary coloring by “top half” and “bottom half” values can always be matched non-crossingly between opposite colors. Thus, for odd N, choose the unmatched position, which must have even 0-based index, and add the optimal values of the even prefix before it and the even suffix after it. Compute these block values for all even prefixes and suffixes using a dynamic order-statistics structure, then take the best split.
