The key is to view deleting all occurrences of a value x as replacing those positions with 0, since they vanish and no longer contribute to any subarray. The answer is the maximum non-empty subarray sum over all such transformed arrays, including the original array with no deletion. We can evaluate each candidate x efficiently by maintaining the array in a segment tree that supports point updates and stores total sum, best prefix, best suffix, and best subarray. Switching between candidate values only requires updating positions of those values, and each index is updated O(1) times total, giving O(n log n). Skip any value whose frequency equals n because deleting it would empty the array.
