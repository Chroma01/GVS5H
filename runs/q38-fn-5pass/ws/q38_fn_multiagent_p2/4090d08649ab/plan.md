Characterize f(L,R) as the number of maximal consecutive-value blocks among the distinct values appearing in A[L..R]. Equivalently, f(L,R) equals the number of distinct values in the subarray minus the number of adjacent value pairs (x,x+1) that both appear in it. Therefore the required sum can be computed as the total number of subarrays containing each value, minus the total number of subarrays containing each adjacent pair. Compute value occurrence lists, count subarrays avoiding each value, and for each adjacent pair merge their occurrence lists to count subarrays avoiding both values. This yields an O(N) or O(N log N) solution using only occurrence lists and gap arithmetic.
