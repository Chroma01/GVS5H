Use sqrt decomposition on A prefixes. Split A into blocks of size S≈500 and precompute, block by block, the contribution of each full A block to every B prefix; adding these contributions gives base answers for all queries whose X is a block boundary in O(N^2/S). For the leftover partial A elements, process all requests offline in increasing Y with a Fenwick tree over compressed B values, so the current tree represents B_1..B_Y and each partial element's sum of absolute differences can be obtained from count/sum of B values <= A_i in O(log N). Group partial requests by (Y, A-block) and sort by offset to evaluate each A element at most once per distinct Y, giving worst-case O(KS log N). Combine base and partial contributions.
