For a fixed interval and K, an optimal pairing exists using the K smallest mochi as tops and the K largest mochi as bottoms, paired in sorted order. Thus K is feasible iff the interval length is at least 2K and for every offset i, `2*A[L+i] <= A[R-K+1+i]`. Precompute `nxt[p]` = first index with `A[nxt[p]] >= 2*A[p]` using two pointers, and define `C[p] = nxt[p] - p`. Then the feasibility condition becomes `max(C[L..L+K-1]) <= R-K+1-L`, which can be checked with a range-maximum query. Answer each query by binary searching K in `[0, floor((R-L+1)/2)]` using this O(1) predicate.
