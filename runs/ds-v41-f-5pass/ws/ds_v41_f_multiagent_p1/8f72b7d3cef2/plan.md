We need compute, for every starting slime, the maximum total size of the contiguous interval it can eventually absorb. This is equivalent to starting with an interval containing K and repeatedly expanding it left or right whenever the adjacent outside value is strictly less than the current interval sum. Since the sum only grows, each starting index has a unique maximal reachable interval. The key is to compute these maximal intervals for all K without simulating each independently, likely using prefix sums plus a monotonic/Cartesian-tree or divide-and-conquer structure based on maximum values. Then output the interval sum for each K. The implementation must be efficient enough for N up to 5e5.
