- **Sample tests:** PASS by manual verification: `"cdcd" -> "cccc"`, `"aca" -> "aaa"`, `"bc" -> ""`. Additional checks: `n < 3` returns empty, all-same strings return themselves, and lexicographic ties such as `"abab"` choose `"aaaa"`.
- **Problem model:** Changing `caption[i]` to target character `c` costs `abs(ord(caption[i]) - ord(c))`. A good caption has every maximal run length at least 3. If `n < 3`, impossible; if `n >= 3`, always possible by making the whole string one run.
- **DP state:** `dp[i][c][l]` is the minimum cost to complete positions `i..n-1` given an open run of character `c` with current length capped at `l`, where `l=3` means length at least 3. Flattened state index is `c * 3 + (l - 1)`.
- **Transitions:** For `l=1`, only extend to `l=2`. For `l=2`, only extend to `l=3`. For `l=3`, either extend the same character or switch to a different character, starting a new run of length 1. At `i=n`, only `l=3` is valid.
- **Switch optimization:** For each position, compute `g[d] = dist(d, caption[i]) + dp[i+1][d][1]`. The best switch excluding current character `c` is obtained from best and second-best values over all 26 characters, giving O(26n) time.
- **Storage:** A flat `array('i')` stores all suffix layers: `(n+1) * 78` 32-bit integers, about 16 MB at maximum constraints. `INF = 10**9` is far above the maximum real cost `25 * 50000 = 1.25e6`. Invalid values are capped to `INF` to keep arithmetic clean.
- **Reconstruction:** First choose the smallest character `c` such that `dist(c, caption[0]) + dp[1][c][1] == ans`. Then process left to right maintaining current state and remaining optimal cost `rem = dp[i][state]`. Try target characters from `'a'` to `'z'`; allow extension always, and allow switching only when current capped length is 3. Choose the first character satisfying `here_cost + dp[i+1][next_state] == rem`.
- **Pitfalls handled:** Final run must have capped length 3; switching to the same character is disallowed because adjacent same runs merge; capped length must not allow closing runs of length 1 or 2; lexicographic ties are resolved by trying characters in increasing order and using exact suffix-cost equality; `n < 3` returns empty string.
- **Complexity:** Time O(26n). Memory O(78n) with compact 4-byte integer storage, plus small input/output buffers.
