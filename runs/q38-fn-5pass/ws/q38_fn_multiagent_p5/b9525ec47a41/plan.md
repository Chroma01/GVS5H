The center indegree is forced by the fixed total indegree \(N+\operatorname{popcount}(s)\), so it suffices to count feasible length-\(N\) prefixes \((d_0,\ldots,d_{N-1})\). Encode each cycle edge orientation by a binary variable \(a_i\); for vertex \(i\), the pair \((a_{i-1},a_i)\) must belong to a small relation determined by \(s_i\) and \(d_i\). Feasibility of a cyclic prefix is exactly that the composition of these relations contains a diagonal pair \((a_{-1}=a_{N-1})\), which can be recognized by a 16-state DFA whose states are relations on \(\{0,1\}\). Run a linear DP over this DFA, counting label sequences \((d_i)\) rather than orientations, and merge different \(d_i\) symbols that induce the same DFA transition. The answer is the total DP weight in accepting states after processing all \(N\) vertices, modulo \(998244353\).
