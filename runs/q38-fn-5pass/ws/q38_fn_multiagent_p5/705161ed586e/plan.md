Model the cost of changing `caption[i]` to a target character `c` as the absolute alphabet distance. Use suffix dynamic programming with state `(last character, current run length capped at 3)`, where length `3` means the current run already has at least 3 occurrences. Compute `dp[i][c][l]` from right to left as the minimum cost to finish positions `i..n-1` given the current run state before `i`; transitions either extend the current run or, only when `l == 3`, switch to a new character. Optimize switch transitions by precomputing the best and second-best values over all possible new characters, giving `O(26 * n)` time. Store the suffix DP compactly for all positions, then reconstruct the lexicographically smallest optimal caption greedily by trying characters from `'a'` to `'z'` and keeping the smallest one that can still achieve the optimal remaining cost.
