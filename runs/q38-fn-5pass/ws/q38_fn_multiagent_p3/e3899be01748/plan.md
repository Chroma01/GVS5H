Use a dynamic programming scan from left to right. For each possible non-zero last digit `d` from 1 to 9, maintain the frequency of residues modulo `d` for all substrings ending at the previous position. When reading the next digit `x`, extend every previous substring by `x` and also start a new substring consisting of `x`, updating residues modulo each `d`. If `x == d`, add the number of substrings ending here with residue 0 to the answer. Digits `0` do not contribute directly, but substrings ending in `0` must still be tracked because they can be extended later.
