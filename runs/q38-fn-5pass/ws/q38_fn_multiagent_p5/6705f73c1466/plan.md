Treat the positions of the `1`s as the only relevant elements, since adjacent swaps move individual `1`s through `0`s. If the `1`s end up in consecutive positions starting at some offset `x`, the `i`-th `1` should move to position `x + i`. Minimizing the total adjacent swaps is therefore minimizing `sum |pos[i] - (x + i)|`, which becomes minimizing `sum |(pos[i] - i) - x|` over `x`. This is solved by choosing `x` as the median of the adjusted values `pos[i] - i`, then summing absolute deviations. The final answer is that sum, using 64-bit integer arithmetic.
