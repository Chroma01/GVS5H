- **Core formula:** For a center B, valid triplets correspond to ordered pairs (A, C) in S with A + C = 2B. Since 2B is even, A and C must have the same parity. Encode even values s = 2u and odd values s = 2u + 1 separately by u = s // 2. Even-even pairs contribute the self-convolution coefficient at index B. Odd-odd pairs contribute the self-convolution coefficient at index B - 1. Summing these two coefficients over all B in S gives all ordered pairs including the invalid self-pair (B, B). The answer is (total - N) // 2.
- **Carry-free big-integer convolution:** For each parity, pack its indicator as bits at bit positions base * u, where base = max(even_count, odd_count).bit_length(), at least 1. This represents a polynomial in base B = 2^base with digits 0 or 1. Squaring the packed integer produces coefficients c_k = number of ordered pairs with u + v = k. Since each c_k <= parity_count < 2^base, no coefficient carries into the next base-B digit.
- **Packing details:** A fixed bytearray of size 1,000,001 stores membership, avoiding a large Python list of input values. Counts and maxima are computed while parsing. Packing loops over even and odd value ranges separately, setting one bit per present value at bit position base * u. This avoids multiplication inside the inner loop by incrementing the bit position by base each step.
- **Extraction details:** After squaring, convert each squared integer to little-endian bytes with at least 8 extra padding bytes. For coefficient index k, its bits start at bit position base * k. Read an 8-byte little-endian chunk at byte offset (base * k) // 8 using struct.unpack_from('<Q', ...), shift right by (base * k) % 8, and mask with (1 << base) - 1. Under the constraints base <= 19, so the coefficient always fits inside the 64-bit chunk after the bit offset.
- **Indexing by center:** For each present value s, add coefficient index s from the even convolution and coefficient index s - 1 from the odd convolution. The implementation loops odd centers and even centers separately to keep bit positions incremental. Single-parity cases skip unnecessary zero-data reads.
- **Input parsing:** A manual byte parser avoids the memory spike of split() on one million tokens. It skips the first integer N, marks present values, and tracks parity counts and maximum values. The fixed present array relies on the constraint S_i <= 10^6.
- **Complexity and performance:** Packing and extraction are O(max(S) + N) Python-level operations, dominated by two big-integer squarings of about base * 500000 bits each in the worst dense case. The big-integer multiplication is done in C; Python-level work is mainly parsing, bit packing, and 2 million struct extractions in the worst case.
- **Edge cases:** N < 3 returns 0 immediately. If one parity is empty, only the corresponding convolution is built and read. Odd value 1 maps to u = 0, while even values start at u = 1 because 0 is not in S. The self-pair subtraction uses N = even_count + odd_count, which is valid because input values are distinct.
