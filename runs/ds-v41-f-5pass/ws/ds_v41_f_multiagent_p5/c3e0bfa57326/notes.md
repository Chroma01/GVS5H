- **Reduction:** A valid parenthesis sequence is a rooted ordered forest; add a virtual root (node 0) so the whole string is one plane rooted tree.
- **Operation meaning:** A contiguous valid substring equals a consecutive block of siblings of one parent. The special reversal reverses that block's order and mirrors each selected subtree.
- **Reachability:** Pure sibling reversal is obtained by reversing the block then reversing each child individually (each child's substring is valid). Adjacent transpositions generate all sibling permutations; single-child reversal gives free mirroring. Hence reachable strings = all plane embeddings of the given unordered rooted tree.
- **Counting:** Number of distinct ordered trees with a fixed unordered shape = prod over nodes of (deg! / prod_c m_c!) where m_c are child isomorphism-class multiplicities. This equals prod deg! / |Aut| (rooted unordered automorphism group), which is the number of distinct strings (string <-> plane tree is a bijection; child subtree strings are primitive Dyck words so concatenations parse uniquely, making the product exact).
- **Recurrence form:** f(v) = multinomial(v) * prod_{children c} f(c); answer = f(virtual root) = product of node multinomials. Must include the virtual root's multinomial (counts top-level block orderings).
- **Implementation:** Iterative stack parse (no recursion). Nodes are created in preorder so children always have larger indices; iterate v from m-1 down to 0 to process children first. Canonical ID via sorted tuple of child IDs mapped through a dict (AHU for rooted unordered trees). Precompute factorials and inverse factorials up to m (max degree <= m-1). For each node multiply fact[d] and inv_fact[freq] for each distinct child id.
- **Validation:** Sample 1 `(())()` -> virtual root children classes {wrapped-leaf, leaf} distinct => 2!/(1!1!)=2; inner `(())` => 1 -> answer 2. Sample 2 `()` -> 1. Hand-checks: `(())` and `()` -> 1; root with two children both = "node with leaf + chain-of-2" yields prod multinomial 1*2*2 = 4 distinct strings (matches enumeration of order+orientation combos where s t vs t s are distinct but swapping identical orientations collapses), confirming multinomial formula over naive orientation products.
- **Complexity:** O(N log N) time, O(N) space, fine for N=5000.
- **Pitfalls avoided:** forgetting virtual root; recursion depth; treating isomorphic children as distinguishable (multinomial handles collisions); forgetting that block reversal also mirrors children.
