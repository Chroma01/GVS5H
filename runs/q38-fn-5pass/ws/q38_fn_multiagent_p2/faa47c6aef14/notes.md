- **Independence:** Red balls move only along permutation P, and blue balls only along Q. A ball can reach X iff its permutation cycle contains X. If any initial ball of a color is outside that cycle, the answer is -1.
- **One color reduction:** In the cycle containing X, every vertex has a unique directed distance to X. Paths from different starting vertices to X are nested by distance, so all initial balls of one color lie on the path from the farthest initial ball to X. Operating that path once, from farthest to predecessor of X, moves all balls of that color to X. The farthest ball gives a lower bound, so this path is necessary and sufficient.
- **Excluding X:** Operating X only moves already-targeted balls away. Deleting all operations on X from any valid sequence leaves a valid sequence with fewer operations, so an optimal sequence never operates X. Required paths therefore exclude X.
- **Two-color synchronization:** A valid operation sequence must contain the red required path and the blue required path as subsequences, because the farthest ball of each color must be moved along its path in order. Conversely, any sequence containing both paths as subsequences works: extra operations can only advance a ball earlier along its path, and X is never operated.
- **SCS formula:** The minimum length of a sequence containing two sequences as subsequences is |R| + |B| - LCS(R, B). Thus the answer is the shortest common supersequence length of the two required paths.
- **LCS via LIS:** Each required path has distinct vertices. Map vertices of one path to their positions, transform the other path into these positions, and compute the length of a strict LIS. This gives the LCS in O(N log N).
- **Implementation details:** Parse input 0-indexed. `build_path` follows the permutation from X to mark its cycle and store forward positions. It scans balls of that color, rejects unmarked vertices, computes distance as `cycle_length - position` with X distance 0, finds the farthest ball, and returns the path by following the permutation from farthest toward X. If no ball outside X exists, it returns an empty path.
- **Complexities:** Cycle checks and path construction are O(N). LCS/LIS is O(N log N). Memory is O(N).
- **Edge cases:** No balls or only balls at X gives answer 0. Self-loop cycles not containing X with balls are impossible. Disjoint paths give LCS 0. Conflicting orders force repeated common boxes, counted correctly by the SCS formula.
