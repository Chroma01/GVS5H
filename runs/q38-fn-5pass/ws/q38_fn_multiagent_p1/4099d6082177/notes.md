- **State definition:** For the rooted subtree at vertex v, `state[v] = -1` means impossible, `0` means the subtree is fully decomposed into complete K-vertex paths, and a positive value `l` means there is exactly one unfinished path of `l` vertices ending at v, which must be extended through the edge to v's parent.
- **One open path per subtree:** A subtree has only one edge to the rest of the tree, so at most one path can cross that edge. Its intersection with the subtree must be a path ending at the subtree root.
- **Transitions:** At v, inspect child states. Any child state `-1` makes v impossible. More than two positive child states is impossible because v would need degree greater than 2 in the path decomposition.
- **Zero positive children:** If no child needs v, then v must start a new unfinished path of length 1 upward, unless v is the root. For K > 1, a root with no positive child cannot be closed, so it remains state 1 and the answer is No.
- **One positive child:** If the child open path has length a, adding v gives length a + 1. It closes exactly when a + 1 == K; otherwise it must continue upward if a + 1 < K.
- **Two positive children:** If child open lengths are a and b, they must be joined through v. This uses both incident path edges at v, so the path cannot continue to the parent. It is valid exactly when a + b + 1 == K.
- **Modulo uniqueness:** If a subtree has size S and one open path of length l inside it, then S is congruent to l modulo K. Thus the open length is forced by the subtree size, and a closed subtree cannot be altered to provide a positive open segment. This justifies storing only one state.
- **Root correctness:** The root can be arbitrary. If a full decomposition exists, every subtree has the unique crossing path, so the DP reaches state 0 at the root. Conversely, state 0 at the root gives a valid decomposition by induction.
- **Implementation details:** Use iterative DFS to avoid recursion depth issues, build parent and postorder, then process vertices in reverse order. The algorithm is O(NK) time and memory. K = 1 is trivially Yes.
- **Edge cases:** K = 1, single vertex, K = 2 reduces to perfect matching, and two child remainders whose sum is less than K - 1 are impossible because v cannot also connect to its parent.
