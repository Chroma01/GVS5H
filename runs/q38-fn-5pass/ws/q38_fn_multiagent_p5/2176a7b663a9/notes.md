- **Core observation:** Two vertices are adjacent exactly when their intervals are disjoint. Since all vertex weights are positive, if the queried intervals are disjoint, the direct edge is always optimal.
- **Overlapping query reduction:** For overlapping intervals, order them as A then B so that L_A <= L_B (tie by smaller R). Overlap implies L_B <= R_A. Any path from A to B can be shortened to at most four vertices without increasing weight.
- **One-intermediate case:** If a path contains a vertex left of A (R < L_A) or right of both intervals (L > max(R_A, R_B)), that vertex alone connects A and B. This gives extra cost min(min R < L_A, min L > max(R_A, R_B)).
- **Two-intermediate case:** If no such one-intermediate vertex exists on the path, the first vertex after A must be right of A (L > R_A), and the last vertex before B must be left of B (R < L_B). Any such pair X, Y are disjoint because R_Y < L_B <= R_A < L_X, so A-X-Y-B is a valid path. The best such path uses the lightest X and lightest Y independently.
- **Query formula:** For overlapping s,t, answer is W_s + W_t + min( left_of(L_A), right_of(max(R_A,R_B)), right_of(R_A) + left_of(L_B) ), where left_of(x) means minimum weight with R < x and right_of(x) means minimum weight with L > x. If all candidates are infinite, output -1.
- **Preprocessing:** Coordinates are in [1, 2N]. Store minimum weight for each exact R and exact L. Build prefix minima over R and suffix minima over L. Then left_of(x) = pref[x-1], right_of(x) = suff[x+1]. This makes each query O(1).
- **Strict inequalities:** Intersection is empty only with strict endpoint separation. The candidate sets exclude s and t in the overlapping case: B has L_B <= R_A, A has R_A >= L_B, and neither endpoint can be left of L_A or right of max(R_A,R_B).
- **Tie handling:** When L_s = L_t, choosing the interval with smaller R as A preserves L_B <= R_A. In this containment-like case, the two-intermediate candidate never beats the one-intermediate left candidate, but including it is harmless.
- **Implementation details:** Read all integers into a list for speed. Use INF = 10**30. Arrays have length 2N+2 so indices 0 and 2N+1 serve as safe infinite sentinels. Output answers joined by newlines.
- **Complexity:** O(N + Q + 2N) time and O(N) memory.
