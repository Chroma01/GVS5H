- **Reduction to slopes:** From viewpoint (0,h), building i subtends the slope interval [-h/X_i, (H_i-h)/X_i] = [a_i, t_i]. Only closer buildings (smaller index) can block a building. Building i is visible iff some slope in its interval is not covered by the union of intervals of 1..i-1.
- **Key lemma:** If t_{i+1} <= t_i then interval(i+1) is a subset of interval(i), because -h/X_{i+1} >= -h/X_i and top slopes satisfy t_{i+1} <= t_i. So building i alone blocks all of building i+1. Therefore all buildings are visible iff t_1 < t_2 < ... < t_N strictly.
- **Touching counts:** At equality t_i = t_{i+1} the line to the top of i+1 passes through the top of i, and every lower point of i+1 is strictly inside building i. At the boundary the building is blocked, so the answer is the boundary value M itself (confirmed by sample 1 at h=1.5).
- **Threshold form:** t_{i+1} > t_i  <=>  h > f_i with f_i = (X_{i+1}*H_i - X_i*H_{i+1})/(X_{i+1}-X_i). All visible iff h > M = max_i f_i; not all visible exactly for h <= M. Answer is M when M >= 0.
- **Answer logic:** N == 1 -> always visible -> -1. M < 0 -> h=0 sees all -> -1. M >= 0 -> print M (including M = 0, e.g. sample 3).
- **Exact comparison:** All denominators X_{i+1}-X_i > 0. Compare fractions with big-int cross multiplication num*best_den > best_num*den (correct for negatives too). Numerator magnitude up to ~1e18, Python ints handle it. Keep this exact for selecting the max.
- **Output formatting (fixed):** Print the max intercept as a correctly-rounded Python float via f"{best_num / best_den:.18f}". The previous Decimal(prec=60) approach produced the exact decimal expansion (e.g. 17.142857142857142857) which fails the sample harness string match. Float formatting yields the required 18-decimal strings: sample 4 -> 17.142857142857142350 (double 120/7 = 17.1428571428571423496... rounds up at the 18th place). Well within the 1e-9 tolerance regardless.
