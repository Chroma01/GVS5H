- **Problem summary:** Build graph on `nums` where edge `(i,j)` iff `lcm(nums[i], nums[j]) <= threshold`. Count connected components. `n <= 1e5`, `nums[i] <= 1e9`, `threshold <= 2e5`.
- **Key observation (isolated values):** `lcm(a,b) >= max(a,b)`, so any value `> threshold` has no edges and is its own component. Add `len(nums) - len(active)` where `active = [v for v in nums if v <= threshold]`.
- **Key observation (connectivity characterization):** For active values (all `<= threshold`), `lcm(a,b) <= threshold` iff some `L <= threshold` exists with both `a | L` and `b | L` (take `L = lcm(a,b)`). Equivalently, `a` and `b` are joined in the hypergraph of active divisors of each `L <= threshold`.
- **Algorithm:** DSU over distinct active values. Use `first_divisor[L]` (size `threshold+1`, init `-1`) to record the first active value seen dividing `L`. For each active `v`, walk multiples `L = v, 2v, ... <= threshold`; set `first_divisor[L]=v` if unset, else `union(v, first_divisor[L])`. Because any two divisors of `L` have lcm dividing `L` (hence `<= threshold`), every such union is a valid edge.
- **Correctness of union rule:** If `lcm(a,b) = L <= threshold`, both divide `L`; when both processed, at least one triggers a union, so they land in the same component. Conversely every union joins true edges. Result matches the original graph exactly.
- **Counting:** Answer = number of distinct DSU roots among active values + number of values strictly `> threshold`.
- **Complexity:** Harmonic sieve over active values: `sum over active v of threshold/v <= threshold * H(threshold) ~ 2.4e6` for `threshold=2e5`. Near-linear, well within limits. Memory `O(threshold + n)`.
- **Verified examples:** `[2,4,8,3,9], 5` -> active `{2,4,3}`, `8,9` isolated; roots `{2,4}`, `{3}` -> `2 + 2 = 4`. `[2,4,8,3,9,12], 10` -> `12` isolated, active all connect via `lcm(2,3)=6` -> `1 + 1 = 2`.
- **Edge cases handled:** `threshold = 1` (only value `1` active, no unions); all values `> threshold` (returns `n`, handled by early `not active` check); duplicates bypassed since DSU indexed by distinct value (constraints guarantee uniqueness anyway); no overflow since lcm is never computed directly.
- **Implementation pitfalls avoided:** virtual multiples are never counted as nodes/roots; DSU indices come only from actual present values; `first_divisor` sized exactly `threshold+1`.
