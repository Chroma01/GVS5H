Use a DSU to maintain connected components, treating every node initially as its own component. Since any value greater than `threshold` cannot form an edge, those nodes remain isolated. For values `<= threshold`, two nodes are connected exactly when their values share some common multiple `m <= threshold`, because `lcm(a, b) <= threshold` iff there exists such an `m` divisible by both. Enumerate all multiples of each present value up to `threshold`, and for each multiple, union all present values that divide it using a `first_divisor` array. This avoids pairwise checks and runs in roughly `O(threshold log threshold)` time.
