Expand B^p as a sum of words in the fixed matrix A and elementary matrices for the zero cells, then sum over all nonzero replacements. For odd prime p, the one-variable sums vanish unless each used zero cell appears 0 or p-1 times; because the word length is p, this leaves only the all-A word and words with exactly one zero cell repeated p-1 times. These give (-1)^K times A^p plus simple row/column corrections for zero diagonal cells, and for p=3 an additional transpose correction for zero off-diagonal cells. For p=2 there is only one completion, so square it directly. Compute A^p modulo p by binary exponentiation and apply the O(N^2) corrections.
