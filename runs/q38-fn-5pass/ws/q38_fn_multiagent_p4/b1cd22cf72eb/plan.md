For a fixed common sum H, each final upper length u_i must satisfy max(0, H - D_i) <= u_i <= min(U_i, H), and the lower length is then H - u_i. Feasibility for this H is equivalent to choosing one value from each interval so that adjacent values differ by at most X, which can be checked in O(N) by propagating the possible range of u_i. If H is feasible, then H-1 is also feasible, so the feasible H values form a prefix and we can binary search the maximum feasible H. The minimum cost is then the total original length minus N times this maximum H.
