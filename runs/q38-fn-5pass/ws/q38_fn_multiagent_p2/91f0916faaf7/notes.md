- **Prime-wise decomposition:** For each prime p, let e_i = v_p(S_i). The condition f(S_i/S_{i+1}) = A_i is equivalent to |e_i - e_{i+1}| = v_p(A_i). The gcd condition is equivalent to min_i e_i = 0 for every prime p. The score product_i S_i factorizes as product_p p^{sum_i e_i}, so the final answer is the product over primes of independent per-prime sums.
- **Per-prime problem:** For fixed p, define d_i = v_p(A_i). Need sum of p^{sum e_i} over nonnegative integer paths e_1..e_N with |e_i-e_{i+1}|=d_i and at least one e_i=0. If a path touches 0, every height is at most H = sum_i d_i, so DP over heights 0..H is sufficient.
- **DP states:** Use two arrays total[h] and zero[h]. total[h] is the weighted sum of prefixes ending at height h, regardless of whether 0 has been visited. zero[h] is the weighted sum of prefixes ending at h that have already visited 0. Initialization: total[h] = p^h for all h, zero[0] = 1, zero[h>0] = 0.
- **Transitions:** If d=0, height stays h and weight multiplies by p^h. If d>0, target 0 receives total[d] (both seen and unseen become seen). For target h>0, total_new[h] = (total[h-d] + total[h+d]) * p^h, and zero_new[h] = (zero[h-d] + zero[h+d]) * p^h, using only valid source heights. The implementation splits target ranges to avoid boundary checks inside the main loop.
- **Complexity:** Sum of H over all primes equals sum_i Omega(A_i), at most 9*(N-1) because A_i <= 1000. The DP cost is O(N * sum_p H_p), about 9e6 iterations in the worst case. Memory is O(max H + number_of_primes * N), easily small.
- **Implementation details:** Factor all A_i using a smallest-prime-factor sieve. Build a dictionary mapping each appearing prime to its exponent sequence. Primes not appearing have per-prime contribution 1 and are skipped. All arithmetic is modulo 998244353. Edge case all A_i=1 gives answer 1.
