- **Problem structure:** Allowed points are the full grid `[0,W]x[0,H]` minus the inclusive forbidden rectangle `B=[L,R]x[D,U]`. A path is monotone (+x/+y), with arbitrary start and end among allowed points.
- **Full-grid helpers:** For a point `(a,b)`, paths ending there from any start are `P(a,b)=C(a+b+2,a+1)-1`. Paths starting there to any end are `Q(a,b)=C(W-a+H-b+2,W-a+1)-1`. The prefix sum of `C(x+y+2,x+1)` over `[0..X]x[0..Y]` is `pref_end(X,Y)=C(X+Y+4,Y+2)-X-Y-4`. Total full-grid paths in a `(w+1)x(h+1)` grid are `pref_end(w,h)-(w+1)(h+1)`.
- **Full outside count:** Count full-grid paths with start/end outside `B` by inclusion-exclusion over start/end inside `B`: `full_out = all - start_in_B - end_in_B + both_in_B`. `end_in_B` is `rect_sum(L,R,D,U)-area`; `start_in_B` is the same after reflecting coordinates `(x,y)->(W-x,H-y)`; `both_in_B` is `total_paths(R-L,U-D)` because monotone paths between two points inside `B` stay inside `B`.
- **Invalid paths:** `full_out` still includes paths that enter `B`. A monotone path entering `B` has a unique first entry, either bottom `(x,D)` from below (if `D>0`) or left `(L,y)` from the left (if `L>0`). The corner `(L,D)` is counted twice, correctly, because entry from below and from left are different paths.
- **First-entry contribution:** Bottom term for `x` is `P(x,D-1) * (Q(x,D)-P(R-x,U-D))`. In binomial form: `(C(x+D+1,D)-1) * (C(W-x+H-D+2,H-D+1)-C(R-x+U-D+2,U-D+1))`. Left term is analogous: `(C(L+y+1,L)-1) * (C(W-L+H-y+2,W-L+1)-C(R-L+U-y+2,R-L+1))`.
- **Edge sum implementation:** The edge sums are evaluated in `O(width+height)` using recurrences, not one `comb` per point. For bottom, maintain `A=C(x+D+1,D)`, `Q=C(W-x+H-D+2,H-D+1)`, `Inside=C(R-x+U-D+2,U-D+1)` and update `x->x+1` by ratios `(x+D+2)/(x+2)`, `(W-x+1)/(W-x+H-D+2)`, `(R-x+1)/(R-x+U-D+2)`. For left, update `y->y+1` by `(L+y+2)/(y+2)`, `(H-y+1)/(W-L+H-y+2)`, `(U-y+1)/(R-L+U-y+2)`. Modular inverses are precomputed only up to the maximum denominator actually used, and only if an edge has length > 1.
- **Boundary cases:** If `L=D=0`, no outside path can enter `B`. If `R=W` and `U=H`, no path that enters `B` can end outside. In both cases invalid paths are zero. `D=0` skips bottom entries; `L=0` skips left entries. One-dimensional grids are handled naturally by the same formulas.
- **Modulo/performance:** `MOD=998244353` is larger than all needed `n` (`<=2e6+4`), so factorial inverses are valid. Factorials and inverse factorials are stored in `array('I')` to save memory; the inverse array for recurrences is a list for speed. Invalid terms are accumulated as congruent integers without per-term modulo, then reduced at the end.
