- **Core characterization:** For BFS layers from vertex 1 with sizes b0=1,b1,...,bk, valid graphs have edges only inside a layer or between consecutive layers, and every vertex in layer i>0 chooses a nonempty subset of layer i-1. The parity condition is sum of even-indexed layer sizes = N/2.
- **Generating function:** For fixed layer sizes, labeled count is (N-1)! / prod b_i! times prod (1+x)^{C(b_i,2)} and prod ((1+x)^{b_{i-1}}-1)^{b_i}. After dividing by x^{N-1}, each added layer contributes invfact[b] * (1+x)^{C(b,2)} * (((1+x)^a-1)/x)^b, where a is previous layer size.
- **Evaluation DP:** Instead of polynomial convolutions, evaluate the divided polynomial H(x) at x=0..deg. State is (used, even_count, prev_size, parity). Transition adds next layer size b. At x=0, ((1+x)^a-1)/x is replaced by its limit a.
- **State pruning:** Keep only states with even_count <= N/2 and odd_count <= N/2. A necessary finishability test uses the next layer parity to bound how many additional even vertices can still be added. Afterwards, reverse reachability from balanced final states removes states that cannot exactly finish.
- **Degree reduction:** The maximum extra edge count is computed by a max-plus DP over the filtered state graph. A layer of size b after previous size a contributes b*(a-1)+C(b,2) extra edges. This actual degree is often smaller than D-(N-1), reducing interpolation points and giving trailing zeros.
- **No-mod accumulation:** During each scalar DP evaluation, destination dp entries are accumulated without modulo. When a state is read as a source, its value is reduced modulo P. Each state has at most N incoming transitions, so intermediate integers stay small enough.
- **Interpolation:** Values of A(x)=(N-1)!H(x) are obtained at consecutive points 0..deg. Newton finite differences convert them to power-basis coefficients. Since deg <= 406 and P > 1e8, all needed inverses exist. Coefficients beyond the actual degree are output as zero.
- **Complexity:** State count and transitions are small after pruning. Runtime is dominated by (deg+1) scalar DP passes plus O(deg^2) interpolation, easily within limits for N<=30.
- **Edge cases:** N=2 gives degree 0 and answer 1. Factorials and interpolation denominators are invertible because P>N and P>deg.
