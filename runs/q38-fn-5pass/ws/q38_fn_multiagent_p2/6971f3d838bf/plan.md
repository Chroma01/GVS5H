If all elements are non-positive, no deletion can create a positive sum, so return `max(nums)`. Otherwise, the original maximum subarray is positive, so we can safely use empty-allowed prefix/suffix/best aggregates without risking an invalid zero answer. Only deleting a negative value can improve the result; for a fixed negative `x`, removing all occurrences of `x` turns those positions into zero separators and leaves gaps of non-`x` elements. For each gap, we need its total sum, best prefix, best suffix, and best subarray, which can be obtained with a segment tree range aggregate query. Since the total number of gaps over all negative values is `O(n)`, scanning these gap aggregates per value gives an `O(n log n)` overall solution.
