Model the pieces as ordered particles and work with the gaps/runs of occupied squares: the operation preserves order, never increases the distance between two surviving pieces, and makes adjacent pieces behave as a rigid block that can only translate or merge. A correct solution should therefore characterize reachability and minimum operations via gap/run transformations (or an equivalent reverse-time expansion), not by independent nearest-target distances alone. For a fixed operation limit \(T\), derive a linear-time feasibility predicate by reversing the operation and greedily matching the expanded target runs/gaps against the initial runs/gaps. Binary search the minimum \(T\), using necessary impossibility checks such as insufficient pieces and non-embeddable target gaps to prune early.
