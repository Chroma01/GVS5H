Model the choice of K edges as assigning integer levels to vertices: we need levels from 0 at vertex 1 to d at vertex N, with every edge satisfying level(v) ≤ level(u)+1. The cost is the number of edges that increase the level by exactly 1; this cost must be ≤ K. This labeling problem is equivalent to a min‑cost flow dual: send flow from 1 to N where each edge’s first use costs 0 and each subsequent use costs 1. For a fixed target distance d, the minimum required K equals the sum over flow units with marginal cost < d of (d − marginal cost). Since the answer cannot exceed the shortest unweighted path length L from 1 to N, we can compute the first M marginal costs via successive shortest augmenting paths and check all d from 0 to L.
