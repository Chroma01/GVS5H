Characterize a Snowflake Tree by its center: it has x chosen neighbors, and each chosen neighbor has exactly y kept leaves. For any fixed center, a neighbor can serve as one of the x vertices only if its degree excluding the center is at least y, and then keeping it contributes y+1 vertices. Thus for each center, sort the values deg(neighbor)-1 and test candidate y values equal to those sorted values. The maximum number of kept vertices over all centers and valid y gives the answer as N minus that maximum. Efficiency is O(N log N) by processing each vertex’s neighbor list.
