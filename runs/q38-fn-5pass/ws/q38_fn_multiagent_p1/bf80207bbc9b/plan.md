Model each row as a W-bit mask and note that row/column flips commute, so the final cell is `A[i][j] xor rowFlip[i] xor colFlip[j]`. For a fixed column-flip mask, each row can independently choose its row flip to minimize its number of ones, giving cost `min(popcount(rowMask xor colMask), W - popcount(rowMask xor colMask))`. Count frequencies of row masks, then compute the total cost for every column mask as an XOR convolution between the row-mask frequency array and the cost-by-popcount array. Use Fast Walsh-Hadamard Transform to compute this convolution in `O(W * 2^W)` time, then take the minimum value.
