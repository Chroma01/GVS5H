- **Core property:** After any prefix of contests, the final/current rating is a nondecreasing function of the initial rating. Therefore, among sorted unique queried initial ratings, the indices whose current rating lies in `[L, R]` form one contiguous block. It is sufficient to maintain values only at queried initial ratings.
- **Chosen method:** Build a lazy segment tree over the sorted unique query values. Leaf `i` stores the current rating for initial value `vals[i]`. For each contest `[L, R]`, compute `l = first_ge(L)` and `r = first_ge(R + 1) - 1`. If `l <= r`, add `1` to `[l, r]`. This uses only maximum values, not minimums.
- **No-push lazy tree:** Store `mx[k]` as the maximum in node `k` excluding ancestors' lazy additions, and `lazy[k]` as pending addition for the whole node. Invariant: `mx[k] = max(mx[2k], mx[2k+1]) + lazy[k]`. A full-cover update increments both `mx[k]` and `lazy[k]`. A partial range update applies to canonical nodes and then pulls ancestors using the invariant. No push is needed during updates.
- **Search without push:** `first_ge(x)` carries `need = x - sum(lazy ancestors)`. At node `k`, the actual maximum of the left child is `mx[left] + lazy[k] + ancestors`, so compare `mx[left] + lazy[k] >= need`. Descend left if true, otherwise right, then subtract `lazy[k]` from `need`. Padding leaves have very negative `mx`, so they are never selected for positive query thresholds.
- **Complexity:** Let `M` be the number of unique query values, `M <= Q`. Each contest performs two `O(log M)` searches and one `O(log M)` range add. Final propagation is `O(M)`, answering is `O(Q)`. Memory is `O(M)`.
- **Edge cases handled:** `M = 1` with `size = 1` and no internal lazy nodes; empty update ranges; all current values below `L` or above `R`; non-power-of-two `M` with padding leaves; duplicate queries; ratings growing beyond `5e5`. `R + 1` is valid because all ratings are integers.
- **Implementation notes:** Read all input first because the queries determine the compressed domain. Use a max-only segment tree, `NEG = -10**9`, iterative range add, and push all lazy values to leaves before answering. Map query values to indices with a dictionary for fast output.
