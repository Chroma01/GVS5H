- **Approach:** Model constraints as an undirected graph with XOR edge weights. For each connected component, fix one root to 0 and compute relative values `val[v]` by iterative DFS/BFS. If every edge satisfies `val[u] xor val[v] = Z`, the component is consistent.
- **Solution form:** In a consistent component, every valid assignment is `A[v] = C xor val[v]` for one component-wide constant `C`. The root value itself is `C`.
- **Consistency check:** During traversal, when an edge reaches an already visited vertex, verify the implied XOR. A mismatch means no good sequence exists. This also catches self-loops with nonzero weight and inconsistent cycles.
- **Minimization:** The total sum separates by bit: `sum(A) = sum_b 2^b * (# of vertices with bit b set)`. For each bit, if `cnt` vertices have that bit set in `val`, choosing `C_b = 0` gives `cnt` ones, while `C_b = 1` gives `size - cnt` ones. Choose the smaller; ties may choose 0.
- **Bit range:** Only bits up to `max_z.bit_length() - 1` can appear in any relative value. Higher bits are all zero in `val`, so setting them in `C` would only increase the sum. If `max_z = 0`, no bits need processing.
- **Implementation details:** Use iterative stack to avoid recursion depth issues. Store components in a list so the optimal constant can be applied after bit counts are known. Use `val = [-1] * n` as unvisited sentinel; all real relative values are non-negative.
- **Optimization:** Track `has_nonzero` while assigning vertices. If a component has only zero relative values, skip bit counting and use `C = 0`. For nontrivial components, count set bits by scanning the component once per bit mask.
- **Edge cases:** `M = 0` gives all zeros. Isolated vertices are singleton components with value 0. Self-loops with `Z = 0` are harmless; self-loops with `Z != 0` are contradictions. Parallel edges are checked naturally.
- **Complexity:** Graph construction and traversal are `O(N + M)`. Bit counting is `O(N * B)` where `B <= 30` for `Z_i <= 1e9`. Memory is `O(N + M)`.
- **Pitfalls:** Do not use recursive DFS. Do not forget to assign answers for components where the optimal constant is zero but relative values are nonzero. Do not consider bits above the maximum bit present in any `Z`.
