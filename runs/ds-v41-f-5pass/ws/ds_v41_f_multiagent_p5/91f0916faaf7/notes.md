- **Problem structure:** For coprime P,Q, f(P/Q)=PQ. Writing reduced S_i/S_{i+1}=u_i/v_i gives u_i*v_i=A_i and gcd(u_i,v_i)=1. Therefore for each prime p, the exponent difference v_p(S_i)-v_p(S_{i+1}) equals +v_p(A_i), -v_p(A_i), or 0 when v_p(A_i)=0. Zero exponent edges force equal exponents on adjacent positions.
- **Decoupling over primes:** The choosing of which side of each edge gets p^{v_p(A_i)} is independent per prime. Score = prod_i S_i = prod_p p^{sum_i e_{i,p}}. The gcd condition is equivalent to: for every prime p, min_i e_{i,p} = 0 (primes not dividing any A_i can be set to exponent 0 and give factor 1). Hence answer = product over primes p dividing some A_i of F_p, where F_p sums p^{sum_i(e_i - min e)} over all valid sign choices of steps ±v_p(A_i).
- **Per-prime walk:** With a_i=v_p(A_i), the sequence e_i is a walk with steps 0 (a_i=0) or ±a_i, normalized so its global minimum is 0. Translation invariance lets us set the minimum to 0.
- **First-global-min split:** Pick the smallest index j attaining the minimum. Then F_p = sum_{j=1..N} L_j * R_j where L_j uses edges left of j as a walk that stays strictly positive (after reversing, a positive walk starting at 0), and R_j uses edges right of j as a nonnegative walk starting at 0. Every sign choice has a unique j, so the split is a bijection.
- **DPs used:** L_j = D_j(0) with forward recurrence D_{i+1}(h') = p^{h'-v}D_i(h'-v) + p^{h'+v}D_i(h'+v), initial D_1(h)=1 for h>=1, landing L_{i+1}=p^v D_i(v). R_j = V_j(0) with backward recurrence V_i(h) = p^{h+v}V_{i+1}(h+v) + [h>=v] p^{h-v}V_{i+1}(h-v), base V_N(h)=1. Zero edges multiply every entry by p^h. Arrays have size W_p+1 with W_p=sum_i v_p(A_i); only positions j=1 or a_{j-1}>0 give nonzero L_j, and R is stored at the same positions.
- **Complexity:** sum over primes of W_p = sum_i Omega(A_i) <= 9*1000 = 9000. Each prime processes n-1 edges on an array of length W_p+1, so total ~ (n-1)*sum W_p <= 9e6 list-element operations per DP, well within limits. All arithmetic modulo 998244353.
- **Verification:** Sample 2 (N=2,A=[9]) gives F_3 = 2*9 = 18. For Sample 1, p=2 exponent vector [0,0,1,1,0] gives F_2 = 194, p=3 vector [0,2,0,0,2] gives F_3 = 4843476, product 194*4843476 mod 998244353 = 939634344, matching. Hand traces of both DPs (L_j, R_j) confirmed the intermediate values.
- **Edge cases:** A_i=1 contributes nothing; all-A=1 gives answer 1. N=2 formula reduces to 2*p^e. Heights capped by total W_p; states above W_p can never return to 0 and are safely dropped.
- **Sample outputs expected:** 1) 939634344, 2) 18, 3) 192457116.
