- **Model:** one binary variable per physical grid edge = whether the segment touches that edge midpoint. No-dead-end on the torus means the two half-edges across every shared cell boundary are equal, so the half-edges glue into a single per-edge variable (wrap-around edges included).
- **Cell constraints:** define x[i][j] = horizontal edge on top of cell (i,j) (equal to the bottom edge of cell above), y[i][j] = vertical edge on left of cell (i,j) (equal to right edge of left neighbour). With c=1 for A, 0 for B, every cell gives x[i][j] xor x[(i+1)%H][j] = c[i][j] and y[i][j] xor y[i][(j+1)%W] = c[i][j]. Type A needs exactly these (one of top/bottom and one of left/right active). Type B additionally needs x[i][j] xor y[i][j] = 1. This is a complete characterisation.
- **Parametrisation:** a_j = x[0][j], x[i][j] = a_j xor G[i][j] (G = prefix of c down the column). b_i = y[i][0], y[i][j] = b_i xor Hh[i][j] (Hh = prefix of c along the row). Consistency around the torus requires G[H][j]=0 for every column and Hh[i][W]=0 for every row, i.e. every column sum and every row sum of c is even; otherwise answer is 0.
- **B-cell equations:** for each B cell, a_j xor b_i = 1 xor G[i][j] xor Hh[i][j]. If a grid cell is A, no cross equation is added.
- **Counting:** this is a GF(2) system over H+W nodes (W column vars a_j, H row vars b_i). If consistent, the number of solutions is 2^(number of connected components of the constraint graph, counting isolated nodes). Components = (H+W) minus the number of successful merges.
- **Algorithm:** DSU with parity over H+W nodes. Row node for i is index W+i, column node j is index j. Maintain Gcol[j] and hprefix so each B cell yields its equation in O(1). Check row sums (hprefix after each row) and column sums (Gcol after all rows) are even. O(HW) per test, O(sum HW) overall.
- **DSU parity convention:** par[x] = value[x] xor value[parent[x]]. find returns (root, value[x] xor value[root]). For union(a,b,p) requiring value[a] xor value[b]=p: if same root, consistent iff pa xor pb == p; else par[child] = p xor pa xor pb, and this is the same value whether ra or rb is attached (xor is symmetric).
- **Verification:** samples give 2, 0, 2. Hand checks: all-A 2x2 -> 2^4=16 (four free bits, no B coupling); all-B 2x2 -> 2^1=2 (all-horizontal or all-vertical only); all-A 2x3 -> 0 (odd row sum / odd cycle of != constraints). 2x2 with even row/col sums forces c all-equal, giving 16 or 2.
- **Pitfall:** row node index must be W+i (not H+i); using H+i collides with column nodes when H>W.
