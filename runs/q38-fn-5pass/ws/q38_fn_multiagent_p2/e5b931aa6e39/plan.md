Use the factorization x^3 - y^3 = (x-y)(x^2+xy+y^2). Let d = x-y, so d is a positive divisor of N and x = y+d. For each possible d, substitute x = y+d to obtain a quadratic equation in y: 3y^2 + 3dy + d^2 = N/d. Since d^3 <= N, it is enough to test d up to the integer cube root of N, which is at most 10^6. For each divisor d, check whether the quadratic has a positive integer solution using an integer discriminant test.
