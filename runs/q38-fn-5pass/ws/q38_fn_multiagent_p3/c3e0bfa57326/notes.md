- **Representation:** A valid parenthesis sequence is an ordered rooted forest. Add a super-root whose children are the top-level balanced components. Each matching pair of parentheses corresponds to one node, and its immediate enclosed components are its children.
- **Operation effect:** The operation reverses a valid substring and swaps parentheses. In tree terms, this is the mirror image of a contiguous forest of sibling subtrees: it reverses the order of those siblings and recursively mirrors each subtree. Therefore the unordered rooted tree shape is invariant.
- **Reachability:** Any adjacent pair of sibling subtrees A and B can be swapped while preserving their internal ordered forms. Apply the operation to AB, obtaining mirror(B) mirror(A). Then apply the operation separately to mirror(B) and mirror(A), restoring B and A in swapped order. Adjacent swaps generate arbitrary permutations of children at every node. Since operations inside a subtree do not affect its position, all ordered trees with the same unordered rooted tree shape are reachable, and no other shapes are reachable.
- **Counting formula:** For each node, group its children by unordered-subtree isomorphism class. If the node has degree d and class multiplicities m_1, m_2, ..., then the number of distinct local child orderings is d! / product(m_i!). The total number of reachable strings is the product of these local multinomial factors over all nodes, including the super-root. This product also correctly accounts for independently choosing ordered variants inside repeated isomorphic subtrees.
- **Canonical subtree IDs:** Parse the tree iteratively with a stack. Node indices are assigned in preorder, so processing nodes in reverse index order guarantees that every child is processed before its parent. For each node, collect canonical IDs of its children, sort them, and use the resulting tuple as a dictionary key to assign a canonical unordered-subtree ID. The empty tuple represents a leaf.
- **Implementation details:** Precompute factorials and inverse factorials up to the number of nodes modulo 998244353. During the bottom-up pass, after sorting child IDs, multiply the answer by fact[d] and by invfact[count] for each group of equal child IDs. The super-root is processed like any other node for top-level forest permutations.
- **Complexity:** There are at most N/2 real nodes plus the super-root. Sorting all child lists costs O(N log N) in the worst case, and memory usage is O(N). With N <= 5000 this is easily fast enough.
- **Edge cases:** The code handles an empty forest if present, high-degree nodes, many identical subtrees, and avoids recursion depth issues by using an explicit stack and reverse-index processing.
