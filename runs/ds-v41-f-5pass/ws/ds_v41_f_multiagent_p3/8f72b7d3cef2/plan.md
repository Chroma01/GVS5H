The process is deterministic: a slime can always absorb any adjacent smaller slime, and absorbing more never reduces future options. The final interval for each start is the maximal contiguous segment reachable by expanding to smaller adjacent boundaries. Build a max Cartesian tree (with tie-breaking) where each node's subtree corresponds to the segment it dominates. For each node, compute its segment sum and whether it can start expanding within its own segment via a strictly smaller immediate neighbor. Also compute whether its segment sum exceeds its parent's value, meaning a start that has consumed the node's segment can absorb the parent and then the parent's entire segment. Propagate reachability upward to find the highest ancestor whose segment becomes the final answer. Finally, output either that segment sum or the initial value if no expansion is possible.
