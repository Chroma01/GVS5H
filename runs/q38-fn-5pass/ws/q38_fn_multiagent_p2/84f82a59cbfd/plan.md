A 400 number is exactly a square of an integer whose prime factorization contains exactly two distinct primes, because all exponents in the 400 number are even. Since A is at most 10^12, the square root is at most 10^6, so we can precompute all valid square roots up to 10^6 using a sieve that counts distinct prime factors. Squaring those roots gives all 400 numbers up to 10^12, which can be sorted once. Each query can then be answered by binary searching the largest precomputed 400 number not exceeding A.
