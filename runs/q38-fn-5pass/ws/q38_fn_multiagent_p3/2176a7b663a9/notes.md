- **Structural proof:** If s,t are disjoint, the direct edge is optimal because all vertex weights are positive. If s,t intersect, consider any path. The first internal vertex is disjoint from s. If it is also disjoint from t, a two-edge path exists. Otherwise it must lie strictly on the side of s opposite the overlap with t. The last internal vertex has the symmetric property. If neither gives a two-edge path, the first and last internal vertices lie on opposite sides of the overlap, hence are automatically disjoint, so the path can be shortened to three edges. Same-side three-edge paths are dominated by a two-edge path because one of the two intermediates is disjoint from both endpoints. Thus only direct, two-edge, and two cross-side three-edge shapes matter.
- **Query formula:** For intersecting s,t, the answer is W_s+W_t plus the minimum of four intermediate costs: common left minimum with R < min(L_s,L_t); common right minimum with L > max(R_s,R_t); left-of-s plus right-of-t; right-of-s plus left-of-t. The cross pairs are automatically disjoint because s and t intersect. If all four costs are infinite, no path exists.
- **Precomputation:** Store minimum weight at each right endpoint and take prefix minima, so left[x] is the minimum weight with R <= x; use left[coord-1] for R < coord. Store minimum weight at each left endpoint and take suffix minima, so right[x] is the minimum weight with L >= x; use right[coord+1] for L > coord. Coordinates are at most 2N, so arrays of size O(N) suffice.
- **Edge cases:** Closed intervals require strict inequalities; touching at an endpoint is intersection, not an edge. Isolated vertices intersect every interval, and the formula naturally yields no intermediate. Boundaries L=1 and R=2N are handled by index 0 and maxC+1 sentinels. The same vertex cannot be chosen twice in a cross sum because the two side conditions are mutually exclusive for intersecting endpoints.
- **Validation:** The program contains a brute-force validator that runs only when stdin is empty. It builds the explicit graph for N <= 8, computes exact minimum vertex-weight paths with Dijkstra, and compares them with the formula on 1000 random cases plus adversarial cases: containment, endpoint touching, all isolated, duplicates, boundary points, induced P4, and missing cross intermediates. The formula is confirmed by these checks and by the proof above.
- **Complexity:** Preprocessing is O(N + max coordinate) = O(N), each query is O(1), total O(N + Q), memory O(N).
