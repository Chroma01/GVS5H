For a target distance D, characterize feasibility by integer potentials p_v in [0,D] with p_1=0, p_N=D, and p_v ≤ p_u+1 for every edge u→v. If we set exactly the edges with p_v=p_u+1 to weight 1, every 1→N path uses at least D such edges; conversely, any choice of K edges achieving distance D yields such a potential with at most K +1 edges. Thus, for each D, we need the minimum possible number of +1 edges, which can be computed as a minimum s-t cut on a layered graph with binary variables x_{v,i}=1 iff p_v≥i. Infinite edges enforce monotonicity x_{v,i}⇒x_{v,i−1} and constraints x_{v,i}⇒x_{u,i−1}; unit edges count x_{v,i}=1 and x_{u,i}=0. Scan D downward from min(K, unweighted shortest path length) and output the first D whose min-cut value is ≤K.
