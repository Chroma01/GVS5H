Use the small target length (≤4) to treat coverage requirements as a bitmask over target indices. For any subset of targets, one nums element can satisfy all of them only if it becomes divisible by their LCM; the cheapest way is to round it up to the next multiple of that LCM. Compute this cost for every nums element and every subset, then run a DP over masks where adding an element with chosen subset updates covered targets to mask|subset with the computed cost. Since there are at most 16 masks and 16 subsets per element, processing all nums is efficient. The answer is the minimum cost to cover the full target mask.
