Model the constraints as a functional graph where each edge i→A_i requires x_i≤x_{A_i}. Every weak component has exactly one directed cycle, and the inequalities force all cycle nodes to share the same value. For each cycle value c, attached trees can be counted bottom-up with DP g_v(c)=∏_{child u}(∑_{t=1}^{c} g_u(t)). The component total is then ∑_{c=1}^{M} ∏_{v in cycle} g_v(c), and the answer is the product over all components modulo 998244353. Complexity is O(NM), which is safe for N,M≤2025.
