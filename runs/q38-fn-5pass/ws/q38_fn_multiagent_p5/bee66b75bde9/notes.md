- **Core reduction:** A valid coloring is completely determined by row prefix lengths r_x, where row x has black cells exactly in columns 1..r_x. The row condition is automatic, and the column condition is equivalent to r_1 >= r_2 >= ... >= r_N.
- **Bounds from given cells:** A black cell (x, y) forces r_x >= y. A white cell (x, y) forces r_x <= y - 1. For each constrained row, keep L_x as the maximum black column and U_x as the minimum white column minus one. Default values are L_x = 0 and U_x = N.
- **Existence criterion:** A nonincreasing sequence satisfying all bounds exists iff for every row x, max_{j >= x} L_j <= U_x. Necessity follows because r_x must be at least every lower bound below it. Sufficiency follows by choosing r_x = max_{j >= x} L_j, which is nonincreasing and satisfies all upper bounds exactly when the condition holds.
- **Sparse processing:** Since N is huge but only M cells are constrained, only rows appearing in the input need explicit checks. Unconstrained rows have L = 0 and U = N, so they cannot violate the condition. Sort constrained rows in descending order and maintain the maximum L seen so far, representing the suffix maximum over rows at or below the current row.
- **Same-row handling:** For each row, aggregate all black constraints into one lower bound and all white constraints into one upper bound. When scanning a row, update the suffix maximum with that row's lower bound before checking against its upper bound; this catches same-row black/white contradictions.
- **Implementation details:** Use dictionaries for lower and upper bounds. The set of rows to scan is the union of keys from both dictionaries. Input is read all at once for speed. Output is Yes if no violation is found, otherwise No.
- **Edge cases:** White cells in column 1 impose U = 0. Rows with only black constraints contribute to the suffix maximum for rows above them. Rows with only white constraints only check whether some lower row forces too many black cells. If M were 0, the answer would be Yes, although constraints state M >= 1.
- **Complexity:** O(M log M) time due to sorting constrained rows, and O(M) memory. This is independent of N.
