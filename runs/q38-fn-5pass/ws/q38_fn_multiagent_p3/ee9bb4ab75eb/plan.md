Use a trie to represent all prefixes and store how many words pass through each node. For a removed word, a prefix remains usable if its count after removal is at least k; nodes with count > k are always usable, while nodes with count == k are usable only when the removed word does not have that prefix. Compute the maximum depth among always-usable nodes once, then for each word find the maximum depth among count==k nodes not on its root-to-end path. Maintain these count==k nodes in a depth-frequency structure while doing an iterative DFS, temporarily removing nodes on the current path, and query the largest active depth at terminal nodes. Combine the two maxima for each index, returning zeros when removing one word leaves fewer than k strings.
