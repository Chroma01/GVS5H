- **Label/inversion model:** Assign each element a deletion-batch label. If labels are compressed to deletion order, adjacent swaps needed equal the inversion count of the label sequence, and deletion operations equal the number of distinct labels. For equal values, labels can be assumed nondecreasing along original occurrences.
- **Run-level DP:** Consecutive equal elements are compressed into weighted runs. State `(p, l, one)` means previous batch value `p`, current latest batch value `l`, and whether the current latest batch has total length exactly one. For a run `(v, w)`: if `v == l`, join current batch and set `one=False`; otherwise start a new batch with cost `+1`. Additionally, if `v == p`, current batch is singleton, and this run is singleton, put the run into the previous batch with cost `+1`, keeping state `(p, l, True)`.
- **Why only singleton backward extension:** Extending an older batch across the current latest batch costs `size(current) * size(new)` inversions. If this product is at least 2, starting a new batch (cost 1) and, if needed later, starting a new batch for the crossed value (another cost 1) is never worse. Thus only crossing a singleton over a singleton can be strictly useful; all other cases can be matched by starting new batches.
- **DP size:** The current latest batch value is always one of the last two relevant run values, and the previous batch value is correspondingly constrained. In practice and by this invariant, the DP dictionary remains constant-size, so the solver is O(total N).
- **Sentinel caveat:** The DP uses `0` as the sentinel for “no previous batch”, so it is only directly valid for positive input values. The verifier maps canonical labels `0,1,...` to `1,2,...` before calling the DP.
- **Canonical brute force:** Cost depends only on equality pattern, so exact distances are computed on canonical restricted-growth strings. Reverse BFS from the empty sequence uses reverse swaps and reverse deletions (prepend any positive equal block, then canonicalize). Existing labels plus one new label are sufficient for reverse deletions.
- **Optimized BFS edges:** All BFS states are kept canonical. For adjacent swaps, if both swapped values are first occurrences, only their label order swaps; otherwise the simple adjacent swap is already canonical. For prepends, explicit label transformations avoid generic canonicalization: new value becomes label 0 and old labels shift; existing value `v` becomes 0, labels `< v` shift +1, labels `> v` stay.
- **Verifier completeness:** The verifier generates all canonical patterns independently and reports any missing from BFS. It also checks every BFS state against the DP. The exhaustive verifier for length <= 8 passes.
- **Stress mode:** With empty stdin, the program first runs exhaustive verification up to length 8. If that passes, it builds exact distances up to length 10, exhaustively checks all canonical states up to 10, and additionally checks random raw sequences of lengths 9/10. The test mode prints any missing patterns or DP/brute-force mismatches.
- **Current result:** The included verifier/stress mode reports no counterexamples; the original solver path is finalized.
- **Complexity:** Original solver: O(total N) time, O(1) DP states per test case. Test mode: exponential in `max_len` but tiny for `max_len <= 10`; not executed on normal judge input.
