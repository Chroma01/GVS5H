Model the constraints as a functional graph with edges i -> A_i, where values must be nondecreasing toward cycles; hence every cycle's values must be equal. For each component, fix the common cycle value c, count independent attached rooted-tree assignments with a DP over values 1..M, then sum over c and multiply components. Use Kahn pruning to separate cycle nodes from tree nodes and process trees leaves-to-roots efficiently in O(NM).
