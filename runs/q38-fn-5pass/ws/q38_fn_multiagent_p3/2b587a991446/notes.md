- **Core model:** The state space of ordered pairs is too large. The solution treats passing as using one gadget: either a branching vertex or a biconnected component. Outside the gadget, tokens move along shortest paths; the gadget supplies the order reversal.
- **Vertex gadget formula:** For a vertex v with original degree at least 3, let a=distS[v], b=distT[v]. Candidate is 2*(a+b)+extra. extra=2 if shortest-path predecessor neighbors from v toward S and T can be chosen distinct; otherwise extra=4. If S=v or T=v, extra=4. This covers tree-like passing using empty side branches.
- **Biconnected decomposition:** Use iterative Tarjan edge-stack to get vertex-biconnected components. Single-edge components are bridges and are skipped. Sum of component sizes is O(N+M).
- **Simple cycle blocks:** If a block has E=V and all internal degrees 2, it is a simple cycle. Candidate is cycle_length + 2*best, where best is the minimum ordered distinct pair distS[x]+distT[y]. This avoids the undercount that a general min-cost flow with global distances can cause on pure cycles.
- **Non-simple blocks:** Build a vertex-split network. For each block vertex v: source->v_out capacity 2 cost distS[v], v_in->sink capacity 2 cost distT[v], v_in->v_out capacity 1 cost 0. Each undirected block edge becomes two directed arcs out->in capacity 1 cost 1. Sending two units gives two internally vertex-disjoint paths and their outside entry/exit costs.
- **Flow implementation:** Successive shortest augmenting path with potentials, only two augmentations. Forward-star arrays are used to reduce memory. Dijkstra uses reduced costs and touched-node lists for potential updates.
- **Pruning:** Vertex candidates are computed first to get an initial upper bound. For a block, if 2*(min distS + min distT) >= current ans, skip flow. Source/sink edges whose cost plus the block minimum already reaches ans are omitted. The flow stops if the first augmentation already reaches ans.
- **Correctness intuition:** Bridges cannot reverse token order. A degree-3 vertex gives a local parking strategy with extra 2 or 4 depending on whether S and T approach through different branches. A cycle or 2-connected block gives two disjoint corridors; the min-cost flow finds the cheapest such pair. If no gadget exists, the graph is a path and the answer is -1.
- **Complexities:** BFS O(N+M). Tarjan O(N+M). Simple-cycle processing O(total block vertices). Flow is run only on non-simple blocks; total network size over such blocks is O(N+M), with two Dijkstra runs per block.
