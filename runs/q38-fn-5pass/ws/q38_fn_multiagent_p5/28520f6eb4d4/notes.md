- **Visibility reduction:** For observer `(0, h)` and target building `i`, the line to the top of building `i` is the highest possible line to that building at every earlier x-coordinate. If that line intersects an earlier building, every lower point on building `i` gives an even lower line there, so it also intersects. Thus building `i` is visible iff the line from `(0, h)` to `(X_i, H_i)` is strictly above `H_j` at every earlier `X_j`.
- **Critical height:** For a pair `j < i`, the line through their tops has y-intercept `b = (X_i * H_j - X_j * H_i) / (X_i - X_j)`. Building `i` is blocked by building `j` exactly when `h <= b`, because touching a top counts as intersection. All buildings are visible iff `h` is strictly greater than the maximum `b` over all pairs. Therefore the answer is the maximum non-negative pair intercept, or `-1` if all intercepts are negative. If the maximum is exactly `0`, the answer is `0`, not `-1`.
- **Adjacent-pair sufficiency:** For any three tops `A, B, C` in increasing x-order, compare `B` with the line `AC`. If `B` is on or above line `AC`, then the intercept of line `BC` is at least the intercept of line `AC`. If `B` is below line `AC`, then the intercept of line `AB` is at least the intercept of line `AC`. By induction over an interval, some adjacent pair inside the interval has intercept at least that of the endpoint pair. Hence the global maximum over all pairs is attained by an adjacent pair in the input order.
- **Exact arithmetic for selection:** For adjacent buildings, compute `num = X[i+1] * H[i] - X[i] * H[i+1]` and `den = X[i+1] - X[i] > 0`. Track the maximum fraction by cross multiplication using Python integers. This avoids floating-point errors for the exact distinction between negative, zero, and positive answers.
- **Output formatting:** Non-negative answers are printed using float formatting with exactly 18 digits after the decimal point: `f"{best_num / best_den:.18f}"`. Negative or no-intercept cases print exactly `-1`. This satisfies the required absolute or relative error tolerance: the selected fraction is exact for sign and comparison, and double precision is sufficient for the final decimal output.
- **Sample verification:** Sample 1 gives best fraction `3/2`, printed as `1.500000000000000000`. Sample 2 has all adjacent intercepts negative, printed as `-1`. Sample 3 has maximum intercept exactly `0`, printed as `0.000000000000000000`. Sample 4 has best fraction `120/7`, and Python float formatting produces `17.142857142857142350`, matching the sample within tolerance.
- **Complexity:** The scan is `O(N)` time and `O(1)` additional memory besides input handling.
