- **Characterization:** A valid connected graph is uniquely described by BFS layers from vertex 1. Layer 0 is `{1}`, all later layers are nonempty, edges may appear only inside a layer or between adjacent layers, and every vertex in layer i>0 needs at least one neighbor in layer i-1. The parity condition means even-indexed layers and odd-indexed layers each contain N/2 vertices.
- **Layer counting:** For fixed ordered layer sizes, labels are chosen sequentially. If the previous layer has size a and the new layer has size b, the edge-count generating factor is `C(rem,b) * (1+x)^{C(b,2)} * ((1+x)^a - 1)^b`, where rem is the number of unused non-root labels. The first factor chooses labels, the second chooses internal edges, and the third chooses nonempty parent-neighbor sets for each new vertex.
- **DP state:** State `(used_even, used_odd, last_size, next_parity)` is sufficient. `used_even` includes vertex 1. Future label choices depend only on remaining count, and future edge factors depend only on last layer size and next parity. Counts are never allowed to exceed N/2.
- **Evaluation strategy:** The whole DP is run at scalar points `x = 0..L`, where L is the maximum possible degree. At a point t, each transition factor becomes `C(rem,b) * (1+t)^{C(b,2)} * ((1+t)^a - 1)^b`. Since N<=30, layer sizes are at most 15, so only powers up to `max(15, C(15,2))=105` are needed for evaluation.
- **Interpolation:** Values `F(0)..F(L)` determine the polynomial modulo P because P > D >= L. Newton forward differences give coefficients in the binomial basis `C(x,k)`, then a recurrence converts them to standard coefficients. All divisions are by k <= 435, invertible modulo P.
- **Degree bound:** The maximum degree is computed by a max-plus DP over the same state graph, adding `C(b,2)+a*b` per transition. This is often smaller than D (for example N=10 gives 41 instead of 45), reducing evaluations and allowing trailing zeros to be printed directly.
- **Pruning:** States that cannot reach a terminal state are removed by reverse reachability from terminal states. This reduces DP work and avoids processing dead parity completions.
- **Performance:** Transition factors are grouped by `(a,b,comb)` so each evaluation point computes only one factor per key. DP values are accumulated with delayed modular reduction using a 63-bit threshold, reducing modulo operations while keeping integers small. The total number of scalar DP updates is small enough for Python.
- **Edge cases:** N=2 gives polynomial x. For N>2, F(0)=0 because at least N-1 parent edges are mandatory. Dense graphs beyond the BFS-allowed maximum degree are output as zero. P is large enough for interpolation and binomial coefficients are handled modulo P.
