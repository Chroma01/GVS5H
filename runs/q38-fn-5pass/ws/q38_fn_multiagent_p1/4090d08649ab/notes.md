- **Core reduction:** For a fixed subarray, only the set of distinct values matters. An operation can remove exactly a contiguous interval of values that are all currently present. Values that differ by 1 and are both present belong to the same component; an operation cannot remove values from two different components because the missing value between them would make the chosen interval invalid. Hence f(L,R) is the number of connected components of the distinct-value set, i.e. |S| minus the number of adjacent pairs (x,x+1) contained in S.
- **Aggregate formula:** For each right endpoint R, let last[v] be the last position of value v up to R. A subarray [L,R] contains v iff L <= last[v], so the total number of distinct values over all subarrays ending at R is sum_v last[v]. It contains both x and x+1 iff L <= min(last[x], last[x+1]), so the total number of present adjacent pairs over those subarrays is sum_x min(last[x], last[x+1]). Therefore the contribution of all subarrays ending at R is sum_last - adjacent_min_sum.
- **Sweep update:** When processing position i with value v, only last[v] changes. sum_last increases by i - old_last[v]. The adjacent-minimum sum changes only for pairs (v-1,v) and (v,v+1), so subtract their old minima, update last[v]=i, add their new minima, then add sum_last - adjacent_min_sum to the answer. Boundary checks handle values 1 and N.
- **Implementation details:** Use a list last of length N+2 initialized to zero. Iterate i from 1 to N over the input values. Use conditional expressions instead of min for speed, and Python integers for the large answer. Read all input with sys.stdin.buffer.read().split().
- **Validation:** The sweep gives sample 1 total 16 and sample 2 total 23. It also matches brute force on small cases such as [1,2,3], [1,3,2], [1,2,1], [2,4,2,3], and N=1. The component argument covers all operation sequences, so no multiplicity or ordering effect is missed.
- **Complexity:** Each array element causes O(1) updates, so time is O(N) and memory is O(N) for the last-occurrence array and input list.
