The key is to view sorting as resolving every inversion exactly once, minimizing the position at which each crossing occurs. Process values from largest to smallest, placing value k at its final position k; at that moment only values ≤ k remain, so k’s current position is determined by how many smaller values were originally to its left. Moving k right then costs a contiguous sum of swap positions, giving an O(N log N) formula that can be computed with a Fenwick tree over original positions.
