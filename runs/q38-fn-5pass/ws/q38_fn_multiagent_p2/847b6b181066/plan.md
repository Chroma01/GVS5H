Track the cumulative wind displacement after each step. A smoke particle generated at time g is at position current_displacement - displacement_at_g at time t, so store the set of cumulative displacements at all generation times, starting with (0,0). At each step, update the displacement; if the origin is empty, add the current displacement to the generation set. Then smoke exists at (R,C) iff current_displacement - (R,C) is in the generation set.
