- **Feasibility:** Red moves flip the parity of `r+c`, while blue moves preserve it. Therefore a closed cycle requires `R` to be even. If `R=0`, every blue move flips both row parity and column parity, so `B` must also be even. These conditions are sufficient.
- **All-red construction:** For even `R`, output the perimeter of a `2 x (R/2)` rectangle: top row left-to-right, then bottom row right-to-left. For `R=2`, this is a valid two-square vertical cycle.
- **All-blue construction:** For even `B`, use the coordinate transform `(a,b) -> (r,c) = (a+b, a-b)`. Blue moves in the original board become orthogonal moves in `(a,b)`. Trace a `2 x (B/2)` rectangle in transformed coordinates, using `a0 = B/2 + 2` to keep all mapped columns positive.
- **Mixed red path:** For `R >= 2` even and `B >= 1`, build an orthogonal red path from `S=(0,0)` to `A=(1,0)` of length `R-1`. It uses rows `0` and `1`, and columns `0,-1,...,-d`, where `d=(R-2)//2`. The vertex `A` is output as the first blue piece.
- **Mixed blue path in transformed coordinates:** Use `u=r+c`, `v=r-c`. A blue diagonal move is exactly a step of length `2` in `u` or `v`. The start `A=(1,0)` has `(u,v)=(1,1)`.
- **Odd blue path fix:** For odd `B=2m+1`, the blue path is now generated as: east `m` steps (`u += 2`), one south step (`v -= 2`), west `m` steps (`u -= 2`). This ends at `(u,v)=(1,-1)`, which maps back to `T=(0,1)`. Every consecutive blue edge is diagonal by construction, and the path is a simple hairpin.
- **Even blue path:** For even `B=2m`, the path is: south `m` steps, one west step, north `m-1` steps, ending at `(u,v)=(-1,-1)`, which maps back to `T=(-1,0)`. This is equivalent to the previous valid even construction but is generated uniformly.
- **Disjointness:** The red path lies in rows `0/1` and columns `<=0`. The odd blue path has columns `>=1`, with only `T=(0,1)` in row `0`; the red path has no `(0,1)`. The even blue path has columns `>=1` except `T=(-1,0)`, and the red path has only `(0,0)` and `(1,0)` in column `0`. Thus all occupied squares are distinct.
- **Counts and order:** Output `pts[:-1]` as red, `pts[-1]=A` as blue, `q[:-1]` as blue, and `q[-1]=T` as red. The red edges are the `R-1` edges along `pts` plus the closing edge `T -> S`. The blue edges are exactly the `B` edges from `A` through `q`.
- **Special case:** The case `(R,B)=(2,3)` still prints the sample placement directly, including the trailing space on the second line.
- **Checks:** The sample produces the special `(2,3)` block, `No` for `(1,1)`, and the all-red 4-cycle for `(4,0)`. Manual edge checks cover `R=2` with `B=1,2,4,5`, `R=4` with `B=1..5`, `R=0` with even `B`, and `B=0`.
- **Bounds:** All pre-shift coordinates have absolute value at most about `100000`; with `OFF=1_000_000`, all printed rows and columns are safely inside `1..10^9`.
- **Implementation:** Input is read in bulk, answers are buffered, and each test case is processed in `O(R+B)` time and output size.
