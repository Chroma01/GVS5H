Reduce f(L,R) to the number of maximal consecutive integer intervals whose every value appears in the subarray; equivalently, count values x such that the subarray contains x and does not contain x-1. Therefore the total answer is the sum over x of subarrays containing at least one occurrence of x and no occurrence of x-1. For each x, positions of x-1 split the array into gaps; within each gap, count subarrays containing at least one x and sum these counts. Since each array element participates in only the calculations for its own value and the next value, an O(N) or O(N log N) merge over occurrence lists suffices.
