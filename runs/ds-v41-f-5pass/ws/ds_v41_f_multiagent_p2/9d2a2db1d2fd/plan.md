Model each block as a vertex with capacity F, and adjacent blocks as edges weighted by min(F_u,F_v). For any block path, the extra stair cost beyond |Y-Z| is determined by the minimum-capacity vertex on that path, so we must maximize this bottleneck. Build a maximum spanning/Kruskal reconstruction tree over the grid to represent maximum bottleneck connectivity. Then answer queries with LCA on the reconstruction tree, using the formula |Y-Z| + 2*max(0, min(Y,Z)-M), where M is the maximum bottleneck. Same-block queries are handled directly as |Y-Z|.
