- **Core characterization:** A minimum successful swap has a witness of one of two types. Type T is a doubled tree-like spider: all used edges are traversed twice. Type C is a cycle with two tails to S and T attached at distinct cycle vertices: cycle edges once, tails twice. The answer is the minimum over these witnesses.
- **Type T formula:** For a center v with degree at least 3, use global BFS distances ds=dist(S,v), dt=dist(T,v). If v is S or T, cost is `2*(other_distance+2)`. Otherwise inspect first edges of shortest paths from v to S and T. If they can be chosen distinct, one buffer direction is enough (`k=1`); if forced to share the first edge, two buffer directions are needed (`k=2`). Cost is `2*(ds+dt+k)`. Degree at least 3 is sufficient and necessary for this local tree-like witness.
- **Type C structure:** Only biconnected components on the block-cut path between S and T can provide a cycle with distinct ports p and q. Candidate cost is `2*dist(S,p)+2*dist(T,q)+shortest_cycle_through(p,q)` inside that block. If ports coincide, Type T is no worse and the cycle-once support is not schedulable cheaper.
- **Block-cut construction:** Iterative Tarjan gives vertex-biconnected components (bridges are size-1 components). Articulation vertices are those appearing in more than one component. The block-cut tree path gives the unique sequence of blocks/terminals relevant for Type C.
- **Shortest cycle through two vertices:** A previous first-branch BFS heuristic can underestimate. Counterexample: a long cycle through root and target plus a chord creating a shorter cycle not containing target; the heuristic may use a tail attached to that shorter cycle. The solver now uses a dominator-tree algorithm on the BFS shortest-path DAG from the root.
- **Dominator cycle algorithm:** BFS from root gives the shortest-path DAG. Immediate dominators are computed in topological (BFS-layer) order: idom(v) is the LCA of all DAG predecessors of v. Binary lifting is used only while building idom. After that, root-child subtrees of the dominator tree replace LCA queries: two vertices have LCA root iff they lie in different root-child subtrees. A non-root edge (a,b) gives a valid cycle of length `dist[a]+dist[b]+1` iff a and b are in different root-child subtrees and target dominates a or b in the dominator tree. This exactly captures cycles where two internally disjoint shortest paths close by that edge and contain the target.
- **Complexity:** Two global BFS runs, one Tarjan pass, block-cut construction, and Type T scan are O(N+M). Dominator processing is done only for blocks on the S-T block-cut path; total edges over those blocks is O(M), with O(E log V) per processed block due to binary lifting. Memory is O(N+M), with large temporary structures freed before dominator processing.
- **Impossibility:** If no Type T center and no Type C cycle candidate exists, the graph is effectively a path for the two tokens, and the answer is -1.
