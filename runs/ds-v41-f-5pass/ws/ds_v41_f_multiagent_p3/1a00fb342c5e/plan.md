Model the constraints as a weighted graph on N vertices, where each relation \(A_x \oplus A_y = Z\) is an edge with XOR weight Z. For each connected component, assign a relative value \(D_v\) by traversing edges, checking for contradictions; if any edge violates the implied relation, no solution exists. Within a component, every valid assignment has the form \(A_v = r \oplus D_v\) for a single component-root value \(r\). Since the total sum decomposes bitwise, choose each bit of \(r\) independently to minimize the number of vertices whose bit is 1, i.e. compare the count of 1s and 0s in \(D_v\) for that bit. Finally combine the chosen component values and output the resulting minimum-sum sequence, or -1 if inconsistent.
