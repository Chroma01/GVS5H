Reduce the problem to choosing a final contiguous block length equal to the total number of ones. Represent the existing ones by their positions, then transform positions to account for the fixed spacing inside the final block. The minimum adjacent swaps is the minimum sum of absolute deviations of these transformed positions from the block start, achieved at the median. The implementation should run in O(N) time and O(N) or O(number of ones) memory, which is safe for N up to 5e5. Validate the formula against samples and edge cases before finalizing.
