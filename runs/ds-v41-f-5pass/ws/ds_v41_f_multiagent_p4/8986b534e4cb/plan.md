Reduce the condition on road weights to constraints on prefix sums P_0..P_{N-1}: each person i becomes an interval [a_i,b_i]=[min(S_i,T_i)-1, max(S_i,T_i)-1] with type + if S_i<T_i else -, requiring P_{a_i}=P_{b_i} and all interior P_k strictly above or below that value. A set of people is satisfiable exactly when no two chosen intervals have the same left endpoint, the same right endpoint, or cross while having the same type; this makes feasibility monotone and reduces each query to checking whether its index range contains such a bad pair. Precompute for every right index j the largest left index i<j that forms a bad pair with j, then take prefix maxima over j. A query [L,R] is Yes iff that prefix maximum up to R is less than L.
