- **Gap model:** Sort initial piece positions `a_1<...<a_M` and final positions `b_1<...<b_Q`. Since pieces never split and order is preserved, each final gap must be assigned to one initial gap `d_i=a_{i+1}-a_i` with `f_j<=d_{c_j}`. Unassigned initial gaps are internal and reduced to zero. Let `r_i=d_i-e_i`, where `e_i` is the chosen final gap or zero. `S=sum r_i=(a_M-a_1)-(b_Q-b_1)` is fixed.
- **Operation cost for fixed reductions:** Let `L=b_1-a_1`, `R=a_M-b_Q`, `D=L-R`. If all `r_i>0`, one positive component touches both ends and the minimum is `(S+|D|)/2`. If zero gaps split components, internal components not touching an end must have even sum. Let `p` be parity of the left component and `q` parity of the right component. Then `p xor q = S mod 2`, and the minimum is `(S+p+q+|D+p-q|)/2`. This is never smaller than the all-positive value, so if a strict-only embedding exists it is optimal.
- **Exact matches and parity:** A selected boundary with `d_i=f_j` has `r_i=0` and separates components. Define prefix parities `Dpref[i]=sum_{0..i} d`, `Fpref[j]=sum_{0..j} f`. For an exact match `(i,j)`, the prefix reduction parity is `H=Dpref[i] xor Fpref[j]`. All exact matches used in a valid embedding must have the same `H`; otherwise an internal component has odd sum. Conversely, if all exact matches have the same `H=p`, internal parity is satisfied, with left parity `p` and right parity `S xor p`.
- **Feasibility for a fixed p:** We need an embedding using at least one exact match, all exact matches having `H=p`. Choose the first exact match `(c,j)`. Before it, all matches must be strict (`d_i>f_t`). After it, matches may be strict or exact with `H=p`.
- **Prefix/suffix greedy:** `pref[j]` is the earliest last index matching first `j` final gaps strictly; computed by one left-to-right scan. For fixed `p`, `suff[t]` is the latest possible index of final gap `t` in a right-to-left greedy matching of suffix `t..K-1` under allowed relation `d_i>f_t` or (`d_i==f_t` and `H=p`). Then `(c,j)` can be the first exact iff `pref[j] < c < suff[j+1]` and `c` is an equality position with `Dpref[c] xor Fpref[j]=p`.
- **Algorithm:** Parse gaps. If `Q>M` or `S<0`, impossible. If `K=0`, answer is `(S+|D|)/2`. Try strict-only embedding; if it succeeds, return `(S+|D|)/2`. Otherwise build equality lists by `(value, Dpref parity)`, compute `Fpref`, and for `p=0,1` compute suffix greedy and test first exact candidates using binary search. Take the minimum feasible cost.
- **Correctness of greedy:** For a fixed allowed relation, earliest left greedy gives the minimum possible last index for each prefix, and latest right greedy gives the maximum possible first index for each suffix. Therefore the prefix/suffix condition is necessary and sufficient for existence of an embedding with a chosen first exact match.
- **Edge cases:** `M=1,Q=1` is handled by `K=0`. `Q>M` and span increase are immediate `-1`. Strict-only means all selected matches satisfy `d_i>f_j`; equality is not allowed there because it creates a zero gap.
- **Complexity:** Per test case, parsing and scans are `O(N)`, plus `O(K log occ)` binary searches over equality lists. Sum `N<=1e6`, so this is easily fast enough. Memory is linear in the number of gaps.
