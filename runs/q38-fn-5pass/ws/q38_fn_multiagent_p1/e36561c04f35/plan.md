Compress the initial sequence into maximal equal-value runs; deleting each run costs one operation, so the baseline is the number of runs. An adjacent swap can reduce the run count by at most 2, and only swaps that reduce it by exactly 2 give a net saving of one operation. Such a saving swap is possible exactly for four consecutive runs with values x, y, x, y where the two middle runs have length 1; it deletes those two middle runs and increases the two outer runs. Thus the answer is the initial run count minus the maximum number of non-overlapping saving swaps, where chosen swap starts must differ by at least 3. The maximum set of starts with gap at least 3 can be found greedily by scanning valid starts left to right and taking the earliest possible one.
