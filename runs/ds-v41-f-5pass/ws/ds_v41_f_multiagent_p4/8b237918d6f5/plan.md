We need to maximize the shortest path length after setting exactly K edges to weight 1. Since N ≤ 30, the answer is at most N−1, so we can binary search the answer L. For a fixed L, the condition that every 1→N path contains at least L selected edges is equivalent to the existence of a vertex labeling d: V → {0..L} with d(1)=0, d(N)=L, and d(v) ≤ d(u)+1 for every edge u→v; the number of edges with d(v)=d(u)+1 is the number of selected edges needed. Minimizing this number over all valid labelings can be formulated as a minimum s-t cut in a layered graph with O(N·L) nodes. We build the graph, compute the min cut via max flow (Dinic), and check whether it is ≤ K. Binary search then finds the maximum feasible L.
