- **Model:** Graph G has edge i-j iff intervals [L_i,R_i],[L_j,R_j] are disjoint. G is the complement of an interval graph (co-interval graph). Interval graphs are chordal and contain no induced C5; since complement of P5 is C5 and any induced P_k (k>=5) contains an induced P5, G has no induced path on 5+ vertices. With all W_i positive, a minimum-weight path is simple and chordless, and any chord lets you shortcut to a cheaper subpath. Hence every optimal path has at most 4 vertices (at most 3 edges).
- **Only three path shapes matter:** 2 vertices (direct edge), 3 vertices s-u-t with u disjoint from both s and t, and 4 vertices s-a-b-t forming an induced P4 (s-a, a-b, b-t disjoint; s-b and a-t overlap; s-t already overlap).
- **Direct edge:** if s,t intervals are disjoint (R_s < L_t or R_t < L_s), answer is exactly W_s+W_t because any path contains both endpoints and all weights are positive.
- **3-vertex path:** the set of u disjoint from both intervals equals {R_u < min(L_s,L_t)} union {L_u > max(R_s,R_t)} when s,t overlap (no u can sit "between" two overlapping intervals). Use pref[minL-1] and suff[maxR+1]. For containment (t inside s or vice versa) this automatically reduces to neighbours of the larger interval, which is correct since the containing interval's neighbours are disjoint from the contained one too. Candidate = W_s+W_t+min(pref[minL-1], suff[maxR+1]).
- **4-vertex induced path exists only for strictly crossing intervals** (Ls<Lt and Rs<Rt, or the mirror), with overlap guaranteed since the non-crossing cases were already split off. Earlier-starting endpoint gets a right neighbour with L in (R_earlier, R_later]; later-starting endpoint gets a left neighbour with R in [L_earlier, L_later). Candidate = W_s+W_t+pref[L_later-1]+suff[R_earlier+1]. Using the full pref/suff ranges is safe: a chosen vertex beyond the induced window is disjoint from both endpoints, so it is dominated by a 3-vertex path, and the pairing is always a genuine valid walk (L_b < L_later <= R_earlier < L_a guarantees a-b disjoint, and all chosen vertices differ from s,t and each other).
- **Containment / equal endpoints:** if L_s<=L_t and R_s>=R_t (t inside s), no induced P4 exists and distance is 2 whenever reachable; handled by the 3-vertex branch only. Strict inequalities (L_s<L_t, R_s<R_t) correctly exclude equal-left/equal-right configurations.
- **Precomputation:** M=2N+2 coordinate range. pref[x]=min W_i with R_i<=x via prefix min; suff[x]=min W_i with L_i>=x via suffix min. Use a big integer INF; sums with INF stay >=INF so guarded comparisons are safe. Indices bounded since 1<=L<=R<=2N.
- **Per query O(1):** if disjoint print W_s+W_t; else take min over the 3-vertex candidate and the applicable crossing 4-vertex candidate, printing -1 when still INF.
