Model the rating after each contest as a nondecreasing function of the initial rating over the fixed domain 1..500000. For each contest interval [L, R], the initial ratings whose current value lies in [L, R] form one contiguous index range, so we can add 1 to that range. Use a lazy segment tree storing min/max values to find the first index with value >= L and the last index with value <= R, then apply a range increment. After processing all contests, answer each query by point-querying the segment tree at the initial rating X.
