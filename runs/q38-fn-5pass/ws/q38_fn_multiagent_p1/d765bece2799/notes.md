- **Implemented solution:** Monotonic-stack per-element contribution. The answer is the bounded-length sum of subarray minimums plus the bounded-length sum of subarray maximums. Maximums are handled by applying the minimum routine to the negated array and subtracting the result.
- **Minimum contribution boundaries:** For each index `i`, assign subarrays to `i` as the rightmost minimum. The left boundary is the previous strictly smaller element, and the right boundary is the next smaller-or-equal element. Then `left_count = i - prev_less` and `right_count = next_le - i`. The left-to-right stack pops `>=` to obtain previous strictly smaller. The right-to-left stack pops `>` to obtain next smaller-or-equal.
- **Tie-breaking correctness:** Equal minima to the left are allowed, but equal minima to the right are excluded. This makes every subarray contribute exactly once, assigned to its rightmost minimum. The same partitioning is valid after negation for maximums.
- **Bounded length counting:** For a fixed element, a start choice contributes `x = i - start + 1` and an end choice contributes `y = end - i + 1`. The subarray length is `x + y - 1`, so the cap `length <= k` becomes `x + y <= k + 1`. Let `limit = k + 1`.
- **Pair-count formula:** Count positive pairs `(x, y)` with `1 <= x <= left`, `1 <= y <= right`, and `x + y <= limit`. If `limit >= left + right`, all `left * right` pairs are valid. Otherwise, only `x <= min(left, limit - 1)` can contribute. For `x <= limit - right`, all `right` values of `y` are valid. The remaining `x` values contribute `limit - x` choices, summed arithmetically in O(1).
- **Complexity:** Each minimum-sum pass uses two linear monotonic-stack passes and O(1) work per element. It is called twice, so total time is O(n) and extra space is O(n). This fits `n <= 80000` comfortably.
- **Sample tests verdict:** pass. The provided examples produce `20` for `[1, 2, 3], k = 2` and `-6` for `[1, -3, 1], k = 2`.
- **Edge tests checked:** `k = 1` yields `2 * sum(nums)`. `k = n` uses the all-pairs branch and matches the standard unbounded contribution formula. Duplicates such as `[1, 1, 1], k = 2` yield `10`. Negative arrays such as `[-1, -2], k = 2` yield `-9`. Single-element arrays `[5]` and `[-5]` yield `10` and `-10`. Zeros and large values within constraints are handled correctly by Python integers.
- **Edge cases:** Duplicates, negative values, single-element arrays, `k = 1`, and `k = n` are all handled correctly. Python integers avoid overflow.
- **Alternatives considered:** Sliding-window group aggregates, DSU threshold sweeps, and Cartesian-tree counting are possible, but the monotonic-stack contribution method is the simplest linear implementation for this bounded-length sum.
