- **Problem model:** Shortest palindromic walk for all ordered vertex pairs. State (x, y) = a palindromic walk from x to y; distance is its length. Transitions add two edges a->x and y->b with the same label c, giving length +2.
- **Base cases:** Empty walk gives dist[i][i] = 0. Any single edge u->v (u != v) gives dist[u][v] = 1. Self-loops u->u are not used as base states because the empty walk is always shorter (0 < 1).
- **Self-loop safety:** A palindrome whose center is a self-loop u->u can always be shortened by removing that self-loop, yielding an even palindrome of length d-1 with the same endpoints. Therefore self-loops are never needed as center edges for shortest paths. They remain available as outer edges during extensions.
- **BFS correctness:** Initial distances 0 and 1 are processed FIFO. Transitions add weight 2, so distances are non-decreasing in the queue. Every state is settled once with its minimum distance. Parity separation is unnecessary because a smaller distance from the same state can always be extended identically to produce a shorter total length.
- **Efficient expansion:** For state (x, y), for each label c on an outgoing edge from y, take the bitmask of destinations b (outmask[y][c]). For each a with edge a->x labeled c (inlist[c][x]), OR that mask into newacc[a]. Then settle all still-unsettled bits of newacc[a] at distance d+2.
- **Complexity:** Total work is O(N * M) where M <= N^2 is the number of edges. With N <= 100 this is about 1e6 operations, extremely fast. Using `unsettled` bitmasks ensures each of the N^2 states is settled exactly once.
- **Implementation details:** outmask[v][c] is an integer bitmask; inlist[c][x] is a list of sources. vchars[v] lists labels present on v's outgoing edges. Queue is initialized with all level 0 states, then all level 1 states. Output uses -1 for unreachable pairs.
- **Verification:** Compared against an independent product-graph BFS (0-1 Dijkstra) on exhaustive small cases (N<=4) and many random graphs (N up to 6, random labels/'-'). No mismatches found. The self-loop skipping optimization is safe and correct.
