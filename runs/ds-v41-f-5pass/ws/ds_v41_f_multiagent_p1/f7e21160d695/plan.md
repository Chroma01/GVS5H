The key is that f(x,y) equals the maximum edge weight on the unique path between x and y in any minimum spanning tree, equivalently the weight at the LCA in a Kruskal reconstruction tree. Build that tree while processing edges by increasing weight with DSU; each merge creates an internal node whose weight is the current edge weight. Then reduce the assignment problem to a bottom-up matching on this tree: at each node, pair as many A-items and B-items inside the subtree as possible, and pass only the unmatched surplus upward, paying the node weight for each crossing pair formed at that merge. Track multiplicities because input sequences may contain duplicate vertices, and use 64-bit arithmetic. Finally output the accumulated crossing cost.
