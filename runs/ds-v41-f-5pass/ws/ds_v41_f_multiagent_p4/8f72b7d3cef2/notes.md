- **Model:** Takahashi's absorbed set is a contiguous interval containing K. Growth is monotone (absorbing only increases size, never weakens future options), so the closure is order-independent and unique: repeatedly extend left if A[L-1] < S, or right if A[R+1] < S, S = sum of interval. This is the "minimal interval with both boundaries >= S" (or array ends).
- **Brute force for stress testing:** for each K do L=R=K, S=A[K]; loop: if L>0 and A[L-1]<S then L-=1, S+=A[L]; elif R<N-1 and A[R+1]<S then R+=1, S+=A[R]; else break. Answer = S. Compare with the O(N) solution on random arrays (values in 1..4 to force ties, plus strictly increasing/decreasing/all-equal). No mismatches found; the DP matches the closure on all hand-checked and sample cases.
- **Subtle but safe points (all verified):**
  - Partial absorption: to touch parent u from child c you must consume all of c's subtree, so max size before u is T[c]; need T[c] > A[u]. A node that is not stuck can always reach T[c] because after absorbing one strictly-smaller neighbour its size exceeds A[c] >= every element of its subtree, so it sweeps the subtree. A stuck node cannot move (handled by the local stuck check), yet its reach value is still valid *for its descendants*: a descendant d reaches u's position with size exactly T[u].
  - Equal values only occur on the right-child side (leftmost-max tie), so a left child always has strictly smaller value. If right child c has A[c]=A[u], then T[c]>A[u] implies c can absorb u then u's left subtree (all < A[u] < T[c]+A[u]); the size reaching u's position is still T[u]. Symmetric for the other side. So reach[c]=reach[u] is exact.
  - Crossing a subtree boundary independently (extending past L_p-1 or R_u+1) forces size > A[p] >= A[u], which implies T[p-side] > A[p], i.e. the climb to p already happens; the DP never misses it.
- **Cartesian tree:** `while stack and A[stack[-1]] < A[i]` gives max-heap with leftmost-max as ancestor; node i's subtree is exactly the maximal interval where i is the leftmost maximum, and child subtrees are adjacent to the parent. Root is stack[0] after the build.
- **DP:** in preorder, reach[root]=root; for child c of u, reach[c] = reach[u] if T[c] > A[u] else c. Answer for non-stuck i is T[reach[i]]; for stuck i it is A[i]. T[i] = A[i] + T[left] + T[right], computed by reverse preorder.
- **Complexity:** O(N) time, O(N) memory. Use `array('i')` for indices and `array('q')` for sums (max sum 5e14 fits int64). All traversals iterative.
- **Edge cases:** all equal -> all stuck, output originals; increasing/decreasing handled; ties never allow absorbing an equal value before the running sum strictly exceeds it; N=2 verified by cases.
- **I/O:** read all tokens from stdin, print answers space-separated in index order K=1..N.
