The key observation is that multiplicities do not matter: an operation can erase exactly a contiguous interval of values that are all present, so the minimum number of operations for a subarray is the number of connected components of the set of distinct values appearing in it. For any set S, components = |S| - number of adjacent value pairs (x, x+1) both contained in S. Therefore the required sum splits into (sum over subarrays of distinct value count) minus (sum over x of subarrays containing both x and x+1). The first term can be computed from occurrence gaps for each value, and the second by sweeping merged occurrence lists for each adjacent pair; each occurrence participates in at most two pairs, giving O(N) total work. We will implement this with 64-bit integers and validate on samples.
