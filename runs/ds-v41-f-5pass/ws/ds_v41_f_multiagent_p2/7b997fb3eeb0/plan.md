The maximum number of pairs for an interval [L,R] is the largest K such that the K smallest elements can be paired with the K largest elements under the condition 2*a <= b. This reduces to checking whether max_{i in [L, L+K-1]} d[i] <= (R-L+1)-K, where d[i] is the distance from i to the first index j with A[j] >= 2*A[i]. Precompute d for all indices, build a sparse table for range maximum queries, then binary search K for each query. This yields O((N+Q) log N) time and O(N log N) memory.
