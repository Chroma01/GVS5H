- **Approach:** The parity sequence is forced once the first parity is known. For any valid prefix, the number of completions depends only on the remaining odd/even counts and the parity required at the next position. If the required parity matches the forced slot counts, the number of completions is `rem_odd! * rem_even!`; otherwise it is `0`.
- **Capped arithmetic:** Use `CAP = original k + 1`. Precompute factorials capped at `CAP`, and multiply with a safe capped multiplication. Counts below `CAP` are exact; counts at or above `CAP` are guaranteed to be large enough for the current `k`, because the current `k` is always less than `CAP`.
- **Total check:** The total number of valid permutations is the sum of odd-start and even-start completions, capped at `CAP`. If this capped total is less than `k`, return an empty list. With `CAP = k + 1`, this check is exact whenever the true total is below `k`.
- **Unranking:** Build the answer position by position. Try unused values from `1` to `n` in increasing order, skipping values with the same parity as the previous value. For each candidate, compute the number of completions after fixing it. If that count is at least `k`, choose the candidate; otherwise subtract the count and continue. This matches lexicographic order because all permutations with a smaller next value form an earlier contiguous block.
- **Edge cases:** `n = 1` has one permutation; `n = 2` has two. For odd `n`, only odd-start patterns are possible; for even `n`, both odd-start and even-start patterns are possible. `k` is 1-indexed. The completion function returns `1` for an empty suffix before checking parity.
- **Complexity:** `O(n^2)` time due to scanning values at each position, and `O(n)` space for capped factorials and used flags. This is easily sufficient for `n <= 100`.
- **Pitfalls:** Do not recompute `CAP` after mutating `k`; keep it based on the original input. When counting after choosing a value, pass the opposite parity as the next required parity. Cap the sum of the two starting-parity totals as well.
