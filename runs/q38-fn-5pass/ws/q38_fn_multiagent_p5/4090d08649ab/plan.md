The key observation is that for a subarray, the minimum number of operations equals the number of maximal consecutive blocks among the distinct values appearing in that subarray. Equivalently, this is `(# distinct values) - (# adjacent pairs x, x+1 that both appear)`. Therefore, the required sum can be split into two independent sums over all subarrays: the total number of distinct values over all subarrays, and the total number of subarrays containing both values of each adjacent pair. The distinct-value sum can be computed by assigning each occurrence to the subarrays where it is the first occurrence of that value. The adjacent-pair sum can be computed per pair using inclusion-exclusion on subarrays avoiding one or both values, merging their position lists in total linear time.
