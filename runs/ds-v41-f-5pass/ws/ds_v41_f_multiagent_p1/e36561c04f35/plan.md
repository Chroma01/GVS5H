We need minimize swaps plus prefix-deletions of uniform runs. Swaps make arbitrary reordering possible, so the core is choosing an order in which value groups are consumed by deletions, paying swaps for moving desired elements to the front and one deletion per deleted block. A useful reduction is to characterize when a value can be deleted cheaply based on current prefix and remaining occurrences, then derive a DP or greedy over the sequence. Finally implement the resulting O(N) or O(N log N) per total input and validate against samples and brute force on small N.
