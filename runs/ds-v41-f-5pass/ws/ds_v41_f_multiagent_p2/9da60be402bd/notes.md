- **Problem reduction:** A palindromic walk is characterised by its two endpoints. State (u, v) means "there is a palindromic walk from u to v"; its value is the shortest such length. Answer matrix is the table of these states.
- **Base cases:** length 0 for every (i, i) (empty string is a palindrome), length 1 for every existing edge i -> j (single character is a palindrome). Self-loops are handled automatically because (i, i) is already 0.
- **Transition (outward extension):** From a palindromic walk u -> v of length d, pick an incoming edge x -> u with label c and an outgoing edge v -> y with the same label c. The new string c + (old) + c is a palindrome from x to y of length d + 2. Every palindrome peels down to length 0 (even) or length 1 (odd), so BFS over these two bases is complete.
- **BFS ordering:** Push all length-0 states first, then all length-1 states. Each expansion adds exactly 2, so FIFO order keeps distances non-decreasing (0,1, then 2,3, ...). First time a state is set is its shortest distance; never overwrite.
- **Efficiency trick:** Pre-group edges into per-label bitsets in_mask[c][v] (predecessors x of v) and out_mask[c][u] (successors y of u). For a popped state (u, v), iterate only over labels present in in_labels[u], then over the bits x of that predecessor mask. For each x, candidates = out_mask[c][v] AND unvis-row of x; iterate those bits y, set dist, clear the unvisited bit, enqueue.
- **Complexity:** States are ≤ N^2. Bit extraction of predecessors totals sum_u indegree(u) per u-layer, all bounded by N·E ≤ N^3; successful sets/pushes ≤ N^2. With N ≤ 100 this is ~10^6 big-int operations, comfortable in Python. The bitset AND on Python ints makes the "which y are still free" check O(1) word-parallel.
- **Pitfall - self-loops allow the last edge to differ:** A path may reach the target and then leave/return via a self-loop. Example from sample 2: 1 -> 2 -> 3 -> 3 gives labels "s t s", a palindrome, even though the only edge entering 3 from another vertex is 't'. Do not assume the final edge must come from a different vertex.
- **Pitfall - parity:** Both even and odd palindromes are covered by the two bases; do not special-case parity in the transitions.
- **Output:** Unreachable pairs stay -1. Diagonal is always 0. Print rows space-separated.
