- **Core model:** A state `(u, v)` represents some palindrome-labeled path from `u` to `v`. It can be extended outward to `(p, q)` when a letter `c` labels both `p -> u` and `v -> q`; the new path has length increased by 2.
- **Centers and parity:** Even palindromes grow from empty centers `(x, x)` with length 0. Odd palindromes grow from single-edge centers `(u, v)` with length 1. The two parities are run as separate BFSs because their initial distances differ and because the shortest overall answer is the minimum of the two parity-specific shortest distances.
- **BFS implementation:** States are flattened to `u * N + v`. Distances are actual lengths. Every transition adds 2, so FIFO BFS is correct within each parity. States are marked visited when enqueued.
- **Transition generation:** For each left vertex `u` and letter `c`, store the list of predecessors `p` with `p -> u` labeled `c`. For each right vertex `v` and letter `c`, store an outgoing bitset of `q` with `v -> q` labeled `c`. For a popped state `(u, v)`, iterate only letters that have incoming edges to `u`. For each predecessor `p`, candidate new right endpoints are `outgoing[v][c] & unvisited[p]`. Newly found bits are cleared in batch and each bit is converted to a state index and enqueued.
- **Complexity:** Each state is enqueued once per BFS. For fixed `u`, the predecessor loop over all popped states with left endpoint `u` costs at most `N * indegree(u)`, so total predecessor iterations are at most `N * E <= 1e6` per BFS. Bit iteration happens only for newly visited states, at most `N^2` per BFS. Memory is `O(N^2)` plus small per-letter structures.
- **Correctness sketch:** Every palindrome can be stripped from the outside until it becomes either an empty path at a vertex or a single edge, so every valid path corresponds to a path in the pair-state graph from a center. Conversely, every transition constructs a valid palindrome path. BFS gives the shortest state-graph distance for each parity, and taking the minimum over even and odd distances gives the shortest palindrome path overall.
- **Edge cases:** The diagonal is initialized to 0, so self-loops or cycles cannot override the empty path. Unreachable pairs remain -1. Directedness is preserved by using incoming edges for the left endpoint and outgoing edges for the right endpoint. Input parsing joins all remaining tokens, so it works whether rows are line-separated or character-separated.
