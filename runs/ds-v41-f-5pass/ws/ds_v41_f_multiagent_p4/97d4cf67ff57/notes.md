- **Problem model:** Need a connected subtree of the host tree T where every chosen vertex has chosen-degree exactly 1 or 4 and at least one chosen vertex has degree 4. Maximize chosen vertices; print -1 if impossible. Because T is a tree, any connected chosen set is automatically acyclic, so only degrees and connectedness matter. Since a subgraph (not induced) is allowed, we may freely drop unused edges between chosen vertices.
- **Counting structure:** If an alkane has I internal (deg-4) and L leaves, then L + 4I = 2(I+L-1) => L = 2I+2, total n = 3I+2. Minimum alkane is the star K1,4 (n=5). So n < 5 is immediately -1.
- **Rooting trick:** Every alkane has >=1 deg-4 vertex; root it there. Then the root picks exactly 4 child branches, every non-root internal vertex picks its parent edge plus exactly 3 child branches, and leaves pick only their parent edge. This gives a clean recursive definition and avoids double counting.
- **Directed-edge DP:** Define f(v,u) = max size of v's branch when edge (u,v) is used and u is v's parent. f(v,u) = max(1 [v is a leaf], 1 + sum of top-3 f(w,v) over neighbors w != u) — the internal option is valid only when v has >=3 neighbors besides u (i.e. deg_T(v) >= 4). Every branch is always valid with value >=1 via the leaf fallback, and internal always beats leaf when legal, so no extra maximization subtlety.
- **Two passes / rerooting:** Root T at 0. Pass 1 (reverse pre-order) computes up[v] = f(v,parent) bottom-up from children. Pass 2 (pre-order) computes pm[v] = f(parent,v) top-down: incoming messages to v are up[child] for children and pm[v] for its parent, and for each child c, f(v,c) = 1 + top-3 of incoming excluding c, when deg_T(v)-1 >= 3.
- **Answer:** For each v with deg_T(v) >= 4, candidate = 1 + top-4 of its incoming messages (all neighbors). Take the maximum, else -1. This covers every alkane because it is considered at its own root.
- **Efficiency details:** Keep top-3 (bottom-up) and top-4 (top-down) via 4 tracked (value,index) pairs so each vertex is O(deg). Total O(N), well within limits for N=2e5. Use iterative DFS (no recursion) to avoid stack overflow. Standard library only.
- **Pitfalls handled:** exact degree (3 for non-root internal, 4 for root) rather than at-most; correct neighbor-exclusion when forming child messages via the stored top-4 indices; leaf fallback value 1 always available; -1 when no vertex has degree >=4; min-size guard for n<5.
