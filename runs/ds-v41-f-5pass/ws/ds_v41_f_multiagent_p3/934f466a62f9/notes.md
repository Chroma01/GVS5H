- **Reduction (kept):** pair price = max over 3 coords. Any even per-colour (X/Y/Z) count colouring of the 2K chosen items can be split into same-colour pairs whose prices sum to >= the assigned sum; conversely colouring each optimal pair by its argmax colouring is even with assigned sum = total price. So: choose 2K items, colour each X/Y/Z with all counts even, maximise assigned-coordinate sum.
- **Base:** V = sum of top 2K M_i (M_i = max coord), coloured by argmax. V is an absolute upper bound (each item contributes <= M_i). If counts all even, answer = V. Otherwise exactly two colours are odd (sum of counts = 2K even), giving mask O.
- **Ops:** (1) recolor a->b on a selected item (mask {a,b}, loss M_i - v_i[b]); (2) swap remove-selected-a add-unselected-b (mask {a,b}, loss M_i - v_j[b]). Both losses >= 0 since M_i >= M_j >= v_j[b].
- **At-most-2-ops proof (kept):** masks are A=(0,1),B=(0,2),C=(1,2) with A xor B = C, and A xor B xor C = 0. Any op multiset whose xor = O contains a size-2 (two duplicate masks) or size-3 (all three masks) sub-multiset with xor 0; deleting it preserves total xor O and cannot increase cost (costs >= 0). Repeat until size <= 2. So optimum loss = min(single op with mask O, one op of each of the two other masks). This also shows every valid configuration is reachable from base (choose swaps to change selection, recolors to fix colours; loss is additive when items are used once), so min over <=2 resource-disjoint ops equals the true minimum loss V - answer.

For a swap, the best removal and best addition are independent (min M over selected pool, max coord over unselected pool), each within the top-2 of its pool; recolors likewise need top-2 per source colour. Code keeps TOPREC=TOPSEL=TOPC=6 (generous) and takes the full top-6 x top-6 product per swap direction, so the optimal disjoint pair is always generated.
