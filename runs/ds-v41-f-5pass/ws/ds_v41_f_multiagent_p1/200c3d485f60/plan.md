Model the array as a sequence of runs of equal values. With exactly k equal adjacent pairs among n-1 gaps, the number of runs is n-k, and the k equal-gap positions can be chosen from the n-1 gaps. Then assign one of m values to the first run and one of m-1 different values to each subsequent run, giving the formula m * C(n-1, k) * (m-1)^(n-1-k). The main implementation work is computing binomial coefficients modulo 1e9+7 efficiently for n up to 1e5, plus modular exponentiation. Edge cases include k > n-1, m=1, and k=0, which the formula handles naturally if powers and combinations are computed correctly.
