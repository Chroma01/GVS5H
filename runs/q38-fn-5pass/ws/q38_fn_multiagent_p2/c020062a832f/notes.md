- **Core observation:** Increasing k by one adds 1 modulo M to every element. Relative order of elements that do not wrap is unchanged. Only elements whose current value is M-1 wrap to 0, and all inversion changes come from pairs involving those positions.
- **Transition formula:** For a wrapping position p (1-based), before the step it is the maximum value M-1 and after the step it is the minimum value 0. For every earlier index q, the pair (q,p) changes from non-inversion to inversion, contributing +1. For every later index q, the pair (p,q) changes from inversion to non-inversion, contributing -1. The net change is (p-1)-(N-p)=2p-N-1. Pairs where both positions wrap remain equal before and after, so they contribute 0.
- **Grouping by value:** At the transition from k to k+1, the wrapping positions are exactly those with original A_i = M-1-k. Precompute for each value v the sum of 2p-N-1 over all positions p with A_i=v. Then each answer is obtained by adding one precomputed delta sum.
- **Initial inversion count:** Compute inversions for k=0 with a Fenwick tree over values 0..M-1. Scanning left to right, if the current value is a, the number of previous elements greater than a is i - count(previous values <= a). Use 1-based Fenwick indices a+1.
- **Implementation details:** Use 0-based loop index i and store delta[a] += 2*i + 1 - N, which is equivalent to 2*(i+1)-N-1. After the initial count, output inv for k=0, then iterate value from M-1 down to 1, adding delta[value] and outputting the updated inv. Do not add delta[0] because that would correspond to returning from k=M-1 to k=M.
- **Edge cases:** M=1 produces only k=0 and the loop over values is empty. N=1 gives zero inversions and zero deltas. Duplicate values are handled naturally because all positions in the wrapping group are summed together. Python integers avoid overflow.
- **Complexity:** The Fenwick scan is O(N log M), the delta precomputation is O(N), and producing answers is O(M). Memory is O(N+M).
- **Verification:** The formula matches the samples: sample 1 gives 3,1,1; sample 2 gives 7,3,3,1,1,5; sample 3 gives 0,6,10,12,12,10,6.
