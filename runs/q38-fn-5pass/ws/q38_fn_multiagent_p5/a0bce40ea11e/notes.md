- **Core algebra:** Work over F_p. For odd p, summing x^m over F_p^* gives -1 when m=0 or m=p-1, and 0 otherwise. In the length-p expansion of (A + sum x_e E_e)^p, surviving words are the all-A word and words where exactly one zero-position elementary matrix E_e appears p-1 times and A appears once. Every one of the K zero variables contributes a factor -1, so the global factor is (-1)^K.
- **One-variable terms:** For a diagonal zero E_ii, the sum over the position of A is A E_ii + E_ii A, because E_ii A E_ii = A_ii E_ii = 0. Thus add column i and row i of the original A. For an off-diagonal zero E_ij, E_ij^2=0; only p=3 can place A between two copies, contributing A_ji E_ij. For p>3, off-diagonal zeros contribute nothing.
- **p=2 and p=1:** For p=2, F_2^*={1}, so every zero becomes 1 and B is the all-ones matrix. Hence B^2 has every entry N mod 2. For p=1, all outputs are 0 modulo 1.
- **Matrix power:** For odd p, compute A^p modulo p by binary exponentiation. mat_pow starts with result=None and assigns base on the first set bit, avoiding identity multiplications and the final unnecessary squaring. Powers of the same matrix commute, so result*base is valid.
- **Multiplication implementation:** On CPython, mat_mul transposes Y and computes each entry as sum(map(mul, row, col)) % p, keeping the inner loop in C. On PyPy, it uses unrolled row accumulation: for each nonzero X[i][j], add X[i][j] times row j of Y into Z[i], with the k-loop unrolled by 4. Both postpone modulo until after a row or dot product is complete. Intermediate sums are at most N(p-1)^2 <= 1e20, safe for Python ints.
- **Corrections and sign:** After A^p is computed, iterate over stored zero positions. Diagonal zeros add column and row of A; if p==3, off-diagonal zeros add A[j][i] to (i,j). Finally multiply by -1 if zero_count is odd, otherwise just reduce modulo p. Corrections are applied to the fresh matrix returned by mat_pow, so original A remains unchanged.
- **Complexity:** Dense multiplication is O(N^3), N<=100. Exponentiation uses O(log p) multiplications, at most about 60 in the worst case. Total O(N^3 log p), memory O(N^2). The p=1 and p=2 cases are O(N^2) output.
- **Pitfalls:** The odd-p rule fails for p=2 because exponent 1 also survives. The off-diagonal p=3 correction uses the transposed fixed entry and vanishes if that entry is zero. The global sign must be applied after all corrections. mat_mul does not mutate inputs, so aliasing in mat_pow is safe.
