Reduce the problem to operating on the 26 letter frequencies. For a fixed target frequency k, each letter's final count is either 0 or k. Insert/delete costs are captured by |freq[i] - target[i]|, while a change i→i+1 can save one operation when letter i has surplus and letter i+1 has deficit. Moving farther than one step is never better than delete+insert, so only adjacent savings need consideration. Enumerate all feasible k from 0 to n and use a small DP over the 26 letters with state “unused” or “used with count k” to find the global minimum.
