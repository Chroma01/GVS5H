- **Problem:** count substrings of a digit string s (n up to 1e5) that are divisible by their non-zero last digit. Leading zeros allowed. A substring is counted iff it ends in some digit d in 1..9 and its numeric value is divisible by d.
- **Chosen approach (per-digit residue DP):** for each d in 1..9 independently scan s, keeping cnt[r] = number of substrings ending at the previous index whose value is ≡ r (mod d). For char c: every old remainder r moves to (10*r + c) mod d, and one new length-1 substring with residue c mod d is added. If c == d, add new_cnt[0] to the answer. The value recurrence x -> 10x + c naturally absorbs leading zeros, so no special handling is needed.
- **Correctness:** every counted substring ends exactly in d (c == d) and has value ≡ 0 mod d; a substring is counted only under its unique last digit, so nothing is double counted. Reset cnt per d.
- **Complexity:** O(n * (1+2+...+9)) = O(45n) time, O(max d) extra space per d. Fine for n = 1e5.
- **Optimizations applied:** skip any d not present in s; precompute per-d transition tables trans[c][r] to avoid per-step modulo; use enumerate over cnt; allocate a fresh [0]*d list each step (C-level and fast).
- **Verification (hand-checked):** "12936" -> contributions d1:1, d2:2, d9:1, d3:3, d6:4 = 11. "1010101010" -> only d1 fires, positions of '1' give 1+3+5+7+9 = 25. "5701283" -> 18 by the same reasoning. Small case "12" -> 3 ("1","2","12"), matching the DP. All-zeros input s="0" -> 0; single non-zero digit counts itself.
- **Edge cases:** substrings ending in 0 are never counted (d ranges 1..9); d=1 counts all substrings ending in 1; substring shorter than any suffix length still uses the value recurrence correctly, unlike divisibility-rule approaches that must pad.
- **Fallback if the Python constant factor proves tight (not needed here):** O(n) divisibility rules: d1/d5 count every substring ending in that digit; d2 any even last digit; d3/d9 use digit-sum prefix counts; d6 = last digit 6 (already even) plus digit sum mod 3; d4 last-two-digit rule; d8 last-three-digit rule; d7 uses normalized prefix H[k] = P[k] * inv(10)^k mod 7 with a hashmap of equal H values. Simpler but more edge cases, so only a backup.
