Treat a palindrome path as built from its center outward. Even-length palindromes have an empty center at a vertex, so start BFS from states `(v, v)`; odd-length palindromes have a single edge center, so start BFS from all edge states `(u, v)`. A state `(u, v)` means there is a palindrome path from `u` to `v`; it can be extended by one matching pair to `(p, q)` when some letter `c` labels an edge `p -> u` and an edge `v -> q`. Run two unweighted BFSs on the `N^2` pair states, where each transition adds two original edges, then convert half-length distances to actual lengths and take the minimum for each ordered pair. Use precomputed incoming/outgoing lists by letter, optionally with bitsets, to keep transitions efficient for `N <= 100`.
