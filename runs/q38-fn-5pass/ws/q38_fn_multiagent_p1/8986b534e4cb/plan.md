Normalize each person to an interval `[l, r]` (`l < r`) and a type: `+` if `S = l`, `-` if `S = r`. A set of people is feasible iff no two intervals share the same `l` or the same `r`, and no two intervals of the same type cross (`l_i < l_j < r_i < r_j` or vice versa). This property is monotone, so compute `maxR[L]` for every left index `L` using a sliding window over the people sequence. Maintain active intervals with endpoint occupancy arrays and, for each type, a segment tree over left endpoints storing the corresponding right endpoints. When adding `[l, r]` of type `t`, reject if `l` or `r` is already occupied; otherwise reject if the rightmost active left endpoint `< l` with stored right endpoint `> l` has right endpoint `< r`, or if the maximum stored right endpoint among active left endpoints in `(l, r)` is `> r`. If adding fails, record `maxR[L]`, remove `L`, and retry; answer each query `[L, R]` with `Yes` iff `R <= maxR[L]`.
