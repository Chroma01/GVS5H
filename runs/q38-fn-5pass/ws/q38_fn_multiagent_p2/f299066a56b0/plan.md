Because the mochi sizes are already sorted, the problem becomes finding the maximum number of disjoint pairs where the smaller element is at most half of the larger element. A greedy two-pointer strategy can pair the smallest possible top mochi with the smallest possible bottom mochi that satisfies the condition, maximizing the number of pairs. Alternatively, binary search on the answer K and check whether the first K small mochi can be paired with the last K large mochi. The final solution should run in O(N) or O(N log N) time, which is safe for N up to 5×10^5.
