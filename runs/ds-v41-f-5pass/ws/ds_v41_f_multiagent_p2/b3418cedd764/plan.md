Model the condition as a functional graph with edges i -> A_i and constraint x_i <= x_{A_i}; every directed cycle forces all its nodes to have equal value. Non-cycle nodes form trees hanging off cycle nodes, so compute bottom-up DP for each tree: dp_v[t] counts assignments in v's subtree when x_v=t, combining children via prefix sums of their DP. For each cycle node v, compute f_v[c] as the product over its tree children of their prefix sums at c. Multiply f_v[c] across all nodes of the same cycle and sum over c=1..M. The total complexity is O(NM), which is safe for N,M <= 2025.
