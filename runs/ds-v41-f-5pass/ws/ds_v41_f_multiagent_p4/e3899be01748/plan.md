Process each possible last digit d from 1 to 9 independently using a residue-count DP. While scanning left to right, maintain for each d how many substrings ending at the current position have each residue modulo d. When the new digit is c, every existing substring value transforms as value -> value*10 + c, and a new one-character substring with value c is added. If c equals d, then all maintained substrings for that d that now have residue 0 are exactly the valid substrings ending at this position, so add that count to the answer. This gives O(n * (1+2+...+9)) = O(45n) time and small constant extra space.
