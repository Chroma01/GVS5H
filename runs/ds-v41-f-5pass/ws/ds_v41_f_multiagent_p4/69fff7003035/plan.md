The key is to count, over all permutations, how much each number contributes to the concatenated decimal value. For a fixed value x with digit length L, its contribution depends on how many digits appear after it in the permutation, so aggregate by digit length using factorial counts. Precompute powers of 10 up to the total possible digit count and modular factorials/inverses. Then sum each x from 1 to N with its length-based multiplier, and output the total modulo 998244353. The final algorithm should run in O(N) or O(N log N), suitable for N up to 2e5.
