For a fixed X, each index i requires r_i = ceil(X / points[i]) visits; the base path from -1 to n-1 gives one visit per index, so remaining deficits are d_i = max(0, r_i - 1). Extra moves can be modeled as choosing a suffix of positions to receive one free leftward visit (cost 1 each, starting at e) plus round trips on edges (cost 2 per unit, covering two adjacent positions). The minimum number of round trips equals the maximum weight independent set (MWIS) on a path with weights d_i, where the suffix [e, n-2] has weights reduced by 1 (floored at 0). By precomputing prefix and suffix DP arrays for MWIS, we can evaluate all possible e in O(n) per check. Total moves = n + min_e (n-1-e + 2*MWIS(e)).
