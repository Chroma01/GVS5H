The shortest palindrome with prefix S can be reduced to finding the longest suffix of S that is already a palindrome. If that suffix starts at index k, then the answer is S followed by the reverse of S[:k]. Compute this longest palindromic suffix in O(|S|) using Manacher, KMP, or Z-function on a reversed-string construction. Then construct the result carefully to avoid off-by-one errors. Verify correctness on sample and boundary cases before finalizing.
