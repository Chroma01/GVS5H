- **Problem restated:** reverse process = build A from empty by prepending a constant block (cost 1) or adjacent swap (cost 1); answer = min operations = #prepended blocks + #swaps.
- **Equivalent formulation:** partition each value's occurrences into consecutive chunks (groups). Each group has a head (first occurrence). The deletion order is the order of the heads (smallest-first). Cost = (#heads) + #{(i<j) : head(i) > head(j)}. This model assumes the group order is fixed by head order.
- **Correction:** The group order is NOT necessarily the head order. In `[1,2,1,1]` the optimal groups are `{2}` (head pos2) and `{1,1,1}` (head pos1), but the `{2}` group is deleted first, so the head order is reversed. The cost is then `2 + 1 = 3`. The formula `#heads + inversions of head sequence` gives 4 for this grouping when using head order, so the head-order assumption is false.
- **Online process:** Process left to right. Maintain groups with sizes. For value v, if it has a current group g, extending costs `total_elements_so_far - prefix_sum(g)`. Creating a new group costs 1, appended at the end. This online process implicitly uses creation order as group order, so it cannot represent the optimal reversal seen in `[1,2,1,1]`.
- **Greedy rule implemented:** Create a new group iff extend cost > 1, else extend. This passes all provided samples (`[1,1,2,1,2]` -> 3, `[4,2,1,3]` -> 4, alternating length 11 -> 8). It fails on `[1,2,1,1]`, where it returns 4 instead of 3. Thus it is not a correct general solution.
- **Exact recurrence (exponential) from earlier work:** `f(A) = 1 + min_{k>=1} [ swaps(first k occurrences of A[0]) + f(A minus those runs) ]`. This is correct but has exponential state space; it was verified on small cases but TLEs on large alternating inputs.
- **Open problem:** A correct polynomial-time algorithm (target O(N log N)) is still not derived. The main difficulty is that the optimal ordering of groups can differ from their head order, and the decision to split a value depends globally on future sizes and interleavings.
- **Sample validations:** The greedy matches the three official samples. The known counterexample `[1,2,1,1]` (answer 3) is handled incorrectly by the greedy.
