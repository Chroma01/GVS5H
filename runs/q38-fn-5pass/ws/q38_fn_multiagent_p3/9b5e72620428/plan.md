For a fixed target sum S, every known value in A or B must be at most S. Known A and known B elements that are paired together must sum to S; if k such known-known pairs are made, the remaining known A need unknown B positions and the remaining known B need unknown A positions, so k must be at least L = max(0, nA + nB - N). Conversely, if all known values are <= S and there is a matching of at least L known-known pairs with sum S, the unknown positions can always be filled. For a given S, the maximum such matching size is sum_x min(cntA[x], cntB[S-x]), so when L > 0 it suffices to test sums S that occur as a+b for known values a,b and satisfy S >= maxKnown. Accumulate this matching size for all candidate sums and check whether any reaches L.
