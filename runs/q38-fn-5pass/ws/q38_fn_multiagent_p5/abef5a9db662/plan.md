Maintain an array `A[x]` for every possible initial rating `x = 1..500000`, where `A[x]` is Takahashi's current rating after processing some contests. Initially `A[x] = x`, and this array remains nondecreasing after each contest. For a contest interval `[L, R]`, the indices `x` whose current rating lies in `[L, R]` form one contiguous range, so we can find its endpoints and add 1 to that whole range. Use a lazy segment tree supporting range add and `first_ge(value)` queries to process all contests efficiently, then answer each query by point-querying the final array.
