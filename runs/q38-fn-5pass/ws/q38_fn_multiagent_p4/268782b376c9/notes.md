- **Core reduction:** For target score `s`, index `i` needs `r_i = ceil(s / points[i])` visits. The walk starts at `-1`, first move is forced to `0`, and the final index is some `t` in `[0, n-1]`.
- **Base walk for endpoint t:** Minimum traversal pattern is go to `n-1`, then return to `t`, using `2*n - 1 - t` moves. Base visits are `1` for `i < t`, `2` for `t <= i <= n-2`, and `1` for the last index.
- **Deficits and extra pairs:** Let `a_i = max(0, r_i - 1)` and `b_i = max(0, r_i - 2)`. For endpoint `t`, deficits are `a_i` before `t`, `b_i` from `t` through `n-2`, and `a_{n-1}` at the end. One extra back-and-forth pair across an edge costs `2` moves and adds one visit to both endpoints.
- **MWIS dual:** The minimum number of extra pairs covering vertex deficits on a path equals the maximum-weight independent set on that vertex path with those deficit weights. Thus `moves(t) = 2*n - 1 - t + 2 * MWIS(deficits(t))`.
- **Linear check:** The implementation computes suffix MWIS states on the mixed suffix weights, then sweeps endpoints while maintaining prefix MWIS states. Boundary states are combined to forbid taking both `t-1` and `t`.
- **Optimized implementation:** The previous version stored both prefix and suffix arrays plus an explicit `c` array. The current version stores only `a`, `suff0`, and `suff1`, and derives suffix weights as `max(0, a[i] - 1)` for non-last indices.
- **Binary search:** Feasibility is monotone. Upper bound `min(points) * m + 1` is safe because the minimum score cannot exceed the score of any index, in particular an index with minimum point value.
- **Prunes and edge cases:** If `m < n`, positive minimum is impossible, return `0`. If `sum(r_i) > m`, return false immediately because each move contributes exactly one visit. Extra unused moves are allowed, so only minimum required moves matter.
- **Verification:** Sample tests pass. Small brute-force walk enumeration for tiny `n` and `m` agrees with the binary-search answers, including asymmetric start cases such as `[1,100]` versus `[100,1]`. No endpoint/DP combination bug was found.
- **Complexity:** `O(n log(min(points) * m))` time and `O(n)` memory per feasibility check. Python integers avoid overflow.
