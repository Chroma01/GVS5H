The key observation is that for each right endpoint `r`, only conflicting pairs whose larger element is `<= r` matter; they invalidate every subarray start `l <= max(min(a,b))` among those pairs. Thus the number of valid subarrays ending at `r` is `r - M_r`, where `M_r` is that maximum smaller element. Removing a pair only increases the count at endpoints `r` where that pair is the unique active pair attaining `M_r`; the gain there is the drop from `M_r` to the second-largest active smaller element. We can sweep `r` from `1` to `n`, add pairs by their larger element, maintain the top two distinct smaller values and whether the top value has count one, and record contiguous intervals during which each pair is the unique maximum. Then sum the per-endpoint gains over each pair’s interval using a prefix sum of second maxima, add the best gain to the baseline count, and return it.
