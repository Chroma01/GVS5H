- **Reduction:** For a target D, we need a set of at most K edges such that every directed 1-to-N path contains at least D chosen edges. Exact K is harmless because changing more edges from 0 to 1 cannot decrease any path weight.
- **Label characterization:** Such a set exists iff there are integer labels d_v in [0,D] with d_1=0, d_N=D, and d_v <= d_u+1 for every edge u->v, with at most K edges satisfying d_v=d_u+1. Given labels, choose exactly those tight edges; along any 1-to-N path the label increases by D and each edge increases by at most 1, so the path uses at least D tight edges. Given a chosen set, shortest chosen-edge counts capped at D give such labels, and every tight edge must be chosen.
- **Min-cut encoding:** Use binary variables y_{v,i}=1 iff d_v>=i. Source side means 1. Force d_1=0 with INF edges (1,i)->sink and d_N=D with source->(N,i). Nesting y_{v,i+1}<=y_{v,i} is enforced by INF edges (v,i+1)->(v,i). Edge constraint y_{v,i}<=y_{u,i-1} is enforced by INF edges (v,i)->(u,i-1) for i>=2. The cost indicator d_v=d_u+1 is exactly y_{v,i}=1 and y_{u,i}=0 for one i, so add capacity-1 edges (v,i)->(u,i) for all i. The min s-t cut value is the minimum number of tight edges.
- **Search bound:** The answer is at most the unweighted shortest path length and at most K. Compute U=min(K, BFS distance) and test D=U,U-1,...,0. Feasibility is monotone, so the first feasible D is optimal.
- **Implementation details:** Dinic max-flow is rebuilt for each D. Node id is v*D+(i-1), with source=N*D and sink=N*D+1. INF=1e9 is far above any finite valid cut (at most M). Max-flow is capped at K+1, so infeasible cases stop quickly even if the true min cut is INF. Parallel edges are kept distinct by adding separate capacity-1 edges. D=0 returns True.
- **Verification:** Sample 1 gives min cut 2 for D=1 with K=2. Sample 2 gives min cut 3 for D=2 with K=3. Sample 3 has two parallel 1->2 edges, so D=1 costs 2>K and answer 0. Irrelevant vertices/edges can be assigned labels to avoid extra cost, and edges entering 1 or leaving N do not create false costs.
