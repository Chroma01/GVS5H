Compute all-pairs shortest lengths of palindromic label paths by BFS over pairs of vertices representing the two ends of the palindrome being built. Initialize distance 0 for (i,i) with the empty palindrome, and distance 1 for every existing directed edge. From state (u,v), extend outward by pairing an incoming edge p->u with an outgoing edge v->q having the same label, producing state (p,q) with distance increased by 2. Precompute predecessor and successor lists grouped by label so each transition is efficient. Finally, output the BFS distances, using -1 for unreachable pairs.
