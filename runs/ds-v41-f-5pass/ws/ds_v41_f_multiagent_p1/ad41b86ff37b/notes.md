- **Problem restatement:** delete vertices (with adjacent edges) so the remaining induced subtree is a Snowflake Tree (center, x branch vertices attached to center, each branch carrying y leaves; x>=1, y>=1). Answer = N minus the maximum size of a removable snowflake subtree.
- **Key equivalence:** For a fixed center c and parameter y, a neighbor v of c can be a branch iff v has at least y neighbors besides c, i.e. avail(v) = deg(v) - 1 >= y. Subcomponents hanging off distinct neighbors of c are vertex-disjoint in a tree, so chosen branches never conflict. Thus the largest snowflake with center c uses, for a chosen set of x branches, y = min avail over those branches. Picking the x largest avail values maximizes that minimum.
- **Per-center formula:** Let a = sorted(avail(neighbor of c)) descending. For each x = 1..len, if a[x-1] >= 1 then candidate = 1 + x * (a[x-1] + 1). Take max over all centers and all x. Answer = N - global best.
- **Why the sorted-prefix trick is exact:** For fixed x, the best achievable y is the x-th largest avail (the tightest branch), so candidate 1 + x*(y+1) is maximized by the top-x prefix; iterating all x covers every optimal (x,y) pair.
- **Complexity:** Sorting each center's neighbor list: total work sum_c deg(c) log deg(c) <= O(N log N) because sum deg = 2(N-1). Linear memory for adjacency. Comfortably fits N <= 3e5 in Python.
- **Edge cases / pitfalls:** y must be >= 1 and x >= 1, so stop a center's loop as soon as the sorted avail drops below 1 (descending order makes the rest invalid). avail uses deg(v)-1 (exclude center), not deg(v). The center need not be a tree centroid; center may be a leaf (x=1 branch is the middle of a path). Extra neighbors of a chosen branch are simply among the deleted vertices.
- **Guarantee:** N >= 3 implies a 3-vertex path is always a valid snowflake (x=1, y=1), so best >= 3 and the leftover is a single snowflake.
- **Verification:** S1: center 4, neighbors avail {3->2,5->2,8->0}; x=2 gives 1+2*3=7, N-7=1. S2: center 1, avail of vertex 2 is 1, x=1 gives 3, N-3=0. S3: center 2, avails {3,1,1}; x=3 gives 1+3*2=7, N-7=3. All match.
- **Superseded:** earlier worry about quadratic per-center work is resolved by the degree-sum bound; no need for heavy machinery.
