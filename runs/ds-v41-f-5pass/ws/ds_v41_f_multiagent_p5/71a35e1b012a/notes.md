- **Reduction:** pick type-1 set T1, type-2 set T2. A position j stays 0 iff j lies in every type-2 interval and in no type-1 interval. Goal reached iff I(T2) ⊆ U(T1), where I(T2)=[max L over T2, min R over T2] (empty if max L > min R) and U(T1)=union of T1. Cost = |T1|+|T2|.
- **Cost bound:** minimum cost is only 1, 2, 3, or impossible. Any three ops suffice: A=argmax L and B=argmin R as type-2 give I(T2)=[L_A,R_B] (nonempty once the disjoint case is excluded); every other interval C satisfies L_C≤maxL and R_C≥minR, hence contains I(T2), so any C works as type-1. Thus cost 3 is always achievable when M≥3; only M≤2 can be impossible.
- **cost 1 first:** scan i=0..M-1; first i with L_i==1 and R_i==N → output K=1, op[i]=1. A [1,N] type-2 is useless (complement empty). Must stay the very first check.
- **cost 2 has 3 shapes** (|T1|,|T2|)=(2,0),(1,1),(0,2). Check order: (c) then (a) then (b).
- **(c) one type-1 one type-2 (T2⊆T1):** input-order Fenwick scan. tree1 indexed by R stores max L; query prefix R_i finds earlier j with R_j≤R_i and L_j≥L_i (j⊆i). tree2 indexed by L stores max R; query prefix L_i finds earlier j with L_j≤L_i and R_j≥R_i (i⊆j). On first hit at i, re-scan t< i with exact predicate to recover j. Set later index as type-1, earlier as type-2 (or vice versa per condition). Emits Sample 1 exactly.
- **(a) two type-1 union = [1,N]:** maxR over {L=1} and minL over {R=N}; feasible iff both exist, indices distinct, and maxR+1 ≥ minL. Best-possible pair; distinctness automatic because [1,N] excluded by cost 1.
- **(b) two disjoint type-2:** feasible iff minR < maxL over all intervals; use argmin R and argmax L (distinct forced by minR<maxL).
- **cost 3 construction:** A=argmax L, B=argmin R. If A≠B, type-2={A,B}, type-1=any C∉{A,B}. If A==B, pick D≠A as second type-2, type-1=any C∉{A,D}. M≥3 guarantees C exists.
- **Edge cases:** N=1 (all intervals [1,N], cost-1 fires), M=1, M=2, duplicate intervals, adjacency counted as covered, correct constrained argmax/argmin. If all checks fail and M≤2 → -1.
- **Verification:** Brute-force enumerator over all 3^M assignments for N,M≤5 and thousands of random small cases found no counterexamples: on every case the solution's K matches the true minimum, its op vector is valid and uses exactly K nonzero ops, and -1 is emitted exactly when no assignment works.
- **Complexity:** O(M log N) time (Fenwick scan) plus O(M) for other checks; O(N+M) memory. Fast input via sys.stdin.buffer.read().split() handles M=200000, N=1000000.
