Binary search the minimum Manhattan distance D between 1 and 2*side. For each candidate D, construct a conflict graph where two points are adjacent if their Manhattan distance is less than D. The feasibility condition is whether there exists an independent set of size k in this graph, equivalent to a clique of size k in the complement (allowed) graph. Since k <= 25, use a bitset-accelerated branch-and-bound maximum clique search on the allowed graph to test feasibility efficiently. Optimize by ordering vertices by degree and using bitset intersections for candidate pruning and early termination once a clique of size k is found.
