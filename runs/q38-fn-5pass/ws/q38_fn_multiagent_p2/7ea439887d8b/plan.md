Model the process as a shortest-path problem on 2N states: `(vertex, parity)`, where `parity = 0` means the graph is in its original orientation and `parity = 1` means all edges are reversed. A move costs 1 and follows outgoing edges in the current orientation, while a reversal costs X and toggles parity at the same vertex. Run Dijkstra from `(1, 0)` over these states, relaxing move transitions and reversal transitions. The answer is the minimum distance to `(N, 0)` or `(N, 1)`, using 64-bit integer arithmetic because the answer can be large.
