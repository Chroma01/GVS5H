- **Core idea:** Every downward ancestor-descendant path is a contiguous suffix of some root-to-node path. For a fixed endpoint, positive edge weights imply the longest valid suffix is the earliest-start suffix that keeps all node values unique. Checking only that suffix for every endpoint is sufficient for the global longest length and the minimum-node tie-break.
- **Window invariant:** `start_depth` is the left boundary of the current unique-value window ending at the current node. `last` maps each value to the deepest active depth where it occurs. When entering a node, if its previous occurrence is at or after `start_depth`, move `start_depth` to `last[value] + 1`.
- **State restoration:** Iterative DFS uses enter/exit events. Before updating state for a node, save `old_last` and `old_start`. Push the exit event before children so it is processed after the whole subtree. On exit, restore `last` (delete the key if there was no previous active occurrence), restore `start_depth`, and pop `path_nodes`.
- **Path and distance storage:** `path_nodes` stores the current root-to-node path, so the ancestor at `start_depth` is available in O(1). `dist_node[u]` stores root distance, giving candidate length as `dist[current] - dist[ancestor]`. Node count is `depth - start_depth + 1`.
- **Tie handling:** Update the answer when a longer path is found. For equal length, keep the smaller node count. Positive edge weights ensure that for the same endpoint, a later-start suffix has strictly smaller length, so it cannot be a globally longest path if the earliest-start suffix is longer.
- **Implementation choice:** A dictionary is used for `last` instead of a bounded array. This avoids `max(nums)`, handles arbitrary integer values, and keeps expected O(n) time. The restoration logic is equivalent to array restoration but deletes values when no active ancestor has that value.
- **Validated cases:** Provided examples; all values duplicate; all values unique on a chain; duplicate values across sibling branches; duplicate ancestor-descendant values with a long valid suffix after the duplicate; single-node paths; guards for `n == 0` and `n == 1`; deep chain handled iteratively without recursion-depth issues.
- **Complexity:** Time is O(n) expected due to dictionary operations. Space is O(n) for adjacency, DFS stack, path state, distance array, and last-occurrence dictionary.
- **Edge cases:** Single-node paths have length 0 and node count 1. Repeated values force the window start past the previous occurrence. Sibling subtrees must not leak `last` entries or `start_depth`; exit events guarantee this. The suffix-only tie argument relies on strictly positive edge lengths, as given by the constraints.
