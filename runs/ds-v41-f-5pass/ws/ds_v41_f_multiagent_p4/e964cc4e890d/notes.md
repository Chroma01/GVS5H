- **Cut characterization:** final graph = forward path 1→…→2N plus matching edges W→B. It is strongly connected ⟺ S_1='B', S_{2N}='W', and for every internal cut i∈[1,2N−1] the number of back edges x_i = # black prefix matched to white suffix satisfies x_i ≥ 1. If T_i = Wp[i]−Bp[i] < 0 then x_i ≥ −T_i > 0 automatically; only cuts with T_i ≥ 0 need explicit enforcement.
- **DP reduction:** let s = x_i. Transitions: at 'B', s→s with weight s+T_{i−1}, s→s+1 weight 1; at 'W', s→s weight 1, s→s−1 weight s. Start s=0, end s=0, require s≥1 for all internal cuts. This DP is O(N^2); it was verified against brute force for small N (BWBW=1, BBWW=2, BWWBBW=2, BWBBWW=4, B^N W^N=N!).
- **Closed recurrence:** Let the internal cuts with T_i ≥ 0 be indexed t=1..L (in increasing position), with k_t=Bp[i], j_t=Wp[i], T_t=T_i. Define h_t by
  h_t = inv_fact[T_t] · ( fact[j_t] − Σ_{s<t} h_s · fact[j_t − k_s] ) mod MOD.
  Then answer = h_L (if the end cut i=2N is included as the last candidate, T=0, j=k=N, its h equals the answer). This matches the DP on all tested small cases and sample3. The recurrence is a convolution: h_t = inv_fact[T_t] · ( fact[j_t] − Σ_{s<t} h_s · fact[j_t − k_s] ).
- **CDQ + NTT:** Solve the recurrence with divide-and-conquer on candidate indices. For a node [l,r], solve left half, then convolve the left half's h values (grouped by Bc) with the factorial sequence to add contributions to the right half's accum, then solve right half. Leaf: h = (fact[Wc] − accum) · inv_fact[Tc].
- **Truncation:** For t in right half and s in left half, j_t ≥ j_{mid+1} ≥ k_{mid} ≥ k_s, so all needed indices d = j_t − k_s lie in [olo−(nA−1), ohi] where olo = Wc[mid+1]−bmin, ohi = Wc[r]−bmin, nA = bmax−bmin+1. Hence slice qlo = max(0, olo−(nA−1)), qhi = ohi; convolution length is O(segment size).
- **Convolution dispatch:** product n·m ≤ 400 pure Python; ≤ 250000 numpy 15-bit split (min(n,m) ≤ 500 ⇒ int64 safe); else numpy NTT. NTT tables precomputed up to 2^19 (covers 2N+2). Primitive root 3, standard DIT butterflies.
- **Complexity:** O(N log^2 N) time, O(N) memory. For N=2e5, max NTT length 2^19. Direct O(N^2) DP used when M ≤ 800 for simplicity and speed.
- **Edge cases:** S_1 ≠ 'B' or S_{2N} ≠ 'W' ⇒ answer 0. N=1: S must be "BW", answer 1.
