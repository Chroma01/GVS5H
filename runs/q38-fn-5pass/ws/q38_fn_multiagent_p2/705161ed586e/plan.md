Model the target caption as a sequence of runs where each run has length at least 3, and the cost of assigning a character to a position is its absolute alphabet distance from the original character. Use backward dynamic programming over position, previous run character, and current run length capped at 3 to compute the minimum suffix cost. Optimize transitions by maintaining the best and second-best switch costs over the 26 letters, giving O(26n) time. Store all DP rows compactly so the final string can be reconstructed. Reconstruct greedily by choosing the smallest feasible character at each position that preserves optimal cost, which yields the lexicographically smallest caption among all minimum-operation solutions.
