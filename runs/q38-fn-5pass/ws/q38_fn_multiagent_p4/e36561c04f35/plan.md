Model each deletion operation as a batch of equal values and assign every element the batch’s deletion-order label. The total cost is the number of batches plus the number of inversions between these labels in the original sequence, since each inversion corresponds to one adjacent swap needed to bring a later-deleted batch element before an earlier-deleted one. Thus the problem becomes partitioning each value’s occurrences into ordered batches so as to minimize batches + inversions, with equal-value batch labels nondecreasing and batch first occurrences appearing in deletion order. Derive an efficient occurrence-based DP/greedy characterization from this model, using data structures to maintain label-count information and evaluate extending an existing batch versus starting a new one. Implement the resulting O(N log N) total-time algorithm and verify it on samples and edge cases.
