Because each food contributes to only one vitamin, split foods by vitamin type. For each type, compute the maximum vitamin amount achievable with at most `c` calories using a 0/1 knapsack DP over calories `0..X`. After prefix-maxing these arrays, the problem becomes allocating calories among the three vitamin types: maximize `min(dp1[c1], dp2[c2], dp3[X-c1-c2])` over all `c1 + c2 <= X`. This gives an `O(NX + X^2)` solution, feasible for `N, X <= 5000`. Missing vitamin types naturally produce zero values and lead to answer `0`.
