Collect the positions of all `1`s in the string. If there are `k` ones, their final contiguous block can be represented by target positions `x, x+1, ..., x+k-1` for some integer `x`. To minimize adjacent swaps, match the `j`-th one to the `j`-th target position, giving cost `sum |p_j - (x+j-1)|`. Define `a_j = p_j - (j-1)` using 0-based positions, so the problem reduces to choosing `x` that minimizes `sum |a_j - x|`, which is achieved by the median of `a_j`. The answer is the sum of absolute deviations from this median.
