Model each vertex as two states: normal orientation and reversed orientation. Moving along an original edge costs 1 in the corresponding orientation layer, while switching orientation at the same vertex costs X. Then the problem becomes a shortest-path problem from vertex 1 in the normal state to vertex N in either state. Run Dijkstra on this doubled graph with nonnegative weights. The answer may exceed 32-bit range, so use 64-bit-safe integers.
