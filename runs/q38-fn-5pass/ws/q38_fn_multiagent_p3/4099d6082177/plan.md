For K=1 the answer is always Yes. Otherwise root the tree arbitrarily and process subtrees bottom-up. For each subtree, at most one path can use the edge to its parent; return 0 if the subtree can be completely decomposed, otherwise return the number of vertices (1..K-1) in the unfinished path segment that contains the subtree root and must be extended upward. At a vertex, every child returning a positive value must be attached to that vertex, and since the vertex belongs to only one path, there can be at most two such children: two must together with the vertex form a completed path of K vertices, one may either complete the path if its length is K-1 or be passed upward, and none starts a new upward segment. The root is valid exactly when it returns 0.
