Derive the count by choosing exactly k of the n-1 adjacent gaps to be equalities; the remaining gaps must be inequalities. These chosen equalities split the array into n-k runs of equal values, and since neighboring runs must differ, the number of value assignments is m * (m-1)^(n-1-k). Thus the answer is C(n-1, k) * m * (m-1)^(n-1-k) modulo 1e9+7. Implement modular binomial coefficients efficiently for n up to 1e5, and use fast modular exponentiation.
