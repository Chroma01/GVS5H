- **Core idea:** Process values from N down to 1. When value x is processed, all larger values have already been moved to their final positions x+1..N, so x only needs to move right inside the prefix of length x.
- **Current position formula:** Let pos[x] be the initial position of x. Among positions 1..pos[x], let larger_left be the number of already processed larger values. Those larger values started to the left of x and crossed it while moving right, pushing x left by one each. Therefore x's current position is cur = pos[x] - larger_left.
- **Validity of cur:** cur is the rank of x among values <= x in the current prefix, so cur <= x. It is also at least 1 because larger_left <= pos[x]-1.
- **Cost calculation:** Moving x from cur to final position x uses adjacent swaps at indices cur, cur+1, ..., x-1. Add the arithmetic sum (cur + x - 1) * (x - cur) // 2. If cur == x, the cost is zero.
- **Fenwick tree usage:** Maintain a Fenwick tree over initial positions of processed larger values. For each x descending, query prefix pos[x]-1 to get larger_left, then update pos[x]. This gives O(log N) per value.
- **Greedy correctness sketch:** A larger value must end to the right of every smaller value. If a larger value is initially left of a smaller one, their crossing is mandatory. Moving larger values right as early as possible shifts smaller values left, which can only reduce the indices of their future swaps. The greedy order resolves each inversion exactly once and minimizes the positions where those crossings occur. Extra swaps of non-inverted pairs add positive cost and are not beneficial.
- **Edge cases:** Already sorted permutations produce cur == x for every value and answer 0. Reverse permutations are handled without simulation. Python integers safely hold the maximum answer.
- **Complexity:** O(N log N) time and O(N) memory, suitable for N up to 2e5.
- **Implementation details:** Use 1-indexed positions. Query before update so only larger values are counted. Read all input from stdin.buffer and print the final answer.
