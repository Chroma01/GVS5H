- **Chosen approach:** Generic residue dynamic programming over divisors 1 through 9. After processing each character, `dp[d][r]` stores how many substrings ending at the current position have numeric value congruent to `r` modulo `d`.
- **Transition:** When a new digit `x` arrives, every substring ending at the previous position can be extended by `x`. If its old residue modulo `d` was `r`, the new residue is `(r * 10 + x) % d`. The one-character substring `x` contributes residue `x % d`. A fresh table is built each step because several old residues can map to the same new residue, so in-place updates would corrupt counts.
- **Answer accumulation:** If the current digit `x` is non-zero, substrings ending at this position are divisible by their last digit exactly when their value is `0` modulo `x`. Therefore add `dp[x][0]` after the transition. Digit `0` is never counted, but its states are still updated because zero-ending substrings can be extended later.
- **Leading zeros:** The recurrence naturally treats a substring like `"01"` as value `1`, matching the problem statement. No special handling for leading zeros is needed.
- **Complexity:** There are `1 + 2 + ... + 9 = 45` residue states total. Each character performs at most 45 residue updates, so time is `O(45n)`, effectively linear. Memory is `O(1)` because only 45 counters are maintained. For `n = 10^5`, this is about 4.5 million inner updates, comfortably within limits.
- **Implementation details:** Transition tables and digit modulo tables are precomputed to avoid repeated modulo arithmetic inside the main loop. `dp` is indexed directly by divisor, with index `0` unused. The modulo-1 case works naturally because it has a single residue bucket.
- **Validation:** Single-character non-zero digits contribute `1`. Endings in `1`, `2`, and `5` count all substrings ending there because the DP residue for those divisors becomes zero for every such substring. Endings in `6` are handled directly modulo `6`. Examples with leading zeros and strings ending in zero are handled by skipping zero endings while preserving extendable states.
