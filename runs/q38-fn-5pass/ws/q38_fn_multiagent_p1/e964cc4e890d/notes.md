- **Strong connectivity reduction:** The path edges give reachability to the right. The graph is strongly connected iff every cut between consecutive vertices is crossed by at least one added white-to-black edge from right to left. If the first vertex is not black or the last vertex is not white, some end cut cannot be crossed, so the answer is zero. If first is black and last is white, pairing the first black with the last white gives at least one valid matching.
- **Permutation formulation:** Let black vertices be `b_1 < ... < b_N` and white vertices be `w_1 < ... < w_N`. A matching is a permutation `a_j`, where black `j` is matched with white `a_j`. For `s = 1..N-1`, let `R_s` be the number of whites before `b_{s+1}`. The cut just before `b_{s+1}` is crossed iff `max(a_1,...,a_s) > R_s`. The final cut is automatic when the last vertex is white.
- **Bad events and constraint reduction:** Event `E_s` is `max(a_1,...,a_s) <= R_s`, i.e. the first `s` matched white indices all lie in `[1, R_s]`. If `R_s < s`, `E_s` is impossible. If several constraints have the same `R`, the earliest `s` dominates later ones. Thus keep only first increases of `R_s` with `R_s >= s`.
- **Inclusion-exclusion DP:** For a chain of kept constraints `p_1 < ... < p_k`, the number of permutations satisfying all corresponding bad events is a product of falling factorials. Define coefficients `D_i` for chains ending at constraint `i`. They satisfy:
  `D_i * fact[r_i - s_i] = -fact[r_i] - sum_{p<i} D_p * fact[r_i - s_p]`.
  The final answer is `fact[N] + sum_i D_i * fact[N - s_i]` modulo `998244353`.
- **Validation:** This recurrence was checked against direct permutation enumeration for small `N`, endpoint cases (`N=1`, no constraints, duplicate `R_s`, automatic constraints), and the provided samples.
- **CDQ convolution:** The DP is an online triangular convolution. Maintain `add[j] = sum_{p<j} D_p fact[r_j - s_p]`. CDQ over constraint indices: solve left half, add contributions from left to right by convolution, then solve right half.
- **Shifted convolution details:** For left indices `[l, mid)` and right indices `[mid, r)`, let `s_min = s_l`, `s_max_left = s_{mid-1}`, `r_min_right = r_mid`, `r_max_right = r_{r-1}`. Use `A[x] = D_i` at `x = s_i - s_min`, and `B[t] = fact[min_d + t]` where `min_d = r_min_right - s_max_left`. For right index `j`, the needed sum is coefficient `q = r_j - s_min - min_d` of `A * B`.
- **NTT implementation:** Modulo `998244353`, primitive root `3`. Uses no-bit-reversal DIF forward and DIT inverse transforms. Pointwise multiplication of bit-reversed spectra is valid because both forward transforms use the same permutation.
- **Performance thresholds:** Direct `O(m^2)` for `m <= 2000`. CDQ blocks of size `64` are processed naively. Cross contributions are naive when the pair count is at most `8000`, or when the estimated NTT length is much larger than the pair count; otherwise NTT is used.
- **Complexity:** Precomputation `O(N)`. CDQ with NTT is about `O(N log^2 N)` in the worst case, with memory `O(N)`. The implementation includes fallbacks to avoid many tiny NTTs and to handle sparse coordinate gaps.
- **Edge cases handled:** `N=1` with `BW` gives `1`; invalid first/last colors give `0`; no reduced constraints gives `N!`; constraints with `r_i = s_i` use `invfact[0] = 1`.
