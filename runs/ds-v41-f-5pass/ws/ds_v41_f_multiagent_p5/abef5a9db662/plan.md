Process contests forward while maintaining the mapping F(X) = current rating for initial rating X. Since F is non-decreasing, the set of initial ratings whose current rating lies in [L_i, R_i] forms a contiguous interval [A, B]. Find A as the first index with F(X) >= L_i and B as the last index with F(X) <= R_i, then add 1 to F on [A, B]. Use an iterative lazy segment tree over X=1..500000 to support range add, point query, and finding the first index with value >= a target in O(log M). Finally answer each query by point-querying F(X).
