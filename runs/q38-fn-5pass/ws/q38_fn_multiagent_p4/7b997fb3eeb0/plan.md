For a sorted interval, the maximum number of pairs is the largest K such that the K smallest elements can be matched to the K largest elements; this is equivalent to `2*A[L+t] <= A[R-K+1+t]` for all `t=0..K-1`. Precompute `p[i]` as the first index with `A[p[i]] >= 2*A[i]`, and define `D[i] = p[i] - i`. Then the condition for a query `[L,R]` and candidate `K` becomes `max(D[L..L+K-1]) <= (R-L+1)-K`, which is monotone in `K`. Compute `p` with a two-pointer scan, build a range-maximum sparse table over `D`, and answer each query by binary searching the largest valid `K`. This gives `O((N+Q)logN)` time and is feasible for `N,Q <= 2e5`.
