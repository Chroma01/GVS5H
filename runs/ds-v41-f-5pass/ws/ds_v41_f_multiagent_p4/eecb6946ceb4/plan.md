Use an autocorrelation/convolution approach over the value domain: create a binary indicator array for S, convolve it with itself, and use the coefficient at sum 2B to count ordered pairs symmetric around B. For each B in S, the convolution counts all ordered pairs (A,C) with A+C=2B, including the self-pair (B,B). Summing over all B, subtract N self-pairs, then divide by 2 because each valid fine triplet appears as both (A,C) and (C,A). Since the indicator is 0/1 and N <= 10^6, a single NTT modulo 998244353 gives exact coefficients. Max value <= 10^6 keeps convolution length around 2^21, which is efficient.
