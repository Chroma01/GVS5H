Root the tree arbitrarily and process vertices bottom-up. For each subtree, keep a state: `-1` if impossible, `0` if the subtree is already fully decomposed, or a positive integer `< K` meaning there is exactly one unfinished path of that length that must connect to the parent. At a vertex, only child subtrees with positive states need to use this vertex; if there are 0, 1, or 2 such children, check whether they can either complete a path of length `K` or leave a valid open path upward, otherwise the decomposition is impossible. The whole tree is decomposable iff the root state is `0`, with `K = 1` handled trivially as `Yes`.
