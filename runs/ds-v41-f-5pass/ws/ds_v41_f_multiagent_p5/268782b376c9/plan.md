Use binary search on the answer T because feasibility is monotone: if a minimum score T is achievable, every smaller score is also achievable. For a candidate T, each index i must be visited at least ceil(T / points[i]) times. This becomes a minimum-move path problem on a line starting at -1; compute the minimum total moves needed to satisfy all required visit counts. The check can be done in O(n) with a right-to-left DP/greedy over edge crossings or possible final index. Total complexity O(n log(maxScore)), which fits the constraints.
