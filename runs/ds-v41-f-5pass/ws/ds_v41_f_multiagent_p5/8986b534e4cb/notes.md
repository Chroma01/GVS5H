- **Model:** Set P[1]=0, P[x+1]=P[x]+w_x. Person (S,T): l=min, r=max, up=(S<T) requires P[l]=P[r] and every interior x has P[x]>P[l] (up) or P[x]<P[l] (down). Feasibility of a subset is equivalent to acyclicity of the strict difference constraints after contracting equalities. The pairwise conflict criterion is: conflict iff same l, same r, or same direction and properly crossing (l_i<l_j<r_i<r_j). This is believed sufficient (each direction's non-crossing intervals are laminar) and matches all samples and manual checks.
- **nc and queries:** nc[i] = min j>i conflicting. Feasibility is monotone under subsets, so [L,R] is valid iff min_{i in [L,R]} nc[i] > R. Since nc[i]>i, a suffix minimum over [L,M] is exact. Query [L,R] -> Yes iff suf[L] > R.
- **Same-endpoint conflicts:** Computed in O(M) using a dictionary of last seen index for each L and each R. For each i, if a previous index prev had the same L, set nsl[prev]=i; similarly for R. This correctly gives the smallest j>i with the same endpoint.
- **Crossing conflicts:** For each direction group separately, process persons in increasing index order. Maintain active intervals. For current j, find all active i that properly cross j and have not yet been matched; assign crossed[i]=j and delete i. Two segment trees with lazy-deletion heaps:
  - Tree A (indexed by compressed r): stores min(l*BIG+i) among active i. Query r in (l_j, r_j) for min < l_j*BIG to find l_i < l_j < r_i < r_j.
  - Tree B (indexed by compressed l): stores max(r*BIG+i) among active i. Query l in (l_j, r_j) for max >= (r_j+1)*BIG to find l_j < l_i < r_j < r_i.
  - Big = M+1 recovers index i as value % BIG (or (-value) % BIG for B). Each i is deleted once, giving amortized O(M log M) per direction.
- **Edge cases:** direction group with <2 members skipped; touching (r_i = l_j) is not crossing and is feasible; nested different directions and crossing different directions are always feasible; M=1 gives nc=INF -> Yes. All strict inequalities are handled correctly by the thresholds.
- **Performance:** O((M+Q) log M) time. Compression keeps segment tree sizes ≤ 2*2^18. In Python, the heavy constant factor comes from the many segment-tree updates; the code uses local bindings and breaks early when a parent value does not change.
