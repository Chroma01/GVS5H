Use binary search on the answer because feasibility is monotone: if a minimum score is achievable, any smaller score is also achievable. For a candidate score `s`, each index `i` requires `c_i = ceil(s / points[i])` visits. A walk on the line can be characterized by its ending index `t` and the number of right-to-left traversals of each edge; after accounting for the mandatory first traversal of every edge, the minimum extra traversals for fixed `t` equal a maximum-weight independent set on a path. The path weights are `H_i = max(0, c_i - 1)` for the prefix before `t` and `L_i = max(0, c_i - 2)` for the suffix from `t`, with the last weight always `H_{n-1}`, and the move count is `2n - 1 - t + 2 * MWIS`. Compute the minimum over all `t` in O(n) per check using prefix/suffix DP, then binary search the maximum feasible score.
