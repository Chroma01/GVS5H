- **Core reduction:** For a final common sum H, every tooth contributes exactly H to the final total length. Since operations only reduce lengths, the final total is N*H and the cost is original_total - N*H. Therefore minimizing cost is equivalent to maximizing feasible H.
- **Per-tooth interval:** If the final upper length is u_i, the final lower length is H - u_i. Validity requires 0 <= u_i <= U_i and 0 <= H - u_i <= D_i, so u_i must lie in [max(0, H - D_i), min(U_i, H)].
- **Chain feasibility:** For fixed H, we need to choose one integer from each interval such that adjacent chosen values differ by at most X. The set of possible values at each position remains an interval. Starting from the first interval, the reachable interval for the next position is the previous interval expanded by X, intersected with the current interval. If this intersection becomes empty, H is infeasible.
- **Monotonicity:** If H is feasible, then H-1 is also feasible. Given a valid sequence u_i for H, replacing each u_i by min(u_i, H-1) preserves all interval bounds and does not increase adjacent differences. Thus feasible H values form a prefix, allowing binary search for the maximum H.
- **Search bounds:** H cannot exceed min_i(U_i + D_i), because each final tooth sum cannot exceed its original sum. H = 0 is always feasible by making all lengths zero, so binary search can start from 0.
- **Implementation details:** The solution reads all input, stores pairs, and keeps the first pair separately plus a tail list for faster iteration inside the feasibility check. Binary search uses upper-mid to find the largest feasible H. Python integers handle the large answer safely.
- **Complexity:** Each feasibility check is O(N). Binary search over H up to 2e9 takes about 31 iterations, so total time is O(N log max(U_i + D_i)), with O(N) memory.
- **Pitfalls:** A greedy fixed choice of values is not enough; the whole possible interval must be propagated. Pairwise adjacent interval compatibility alone is not sufficient over a chain. The interval lower bound must include 0, and the upper bound must include H. Final lengths may be zero because the operation allows reducing a positive length to zero.
