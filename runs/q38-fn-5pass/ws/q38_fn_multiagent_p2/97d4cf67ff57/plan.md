Root the tree arbitrarily and process it bottom-up. For each node u, compute dp[u] as the maximum size of a valid branch inside u's subtree that contains u, uses the edge to u's parent, and makes u have degree 4; such a branch must choose exactly three child branches, each either a single leaf or a valid dp branch from that child. Compute dp[u] from the largest three child contributions, using dp[v] when valid and 1 otherwise. Then evaluate every node as the topmost vertex of the final alkane: it may have degree 4 by choosing four child branches, or degree 1 by choosing one child branch that is a valid dp branch. Take the maximum over all nodes, or output -1 if no valid candidate exists.
