Process the permutation as a sequence of independent element moves: fix values from N down to 1, since larger values ultimately belong to the suffix and can be moved right without disturbing already fixed larger elements. For each value v, compute its current compressed position among remaining values 1..v; the required cost to move it to position v is the sum of edge indices from that position to v-1. This yields an O(N log N) formula using a Fenwick tree over original positions while iterating v increasingly. Prove the greedy/exchange argument that this minimizing per-value rightward movement is globally optimal. Then implement and stress-test against brute force for small N.
