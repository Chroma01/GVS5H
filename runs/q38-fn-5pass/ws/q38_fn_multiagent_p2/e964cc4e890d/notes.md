- Reduction to prefix cuts: path edges only move right, so strong connectivity is equivalent to vertex 2N reaching vertex 1. This holds iff every proper prefix has at least one added edge entering it from the suffix. If S_1 is W or S_{2N} is B, impossible.
- Only cuts just before black vertices need checking. For the prefix before the (b+1)-th black, let j=b and a=#whites before it. If a<j, a closed prefix is impossible by pigeonhole. If a>=j, the bad event is that the first j black ranks are matched only to the first a white ranks.
- Encode a pairing as a permutation P of white ranks matched to black ranks. Constraint (j,a) requires max(P_1,...,P_j)>a. Since a is nondecreasing, constraints with the same a are redundant after the first one; keep only strictly increasing a.
- Inclusion-exclusion over bad prefix events gives a triangular DP. For selected constraints ending at t, the count factorizes into falling factorials. Define F[t] as the signed sum of subsets ending at t. Recurrence:
  F[t] = (fact[a_t] - sum_{p<t} F[p] fact[a_t-j_p]) * invfact[a_t-j_t].
  Answer = fact[N] - sum_t F[t] fact[N-j_t].
- The DP is an online convolution: updates are at coordinates j_p, queries at coordinates a_t, kernel is factorial of the difference. CDQ divide-and-conquer over constraint index computes all dependencies.
- For a CDQ batch, left updates have max coordinate max_j_left, right queries have min coordinate min_a_right. Because a_t >= j_t > max_j_left, every shifted query index is strictly larger than every shifted update index. Therefore a cyclic convolution of length L > max_a_right-min_j_left gives correct queried coefficients even though the kernel is padded to length L; wrap-around cannot reach queried indices. This lets each batch use NTT length based only on coordinate span.
- The factorial kernel K[d]=d! for d=0..L-1 is the same for all batches of the same length, so its NTT transform is cached by L.
- NTT implementation uses modulus 998244353 and primitive root 3. It uses DIF forward and DIT inverse without explicit bit reversal: forward outputs bit-reversed order, inverse consumes bit-reversed order. Stage roots are precomputed; inverse roots are derived from forward roots by negating the reversed half.
- Factorials are precomputed up to max(N, max power-of-two span). Values beyond N in the padded kernel are harmless because they cannot affect queried coefficients under the no-wrap argument.
- Implementation uses direct O(M^2) for M<=3000. For larger M, CDQ uses leaf size 64 and naive cross contributions when left_size*right_size<=32768; otherwise NTT. Accumulators are kept as unreduced Python integers and reduced when computing F, which avoids many modulo operations in inner loops.
- Validated conceptually against samples and small brute-force cases; endpoint failures and redundant constraints are handled explicitly.
