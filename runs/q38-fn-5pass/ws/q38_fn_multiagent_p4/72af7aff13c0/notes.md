- **Core formula:** For a cell `(r,c)`, its total contribution is `A[r][c] * L * Rex`, where `L` is the sum of path products from `(0,0)` to `(r,c)` excluding the cell, and `Rex` is the sum from `(r,c)` to `(R-1,C-1)` excluding the cell. A point assignment changes the global answer by `(new-old)*L*Rex`.
- **No division:** `L` and `Rex` are read from neighboring forward/backward DP values, so zero cell values are safe.
- **Orientation:** The grid is optionally transposed so the DP dimension `R` is small. The chosen orientation is estimated by `R * (Q + number_of_horizontal_moves_in_that_orientation)`, with a cap to avoid too-large `R`. Transposition maps original `L/R/U/D` to new `U/D/L/R` respectively.
- **DP storage:** `F[c][i]` is forward DP in normal row order. `G[c][k]` is backward DP stored reversed by row: `G[c][k] = B[c][R-1-k]`. Reversing makes the part of backward DP affected by an update also recomputable top-down, which simplifies lazy refreshes.
- **Lazy invariant:** After processing a query at current column `c`, all `F` columns up to `c` are fresh and all `G` columns from `c` onward are fresh. Moving right can make `F[c]` stale; moving left can make `G[c]` stale. Vertical moves keep both current columns fresh.
- **Right move processing:** Compute only the old prefix of `F[c]` needed for `L`, apply the answer delta, then compute the new suffix of `F[c]`. `G[c]` is already fresh; only its affected suffix is recomputed.
- **Left move processing:** Compute the old prefix of reversed `G[c]` needed for `Rex`, apply the answer delta, then compute the new suffix of `G[c]`. `F[c]` is already fresh; only its affected suffix is recomputed.
- **Vertical move processing:** Both current DP columns are fresh. Recompute the affected suffix of `F[c]` and the affected suffix of reversed `G[c]`.
- **Same-value assignments:** If the assigned value equals the old value, the answer and grid do not change. Only a stale column caused by the horizontal move needs a full refresh to restore the invariant.
- **Boundaries:** Start cell uses `L=1`; end cell uses `Rex=1`. In reversed backward DP, update at row `r` affects `G` indices `k >= R-1-r`.
- **Complexity:** Initial DP is `O(HW)`. Each query is `O(min(H,W))` (with a small constant; horizontal moves may touch up to about two affected DP parts). With the chosen orientation this fits the constraints.
