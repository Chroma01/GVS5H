- **Model:** A flip at position i costs the current total weight sum(A_k*C_k) after the flip. Total cost = sum over operations of the weight of the 1-set after that op.
- **Classification:** F = {A=1,B=0} forced off once. T = {A=0,B=1} forced on once. M = {A=1,B=1} optional: either untouched, or flipped off then on (exactly twice). Ignored = {A=0,B=0}, never flipped. Flipping extra times never helps.
- **Provable schedule shape:** all 1->0 flips happen before all 0->1 flips (adjacent swap of a 0->1 then 1->0 reduces cost by C_i+C_j>0). Off-phase order is descending C; on-phase order is ascending C (minimizes sum of weights via pair-min terms).
- **Exact cost for chosen set S of M to toggle:** let K=|F|+|T|, s=|S|, P=sum(S), CM=sum(M), Q=sum of pairwise min within S, RF=sum_{F x S} min, RT=sum_{T x S} min. Then Total(S) = (K+2s)(CM-P) + PFF + CT + PTT + 2Q + P + RF + RT, where PFF/PTT are sums of pairwise min inside F/T. OffTerm(X)=sum of pairwise min; OnTerm(Y)=sum(Y)+sum of pairwise min.
- **Prefix theorem (proved):** for a>b with b in S, a not in S, swapping gives delta = (1-(K+2s))(a-b) + 2 dQ + dRF + dRT <= (a-b)[1-(K+2s)+2(s-1)+K] = -(a-b) < 0. So no optimal S has this pattern; optimal S is always the largest |S| elements of M, i.e. a prefix in descending C. Scan all prefix sizes, take the min (sequence is not unimodal, so scan everything).
- **Marginal for prefix build (descending):** adding c when all chosen are >= c means pairwise-min within S is s*c, so Q term folds in. delta = 2(CM-P) - (K+1)c + SF(c) + ST(c), with SF(c)=sum_F min(c,.), ST(c)=sum_T min(c,.). Compute via sorted F/T + prefix sums + bisect: SF = prefF[bisect_left(F,c)] + c*(f - idx), same for T.
- **Base cost (S empty):** base = K*CM + PFF + CT + PTT. PFF = sum_i Fs[i]*(f-1-i) (ascending; each element is the min in pairs with all larger ones). PTT analogously. Equivalent to the plan's "-SigmaFmax" form since PFF = (f-1)*CF - SigmaFmax.
- **Disproven:** the earlier marginal formula delta = (CF+2CM) - 2P - (t+1)c - SF(c) + ST(c) is wrong (wrong constant, wrong SF/ST signs). Correct marginal derived above; verified it reproduces S={2} cost 18 on a hand case where the bad formula gives 29.
- **Verified by hand:** sample 1 -> 16, sample 2 -> 0; plus several small brute-force checks (e.g. A=(1,1,1) B=(0,0,1) C=(1,1,100) -> 103; A=(1,1) B=(0,1) C=(2,3) -> 3).
- **Complexity:** O(N log N) time (sorts + bisect per M element), O(N) memory. Python ints handle 64-bit-range sums automatically.
