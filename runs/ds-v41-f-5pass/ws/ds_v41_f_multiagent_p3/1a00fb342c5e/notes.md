- **Model:** Each constraint A_x xor A_y = Z is a XOR potential edge on a graph of N vertices. Within a connected component all valid assignments equal A_v = r xor D_v for one free value r, where D is any fixed potential from the component root.
- **Feasibility:** Run BFS from each unvisited vertex, setting D_v = D_u xor Z for tree edges; for every edge (u,v,Z) with both endpoints visited, require D_u xor D_v == Z. Any violation (including odd cycles) means no solution -> print -1. Self-loops (x==y) require Z==0; they are covered by the same check since D_x xor D_x = 0.
- **Per-bit optimality:** sum A = sum over bits 2^k * (number of vertices with that bit = 1). XOR acts bitwise independently, so r can be chosen bit by bit. For bit k, count c1 = number of D_v with that bit set; setting r's bit to 0 costs c1, to 1 costs s-c1. Choose the smaller: set r's bit to 1 iff c1 > s-c1. Bits are independent across and within components, so component choices are independent too.
- **Bit range:** Z <= 1e9 < 2^30, so all potentials fit in 30 bits; using 31 bits is safe. Higher bits never help (all D bits are 0 there, so choosing r=0 is strictly better).
- **Implementation details that matter:** use iterative BFS (no recursion limit issues); only add edge (y,Z) again when x != y to avoid a doubled self-loop; adjacency store both directions for normal edges so every edge is checked from at least one side; unvisited sentinel by boolean, not by D value (D can legitimately be 0).
- **Complexity:** O(N + M) for BFS plus O(31 * N) for bit counting: fine for N = 2e5, M = 1e5.
- **Verified samples:** Sample 1 -> "0 3 4"; Sample 2 -> "-1" (D_2 xor D_3 = 7 != 5); Sample 3 -> "0 2 9 6 0" (all one component, r=0). Edge cases: M=0 gives all zeros; self-loop Z!=0 gives -1; duplicate/contradictory edges caught by edge check.
