The problem reduces to choosing 2K items and assigning each to one of three colors (corresponding to beauty, tastiness, popularity) such that each color count is even, maximizing the sum of the assigned coordinate values. This works because for any pairing, assigning each pair to its argmax coordinate gives exactly the total price, and conversely any even-colored assignment can be paired within colors. 
For a fixed set of 2K items, the best base assignment uses each item's maximum coordinate M_i. We sort items by M_i descending and take the top 2K. If the color counts are already even, this is optimal. Otherwise, only the parity of two colors is odd; fixing it requires at most two operations: flipping a selected item to another color, or swapping a selected item with an unselected one. These operations correspond to edges in a 3-node parity graph. We compute the minimum cost to fix the parity by considering direct edge between the two odd colors, or a 2-edge path via the third color. Distinctness of used items is enforced because operations may share selected or unselected items.
The algorithm runs in O(N log N) per test case, easily within limits since the sum of N is ≤ 1e5.
