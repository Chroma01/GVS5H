Use the characterization that for any candidate divisor d, a valid K-element subset containing A_i exists with all elements divisible by d iff d divides A_i and at least K input values are divisible by d. Therefore the answer for A_i is the largest divisor d of A_i whose frequency count cnt[d] is at least K. Compute cnt[d] for all d up to max(A) with a multiple sieve over value frequencies, then process d from largest to smallest and assign ans[m]=d for every multiple m of d that has not yet been assigned. Finally, output ans[A_i] for each original position. Complexity is O(M log M + N) where M = max(A), which is suitable for the constraints.
