The remaining graph must be a connected subtree that is exactly a snowflake. For a fixed center c and leaf parameter y, each blue vertex can be any neighbor v of c with at least y neighbors other than c, so the best size for that c,y is 1 + x*(1+y), where x is the number of such neighbors. Maximize this quantity over all possible centers c and positive y. Then the answer is N minus the maximum kept vertices. This can be computed efficiently by sorting the values deg(v)-1 for neighbors v of each candidate center.
