For a fixed target sum H, each tooth pair imposes an interval for the final upper tooth length: `max(0, H - D_i) <= u_i <= min(U_i, H)`. We need to choose one value from each interval so that adjacent upper lengths differ by at most X. This can be checked greedily by maintaining the interval of possible current upper lengths and intersecting it with the next interval expanded by X. Feasibility is monotone with respect to H, so binary search the maximum feasible H. The minimum cost is then `sum(U_i + D_i) - N * H`.
