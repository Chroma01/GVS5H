Treat red and blue balls independently first: a red ball can reach X only if it lies on the P-cycle containing X, and similarly blue on the Q-cycle. For a feasible color, the only ball that determines the required firing sequence is the occupied vertex farthest from X along the permutation direction; all other balls of that color lie on the path from that vertex to X. Thus we obtain two ordered lists of boxes to operate, R for red and B for blue, both ending just before X. An operation can advance both critical balls only when the next required box is the same, so the maximum number of shared operations is the LCS of R and B. The minimum number of operations is |R| + |B| - LCS(R,B), with -1 if any ball is in the wrong cycle.
