- **Core reduction:** f(x,y) is the minimax path value. In any MST, f(x,y) equals the maximum edge weight on the MST path. Equivalently, in a Kruskal reconstruction tree, f(x,y) is the LCA weight of leaves x and y. The cost matrix is ultrametric: merge weights only increase as we go upward.
- **Matching structure:** Because costs only increase, it is optimal to pair as many A/B elements as possible at the lowest merge weight. Within a DSU component, individual identities are irrelevant; only the surplus (#A - #B) matters.
- **DSU sweep:** Initialize diff[v] = countA[v] - countB[v]. Sort edges by weight. For each edge (w,u,v), find roots. If same root, skip. Let du,dv be diffs. If signs are opposite, p = min(|du|,|dv|) pairs must be matched at cost w, so ans += w*p. Merge components and set new diff = du+dv. Output ans.
- **Correctness of greedy:** Any pair crossing between components merged at weight w has fixed cost w. Pairing them now cannot hurt future costs because after the merge, all vertices in the combined component are interchangeable for all higher-level merges. Equal-weight edges can be processed in any order; the total number of pairs formed at that weight is invariant.
- **Duplicates and limits:** Duplicate vertices in A or B are handled by counts in diff. Python integers handle the maximum answer (~2e14) naturally.
- **Complexity:** O(M log M + N + K) time, O(N + M) memory.
- **Pitfalls avoided:** Do not compute all-pairs bottleneck distances or run Hungarian matching. Skip edges already inside one DSU component. Use iterative find to avoid recursion limits. Update the new root’s diff after union.
