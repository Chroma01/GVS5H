- **Problem shape:** p has exactly two `*`, so `p.split('*')` gives three literal segments A, B, C. A matching substring is contiguous `s[l:r]` where A matches at `l`, B somewhere after, C after that, with stars absorbing the gaps.
- **Greedy correctness:** For a fixed start `l`, pick the earliest B occurrence starting at or after `l+len(A)`, then the earliest C occurrence starting at or after `B_end`. A later B can only push B_end later, hence can only keep or increase the earliest valid C start, so earliest B is optimal for that `l`. Minimize `r-l` over all `l`.
- **Candidate starts:** If A is nonempty, `l` must be an occurrence start of A (pattern begins with literal A). If A is empty, the leading star can absorb anything, so iterate `l` over `0..n`.
- **Empty-segment handling:** An empty B is treated as occurring at every position, so `b = p1`; an empty C is treated as `c = p2`. This unifies all four non-empty/empty combinations and avoids off-by-one star bugs (stars may match zero characters, segments must not overlap but may be adjacent).
- **Next-occurrence arrays:** Build `nxt[i]` = smallest occurrence start `>= i` (INF if none) by placing occurrence starts then sweeping `i` from `n` down to `0` taking suffix minima. Size `n+2`; index `n+1` stays INF.
- **Matching:** Collect overlapping occurrences with KMP in `O(n + seg_len)`. Doing all three KMP passes is `O(n + m)`. Avoid Python `str.find` loops for overlapping matches; KMP is deterministic.
- **Complexity:** `O(n + m)` time, `O(n + m)` memory (three occurrence lists plus two arrays).
- **Return:** `best` stays `-1` if no candidate produced a finite end; otherwise the minimal length. Empty-match case (`p == "**"`) yields 0 because for `l` with all segments empty, `length = 0`.
- **Verified:** ex1 `"abaacbaecebce","ba*c*ce"` -> 8 (l=5); ex2 `"baccbaadbc","cc*baa*adb"` -> -1 (B at 4, C at 6, C cannot follow B); ex3 `"a","**"` -> 0; ex4 `"madlogic","*adlogi*"` -> 6 (l=1, B at 1).
- **Pitfalls confirmed safe:** non-overlap is enforced by requiring `nextB[p1] >= p1` and `nextC[p2] >= p2`; touching (gap 0) allowed; INF comparisons use `float('inf')` so `b == INF` works for any int `b`.
