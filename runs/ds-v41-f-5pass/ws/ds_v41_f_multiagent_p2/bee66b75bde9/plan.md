Represent any valid coloring by row cutoffs r_i and column cutoffs c_j, where cell (i,j) is black iff j <= r_i iff i <= c_j. Translate every already colored cell into lower/upper bounds on the corresponding row cutoff and column cutoff. The main difficulty is checking whether row and column cutoffs can be chosen consistently, especially since N is up to 10^9 and only M cells are constrained. Reduce the check to only O(M) relevant rows, columns, and boundary positions, then test feasibility with sorting/sweeping or interval propagation. After deriving the criterion, verify it against brute force for small N and then implement an O(M log M) Python solution.
