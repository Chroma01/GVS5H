- **Induced connected subgraphs:** Any connected subgraph of a tree must contain every original edge whose endpoints are both selected; otherwise that edge is the unique path between its endpoints and omitting it disconnects the subgraph. Thus the problem is equivalent to choosing a connected vertex set and taking all edges inside it.
- **Core reduction:** In an alkane, vertices of degree 4 form a connected core. If two degree-4 vertices were connected by a path containing a degree-1 vertex, that internal vertex would need degree at least 2, impossible. Hence all internal vertices on paths between degree-4 vertices are also degree-4.
- **Size formula:** If the core has F vertices, it has F-1 core edges. Each core vertex has total degree 4, so the number of attached leaves is 4F - 2(F-1) = 2F+2. Total vertices are F + (2F+2) = 3F+2. Maximizing the alkane size is therefore equivalent to maximizing the number F of core vertices.
- **Feasible core characterization:** A vertex can be in the core only if its original degree is at least 4. A set C of such vertices is a valid core iff it is connected and every vertex has at most 4 neighbors inside C. Sufficiency follows because each v in C has at least 4 - deg_C(v) neighbors outside C, and in a tree no outside vertex can be adjacent to two different vertices of a connected C, so enough distinct leaves can be attached.
- **DP state:** Root the tree arbitrarily. For each vertex v, dp[v] is the maximum size of a valid core contained in v's rooted subtree, containing v, and assuming v has a selected core parent. Then v may use at most 3 selected child branches, so dp[v] = 1 + sum of the best up to 3 child dp values.
- **Best answer:** If v is the highest selected core vertex, it has no selected parent and may use up to 4 child branches. The best core size is max over good vertices v of 1 + sum of the best up to 4 child dp values. Non-good vertices have dp 0 and cannot connect core branches.
- **Implementation details:** Use iterative DFS to avoid recursion depth. Maintain only the top four child dp values for each vertex in O(deg(v)) time. If no good vertex exists, best remains 0 and the answer is -1; otherwise the answer is 3*best + 2.
- **Complexity and edge cases:** Time and memory are O(N). A single good vertex gives best=1 and answer=5, corresponding to a star with four leaves. A non-good root does not break the DP because every connected core has a unique highest good vertex.
