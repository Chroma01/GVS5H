- **Core observation:** For any edge, at most one path can cross it because paths are vertex-disjoint and the graph is a tree. Therefore, for any component obtained by cutting an edge, its size modulo K is either 0 if no path crosses, or exactly the length (1..K-1) of the unfinished path segment inside that component.
- **Local condition:** For K > 1, remove a vertex v and look at all incident components. The path containing v uses either one incident component of remainder K-1 (v is an endpoint), or two incident components whose remainders sum to K-1 (v is internal). All other incident components must have remainder 0. This condition is necessary.
- **Sufficiency:** Build a graph H containing exactly the edges whose directed component remainder is nonzero. The local condition gives every vertex degree 1 or 2 in H, so H is a disjoint union of paths. Along an H path, let e_i be the remainder from vertex i to i+1. At an endpoint e_1 = K-1. At an internal vertex, the two directed remainders sum to K-1, and opposite directed remainders on the same edge sum to K, so (K - e_{i-1}) + e_i = K-1, hence e_i = e_{i-1} - 1. The other endpoint requires K - e_{L-1} = K-1, so e_{L-1}=1 and therefore L=K. Thus H partitions all vertices into paths of exactly K vertices.
- **Directed remainders from one root:** Let sub[v] be subtree size modulo K. For a child c of v, the component on c's side after removing v has remainder sub[c]. For the parent side, the component size is M - subtree_size[v], and since M = N*K is divisible by K, its remainder is 0 if sub[v] == 0, otherwise K - sub[v].
- **Implementation:** Use iterative DFS to avoid recursion depth issues. Accumulate subtree sizes modulo K bottom-up. Then scan every vertex's adjacency list, count nonzero incident remainders, and require either one remainder equal to K-1 or two remainders summing to K-1.
- **Edge cases:** K=1 is always Yes. K=2 makes the two-remainder case impossible because positive remainders cannot sum to 1, so the condition reduces to a perfect matching condition. K=M requires the whole tree to be a path, which the local condition detects. Leaves automatically pass because their only component has size M-1, congruent to K-1.
- **Complexity:** O(NK) time and O(NK) memory, within the 2e5 limit.
- **Pitfalls:** Do not rely only on the sum of nonzero remainders modulo K; the count must be exactly 1 or 2. Do not treat zero remainders as usable path edges. Compute the parent-side remainder as the complement of the subtree remainder, not as the subtree remainder itself.
