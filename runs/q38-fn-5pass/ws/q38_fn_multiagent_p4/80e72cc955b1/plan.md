Treat each integer independently: an element `x` must be selected exactly `f(x)` times, where `f(x)` is the number of times `x` can be divided by 4 before becoming zero. Since each operation consumes two selections and selecting a zero is harmless, the minimum operations for a query is `ceil(sum(f(x) for x in [l, r]) / 2)`. Compute this range sum efficiently with a prefix-sum helper over `f(x)`, grouping values by intervals where `f(x)` is constant. Then process all queries in linear time using the prefix helper.
