Exploit the small bound K ≤ 20 by using a banded edit-distance dynamic program: any successful conversion can deviate from the main diagonal by at most K. First reject immediately if the length difference exceeds K. Then scan aligned prefixes of S and T, keeping only edit costs for positions within K of the current index. The DP tracks insertions, deletions, and replacements with unit cost, and we stop early if no state can still be ≤ K or if the final prefixes have cost ≤ K. Complexity is O(|S| * K) time and O(K) memory, which is safe for lengths up to 500000.
