The problem requires answering many prefix-pair absolute-difference sums. Since N is 1e5 and K is 1e4, a direct O(XY) per query is too slow. We can split each query into full blocks and a partial block using sqrt decomposition on the A-array. For each full block, precompute its contribution to every distinct Y that appears in queries by sweeping over B and maintaining a running sum with binary search on the block's sorted A-values. For the partial block, process queries offline sorted by Y: sweep Y from 1 to N, maintaining a Fenwick tree over compressed B-values to answer sum |a - B_j| for any a in O(log N). This yields O((N^2/S) log S + K S log N) time, which is fast enough for the constraints.
