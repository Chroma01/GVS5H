- **Approach:** Split `p` into `left`, `middle`, and `right` around the two stars. A matching substring must contain these literals in order without overlap; stars fill gaps. Empty literals let the corresponding boundary be trimmed to the next required literal, and `p == "**"` gives `0`.
- **Occurrence finder:** KMP helper returns sorted start indices for a non-empty literal in `s` in `O(|s| + |literal|)`. Empty literals are not searched; literals longer than `s` yield no occurrences.
- **Early failure:** If any non-empty literal has no occurrence, return `-1`.
- **Middle empty:** If only one side literal remains, return its length if it occurs. If both `left` and `right` remain, sweep right starts and maintain the latest left occurrence with `left_end <= right_start`; candidate length is `right_end - left_start`.
- **Middle non-empty:** If both sides are empty, answer is middle length. Otherwise sweep middle starts. Maintain latest left occurrence ending at or before the middle start. Maintain earliest right occurrence starting at or after the middle end with a monotonic pointer. Candidate length is `right_end - left_start`, using middle boundaries when a side is empty.
- **Ordering rule:** Adjacent literals are allowed, so constraints are `previous_end <= next_start`. Overlapping literal occurrences are invalid because pattern parts consume characters sequentially.
- **Monotonicity:** Occurrence lists are sorted. Middle starts and thresholds increase, so the left and right pointers only move forward. If no right occurrence remains for a middle that already has a valid left, later middles cannot match either.
- **Edge cases:** Consecutive stars, stars at ends, `p == "**"`, empty side fragments, required fragment longer than `s`, overlapping same-string fragments, and no valid ordering.
- **Complexity:** KMP scans `s` at most three times and builds prefix arrays for the three literals. Sweeps are linear in occurrence counts. Time `O(|s| + |p|)`, memory `O(|s| + |p|)` worst case.
