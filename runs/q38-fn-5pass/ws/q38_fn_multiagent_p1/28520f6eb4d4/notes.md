- **Visibility reduction:** For a fixed observer height `y` and building `i`, aiming at the top `(X_i, H_i)` is always best: any lower point on building `i` gives a lower segment at every intermediate coordinate. Thus building `i` is visible iff the line from `(0, y)` to its top is strictly above every previous building top.
- **Threshold formula:** For `j < i`, strict non-intersection with building `j` gives `y > (H_j * X_i - H_i * X_j) / (X_i - X_j)`. Building `i` is visible iff `y` is strictly greater than the maximum of these thresholds over `j < i`. The answer is the maximum threshold over all `i` if it is non-negative; if all thresholds are negative, height `0` sees everything and the answer is `-1`. Equality blocks visibility, so a maximum threshold of `0` gives answer `0`.
- **Per-building optimization:** For current point `C = (x, h)`, the threshold with previous point `P` is the y-intercept of line `PC`. Since `intercept = h - slope(P, C) * x` and `x > 0`, maximizing the intercept is equivalent to minimizing the slope from `P` to `C`.
- **Upper hull sufficiency:** Only vertices of the upper convex hull of previous tops can minimize the slope to a point on the right. If a point lies below a hull segment `AB`, then for any `C` to the right its slope to `C` is at least the minimum of slopes from `A` and `B` to `C`. Collinear middle points can be removed because endpoints of a collinear chain are sufficient.
- **Hull maintenance:** Process points by increasing `x`. Maintain edge slopes strictly decreasing. When adding `C`, pop the last hull point `B` while `slope(A, B) <= slope(B, C)`, using exact cross multiplication: `(hB - hA) * (xC - xB) <= (hC - hB) * (xB - xA)`. This also removes collinear points.
- **Tangent binary search:** For hull vertices `P_k` and current `C`, `f_k = slope(P_k, C)` is unimodal. With strictly decreasing edge slopes `e_k`, the predicate `f_k <= f_{k+1}` is monotone false-then-true. It is equivalent to `e_k <= f_{k+1}`, checked exactly as `edy[k] * (x - xs[k+1]) <= (h - hs[k+1]) * edx[k]`. Binary search the first true predicate; if none exists, the last vertex is optimal.
- **Exact rational maximum:** Store the best threshold as numerator and denominator. Compare candidates by cross multiplication to avoid precision issues. Products are at most about `1e18` for geometry and about `1e27` for best-rational comparison, safely handled by Python integers.
- **Complexity:** `O(N log N)` time due to binary searches on the hull, `O(N)` memory. Total hull pops are `O(N)`.
