Model each edge of the toroidal grid by a binary variable indicating whether a segment endpoint is present. For an A cell the two horizontal edge variables must differ and the two vertical edge variables must differ; for a B cell the two horizontal variables are equal, the two vertical variables are equal, and the common horizontal value must differ from the common vertical value. This implies each row and each column must contain an even number of A cells, otherwise no assignment exists. When these parity conditions hold, choose one free horizontal variable per row and one free vertical variable per column; every B cell then gives a XOR equation between its row variable and column variable. Count consistent assignments of these equations with a parity DSU: if consistent, the answer is 2^(number of connected components among all row/column variables) modulo 998244353.
