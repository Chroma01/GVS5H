- **Problem reduction:** Count all monotone (right/up) lattice paths on valid blocks, including length-zero paths, where valid = grid [0,W]x[0,H] minus forbidden box F=[L,R]x[D,U]. Answer = sum over valid end cells t of g(t) = number of valid paths ending at t.
- **Full-grid DP closed form:** In the unobstructed grid, paths ending at t=(x,y) from any start s<=t number `f_full(x,y) = C(x+y+2, x+1) - 1` (from hockey-stick sum of C(i+j,i)). This is verified by the recurrence f = 1 + f(left) + f(down).
- **Complementary counting:** Answer = sum_{t valid} f_full(t) - sum_{t valid} corr(t), where corr(t) counts full-grid paths ending at valid t that touch F. Decompose each bad path by its first F-cell c: corr(t)=sum_{c in F, c<=t} H(c)*C(t-c), with H(c)=# prefixes ending at c whose first F-cell is c.
- **H(c) structure:** H(c)=1 + [x==L,L>=1]*f_full(L-1,y) + [y==D,D>=1]*f_full(x,D-1). Interior F-cells (x>L,y>D) have H=1. Boundary strip values equal f_full because a path to (L-1,y) never has x>=L, and to (x,D-1) never has y>=D.
- **Key sums:** sum_{t valid} corr(t) = sum_{c in F} H(c)*W(c), where W(c) = sum_{t valid,t>=c} C(t-c) = S(c)-R(c), with S(c)=C((W-x)+(H-y)+2, W-x+1)-1 and R(c)=C((R-x)+(U-y)+2, R-x+1)-1.
- **Rectangle binomial prefix:** Pprefix(X,Y)=sum_{x=0..X}sum_{y=0..Y}C(x+y+2,x+1) = C(X+Y+4, X+2) - X - Y - 4 (returns 0 if X<0 or Y<0). Used for whole-grid sum, F-sum, sum_F W, and all four transition terms.
- **Formula summary:** Answer = [Pprefix(W,H)-(W+1)(H+1)] - [Pf - areaF] - [sumF_W + Term2 + Term3], where Pf is the inclusion-exclusion of Pprefix over F, areaF=(R-L+1)(U-D+1), Term2=[L>=1]*sum_{y=D..U} f_full(L-1,y)*W(L,y), Term3=[D>=1]*sum_{x=L..R} f_full(x,D-1)*W(x,D).
- **Efficiency:** Precompute factorials/inverse factorials/inverses to W+H+4. Term2 and Term3 loops run O(U-D) and O(R-L); binomials inside are updated incrementally in O(1) per step using ratio identities C(n+1,k)=C(n,k)(n+1)/(n+1-k), C(n-1,k)=C(n,k)(n-k)/n, C(n-1,k-1)=C(n,k)k/n. Total O(W+H).
- **Edge cases handled:** L=0 or D=0 disables the corresponding entry term and makes Pprefix(-1,*) zero; R=W or U=H makes the shifted terms vanish. Verified by hand on sample 1 (192) and several tiny grids including corner holes (e.g. W=1,H=0,L=R=D=U=0 -> 1; W=2,H=0 hole at x=1 -> 2; W=2,H=2 center hole -> 28).
