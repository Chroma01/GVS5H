The graph is always bipartite, and the game ends when the graph is a connected complete bipartite graph. For odd `N`, the final number of edges is always even, so the winner is determined only by the parity of `M`. For even `N`, classify connected components by whether their vertex count is odd; let `k` be the number of odd-sized components. If `k = 0`, the final bipartition parity is fixed, so use the parity of the total number of missing internal edges `sum(a_i*b_i - m_i)`. If `k = 2`, the first player can always force a win; if `k >= 4`, the winner is again determined by the parity of `M`.
