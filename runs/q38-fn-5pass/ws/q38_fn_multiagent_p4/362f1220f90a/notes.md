- **Validation:** Sample tests pass: `TFTF/ab -> ababa`, `TFTF/abc -> ""`, `F/d -> a`. Additional edge cases checked: `m=1` with T/F combinations, all T, all F, overlapping T conflicts, fully fixed F windows equal to `str2`, periodic `str2` such as `aa`/`aaa`, and cases where greedy choice needs DP lookahead. No failing cases found.
- **Fallback choice:** The previous highly optimized shortcut DP was replaced by a simpler bitset DP with only sparse preimage optimization. This keeps the same asymptotic behavior but is easier to reason about and less prone to subtle inverse-mask errors.
- **T propagation:** Every `T` start writes `str2` into a fixed array of length `L = n + m - 1`. Any conflicting fixed character immediately returns `""`. If there is no `F`, the unique consistent fixed word is returned.
- **KMP automaton:** States are normalized prefix-match lengths `0..m-1`. After a full match, the state is normalized to `pi[m-1]`. A forbidden match at an `F` end occurs exactly when the current state is `m-1` and the chosen character is `str2[-1]`.
- **DP state:** `feas[pos]` is an `m`-bit mask. Bit `q` means positions `pos..L-1` can be completed if the KMP state before `pos` is `q`. Base `feas[L]` is all states feasible.
- **DP transitions:** For fixed positions, keep states whose deterministic transition lands in `feas[pos+1]`, excluding state `m-1` if the fixed character would complete `str2` at an F end. For free positions, keep states that can reach at least one feasible next state, using nonmatching transitions at F ends.
- **Bitset optimizations:** Full-mask future sets are handled in O(1). Sparse feasible sets use preimage masks to avoid scanning all states. Dense non-full sets scan all states. This keeps worst-case practical: `L <= 10499`, `m <= 500`.
- **Reconstruction:** Starting from state `0`, choose the smallest character that is allowed at the current position and leads to a state marked feasible by `feas[pos+1]`. Fixed positions must use their forced character.
- **Complexity:** T propagation is `O(nm)` worst case. DP is `O(L*m)` worst case with bitset shortcuts reducing common sparse/dense cases. Reconstruction is `O(26L)`. Memory is `O(L*m/word + 26m)` in Python integer bitsets.
