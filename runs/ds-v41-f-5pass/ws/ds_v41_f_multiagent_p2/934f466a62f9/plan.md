The key reduction is to view each pair's price as choosing one of three coordinates and assigning both cakes to that coordinate. This transforms the problem into selecting 2K cakes and assigning each to one of X, Y, Z such that the number of cakes assigned to each coordinate is even, maximizing the sum of assigned coordinate values. This maximum is exactly the answer. We can solve this selection problem using Lagrangian relaxation (Aliens trick) on the number of selected cakes. For a fixed penalty λ per selected cake, we can compute the optimal even-assignment via a simple DP over the 8 parity states of the three coordinates. By binary searching λ, we find the value where the optimal number of selected cakes equals 2K, then reconstruct the answer.
