- **Core invariant:** For the sorted unique query initial ratings, the current ratings stay nondecreasing. For any contest, the compressed indices whose current rating lies in `[L, R]` form one contiguous interval.
- **Chosen structure:** Forward query-only iterative lazy segment tree. Leaves store current rating for each unique query initial rating. Internal nodes store segment maximum; lazy array stores pending range additions. Padding leaves use a very negative value so they never match a threshold.
- **Boundary search:** `find_first_ge(t)` returns the first compressed index with value at least `t`. It checks the root maximum, then descends from the root. Before inspecting children it pushes the current node's lazy tag. If the left child maximum is at least `t` it goes left, otherwise right. If no value reaches `t` it returns `M`.
- **Range update:** For contest `[L, R]`, left is `first_ge(L)` and right is `first_ge(R + 1)`. If left < right, add 1 to `[left, right)`. The iterative range add pushes ancestors of both boundaries, applies +1 to covered nodes, and recomputes ancestors from child maxima. The push phase guarantees recomputed nodes have no pending tag.
- **Monotonicity proof:** If a left outside value is `< L`, it remains at most `L-1` while the first updated value becomes at least `L+1`. If a right outside value is `> R`, it is at least `R+1` while the last updated value becomes at most `R+1`. Adding a constant inside the interval preserves order, so the array remains sorted.
- **Complexity:** With `M` unique queries, build is `O(M)`. Each contest does two `O(log M)` searches and at most one `O(log M)` range add. Final propagation is `O(size)`. Total `O((N + Q) log Q + Q)`, memory `O(N + Q)`.
- **Implementation details:** Contests are stored because queries appear after them. Queries are compressed with `sorted(set(queries))`. The lazy array is allocated with length `2 * size` so push code can update child lazy entries without bounds checks. After all contests, lazy tags are pushed top-down to leaves, a dictionary maps each initial rating to its final rating, and answers are printed in original order.
- **Edge cases:** `M=1` gives `size=1` and `log=0`; the loops degenerate correctly. Empty affected ranges occur when left == right. All values below `L` are skipped by the root maximum check; all values above `R` give right == left. Final ratings can exceed `5e5` but Python integers handle them.
- **Performance notes:** The hot push code is inlined in search, range add, and final propagation to avoid millions of helper function calls. Alignment masks are precomputed for iterative lazy propagation. Default arguments bind the large arrays locally inside nested functions. The main loop uses the root maximum to skip searches when no value can enter the interval, and `range_add` has a full-tree shortcut when the compressed domain is a power of two.
