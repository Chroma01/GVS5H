Model the final value as A_{i,j} xor r_i xor c_j, where r_i encodes whether row i is flipped and c encodes the flipped columns. For a fixed column mask c, each row independently chooses r_i to minimize its number of ones, contributing min(popcount(row_i xor c), W - popcount(row_i xor c)). Because W ≤ 18, compress identical row patterns into a frequency array over 2^W masks, then compute the sum over all rows for every c via XOR convolution. The answer is the minimum over all column masks c. This avoids O(H·2^W) and fits the constraints.
