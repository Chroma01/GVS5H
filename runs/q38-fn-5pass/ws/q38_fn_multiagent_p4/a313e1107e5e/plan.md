Compute `dp[i]`, the length of the longest strictly increasing subsequence ending at position `i` using only elements before `i`. For a query `(R, X)`, the answer is the maximum `dp[i]` over all `i <= R` with `A_i <= X`, because any valid subsequence ending at such an `i` automatically uses only values `<= X`. Compute all `dp[i]` online with a Fenwick tree over compressed values, storing maximum `dp` for smaller values. Then answer all queries offline by sorting them by `R` and maintaining a second Fenwick tree over values containing `dp[i]` for processed positions. This gives an `O((N + Q) log N)` solution.
