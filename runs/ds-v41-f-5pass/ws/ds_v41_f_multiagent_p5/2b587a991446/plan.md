The problem reduces to determining if two tokens can swap positions on a connected undirected graph without ever occupying the same vertex. Swapping is impossible on a tree, so if M = N-1 output -1. Otherwise, the minimum moves can be found by analyzing shortest paths and cycles: the optimal sequence uses a cycle to let the tokens pass each other. We can compute shortest distances from S and T via BFS, then find the shortest cycle that can be used for the swap (or the distance to the nearest cycle) and combine these distances to get the exact minimum. The overall solution runs in O(N+M) time.
