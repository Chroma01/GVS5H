- **Problem reduction:** The sum of all in-degrees equals the number of undirected edges, `N + popcount(s)`. Therefore `d_N` is forced by the prefix `(d_0,...,d_{N-1})`. It is enough to count feasible prefixes.
- **Cycle orientation encoding:** Let `a_i = 1` mean the cycle edge `i -> i+1` (mod `N`). The cycle contribution to vertex `i` is `a_{i-1} + 1 - a_i`, with values `0,1,2` for pairs `(0,1),(0,0)/(1,1),(1,0)`. If `s_i=0`, `d_i` equals this contribution. If `s_i=1`, the spoke may add `0` or `1`, so `d_i` is that contribution or plus one.
- **Local relations:** For `s=0`: `d=0 -> {(0,1)}`, `d=1 -> {(0,0),(1,1)}`, `d=2 -> {(1,0)}`. For `s=1`: `d=0 -> {(0,1)}`, `d=1 -> {(0,1),(0,0),(1,1)}`, `d=2 -> {(0,0),(1,1),(1,0)}`, `d=3 -> {(1,0)}`.
- **DFA view:** A prefix is feasible iff the composition of these binary relations contains a diagonal pair `(0,0)` or `(1,1)`, corresponding to the same closing cycle-edge orientation. Start with the identity relation. Acceptance is diagonal membership. Different degree values that induce the same next relation are counted with multiplicity, so distinct degree sequences are counted, not orientations.
- **State representation:** A relation on `{0,1}` is a 4-bit mask. It is split into two row subsets: `u = mask & 3` and `v = (mask >> 2) & 3`. For each local relation, a row table maps a subset `S` of possible previous values to the subset of possible next values. The next state is `table[u] | (table[v] << 2)`. Tables are generated from the relation masks to avoid manual composition errors.
- **Pruning:** The empty relation is dead; transitions to it are discarded. Reachable nonempty states from the identity are 12, and the DP runs only on these states.
- **Performance:** `N` is up to `10^6`. A generic sparse 12-state DP is conceptually simple but can be tight in Python. The program builds reduced transition matrices and generates an unrolled `run` function with local variables for the 12 DP entries. Each input character executes one branch and 12 modular assignments. A generic fallback is included if `exec` fails.
- **Center-degree consistency:** For any realized prefix, the sum of cycle contributions is always `N`. If `K = popcount(s)` and `b_i` is the spoke contribution to vertex `i`, then `sum(prefix) = N + sum(b_i)`. The center indegree is `K - sum(b_i) = N + K - sum(prefix)`, exactly the forced value.
- **Pitfalls checked:** Do not count orientations directly; use multiplicities for different `d_i` values leading to the same DFA transition. Do not accept merely nonempty relations; diagonal membership is required. Dropping empty transitions is safe because empty cannot become nonempty. Modulo is applied after each position. Sample 1 traces to 14.
