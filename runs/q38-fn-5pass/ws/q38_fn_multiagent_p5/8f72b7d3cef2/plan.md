Use a max Cartesian tree (with any consistent tie-breaking for equal sizes) so that each node represents a contiguous segment in which it is a maximum. For every node, compute its segment sum and decide whether starting at that node can absorb its whole segment: this is true for a leaf, and otherwise true iff at least one immediate neighbor inside the segment is strictly smaller. For an edge from a child segment to its parent, any slime that has already absorbed the whole child segment can absorb the parent and then the sibling segment exactly when the child segment sum is strictly greater than the parent’s size. Mark such edges as passable; a node that can absorb its own segment can climb only through consecutive passable edges, and its final size is the sum of the topmost reachable ancestor. Otherwise it cannot make a first move within its segment and its answer is its own size.
