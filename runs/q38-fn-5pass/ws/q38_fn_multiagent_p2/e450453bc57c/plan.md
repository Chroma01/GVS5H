Reduce the problem to selecting exactly k non-overlapping windows of length x, because making extra windows equal only adds nonnegative cost. For each length-x window, compute the minimum operations to make all its elements equal, which is the sum of absolute deviations to a median of that window. Compute all window costs efficiently with a sliding median structure, then use dynamic programming over prefixes to choose k non-overlapping windows with minimum total cost. The DP transition either skips the current position or takes a window ending at the current position, using the cost of that window plus the best solution for the prefix before it.
