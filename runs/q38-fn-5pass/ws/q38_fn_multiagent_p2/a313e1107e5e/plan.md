Process the queries offline in increasing order of `R`, maintaining the standard LIS “tails” array for the prefix `A[1..R]`. For each new element `A_i`, update the tails array using `bisect_left` to preserve the minimum possible ending value for each increasing subsequence length. For a query `(R, X)`, the answer is the number of tails values `<= X`, obtained with `bisect_right`, because a length `L` LIS with all elements `<= X` exists iff the minimum possible tail for length `L` is `<= X`. Finally, output answers in the original query order.
