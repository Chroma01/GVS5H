- **Core reduction:** The XOR of any chosen K elements equals total_xor XOR the XOR of the excluded N-K elements. Let M = min(K, N-K). If K <= N-K, maximize subset_xor directly; otherwise maximize total_xor XOR subset_xor over excluded M-subsets. This can be written uniformly as maximizing mask XOR subset_xor, where mask is 0 in the direct case and total_xor in the complement case.
- **Bound on M:** The guarantee C(N, K) <= 10^6 also gives C(N, M) <= 10^6. Since M <= N/2, M is very small in all feasible large-N cases; in fact M is at most 11. When M is larger, N is small enough that exhaustive combination enumeration is safe.
- **Enumeration strategy:** Use recursive combination generation over indices, carrying the current XOR incrementally. The loop upper bound is n - rem + 1, ensuring enough remaining elements are available. This visits only partial combinations up to the chosen size and does not store combinations.
- **Base cases:** To reduce Python function-call overhead, the recursion stops at rem == 1, rem == 2, and rem == 3, updating the answer with direct loops. This is especially useful for the worst small-N cases such as M around 10 or 11.
- **Special cases:** M == 1 is handled by a single loop, using max(arr) when mask == 0. M == 2 is handled by nested loops. These cover the cases where N can be largest, such as N up to about 200000 for M == 1 and about 1414 for M == 2.
- **Performance:** The number of leaves is at most 10^6. With the base cases, the number of recursive calls is well below a few million, and the inner loops perform simple integer XOR and comparison operations. Memory usage is dominated by the input array.
- **Edge cases:** K == N gives M == 0 and the answer is total_xor. K == N-1 uses M == 1 with mask == total_xor. Duplicate values are allowed, but enumeration is by index, so distinctness is respected. XOR values are non-negative, so initializing ans to 0 is safe.
- **Input/output:** Read all tokens with sys.stdin.buffer.read().split(), compute total_xor while parsing, and write the answer with sys.stdout.write.
