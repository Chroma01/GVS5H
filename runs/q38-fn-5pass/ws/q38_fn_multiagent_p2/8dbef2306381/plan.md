Model reachability as a boolean DP over squares: square 1 is reachable, bad squares are unreachable, and a good square x is reachable if any square x-i with A <= i <= B is reachable. Because B <= 20, maintain the last B DP values as a bitmask and process maximal good/bad runs instead of iterating up to N. Handle A = B separately: the path is forced to squares congruent to 1 modulo A, so check N and all bad intervals for those required squares. For A < B, the jump lengths have gcd 1; precompute a small threshold T such that every distance at least T is representable as a sum of allowed jumps, then accelerate long good runs by setting the mask to all ones if any reachable bit can enter, and clear the mask for bad runs of length at least B. Process the runs from square 2 to N and answer from the bit representing square N.
