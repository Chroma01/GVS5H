- **Core reduction:** For a subarray, only the set S of distinct values matters. One operation can erase exactly one interval of values fully contained in S, so the minimum number of operations is the number of contiguous components of S. For any subset of integers, components = |S| minus the number of adjacent pairs (v, v+1) that are both present.
- **Right-endpoint sweep:** Sweep r from 1 to N. Let last[v] be the last occurrence of v up to r. For fixed r, value v appears in A[L..r] for exactly last[v] choices of L. Adjacent pair (v, v+1) both appears for exactly min(last[v], last[v+1]) choices of L. Therefore the sum of f(L,r) over all L is sum_v last[v] - sum_v min(last[v], last[v+1]). Add this current value to the answer at each r.
- **Update rule:** When processing A[r]=x, only last[x] changes, from old value p to r. The first aggregate increases by r-p. The second aggregate only changes for pairs (x-1,x) and (x,x+1). For the left pair, the new minimum is last[x-1] because r is larger than any previous occurrence; the delta is last[x-1] - min(last[x-1], p), which is last[x-1]-p if last[x-1] >= p, otherwise 0. The right pair is symmetric. Use sentinels last[0]=last[N+1]=0 so boundary values need no special cases.
- **Implementation details:** Use fast input with sys.stdin.buffer.read().split(). Store last occurrences in a list of size N+2. Python integers safely handle the large answer. The algorithm is O(N) time and O(N) memory.
- **Validator:** A small brute force maintains the present set for each left endpoint and updates the component count when adding a new value x by delta = 1 - (x-1 present) - (x+1 present). It compares this against solve_array on random small arrays and deterministic edge cases. The validator is only run when the program is invoked with the argument --validate; normal judge execution reads stdin and prints the answer.
- **Edge cases covered:** N=1, all values equal, strictly increasing or decreasing values, x=1, x=N, repeated values, and values whose neighbors have last occurrences before or after the previous occurrence of x.
