Extract the positions of all 1s in the string, preserving their left-to-right order. Since swaps only change positions and the relative order of 1s never needs to change, the problem reduces to moving these positions into a block of consecutive indices. For k ones at positions p_1..p_k, choosing a contiguous target block is equivalent to choosing a start x so that the total movement is minimized. Transform each position to q_j = p_j - j, because this removes the required consecutive spacing; then the optimal start is determined by the median of these q values. Compute the sum of absolute deviations from that median, using efficient selection or sorting, and output it.
