Reduce the operation sequence to an optimal strategy: process values from largest to smallest, moving each value k rightward to its final position without disturbing already-fixed larger values. For each k, its cost depends on its rank among values <= k in the original permutation, giving an arithmetic-series contribution. Compute these ranks efficiently with a Fenwick tree over original positions while iterating values in increasing order. Sum all contributions using 64-bit arithmetic for N up to 2e5.
