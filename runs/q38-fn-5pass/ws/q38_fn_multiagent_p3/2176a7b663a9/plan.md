Use the interval-order view: edges join disjoint intervals, and all vertices with at least one edge lie in one connected component; vertices intersecting every interval are isolated and can only answer -1. Because weights are positive, a shortest path is induced; the disjointness graph of intervals has no induced path with more than three edges, so only paths of length 1, 2, or 3 need be considered. For disjoint endpoints the direct edge is optimal; for intersecting endpoints, any same-side 3-edge path is dominated by a 2-edge path, leaving only a common neighbor or two cross-side intermediates. Precompute minimum weights of intervals lying strictly left or right of each coordinate, then answer each query in O(1) from endpoint sums, common-neighbor minimum, and two cross sums.
