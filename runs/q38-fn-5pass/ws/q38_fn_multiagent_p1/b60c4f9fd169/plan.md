The task is to decide whether the edit distance between two very long strings is at most K, where K is small (≤20). A full O(|S||T|) dynamic programming table is impossible, but only cells within K diagonals of the main diagonal can affect the answer, so a banded edit-distance DP is sufficient. We can maintain only the current and previous rows restricted to the relevant diagonal band, or equivalently use a diagonal-based DP, updating states in O(K) per character of the shorter string. If the length difference exceeds K, the answer is immediately No. The final answer is Yes if any reachable state at the end has cost ≤K.
