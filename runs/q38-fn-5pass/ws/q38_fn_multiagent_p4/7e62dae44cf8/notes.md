- **Core model:** The absorbed cells always form one connected region containing the start cell, and Takahashi's strength is the sum of strengths in that region. A cell outside the region can be absorbed iff it is adjacent to the region and `s * X < total`.
- **Greedy correctness:** Absorbing any currently absorbable cell only increases total strength and can only add new boundary cells; it never makes an existing boundary cell harder to absorb. Therefore the process is monotone. If the weakest boundary cell is not absorbable, every boundary cell is not absorbable, so no further action is possible. The min-heap greedy expansion reaches the closure of all cells that can be absorbed in any valid order. For any valid sequence, after greedy has absorbed a superset of the sequence prefix, the next sequence cell is boundary and its condition still holds because greedy's total is at least as large; greedy cannot stop while that cell is absorbable. Hence greedy's final total is maximal.
- **Implementation:** Use a flat array `S` of length `H*W`. `state` is a bytearray: 0 unseen/not in heap, 1 currently in heap, 2 absorbed. Start is absorbed. Push its neighbors into a heap as `(strength, index)`. When popping, skip entries whose state is not 1. If `s * X >= total`, break. Otherwise mark absorbed, add `s` to total, and push each neighbor with state 0, marking it 1. Marking on push avoids duplicate heap entries; a boundary cell remains boundary until absorbed.
- **Complexity:** Each cell is pushed at most once and popped at most once, so time is O(HW log HW) and memory O(HW), within limits for 250000 cells.
- **Pitfalls:** Use exact integer comparison `s * X < total`; never use floating division. The inequality is strict. Python integers safely handle `s * X` up to 1e21. If using mark-on-push, distinguish in-heap from absorbed states; otherwise stale duplicates must be skipped.
