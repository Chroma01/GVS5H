Only numbers ≤ threshold can have any edge, because lcm(a,b) ≥ max(a,b); numbers > threshold are isolated singletons. For values ≤ threshold, lcm(a,b) ≤ T is equivalent to a and b both dividing some integer m ≤ T. Build a DSU over auxiliary nodes 1..T and union each present value x with every multiple of x up to T. This connects exactly the present values that share a common multiple ≤ T, hence have lcm ≤ T. Finally, count distinct DSU roots among present values ≤ T and add one component for each value > T.
