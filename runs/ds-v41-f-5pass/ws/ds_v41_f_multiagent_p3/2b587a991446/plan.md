Model each configuration as an ordered pair (position of A, position of B) with distinct vertices, and the answer as the shortest path in this configuration graph from (S,T) to (T,S). A direct BFS over all N^2 pairs is too large, so the key is to find a structural reduction or optimized shortest-path formulation using the original graph and the constraint that the pieces cannot occupy the same vertex. We will first characterize reachability and derive conditions under which swapping is impossible, then design an efficient algorithm based on distances in the original graph or a small auxiliary state graph. Finally, we will validate the derived formula/algorithm against edge cases such as N=2, articulation points, and graphs where S and T are close.
