Count triplets by fixing the middle element B and counting pairs {A,C} in S with A+C=2B and A<B<C. Represent S as a binary indicator array over values 0..max(S). Compute the convolution of this indicator array with itself to obtain, for every possible sum s, the number of ordered pairs (a,c) in S with a+c=s. For each B in S, the number of valid unordered pairs {A,C} is (conv[2B] - 1) // 2: subtract the (B,B) pair and divide by 2 because convolution counts both (A,C) and (C,A). Sum this contribution over all B in S and print the total.
