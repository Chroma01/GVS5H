- **Model:** Let `h[i][j]` be whether an endpoint exists on the left edge of cell `(i,j)` (equivalently the right edge of the previous cell), and `v[i][j]` be whether an endpoint exists on the top edge of cell `(i,j)`. For an A tile, horizontal edge indicators differ and vertical edge indicators differ: `h[i][j] xor h[i][j+1] = 1`, `v[i][j] xor v[i+1][j] = 1`. For a B tile, horizontal indicators are equal, vertical indicators are equal, and the two common values differ: `h[i][j] = h[i][j+1]`, `v[i][j] = v[i+1][j]`, `h[i][j] xor v[i][j] = 1`.
- **Parity conditions:** XORing the horizontal constraints around a row shows every row must contain an even number of A cells. XORing vertical constraints around a column shows every column must contain an even number of A cells. If either fails, the answer is 0.
- **Reduced variables:** When row/column parities hold, all horizontal edge variables in row `i` are determined by one free bit `r_i` and the row prefix parity of A cells to the left: `h[i][j] = r_i xor row_pref[i][j]`. Similarly, all vertical edge variables in column `j` are determined by one free bit `c_j` and the column prefix parity of A cells above: `v[i][j] = c_j xor col_pref[i][j]`.
- **B-cell equations:** For each B cell, the cross condition gives one XOR equation between a row variable and a column variable: `r_i xor c_j = 1 xor row_pref[i][j] xor col_pref[i][j]`. A cells impose no equation between row and column variables.
- **Counting:** Build a parity DSU on `H + W` nodes (rows and columns). Each B cell is an XOR edge with the label above. If any cycle is inconsistent, answer 0. Otherwise each connected component of this bipartite XOR graph contributes one free bit, including isolated row/column nodes, so the answer is `2^(number of DSU components) mod 998244353`.
- **Implementation:** Process the grid once. Maintain `col_pref[j]` as the parity of A cells above the current row. For each row, maintain `row_pref` as the parity of A cells to the left. For a B cell, compute `label = 1 ^ row_pref ^ col_pref[j]` and union row node `i` with column node `H+j`. After finishing a row, if `row_pref != 0`, mark invalid and skip remaining row tokens. After all rows, if any `col_pref[j] != 0`, mark invalid.
- **DSU details:** `parity[x]` stores the XOR from `x` to its parent. `find` returns the root and compresses the path, leaving `parity[x]` as XOR to the root. Union by rank is used. For an equation `val[a] xor val[b] = label`, if roots differ, attach one root to the other with root parity `label xor parity[a] xor parity[b]`. If roots are the same, consistency requires `parity[a] xor parity[b] == label`.
- **Pitfalls:** Prefixes must be taken before the current cell; for a B cell the current cell does not change them, but A cells must update prefixes after their position. Isolated variables still count as components. Row/column parity alone is not sufficient; B-equation cycles can still be inconsistent. Torus wrap-around is exactly what forces the row/column parity checks. Use iterative find to avoid recursion depth issues. When invalid, skip remaining row tokens correctly by advancing the input index.
- **Complexity:** `O(HW alpha(H+W))` per test case, with total `HW <= 10^6`. Memory is `O(H+W)` per test case plus input tokens.
