- **Approach:** Because `target.length <= 4`, use bitmask DP over satisfied target entries. For each subset mask, precompute the LCM of the corresponding target values. For a current `nums` value `x`, `cost[mask] = (-x) % lcm[mask]` is the minimum increments needed to make `x` a multiple of every target in that mask.
- **DP state:** `dp[mask]` is the minimum total increment cost after processing a prefix of `nums` such that all target entries represented by `mask` are already satisfied. Initially `dp[0] = 0` and all other states are infinite.
- **Transition:** For each `x`, start with `ndp = dp[:]` to represent skipping `x`. From each reachable mask, choose a nonempty submask of currently uncovered targets and assign `x` to satisfy that submask: `ndp[mask | sub] = min(ndp[mask | sub], dp[mask] + cost[sub])`. Replacing `dp` with `ndp` ensures each `nums` element is used at most once.
- **Submask restriction:** It is sufficient to assign an element only to currently uncovered targets. If a target is already covered, adding it to the subset replaces the LCM by a multiple, so the nearest multiple cannot become closer. Thus covering an already satisfied target with the same element never reduces cost.
- **Correctness:** Any valid plan can be viewed as assigning each incremented element to the set of target entries it satisfies. The cheapest way for an element to satisfy a set is the nearest multiple of that set's LCM. The DP considers skipping or assigning each element to any subset of still-uncovered targets, so it can reproduce an optimal assignment. Conversely, every transition corresponds to a valid increment plan, so the final full-mask value is attainable and minimal.
- **Complexity:** With `m = len(target) <= 4`, there are at most 16 masks and `3^m - 2^m <= 65` transitions per element. Time is `O(n * 3^m)` and memory is `O(2^m)`, easily within the constraints.
- **Large values:** The LCM of up to four values each at most `10^4` is at most about `10^16`, safely handled by Python integers. `INF = 10**30` is far above the guaranteed optimal upper bound of at most `sum(target[i] - 1) <= 39996`, obtained by assigning distinct `nums` elements to each target.
- **Edge cases:** Target value `1` has zero cost for any element. Duplicate target values can be satisfied together because their LCM is unchanged. Already satisfied targets produce zero-cost transitions. Early return on `dp[full] == 0` is safe because all costs are nonnegative.
