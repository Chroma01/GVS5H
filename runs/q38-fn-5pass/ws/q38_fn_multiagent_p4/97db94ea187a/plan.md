Count graphs by their exact BFS layer sizes from vertex 1. For a fixed ordered layer-size sequence starting with layer size 1, label assignments contribute \((N-1)!/\prod a_i!\), within-layer edges contribute \((1+x)^{\binom{a_i}{2}}\), and edges from a previous layer of size \(p\) to a new layer of size \(a\) contribute \(((1+x)^p-1)^a\) by inclusion-exclusion, since every new-layer vertex needs at least one neighbor in the previous layer. The desired answer is the coefficient polynomial summed over alternating layer sequences whose total even and odd vertex counts are both \(N/2\). To avoid polynomial convolutions, evaluate this DP at \(x=0,1,\dots,E\) modulo \(P\), where each transition is only a scalar factor, then interpolate the coefficients from these values. Output coefficients for \(M=N-1,\dots,E\).
