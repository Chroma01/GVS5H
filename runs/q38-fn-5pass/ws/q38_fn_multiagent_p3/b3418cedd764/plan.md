Model the constraints as a functional graph with edges `i -> A_i`; every directed cycle forces all its nodes to have the same value, while nodes feeding into a cycle form rooted trees where each child value is at most its parent value. For each node `u`, compute `f_u[v]`, the number of valid assignments in the non-cycle subtree rooted at `u` when `x_u = v`, using the recurrence `f_u[v] = product over children c of sum_{t=1..v} f_c[t]`. Identify cycle nodes by indegree pruning, process non-cycle nodes in removal order so children are computed before parents, and store prefix sums of each `f_u`. For each cycle, choose a common value `v`, multiply `f_u[v]` over all cycle nodes `u`, sum over `v = 1..M`, and multiply results across connected components. The total complexity is `O(NM)`, which fits `N, M <= 2025`.
