- **Problem model:** minimum ops = min over multiset permutations S of (runs(S) + inv(A,S)). Swaps commute with deletions, so pay only the minimal adjacent swaps. Answer = m - G, where m is the initial number of runs and G is the maximum number of Type2 moves.
- **Moves on runs:** a Type2 move is an alternating window b a b a whose two middle runs have length 1; it removes 2 runs and costs 1 swap, net saving 1. A Type1 move is X Y X with the last two runs length 1; it removes 1 run and costs 1 swap, net 0, but can enable Type2. Only Type2 changes the answer.
- **Stack algorithm (implemented):** process runs left to right, merging equal adjacent values. After each push, loop: (a) apply any Type2 on the top 4 runs; (b) otherwise, for top 3 runs [v1,v2,v3] with v1==v3 and l2==l3==1, skip Type1 if the next input run n1 equals v2 (top4 becomes a Type2), or if n1 != v3 and the runs two/three ahead satisfy n2==v3, n3==n1 with n1,n2 singleton (top run becomes w1 of an upcoming Type2); else apply Type1. Answer = m - Type2 count.
- **Why Type1 is needed:** [1,2,1,3,2,3] requires Type1 on the leading [1,2,1] so the 2 becomes adjacent to the following 3, enabling Type2 [2,3,2,3]; total answer 5. Contrast [1,2,1,3,1,3] where the same Type1 would destroy the needed 1, so the heuristic correctly skips it.
- **Decisive differential stress test:** executed against an exact brute-force oracle. (a) all value-sequences over alphabet {1,2,3} with n=10 and n=11, including random run-lengths in {1,2,3}; (b) 100000 random sequences over {1,2,3,4} with n<=14 and random run-lengths; (c) adversarial patterns (long alternating with injected blocking values, patterns needing longer lookahead). **Zero mismatches** were found. The heuristic is therefore considered exact for the constraints.
- **Verification:** all three samples pass (3, 4, 8); [1,2,1,3,1,3] -> 5; [1,2,1,3,2,3] -> 5; [1,2,1,3,1,3,2,3] -> 7. Alternating n -> n - floor((n-1)/3) matching the sample for n=11.
- **Implementation:** read all input with sys.stdin.buffer.read().split(); compress to runs; stack simulation is O(sum N). T up to 1e5, sum N up to 2e5, one output line per case.
- **Disproven earlier attempts:** plain depth-1 stack heuristic (fails [1,2,1,3,1,3]); Type2-only stack (fails [1,2,1,3,2,3]). Both Type1 and Type2 are genuinely necessary.
