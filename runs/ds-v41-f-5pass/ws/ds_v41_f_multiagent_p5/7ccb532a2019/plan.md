The alphabet size is only 26, so enumerate every possible common frequency k that a non-absent letter could have in the final good string. For a fixed k, each letter is either absent with final count 0 or present with final count exactly k. The cost is driven by deleting excess copies, inserting missing copies, and using one-step letter changes to move surplus into the next letter. A DP over letters a..z with two states per letter captures the only useful coupling, where surplus at letter i can reduce a deficit at letter i+1. Take the minimum cost over all k and DP states, giving an O(26*n) algorithm that fits the constraints.
