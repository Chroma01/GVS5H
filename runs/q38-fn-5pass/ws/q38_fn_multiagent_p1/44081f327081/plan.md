Compute, for every possible divisor d up to max(A), how many array elements are divisible by d. For a fixed i, a value d can be the GCD of some K chosen elements including A_i exactly when d divides A_i and at least K elements are divisible by d. Therefore the answer for A_i is the largest divisor d of A_i with count[d] >= K. Build the counts using a frequency array and a multiples sieve, then propagate the best valid divisor to every multiple value, and finally output the precomputed answer for each A_i.
