This is a classic "minimize the maximum" problem solvable with binary search on the answer combined with a feasibility check. For a candidate maximum run length L, compute the minimum flips needed so no L+1 identical characters are ever consecutive; L is feasible if that count is <= numOps. Handle L == 1 separately (the string must alternate, so count mismatches against the two alternating patterns) and L >= 2 via the formula len // (L+1) summed over each maximal run of identical characters. Binary search L over [1, n] to find the smallest feasible value. Return that value as the answer.
