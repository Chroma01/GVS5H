The total cost equals the initial total tooth length minus N times the final common sum H, so the goal is to maximize a feasible H. For a fixed H, each upper tooth length u_i must lie in the interval [max(0, H - D_i), min(U_i, H)], and adjacent upper lengths must differ by at most X. Feasibility for fixed H can be checked greedily by propagating the reachable interval of u_i from left to right. This feasibility is monotone in H, so binary search the maximum feasible H over [0, min_i(U_i + D_i)]. Finally compute the minimum cost as sum(U_i + D_i) - N * H_best.
