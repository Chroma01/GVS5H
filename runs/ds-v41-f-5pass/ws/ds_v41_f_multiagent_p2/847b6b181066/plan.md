Reduce the smoke process to prefix displacements of the wind sequence from the origin. Because cell (0,0) is occupied at every time after generation, smoke reaches (R,C) at time t+0.5 exactly when some earlier origin position plus the intervening wind equals (R,C). This is equivalent to checking whether A_t - (R,C) has appeared among previous prefix sums A_s for s < t. Scan the wind string once, maintaining seen prefix coordinates in a hash set and emitting 1 or 0 for each t. The intended solution is O(N) time and O(N) space.
