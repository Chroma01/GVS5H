Binary search the answer K, the minimum vitamin intake. For a fixed K, each vitamin type is independent because every food contributes to only one vitamin type, so compute the minimum calories needed separately to reach at least K units of vitamins 1, 2, and 3. If the sum of these three minimum costs is at most X, then K is feasible. Precompute 0/1 knapsack DP arrays per vitamin over calorie budgets up to X, then use them to answer each feasibility check quickly. The answer is the largest feasible K, with 0 handled as a valid lower bound.
