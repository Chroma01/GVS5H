- **Core model:** State `(u, v)` means there is a palindrome-labeled path from `u` to `v`. The answer for each pair is the shortest distance to that state.
- **Centers:** Even-length palindromes start from empty paths `(i, i)` with length `0`. Odd-length palindromes start from single edges `(u, v)` with length `1`. Self-loop edge centers are omitted because `(i, i)` with length `0` is shorter and dominates all outer expansions.
- **Expansion:** From state `(x, y)`, add one edge on each side with the same label: if `p -> x` and `y -> q` both have label `c`, then `(p, q)` is reachable with length `dist[x][y] + 2`. Directedness is handled by using incoming edges to the left endpoint and outgoing edges from the right endpoint.
- **Why one distance per state is enough:** Any palindrome path can be peeled recursively to a center. If an inner endpoint pair has a shorter palindrome, replacing the inner part by that shorter palindrome and keeping the same outer edges gives a valid shorter palindrome for the outer pair. Thus longer distances for the same endpoint pair are never needed.
- **BFS correctness:** All state transitions cost `2`. The queue is initialized with all distance-0 states first, then all distance-1 states. FIFO processing then visits states in nondecreasing distance order (`0, 1, 2, 3, ...`), so the first time a state is discovered is its shortest distance.
- **Bitset representation:** `out_masks[c][y]` is an integer bitset of vertices `q` such that `y -> q` has label `c`. `in_edges[x]` stores incoming edges `(p, c)` to `x`. For a popped state `(x, y)`, iterating `in_edges[x]` and intersecting with `out_masks[c][y]` generates all valid outer extensions.
- **Unvisited rows:** `unvisited[p]` is a bitset of vertices `q` whose distance in row `p` is still unknown. For each incoming edge `(p, c)`, `mask = out_masks[c][y] & unvisited[p]` gives exactly the newly reached states `(p, q)`. The bits in `mask` are cleared at once, then each bit is set in `dist` and enqueued.
- **Complexity:** There are at most `N^2` states. For each processed state, we scan incoming edges of its left endpoint, at most `N`, giving `O(N^3)` elementary operations, about `10^6` for `N = 100`. Bit enumeration over newly discovered states totals `O(N^2)`. Memory is `O(N^2)`.
- **Early stop:** A `remaining` counter tracks unvisited pairs. It is decremented for sources and discoveries. BFS stops once all pairs have known distances, which avoids processing the queue in dense cases where all states are initialized as sources.
- **Edge cases:** Diagonal answers are always `0`. Self-loops are ignored as length-1 sources because `0` is shorter. Unreachable pairs remain `-1`. Input is read with `split()`; each row is expected to have length `N`.
