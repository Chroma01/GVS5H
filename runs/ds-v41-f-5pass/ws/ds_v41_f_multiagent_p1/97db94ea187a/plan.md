For a fixed sequence of layer sizes, the number of valid graphs is a product of independent factors: multinomial label assignments, forced edges from each vertex to the previous layer, and arbitrary internal edges. Use dynamic programming over layers, tracking the number of even and odd vertices used, the size of the last layer, and a polynomial in x that counts edges.
