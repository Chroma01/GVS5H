The minimax path value f(x, y) is the smallest edge-weight threshold at which x and y become connected, so it can be represented by a Kruskal reconstruction tree built from edges sorted by weight. In this tree, f(x, y) equals the weight of the LCA of leaves x and y, turning the problem into matching K marked A leaves to K marked B leaves on a rooted tree with cost equal to LCA weight. An optimal matching can be obtained greedily bottom-up: inside each subtree, match as many A and B occurrences as possible, and only unmatched surplus of opposite signs from different children are matched at the current node. At an internal node with weight w, if child surpluses are s_i = (#A - #B) after internal matching, the number of pairs whose LCA is this node is min(sum positive s_i, sum negative -s_i), contributing w times that count. Summing these contributions over all internal nodes gives the minimum total cost.
