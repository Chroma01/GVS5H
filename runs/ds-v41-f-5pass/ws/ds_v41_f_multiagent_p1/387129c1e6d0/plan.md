Process Santa's moves in order while maintaining the current coordinate. For each axis-aligned move, efficiently find all unvisited houses lying on the traversed segment, mark them visited, and remove them from future consideration. Use separate sorted structures for houses grouped by x-coordinate and by y-coordinate, since vertical moves only need same x and horizontal moves only need same y. Because each house is counted at most once, deletions are total O(N), allowing an overall near O((N+M) log N) solution. Update Santa's position after each move and output the final coordinate plus the visited count.
