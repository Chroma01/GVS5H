Group foods by vitamin since each food contributes to only one vitamin, making the three vitamin requirements independent. For each vitamin, run a 0/1 knapsack over calories up to X to compute the maximum units of that vitamin achievable for every calorie budget, then convert this into the minimum calories needed to reach any target amount. Since feasibility for a candidate answer K is simply whether the sum of the three minimum required calories is at most X, use binary search over K. The upper bound can be the maximum possible total units for any single vitamin. This avoids re-running DP for every binary-search step.
