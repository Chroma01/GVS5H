The key reduction is that a pair can be charged to one of the three attributes that attains the maximum; then we only need to choose \(2K\) cakes and color them by that attribute, with each color used an even number of times. For a fixed integer penalty \(\lambda\) per pair, maximize the doubled adjusted score \(\sum(2\text{value}-\lambda)\) over even color counts; the optimal value as a function of the number of pairs is concave (cardinality-constrained matching polytope), so an Aliens-trick binary search applies. For fixed \(\lambda\), take each cake's best gain (unused on zero ties), then the parity mask can be corrected by changing at most three cakes' states; keep the top few change candidates for each of the seven masks and enumerate combinations to get the maximum adjusted score and the minimum optimal pair count. Binary search the smallest \(\lambda\) whose minimum optimal pair count is at most \(K\), then recover the exact answer by adding back the penalty.
