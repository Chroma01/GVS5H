Model the multiset of words in a trie, where each node stores how many word occurrences pass through it. After deleting one occurrence, only nodes on that word’s trie path have their counts decreased by one, so the answer is the deepest node whose remaining count is at least k. Split candidates into two groups: nodes on the deleted word’s path that originally had count at least k+1, and nodes off the path that originally had count at least k. Assign each word occurrence a DFS position so every trie node covers a contiguous interval of positions; then off-path candidates for an occurrence are exactly qualifying intervals that do not contain its position, which can be computed with prefix/suffix sweeps over interval endpoints. Combine the best on-path and off-path depths per occurrence, returning 0 whenever fewer than k words remain.
