Maintain, for each possible non-zero last digit `d = 1..9`, a frequency array of residues modulo `d` for all substrings ending at the current position. When reading a new digit `x`, update each `d`'s frequency by extending every previous substring: new residue = `(old residue * 10 + x) % d`, and also add the one-character substring `x`. If `x` is non-zero, add the frequency of residue `0` for `d = x`, because those are exactly the substrings ending at this position whose last digit is `x` and whose value is divisible by `x`. This gives `O(90n)` time and `O(1)` memory, naturally handling leading zeros and single-digit substrings.
