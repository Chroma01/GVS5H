The key observation is that chosen subarrays are non-overlapping, so the cost to equalize each length-x window is independent. First compute for every possible window start the minimum operations needed to make that window all equal, which is the sum of absolute deviations from its median. Then reduce the problem to choosing exactly k non-overlapping windows with minimum total cost, solvable by DP over positions with k up to 15. Use an efficient sliding-window median structure to avoid O(n*x) preprocessing. The final answer is the best DP value after processing all positions.
