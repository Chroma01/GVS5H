Use the identity for any positive integer x: if t is the number of trailing zero bits of x, then f(x)=x/2^t = x - sum_{k=1..t} x/2^k. Therefore the desired answer equals the total sum of all pair sums minus, for every power M=2^k, the sum of (Ai+Aj)/M over pairs where M divides Ai+Aj. The total pair sum is (N+1)*sum(A). For each M, group values by residue modulo M and combine complementary residues r and (-r mod M) to compute the correction efficiently. This gives O(N log max(A)) time and O(N) memory using dictionaries.
