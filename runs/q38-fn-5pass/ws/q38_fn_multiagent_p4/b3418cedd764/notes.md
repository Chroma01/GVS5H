- **Model:** Treat each constraint as a functional graph edge i -> A_i. Every weak component has one directed cycle. Around a cycle, inequalities force all cycle vertices to have the same value. Non-cycle vertices form rooted in-trees feeding into cycle vertices.
- **DP definition:** For a non-cycle vertex u, dp_u[v] is the number of valid assignments in u's subtree with x_u <= v. For a leaf, dp[v] = v. For an internal node, exact count at value t is product over children c of dp_c[t], because each child must be <= t. Then dp_u is the prefix sum of these exact counts.
- **Cycle handling:** For a cycle component, all cycle vertices share value v. The contribution is sum_{v=1..M} product of dp_child[v] over all non-cycle children attached to any cycle vertex. Cycle vertices themselves contribute exactly one choice for each v. Multiply answers of independent components modulo 998244353.
- **Cycle detection:** Use indegree peeling. Nodes popped are non-cycle and appear in bottom-up order (children before parent). Nodes left are cycle nodes, including self-loops.
- **Implementation optimizations:** A shared base list represents all leaf DP arrays. Arrays are freed by setting dp[child] = None after merging. Single-child nodes reuse the child's array and only copy if it is the shared base. Multi-child nodes start the product with the first child to save one pointwise multiplication. Cycle accumulators similarly start with the first attached child. Base arrays are copied before any in-place modification. Prefix sums and final sums use conditional subtraction instead of modulo where safe.
- **Complexity:** Each edge causes at most one pointwise multiplication over M values, and each non-cycle internal node causes one prefix pass over M values. Time is O(NM). Memory is reduced by freeing child arrays; worst-case live arrays are still bounded by O(NM), feasible for N,M <= 2025.
- **Edge cases:** Pure cycles give M. Self-loops are cycles of length one. M=1 works with all arrays of length 2. Multiple components are multiplied independently. Modulo is applied after products and sums.
