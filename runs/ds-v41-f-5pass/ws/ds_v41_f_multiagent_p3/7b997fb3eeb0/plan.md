For a range of length M, the maximum number of pairs K satisfies 2*A[L+i-1] <= A[R-K+i] for all i. Setting D = M - K, this becomes D >= max_{j in [L, R-D]} g(j), where g(j) is the distance from j to the first index k with A[k] >= 2*A[j]. Precompute g for all positions, then build a range-maximum query structure. For each query, binary search the smallest valid D in [ceil(M/2), M] and return M - D.
