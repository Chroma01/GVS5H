- **Current approach:** Trie-based solution replaces the sorted sliding-window method. Each trie node represents a prefix and stores how many words have that prefix.
- **Feasibility rule:** For a prefix node with count `c`, after deleting one word it still supports `k` strings iff `c >= k + 1`, or `c == k` and the deleted word is outside the node's terminal subtree.
- **Global contribution:** Nodes with `count >= k + 1` are valid for every deletion. Keep the maximum depth among them as `global_best`.
- **Count == k contribution:** Such a node is valid for every deletion except deletions of words inside its subtree. Its terminal words form a contiguous DFS interval `[l, r]`, and the node contributes its depth to all positions outside that interval.
- **Terminal positions:** Terminal indices are stored using linked lists (`term_head` and `next_term`) to handle duplicates without many small lists. An iterative DFS assigns each terminal a unique position. Terminals at a node are visited before children, so every subtree's terminals are contiguous.
- **Interval outside maximum:** For each `count == k` interval `[l, r]` with depth `d`, update `best_start[l]` and `best_end[r]`. For position `p`, intervals not covering `p` are exactly those with `r < p` or `l > p`. A prefix running maximum over `best_end` and a suffix running maximum over `best_start` give the best outside depth for each position.
- **Answer assembly:** `suffix[p]` stores the maximum `best_start` strictly after `p`. During the left-to-right pass, `running` stores the maximum `best_end` strictly before `p`. Combine these with `global_best` and write the result to the original index using `pos_to_orig`.
- **Edge cases:** If `n == k`, every `count == k` interval covers all positions and no `count >= k + 1` node exists, so all answers naturally become zero. The `k == 1` case also works naturally: unique full-word nodes contribute to all other positions, while duplicated or globally frequent prefixes contribute everywhere.
- **Complexity:** Trie construction is `O(total characters)`. DFS and prefix/suffix processing are `O(nodes + n)`, with `nodes <= total characters + 1`. Memory is `O(total characters + n)`.
