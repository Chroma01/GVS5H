The shortest palindrome with prefix S is obtained by appending the reverse of the shortest prefix of S needed to make the whole string palindrome. This is equivalent to finding the longest palindromic suffix of S. Compute that length efficiently using the KMP prefix function on the string S + "#" + reverse(S), where the final prefix-function value gives the longest suffix of S that is also a prefix of reverse(S), i.e. the longest palindromic suffix. Then output S plus the reverse of the remaining prefix before that suffix.
