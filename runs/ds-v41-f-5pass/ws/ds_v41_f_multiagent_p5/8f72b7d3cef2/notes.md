- **Model:** Takahashi occupies a contiguous interval containing K; his size is the interval sum. He may extend over an adjacent element strictly smaller than his current size. Since all values are positive, any absorption only increases the size, so the reachable set is the unique maximal closure — greedy (absorb everything currently absorbable) is optimal and order-independent.
- **Threshold view:** With current size S, the maximal interval around K whose other elements satisfy x < S (initially for size A_K, all non-K elements < A_K) has sum W; all of it is absorbable, raising size to W. Iterate S <- W to a fixed point; that is the answer.
- **Component tree:** Build the Kruskal reconstruction tree on edges (i,i+1) weighted max(A_i,A_{i+1}), processing weights increasingly, creating one internal node per successful union. For every node u, value(u) = max A in its subtree and sum(u) = subtree sum (holds even with equal weights because the tree shape is weight-order independent). The component of {A_i < t} containing a leaf is exactly the highest ancestor u of that leaf with value(u) < t.
- **f recurrence:** f(u) = final reachable size when the current component is u. If no proper ancestor has value < sum(u), then u cannot expand, so f(u)=sum(u); otherwise f(u)=f(w) where w is the highest ancestor with value(w) < sum(u). Since ancestors are processed first in pre-order DFS, f(w) is available. For internal nodes value(u) < sum(u) always (two positive leaves ⇒ max ≤ sum−min < sum).
- **Finding w:** Along a root→node path, values are non-increasing. Keep the path values as negatives (non-decreasing) and use bisect_right(negvals, -S) to get the first (shallowest) node with value < S. Same routine for the initial jump.
- **Initial step:** T0 = A_K plus the sums of the maximal contiguous runs strictly below A_K immediately left/right of K (bounded by nearest index with A ≥ A_K, via monotonic stacks, using prefix sums). If T0 == A_K the answer is A_K. Otherwise w = highest ancestor with value < T0 and the answer is f(w). Equal-valued neighbors correctly block because A ≥ A_K is not absorbable.
- **Complexity:** O(N log N) time (sort of edges plus one bisect per node), O(N) nodes (2N−1), 64-bit sums fit Python ints.
- **Validation:** Matches both provided samples and hand brute force: [3,1,4,1,5] → [4,1,14,1,14]; [2,2,1,2] → [2,7,1,7]; [1,2,3] → [1,3,6]; sample1 K=4 gives T0=7 → node sum13 → 13.
- **Pitfalls handled:** strict '<' (not '≤'); equal values blocking initially but becoming absorbable after growth; absorbing a smaller element never hurts future moves.
