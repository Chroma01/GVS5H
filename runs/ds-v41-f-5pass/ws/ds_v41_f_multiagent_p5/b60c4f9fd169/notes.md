- **Problem:** decide whether Levenshtein distance (insert/delete/replace, each cost 1) between S and T is ≤ K. |S|,|T| ≤ 5e5, 1 ≤ K ≤ 20, single test.
- **Reductions:** trim the common prefix, then the common suffix of the remainder. Edit distance is invariant under stripping a shared prefix/suffix. Prefix proof: define D on cX,cY; the sub-array D'[i][j]=D[i+1][j+1] has bases D'[i][0]=i, D'[0][j]=j and satisfies the exact standard recurrence for X,Y, so D[|X|+1][|Y|+1]=ED(X,Y). Suffix follows by reversal. After trimming, first and last chars of the remainders differ. Then: if a remainder is empty, answer is (other length ≤ K); reject early if |n−m| > K.
- **Core algorithm:** banded by-count wavefront. Diagonal d = i − j. V[d] = furthest x reachable on diagonal d using exactly c operations. Base c=0: V[0]=lcp(0,0). For c=1..K: substitution from V_{c−1}[d]+1 (needs x<n, y<m), deletion from V_{c−1}[d−1]+1 (needs x<n), insertion from V_{c−1}[d+1] (needs y<m, x unchanged); take the max candidate, then extend by lcp. Answer Yes at the first c≤K with V[n−m] ≥ n.
- **Key lemma (monotone extension):** f(x)=x+lcp(x,x−d) is nondecreasing in x. If the match run from x2 reaches x2+L and x1>x2, then either x1≤x2+L (run continues, so from x1 it reaches ≥x2+L) or x1>x2+L already. Hence taking the max transition source then extending once yields the furthest reachable point — no smaller source can beat it.
- **Correctness:** monotone transitions plus the lemma give furthest-reaching dominance; every operation changes d by at most 1, so after c ops |d| ≤ c and the band [−c,c] is exact; each produced point respects x∈[0,n], y=x−d∈[0,m].
- **Sign audit:** deletion increments d (source d−1), insertion decrements d (source d+1), substitution stays on d. Array size 2K+3 with off=K+1; out-of-band entries stay −1; all indices (including off+d±1 at |d|=K) stay in bounds.
- **LCP:** one 64-bit rolling hash, random odd base in [2^33,2^62), arithmetic mod 2^64, plus a power table; binary-search the longest equal prefix. Only O(K²) ≤ 441 queries each O(log n); hash build O(n+m). Random base defeats crafted anti-hash inputs.
- **Differential testing:** built a brute-force O(nm) Levenshtein DP (unit costs) and compared its (distance ≤ K) verdict against this solver over random lowercase pairs with |S|,|T| ≤ 12 and K∈[1,6], plus constructed families: prefix/suffix overlaps, one string a prefix of the other, distances exactly K and K±1, K ≥ both lengths, S==T, and repeated-block "ab"×L vs "ba"×L. No counterexample found; verdicts agree everywhere tested. Hand-traced samples: abc/awtf K=3 Yes, K=2 No; sample 3 Yes. Also verified "abc"/"abcde" K=2 Yes, "abcde"/"abc" K=2 Yes, "ab"/"ba" K=1 No and K=2 Yes. All match brute-force Levenshtein.
- **Complexity/memory:** O(n+m+K² log n) time, O(n+m+K) memory (three int lists, ~55–60MB at 5e5) — safe for typical limits.
- **Edge cases covered:** empty remainder; n or m zero; |n−m|>K; S==T (0 ops); substitutions on already-equal chars are permitted (never help but stay valid, so no false result); answer never depends on diagonals outside [−K,K].
