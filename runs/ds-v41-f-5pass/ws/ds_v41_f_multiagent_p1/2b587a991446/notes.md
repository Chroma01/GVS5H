- **Model:** state (a,b), a≠b; answer = shortest path in product-minus-diagonal from (S,T) to (T,S). Direct BFS is O(N^2), so reduce via block-cut tree (BCT) plus two gadget families.
- **Feasibility:** -1 iff graph is a simple path. Equivalent test: no cycle block on the BCT S-T path AND no degree>=3 vertex on any shortest S-T path. If a 2-connected block is off the path or a branch exists off the path, the connecting articulation has deg>=3 and lies on the path, so an on-path gadget always exists.
- **Gadget 1 (cycle block):** for each block on the BCT path with >=3 vertices, entry x / exit y (x=S or y=T at path ends), cost = 2*(dS[x]+dT[y]) + cyc_B(x,y). Here cyc_B = shortest cycle through x,y inside the block = min-cost 2-flow (vertex-split, cap 2 on x,y, cap 1 elsewhere, edge cap 1 cost 1) from x to y. This equals the sum of two internally vertex-disjoint x-y paths.
- **Gadget 2 (buffer vertex), CORRECTED:** only for v with deg(v)>=3 AND dS[v]+dT[v]==L (v lies on a shortest S-T path). Cost = 2*L + pen, pen = 2 if v∉{S,T}, pen = 4 if v∈{S,T}. The old rule giving pen=4 when dS[v]+dT[v]>L is WRONG: it underestimates. Counterexample reason: for v off every shortest path, paths S→v and T→v overlap, so the "A hides, B passes" schedule invalid and 2*(dS+dT)+4 may be below true optimum.
- **Evidence for buffer necessity:** cycle S-v-T-w1..w5-S plus pendant v-c. Block gadget gives 2+6=8; buffer at v (m=L=2, interior) gives 6, achievable: A S→v, A v→c, B T→v, B v→S, A c→v, A v→T = 6.
- **Endpoint pen=4 check:** S-T edge with S having two pendants (deg S=3). True answer 6 = 2*1+4. Schedule: B T→t1, A S→T, A T→t2, B t1→T, B T→S, A t2→T. Symmetric for T. Verified by BFS.
- **Buffer validity for interior v:** pick a shortest S-T path P through v; v has <=2 neighbours on P, hide at an off-P neighbour w. A: S⇝v, v→w; B: T⇝v⇝S; A: w→v⇝T. Total 2L+2, no collisions.
- **Block gadget schedule:** A uses S→x, path P1 in block x→y, y→T; B uses T→y, P2 y→x, x→S. P1,P2 internally disjoint so the swap is schedulable; total = 2(dS[x]+dT[y]) + |P1|+|P2|.
- **Why off-path gadgets unneeded:** any off-path block attaches at a path articulation of degree>=3, whose buffer (2L+2) is <= any cycle-based detour (extra >=3, or 2L+4 when endpoint). So min over the two families suffices.
- **BCT construction:** iterative Tarjan (no recursion). Block = edge list; articulation via low[child]>=disc[u] (root needs >=2 children). BCT nodes: blocks 0..B-1, articulation node B+v. start = B+S if art else block_of[S]; symmetric for T. Unique BCT path gives entry/exit per block.
- **Complexity:** BFS O(N+M); Tarjan O(N+M); MCMF per path block, 2 Dijkstra augmentations, total O((N+M) log(N+M)). Prune blocks with 2*(dS[x]+dT[y])+3 >= current ans.
