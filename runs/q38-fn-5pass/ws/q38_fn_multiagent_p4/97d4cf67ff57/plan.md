Root the tree arbitrarily and run a bottom-up DP over rooted subtrees, considering only connected selected subgraphs whose top vertex is the current node or whose edge to the parent is selected. For a vertex connected to its parent, valid degrees are 1 (no selected children) or 4 (exactly three selected children), so store the best size of a degree-4 branch `f[u]`; a degree-1 branch is always just the single vertex. Each child can contribute either as a leaf of size 1 or as a degree-4 branch `f[child]`, so `f[u]` is obtained by taking the three largest child contributions, and a final alkane rooted at `u` with degree 4 takes the four largest contributions. A final alkane whose root has degree 1 must attach to exactly one child branch `f[child]` to contain a degree-4 vertex. Take the maximum of these final states over all vertices, using iterative postorder to handle `N` up to `2e5`, and output `-1` if no valid state exists.
