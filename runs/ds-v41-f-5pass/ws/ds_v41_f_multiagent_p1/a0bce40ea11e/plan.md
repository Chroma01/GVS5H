The problem is to compute the sum of B^p over all completions of zero entries in A modulo prime p. The key is to expand B^p as a sum over walks of length p, then sum over each zero variable independently. For p > 2, each zero variable must appear either 0 or p-1 times in a walk for the sum to be nonzero; since total steps are p, only one zero variable can appear (exactly p-1 times) along with one fixed nonzero entry. This yields a formula: compute M^p where M is A with zeros set to 0, then add contributions from each zero entry (self-loops contribute row/column entries; for p=3, non-self-loops contribute a single entry), and finally multiply by (-1)^K where K is the number of zeros. For p=2, all zeros become 1, so just compute B^2 mod 2. Matrix exponentiation modulo p is used for M^p.
