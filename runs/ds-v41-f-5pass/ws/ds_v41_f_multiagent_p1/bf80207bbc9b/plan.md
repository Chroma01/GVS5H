Represent each row as a W-bit mask. For any fixed set of column flips, each row can be optimally handled independently by either flipping it or not, contributing min(popcount(row xor col_mask), W - popcount(row xor col_mask)). Aggregate identical row masks into frequencies, then the objective over all column masks is an XOR convolution of these frequencies with a kernel depending only on popcount. Since W ≤ 18, compute all column-mask costs using Fast Walsh-Hadamard Transform in O(W·2^W). Finally take the minimum over all 2^W column-flip choices.
