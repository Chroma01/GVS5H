- **Core characterization:** For a fixed subarray, only the set S of distinct values matters. One operation can erase exactly a consecutive interval of values that are all currently present. Values separated by an absent value can never be erased together. Therefore f(L,R) is the number of connected components of S in the path graph on values 1..N, equivalently |S| minus the number of adjacent pairs (x,x+1) both present.
- **Summation reduction:** The required answer is sum over all values x of the number of subarrays containing x, minus sum over all adjacent pairs (x,x+1) of the number of subarrays containing both x and x+1.
- **Single-value counting:** Build occurrence lists occ[v] using 1-indexed positions. Subarrays avoiding v are exactly subarrays lying completely inside gaps between consecutive occurrences of v, including the prefix before the first occurrence and suffix after the last occurrence. A gap of length g contributes g*(g+1)//2 avoiding subarrays. Store avoid[v], and add total - avoid[v] to the single-value sum.
- **Adjacent-pair counting:** For pair (x,x+1), subarrays avoiding both are gaps in the merged sorted union of occ[x] and occ[x+1]. Use inclusion-exclusion: containing both = total - avoid[x] - avoid[x+1] + avoid_both. If either occurrence list is empty, the pair contribution is zero and can be skipped.
- **Complexity:** Total occurrence-list length is N. Computing all single-value gap sums is O(N). Each occurrence list is merged in at most two adjacent-pair computations, so total merge work is also O(N). Memory is O(N). Python integers safely handle the final answer.
- **Implementation details:** Use total = N*(N+1)//2. For an empty occurrence list, avoid[v] = total. In pair merging, accumulate gap contributions before each next union position and after the final position. Positions from different value lists cannot be equal because each array index has only one value.
- **Edge cases handled:** N=1, absent values, all values equal, all values consecutive, all values nonconsecutive, and pairs where one or both values are absent.
- **Validation:** Sample 1 gives single_sum=18, pair_sum=2, answer=16. Sample 2 gives single_sum=32, pair_sum=9, answer=23.
