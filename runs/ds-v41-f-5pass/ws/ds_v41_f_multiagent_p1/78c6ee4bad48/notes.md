- **Model:** Work with sorted gaps `g_j = X_{j+1} - X_j` for `j = 1..N-1`. Coordinates are recovered as `p_1 = X_1`, `p_k = X_1 + g_1 + ... + g_{k-1}`.
- **Operation effect:** On four consecutive sorted pieces `a<b<c<d`, M=(a+d)/2, so `b -> a+d-b` and `c -> a+d-c`. The new sorted order is `a<c'<b'<d`, i.e. the triple of gaps `(g1,g2,g3)` becomes `(g3,g2,g1)`. Only the outer two gaps are swapped.
- **Reachable states:** Choosing `i` swaps gaps `i` and `i+2`. These adjacent transpositions inside the odd-index chain `(1,3,5,...)` and the even-index chain `(2,4,6,...)` generate the full symmetric group on each class. So the two parity classes can be permuted independently and arbitrarily; no other invariant exists. (Distinctness is guaranteed by the statement.)
- **Objective:** `sum = N*X_1 + sum_{j=1}^{N-1} g_j * (N - j)`. Gap `g_j` appears in positions `j+1..N`, contributing weight `N-j`. Earlier positions carry larger weights.
- **Optimisation:** Rearrangement inequality. Within each parity class pair the largest gap with the smallest weight, i.e. assign gaps sorted descending to gap indices sorted descending. Equivalently sort each class descending and place onto indices `...,5,3,1` (odd) and `...,6,4,2` (even) in that order.
- **Formula check (Sample 1):** N=4, X=1,5,7,10, gaps 4,2,3. Base 4*1=4. Odd {4,3}: index 3 gets 4 (w1), index 1 gets 3 (w3) -> 4+9=13. Even {2}: index 2 w2 -> 4. Total 4+13+4=21. Correct.
- **Formula check (Sample 2):** N=6, X=0,1,6,10,14,16, gaps 1,5,4,4,2. Base 0. Odd {1,4,2} desc {4,2,1} onto indices 5,3,1 weights 1,3,5 -> 4+6+5=15. Even {5,4} desc onto indices 4,2 weights 2,4 -> 10+16=26. Total 41. Correct.
- **Complexity:** O(N log N) time (two sorts), O(N) memory. Fits N<=2e5, coords<=1e12; Python big ints handle sums up to ~2e17 safely.
- **Pitfalls avoided:** 1-based gap indexing when computing weight `N-j`; pure-integer arithmetic (no midpoints/floats); correct rearrangement direction (larger gap to later/smaller-weight position); base term is `N*X_1` not `X_1`.
- **Brute force suggestion (validation):** For small N, BFS over reachable gap orderings via swaps `(i,i+2)`, compute weighted sums, take min, compare with formula. Parity-class independence makes expected state count `(#odd)! * (#even)!`; the formula matched samples directly so no code path depends on it.
