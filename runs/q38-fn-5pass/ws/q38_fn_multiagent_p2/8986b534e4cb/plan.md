Convert each person to an oriented interval \([l,r]\) on the line, where direction `+` means interior stamina is above the endpoint value and direction `-` means it is below. In prefix-potential form, each person requires equal endpoint potentials and strict inequalities for all interior towns; after contracting equal endpoints, feasibility is equivalent to acyclicity of the induced strict-inequality graph. For this interval structure, a cycle exists iff some pair of people is bad: either two same-direction intervals cross, or two intervals share an endpoint while one contains the other (including opposite directions on the same endpoints). Therefore each query is Yes iff the index interval contains no bad pair. We can compute, for every right endpoint \(j\), the maximum previous index \(i<j\) forming a bad pair with \(j\), take prefix maxima, and answer queries by checking whether that prefix maximum is at least \(L\). Same-endpoint bad pairs are handled directly; same-direction crossing pairs are answered as 2D orthogonal range-max queries using a Python-friendly static bitset/block decomposition.
