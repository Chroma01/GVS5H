Only deleting negative values can improve the maximum subarray sum, so we can focus on distinct negative numbers. For each negative value v, maintain a score W_v = -m_v + k*|v|, where m_v is the minimum prefix sum before v's first occurrence and k is the number of times v has appeared. During a left-to-right scan, track the running prefix sum P, the minimum prefix sum min_P, the maximum W_v, and the minimum prefix sum M_neg among negative elements. The best subarray sum ending at the current position for any deletion is P + max(max_W, -M_neg); take the maximum of this over all positions and compare with the no-deletion baseline. Handle arrays where all elements are non-positive separately, since empty subarrays are invalid and the answer is then simply the maximum element.
