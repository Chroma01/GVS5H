- **Verification:** A brute-force BFS verifier for small N (states as sorted tuples of piece positions, operations for every target square, goal checked by occupied set) was used against random small cases and the current algorithm. No discrepancy was found, so the algorithm was not changed.
- **State model:** Only occupied positions matter. Operations preserve order, may merge adjacent pieces into permanent stacks, and never increase any gap between consecutive pieces. A final configuration is obtained by choosing K-1 initial gaps to survive as the gaps of B; every chosen gap must be at least the corresponding B-gap, and all unchosen gaps must be reduced to zero.
- **Operation effects:** Let first/last occupied positions be p,q. Target strictly inside the span: p++, q--, total gap deficit -2. Target at first occupied square: q--, first positive gap -1. Target at last occupied square: p++, last positive gap -1. Target outside the span: pure shift, gaps unchanged.
- **Count variables:** Let c be internal gap-reducing operations, l left-endpoint operations, r right-endpoint operations. Span reduction is fixed: D = span(A)-span(B) = 2c+l+r. With dp = first(B)-first(A), dq = last(B)-last(A), the needed net pure shift is s = dp-c-r. Total operations are c+l+r+|s|.
- **Strict embedding:** If B-gaps can be matched to A-gaps with strict `A_gap > B_gap`, there are no zero-deficit barriers. Then the lower bound max(dp, -dq) is attainable by choosing endpoint/internal/pure-shift counts appropriately.
- **Exact barriers:** A matched gap with equality has deficit zero and can never be touched, so it splits the gap sequence. Every component not touching a global endpoint must have even total deficit. Therefore all exact matches must have the same prefix-deficit parity p. The left endpoint count parity is p, and the right endpoint count parity is D-p.
- **Greedy matcher:** For a fixed parity p, scan A-gaps left to right. If g < current H-gap, it must be unmatched. If g > current H-gap, match it. If g == current H-gap, match only when current prefix parity equals p; otherwise leave it unmatched. This greedy is complete because the prefix deficit parity after processing j A-gaps and matching i B-gaps is fixed as `(sum G[:j] - sum H[:i]) mod 2`, independent of which gaps were chosen. Matching the earliest allowed gap cannot destroy a valid completion.
- **Mode cost:** For feasible parity p, minimal endpoint counts are l=p and r=(D-p)%2. Extra endpoint pairs do not reduce the total cost: increasing l+r by 2 increases the span-reducing operation count by 1 and can reduce |s| by at most 1. Then c=(D-l-r)//2, s=dp-c-r, and cost=c+l+r+|s|. The answer is the minimum feasible mode cost; if strict embedding exists, it is simply the lower bound.
- **Edge cases:** K=1 collapses to one stack and answer is max(dp, -dq). D=0 is a pure shift when exact gaps remain. Exact at the first/last gap forces the corresponding endpoint parity to zero and is handled by the mode parity. K>M, D<0, or failed greedy matching means impossible. Board boundaries are safe by doing gap reductions first and pure shifts last.
- **Complexity:** Each test case uses O(N) time and O(N) memory for gap lists; total O(sum N).
