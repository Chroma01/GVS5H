- **Implemented rule:** For N=1 Fennec always wins. For N=2 Snuke always wins. For N=3 Fennec wins iff at least one A_i is odd. For N>=4 Fennec wins iff the number of odd A_i is odd.
- **Small cases:** With N=1, Fennec opens the only index and wins immediately. With N=2, Fennec must open one index, then Snuke opens the last index and wins. With N=3 and no pass tokens initially, opening an odd pile leaves the opponent with two unopened piles and an even/zero pass pool, which is losing for the opponent; opening an even pile leaves an odd pass pool, which is winning for the opponent. Hence N=3 is winning exactly when an odd pile exists.
- **Large cases:** For N>=4, the game reduces to the parity of the number of odd A_i. Intermediate pass-pool sizes can distinguish zero, odd, and positive even pools, but for the initial position with zero passes and N>=4 these distinctions cancel out, leaving only the parity of odd piles as the deciding invariant.
- **Complexity:** The program reads all values once and counts odd numbers, so time complexity is O(N) and memory usage is O(1) beyond input storage.
