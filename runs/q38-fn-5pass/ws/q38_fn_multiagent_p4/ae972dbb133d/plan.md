Represent each grid edge by a binary variable indicating whether a segment endpoint exists on that edge; the tile rules become local XOR constraints. Type A forces the two horizontal edge variables around the cell to differ and the two vertical edge variables to differ, while Type B forces horizontal variables to be equal, vertical variables to be equal, and the horizontal and vertical variables at that cell to differ. The horizontal constraints decouple by rows and the vertical constraints decouple by columns, so every row and every column must contain an even number of A tiles. If these parity checks pass, all horizontal variables are determined by one free bit per row and all vertical variables by one free bit per column, and each B tile adds one XOR constraint between its row bit and column bit. Count the consistent assignments of these row/column bits using a parity DSU on the bipartite graph of B tiles; the answer is \(2^{\text{number of connected components}}\) modulo 998244353.
