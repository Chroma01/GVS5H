- **Core reduction:** Let S_j be the prefix sum modulo 998244353. Every subarray sum is S_r - S_{l-1}, so the answer is the sum over all pairs 0 <= i < j <= N of (S_j - S_i)^K.
- **Binomial accumulation:** Expand (S_j - S_i)^K as sum_t C(K,t) S_j^t (-1)^{K-t} S_i^{K-t}. While scanning j from left to right, maintain power_sums[p] = sum of previous S_i^p. For each new S_j, add sum_t C(K,t) S_j^t (-1)^{K-t} power_sums[K-t], then update power_sums with S_j.
- **Initial state:** Include S_0 = 0 before processing A_1. This is represented by power_sums[0] = 1 and power_sums[p] = 0 for p > 0.
- **Implementation choices:** Precompute signed binomial coefficients coeff[t] = C(K,t) if (K-t) is even, otherwise -C(K,t). For each prefix, compute powers S_j^p iteratively and simultaneously form the contribution using the old power_sums. Update power_sums only after the contribution to avoid pairing S_j with itself.
- **Modulo handling:** Prefix sums are kept reduced using prefix += a; if prefix >= MOD: prefix -= MOD, valid because 0 <= a < MOD. Power values and power_sums entries are kept below MOD. The contribution total is allowed to be signed and is reduced modulo MOD once per prefix. Negative totals are handled correctly by Python's modulo operator.
- **Complexity:** The algorithm uses O(NK) time and O(K) memory. With K <= 10 and N <= 2e5, this is easily fast enough.
- **Edge cases:** If A_i = 0, prefix may be 0; powers become [1, 0, ..., 0], so only the t = K term can contribute, as expected. The p = 0 term is important and uses power_sums[K]. K = 0 would also work and would count all subarrays, though constraints have K >= 1.
- **Verification:** Sample 1 gives contributions 9, 17, and 49, totaling 75. Sample 2 gives 0 because all prefix sums are 0 and K > 0. The main pitfalls are updating power_sums before contribution and mishandling the zero-power term.
- **Alternative considered:** Maintaining moments of subarrays ending at each position is possible, but it requires O(K^2) per element. The prefix-sum binomial method is simpler and faster for this constraint.
