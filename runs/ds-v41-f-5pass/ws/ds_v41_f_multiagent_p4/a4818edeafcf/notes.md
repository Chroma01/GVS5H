- **Problem:** split A into three non-empty parts (i<j) maximizing distinct(L)+distinct(M)+distinct(R), N<=3e5.
- **Decomposition:** For fixed middle right end j, value(i) = pref[i] + distinct(A[i+1..j]) + suf[j+1]. pref and suf (distinct prefix/suffix counts) are O(N) precomputed with bytearray seen.
- **Key reformulation (simplifies everything):** For prefix A[1..j] let f_v = first occurrence, l_v = last occurrence (in prefix j), D = pref[j] = number of distinct values. Then pref[i] + distinct(A[i+1..j]) = D + C(i), where C(i) = #{v : f_v <= i < l_v}. Proof: value v contributes [f_v<=i] (to pref) + [l_v>i] (to middle) = 1 + [f_v<=i<l_v], since f_v<=l_v guarantees at least one holds.
- **Coverage maintenance:** C(i) is the overlap count of intervals [f_v, l_v-1]. On seeing value x=A[j] with previous occurrence p: if p=0 (new value) nothing changes for C, D+=1; if p>=1 the interval of x extends from [f_x, p-1] to [f_x, j-1], so add +1 on i in [p, j-1]. Equivalent to the original range-add idea but cleaner.
- **Query:** answer candidate = pref[j] + max_i C(i) + suf[j+1]. Since active C values are >=0 and untouched (future) leaves stay 0, global max over the whole tree equals max over active i in [1, j-1]; no range query or activation needed.
- **Segment tree trick:** range-add + global-max only. Use a lazy tree WITHOUT push: tag[k] and mx[k] with invariant mx[k]=tag[k]+max(mx[2k],mx[2k+1]); apply does mx+=f and tag+=f on canonical nodes; pull-up recomputes ancestors as tag[k]+max(children). Use ACL boundary conditions to pick ancestors. Global max is simply mx[1] (no push, O(1)).
- **Complexity:** O(N log N) time, O(N) memory. Steps with a brand-new value skip the range update entirely (fast for all-distinct input).
- **Indices:** i in [p, j-1] maps to leaves [p-1, j-1) (0-indexed i-1). Size = next power of two >= n. j loops 2..n-1; i=1..j-1 ensures all three parts non-empty.
- **Verified:** sample1 -> 5, sample2 -> 9; also hand-checked N=3 cases, [1,1,1]->3, [1,2,1,2]->4, [1,2,3,1]->4, [1,2,1,2,1,2]->6.
