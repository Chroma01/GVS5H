Reduce the problem to determining whether the minimum cost is 1, 2, 3, or impossible. Cost 1 occurs if some interval covers the whole range. Cost 2 can be achieved by exactly one of three configurations: two type-1 intervals whose union covers all, a type-2 interval contained in a type-1 interval, or two type-2 intervals with empty intersection. If none of these hold and M≥3, cost 3 is always achievable by using the interval with maximum L as type-2, the interval with minimum R as type-2, and any third interval as type-1. Otherwise, output -1. This yields an O(M log M) algorithm.
