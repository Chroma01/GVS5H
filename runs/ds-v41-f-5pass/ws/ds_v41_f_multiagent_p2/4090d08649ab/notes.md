- **Operation semantics:** Each operation can erase exactly a contiguous interval of values that are all currently present. Multiplicities are irrelevant. Therefore f(L,R) equals the number of maximal consecutive value-runs among the distinct values in A[L..R].
- **Equivalent formula:** f(L,R) = D(L,R) - P(L,R), where D is the number of distinct values in the subarray and P is the number of adjacent value pairs (v, v+1) such that both v and v+1 occur in the subarray.
- **Sweep state:** Process R from 1 to N. Maintain last[v] = latest occurrence position of value v before updating at R. Let x = A[R], px = last[x]. For fixed R, maintain total = sum_{L=1..R} f(L,R).
- **New distinct contribution:** For L in [px+1, R], x was absent from A[L..R-1] and becomes newly present. This adds +1 to each such L, contributing length R - px to the global total.
- **Adjacency cancellation:** For a neighbour y in {x-1, x+1} within [1,N], let py = last[y]. If py > px, then for L in [px+1, py], y is present before adding x, so x attaches to y and the run count decreases by 1. This subtracts length py - px from the global total. If py <= px, there is no such L.
- **No Fenwick needed:** Because only the global sum of all f(L,R) for the current R is needed, each range-add contributes delta * length directly to total. This gives O(1) work per element instead of O(log N). The code uses this simplification.
- **Complexity:** O(N) time, O(N) memory. Python integers safely handle the answer, which can exceed 64-bit in intermediate multiplications if using other formulas, though here it stays moderate.
- **Edge cases:** N=1 works. All-equal arrays give f=1 for every subarray. Strictly increasing/decreasing arrays give f=1 for every subarray. Values are guaranteed in [1,N], so neighbour checks x>1 and x<n are sufficient.
- **Validation:** The algorithm matches all three samples: 16, 23, 129. It also matches hand-checked small cases and the strict monotone/all-equal cases.
