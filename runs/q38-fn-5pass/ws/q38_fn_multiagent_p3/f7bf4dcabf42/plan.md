Model the LCS process between the fixed string S and a growing string T using the standard LCS DP row. Since N <= 10, represent the DP row by a bitmask of length N where bit i indicates whether LCS(S[:i+1], T) increases by 1 at position i. Precompute the transition for every mask and every lowercase character by reconstructing the DP row, appending the character, and recomputing the new mask. Then perform a length-M DP over these masks, adding 1 for each of the 26 possible characters, and finally sum counts by the popcount of the mask, which equals the LCS length.
