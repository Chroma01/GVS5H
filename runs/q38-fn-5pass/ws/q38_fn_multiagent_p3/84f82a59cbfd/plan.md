A 400 number is exactly a square of an integer whose prime factorization contains exactly two distinct primes, because all exponents must be even and positive. Since A is at most 10^12, the square root is at most 10^6, so we can precompute all integers up to 10^6 with exactly two distinct prime factors. For each query A, the answer is the square of the largest precomputed integer not exceeding floor(sqrt(A)). This reduces each query to an integer square root and a binary search over a sorted candidate list.
