Use dynamic programming over the number of subarrays and the ending index. Let `dp[j][r]` be the minimum cost to partition `nums[0..r]` into exactly `j` subarrays, with the last subarray ending at `r`. The transition is `dp[j][r] = min_{p < r} dp[j-1][p] + (prefixNums[r] + k*j) * (prefixCosts[r] - prefixCosts[p])`, which can be rewritten as a minimum of lines queried at increasing `x` values. Because prefix sums are nondecreasing, optimize each DP layer with a monotone convex hull trick, giving an overall `O(n^2)` solution. Use rolling arrays to keep memory linear, and take the minimum over all valid segment counts for the final answer.
