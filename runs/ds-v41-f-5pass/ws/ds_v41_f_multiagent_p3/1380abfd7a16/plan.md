Process the insertions in reverse because removing later insertions reveals the correct final position of each earlier value. Initialize N empty slots and place values from N down to 1: value i must occupy the P_i-th currently empty slot, since larger values already fixed in place cannot shift it further. Use a Fenwick tree or segment tree to support finding the k-th empty slot efficiently. This gives an O(N log N) solution suitable for N up to 5×10^5. Finally, extract the occupied slots left-to-right to form the answer.
