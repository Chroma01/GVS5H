A valid full coloring is exactly a top-left justified black region, so it can be represented by row black-prefix lengths r_1, r_2, ..., r_N with r_1 >= r_2 >= ... >= r_N. Each given black cell (x, y) imposes r_x >= y, and each given white cell (x, y) imposes r_x <= y - 1. For each constrained row, store the maximum black-column lower bound L_x and the minimum white-column upper bound U_x. Such a nonincreasing sequence exists iff for every row x, the maximum lower bound among rows x through N is at most U_x. Since only M rows are constrained, sort those rows and scan from bottom to top while maintaining the suffix maximum of L.
