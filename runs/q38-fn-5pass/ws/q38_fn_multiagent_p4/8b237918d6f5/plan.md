The answer is the largest D such that at most K edges can be chosen so that every directed path from 1 to N contains at least D chosen edges; if fewer than K are needed, the remaining edges can be chosen arbitrarily because increasing weights cannot shorten the shortest path. For a fixed D, use labels h(v) in {0,...,D} with h(1)=0, h(N)=D, and h(v)<=h(u)+1 for every edge u->v; selecting exactly the edges with h(v)=h(u)+1 certifies distance at least D, and any valid selection yields such labels from capped shortest distances. Therefore the minimum number of edges needed for D is the minimum number of +1 label transitions. This minimum can be computed as a min s-t cut in a layered graph with nodes (v,l) representing h(v)>=l: infinite edges enforce the unary conditions, monotonicity, and h(v)>=l => h(u)>=l-1, while capacity-1 edges (v,l)->(u,l) for each original edge u->v count transitions. Binary search D in [0, min(K,N-1)] and accept D when the min-cut value is <=K.
