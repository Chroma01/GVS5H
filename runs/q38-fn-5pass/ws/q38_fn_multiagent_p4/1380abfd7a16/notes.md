- **Core reduction:** Process insertions backwards. Once values `i+1, ..., N` have fixed final positions, deleting them leaves the array after operation `i`, where value `i` is exactly the `P_i`-th element. Therefore `i` must be placed in the `P_i`-th still-empty final position.
- **Fenwick tree:** Maintain `1` for empty final positions and `0` for filled positions. For `i = N, ..., 1`, find the position whose prefix sum is `P_i`, write `i` there, and add `-1` at that position.
- **Padded power-of-two tree:** Use `size = next power of two >= N`. Initialize the first `N` positions to `1` and build Fenwick nodes below `size`. Because queries start at `size/2`, the root at index `size` is never read; updates can stop before `size`. This removes bound checks and saves one loop iteration per query/update.
- **kth empty search:** With steps `size/2, size/4, ..., 1`, keep `idx = 0`. If `bit[idx + step] < k`, move `idx` and subtract that sum. After the loop, `pos = idx + 1`. This is valid because `k <= current empty count`, and zeros beyond `N` prevent selecting invalid positions.
- **Complexity:** `O(N log N)` time and `O(N)` memory. For `N = 5e5`, about 18 kth-search iterations and roughly 9 update iterations per element. Precomputing query steps and Fenwick ancestors reduces Python overhead.
- **Input/output:** Read all integers via `map` over split tokens, store `P` as a 1-indexed list, then free the token iterator. Store the answer 0-indexed and output with `join(map(str, ans))`.
- **Edge cases:** `N = 1` gives `size = 1`, an empty step list, and direct placement. `P_i = 1` chooses the first empty slot; `P_i = i` chooses the last empty slot. All positions are filled exactly once.
- **Pitfalls:** Off-by-one errors in kth search; using highest power `<= N` instead of padded size; forgetting to update padded ancestors below `size`; not freeing input tokens before allocating large arrays; naive list insertion is quadratic.
- **Alternatives:** Segment tree, implicit treap, sqrt decomposition, or block list can solve it, but reverse Fenwick reconstruction is shortest and fast enough.
