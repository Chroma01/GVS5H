Use the fact that a minimum-weight path with positive vertex weights is induced, and the disjoint-interval graph has no induced path on five vertices; hence any shortest path has at most three edges. For each query, if the two intervals are disjoint, the direct edge is always optimal. Otherwise, only two-edge paths through a common neighbor and three-edge paths through exclusive neighbors on the two sides of the overlapping pair can matter. Precompute minimum vertex weights by interval endpoints so these candidates can be queried quickly. Then answer each query by taking the minimum finite candidate, or -1 if none exists.
