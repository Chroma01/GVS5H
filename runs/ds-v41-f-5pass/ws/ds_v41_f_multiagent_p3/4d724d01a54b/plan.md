Model the optimal sorting process as left-to-right insertion: always resolving the leftmost adjacent inversion is equivalent to inserting each new element into the already sorted prefix. For an element at original position i, let c be the number of earlier elements larger than it; it must swap left across c positions, contributing the arithmetic sum of positions i-1, i-2, ..., i-c. Count c efficiently for every element using a Fenwick tree over values. Sum all contributions to get the minimum total cost in O(N log N). Validate the formula against samples and brute force on small permutations.
