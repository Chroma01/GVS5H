Reformulate each chosen pair as assigning both cakes to one of the three attributes that attains the pair price; then the problem becomes choosing exactly 2K cakes and coloring them X/Y/Z such that each color is used an even number of times, maximizing the sum of the chosen attribute values. For a fixed penalty λ per pair, double all attribute values and subtract λ from every selected cake; an 8-state parity DP over the color-count parities computes the best doubled adjusted value and, among ties, the maximum number of selected cakes. The optimal value as a function of K is concave (it is a maximum-weight matching cardinality value), so we can binary search the largest integer λ for which the tie-max selected count is at least 2K. Recover the answer as `(dp_value + λ * 2K) // 2`. This gives O(N log V) per test case with a small constant, where V ≤ 2·10^9.
