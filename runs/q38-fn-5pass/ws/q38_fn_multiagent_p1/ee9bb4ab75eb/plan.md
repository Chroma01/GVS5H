Build a trie over all words, storing for each prefix node the number of words that pass through it, its depth, and the terminal node for each input index. Use an Euler tour of the trie to answer in O(1) whether a prefix node is an ancestor of a given word's terminal node. For each removal, a prefix node remains usable by k strings iff its count minus one, when the removed word passes it, is at least k. Sort all nodes with count >= k by depth descending, then for each index scan this list until the first node satisfying that condition; its depth is the answer. If removing leaves fewer than k strings, answer 0; otherwise the root guarantees termination.
