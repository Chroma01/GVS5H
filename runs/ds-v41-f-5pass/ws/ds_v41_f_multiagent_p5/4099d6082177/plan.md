Model the decomposition as orienting/selecting edges so every vertex belongs to exactly one path of exactly K vertices, meaning each path component has K-1 internal edges and no extra incident selected edges. A useful characterization is that the tree can be split into paths of length K iff all components formed by removing a suitable set of edges have size K and are paths. Equivalently, this can be checked bottom-up by greedily growing path fragments from leaves and matching leftover lengths at branching vertices. Since NK is up to 2e5, an O(NK) tree DP or greedy leaf-pruning algorithm is required. The main challenge is to handle K=1 and large K correctly, and to detect impossible residue counts at internal nodes.
