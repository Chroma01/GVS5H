The key observation is that a 400 number is exactly the square of an integer whose prime factorization has exactly two distinct primes. Since A ≤ 10^12, the square root is at most 10^6, so we can precompute all bases up to 10^6 with exactly two distinct prime factors and square them. Sort the resulting 400 numbers once, then answer each query with binary search for the largest value not exceeding A. This gives O(10^6 log log 10^6 + Q log M) time and is easily fast enough.
