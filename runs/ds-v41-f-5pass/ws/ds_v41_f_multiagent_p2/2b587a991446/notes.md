- **Model:** state = ordered pair of distinct vertices; move one coordinate to an adjacent vertex keeping distinct. Answer = dist((S,T),(T,S)), else -1. Oracle = BFS over pairs (flat index a*base+b).
- **Reachability:** finite iff graph is not a simple path. A path (all degrees <= 2, tree) splits the configuration space so the swap is impossible -> -1. Any cycle or any degree>=3 vertex makes it reachable.
- **Two generator families (answer = min):**
  - CYCLE: min over cycle C, distinct p,q in C of `2*dS[p] + 2*dT[q] + |C|`. Interpretation: send A to p, B to q, swap around C (cost exactly |C|, one arc each), return. Validated on triangle/lollipop/dumbbell.
  - BRANCH: min over v with deg>=3 of `2*dS[v] + 2*dT[v] + extra`, extra in {2,4}.
- **Corrected BRANCH extra:** Let A_set = neighbours u of v with dS[u]=dS[v]-1 (shortest-path entry neighbours), B_set likewise for dT. extra=2 iff there exist n_S in A_set, n_T in B_set with n_S != n_T (a third neighbour is the siding). So extra=4 iff `v==S or v==T`, or (`cntS[v]==1 and cntT[v]==1 and s_entry[v]==t_entry[v]`). Equivalent clean test, avoids cut-vertex machinery. Example: v with arms x,y connected by a long path + leaf z, S=x,T=y -> extra 2 -> 6 (this beat the older "same component => 4" rule which gave a wrong larger value).
- **BRANCH sanity examples:** star centre, S,T leaves -> 2+2+2=6. S=centre star -> 0+2+4=6. S=1,T=2 on arm1 of v=3 (arms 4,5) -> same unique entry 2 -> extra4 -> 10. Path S-m-T-n-o with o(p,q) branch -> both entries n -> extra4 -> 16.
- **Efficient CYCLE term:** enumerate fundamental cycles of BFS trees rooted at S and at T (non-tree edges). For a non-tree edge (a,b), min d_root on its cycle is the LCA L (tree depths decrease by 1). Cost reduces to `cost1 = 2*mq + d[a]+d[b] + 1` and `cost2 = 2*d_other[L] + d[a]+d[b] + 3`, where mq = min d_other over the cycle excluding L. Compute LCA and mq in ONE O(log) lifting pass (accumulate `down` mins while aligning depths and while lifting both to children of L; remember to add the final two children explicitly). No need for depth[L] in the cost.
- **Small-n safety:** for n<=100 answer by exact config-BFS (brute), avoiding any formula risk on tiny tests.
- **m==n-1 (tree):** skip cycle terms; branch may still apply. Pure path -> -1.
- **Unverified:** whether BFS(S)/BFS(T) fundamental cycles always contain an optimal cycle on dense multi-chord graphs; the branch entry-set rule is hand-verified on several examples but not exhaustively.
