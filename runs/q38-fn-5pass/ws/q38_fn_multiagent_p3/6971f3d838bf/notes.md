- **Validation:** Checked the provided examples and brute-force reasoning for n=1, all equal, all non-positive, duplicates, frequency-one negatives, and mixed positive/negative arrays. No correctness failures were found. The segment-tree core is sound; the implementation was extended with safe fast paths for frequency-one deletions and non-positive arrays.
- **Baseline and non-negative deletions:** The no-operation answer is Kadane's maximum subarray sum. Deleting a non-negative value cannot improve the answer: any subarray after deleting x >= 0 maps back to a contiguous original interval by inserting the removed x values, which only increases or preserves the sum. Therefore only negative values need explicit evaluation.
- **Non-positive early return:** If max(nums) <= 0, every subarray sum is <= 0. Deleting negative values cannot create a positive sum, and if the maximum element is deleted the remaining maximum is no larger. Returning the baseline is exact.
- **Frequency-one negatives:** If a negative value occurs once at index i, deleting it is equivalent to deleting index i. The best resulting subarray is the maximum of: best subarray entirely left of i, best subarray entirely right of i, and a crossing subarray made from the best suffix ending exactly at i-1 plus the best prefix starting exactly at i+1. This is computed in linear time using end_at, pref_best, start_at, and a backward suffix-best scan.
- **Multi-occurrence negatives:** For negative values with frequency at least two, use an active/inactive segment tree. For a candidate value, deactivate all its occurrences; the root's best summary is the maximum subarray sum of the remaining concatenated sequence. Then reactivate the same indices. Values occurring in every position are skipped because deletion would make the array empty.
- **Segment tree summary:** Each node stores total sum, best non-empty prefix, best non-empty suffix, and best non-empty subarray. An active leaf is (v, v, v, v). An inactive leaf is the empty identity (0, NEG, NEG, NEG), which makes deleted positions disappear while preserving correct concatenation.
- **Combine rule:** For left L and right R: sum = L.sum + R.sum; pref = max(L.pref, L.sum + R.pref); suff = max(R.suff, R.sum + L.suff); best = max(L.best, R.best, L.suff + R.pref). The identity works correctly with negative values and never returns an empty subarray.
- **Complexity:** Baseline and single-deletion handling are O(n). The segment tree is built only when needed. Each occurrence of a multi-occurrence negative value is deactivated and reactivated once, giving O(m log n) time where m is the total number of such occurrences, worst-case O(n log n). Memory is O(n).
- **Edge cases:** n=1 returns the single element. All equal negative arrays return baseline because deletion is invalid. All-negative and all-zero arrays are covered by the early return. Empty gaps between deleted occurrences are handled by inactive identity nodes. NEG = -10**18 is safely below any real sum magnitude, whose bound is about 10**11.
