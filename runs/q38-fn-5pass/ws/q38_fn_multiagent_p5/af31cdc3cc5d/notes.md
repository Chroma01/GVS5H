- **Problem view:** A removal sequence is a non-crossing matching of original positions. If positions i<j are removed together, all positions between them were removed earlier in pairs, so j-i is odd. Thus every pair consumes one odd and one even original index.
- **Even segment optimum:** For an even contiguous segment of length 2k, each pair contributes one larger and one smaller element. Therefore the total is at most the sum of the k largest values minus the sum of the k smallest values. This bound is achievable: color the k largest values positive and the k smallest negative. While elements remain, equal positive/negative counts guarantee an adjacent opposite-color pair; remove it. Each removed pair has one positive and one negative, and all positives are at least all negatives, so the total reaches the bound. The internal order of an even segment does not matter.
- **Odd N:** Starting from odd length, exactly one element remains. Since each pair consumes one odd and one even original index, the remaining original index must be odd. If it is 2p+1, the left prefix has length 2p and the right suffix has length 2(m-p), where N=2m+1. These two even segments are independent, so the answer is max over p of value(prefix 2p) + value(suffix 2(m-p)).
- **Streaming half-sums:** For every even prefix/suffix we need sum of the largest half minus sum of the smallest half. Maintain a max-heap `low` for the smaller half and a min-heap `high` for the larger half, with `low` having one extra element when the processed count is odd. Keep actual sums of both heaps. Insert each value into the appropriate heap, rebalance to target sizes, and record `sum_high - sum_low` after every even count.
- **Suffix computation:** The value of an even segment depends only on its multiset, so suffix values are obtained by running the same streaming procedure on the reversed array. `suff[q]` becomes the optimum for the last `2q` elements.
- **Implementation details:** Store `pref[p]` for first `2p` elements and `suff[q]` for last `2q` elements, both length `m+1`. For even N, print `pref[N//2]`. For odd N, scan `pref[p] + suff[m-p]`. `vals[0]=0` handles empty prefix/suffix. Ties are harmless because equal values may be assigned to either half. Python integers safely hold answers up to about 1.5e14.
- **Complexity:** Each pass performs O(N) heap insertions and O(N) rebalancing moves, giving O(N log N) time and O(N) memory.
