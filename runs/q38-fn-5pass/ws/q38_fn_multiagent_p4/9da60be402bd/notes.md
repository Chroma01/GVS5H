- **State model:** A state `(u, v)` represents the shortest palindrome-labeled path from `u` to `v`. Every palindrome can be built outward from a center: empty path `(v, v)` of length 0, or a single edge `(u, v)` of length 1.
- **Expansion rule:** From a palindrome path `u -> ... -> v`, if there are edges `x -> u` and `v -> y` with the same label, then `x -> ... -> y` is a palindrome with length increased by 2. Because the graph is directed, the left side uses incoming edges to the current left vertex, while the right side uses outgoing edges from the current right vertex.
- **Parity separation:** All expansions add cost 2, so even and odd lengths form independent BFS layers. Even BFS starts from all `(v, v)` at distance 0. Odd BFS starts from all labeled edges at distance 1.
- **Independent visited sets:** `visited` is maintained separately for even and odd parity. A pair may need to be processed in both parities even if its global shortest distance was already found in the other parity, because outgoing transitions preserve parity.
- **Self-loops:** A self-loop creates an odd source `(v, v)` even though the answer for `(v, v)` remains 0. It must still be included in the odd frontier to generate odd-length palindromes centered at that self-loop.
- **Bitset representation:** For each left vertex `u`, frontier and visited sets are Python integers whose bits represent right vertices. `succ[c][v]` is a bitmask of `y` such that `v -> y` has label `c`. `pred_info[u]` stores labels and incoming vertices `x` for edges `x -> u`.
- **Layer transition:** For current left `u` and right-bitset `B`, for each label `c` with incoming edges to `u`, compute `m = OR succ[c][v]` over all `v` in `B`. For each incoming `x`, add `m & ~visited[x]` to the next frontier of `x`.
- **Distance updates:** A flat `dist` array stores the global minimum over both parities. When a state is first reached in a parity, it is marked visited and enqueued even if the global distance is not improved, because it may still be needed for further states of that parity.
- **Complexity:** Each parity visits each pair at most once. The bitset OR work is `O(26 * N^2)` bit operations per parity. Scanning incoming lists is bounded by `O(N * E)` per parity, at most about `10^6` for `N = 100`, which is fast in Python.
- **Implementation details:** Input is parsed as bytes; `'-'` has code 45. Diagonal distances are initialized before edges so self-loops do not overwrite answer 0. Unreachable entries remain `INF` and are printed as `-1`.
