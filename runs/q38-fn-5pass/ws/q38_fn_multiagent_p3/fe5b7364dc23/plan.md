Use prefix sums: if S_j = A_1 + ... + A_j and S_0 = 0, then every subarray sum is S_r - S_{l-1}. Expand (S_r - S_i)^K by the binomial theorem, so the total sum can be computed by scanning prefixes from left to right while maintaining the sums of powers S_i^t for all previous prefixes i. For each new prefix S_j, add its contribution against all earlier prefixes using the stored power sums, then update those stored power sums with S_j. Since K <= 10, this gives an O(NK) solution modulo 998244353.
