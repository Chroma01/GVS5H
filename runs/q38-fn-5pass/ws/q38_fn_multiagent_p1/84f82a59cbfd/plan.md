A 400 number is exactly the square of an integer whose prime factorization contains exactly two distinct primes, because all prime exponents must be even. Since A ≤ 10^12, the square root is at most 10^6, so we can precompute every integer up to 10^6 with exactly two distinct prime factors and store their squares. Then each query can be answered by binary searching this sorted list for the largest square not exceeding A. This gives fast per-query time after a one-time sieve-like preprocessing step.
