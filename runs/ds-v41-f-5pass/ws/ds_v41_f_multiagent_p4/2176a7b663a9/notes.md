- **Core reduction:** Graph is the comparability graph of the interval order `i ≺ j ⇔ R_i < L_j`. Edge iff intervals are disjoint (`R_i < L_j` or `R_j < L_i`). Any path can be shortcut to length ≤3 using a subset of its vertices, so minimum-weight path is among length 1, 2, or 3.
- **Length 1:** Direct edge iff `R_s < L_t` or `R_t < L_s`; answer `W_s + W_t`.
- **Length 2:** For intersecting intervals `s,t`, a common neighbor `u` must be disjoint from both; because `s,t` intersect, `u` must lie entirely left of both or entirely right of both. Minimum weight = `min( prefR[min(L_s,L_t)], suffL[max(R_s,R_t)] )`, where `prefR[x] = min W_i with R_i < x` and `suffL[x] = min W_i with L_i > x`.
- **Length 3:** Only needed when intervals strictly cross: either `L_s < L_t and R_s < R_t` (and they intersect, so `L_t ≤ R_s`) or symmetric. For the first case, any valid middle pair must use `a` with `R_s < L_a ≤ R_t` and `b` with `L_s ≤ R_b < L_t`; they are automatically disjoint. Minimum extra weight = RMQ on `L` over `[R_s+1, R_t]` plus RMQ on `R` over `[L_s, L_t-1]`. Symmetric case swaps roles.
- **Containment cases:** If one interval contains the other, any neighbor of one is a common neighbor, so length 2 suffices (or no path exists). Length 3 never improves over length 2 because weights are positive.
- **Preprocessing:** Arrays `minL[val]`, `minR[val]` store minimum weight per endpoint value. Prefix minima on `R` and suffix minima on `L` give O(1) length-2 queries. Iterative segment trees over `minL` and `minR` answer range-min for length-3 in O(log N).
- **Complexity:** O((N + Q) log N) time, O(N) memory. N, Q ≤ 2×10^5, coordinates ≤ 2N.
- **Edge cases:** Ranges may be empty (handle `l > r` returning INF). Intermediate vertices are guaranteed distinct from endpoints and from each other by range construction. If no path, output -1.
