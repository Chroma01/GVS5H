- **Problem model:** Directed functional graph edges i -> A_i with constraint x_i <= x_{A_i}. Every directed cycle forces all its nodes equal; non-cycle nodes form rooted in-trees hanging off cycle nodes.
- **Cycle detection:** Compute indegree (number of children). Peel nodes with indegree 0 repeatedly; remaining nodes are exactly cycle nodes. Removed order is leaves-to-roots, suitable for bottom-up DP.
- **DP definition:** For non-cycle node v, dp_v[t] = number of valid assignments in v's subtree (excluding ancestors) with x_v = t. Then dp_v[t] = product over non-cycle children c of sum_{s=1}^t dp_c[s]. Leaves have dp_v[t] = 1.
- **Accumulator trick:** Store acc[v] = product over already-processed children c of prefixsum(dp_c)[t]. Initially None (all ones). Process removed nodes in peel order: dp_u is acc[u] (or all ones). Compute prefix of dp_u and merge into acc[parent] by elementwise multiplication. If parent acc is None, assign the prefix array directly; else multiply in place. This uses one O(M) loop per non-cycle node and avoids extra prefix arrays.
- **Cycle handling:** For cycle node v, acc[v] after all non-cycle processing equals f_v[t] = product over its non-cycle children of prefixsum(dp_c)[t] (or all ones). For a directed cycle, all nodes share value t, so contribution is S[t] = product_{v in cycle} f_v[t]. Sum S[t] for t=1..M, multiply this cycle sum across all cycles. Use first non-None acc as running product and free arrays as processed.
- **Complexity:** O(NM) time, since each non-cycle node and each cycle node with attached trees contributes O(M), total ≤ 2NM. Memory O(NM) worst but peak ~N/2 arrays of length M due to lazy freeing, safe for N,M ≤ 2025.
- **Edge cases:** Self-loops (cycle length 1) work; multiple cycles are independent and their sums multiply. M=1 works. Input A_i are 1-indexed. All arithmetic mod 998244353. Prefix sums use s += arr[t]; if s >= MOD: s -= MOD (since s, arr[t] < MOD). Leaf prefix is list(range(M+1)) (valid because M < MOD).
