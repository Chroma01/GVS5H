Compute the minimax distance f(x, y) via a Kruskal reconstruction tree: sort edges by weight and merge DSU components, creating an internal node whose weight is the edge weight at which the two components first connect. In this tree, f(x, y) equals the weight of the LCA of leaves x and y, so the cost function becomes an ultrametric. For the bipartite matching between the multiset A and the multiset B, process the tree bottom-up: each leaf stores counts of A and B, and each internal node matches as many opposite-color unmatched points as possible at its own weight, carrying only the surplus color upward. This greedy is optimal because any pair not matched inside a child subtree must be matched across that subtree boundary and therefore pays at least the current node weight, while all such cross pairs have exactly that cost. The accumulated cost after processing the root is the minimum possible sum.
