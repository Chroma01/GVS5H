- **Core condition:** For a fixed middle value x, let t be the number of x's among the four side elements. The middle is the unique mode exactly when t >= 2, or t == 1 and the three non-x side values are pairwise distinct. t == 0 is never valid.
- **Sweep state:** Coordinate-compress values. Sweep the middle index. Maintain left frequencies for indices before the middle and right frequencies for indices after it. Maintain dupL and dupR as sums of C(freq, 2) on each side. Initialize right with all elements; for each middle, remove it from right, process, then add it to left. Frequency updates adjust dup by the old or new frequency.
- **Side pair categories:** For a side with length S and fx occurrences of x, nonx = S - fx. The numbers of side pairs containing 0, 1, or 2 x's are C(nonx, 2), fx * nonx, and C(fx, 2). Use L0,L1,L2 and R0,R1,R2 for left and right.
- **At least two side x's:** These cases are always valid. Count them as L2 * (R0 + R1 + R2) + L1 * (R1 + R2) + L0 * R2.
- **Exactly one side x:** If the left pair has one x and the right pair has zero x, multiply by Lx. For each non-x value y on the left, the right pair must be a distinct-value non-x pair not containing y. If D2R is the number of distinct-value non-x pairs on the right, the count for y is D2R - right[y] * (Rnx - right[y]). Sum over y != x. The symmetric right-one-x term uses Rx and D2L.
- **Distinct-pair helper:** For a side excluding x, D2 = C(nonx, 2) - (dup - C(fx, 2)). This removes duplicate pairs among non-x values from all non-x pairs.
- **Complexity:** The inner sum scans compressed values for each middle index, giving O(n * m) <= O(n^2) time for n <= 1000 and O(m) memory. Exact integer arithmetic is used; only the answer is reduced modulo 1e9 + 7.
- **Pitfalls:** The exactly-one-x terms need the Lx and Rx multipliers. Zero-x side pairs must be distinct-value pairs in the t == 1 case. Exclude x from the non-x duplicate sums. The right side length is n - mid - 1 after removing the current middle, and the left side length is mid before adding it.
- **Validation:** Added brute_force, which enumerates all index combinations of size 5 and checks that the middle value's frequency is strictly greater than every other frequency. run_tests asserts the three provided examples, several deterministic small cases, and random small arrays with lengths 5 to 12 and small positive or negative value ranges. It also includes large all-same and all-distinct sanity checks, using the all-same answer C(n, 5) modulo 1e9 + 7. The tests are guarded by the main module check, so importing Solution does not run them.
- **Current status:** The sweep implementation passed the added brute-force validation in the intended test harness; no algorithmic changes were needed.
