- **Core reduction:** Split `p` into `A`, `B`, `C` around the two `*`. A matching substring is exactly a span containing the non-empty literal blocks in order without overlap; empty blocks are ignored. If all blocks are empty, answer is `0`; if one block remains, answer is its length if it occurs.
- **Occurrence finding:** KMP finds all start positions for each distinct non-empty block in `O(|s| + |block|)`. Occurrence lists are sorted and include overlaps. Repeated blocks are cached.
- **Lower bound:** If total literal length exceeds `|s|`, return `-1` because literal blocks cannot overlap.
- **Two-block cases:** For remaining blocks `P0`, `P1`, scan starts of `P1` while maintaining the latest `P0` start whose end is `<=` the current `P1` start. Candidate length is `start1 + len1 - last0`. This covers `A*B*`, `A**C`, and `*B*C`.
- **Three-block case:** Scan starts of `B`. Maintain the latest `A` start ending before the current `B` start, and the earliest `C` start at or after the current `B` end. Because `B` starts and ends are nondecreasing, both pointers move forward. Candidate length is `startC + lenC - startA`.
- **Empty-block handling:** If `A` is empty, an optimal substring starts at `B` (or at `C` if `B` is empty). If `C` is empty, it ends at `B` (or at `A` if `B` is empty). Dropping optional prefix/suffix matched by stars only shortens the substring, so spans between first and last non-empty blocks are sufficient.
- **Overlap rule:** Non-overlap uses `end <= start`, allowing adjacent blocks but forbidding shared characters. Examples: `a**a` does not match `"a"`, and `ab**bc` does not match `"abc"`.
- **Validation:** Samples pass: `ba*c*ce` -> `8`, `cc*baa*adb` -> `-1`, `**` -> `0`, `*adlogi*` -> `6`. Edge cases checked include all-empty pattern, single non-empty block, missing occurrence, reversed order, adjacent blocks, overlapping blocks, repeated blocks using the same occurrence list, and total literal length greater than `s`.
- **Optimality:** For a fixed middle/second block, the latest previous block and earliest next block minimize the span; scanning every occurrence of the middle/second block considers every possible optimal placement. Early exit when answer equals the sum of block lengths is safe because that is the global lower bound.
- **Complexity:** At most three KMP scans and linear passes over occurrence lists. Time is `O(|s| + |p|)`, memory is `O(|s| + |p| + occurrences)`.
