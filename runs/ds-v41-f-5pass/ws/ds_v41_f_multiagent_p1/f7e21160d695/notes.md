- **Core reduction:** f(x,y) is the bottleneck (minimax) path value. In a connected undirected graph it equals the max edge weight on the x-y path of any MST, and equals the smallest threshold t such that x and y are connected using only edges of weight <= t. Classically: f(x,y) = weight of the merge in Kruskal's algorithm at which x and y first land in the same component = LCA-weight in the Kruskal reconstruction (merge) tree. It is an ultrametric: f(x,z) <= max(f(x,y), f(y,z)). It is NOT a sum of weights.
- **Assignment structure:** K can be 2e5 so O(K^3) Hungarian assignment is impossible. The merge tree is monotone (parent weight >= child weight), so any pair's LCA is at weight <= the weight at which either member would meet an outsider. Therefore greedily pairing as many A-B items as possible at the deepest (cheapest) merge and pushing only the unmatched surplus upward yields an optimum; any optimal permutation can be transformed into this form with no cost increase. Answer = sum over merges of (merge weight) * (new A-B pairs formed there).
- **Algorithm (Approach A, implemented):** sort edges ascending by weight; DSU where each root stores `sA` (unmatched A-items) and `sB` (unmatched B-items) accumulated from A/B vertex multiplicities. On union of roots L,R at weight w, form `pairs = min(sA_L, sB_R) + min(sA_R, sB_L)`, add `w * pairs`, then new surpluses `sA = sA_L + sA_R - pairs`, `sB = sB_L + sB_R - pairs`.
- **Invariant:** after each merge a component's surplus is one-sided (only A's or only B's). This makes the pairwise min formula valid; the simpler `min(totalA, totalB)` also works under the invariant but the explicit form is safe.
- **Pitfalls:** A_i != B_j for all i,j, so no self-pair f(x,x)=0 arises, but duplicates within A and within B are allowed -> track integer multiplicities, never booleans/sets. Skip edges joining already-connected roots (avoids double counting). Equal weights: any tie order gives the same total since every merge at that weight costs the same and the number of pairs formed there is invariant. 64-bit magnitude <= 2e5 * 1e9 = 2e14 fits Python ints trivially. At the end (graph connected) both surpluses are zero since |A|=|B|=K (final consistency check, not needed for output).
