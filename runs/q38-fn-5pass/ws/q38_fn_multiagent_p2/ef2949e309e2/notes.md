- **Problem reduction:** For a fixed middle index with value x, choose two positions left and two right. Let k be the number of chosen side elements equal to x. The middle value is the unique mode iff k >= 2, or k == 1 and the three non-x chosen side values are pairwise distinct. k == 0 is never valid.
- **Sweep state:** Coordinate-compress values. Sweep the middle index left to right. Before processing index i, remove nums[i] from the right frequency map; after processing, add it to the left. Maintain left/right lengths, frequencies, and sum of squared frequencies for each side.
- **Pair categories:** For a side of length N with f occurrences of x, the number of pairs with 0, 1, 2 copies of x are C(N-f,2), f*(N-f), and C(f,2). All choices with left copies a and right copies b satisfying a+b >= 2 are valid and are added directly.
- **k == 1 counting:** If the left side supplies the only x, sum over y != x: left_x * left_y * D_right_excluding(x,y), where D_right_excluding(x,y) is the number of right pairs with two distinct values, neither x nor y. The symmetric term is added when the right side supplies the only x.
- **Distinct-pair formula:** For a side, let M be the number of non-x elements and totalD = (M^2 - (sumsq - f[x]^2)) // 2, the number of pairs of distinct non-x values. Excluding an additional value y subtracts f[y] * (M - f[y]), leaving totalD - f[y] * (M - f[y]).
- **Complexity:** There are n middle positions and at most n distinct values, so the two auxiliary loops give O(n^2) worst-case time and O(n) memory, easily within n <= 1000.
- **Edge cases:** Positions with fewer than two elements on either side are skipped. All-equal arrays are counted through the two-copy pair products. All-distinct arrays contribute zero because the middle value never appears on the sides. Negative values are handled by compression.
- **Implementation details:** Precompute C2 values, use exact integer arithmetic for combinatorial counts, and reduce the answer modulo 10^9+7 after each middle index. The right frequency of x used for processing is the count after removing the current middle element.
