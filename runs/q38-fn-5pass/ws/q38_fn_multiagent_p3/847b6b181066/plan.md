Model each smoke particle by the prefix displacement of the wind at its generation time. If P[t] is the cumulative wind displacement after t steps, then a particle generated at time g is at P[t] - P[g] at time t+0.5, so it is at (R,C) exactly when P[g] = P[t] - (R,C). A particle exists for any prefix position that has appeared before the current time, so we can scan left to right while maintaining the set of prefix positions seen so far. For each t, check whether P[t] - (R,C) is already in the set, then insert P[t] for future times. This gives an O(N) time and O(N) memory solution.
