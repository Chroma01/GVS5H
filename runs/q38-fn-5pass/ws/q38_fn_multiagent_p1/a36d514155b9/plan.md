Count the contribution of each unordered pair of cells across all valid arrangements: any fixed pair of cells is occupied together in exactly C(m*n - 2, k - 2) arrangements. The total Manhattan distance over all cell pairs separates into independent row and column contributions. For a 1D length L, the sum of distances over all coordinate pairs is L*(L^2 - 1)/6, so multiply the row contribution by n^2 and the column contribution by m^2. Compute the binomial coefficient modulo 10^9 + 7 using factorials and modular inverses, then multiply it by the total geometric pair-distance sum modulo 10^9 + 7.
