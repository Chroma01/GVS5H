- **Reduction:** path edges i->i+1 plus one back edge white->black per pair. Strongly connected iff every cut x in [1,2N-1] has a pair with black b<=x<white w, i.e. intervals [b,w-1] (only when w>b) cover [1,2N-1]. Requires S1='B' and S_{2N}='W', else 0.
- **Permutation form:** blacks b_1<...<b_N, whites w_1<...<w_N, matching = bijection pi (black k -> white pi(k)). Condition is M_k=max(pi(1..k)) > q_k for k=1..N-1, where q_k = #whites before b_{k+1} = b_{k+1}-1-k. q nondecreasing; only run starts (q_l>q_{l-1}) bind, since M_k nondecreasing makes the smallest k of a plateau hardest. Keep run starts with q_l>=l; others auto (M_l>=l>q_l).
- **Inclusion-exclusion:** for subset T={j_1<...<j_t}, #{pi: M_{L_{j_a}}<=V_{j_a} for all a} = (N-L_{j_t})! * prod_a (V_{j_a}-L_{j_{a-1}})!/(V_{j_a}-L_{j_a})!, L_0=0. Hence answer = sum_j e[j]*(N-L_j)!, with e[0]=1, e[j]=-invfact[V_j-L_j]*sum_{i<j} e[i]*fact[V_j-L_i]. Online convolution; CDQ divide-and-conquer.
- **CDQ add:** left [lo,i1], right [j0,j1]; M=L_lo, A[L_i-M]=e[i], b0=V_{j0}-L_{i1}, F[t]=fact[b0+t], Flen=V_{j1}-b0-L_lo+1; then acc[j]+=conv[V_j-M-b0]. All indices in range (b0>=1). Per level A/F spans are disjoint => O(N) per level, O(N log^2 N) total.
- **Validation:** samples checked by hand. Sample1 (N=2) ->1; sample2 fails S_{2N}='B' ->0; sample3: q=[2,3,3,3,5,6,6,8], kept L=[1,2,5,6,8], V=[2,3,5,6,8], giving e=[1,-2,-2,-60,-372,-27696] and answer sum e[j]*(9-L_j)! = 240792. Alternating S gives 1,3,13,71 (A001865-like), consistent.
- **Convolution backends:** la/lb ==1 scalar; numpy direct (split into 15-bit halves, 4 np.convolve, exact int64) when la*lb<=2^18; else numpy NTT with cached vectorized rev/root tables (int64, products<2^60). Fallback without numpy: python direct (<=2e5) else Kronecker with 10-byte limbs (max coeff<2^78). Numpy assumed present on the judge.
- **Tuning:** SMALL=32 leaf threshold (leaf cost ~m*SMALL/2 python ops). Numpy direct covers small nodes to cut NTT call count; NTT reserved for large nodes. Peak memory from rev/root caches ~ tens of MB. These thresholds are estimates, not benchmarked here.
- **Brute force:** kept for N<=8 using reversed-graph BFS from vertex 0 (any u reaches 0 via path-back edges, so 0 reaching all <=> strongly connected). Main path handles N>=9.
