- **Reachable structure:** The operation preserves the order of pieces and never increases the gap between consecutive pieces; once two pieces coincide they move together forever. Final configs are obtained by partitioning the K initial pieces into M consecutive blocks, block t sent to target b[t].
- **Validity:** Assignment valid iff every block-boundary gap is preserved correctly: for boundary piece index r (last piece of block t), need g_r = p[r+1]-p[r] >= b[t+1]-b[t]; internal gaps only shrink (h=0). This is exactly D_{j+1} <= D_j, so D_j = q_j - p_j is non-increasing.
- **Key fact (T0):** Since D is non-increasing, max_j |D_j| = max(D_1, -D_K) = max(b[0]-p[0], p[K-1]-b[M-1]) = T0, independent of the assignment. So T0 is the displacement lower bound for every valid assignment. If T0 < 0, no assignment exists (endpoints would force D to be non-monotone).
- **Exact min-T model:** Each step has sign pattern (+prefix, optional one 0, -suffix). Let R_j,L_j,Z_j count right/left/stay moves; R_j-L_j=D_j, R_j+L_j+Z_j=T. With z_j=Z_j (parity z_j ≡ T+D_j mod 2) the only binding constraints reduce to z_j+z_{j+1} <= Δ_j (Δ_j = gap j total reduction). Ends give automatic constraints (because D_1 >= 1-p_1 and D_K <= N-p_K).
- **Consequence:** Only gaps with Δ_j = 0 (block boundary where g_r == Bgap) force a parity condition T ≡ D_r (mod 2). Δ_j=1 is self-consistent; Δ_j>=2 is free. Hence answer ∈ {T0, T0+1, -1}: T=T0 if some valid assignment has every equality-boundary parity ≡ T0 mod 2, else T0+1 if some has all ≡ (T0+1) mod 2, else -1.
- **Greedy:** Process boundaries left to right, choosing the smallest feasible boundary index r (largest room left). A candidate r is valid if g_r > bg (strict, no parity), or g_r == bg with (b[t]-p[r]) parity == target. Each r must satisfy r <= cap_t = K-M+t and r > previous. Position scan is amortized O(K+M).
- **Edge cases:** K<M -> -1. M==1 -> no boundaries, answer T0. T0<0 -> -1. If K>M then T0=0 impossible (greedy fails).
- **Samples:** verified three samples (3, -1, 5) plus counterexample p=[1,2,4] b=[2,4] gives T0+1=2 (matching-parity equality at boundary), and a merge example p=[1,2,10] b=[1,2] gives 8.
- **Complexity:** O(sum N) total.
