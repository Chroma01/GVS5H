Group foods by vitamin type and, for each vitamin, run a 0/1 knapsack DP over calorie capacity `X` to compute the maximum amount of that vitamin achievable within each calorie budget. Since foods for different vitamins are independent, a target value `T` is feasible iff the minimum calories needed to obtain at least `T` of vitamin 1, vitamin 2, and vitamin 3 sum to at most `X`. Binary search the maximum feasible `T`, using the precomputed DP arrays to test feasibility quickly. The DP precomputation costs `O(NX)`, and each feasibility check costs `O(X)`.
