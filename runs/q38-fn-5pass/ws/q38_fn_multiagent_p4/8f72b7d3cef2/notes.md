- **Core structure:** Build a max Cartesian tree with inorder equal to the original array. Use a monotonic stack and pop only while `A[stack[-1]] < A[i]`. For each node `v`, its subtree is a contiguous interval `I_v`, all values in `I_v` are `<= A[v]`, and `S[v]` is the sum of that interval.
- **Initial move:** If slime `i` has no original adjacent slime strictly smaller than `A[i]`, it cannot make the first move, so the answer is `A[i]`. If it has such a neighbor, that neighbor lies inside `I_i`; after absorbing it, Takahashi's size becomes `> A[i]`, and every remaining slime in `I_i` is `<= A[i]`, so the whole subtree `I_i` can be absorbed.
- **Climbing ancestors:** After absorbing `I_v`, the current size is `S[v]`. The parent `p` is adjacent. If `S[v] > A[p]`, absorb `p`; then the size is `> A[p]`, so the rest of `p`'s subtree (all values `<= A[p]`) can also be absorbed, reaching `S[p]`. If `S[v] <= A[p]`, `p` cannot be absorbed. Any other adjacent outside slime is an ancestor with value at least `A[p]`, so it is also impossible. Therefore reachable ancestors are exactly those connected by passable edges `child -> parent` where `S[child] > A[parent]`.
- **Answer formula:** For a movable start `i`, the maximum final size is `S[top[i]]`, where `top[i]` is the highest ancestor reachable through passable edges. For a non-movable start, the answer is `A[i]`.
- **Implementation:** Build `left` and `right` arrays without storing parents. The root is `stack[0]` after construction. Generate an iterative DFS order, compute subtree sums in reversed order, then propagate `top` from root to children. Use strict inequalities everywhere: initial absorption needs `<`, and climbing needs `S[child] > A[parent]`.
- **Pitfalls:** Equal values are barriers unless the side sum strictly exceeds them. A node that cannot move initially must not inherit an ancestor's sum even if descendants can pass through it. Positive sizes are essential for the "one absorption makes size > A[i]" argument. Avoid recursion because the Cartesian tree can be a chain of length `N`.
- **Complexity:** Time `O(N)`, memory `O(N)`. Python integers handle sums up to `5e14`.
