Represent the orientation of each cycle edge by a binary variable \(a_i\), so the cycle indegree at vertex \(i\) is \(1+a_i-a_{i-1}\). If \(s_i=1\), the spoke contributes an additional \(x_i\in\{0,1\}\) to vertex \(i\); otherwise \(x_i=0\). The center indegree is then forced by the prefix sum, since \(\sum_{i=0}^{N-1} d_i = N+\sum x_i\), so distinct full sequences are in bijection with distinct feasible prefixes \((d_0,\ldots,d_{N-1})\). For each position, view \((a_{i-1}\to a_i)\) as a labeled transition on two states, and count distinct label strings whose composed relation contains a diagonal pair. This gives an \(O(N)\)-time, \(O(1)\)-memory DP over at most 16 relations modulo 998244353.
