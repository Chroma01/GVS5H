The sequence B at step k is A with every value shifted by k modulo M. Instead of recomputing each k, maintain the inversion count as k increases by 1; only pairs involving the current value M-1 change their relative order. Precompute, for each value v, the net change when all occurrences of v are the M-1 entries and then wrap to 0. Compute the k=0 inversion count once using a Fenwick tree over values, then apply these precomputed changes in the correct cyclic order for k=1..M-1. This yields an O(N log M + M) solution, safe for 2e5.
