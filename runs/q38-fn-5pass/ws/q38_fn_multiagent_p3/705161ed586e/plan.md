Model the final string as a sequence of runs, each run having length at least 3, and use dynamic programming over the processed prefix. Keep states by the current run character and capped run length category: 1, 2, or at least 3. For each new position, update only these states in O(26) time using direct transitions and the best previous length-3 states for starting a new run. To handle the lexicographically smallest tie, maintain a rank for each reachable state representing the lexicographic order of its best prefix, and break equal-cost transitions by the smallest parent rank. Store compact parent pointers for reconstruction, then choose the minimum-cost valid final state with the smallest rank.
