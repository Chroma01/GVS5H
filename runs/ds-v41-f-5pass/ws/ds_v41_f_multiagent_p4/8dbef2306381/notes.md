- **Model:** bad squares are a union of given intervals; merge touching (L = prev_R+1) or overlapping ones into maximal bad blocks. Square 1 and N are always good by constraints (L_i>1, R_i<N).
- **Window DP:** B≤20, so track reachability of the last B squares as a bitmask (bit 0 = current square). On a good square the next bit is 1 iff mask has a set bit in band = bits [A-1,B-1] (jump length i ⇒ predecessor at distance i-1); on bad squares the new bit is forced 0. Update: mask = ((mask<<1)|bit) & full.
- **Barrier:** a maximal bad block of length ≥ B is impassable. Best case is jumping B from its left neighbour L-1, landing at L+B-1 < R+1. Return No. Merging is essential: [2,2],[3,3],[4,4] with B=3 is uncrossable only after merging to [2,4].
- **Fixed jumps A==B:** path forced to 1,1+A,…,N. Feasible iff A | (N-1) and no forced square 1+kA lies in a bad block (k ≤ K-1).
- **Saturation / fast-forward (A<B):** on an all-good stretch every non-zero mask reaches full within A²-A+B-1 steps. Reason: let q be the largest reachable point; with k0=ceil((A-1)/(B-A)) the reachable set contains q+k0·A onward contiguously, so the window [x-B+1,x] is filled once x ≥ q+k0·A+B-1. full is a fixed point, 0 is absorbing. Threshold T=A²+B+5 is provably ≥ the bound, so a gap ≥ T can jump straight to full.
- **Complexity:** O(M·T) time, O(M) memory; M≤2e4, T≤~400 ⇒ ≤ ~9e6 simple ops.
- **Zero mask:** once mask becomes 0 it stays 0 ⇒ return No.
- **A=1:** band = full, so any non-zero mask immediately generates/monotone-grows; still correct under the same code path.
- **Edge cases verified by hand:** M=0; N=2 (needs A=1); interval starting at L=2 (zero-length leading gap); adjacent vs one-good-square-separated blocks; length exactly B-1 (passable) vs B (barrier); A==B with bad squares on/off the arithmetic path; all three provided samples (Yes/No/Yes traced step-by-step through the mask).
- **Stress test:** an independent O(N) reachability-array brute force plus a randomized generator (small N, random A≤B, random sorted non-overlapping bad intervals incl. adjacency, length B-1/B, boundary/tail blocks, A==B, A==1) was prepared. Manual tracing of the samples and of the tricky merged-block, fixed-jump, and threshold-gap cases produced no mismatch; the saturation bound is proved, so no counterexample is expected. (This environment cannot execute the harness; verification is by exhaustive reasoning and hand traces.)
- **Potential risk:** none found in logic; only constant-factor speed of the inner loop, which is small relative to the limit.
