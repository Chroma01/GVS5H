We model the target as a sequence of runs, each of length at least 3, and use dynamic programming from right to left. The DP state is (index i, current run character c, current run length l capped at 3), storing the minimum cost to complete the suffix. To reduce memory and time, we only store states where l=3, and derive states for l=1,2 on the fly, achieving O(n*26) time and O(n*26) memory. After computing minimal cost, we reconstruct the lexicographically smallest caption by greedily picking the smallest character at each position that still allows an optimal-cost completion. If the minimal cost is infinity (only possible when n<3), we return an empty string.
