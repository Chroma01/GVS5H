- **Core reduction:** Build a trie of all word occurrences. Each trie node represents a prefix and stores how many occurrences pass through it. After deleting one occurrence, only nodes on that occurrence's root-to-terminal path decrease by one. The answer for that deletion is the deepest node whose adjusted count is at least k.
- **Count categories:** A node with original count greater than k remains valid for every deletion. A node with count exactly k is valid only when the deleted occurrence is not in its subtree. Nodes with count less than k are never valid. Therefore each answer is the maximum of a global deepest count>k node and the deepest count==k node whose interval does not contain the deleted occurrence's position.
- **DFS intervals:** Assign each occurrence a DFS position by traversing the trie and emitting terminal occurrences at a node before its children. Then every node's subtree corresponds to a contiguous interval [l, r]. A node is on the deleted word's path exactly when the deleted occurrence's position lies inside that interval.
- **Offline sweeps:** For every node with count == k, record its interval and depth. For a position p, intervals not containing p are exactly those ending before p or starting after p. Bucket maximum depth by interval end and by interval start. A prefix sweep over ends gives the best left interval for each p; a suffix sweep over starts gives the best right interval for each p. Combine these with the global count>k maximum.
- **Implementation details:** Return zeros immediately when n <= k. Use one global transition dictionary keyed by node * 26 + character index to avoid creating a dictionary per trie node. Store children using first_child and next_sibling arrays. Store terminal occurrences as linked lists using term_head and term_next. Use iterative DFS to avoid recursion-depth issues. During DFS, term_next is overwritten with each occurrence's DFS position, so it later serves as the position array for final answers. start_max and end_max are converted in place into right-best and left-best arrays.
- **Edge cases checked:** n == k returns all zeros. k == 1 returns the maximum remaining word length, including prefix/extension cases. Duplicate words are separate occurrences linked at the same terminal node. Words that are prefixes of other words are emitted before descendants, so descendant intervals correctly exclude ancestor-terminal occurrences. The root has count n and contributes only depth 0 when n > k. Chain cases with terminals at every depth, branching cases, and count==k intervals on both sides of a deleted position behave correctly.
- **Verification:** Manual checks of both samples and key edge cases pass with the current implementation; no failing case was found, so the solution is retained unchanged.
- **Complexity:** Time is O(total characters + n). Memory is O(total characters + n).
