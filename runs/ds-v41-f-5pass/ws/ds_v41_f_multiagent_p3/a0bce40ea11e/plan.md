Use the fact that summing monomials over F_p^* kills any term where a zero-entry variable has exponent not divisible by p-1. For p>2, this means each zero edge in a length-p walk is used either 0 or p-1 times, and at most one zero edge can be used p-1 times. Thus the answer is (-1)^K times (F^p + C), where F keeps only originally nonzero entries and C collects walks with exactly one zero edge used p-1 times and one fixed edge. p=2 is special because F_2^*={1}, so replace all zeros by 1 and compute the matrix square directly.
