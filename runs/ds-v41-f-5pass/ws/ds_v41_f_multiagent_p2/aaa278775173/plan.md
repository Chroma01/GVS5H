Use dynamic programming over the grid with a small constant number of directional/turn states. For each cell, track the best valid V-shaped segment ending there, including whether the single clockwise 90-degree turn has already been used. Since the value sequence is 1, 2, 0, 2, 0, ..., the required value at each step depends only on the current length parity. Transitions come from the previous diagonal neighbor, or from a previous diagonal neighbor followed by a clockwise turn. The answer is the maximum length over all valid states, with special handling for length 1 at any cell containing 1.
