The key is to reduce stair usage to a maximum-bottleneck path problem: free walkways mean an optimal route can be viewed as moving at some floor level through buildings of height at least that level. Let M be the maximum possible minimum building height along any path between the start and target cells. Then the answer is |Y-Z| if M >= min(Y,Z), otherwise Y+Z-2M. Compute M for all cell pairs by building a maximum spanning tree of the grid graph where adjacent cells have edge weight min(F[u],F[v]), then answering path-minimum queries on this tree. Use Kruskal descending for the MST and binary lifting with LCA for O(log(HW)) per query.
