Treat each XOR constraint as a weighted edge and use a parity DSU to accumulate each vertex’s XOR offset relative to its component root. A contradiction in any DSU merge means no solution exists. Once consistent, process each connected component independently: for every bit, choosing the root bit determines all other bits in that component, and the optimal choice minimizes the number of 1s. Assign the optimal root value per component and derive all vertex values using the stored offsets.
