- **Problem model:** Answer A[i][j] = length of shortest path i->j whose label string is a palindrome (empty string counts, so A[i][i]=0; no path => -1). Paths may repeat vertices/edges, lengths unbounded.
- **Key reduction:** A palindrome is built by matching letters from both ends toward a centre. The centre is either a vertex (even length) or an edge (odd length). Encode the "currently unmatched inner segment" as the ordered pair of vertices (u,v) bounding a palindromic path from u to v. Distance of state (u,v) = shortest palindromic path u->v.
- **Transitions:** From (u,v) at distance d, for each letter c take any incoming c-edge x->u and any outgoing c-edge v->y; then x -> (inner) -> y has label c + (palindrome) + c, still a palindrome, length d+2. Relax (x,y) to d+2.
- **Initialisation:** dist[i][i]=0 for all i (empty centre); dist[u][v]=1 for every edge u->v (single-letter centre). BFS processes level 0 then level 1 then levels of step 2.
- **Correctness of single visit per state:** Each state only needs its *minimum* distance. If a longer inner palindrome were needed as an intermediate, replacing it with the shortest one still yields a valid palindrome and a shorter total path, so expanding each state once at its BFS distance is optimal.
- **Complexity:** Naive expansion is sum_c E_c^2 <= E^2 = 10^8 transitions, too slow in Python. Optimise by storing label-indexed neighbour sets as bitmasks: in_mask[c][u] (x's) and out_mask[c][v] (y's). For each popped (u,v) and letter c, OR the outgoing mask Y into every row x in X, discovering new states via Y & ~visited[x]. This reduces inner work to sum over popped states of indeg(u) <= N*E = 10^6 small big-int operations; each state is extracted once.

- **Pitfalls handled:** self-loops (u->u keeps dist 0, not 1); diagonal always 0; BFS ordering (all level-0 seeds enqueued before level-1 seeds, then step-2 growth preserves monotonic level order).
