Treat the final rating as a function of the initial rating X. This function is always nondecreasing, and for each contest the set of initial ratings whose current rating lies in [L_i, R_i] is therefore a contiguous interval. Process contests in order while maintaining the current rating for every possible initial rating 1..500000 in a lazy segment tree. For each contest, use the segment tree to find the first position with value at least L_i and the last position with value at most R_i; if this interval is nonempty, add 1 to it. After all contests, answer each query by reading the stored value at X.
