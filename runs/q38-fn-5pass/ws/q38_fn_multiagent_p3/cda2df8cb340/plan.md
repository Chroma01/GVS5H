Compute the sum over ordered pairs first, then convert it to the required `i <= j` sum. For each power of two `m = 2^t`, define `H_t` as the sum of `(a+b)/m` over ordered pairs with `m | (a+b)`. If a pair has `v2(a+b)=r`, its contribution to `H_0 - sum_{t>=1} H_t` is `(a+b) - (a+b)/2 - ... - (a+b)/2^r = f(a+b)`, so the ordered answer is `H_0 - sum_{t>=1} H_t`. Compute each `H_t` by grouping values by residue modulo `m`, storing count and value-sum per residue, and using `H_t = (1/m) * sum_r (c_r*s_{-r} + s_r*c_{-r})`. Use bit masks for powers of two and only iterate `t` up to `floor(log2(2*max(A)))`, giving `O(N log A)` time and `O(N)` memory. Finally add the diagonal correction `sum_i f(A_i)` and divide by 2.
