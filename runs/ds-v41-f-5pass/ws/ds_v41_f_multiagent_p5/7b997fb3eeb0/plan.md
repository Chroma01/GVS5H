Exploit that the mochi sizes are already sorted. Precompute for each index i the first index nxt[i] whose value is at least 2*A_i, then define h[i] = nxt[i] - i. For a query [L, R] with length m, the answer K is the largest k ≤ m/2 such that max h over [L, L+k-1] + k ≤ m. Because this condition is monotone in k, answer each query by binary searching k and using a sparse table for O(1) range maximum queries. Overall complexity is O((N+Q) log N), which fits the constraints.
