For p=2, there is only one completion (all zeros become 1), so directly square that matrix modulo 2. For odd p, write each completion as A + Σ x_e E_e and expand the p-th power; summing x_e over F_p^* kills all terms except A^p and terms where exactly one zero position appears p−1 times and the remaining factor is A. This gives answer = (-1)^K (A^p + corrections) modulo p, where corrections are simple: for a diagonal zero (i,i), add column i and row i of A; for an off-diagonal zero, only p=3 contributes, adding A_{j,i} to position (i,j). Compute A^p by binary exponentiation modulo p, accumulate corrections in O(N^2), apply the parity sign, and print.
