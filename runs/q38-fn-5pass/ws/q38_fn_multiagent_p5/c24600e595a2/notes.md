- **Flip classification:** For each index, an optimal sequence uses: exactly one flip for mismatches (1->0 negative, 0->1 positive), no flips for equal 0, and either zero or one off/on pair for equal 1. Extra pairs can be deleted: they either add positive-cost operations or make the index 1 during some interval, never reducing any operation cost.
- **Canonical order:** For fixed temporary pairs, each flip has delta -C or +C. Swapping adjacent independent flips with deltas d1,d2 changes total cost by d1-d2, so sort by increasing delta: all negative flips before all positive flips; negative flips by decreasing C; positive flips by increasing C. Temporary off/on precedence is automatically satisfied.
- **Marginal insertion formula:** For current canonical sequence S, let n be number of negative flips and S_N their sum. For candidate temporary weight c, let x,X be count/sum of negative flips with weight > c, and y,Y count/sum of positive flips with weight < c. Inserting off before jobs <=c and on before jobs >=c gives delta = 2*W0 - X - S_N + Y - c*(1+n-x+y). New off cost is W0-X-c, new on cost is W0-S_N+Y, and c reduces the weight of L=n-x+y old operations between the insertions.
- **Prefix property:** For fixed S, if u>v then delta(u) <= delta(v). Let A be negative weights in (v,u] and B positive weights in [v,u). Then delta(u)-delta(v)=sum(A)+sum(B)-(u-v)M_v-u(|A|+|B|) <= -(u-v)M_v < 0, where M_v=1+n-x_v+y_v>0. Thus replacing a selected smaller equal-1 weight by an unselected larger one never increases cost, so an optimal temporary set is a prefix of equal-1 weights sorted decreasingly.
- **Efficient prefix scan:** Sort R descending, P ascending, E descending. Base cost is canonical cost with no temporary pairs. While scanning equal-C groups of E, maintain: r_ptr/r_gt_sum for R weights > c; p_ptr/p_lt_sum for P weights < c; group_sum/i for previous E groups, all strictly greater than c. For the first pair in a group, x=r_ptr+i, X=r_gt_sum+group_sum, Y=p_lt_sum, y=p_ptr, S_N=sumR+group_sum, n=r+i. This simplifies the first delta to 2*W0 - (r_gt_sum+group_sum) - sumR - group_sum + p_lt_sum - c*(1+r-r_ptr+p_ptr).
- **Equal-C group update:** Within one equal-C group, each additional pair increases S_N by c and increases n-x by 1, while X,Y,x,y unchanged. Therefore the marginal delta decreases by exactly 2*c for each additional pair. Update cost and answer for every prefix size.
- **Complexities and edge cases:** O(N log N) time due to sorting, O(N) memory. Python integers handle the maximum answer. If A=B, base answer is 0 and temporary prefixes only increase cost. Ties are handled by strict >/< queries and group processing; equal weights are interchangeable.
