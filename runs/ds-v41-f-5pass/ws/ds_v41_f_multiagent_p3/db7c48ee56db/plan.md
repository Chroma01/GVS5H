Use the constraint C(N,K)≤10^6 by enumerating all K-subsets only when K is small; otherwise set M=N-K and enumerate excluded M-subsets, combining each excluded XOR with the total XOR of all elements. A DFS over increasing indices maintains the current XOR, so each generated subset is evaluated in O(1) additional work. Since M=min(K,N-K)≤N/2, the search tree size is bounded by roughly (M+1)·C(N,M)≤about 2×10^7 in the worst case. Track the maximum XOR found and handle M=0 as choosing all elements.
