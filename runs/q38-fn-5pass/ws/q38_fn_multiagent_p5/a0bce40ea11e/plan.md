Work over F_p and let K be the number of zero entries; for p>2, expanding (A+sum x_k E_k)^p and summing x_k over F_p^* shows that only monomials with each variable exponent 0 or p-1 survive. Since the word length is p, this leaves only the all-A term and terms where exactly one zero-position elementary matrix appears p-1 times and A appears once, all with common coefficient (-1)^K. For p=2 there is only one completion, where every zero becomes 1, so compute B^2 directly. The one-variable contribution is A E_{ii}+E_{ii}A for a diagonal zero, and for p=3 an off-diagonal zero contributes E_{rc} A E_{rc}=A_{cr}E_{rc}; for p>3 off-diagonal zeros contribute nothing. Thus compute A^p modulo p by fast matrix exponentiation, add these sparse contributions, multiply by (-1)^K modulo p, and print.
