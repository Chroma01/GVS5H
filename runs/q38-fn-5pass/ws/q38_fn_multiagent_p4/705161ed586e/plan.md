Use dynamic programming over the suffix with a state that records the current run character and its length capped at 3, because a run may only be ended after at least three consecutive equal characters. Compute the minimum remaining operation cost from every position and state backwards; while the current run length is 1 or 2 the next character is forced to be the same, and at length 3 we may either continue the same character or start a new run. Optimize the length-3 transition by precomputing the best and second-best values for starting each possible new character, giving O(26n) time. Store all DP layers in compact integer arrays so the optimal cost can be reconstructed greedily. Finally, build the answer left to right by choosing the smallest character that keeps the total cost equal to the DP optimum, which yields the lexicographically smallest minimum-cost caption; return an empty string when n < 3 or no optimal state is reachable.
