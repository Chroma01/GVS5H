We exploit that edges connect intervals with empty intersection, so G is a co-interval graph. Any shortest path in such a graph is chordless and has at most 3 edges, so only direct, length-2, and length-3 candidates matter. For overlapping endpoints, length-2 uses one interval disjoint from both, while length-3 only needs two intervals on opposite sides. Precompute prefix minima over right endpoints and suffix minima over left endpoints to get the cheapest interval entirely left or right of any position. Each query can then be answered in O(1) by combining these precomputed values, outputting -1 if no candidate path exists.
