For any fixed common sum H, the total grinding cost is sum_i(U_i+D_i) - N*H, independent of the individual final upper lengths, provided each tooth can be adjusted feasibly. Thus the objective is to maximize feasible H up to min_i(U_i+D_i). For a candidate H, tooth i allows final upper length in [max(0,H-D_i), min(U_i,H)], and the adjacent constraint can be checked by maintaining the feasible range of possible current upper lengths. Feasibility is monotone in H, so binary search the largest feasible integer H. Finally compute the answer using 64-bit integers.
