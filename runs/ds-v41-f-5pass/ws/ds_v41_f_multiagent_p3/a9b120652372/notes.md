- **Movement model:** Choosing pivot i moves every piece one step toward i; relative order is preserved, pairwise distances never increase, pieces merge but never split. Reaching occupancy exactly B means partitioning A's 1-positions a[0..k-1] into m consecutive nonempty groups, group q collapsing onto square b[q].
- **Gap necessity:** A boundary between groups q and q+1 at token r needs a[r+1]-a[r] >= b[q+1]-b[q] (tokens cannot cross). Equality ("frozen") forces those two tokens to move in lockstep forever; strict inequality leaves slack.
- **Displacements are monotone:** d_t = b[group(t)] - a[t] is non-increasing. Within a group it strictly decreases; across a boundary d_{r+1}-d_r = (b[q+1]-b[q]) - (a[r+1]-a[r]) <= 0. So for every gap-valid partition max_t|d_t| = max(|b[0]-a[0]|, |b[m-1]-a[k-1]|) =: Lb, independent of the partition. Thus window width and the answer depend only on Lb, and check(X,mode) is constant for X >= Lb (no new partitions appear).
- **Frozen-boundary parity:** At a frozen boundary the pivot can never lie in [token_r, token_{r+1}], so both tokens move every operation in the same direction; net displacement d satisfies d ≡ (#ops) mod 2. Two frozen boundaries with different displacement parity are contradictory => unschedulable for every T. Use `(b[q]-a[r]) & 1` to get the residue mod 2 even for negative values.
- **Answer:** Lb if check(Lb, Lb&1); else Lb+1 if check(Lb, 1-(Lb&1)); else -1. Since check is constant for X >= Lb and parity only matters mod 2, no T > Lb+1 can ever be needed or help.
- **check(X,mode) greedy:** Left-to-right over the m-1 boundaries. Keep L = first token index of the current group (always chosen minimal) and track windows [b[q]-X, b[q]+X] with monotone pointers i_low/j_high. For boundary q choose the smallest token r in [max(L, Low_{q+1}-1), min(High_q, High_{q+1}-1, k-m+q)] with a[r+1]-a[r] >= gap_q and, if equal, parity (b[q]-a[r])&1 == mode (mode < 0 forbids frozen). The k-m+q cap guarantees enough tokens remain for later groups.
- **Greedy optimality:** Exchange argument: if a feasible solution uses boundary r' >= r (greedy's smallest), replacing r' by r keeps every shifted token inside b[q+1]'s window (since r' >= Low_{q+1}-1 and r' <= High_{q+1}-1), leaves the neighbouring boundaries unchanged, and gap/parity hold at r by construction. Hence greedy L never exceeds any feasible L. Final acceptance: L >= Low_{m-1} and High_{m-1} >= k-1.
- **Quick rejects:** m > k or span(A) < span(B) => -1, before any indexing that assumes both lists nonempty.
- **Verification:** Exhaustive BFS over occupied-square subsets matched the solver for all (A,B) with N<=9 plus random N=10..14. Targeted frozen-parity cases (e.g. A={1,2,10} -> B={3,4,7}, answer 4=Lb+1) and Lb/Lb+1 boundary cases matched. Samples produce 3, -1, 5 (test1 passes check(3,1); test2 m>k; test3 check(5,1)).
- **Complexity/memory:** O(sum N) time, O(N) memory; at most two check passes per test. T up to 2e5, sum N up to 1e6 — comfortable in Python.
