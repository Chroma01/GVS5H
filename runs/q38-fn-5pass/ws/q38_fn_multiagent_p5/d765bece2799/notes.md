- **Validation:** The provided examples produce 20 and -6. Manual brute-force comparisons were checked for all-equal arrays, duplicate minima/maxima, negative values, mixed signs, `k = 1`, `k = n`, and small mixed cases. No failing case was found, so the current monotonic-stack contribution solution is retained.
- **Chosen approach:** Use contribution decomposition. Compute the sum of minima over all subarrays of length at most `k`, then compute the sum of maxima by applying the same routine to the negated array. The final answer is `sum_min(nums) - sum_min([-x for x in nums])`.
- **Unique assignment:** For minima, assign each subarray to its rightmost minimum. This is achieved by using previous strictly less and next less-or-equal boundaries. For maxima, negating the array makes the same routine assign each subarray to its rightmost maximum.
- **Boundary construction:** `prev_less` is computed left-to-right with a monotonic stack, popping elements `>=` current. `next_less_equal` is computed right-to-left, popping elements `>` current. These boundaries define the maximal interval where the current element is the chosen minimum.
- **Bounded contribution count:** For index `i`, let `left_span = i - prev_less[i]` and `right_span = next_less_equal[i] - i`. A subarray assigned to `i` chooses `a` elements to the left and `b` elements to the right, with `0 <= a < left_span`, `0 <= b < right_span`, and length `a + b + 1 <= k`, so `a + b <= k - 1`.
- **Closed-form pair count:** `count_pairs` counts rectangle points clipped by a diagonal. If `limit >= left_span + right_span - 2`, all pairs are valid. Otherwise, sum over valid `a` values. For small `a`, all `right_span` choices are valid; for the remaining `a`, the number of valid `b` values is `limit - a + 1`, summed arithmetically.
- **Complexity:** Each `sum_min` call does three linear passes plus stack operations, so two calls are `O(n)` time and `O(n)` memory. This fits `n = 80000` comfortably.
- **Edge cases:** `k = 1` counts only singletons. `k = n` degenerates to the classic unbounded sum of subarray minima. Duplicates are handled by strict/non-strict boundary tie-breaking. Negative values are fine because counts are nonnegative and values are multiplied directly.
- **Pitfalls:** Off-by-one errors in boundary definitions, using `a + b <= k` instead of `k - 1`, inconsistent duplicate tie-breaking, and integer division in the arithmetic-series sum. The implementation avoids these by using `limit = k - 1` and a generic clipped-pair formula.
- **Implementation status:** The current code is correct under the validated cases and remains the submitted solution.
