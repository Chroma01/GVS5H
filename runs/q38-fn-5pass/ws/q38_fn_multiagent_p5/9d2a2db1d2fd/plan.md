The key observation is that horizontal movement at floor x is possible exactly within connected components of cells with F >= x, and these components only merge as x decreases. For two cells, let B be the highest floor at which they are connected, i.e. the maximum bottleneck height of a path between them; then the optimal stair count is abs(Y-Z) if min(Y,Z) <= B, otherwise Y+Z-2*B. Thus each query reduces to a bottleneck connectivity query on the grid. Build a maximum spanning tree, or equivalently a Kruskal reconstruction tree, using edge weight min(F_u, F_v), so B for any pair is the value of their LCA in the reconstruction tree. Preprocess LCA with binary lifting and answer all queries in O(log N) after O(HW log HW) preprocessing.
