Use prefix sums to convert each subarray sum into a difference of two prefix values: subarray l..r equals P_r - P_{l-1}. Then the required answer is sum over all pairs i<j of (P_j - P_i)^K. Since K <= 10, expand each pair term using the binomial theorem and process j left-to-right, maintaining only the first K power sums of previous prefix values. This gives an O(N K) or O(N K^2) solution, easily within limits.
