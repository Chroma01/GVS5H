Classify each pair by the exact power of two dividing its sum. For a fixed `t`, a pair contributes `f(A_i+A_j) = (A_i+A_j)/2^t` exactly when `A_i + A_j ≡ 2^t (mod 2^{t+1})`. Since `A_i <= 10^7`, the maximum pair sum is `2*10^7`, so only `t` up to about `24` need to be considered. For each `t`, group elements by residue modulo `2^{t+1}`, storing both the count and the sum of original values for each residue. Then sum all unordered pair sums whose residues complement to `2^t`, handling same-residue pairs separately, and add that total divided by `2^t` to the answer. This yields an `O(N log max(A))` time and `O(N)` memory solution.
