- **Mapping condition:** Scan all pairs `(S_i, T_i)`. Each original letter that appears in `S` may require only one final letter. If one letter in `S` maps to two different letters in `T`, transformation is impossible and the answer is `-1`.
- **Graph construction:** Consider only letters appearing in `S` as active vertices. For every active letter `c` whose required target `d` is different from `c`, add one unique directed edge `c -> d`. Self-mappings are not edges. `E` is the number of unique non-self edges, i.e. the number of active source letters that must be used as the left side of an operation at least once.
- **Indegree:** Indegree counts unique incoming non-self edges from active letters. Multiple occurrences of the same source letter must not increase indegree, because they correspond to one operation source and one token class.
- **Cycle detection:** Prune active vertices with indegree `0` using Kahn's algorithm. The remaining active vertices are exactly the vertices of nontrivial directed cycles. Keep a copy of the original indegrees before pruning.
- **Closed cycles:** A cycle is closed iff every vertex in it has original indegree exactly `1`, meaning its only incoming edge is from its predecessor inside the cycle. Closed cycles are the only cycles that force one extra operation each.
- **Acyclic parts:** Acyclic components can be resolved in exactly `E` operations by processing edges from sinks backward. Each required source letter is used once.
- **Non-closed cycles:** A cycle with an incoming tree edge is not closed and needs no extra operation. The cycle predecessor and the incoming node have the same final target, so moving the predecessor into the incoming node creates a usable hole while still using only the required source letters. The cycle and its trees can then be rotated within `E` operations.
- **Closed cycles and buffer:** A closed cycle has no outside token whose final target lies in the cycle. To move any token in it, an empty label is necessary. Using an empty label requires one additional operation beyond the cycle's own edges, because the buffer label must be used again to move a cycle token to its final target. Each closed cycle needs its own `+1` because tokens from different cycles cannot be merged.
- **Buffer existence:** A buffer exists initially if some letter is absent from `S`. If all 26 letters appear in `S` but some letter is absent from `T`, the graph is not a permutation; it has an indegree-zero non-self node or tree that can be processed to create an empty label.
- **Impossibility:** If `S` and `T` both contain all 26 letters, the consistent mapping is a permutation. If it contains a nontrivial closed cycle, no empty label can ever be created, so the answer is `-1`. Otherwise the answer is `E + closed_cycles`.
- **Implementation details:** Use arrays of size 26. Ignore edges to inactive targets for cycle detection because inactive targets cannot be in cycles. Self-loop vertices are removed by pruning and are never counted as cycles. Complexity is `O(N + 26)` time and `O(1)` extra memory besides input.
- **Edge cases:** `S == T` gives `E = 0`, no cycles, answer `0`. A permutation with only self-loops is already solved. A permutation with a nontrivial cycle is impossible. Non-closed cycles do not add to the answer even when no letter is initially absent from `S`, provided an incoming edge exists.
