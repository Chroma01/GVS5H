- **Model:** The allowed points are the full rectangle `[0,W] x [0,H]` minus the closed forbidden rectangle `F = [L,R] x [D,U]`. Count all monotone paths in the full grid, then subtract exactly the paths that visit `F` at least once.
- **Total full-grid paths:** For a fixed endpoint `(x,y)`, paths from any start are `C(x+y+2, x+1)-1`. Summing over all endpoints gives `C(W+H+4, W+2) - (H+3) - (W+1)(H+2)`.
- **First forbidden point:** Any invalid path has a unique first forbidden point. If it starts inside `F`, it is counted by suffixes from that start. Otherwise the first forbidden point is entered either from below (`y=D`, previous point `(x,D-1)`) or from the left (`x=L`, previous point `(L-1,y)`). The bottom-left corner can be entered from either side, but the predecessor point is unique, so the two sums are disjoint.
- **Suffix sum:** From `(x,y)` to any endpoint in the full grid: `suffix(x,y) = C(W-x + H-y + 2, W-x+1) - 1`.
- **Prefix sums for entry:** From below to `(x,D-1)`: `C(x+D+1, x+1)-1`, valid only if `D>0`. From left to `(L-1,y)`: `C(L+y+1, L)-1`, valid only if `L>0`.
- **Starts inside forbidden rectangle:** Sum `suffix(x,y)` over all `(x,y) in F`. Transform `i=W-x`, `j=H-y`; then the summand is `C(i+j+2, i+1)-1`.
- **Rectangle binomial prefix:** Define `P(n,m) = sum_{0<=i<=n,0<=j<=m} C(i+j+2, i+1)`. Hockey-stick twice gives `P(n,m) = C(n+m+4, n+2) - n - m - 4`. Rectangle sums use inclusion-exclusion.
- **Boundary sums:** The bottom and left first-entry sums are over at most `W+1` and `H+1` points respectively, so direct looping is `O(W+H)`. Each term is computed from factorials. Accumulate products without taking modulo every iteration, then reduce at the end of each loop.
- **Edge cases:** If `D=0`, bottom entry is impossible. If `L=0`, left entry is impossible. If the forbidden rectangle touches the left and bottom boundaries, only paths starting inside it can be invalid. If the whole grid is forbidden, total and invalid are equal and the answer is zero. Length-zero paths are included naturally.
- **Complexity:** Precomputing factorials and inverse factorials up to `W+H+4` costs `O(W+H)` time and memory. The remaining boundary loops are also `O(W+H)`, feasible for `W,H <= 10^6`.
- **Verification:** Sample 1 manually gives total `431`, invalid `239`, answer `192`. Sample 3 has forbidden rectangle touching left and bottom, so invalid paths are exactly those starting inside it, matching the intended structure.
