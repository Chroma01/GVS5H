The core reduction is that f(L,R) equals the number of maximal contiguous intervals of distinct values present in A[L..R]. Equivalently, count each value v that appears in the subarray while v-1 does not. Therefore, the total answer is the sum over v of the number of subarrays containing at least one v and no v-1. For each v, use the positions of v-1 to split the array into allowed segments, then count subarrays in those segments that contain v. Processing all v independently with precomputed position lists yields an O(N) or O(N log N) solution.
