Use the fact that the mochi sizes are already sorted. For a target number of pairs K, the best possible choice is to use the K smallest mochi as top mochi and the K largest mochi as bottom mochi, pairing them in sorted order. Then K is feasible if and only if every paired top satisfies `2 * A[i] <= A[N - K + i]`. Binary search the maximum feasible K from 0 to N//2 using this feasibility check. This gives an efficient O(N log N) solution, which is easily fast enough for N up to 5e5.
