First reduce the problem to a small bitmask DP because `target.length <= 4`. Deduplicate `target` values, since one multiple of a value satisfies all duplicate entries. For every subset of target values, compute the LCM of that subset, which is the value a single `nums` element must be incremented to in order to satisfy all targets in the subset. For each `nums` element, compute the cost to make it a multiple of each subset LCM, then run a DP over covered target masks to choose which elements cover which subsets. The answer is the minimum cost to cover all target masks.
