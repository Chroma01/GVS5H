- **Potential model:** Let `P_v` be the prefix sum of road strengths up to town `v`. A person from `S` to `T` has stamina `P_v - P_S` when moving right and `P_S - P_v` when moving left. After normalizing to `[l, r]` (`l < r`), a `+` interval (`S=l`) requires `P_l = P_r` and `P_v > P_l` for all `l < v < r`. A `-` interval (`S=r`) requires `P_l = P_r` and `P_v < P_l` for all `l < v < r`.
- **Exact forbidden pairwise patterns:** A set is feasible iff:
  1. No two intervals have the same left endpoint.
  2. No two intervals have the same right endpoint.
  3. No two intervals of the same type cross: there are no `l_i < l_j < r_i < r_j` or `l_j < l_i < r_j < r_i` with the same type.
- **Necessity of duplicate endpoints:** If two intervals share left endpoint `l`, say `[l, r]` and `[l, s]` with `r < s`, the first forces `P_r = P_l`, while the second forces `P_r > P_l` for `+` or `P_r < P_l` for `-`, contradiction. The same argument applies to shared right endpoints.
- **Necessity of same-type crossing:** For `+` intervals `[a, c]` and `[b, d]` with `a < b < c < d`, constraints give `P_b > P_a = P_c > P_b`, impossible. For `-` intervals the inequalities reverse and give the same contradiction.
- **Sufficiency idea:** Convert constraints to difference constraints with strict edges of weight 1 and equality edges of weight 0. Equality components are directed paths because each town is a left endpoint of at most one interval and a right endpoint of at most one interval, and all equality edges go from smaller to larger town. Under the three forbidden-pattern conditions, the contracted strict-edge graph is acyclic: any directed cycle would force either a duplicate endpoint or two same-type intervals to cross. Once acyclic, assign each component/town the longest-path distance from a super source. Strict edges then give integer gaps of at least 1, so all intermediate stamina values are positive integers.
- **Integer strictness:** The longest-path construction handles the fact that a non-endpoint town may need to lie strictly between two endpoint potentials. If a town is interior to both a `+` and a `-` interval, the graph has a path of length 2 from the `+` endpoint component to the `-` endpoint component, so the assigned potentials leave room for an integer value.
- **Sliding window:** Feasibility is hereditary, so compute `maxR[L]`, the maximum `R` such that people `L..R` are feasible. Maintain a feasible active window `[L, R]`. Try to extend `R`; when adding fails, record `maxR[L]`, remove `L`, and retry. Query `[L, R]` is feasible iff `R <= maxR[L]`.
- **Active-set checks:** Endpoint occupancy arrays detect duplicate left/right endpoints globally. For each type, a segment tree over left endpoints stores the corresponding right endpoints. When inserting `[l, r]` of type `t`:
  - Reject if `l` or `r` is already occupied.
  - For existing same-type intervals with `a < l`, crossing occurs iff `l < b < r`. Because active same-type intervals are laminar, it is enough to find the rightmost `a < l` with `b > l` and check whether its `b < r`.
  - For existing same-type intervals with `l < a < r`, crossing occurs iff `b > r`. Query the maximum stored `b` over left endpoints in `(l, r)` and reject if it is greater than `r`.
- **Segment tree operations:** Need point update, range maximum, and rightmost prefix search with value greater than a threshold. The prefix search walks from the leaf just before the prefix boundary upward, checking left siblings from right to left, then descends to the rightmost qualifying leaf.
- **Complexity:** `O((M + Q) + M log N)` time and `O(N + M + Q)` memory. With `N <= 4e5`, `M, Q <= 2e5`, this fits comfortably in Python with iterative segment trees.
