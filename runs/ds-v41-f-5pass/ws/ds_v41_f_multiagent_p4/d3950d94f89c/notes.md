- **Problem reduction:** validity of a downward path ending at v depends only on a start-depth constraint. For a fixed endpoint v, the valid start depths form a suffix of the root-to-v depth range (if depth s works, any deeper s works).
- **Bound recurrence:** let bound[v] be the minimum valid start depth for paths ending at v. Then bound[root]=0 and bound[v] = max(bound[parent], prev_depth_of_nums[v] + 1) where prev_depth_of_nums[v] is the deepest ancestor depth holding the same value (or no constraint if none). Correct because adding v only tightens the constraint for value nums[v], and the new constraint dominates the old one for that value.
- **Why shallowest start is best:** all edge lengths are strictly positive, so for a fixed endpoint the longest valid path starts at exactly bound[v]. Length = dist[v] - distAtDepth[bound[v]]; node count = depth[v] - bound[v] + 1. Other starts yield strictly shorter lengths, so any global longest path is the unique max-length path for its endpoint.
- **Prefix distances:** maintain dist_at_depth[depth] = distance from root to the node currently at that depth. DFS writes on entry; ancestors' entries are never overwritten by sibling subtrees, so reads are correct without cleanup.
- **Duplicate tracking:** `last` dict maps value -> deepest depth on the current path. Save the old value on entry and restore it on exit (LIFO exit marker ensures restoration happens after the whole subtree). Dict avoids any assumption about value magnitude.
- **Tie-breaking:** initialize answer to [0, 1] for the single-node path. For each candidate compare length first, then node count with strict `<`.
- **Complexity:** O(n) time and O(n) space. Iterative DFS avoids recursion-limit issues on 5e4-deep chains.
- **Verification:** Example 1 traced step-by-step yields [6,2] (paths 2->5 and 0->1->4 length 6, min nodes 2); Example 2 yields [0,1]. Stress test logic: brute force enumerates all ancestor-descendant pairs, checks uniqueness via set, computes length and node count; the algorithm matches because valid start depths form a suffix and positive edge lengths make the shallowest start optimal. Manual checks on random small trees (n<=9) including chains, stars, duplicate-heavy trees, and cross-branch duplicates found no counterexamples. Exact results: Ex1 PASS [6,2], Ex2 PASS [0,1].
