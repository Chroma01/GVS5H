Reduce the sum over all parent arrays to \((N-1)!\) times the expected distance in a uniformly random recursive tree. For a fixed query \((u,v)\), the distance is the sum of \(A_i\) over vertices \(i\) on the path except the LCA. The probability that edge \(i\)-parent lies on the \(u\)-\(v\) path has a simple piecewise rational form depending only on the relative order of \(i,u,v\). This allows rewriting each query answer as a constant-time combination of prefix sums of \(A_i/i\) and \(A_i(i-1)/(i(i+1))\). Precompute modular inverses, factorials, and these prefix sums modulo 998244353, then answer all queries in O(1).
