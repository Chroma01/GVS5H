Compute the minimum cost to make every length-x window equal, which is the sum of absolute deviations from the window median. Use a sliding-window median structure, such as two heaps with lazy deletion or a Fenwick tree over compressed values, to obtain all window costs in O(n log n). Then solve a weighted interval selection problem: choose k non-overlapping length-x windows with minimum total cost. Use dynamic programming over window end positions and number of selected windows, with recurrence dp[t][i] = min(dp[t][i-1], dp[t-1][i-x] + cost[start]). This gives an O(k n) DP after precomputing costs, which fits the constraints.
