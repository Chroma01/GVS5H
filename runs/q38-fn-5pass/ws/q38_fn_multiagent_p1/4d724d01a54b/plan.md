Process values from N down to 1. For the largest remaining value x, all smaller values must end to its left, so x only needs to move right to position x; its swaps are forced to occur at positions current_pos, current_pos+1, ..., x-1. Moving these swaps as early as possible cannot increase later costs because it shifts smaller elements left, so an optimal sequence can fix x first and recurse. After larger values are fixed, the current position of x is its rank among values <= x in the original permutation, which can be maintained with a Fenwick tree. Sum the arithmetic series for each x to get the minimum cost.
