Model the swap as moving both pieces to one “passing gadget” where they can exchange order, then moving them to the targets. The useful gadgets are exactly vertices of degree at least 3 and non-bridge biconnected components (cycles/2-connected blocks). Compute BFS distances from S and T, build the block-cut tree to identify the entry vertices of each gadget relative to the S-T path, and evaluate the minimum local passing cost for each gadget. Add twice the outside distances to each gadget candidate, take the minimum, and output -1 if no gadget exists (the graph is a path).
