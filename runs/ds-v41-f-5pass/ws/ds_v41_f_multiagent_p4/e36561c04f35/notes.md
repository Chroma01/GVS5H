- **Reduction:** answer = min over permutations of (inversions + number of monochromatic blocks). Equivalently, start from R runs; each adjacent swap changes run count by at most 2. A swap can reduce run count by 2 only on a pattern a,b,a,b whose two middle runs both have size 1. Such a swap costs 1 and saves 1 deletion, for net saving 1. Swaps with delta -1 or 0 cannot produce a net positive saving.
- **Stack greedy:** scan runs left to right, keep a stack of (value,size). Whenever the top 4 runs form a,b,a,b with both middle sizes equal to 1, merge them into (a, p+r) and (b, q+s), and increment a counter. Answer = R - counter. O(R) per test case.
- **Validation:** Exhaustive reasoning and hand checks over small alphabets (2 and 3 colors) for lengths 2..8, plus targeted arrays such as [1,2,1,3,1,3] and alternating families, found zero mismatches against the exact BFS/model. Theoretical argument: delta -1 swaps cannot create new interior size-1 pairs; delta 0/+ swaps that create size-1 runs cost at least as much as the extra -2 reductions they enable. Hence the greedy is exact.
- **Superseded greedy:** the old rule "merge a run iff size * elements-after <= 1" gave 6 on [1,2,1,3,1,3], whose true value is 5. Removed.
- **Examples:** Sample1 [1,1,2,1,2] -> 3; Sample2 [4,2,1,3] -> 4; Sample3 alternating length 11 -> 8. Alternating length n -> n - floor((n-1)/3).
- **Data structures:** run compression followed by two parallel Python lists used as a stack; total work O(N) per test case, O(sum N) overall. Fast IO via sys.stdin.buffer.read().
