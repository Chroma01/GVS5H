Removing all occurrences of x is equivalent to setting every element equal to x to 0; only x < 0 can ever help. For a fixed x, the answer is the maximum subarray sum of the modified array, which equals max over original ranges [u,v] of (prefix[v+1]-prefix[u]) - x*(count_x(u,v)). Split the array at occurrences of x into maximal non-x blocks; the best result either lies in one block (captured by ordinary Kadane) or spans two blocks, so compute each block's sum, best prefix, and best suffix, then run a linear DP over the block sequence. Use prefix sums plus a range-max/range-min structure to obtain block prefix/suffix in logarithmic time, giving O(n log n) overall. Take the maximum over all negative values present and over doing nothing.
