- **Model:** Let horizontal edge variable be whether the shared edge has a line endpoint, and similarly for vertical edges. For a cell, Type A requires exactly one horizontal and one vertical endpoint: `L xor R = 1`, `U xor D = 1`. Type B requires opposite pairs: `L xor R = 0`, `U xor D = 0`, and `L xor U = 1` to exclude the empty/all-four cases.
- **Row/column reduction:** Along each row, horizontal edge differences are forced: A toggles, B does not. Around the toroidal row cycle this is solvable iff the row has even A parity. Then all horizontal edges in the row are determined by one free row bit. Similarly, each column needs even A parity, giving one free column bit per column.
- **Prefix parameterization:** If row bit is the left edge of column 0 and column bit is the top edge of row 0, then for cell `(i,j)`, left edge is `row_bit[i] xor prefixA_left(i,j)`, and top edge is `col_bit[j] xor prefixA_above(i,j)`.
- **B equations:** Every B cell gives one xor equation between its row bit and column bit: `row_bit[i] xor col_bit[j] = 1 xor prefixA_left xor prefixA_above`. A cells impose no cross equation beyond the row/column parity conditions.
- **Counting:** The B equations form a bipartite xor system on H row variables and W column variables. A consistent system has `2^(number of connected components)` assignments. Use a parity DSU; each successful merge reduces component count, and a contradiction gives answer 0.
- **Implementation flow:** Read all tokens. For each case, check row A parity using `bytes.count`. If any row is odd, answer 0. If there are no A cells, answer 2. If there are no B cells, all cells are A; answer `2^(H+W)` iff H is even, else 0. Otherwise process the grid once with a parity DSU.
- **One-pass mixed processing:** Maintain `row_pref` for A parity to the left and `col_pref[j]` for A parity above the current row. For a B cell, union row node `i` and column node `H+j` with label `1 xor row_pref xor col_pref[j]`. For an A cell, toggle `row_pref` and `col_pref[j]`. After all rows, `col_pref` is exactly the final column parity; if any entry is 1, answer 0.
- **DSU details:** `parent[root]` stores negative component size; non-root stores parent index. `diff[x]` stores xor from `x` to its parent. `find` returns root and xor from node to root, with iterative path compression. `union(x,y,w)` enforces `value[x] xor value[y] = w`. When merging roots, the child root's diff is `w xor parity_x xor parity_y`.
- **Shortcuts:** All-B always has exactly two valid placements (all horizontal or all vertical). All-A has no B equations; after row parity (W even), column parity is valid iff H is even, and then every row/column bit is free.
- **Complexity:** Total time is `O(sum HW * alpha(H+W))`, with small constants. Memory is `O(H+W)` per mixed case plus input storage; total `H+W` over cases is at most `sum HW` because `H,W >= 2`.
- **Pitfalls:** Prefixes must exclude the current cell. Wrap-around parity is essential. Isolated row/column variables still contribute a factor of 2. The B equation label must include both left and above prefix parities. Early DSU inconsistency can stop processing because the answer is already 0.
- **Verification:** Sample 1 gives one DSU component and answer 2; sample 2 fails row parity and gives 0; sample 3 gives one component and answer 2.
