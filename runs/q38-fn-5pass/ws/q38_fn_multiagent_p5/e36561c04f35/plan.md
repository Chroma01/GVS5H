View the process as creating monochromatic blocks in deletion order while scanning A left to right; an element either extends its value's current block, paying the number of already seen elements in later blocks, or starts a new block, paying 1. There exists an optimal strategy in which we never extend a non-last block when at least two seen elements are in later blocks, and extending the last block is always free/dominant. Hence only the last block and, if the last block has size 1, the second-last block can matter; all older blocks are dead and force a new block when their value appears. This gives an O(N) DP with a scalar state for last-block size >= 2, up to two states where last-block size is 1, and one state where the current value is the second-last block; update it for each A_i and take the minimum final cost.
