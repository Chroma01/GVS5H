Model the problem as a shortest-path search on pairs of vertices (u,v), where dist[u][v] is the shortest palindrome-labeled path from u to v. Initialize dist[v][v]=0 for the empty path and dist[u][v]=1 for every labeled edge u->v. A longer palindrome is formed by adding a matching pair of edges x->u and v->y with the same label, giving a transition (u,v) -> (x,y) with cost 2. Run a multi-source BFS/Dijkstra over the N^2 pair-states to compute all distances, then output each distance or -1 if unreachable.
