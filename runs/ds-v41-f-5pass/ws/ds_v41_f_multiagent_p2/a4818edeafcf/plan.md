Precompute prefix distinct counts and suffix distinct counts so the first and third subarray contributions are O(1). Sweep the right cut j and maintain, for every possible left cut i < j, the value prefix_distinct[i] + distinct_count(A[i+1..j]). When j advances, appending A[j] increases this value by 1 exactly for left cuts i at or after the previous occurrence of A[j], so this becomes a range-add update. A lazy segment tree over left cuts supports range add, point initialization, and range maximum, giving an O(N log N) solution. For each j, combine the best middle value with suffix_distinct[j+1] to update the answer.
