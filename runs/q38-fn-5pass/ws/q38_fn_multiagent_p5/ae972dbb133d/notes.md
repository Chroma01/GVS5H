- **Model:** For each cell let T,B,L,R be bits indicating whether a segment endpoint lies on that edge. Type A is exactly T xor B = 1 and L xor R = 1. Type B is exactly T xor B = 0, L xor R = 0, and T xor R = 1. These conditions force the correct adjacent or opposite endpoint pair and determine the tile orientation uniquely.
- **Edge variables:** Let h_{i,j} be the top edge of cell (i,j), so its bottom edge is h_{i+1,j}. Let v_{i,j} be the left edge of cell (i,j), so its right edge is v_{i,j+1}. For every cell, the first two local constraints become h_{i,j} xor h_{i+1,j} = 1 if the cell is A else 0, and v_{i,j} xor v_{i,j+1} = 1 if the cell is A else 0. A B cell adds h_{i,j} xor v_{i,j+1} = 1.
- **Cycle checks:** Around each column, the xor of h differences is the parity of A cells in that column, so every column must contain an even number of A cells. Around each row, the xor of v differences is the parity of A cells in that row, so every row must contain an even number of A cells. If either check fails, the answer is 0.
- **Free bits:** If the parity checks pass, each column j has one free bit C_j = h_{0,j}, and h_{i,j} = C_j xor colPref(i,j), where colPref(i,j) is the xor of A cells above row i in column j. Each row i has one free bit R_i = v_{i,0}, and v_{i,j} = R_i xor rowPref(i,j), where rowPref(i,j) is the xor of A cells left of column j in row i.
- **B equations:** For a B cell at (i,j), h_{i,j} xor v_{i,j+1} = 1 becomes R_i xor C_j = 1 xor colPref(i,j) xor rowPref(i,j+1). While scanning a row left to right, rowPref before a B cell equals rowPref(i,j+1) because the current cell contributes 0. Maintain colPref[j] as the xor of A cells in column j from previous rows.
- **Counting:** Use a parity DSU on H+W nodes: row nodes and column nodes. Each B cell adds one equation R_i xor C_j = val. If a cycle is inconsistent, the answer is 0. Otherwise each connected component contributes one free bit, so the answer is 2^{number of DSU components} modulo 998244353. Isolated row or column nodes still contribute a factor of 2.
- **Implementation:** Read all input tokens. For each test case, first scan rows to check row and column A parity and count B cells. If all cells are A, answer directly. Otherwise initialize the DSU and scan the grid again, maintaining rowPref and colPref. On A cells, toggle rowPref and colPref[j]. On B cells, union row i with column H+j using val = 1 xor colPref[j] xor rowPref. Stop early if a contradiction is found.
- **Complexity:** O(HW alpha(H+W)) time per test case and O(H+W) extra memory. The total HW over all tests is at most 1e6, and H+W is also bounded by the total HW for H,W >= 2.
- **Pitfalls:** The B equation uses the right edge v_{i,j+1}, so the row prefix must include A cells up to column j. For a B cell the current cell is not A, so the prefix before processing it is already the needed inclusive prefix. Do not forget isolated DSU components. Check both row and column parity before processing B equations. Torus wrap is handled by the even-parity checks, after which the prefix formulas wrap consistently.
