- **Model:** Binary strings as sorted 1‑positions x[0..M-1], y[0..K-1]. Operation moves all pieces toward center i. Order and number of pieces never increase; occupied set only merges.
- **Partition:** Final occupied squares y are filled by disjoint contiguous blocks of x. Boundaries are chosen gaps G[i] = x[i+1]-x[i] matched to required gaps h[j] = y[j+1]-y[j] in order. Necessary: K <= M and G[i] >= h[j] for each boundary.
- **Reductions:** For each gap, reduction R_gap = G[i] - h[j] (if boundary) or G[i] (if internal, must close to 0). Total reduction = (x[-1]-x[0]) - (y[-1]-y[0]) = P+Q, where P = y[0]-x[0], Q = x[-1]-y[-1].
- **Parity constraint:** If a boundary gap has G[i] == h[j] (zero reduction), no operation may center at or between its endpoints. Hence both pieces move together and their common displacement ≡ t (mod 2). This forces t ≡ y[j] - x[i] (mod 2). For a fixed parity s of operations at the leftmost piece, the allowed condition is G[i] > h[j] OR (x[i] - y[j]) % 2 == (s + x[0] - y[0]) % 2.
- **Min ops:** Lower bound D = max(P, Q) from moving the global left and right boundaries. If a feasible partition exists with parity s = c (where c = 0 if P >= Q else (P+Q) mod 2), answer is D; otherwise if any feasible partition exists, answer is D+1; else -1.
- **Algorithm:** O(M+K) per test. Compute x, y, G, h. Check unconstrained subsequence matching for boundaries. Then for s=0 and s=1, run a greedy earliest‑match for boundaries satisfying G[i] >= h[j] and the parity condition. Determine feasibility and minimal ops.
- **Brute‑force validation:** Exhaustive BFS over all non‑empty supports A,B with N<=8 (all pairs, multiset‑state graph, min ops) matched the solver on both reachability and minimum operation count. No counterexample found. Specifically verified cases where D is achievable vs. D+1 needed, and cases with multiple zero‑reduction boundaries.
- **Edge cases:** K > M → -1. K = 1 → no boundaries, both s checks true, answer D = max(y0-x0, x_last-y0). M = 1 → answer |y0-x0|. Identical supports → 0. If no equality gaps, both s checks pass, answer D.
