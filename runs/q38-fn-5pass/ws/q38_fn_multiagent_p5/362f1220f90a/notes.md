- **Materialize T constraints:** Every `T` window is written into `fixed` of length `n + m - 1`. If an overlap requires two different characters, return empty immediately. After this, respecting `fixed` guarantees all `T` windows match `str2`.
- **Automaton states:** KMP states `0..m`; state `m` means a full match of `str2` just ended. For the next character, state `m` is processed from `pi[m-1]`, so overlapping matches are handled correctly.
- **Automaton construction:** Build the prefix function for `str2`. For each state, use the standard KMP transition: if the character matches the needed pattern character, advance; otherwise fall back through `pi`. State `m` uses `fallback = pi[m-1]` as its start state.
- **Preimage lists:** `src[c][t]` is a bitmask of states that transition to target `t` on character `c`. `src_lists[c]` stores `(target_bit, source_mask)` pairs for nonzero entries. `combined_list` is the analogous union over all 26 characters, used for free positions.
- **Forbidden matches:** A transition into state `m` at position `pos` means the length-`m` window ending at `pos` equals `str2`. This is forbidden exactly when that window starts at an `F` in `str1`.
- **Backward DP:** `dp[pos]` is a bitmask of automaton states before position `pos` from which the suffix can be completed. `dp[L]` contains all states. For each position, remove target state `m` from `dp[pos+1]` if the window ending here is forbidden. For a fixed character, OR source masks from `src_lists[fc]` whose target bit is allowed; for a free character, OR the corresponding masks from `combined_list`. If the resulting mask is empty, no completion exists.
- **Greedy reconstruction:** Starting from state `0`, at each position choose the smallest character that does not create a forbidden match and whose next state is present in `dp[pos+1]`. Fixed positions are forced and checked against the DP. This yields the lexicographically smallest valid completion.
- **Sample validation:** `"TFTF", "ab"` produces `"ababa"`. `"TFTF", "abc"` returns empty because the two `T` placements conflict at the overlap. `"F", "d"` produces `"a"`.
- **Edge cases:** `m = 1` works because state `m` and fallback `0` are handled correctly; an `F` forces a character different from `str2`, while a `T` forces `str2`. All `F` uses the automaton to avoid `str2` in every window, e.g. `str2 = "aa"`, `str1 = "FF"` gives `"aba"`. All `T` is fixed by materialization; consistent overlaps produce the forced string, inconsistent overlaps return empty. Overlapping `T` conflicts are detected directly in `fixed`. Forced impossible `F` windows are detected by the DP when fixed characters make an `F` window equal `str2`, e.g. `str2 = "aaa"`, `str1 = "TFT"`.
- **Complexity:** Materializing `T` costs at most `n*m <= 5e6`. Automaton construction is `O(26*m)`. The DP iterates over at most `m+1` target states for each of `L <= 10499` positions, about `5.3e6` simple bit-mask operations. Memory is `O(L + 26*m)` Python integers plus small tables, well within limits.
- **Implementation notes:** The DP uses precomputed target-bit/source-mask lists instead of repeatedly extracting bits with `bit_length`, keeping the inner loop simple and fast. No external libraries are needed.
