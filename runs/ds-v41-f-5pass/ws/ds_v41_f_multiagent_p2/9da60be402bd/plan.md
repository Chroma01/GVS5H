Model the problem as finding shortest palindromic paths using BFS over pairs of vertices, where a state (u, v) represents a palindromic path from u to v. Initialize trivial palindromes: length 0 for (i, i) and length 1 for every existing edge i→j. Then repeatedly extend outward: if there is an edge x→u and an edge v→y with the same label c, then a palindromic path from x to y of length (current length + 2) exists. Use a 2D distance array to record the shortest length and a queue to process states in increasing distance order. Since N ≤ 100, the number of states is at most 10,000, and the extension step can be done efficiently by pre-grouping edges by label. Finally, output the distance matrix, using -1 for unreachable pairs.
