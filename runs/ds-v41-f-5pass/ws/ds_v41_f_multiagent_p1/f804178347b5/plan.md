Model the majority reduction as a complete ternary tree of height N, where leaves are characters of A and each internal node stores the majority of its three children. The goal is to change the root value, so define a bottom-up DP where each node computes the minimum leaf flips needed to make that node output 0 or 1. For a leaf, the cost to keep its current bit is 0 and to flip it is 1. For an internal node targeting value v, at least two of its three children must end as v, so combine the three children’s DP costs optimally. Finally, compute the original root value and output the DP cost to make the root the opposite value.
