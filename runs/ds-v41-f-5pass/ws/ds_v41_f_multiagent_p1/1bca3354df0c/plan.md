The initial graph is bipartite, so every legal move is exactly an edge addition that keeps the current graph bipartite. Analyze the game by decomposing the graph into connected bipartite components, then understanding moves inside a component and moves that merge two components. The winner should be determined by a parity or Nim-style invariant over component statistics such as bipartition sizes and missing cross edges. Derive and verify this invariant on small cases, then compute it in linear time for all connected components.
