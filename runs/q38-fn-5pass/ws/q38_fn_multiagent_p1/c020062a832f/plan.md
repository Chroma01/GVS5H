Compute the inversion count for k=0 using a Fenwick tree over the values 0..M-1. Observe that increasing k by 1 only changes inversion status for pairs where exactly one element wraps from M-1 to 0; for each wrapping position p, its net contribution after cancellations among all wrapping positions is 2p-N-1. Precompute a difference value for each residue v as the sum of 2p-N-1 over all positions p with A_p=v. Then simulate k=0..M-1 by adding the difference for v=M-1-k to the current answer, giving O(N log M + M) time.
