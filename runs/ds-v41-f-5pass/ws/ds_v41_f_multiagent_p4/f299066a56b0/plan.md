Model the maximum number of kagamimochi as a feasibility problem: for a candidate K, decide whether 2K mochi can be paired so each top is at most half its bottom. Since A is sorted, a greedy or two-pointer check can test feasibility efficiently, allowing binary search over K in the range 0 to floor(N/2). The key is to identify which mochi should be used as tops and which as bottoms without needing explicit pairing construction beyond feasibility. Then implement the check and binary search, paying attention to duplicates and the sorted input guarantee.
