For each value x, let m_x be the number of smaller values initially to its right. In an optimal strategy, process values from largest to smallest; when x is processed, all larger values have been moved away, so x starts at rank x - m_x among the remaining values 1..x and must move right m_x times. Its minimum cost is therefore (x - m_x) + (x - m_x + 1) + ... + (x - 1) = m_x * x - m_x * (m_x + 1) / 2. Compute all m_x with a Fenwick tree by scanning values in increasing order, accumulating this formula. This gives the answer in O(N log N) time.
