Use divide-and-conquer over the array to count valid subarrays. For each segment, count subarrays entirely in the left half, entirely in the right half, and those crossing the midpoint. For crossing subarrays, precompute the cost to make the left part non-decreasing and the running maxima for the right part. Use a monotonic stack to compute left costs in O(n), and a two-pointer with binary search to count valid crossing pairs in O(n log n). The overall complexity is O(n log² n), which fits the constraints. Recursion depth is logarithmic, so no stack overflow issues.
