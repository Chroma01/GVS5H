Use the key observation that lcm(a,b) >= max(a,b), so any nums[i] > threshold cannot have an edge and is an isolated component. For active values <= threshold, lcm(a,b) <= threshold iff both values divide some L <= threshold, so all present divisors of each L form a connected group. Build a DSU over distinct active values, then for each active value enumerate its multiples up to threshold and union it with the first active divisor seen for each multiple. Finally count DSU roots among active values plus every value greater than threshold.
