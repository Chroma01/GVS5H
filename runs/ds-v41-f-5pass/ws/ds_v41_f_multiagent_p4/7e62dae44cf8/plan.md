Treat Takahashi's accumulated body as a growing connected region from the start cell. Only cells on the boundary of this region can ever be absorbed next, and absorbing any allowed cell increases his strength, so it can never make another boundary cell harder to absorb. Therefore, repeatedly absorb the smallest adjacent boundary cell whenever it satisfies strength * X < current strength. Maintain the boundary in a min-heap so stopping is correct when the smallest boundary cell is not absorbable. This gives an efficient O(HW log(HW)) solution.
