- **Reduction:** Row and column flips commute, so only their parities matter. Fix a column-flip mask `c`. For a row mask `r`, the best row flip gives cost `min(popcount(r xor c), W - popcount(r xor c))`. The answer is the minimum over all column masks of the sum of these independent row costs.
- **Convolution form:** Aggregate row masks into `freq[m]`. Define folded Hamming kernel `K[d] = min(popcount(d), W - popcount(d))`. For each column mask `c`, the cost is `sum_m freq[m] * K[m xor c]`, which is an XOR convolution of `freq` and `K`.
- **FWHT approach:** Use unnormalized Fast Walsh-Hadamard Transform for XOR convolution. Transform `freq`, multiply pointwise by the transform of `K`, transform again, and divide every value by `2^W`. The minimum of the normalized array is the answer.
- **Kernel transform optimization:** Instead of building the full kernel array and FWHTing it, compute its Walsh transform analytically. For a mask `s` with popcount `t`, the transform of a radial kernel is `sum_k K_k * [x^k] (1-x)^t (1+x)^(W-t)`. These coefficients are Krawtchouk coefficients. Since `W <= 18`, computing these `W+1` polynomials in `O(W^3)` is negligible and saves one full FWHT pass.
- **Implementation details:** Read all input tokens at once. Convert each row string with `int(s, 2)` into a mask and increment `freq`. After the first FWHT, multiply each transformed coefficient by `kernel_tf[popcount(mask)]`, using `int.bit_count`. Then run the second FWHT and take `min(freq) // (1 << W)`. Delete input data before transforms to reduce memory.
- **Complexity:** Time is `O(H + W^3 + W * 2^W)`. Memory is `O(2^W)`. For `W = 18`, `2^W = 262144`, and two FWHT passes are fast enough in Python.
- **Edge cases:** For `W = 1`, the kernel is identically zero and the answer is always `0`. For a single row, choosing the column mask equal to that row mask gives cost `0`. Intermediate FWHT values can be negative, but the final convolution values are nonnegative and exactly divisible by `2^W`.
- **Pitfalls:** The kernel is folded Hamming distance, not plain Hamming distance. The inverse FWHT requires division by `N = 2^W`. Bit order from `int(s, 2)` does not matter because the kernel depends only on popcount. The analytic kernel transform must match the unnormalized FWHT convention used by the butterfly implementation.
- **Alternative:** Directly constructing the full kernel list and FWHTing it is simpler but uses three FWHT passes. The analytic kernel transform is preferable for Python time limits.
