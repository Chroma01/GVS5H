Model each integer `x` by the number of times it must be divided by 4 to become zero, i.e. `steps(x) = 1 + steps(x // 4)` with `steps(0) = 0`. For a query `[l, r]`, the array contributes a multiset of these step counts, and each operation can reduce two positive step counts by 1, so the minimum operations is `max(max_step, ceil(total_steps / 2))`. Since `r <= 10^9`, `steps(x)` is at most 15, so we can precompute powers of 4 and answer each query in O(15) using a prefix sum of `steps(x)` over ranges. The final answer is the sum of the per-query minimum operations.
