Model the majority reduction as a perfect ternary tree where each internal node computes the majority of its three children. For every node, compute two DP values: the minimum flips to force its output to 0 and to 1. Leaves are initialized from the given string: cost0 = (bit == '1'), cost1 = (bit == '0'). For an internal node, to force output 0, choose two children to be 0 (sum their cost0) and set the third to whichever value is cheaper; symmetrically for output 1. Propagate these costs bottom-up level by level; with N ≤ 13 the tree has at most 3^13 ≈ 1.6M leaves, so an O(3^N) DP is feasible. Finally, determine the original root value by simulating the majority operation on the original bits, then answer is the DP cost to force the opposite value at the root.
