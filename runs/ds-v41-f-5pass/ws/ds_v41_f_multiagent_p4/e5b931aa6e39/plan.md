Use the identity x^3 - y^3 = (x-y)(x^2 + xy + y^2) = N and parameterize d = x-y, so x = y+d. For each possible d, solve d(3y^2 + 3dy + d^2) = N as a quadratic in y. Since N >= d^3, only divisors/d-values up to cube_root(N) need checking, which is at most about 10^6 for N <= 10^18. Check each d by computing the discriminant or using integer binary search for y. If an integer positive y and x=y+d are found, print them; otherwise print -1.
