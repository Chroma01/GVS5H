- **Core model:** Each original letter is a class with a forced final letter. If one source letter is forced to two different targets, impossible. Merging classes with different final targets can never be undone, so only same-target merges are allowed.
- **Graph:** For every used source c add edge c -> forced[c]. Self edges need no operation. `edges` counts non-self edges. `indeg` counts all incoming edges from used sources, including self-loops, because a self-loop with an incoming edge can create an empty letter.
- **Pure cycles:** A directed cycle of length > 1 whose every node has indegree exactly 1 has no incoming tree and no class outside it shares its targets. It needs one extra operation beyond its edges: use an empty letter, rotate the cycle, and leave the empty letter empty again. Self-loops are not counted.
- **Non-pure cycles:** If a cycle has an incoming tree, some cycle node has indegree > 1. A tree node can serve as the temporary label: merge the cycle predecessor into that tree node, rotate the cycle, then process the tree. This uses exactly one operation per non-self edge, so no extra operation is added.
- **Buffer:** A pure cycle can be broken only if some letter can be made empty without extra cost. This happens if `used_count < 26` (an initially empty letter) or `max(indeg) >= 2` (two classes share a final target; merging them empties one source). If pure cycles exist and neither condition holds, all 26 letters are used and every indegree is 1, so the map is a permutation with no possible empty letter; output -1.
- **Answer:** If possible, minimum operations = `edges + pure_cycles`. The lower bound is one operation per non-self forced edge, plus one unavoidable non-satisfying move for each pure cycle; the constructive ordering above attains it.
- **Complexity and checks:** O(N + 26) time, O(1) extra state. Sample checks: 1 gives 4, 2 gives 0, 3 gives -1, 4 gives 4; all pass.
