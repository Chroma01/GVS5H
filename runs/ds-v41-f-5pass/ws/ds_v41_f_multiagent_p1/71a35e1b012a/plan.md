The problem reduces to covering all positions using operations that either set an interval to 1 (op1) or set its complement to 1 (op2). Key observations: an optimal solution uses at most two op2 operations; the minimum cost is always in {-1, 1, 2, 3}. We can check cost 1 (an interval [1,N]), cost 2 (two op1 covering [1,N], one op2+op1 with containment, or two op2 with disjoint intervals), and otherwise if M≥3 the answer is 3 (pick a middle interval as op2 and its immediate neighbors as op1). The implementation will perform these checks in O(M log M) time and output the corresponding operation types.
