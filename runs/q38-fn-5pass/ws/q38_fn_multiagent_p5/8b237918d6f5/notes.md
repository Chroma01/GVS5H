- **Core equivalence:** For a target distance D, distance at least D is equivalent to integer potentials d_v in [0,D] with d_1=0, d_N=D, and d_v <= d_u+1 for every edge u->v. Setting weight 1 on edges with d_v>d_u certifies the lower bound. Conversely, from any weighting with shortest distance at least D, capped shortest distances give such potentials, and every upward edge must already be chosen. Thus D is feasible iff the minimum possible number of upward edges is at most K.
- **Exactly K:** If the minimum required number r is at most K, choose those r edges and arbitrarily add K-r other edges. Raising edge weights cannot shorten any path, so exactly K is equivalent to at most K.
- **Layered min-cut:** Use source side as true for x_{v,i} = (d_v >= i), i=1..D. Force x_{1,i}=false with node->sink INF, and x_{N,i}=true with source->node INF. Add INF implication edges x_{v,i+1}->x_{v,i} and x_{v,i+1}->x_{u,i} for each original edge u->v. Add unit cost edge x_{v,i}->x_{u,i}; a cut pays exactly when x_{v,i}=true and x_{u,i}=false. The implications ensure d_v<=d_u+1, so each original edge is paid at most once, exactly when d_v=d_u+1.
- **Search and bounds:** The answer is at most min(K,N-1): a shortest path can be simple and uses at most K selected edges. Feasibility is monotone in D, so binary search over [0,min(K,N-1)]. D=0 is trivially feasible.
- **Implementation details:** Dinic max-flow with early stop at K+1. INF=1e9 is larger than any finite cut M*D. Rebuild the layered graph for each D; node id is v*D+i for 0-based layers. Multi-edges are handled naturally by parallel unit-capacity cost edges. Recursion limit is increased. Complexity is tiny for N<=30, M<=100, D<=29.
- **Pitfalls checked:** Keep orientation consistent with source side true. D=1 has no transition edges. Do not scan D beyond min(K,N-1). Early stopping is safe because only flow <=K versus >K matters. Self-loops, if any, can be ignored because they never cross a cut and never affect shortest paths.
