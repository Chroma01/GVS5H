A building is visible iff the segment from (0,h) to its top passes strictly above the tops of all earlier buildings; for a pair j<i this yields a critical height R_{j,i}=(H_j X_i-H_i X_j)/(X_i-X_j), and the answer is max R_{j,i} over all pairs, or -1 if that maximum is negative. This R is exactly the slope between transformed points (1/X_i, H_i/X_i), so we need the maximum slope among all pairs of transformed points. The maximum slope is attained by an edge of the convex hull, and the hull can be constructed exactly by processing decreasing X (increasing 1/X) and using an integer orientation test equivalent to the transformed cross product. Finally, scan hull edges, keep the best rational slope with cross multiplication, and output -1 only when the best slope is negative.
