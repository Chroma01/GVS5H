- **Sample tests:** Provided examples pass: [10, 20] gives 2 and [1, 15] gives 10. Edge checks pass: single-digit ranges count all numbers, ranges containing zeros count zero-containing numbers automatically, and r = 999999999 is handled with length 9 and digit sum 81. Verdict: pass.
- **Splitting:** Every positive integer containing digit 0 is beautiful because its digit product is 0. Count those as total numbers minus zero-free numbers, then count beautiful zero-free numbers separately.
- **Zero-free smooth sums:** A zero-free product has only prime factors 2, 3, 5, 7. Therefore a nonzero product can be divisible by digit sum S only when S is 7-smooth. Generate smooth S up to the maximum digit sum of r, which is at most 81.
- **Zero-free DP:** For each smooth S, run a digit DP over padded length M. It tracks position, digit sum, product modulo S, and whether the number has started. Leading zeros are allowed before start; after start only digits 1 through 9 are allowed.
- **Free suffix cache:** A cached free DP counts unrestricted suffixes from a prefix state. The tight DFS for a bound delegates to this cache when choosing a smaller digit, so the same free DP is reused for both r and l - 1 for each S.
- **Pruning:** Upper pruning uses remaining maximum sum 9 per position. Lower pruning for started zero-free states uses remaining minimum sum 1 per position, enforcing length <= digit sum and reducing states. Branches check both bounds before recursing.
- **Zero count:** count_no_zero(n) counts positive integers <= n with no digit 0 by summing 9^length for shorter lengths and scanning digits; zero-containing count is n - count_no_zero(n).
- **Complexity:** M <= 9, smooth sums about 41, DP states roughly O(M * sum(S^2)) over smooth S, with 9 transitions per state. Cache is cleared per S, so memory stays bounded.
- **Edge cases:** count_bound(0) returns 0, single digits are all beautiful, numbers with zeros are handled by the zero count, and 999999999 has sum 81 and product divisible by 81.
