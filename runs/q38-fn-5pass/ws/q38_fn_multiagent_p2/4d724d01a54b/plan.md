Use an induction/exchange argument: the current maximum element must move right to its final position, and doing so first gives a fixed minimum cost while not increasing the cost of sorting the remaining elements. Therefore process values from N down to 1, treating each value as the maximum of the remaining unsorted prefix. Maintain a Fenwick tree over original positions of already removed larger values to compute how far the current value has shifted left. For each value, compute its current position, add the arithmetic sum of swap costs needed to move it to its final position, then mark it removed. This gives an O(N log N) solution with O(N) memory.
