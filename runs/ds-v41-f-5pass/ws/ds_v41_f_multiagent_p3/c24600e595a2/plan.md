Sort all positions by C ascending, classify each as forced off (A=1,B=0), forced on (A=0,B=1), optional (A=1,B=1), or ignored (A=0,B=0). Show that optimal operations consist of one phase turning off all selected 1s in descending C, then one phase turning on all selected 0s in ascending C. For optional positions, prove via exchange argument that the chosen subset is a suffix of the optional positions when sorted by C. Derive a closed-form cost for any suffix size using prefix sums over the sorted optional positions, then minimize over all suffix sizes. Implement in O(N log N) and use 64-bit integers for costs.
