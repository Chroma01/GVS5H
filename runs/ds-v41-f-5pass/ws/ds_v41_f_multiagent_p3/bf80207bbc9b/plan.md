Model column flips as a W-bit mask; once the column flips are fixed, each row can be optimally row-flipped independently to minimize its number of 1s. Thus the objective is the sum over rows of min(popcount(row xor mask), W - popcount(row xor mask)). The main challenge is minimizing this sum over all 2^W column masks efficiently for H up to 2e5 and W <= 18. The solution should exploit the small width via bitmask counts and a fast transform or subset-style optimization, while handling row multiplicities from the input. Finally, implement the optimization in Python with careful I/O and memory.
