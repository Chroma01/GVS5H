The alkane subgraph of a tree is a connected induced subtree where every selected vertex has degree 1 or 4, with at least one degree-4 vertex. Root the given tree arbitrarily and run bottom-up DP. For each vertex attached to its parent, the only possibilities are a leaf (0 selected children) or an internal degree-4 vertex (exactly 3 selected children). Compute the best attached value as the maximum of size 1 and 1 plus the sum of the top three attached child values. Then consider each vertex as the topmost selected vertex: it can be a leaf (one internal attached child) or an internal degree-4 vertex (four best attached children). Take the maximum valid size over all such choices, or output -1 if none exists.
