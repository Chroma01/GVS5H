The core difficulty is to characterize reachable configurations and compute the minimum number of operations. The operation preserves the order of pieces and never increases the distance between consecutive pieces, so the problem can be reduced to matching the gaps of the initial piece positions to the gaps of the required occupied squares. A binary search on the answer `t` is natural: for a fixed `t`, check whether every piece can be assigned to a required square within distance `t` while respecting the order and gap-shrinking constraints. The check can be done greedily in linear time using two pointers to compute allowed index intervals for each required square, then verifying that valid split points exist where initial gaps are large enough for the corresponding required gaps. If the check succeeds for some `t`, the minimum is the smallest such `t`; otherwise the answer is `-1`.
