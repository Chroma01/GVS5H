The cost of the j-th unit of product i is the marginal cost (2j-1)P_i, so the optimal purchase is obtained by taking the cheapest marginal units. For a candidate marginal cost C, all units with marginal cost at most C can be counted and costed in O(N) using k_i=(C//P_i+1)//2 and cost_i=P_i*k_i^2. Binary search the largest C whose total cost is <=M; this gives a base set of affordable units. The remaining budget cannot afford all units with marginal cost C+1, so the only possible extra units are some of those equal to C+1, giving floor(remaining/(C+1)) additional units.
