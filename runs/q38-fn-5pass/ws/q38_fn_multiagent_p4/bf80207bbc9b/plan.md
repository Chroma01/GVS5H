Row and column flips commute, so the final grid is determined by choosing a flip bit for each row and each column. For a fixed column-flip mask, each row can be flipped or not independently, giving row cost `min(popcount(row_mask xor column_mask), W - popcount(row_mask xor column_mask))`. Aggregate identical row masks by frequency, so the total cost for every column mask is an XOR convolution of the frequency array with the kernel `K[d] = min(popcount(d), W - popcount(d))`. Compute all convolution values efficiently using a Fast Walsh-Hadamard Transform in `O(W * 2^W)`, then take the minimum.
