Model the process as choosing monochromatic deletion blocks: each value’s occurrences must be deleted in their original relative order, and the number of adjacent swaps needed for a chosen block order is exactly the number of inversions between elements of different blocks. Thus the task is to partition occurrences into consecutive same-value blocks and order them to minimize (#blocks + inversions). Compress the input into runs, then derive an optimal dynamic-programming/greedy reduction on the run sequence that maximizes the net saving obtained by merging runs with swaps. Prove the reduction rule/DP with exchange arguments and small-case brute force, then implement it in near-linear time over the total input size.
