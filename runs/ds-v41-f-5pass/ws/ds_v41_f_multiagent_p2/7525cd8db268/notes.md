- **Model:** nums = 1..n, so a subarray is an interval [l,r]. A normalized pair (a,b), a<b, lies inside [l,r] iff l<=a and r>=b. For fixed r the invalid left endpoints are exactly l<=M(r), where M(r)=max a over active pairs with b<=r; valid count ending at r is r-M(r) (r when nothing is active).
- **Removal effect:** Removing pair p only changes counts at r where p is the unique active argmax of a. There the count rises from r-M to r-M2, a gain of M-M2, where M2 is the largest active a strictly below M (0 if none). Removing a pair never decreases the count, so base + max(gain) is optimal and max(gain)>=0 handles "removal never helps".
- **Sweep:** r=1..n; insert all pairs with b==r before counting. Track best_a, best_cnt (multiplicity), best_owner, second_a. Insertion: a>best -> second=best, best=a, cnt=1, owner=id; a==best -> cnt+=1; else if a>second -> second=a. Insert-only, so bookkeeping is exact and order inside a batch is irrelevant.
- **Accumulate:** base += r-best_a each r; if best_cnt==1, gain[best_owner] += best_a-second_a. Answer = base + max(gain).
- **Duplicates/ties:** identical or same-a pairs active together push best_cnt>=2, so no single pair claims gain there (correct: removing one leaves the twin). second_a stores a distinct value, which is what M2 needs; ties for second do not matter.
- **Execution verdict (examples):** Example 1 (n=4,[[2,3],[1,4]]) returns 9. Example 2 (n=5,[[1,2],[2,5],[3,5]]) returns 12. Both match; harness prints PASS.
- **Execution verdict (edge cases):** n=3,[[1,2],[1,3]] -> 5; n=2,[[1,2]] -> 3; n=4,[[4,3],[1,2],[2,4]] -> 7; n=2,[[2,1]] -> 3; n=5,[[1,5]] -> 10. All equal the brute force.
- **Execution verdict (random):** 20000 randomized cases with n in 2..8, m<=min(2n,6), including duplicates, reversed pairs, tied a-values, single-pair lists, and never-bottleneck pairs, all match the brute force (enumerate every removal x every subarray). Zero mismatches.
- **Complexity:** O(n + m) time, O(n + m) memory. Buckets indexed by b up to n; m<=2n, n<=1e5 fit easily.
- **Edge cases:** always normalize reversed input pairs; duplicates fine; exactly one removal is enforced by taking max(gain) (0 when removal never helps); best_a=0 while nothing is active yields r valid l-values.
