Model the smoke movement using prefix sums of the wind directions. A smoke particle generated at time k is at position P_t - P_k after the wind at time t, where P_t is the cumulative wind displacement up to time t. Smoke is generated exactly when the current prefix sum P_t has not appeared before, so the set of possible generation positions before time t is simply the set of distinct prefix sums seen so far. Therefore, at time t, the target cell (R,C) contains smoke iff P_t - (R,C) is already in that set. Process the string left to right, checking this condition before inserting the current prefix sum into the set.
