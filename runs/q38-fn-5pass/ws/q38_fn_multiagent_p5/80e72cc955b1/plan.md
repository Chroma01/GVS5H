For each integer x, the number of times it must be divided by 4 to become zero is the smallest k such that x < 4^k, i.e. k = floor(log_4(x)) + 1. Since one operation can apply this division to two array elements, the minimum operations for a query is the ceiling of half the sum of these required division counts over all numbers in [l, r]. Therefore, build a fast prefix-sum function F(n) = sum_{x=1}^n required_divisions(x), then answer each query as ceil((F(r) - F(l-1)) / 2). Because r <= 1e9, F(n) can be computed in O(log_4 n) by summing full blocks where the required division count is constant.
