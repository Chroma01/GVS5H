Iterate each possible non-zero last digit d from 1 to 9 independently and count substrings ending with d whose numeric value is divisible by d. For a fixed d, scan the string left-to-right while maintaining an array of counts of residues modulo d for all substrings ending at the current position. When appending digit c, each existing substring's residue becomes (old_residue * 10 + c) % d, and a new length-1 substring with residue c % d is added. If c equals d, the number of substrings with residue 0 contributes to the answer because they end with d and are divisible by d. Summing over d=1..9 gives an O(n * sum d) = O(45n) solution, which is fast enough for n up to 1e5.
