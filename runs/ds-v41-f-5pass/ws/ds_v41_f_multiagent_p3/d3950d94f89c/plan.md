Use a DFS over the tree while maintaining the current root-to-current-node path. For each value, keep a stack of depths where it appears on the current path; the shallowest valid start depth for the current node is the maximum over values of (second-deepest current occurrence + 1). Maintain root-to-node prefix sums of edge lengths and an array of current path nodes indexed by depth. At each node, evaluate the path from path[min_start_depth] to the current node using prefix sums. Update the global best by larger length, then smaller node count, and backtrack the value stacks and path array. This gives O(n) total time and O(n) auxiliary space.
