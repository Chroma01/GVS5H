- **Problem model:** Each inversion pair, where a larger value x is initially before a smaller value y, must be swapped exactly once. The total cost is the sum of the current positions at which these crossings occur, so the task is to minimize the positions of all required crossings.
- **Key lower bound:** For each value x, let m_x be the number of smaller values initially to its right. Among values 1..x, x initially has rank x - m_x. Each time x crosses one of those m_x smaller values, its rank among values 1..x increases by one, and the swap position is at least that rank. Therefore the required crossings cost at least (x - m_x) + (x - m_x + 1) + ... + (x - 1), which equals m_x * x - m_x * (m_x + 1) // 2. Summing over all x counts each inversion exactly once, by its larger element.
- **Achievability:** Process values from N down to 1. After larger values have been fixed at the right end, the remaining values 1..x occupy the first x positions and preserve their relative order. Moving x right across exactly its m_x smaller values makes it swap at positions x - m_x through x - 1, attaining the lower bound. Hence the summed formula is the exact minimum.
- **Computing m_x:** Scan x = 1..N in increasing order. A Fenwick tree over original positions stores processed smaller values. For x, left = count of processed positions <= pos[x]. Since pos[x] is not yet updated, this is the number of smaller values to the left of x. Then m_x = (x - 1) - left.
- **Complexity:** O(N log N) time and O(N) memory. Python integers safely handle the maximum answer, about N(N-1)(N+1)/6 for the reverse permutation, roughly 1.33e15 when N = 2e5.
- **Implementation details:** Use 1-indexed positions and Fenwick tree. The Fenwick prefix sum at pos[x] is safe because x itself has not been inserted yet. Use integer division for the triangular term. Read all input from sys.stdin.buffer for speed.
- **Edge cases:** Already sorted permutations have all m_x = 0 and answer 0. N = 2 works directly. The reverse permutation gives the maximum case, with m_x = x - 1 for every x.
