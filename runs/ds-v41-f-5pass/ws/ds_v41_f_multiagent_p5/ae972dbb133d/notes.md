- **Model:** Each cell side is a bit (segment touches that edge or not). Shared sides are one variable: h[i][j] = right edge of (i,j) = left edge of (i,j+1 mod W); v[i][j] = bottom edge of (i,j) = top edge of (i+1 mod H, j). No-dead-end ⟺ every shared edge's two endpoints agree, i.e. these equalities hold.
- **Tile edge characterisation (verified by hand):** With T,B,L,R = the four edge bits, Type A ⟺ (T≠B and L≠R), giving exactly the 4 adjacent-edge pairs. Type B ⟺ (T=B and L=R and T≠L), giving exactly the two opposite pairs {T,B} / {L,R}. This is the key reduction.
- **Even-parity requirement:** dv[i][j]=v[i-1][j]^v[i][j]=1 iff S[i][j]='A'; the XOR of dv around the cycle of a column must be 0, so every column needs an even number of A's. Similarly dh[i][j]=h[i][j-1]^h[i][j]=1 iff A, so every row needs an even number of A's. If any row/column has odd A-count the answer is 0.
- **Parameterisation:** With even parities, write v[i][j]=V_j^α(i,j) where α(i,j)=parity of A's in rows 1..i of column j, and h[i][j]=U_i^β(i,j) where β(i,j)=parity of A's in cols 1..j of row i. The A-cell constraints are then satisfied automatically.
- **B-cell equation:** Each B cell forces T≠L ⟺ v[i-1][j]^h[i][j-1]=1. Substituting gives U_i ^ V_j = 1 ^ α(i-1,j) ^ β(i,j-1) = c. This is a bipartite XOR system over H+W nodes.
- **Row-0 shortcut:** For i=0, α(H-1,j)=a0[j]=[S[0][j]='A'], but a B cell at row 0 has S[0][j]='B' so a0[j]=0; hence using colq[j] (initialised 0, never updated in row 0) is exactly correct. colq[j] is updated only for i>0. No special-casing of c needed.
- **Counting:** Parity DSU over H+W nodes. On contradiction → 0. Else #solutions = 2^(number of connected components) (isolated nodes count). Map (U,V)↔edge config is injective and edge config↔placement is bijective, so this equals the placement count. Answer 2^comp mod 998244353.
- **Sample checks (match exactly):** case1 = 2 (comp=1, all 6 nodes joined), case2 = 0 (row 0 has one A → odd parity), case3 = 2 (single component).
- **Hand sanity:** 2×2 all-B → consistent, comp=1 → 2 (the all-vertical and all-horizontal configs; mixed ones break the right/left match).
- **Efficiency notes:** find() uses path compression + union by size; total work O(sum HW · α). Input read via sys.stdin.buffer.read().split() with byte tokens ('A'==65). T up to 1e5, sum HW up to 1e6.
