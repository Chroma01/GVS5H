Root the tree and use the fact that in any rooted subtree, all fully completed paths contribute a multiple of K vertices. Therefore the subtree size modulo K uniquely determines the length of the single unfinished path ending at the subtree root; if the remainder is 0, the subtree must be fully closed. A vertex can belong to only one path, so it can absorb at most two unfinished child paths when closing here, or at most one unfinished child path when passing an unfinished path upward. We can compute subtree remainders bottom-up and check these simple count/sum conditions for each vertex. The special case K=1 is always possible, and the final answer is Yes iff the root is feasible and closed.
