- **Core objective:** The total cost is the initial total tooth length minus `N * H`, where `H` is the final common sum of each upper/lower pair. Therefore the problem is equivalent to maximizing the feasible integer `H`.
- **Fixed-H feasibility:** For a fixed `H`, the final upper length `u_i` must lie in `[max(0, H - D_i), min(U_i, H)]`. The lower length is then `H - u_i`, automatically nonnegative and at most `D_i`.
- **Lipschitz interval condition:** There exists a sequence `u_i` inside these intervals with `|u_i - u_{i+1}| <= X` iff for every ordered pair `(i, j)`, `L_i <= R_j + X * |i - j|`, where `L_i = max(0, H - D_i)` and `R_j = min(U_j, H)`. Sufficiency follows by choosing `u_i = min_j(R_j + X * |i - j|)`, which is `X`-Lipschitz and satisfies all interval bounds when the pairwise condition holds.
- **Closed-form upper bound on H:** The pairwise condition is equivalent to `H <= D_i + U_j + X * |i - j|` for every ordered pair `(i, j)`. If `H <= D_i` or `H <= U_j`, the condition is trivial; otherwise it reduces exactly to this inequality. The diagonal case `i = j` also enforces `H <= U_i + D_i`.
- **Maximum feasible H:** Since all constraints are upper bounds on `H`, the maximum feasible integer `H` is `min_{i,j} (D_i + U_j + X * |i - j|)`.
- **O(N) computation:** Split the absolute value. For `i <= j`, minimize `(D_i - X*i) + (U_j + X*j)` using a left-to-right prefix minimum. For `i >= j`, minimize `(D_i + X*i) + (U_j - X*j)` using a right-to-left suffix minimum. Taking the minimum over all `j` gives the answer.
- **Implementation details:** Use 0-based indices; the transformed expressions are unchanged because only differences `j - i` or `i - j` matter. Python integers handle the large answer range. The final answer is `sum(U_i + D_i) - N * best_h`.
- **Pitfalls:** Do not forget both directions of the absolute value. The binary-search approach is unnecessary once the closed-form minimum is known. Final lengths may be zero, and `H` is integer, but all bounds here are integer.
