Model Takahashi's absorbed cells as a connected visited region, with all unvisited cells adjacent to this region as boundary candidates. Since all strengths are positive and the ability to absorb depends only on the current total strength, absorbing any currently absorbable boundary cell can only increase future options, so the maximum is reached by repeatedly absorbing any absorbable boundary cell until none remain. Maintain the boundary in a min-heap keyed by slime strength: if the weakest boundary cell is not absorbable, no boundary cell is absorbable, so the process stops. Use the strict condition `current_strength > X * candidate_strength` to decide absorption.
