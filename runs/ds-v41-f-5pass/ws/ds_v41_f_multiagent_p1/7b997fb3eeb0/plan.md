The maximum number of pairs in a sorted interval can be characterized by a monotone offset condition. If t is the last index of the smaller elements used as tops, then every x in [L,t] must satisfy A[x] paired with A[x+(R-t)]. Precompute nxt[x], the first index with A[nxt[x]] >= 2*A[x], and define gap[x]=nxt[x]-x. Then a candidate t is valid iff t + max_{x∈[L,t]} gap[x] <= R, with t ≤ floor((L+R-1)/2). Build a static range-max structure over gap, then binary-search the largest valid t per query. The answer is t-L+1, or 0 if no valid t exists.
