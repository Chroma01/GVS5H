The game can be reduced to a parity-count game: after an index is first chosen, its remaining tokens form a common pool of “pass” moves, and only the parity of that pool and the parity of each unchosen `A_i` affect the winner. Let `e` be the number of even `A_i` and `o` the number of odd `A_i`; solving the resulting two-parity DP gives a closed form. For `N=1`, Fennec wins; for `N=2`, Snuke wins; for `N=3`, Snuke wins only when all `A_i` are even. For all `N >= 4`, Snuke wins exactly when `o` is even, otherwise Fennec wins. The implementation only needs to count odd values and apply these branches in `O(N)` time.
