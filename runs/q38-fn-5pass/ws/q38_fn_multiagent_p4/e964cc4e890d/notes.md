- **Strong-connectivity condition:** Because the original edges only go forward, the final graph is strongly connected iff every proper prefix has at least one added edge entering it from the right, i.e. some black vertex in the prefix is paired with a white vertex to its right. Necessity is immediate. Sufficiency follows by repeatedly crossing cut `x-1` from any vertex `x` using a right-to-left added edge whose white tail is reachable by moving right.
- **Surplus prefixes matter:** A prefix with `L` blacks and `T` whites imposes a constraint only when `T >= L`; if `T < L`, pigeonhole forces an entering edge. Prefixes with `T > L` are not redundant and cannot be reduced to balanced cuts only.
- **Constraint reduction:** Order black and white vertices. For a prefix before a black vertex with `L` previous blacks and `T` previous whites, if `T >= L`, the first `L` blacks must not all be matched to the first `T` whites, i.e. `max(assigned_white_indices[1..L]) > T`. For the same `T`, smaller `L` is stronger, so keep only the first occurrence of each distinct `T` with `T >= L`.
- **Endpoint filtering:** The first vertex must be black and the last vertex white. If either endpoint is wrong, answer is `0`. For `N=1`, only `BW` is valid with answer `1`.
- **Renewal recurrence:** Let `C_i` be the number of partial assignments of the first `L_i` blacks to the first `T_i` whites whose earliest violated kept constraint is `i`. Then  
  `C_i = falling(T_i, L_i) - sum_{j<i} C_j * falling(T_i - L_j, L_i - L_j)`.  
  Implemented as  
  `C_i = (fact[T_i] - sum_{j<i} C_j fact[T_i-L_j]) * invfact[T_i-L_i]`.  
  Final answer is `fact[N] - sum_i C_i fact[N-L_i]`.
- **Small path:** If `M <= 4000`, evaluate the recurrence directly in quadratic time. This avoids NTT setup overhead and is fast for small cases.
- **Constant-D arithmetic fast path:** If all kept constraints have the same `D = T-L` and `T_i` form an arithmetic progression with gap `c`, then `C * K = B` as formal power series, where `K[k] = fact[c*k + D]` and `B[i] = fact[T_i]`. Solve by one FPS inverse and one convolution. This generalizes the previous consecutive-`T` fast path and covers uniform-gap surplus cases.
- **General CDQ:** For arbitrary kept constraints, divide-and-conquer online convolution evaluates cross contributions. `Ssum[i]` stores accumulated `sum C_j fact[T_i-L_j]`. Blocks of size `256` are computed naively. Cross contributions are added either by sparse loops or by a shifted convolution: `A` is indexed by `L_j-minL`, and `B` is a factorial slice starting at `minArg = T_m-L_{m-1}`.
- **Sparse/convolution tuning:** Sparse loops are used when `nz * rc` is small, or when it is still much cheaper than the estimated NTT cost. Current thresholds are `NAIVE_LIMIT=50000`, `NAIVE_HARD=1500000`, `NAIVE_FACTOR=4`. Sparse loops adapt loop order depending on whether source or target side is smaller.
- **NTT implementation:** Uses an AtCoder-style radix-4 butterfly with precomputed roots, inverse roots, and a ctz table. The inverse butterfly scales by `inv_sizes[h]`. Convolution falls back to naive multiplication for small products. The maximum transform size is at least `2N+5`.
- **Edge cases:** `M=0` means all `N!` matchings are valid. Trailing whites and prefixes ending at whites are handled by the first-occurrence reduction. All factorial indices are within `[0,N]` for valid endpoint strings.
