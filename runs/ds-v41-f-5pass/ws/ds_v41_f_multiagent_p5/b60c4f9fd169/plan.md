Use the small bound K ≤ 20 to run a banded edit-distance check instead of full O(|S||T|) DP. First reject immediately if |len(S)-len(T)| > K, since insert/delete imbalance alone exceeds K. Then compute the minimum number of insertions, deletions, and replacements needed, allowing only DP states whose diagonal index is within K of the main alignment diagonal. The band width is at most 2K+1, so time is O((|S|+|T|)*K) and memory can be reduced to O(K). If the final computed edit distance is at most K, print Yes; otherwise print No.
