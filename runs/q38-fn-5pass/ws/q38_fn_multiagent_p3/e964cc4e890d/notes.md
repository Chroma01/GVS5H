- **Strong connectivity criterion:** With only path edges `1->2->...->2N`, the final graph is strongly connected iff every internal cut is crossed by at least one added backward edge (white on the right, black on the left). This forces the first vertex to be `B` and the last vertex to be `W`.
- **Permutation model:** Order blacks and whites separately. Let `p_i` be the white rank matched to the `i`-th black. For `i=1..N-1`, let `H_i` be the number of whites before the `(i+1)`-th black. The condition is `max_{r<=i} p_r > H_i` for all `i`, plus the boundary conditions.
- **Bad events and compression:** Event `E_i` is `max_{r<=i} p_r <= H_i`. If `H_i < i`, it is impossible and ignored. For equal `H`, later events are subsets of the earliest one, so only the earliest event for each distinct `H` is kept. Remaining events `(I_a,H_a)` have strictly increasing `I_a` and `H_a`.
- **Validated inclusion-exclusion recurrence:** For compressed events, define `f_a` as the signed subset sum ending at `a`. The recurrence is
  `f_a = -(H_a! + sum_{b<a} f_b * (H_a-I_b)!) / (H_a-I_a)!`.
  The answer is `N! + sum_a f_a * (N-I_a)!`. All divisions are modulo `998244353` using inverse factorials.
- **CDQ structure:** The recurrence is an online triangular convolution. CDQ over event index computes left half, adds its contributions to the right half, then computes the right half. For a node, left `I` values and right `H` values are shifted so the convolution length depends on value spans, not on large constant slack `H-I`.
- **Shifted convolution formula:** For nonzero left events, let `minI` and `maxI` be min/max `I_b`, `U=maxI-minI`, `H_mid=H[mid]`, `V=H[r-1]-H_mid`. Build `A[u]=f_b` at `u=I_b-minI`, and `B[s]=fact[H_mid-maxI+s]`. Coefficient at `U + (H_a-H_mid)` equals `sum_b f_b fact[H_a-I_b]`.
- **Big-integer convolution:** Instead of Python NTT, use exact integer convolution with base `2^128`. Factorials and `f` values are packed as 16-byte little-endian digits. Since each coefficient is at most `N * MOD^2 < 2^128`, there are no carries between base digits. Product bytes are unpacked by reading two 64-bit words per needed coefficient.
- **Prepacked factorials:** `fact_bytes` stores every `fact[i]` as one 128-bit digit. The `B` polynomial for any contiguous factorial window is obtained by slicing this byte buffer and converting to an integer.
- **Exact contributions:** `contrib[a]` is kept as an exact Python integer sum of products of modular representatives. It is reduced only when computing `f[a]`. This avoids modular reductions inside inner loops. The maximum size is about `N * MOD^2`, still small.
- **Hybrid direct path:** Small CDQ blocks and sparse/medium nodes are handled by direct loops. Thresholds are `DIRECT_BLOCK=64`, `SMALL_M=2000`, and `DIRECT_OPS=15000`, with an additional direct condition `ops <= 2*span` to avoid huge sparse big-int convolutions.
- **Boundary corrections confirmed:** Return `0` if `S[0] != 'B'` or `S[-1] != 'W'`. Ignore events with `H_i < i`. For equal `H_i`, keep only the earliest event. `N=1` is handled by the empty-event case: `BW` gives `1`, `WB` gives `0`.
- **Complexity:** The shifted spans over all nodes at one CDQ depth sum to `O(N)`, so the number of packed/extracted coefficients is `O(N log N)`. Big-integer multiplications are performed in C; direct work is bounded by the hybrid thresholds. Memory is linear plus temporary convolution buffers.
- **Validation status:** The recurrence and event compression were previously validated exhaustively for small `N` against brute force and the open-interval DP, and randomly up to `N=8`. The current implementation uses the same recurrence, with the quadratic checker retained conceptually as the small-case path.
