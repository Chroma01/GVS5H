Process queries offline in increasing order of X. Sort array elements by value and maintain a Fenwick tree over positions that stores the maximum LIS length ending at each processed position. When a value v becomes allowed, compute dp for all positions with A_i = v using the Fenwick state containing only strictly smaller values, then apply their updates; this prevents equal values from being chained. For a query (R, X), after all elements with value <= X are processed, the answer is the Fenwick prefix maximum up to R. This gives O((N + Q) log N) time and O(N + Q) memory.
