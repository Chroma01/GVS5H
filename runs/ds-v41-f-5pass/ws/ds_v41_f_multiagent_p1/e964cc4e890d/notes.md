- **Model:** let blacks be b_1<...<b_N and σ(j) be the white-rank matched to b_j (σ a permutation of [N]). The augmented graph is strongly connected iff S[0]=B, S[-1]=W, and for every i=1..N-1, max(σ(1..i)) > t_i, where t_i = number of W before the (i+1)-th black. Cuts not just before a black are implied (smaller right-white set); cut-before-first-black needs S[0]=B, cut-after-last needs S[-1]=W. Verified by hand on several strings.
- **Recurrence (index based, i is an index, not a position):** W(0)=1; W(i) = -inv_fact[t_i-i]·Σ_{j<i} W(j)·fact[t_i-j] when t_i≥i, else 0; answer = Σ_{i=0}^{N-1} W(i)·fact[N-i]. Everything uses t-values and indices consistently (the reduced form uses idx[l], an index).
- **Run reduction (proved):** t non-decreasing; on a maximal constant run [a,b] value T, W=0 except possibly at start a; a is live iff T≥a. Live indices strictly increase and their T values strictly increase, so idx and Tv are monotone staircases (Tv strictly increasing).
- **Fast path (proved):** if idx[k]=s*k and Tv[k]-idx[k]=d constant, then A(x)=ΣW_k x^k satisfies A·K=fact[d] with K(x)=Σ fact[d+s k] x^k, so A=fact[d]·K^{-1} and answer=Σ fact[d]·invK[k]·fact[N-s k]. Covers alternating (s=1,d=0: indecomposable permutations 1,1,3,13,...) and (BBWW)^k (s=2,d=0).
- **General case (CDQ):** recurrence W(k) = -inv_fact[Tv[k]-idx[k]]·Σ_{l<k} W(l)·fact[Tv[k]-idx[l]]. Divide & conquer; each pair (j,k) with j<k is summed once at the node where they first split. offset=idx[l], base=Tv[mid+1]-idx[mid], B=fact[base:base+lenB], C=A⊛B, C[Tv[k]-offset-base] = Σ_{j in left} W(j)·fact[Tv[k]-idx[j]]. base≥1, all fact indices in [0,N].
- **Changed/improved:** CDQ cross contribution now chooses naive branch when (left_cnt)*(right_cnt) ≤ _THRESH, NOT lenA*right_cnt. Using lenA would force a huge convolution when a large index gap sits inside a small node; left_cnt*right_cnt bounds the actual naive loop cost and keeps total naive work linear-ish.
- **Convolution:** exact big-int multiply. Coeffs packed into 10-byte little-endian slots; slot bound needs output coeff ≤ min(la,lb)·(MOD-1)^2 ≤ 2e5·2^60 < 2^78 < 2^80 (holds for poly_inv and all CDQ nodes). `P.to_bytes(count*10+10)` is always sufficient. Shortcuts: length-1 scalar; la*lb≤8000 schoolbook. Direct O(m^2) only for m≤1500.
- **Branch routing:** S bad →0; m==0 → fact[N] (t_i<i for all i ⇒ all permutations valid); fast-path test next (arithmetic idx); m≤_DIRECT direct; else CDQ.
- **Hand-verified (this session):** BWBW→1; alternating N=3→3, N=4→13 (both via fast path); N=3 S=BBWWBW→4; N=4 S=BBWWBBWW→20 (run reduction W(3)=0 exercised). These match the brute-force definitions by direct reasoning. - **Edge cases:** N=1: BW→1, WB→0. m=0 handled. All factorial indices (fact, inv_fact) stay in [0,N]; base≥1; N-idx[k]≥1.
