Because grinding only decreases lengths, for a fixed common sum H each upper tooth must lie in the interval `[max(0, H - D_i), min(U_i, H)]`. The total cost for a chosen H is `sum(U_i + D_i) - N * H`, so minimizing cost is equivalent to maximizing feasible H. Feasibility is monotone: if H is achievable, any smaller H is also achievable, so we can binary search the maximum H. For a candidate H, propagate the reachable interval of upper lengths from left to right, intersecting each tooth’s allowed interval with the previous reachable range expanded by X. The largest feasible H gives the minimum required payment.
