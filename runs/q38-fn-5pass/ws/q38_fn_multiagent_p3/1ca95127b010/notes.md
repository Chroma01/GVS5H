- **Core invariant:** Each operation swaps `0^X 1^Y` with `1^Y 0^X`. The relative order of all `1`s is preserved, and every participating `1` shifts by exactly `X`; similarly, the relative order of all `0`s is preserved, and every participating `0` shifts by exactly `Y`. Therefore the ordered sequence of `1` positions modulo `X` and the ordered sequence of `0` positions modulo `Y` are necessary invariants.
- **Completeness:** The oriented rewrite `0^X 1^Y -> 1^Y 0^X` is terminating and has no nontrivial self-overlap, so each equivalence class has a unique normal form. The two ordered residue sequences determine this normal form; this is the intended complete characterization. A small BFS oracle was included in the code (disabled in `solve`) to validate the invariant on tiny cases.
- **Indexing convention:** The implementation uses 0-indexed positions modulo `X` and `Y`. This is equivalent to using 1-indexed positions because the same constant shift is applied to all positions of a given character.
- **No-operation guard:** If `X + Y > N`, no window of length `X + Y` exists, so the answer is exactly whether `S == T`. This also avoids relying on the invariant in cases where no move can be made.
- **Insufficient color counts:** If the total number of `1`s is less than `Y`, or the total number of `0`s is less than `X`, no operation can actually occur. The residue invariant still forces equality in these cases because gaps between the other color are smaller than the corresponding modulus, but the explicit `X + Y > N` guard is the main safety net.
- **Implementation details:** The solution scans `S` and `T` with two pointers for `1` modulo `X`, then for `0` modulo `Y`. This is `O(N)` time and `O(1)` extra memory. Bytes are used for fast input and character comparison (`49` for `'1'`, `48` for `'0'`).
- **Edge cases covered:** `X = 1` or `Y = 1` (one residue sequence becomes trivial but counts are still checked), empty residue sequences, `X + Y = N`, all-zero or all-one strings, and mismatched counts.
- **Oracle:** `_oracle()` enumerates the full operation graph for random strings of length at most 6 and checks that the invariant neither misses reachable strings nor accepts unreachable ones. It is not executed during judging.
