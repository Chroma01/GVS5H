Use the factorization x^3 - y^3 = (x - y)(x^2 + xy + y^2). Let d = x - y, so d is a positive integer and x = y + d. Substituting gives N = d(3y^2 + 3dy + d^2), and since y >= 1, we must have d^3 < N, so it is enough to test d up to the cube root of N. For each divisor d of N, solve the resulting quadratic in y using an integer discriminant check. If a valid positive integer y is found, output x = y + d and y; otherwise output -1.
