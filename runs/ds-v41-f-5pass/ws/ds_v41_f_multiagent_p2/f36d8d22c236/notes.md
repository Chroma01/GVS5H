- **Model:** Track a global renaming. For each position, source letter S[i] must map to T[i]. Build f[26]; if a source letter needs two different targets, print -1.
- **Core quantity:** Let D = letters appearing in S, image = f(D). Let E = #{c in D : f(c) != c} (nontrivial mappings; self-loops excluded). If E == 0 answer is 0.
- **Graph:** Nontrivial edges c -> f(c) form a functional graph on <=26 nodes (each node out-degree <=1). Components are trees hanging on one cycle each.
- **Trees:** A tree (chain/star) rooted at a fixed point resolves in exactly its edge count by processing leaves-to-root; the target already holds its final group so merging into it is correct.
- **Cycle mechanism (key):** A cycle a1->a2->...->ak->a1 needs a buffer. If some tree node c points into the cycle (say f(c)=a1, same target as ak), merge ak into c, rotate the rest, then move the merged group into a1: cost k+1 = number of edges (cycle k plus the tree edge), i.e. ZERO extra. So such a cycle is free.
- **Isolated cycle:** A cycle where every node has indegree exactly 1 (over nontrivial edges) has no tree to borrow and costs +1 extra operation.
- **Formula:** answer = E + (number of isolated cycles), provided a buffer exists.
- **Buffer:** An empty value usable as temporary. Sources: any letter not in S (|D|<26), or any tree node (processing it empties its value). Any single buffer breaks arbitrarily many isolated cycles (it becomes empty again). Buffer exists iff NOT (|D|==26 and |image|==26).
- **Impossible cases:** (1) conflict in mapping; (2) |D|==26 and |image|==26 and E>0 (a non-identity permutation of all 26 letters): every cycle is isolated and no spare letter exists, so -1. If E==0 there, answer 0.
- **Brute-force validation:** Enumerated all S,T of length N<=3 over alphabets of size K<=4 (using generalized formula with K replacing 26). BFS over all 26^N or K^N strings (min operations) matched the formula exactly. No counterexamples found. Stress cases verified: all-letters-used with |D|==K and |image|<K (spare target letter acts as reusable buffer, e.g., K=4, f: 0->1, 1->0, 2->3, 3->3 gives E=3, one isolated cycle, answer 4); multiple isolated cycles with one buffer (K=6, cycles 0<->1 and 3<->4 plus chain 5->2->2 gives E=5, isolated=2, answer 7); chains feeding into cycles (K=4, f: 0->1,1->0,2->0,3->2 gives E=4, no isolated cycles, answer 4); full permutation non-identity (K=4, f: 0->1,1->0,2->2,3->3 gives -1, confirmed by BFS exhaustive search).
- **Detection details:** Traverse with nxt[v]=f[v] only when f[v]!=-1 and f[v]!=c; stop at v==-1. Use states 0/1/2; a cycle is found when we hit a state-1 node, taken as path[idx:]. All path nodes then marked done. <=26 nodes so O(1) beyond input scan.
- **Complexity:** O(N + 26) time, O(26) extra space.
- **Verified answers:** sample1=4, sample2=0, sample3=-1, sample4=4.
