We need to maintain the sum over all monotone paths from (1,1) to (H,W) of the product of cell values, under point updates. Since H*W ≤ 200000, we can orient the grid so that the smaller dimension H ≤ W (transpose if needed). The DP state is a vector of length H representing the path sums to each cell in the current column. A column update is a lower triangular linear transformation applied in O(H). We use sqrt decomposition on the W columns: divide into blocks of size B ≈ sqrt(W). For each block, precompute its transfer matrix (H×H) by applying the block's columns to H basis vectors. Maintain the DP state at the end of each block. When a cell is updated, recompute the block matrix, then recompute the DP states for all subsequent blocks. Choose B to balance block recomputation O(B·H²) and suffix propagation O((W/B)·H²). Output the last component of the final DP state after each update.
