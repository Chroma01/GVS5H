Recognize that any valid number N must be of the form \(p^{2a} q^{2b}\) for distinct primes p,q and positive integers a,b, so \(N = m^2\) where m has exactly two distinct prime factors. Since \(A \le 10^{12}\), only m up to \(10^6\) must be considered. Precompute all such m using a smallest-prime-factor sieve, square them, and store the squares in sorted order. For each query, binary-search the sorted list for the largest valid square not exceeding A. This gives preprocessing \(O(10^6 \log\log 10^6)\) and \(O(Q \log M)\) query time.
