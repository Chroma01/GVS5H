The key observation is that the answer for (R, X) equals the maximum LIS-ending length dp[i] over positions i ≤ R with A_i ≤ X. First compute dp[i] for every position by scanning left to right and using a max segment tree over compressed values, querying values strictly less than A_i. Then build a persistent max segment tree over compressed A values, where version i stores the best dp value among processed positions with each value. Each query is answered by querying the prefix of version R_i up to the largest compressed value ≤ X_i. This gives O((N + Q) log N) time and O(N log N) memory.
