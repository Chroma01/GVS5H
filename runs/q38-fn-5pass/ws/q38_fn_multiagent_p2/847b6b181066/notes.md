- **Core model:** All smoke particles undergo the same cumulative wind translation. If a particle is generated when the cumulative wind displacement is `g`, then after the current cumulative displacement becomes `D`, that particle is at `D - g`.
- **Generation set:** Smoke is generated at the origin exactly when the origin is empty after the wind step. The origin is occupied iff there exists a previous generation displacement `g` with `D - g = (0, 0)`, i.e. `g = D`. Therefore the set of generation displacements is exactly the set of distinct cumulative displacements visited so far, including the initial `(0, 0)`.
- **Query condition:** For target `(R, C)`, smoke exists at time `t + 0.5` iff `D - (R, C)` is in the generation set. Since `(R, C) != (0, 0)`, adding the current displacement before or after checking the target does not affect the answer.
- **Implementation:** Maintain cumulative displacement `(r, c)`. At each step, update it according to the wind character. If its encoded key is new, add it to the set. Then check whether the encoded key of `(r - R, c - C)` is present.
- **Encoding:** Coordinates of generation displacements are always in `[-N, N]`. Encode `(x, y)` as `(x + N) * (2N + 1) + (y + N)`. For the query displacement, first check that both coordinates are in `[-N, N]`; otherwise it cannot be in the generation set.
- **Edge cases:** The initial smoke at time 0 must be included. Repeated cumulative displacements mean the origin is already occupied, so no new smoke is generated. The target is guaranteed not to be the origin, avoiding ambiguity about whether output is taken before or after generation.
- **Complexity:** Each step performs O(1) expected set operations, so total time is O(N). The set stores at most N + 1 integers, so memory is O(N).
