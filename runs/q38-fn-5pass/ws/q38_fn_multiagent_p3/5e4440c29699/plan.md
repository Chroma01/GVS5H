Charge each invalid path to its first visited point in the forbidden rectangle: this first point is either the starting point inside the rectangle, or it lies on the bottom/left boundary entered from outside. Use closed forms for fixed-start-to-any-end path counts \(F(a,b)=\binom{a+b+2}{a+1}-1\) and total full-grid paths \(T(n,m)=\binom{n+m+4}{n+2}-nm-2n-2m-5\), noting that \(T\) also gives a 2D prefix sum of \(F\). Precompute factorials/inverses up to \(W+H+4\), and evaluate the two remaining one-dimensional boundary sums in linear time.
