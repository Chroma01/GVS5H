Use the small bound K ≤ 20 to avoid full O(|S||T|) edit distance. First reject immediately if the length difference exceeds K. Then run a banded Levenshtein DP that only keeps states within distance K of the main diagonal, since any valid edit sequence with ≤ K operations cannot move far from the diagonal. Handle insert/delete/replace transitions and output Yes iff the final cell is reachable within K operations. The implementation must be memory-efficient for strings up to 500000 characters.
