- **Positive-product DP:** Track only zero-free subsequences with product 1..limit. State is product, length parity, and achievable alternating sums as a Python int bitset. Even length appends +x; odd length appends -x; starting [x] is odd with sum x.
- **Active products:** Instead of scanning all limit products each step, maintain active products and in_active. For each element, iterate over the old active list, collect newly reachable products in new_products, and extend after the loop. This prevents using the current element more than once.
- **Ones:** For x == 1, product is unchanged. Transitions still toggle parity and shift sums by +1 or -1. Starting [1] is handled separately and must not be used as an old state in the same iteration.
- **Large x:** Positive-product DP skips x > limit because any zero-free subsequence containing it exceeds the limit. Such elements can still appear in product-0 subsequences, handled by the zero DP.
- **Zero-containing DP:** Maintain four bitsets: no-zero even/odd and has-zero even/odd. For zero, start [0] and toggle parity without changing sum. For positive x, update both no-zero and has-zero states with +x from even and -x from odd. Product is irrelevant once a zero is present.
