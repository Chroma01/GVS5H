Use the key observation that two values `a` and `b` are connected exactly when their lcm is at most `threshold`, which is equivalent to saying both values divide some integer `l <= threshold`. Therefore, for every possible `l` from `1` to `threshold`, all present numbers that divide `l` form a clique and can be unioned together. Values greater than `threshold` must be isolated because lcm is at least the maximum of the two values. Build divisor buckets by iterating multiples of each present value up to `threshold`, then union indices within each bucket using a DSU.
