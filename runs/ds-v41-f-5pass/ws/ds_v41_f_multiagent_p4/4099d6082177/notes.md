- **Problem model:** Partition all M = N*K vertices into N vertex-disjoint simple paths each containing exactly K vertices (K-1 edges). Equivalent to picking edges so every vertex has selected degree <= 2 and all components are paths of size K.
- **Key invariant:** Root anywhere (vertex 1). A subtree touches the rest only via its parent edge, and a path uses that edge at most once, so a subtree exposes at most one unfinished (open) path. Its return value is enough to summarize the subtree.
- **Return value meaning:** 0 = subtree fully closed; positive L = one open path of L vertices whose endpoint is the subtree root (needs to connect to parent); -1 = impossible.
- **Greedy is forced, not a choice:** At node x, every open child path must be completed via x (that is its only outside neighbor). 0 open children -> start length 1 (close immediately if K==1 else pass up 1). 1 open child -> t=L+1; if t<K pass up t, if t==K close (0), if t>K impossible. 2 open children -> must merge through x; valid only if L1+L2+1==K (then closed 0), else impossible. >=3 open children -> impossible. Any child returning -1 makes x impossible.
- **Why no alternatives:** Each child's return value is uniquely determined (no branching choices exist at any node), so there is nothing to search; the greedy examines a single configuration.
- **Answer:** Yes iff ret[root]==0. An open value at the root means an incomplete path (no parent to finish it); -1 means impossible.
- **Pitfalls:** Use vertices (not edges) as the length unit so merge is L1+L2+1 and extension is L+1; the "length K" in the statement means K vertices. K==1 -> every vertex is its own path, always Yes. Root has no parent so passing an open path up is invalid. Use iterative post-order to avoid recursion limits on path-like trees.
- **Complexity:** O(N*K) time and memory, fine for N*K <= 2e5.
- **Verified:** Sample 1 -> Yes (children of 3 and 5 close at K=2, node 2 starts length 1, root 1 closes at 2). Sample 2 -> No (node 3 has two length-1 open children giving 3 != K=2, propagates impossible).
