Model the objective as a threshold feasibility problem: for a candidate distance d, ask whether at most K edges can be set to 1 so that every 1-to-N path uses at least d of them. Use a potential/layered-cut characterization: assign each vertex an integer level in [0, d] with level(1)=0 and level(N)=d, require level(v) <= level(u)+1 for every edge u->v, and count exactly the edges where level(v)=level(u)+1. The minimum possible count can be computed as an s-t min-cut on a layered graph with one node per vertex and level threshold, using infinite-capacity arcs for nesting and edge constraints and unit-capacity arcs for the cost. Feasibility is monotone in d, so binary search the largest feasible d up to min(K, N-1). If the minimum required number of edges is at most K, the remaining edges can be chosen arbitrarily without decreasing the shortest path.
