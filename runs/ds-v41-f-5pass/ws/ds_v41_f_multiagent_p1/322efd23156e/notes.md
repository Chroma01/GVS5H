- **Problem core:** Maximise the minimum vitamin intake over three independent vitamin groups sharing a total calorie budget X. Each food belongs to exactly one vitamin.
- **Feasibility for fixed K:** The groups decouple. K is feasible iff the sum of the minimum calories needed to reach at least K for each vitamin is <= X.
- **Per‑vitamin DP:** For each vitamin, compute `dp[c]` = maximum units of that vitamin achievable with at most `c` calories (0 <= c <= X). Use a 0/1 knapsack over calories.
- **Exact‑cost DP with max‑cost optimisation:** Maintain `dp[j]` = max value using exactly `j` calories (impossible = -1e18). Process items sorted by cost ascending. For an item `(c, a)`, update `j` from `min(X, maxc + c)` down to `c` using `dp[j - c] + a`. Then `maxc = min(X, maxc + c)`. After all items, take a prefix maximum to obtain the at‑most‑cost DP. This avoids the gap problem that occurs if you cap the loop upper bound without exact‑cost semantics.
- **Binary search:** The answer lies in `[0, hi]` where `hi = min(dp_v[X])` over the three vitamins (0 if any group is empty). For a candidate K, find the smallest cost `c` with `dp_v[c] >= K` via `bisect_left` on the non‑decreasing `dp` array. Sum these minimum costs; feasible iff sum <= X.
- **Complexity:** O(N*X) worst‑case ~25M inner iterations, plus O(X) per vitamin and O(log X) per binary‑search step. Space O(X). Sorting items by cost ascending significantly reduces the inner‑loop length for the max‑cost optimisation.
- **Edge cases:** Empty vitamin group -> its `dp` is all zeros after prefix max, so `hi = 0` and answer 0. Answer 0 is always valid (eat nothing). Sentinel -1e18 is safe because total A_i <= 1e9, so impossible states never become non‑negative before the prefix max.
