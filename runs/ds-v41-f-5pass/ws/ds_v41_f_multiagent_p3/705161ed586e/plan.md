Model a good caption as a concatenation of contiguous blocks, each length at least 3 and internally all the same character, so the operation cost is the sum of absolute character differences from the original caption. Since the alphabet is only 26 letters, evaluate possible target characters per block using prefix sums to compute block costs in O(1). A dynamic program over string positions should compute the minimum total cost to make each prefix or suffix good while enforcing the length-3 minimum block size. After the optimal cost is known, reconstruct the answer greedily from left to right, choosing the smallest possible character and valid block length that still achieves the optimum. Finally, verify impossible cases and lexicographic tie-breaking with the provided examples and small brute-force checks.
