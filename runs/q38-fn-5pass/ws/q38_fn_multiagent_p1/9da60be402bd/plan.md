Treat each possible palindrome path by its current endpoints as a state `(u, v)`, meaning there is a palindrome-labeled path from `u` to `v`. Start BFS from all centers: states `(i, i)` with length `0`, and every edge `(u, v)` with length `1`. From a state `(x, y)`, extend the palindrome by adding one matching edge on both sides: if there is a label `c` with edges `p -> x` and `y -> q`, then `(p, q)` is reachable with length `+2`. Run multi-source BFS over the `N^2` states to obtain the shortest palindrome path length for every pair. Use per-label bitsets for incoming/outgoing vertices so transition generation is fast enough for `N <= 100`.
