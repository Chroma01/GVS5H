- **Reduction lemma (crux, fully proven):** map each boundary point to a CCW perimeter coordinate on length `L = 4*side`. For any two boundary points, `m = |dx|+|dy|` obeys `m <= a_short` (the shorter arc is a real grid path). Split by edge relation: (same/adjacent edges) the arc through the shared corner equals the L1 path and is the shorter arc, so `a_short = m`; (opposite edges: bottom-top or left-right) `m >= side` and one can show `a_short >= side` too. Hence for every `D <= side`: `m >= D` iff `a_short >= D` pointwise. So Manhattan separation reduces exactly to circular separation over the whole binary-search range.
- **Answer bound:** the chosen `k >= 4` points have cyclic arc gaps summing to `L`, so some gap `<= L/k <= side`; Manhattan of that adjacent pair `<= gap <= side`. Optimum lies in integer `[0, side]`; binary search `lo=0, hi=side`, `mid=(lo+hi+1)//2`. (`side >= 1` so `mid >= 1`; `feasible(0)` is never needed, though it would behave fine.)
- **Perimeter mapping:** bottom `(x,0)->x`; right `(side,y)->side+y`; top `(x,side)->2side+(side-x)`; left `(0,y)->3side+(side-y)`. Injective; every corner gives the same value via either adjacent-edge formula. `coords` are strictly increasing (so the doubled array is strictly increasing, making `nxt` well-defined).
- **Feasibility(D):** `pos2 = coords + [c+L for c in coords]` (length `m=2n`). `nxt[i]` = smallest `j>i` with `pos2[j]-pos2[i] >= D`, built by a forward-only two-pointer (thresholds non-decreasing in `i`, so the pointer never rewinds; the `if j<=i: j=i+1` reset is safe because `pos2[i+1] < pos2[i+1]+D`). For each start `i in [0,n)`: jump `k-1` times via `nxt`; accept iff no jump hits `limit = i+n` (keeps points distinct inside one lap) AND the closing arc holds: `pos2[idx]-pos2[i] <= L-D`. Correctness: for a fixed start, greedy-earliest yields the minimal possible last index (`nxt` is non-decreasing), so if any valid selection starts at `i`, greedy also fits and its wrap gap is at least as large. Trying all `n=start` points covers circularity because any valid set maps to consecutive doubled indices starting at its smallest-coordinate member.
- **Consecutive gaps imply pairwise circular separation:** all `k` cyclic gaps `>= D` (the jumps) plus the wrap gap `>= D` gives `a_short >= D` for every pair, since any arc is a sum of one or more gaps. Reverse: any pairwise-separated set has all cyclic gaps `>= D`. So both conditions in the check are required and sufficient.
- **Index safety:** `limit = i+n in [n, 2n-1] < m`, so the sentinel `m=2n` is always caught by `idx >= limit` and never used to index `nxt`.
- **Complexity:** `O(n*k*log(side))`; `n <= 15000`, `k <= 25`, `< 31` search steps — well within limits.
- **Pitfalls:** do not test only "minimum circular gap" (the lemma is what makes it valid, and only for `D <= side`); do not omit either success condition (one-lap index bound AND wrap-gap bound are both needed).
