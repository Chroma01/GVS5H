- **Problem:** Two distinguishable tokens on a simple connected undirected graph. Move one token along an edge per operation, never allowing both tokens on the same vertex. Start (A=S, B=T), goal (A=T, B=S). Output min moves or -1.
- **Baseline (this file):** BFS over ordered pairs (a,b), a != b. Start (S,T), goal (T,S), transitions move one piece to a neighbor not occupied by the other. Guaranteed correct by definition. Complexity O(N^2) states and up to O(N) transitions each. On samples it yields 3, -1, 4. Too slow for N up to 2e5; keep only as a reference oracle for stress-testing the fast solution.
- **Feasibility:** answer is -1 exactly when the graph is a tree (M = N-1). On a tree the two tokens cannot pass each other, so goal is unreachable. If M >= N the configuration space is connected and a solution always exists. (Confirmed by sample 2: single edge -> -1.)
- **Naive state space:** O(N^2) ordered pairs too large for direct BFS at N = 2e5.
- **Disproven formula:** min over cycles C of dist(S,C) + dist(T,C) + |C| is WRONG. Counterexample: cycle 1-2-3-1 plus tail 1-4-5, S=5, T=4. Formula gives dist(S,C)=2 + dist(T,C)=1 + |C|=3 = 6, but true min is 10 (verified by pair-BFS). The tokens must coordinate entry into the cycle and may traverse cycle parts multiple times to avoid collision, so simple additive distance to a cycle is insufficient.
- **Structural insight:** decomposition into 2-vertex-connected blocks + bridges (block-cut tree). Tokens can only swap inside a block containing a cycle. Within a 2-connected block, swapping two specific vertices relates to shortest cycles through them; if S and T are in different blocks the tokens route through the block-cut tree to a cyclic block, swap, then continue. Exact min combines distances from S and T to the chosen cycle plus cycle length plus collision-resolution overhead. Must be validated against the baseline BFS, NOT against the disproven additive formula.
- **Approach for fast version:** still open. Candidate directions: (1) BFS on the block-cut tree with per-block swap costs derived from shortest-cycle computations; (2) reduce to a small set of BFS/Dijkstra runs on the original graph after identifying how far each token must travel before it can "pass". Any candidate must be stress-tested against the pair-BFS baseline on small random graphs (N <= 8) including trees and unicyclic graphs.
- **Edge cases to cover:** tree -> -1; S and T adjacent on a cycle; long tails attached to small cycles (the 10-case above); S or T inside the cycle vs on a tail.
