Because k >= 4, the optimal distance cannot exceed side; for any candidate D <= side, two boundary points have Manhattan distance < D exactly when their circular distance along the square perimeter is < D. Map every point to a coordinate on the perimeter of length L = 4*side, then binary search D from 0 to side. For a fixed D, sort the perimeter coordinates and check whether k positions can be chosen with pairwise circular separation at least D. This check is greedy: for each possible first point, repeatedly take the earliest point at least D ahead; success if k points fit within one full lap and the last is at least D from the first. Complexity is O(n*k*log(side)) with n <= 15000, k <= 25.
