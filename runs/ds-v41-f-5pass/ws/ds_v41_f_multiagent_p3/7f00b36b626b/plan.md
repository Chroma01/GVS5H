Only values <= threshold can participate in any edge, since lcm(a,b) >= max(a,b); larger values are isolated. For participating values, lcm(a,b) <= threshold iff both a and b divide some integer L <= threshold, namely L = lcm(a,b). Thus for each L <= threshold, all present values dividing L form a connected clique and can be unioned together. Use DSU over present values <= threshold, building buckets of present divisors for each L. Finally count DSU components plus all values greater than threshold as isolated.
