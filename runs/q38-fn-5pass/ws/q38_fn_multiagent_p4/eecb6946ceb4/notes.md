- **Input parsing:** A custom byte parser avoids creating one million token objects. Values are stored in `array('I')`, and a fixed `bytearray(1000001)` presence array is filled while parsing. `max_val` is tracked for convolution sizing.
- **Small N path:** For `N <= 2000`, split values by parity and enumerate endpoint pairs only within the same parity. If the midpoint is present, count one triplet. This avoids FFT/big-int overhead for tiny cases.
- **NumPy path:** If NumPy is available, build a float64 indicator from the presence array, use `rfft`, square the spectrum, `irfft`, round to int64, and sum `(conv[2*B] - 1) // 2` over present `B`. The FFT length is the next power of two at least `2*max_val+1`.
- **NumPy validation:** For every present middle `B`, the exact ordered-pair count at `2B` must be odd and at least 1 because it contains the self-pair plus swapped pairs. If rounded coefficients violate this, the NumPy result is rejected and the exact fallback runs. This catches many floating-point rounding failures, though an error changing a coefficient by an even amount would not be detected.
- **Exact fallback idea:** Split endpoints by parity `p`. Write each endpoint as `x = 2*t + p`. For parity `p`, form `P_p(y) = sum y^t`. The coefficient of `y^(B-p)` in `P_p(y)^2` counts ordered endpoint pairs of parity `p` satisfying `A + C = 2B`. The self-pair exists exactly when `B-p` is even, so contribution is `(coeff - self) // 2`.
- **Base-2^20 packing:** Each parity polynomial is packed into a Python integer with base `2^20`. A value with compressed index `t` sets one bit at bit offset `20*t`. For `t = 2*m`, that is byte `5*m`, bit 0. For `t = 2*m+1`, that is byte `5*m+2`, bit 4. `int.from_bytes(..., 'little')` interprets this correctly.
- **Carry safety:** With `S_i <= 10^6`, each parity contains at most `500000` values, so every convolution coefficient is at most `500000 < 2^20`. Even without parity splitting, `N <= 10^6 < 2^20`, so base `2^20` prevents carries between coefficients.
- **Product extraction:** After squaring, `to_bytes(out_len, 'little')` exposes the 20-bit coefficient fields. For even field `k = 2*m`, read bytes at `5*m` and mask with `0xFFFFF`; the mask is necessary because the third byte also contains low bits of the next field. For odd field `k = 2*m+1`, read starting at byte `5*m+2`, shift right by 4, and combine three bytes.
- **Middle parity independence:** The middle `B` need not have the same parity as the endpoints. For example `(1,2,3)` has odd endpoints and even middle. The fallback therefore checks both endpoint parities for every present `B`.
- **Optimized extraction loop:** When both parity products exist, the loop branches on `B & 1` and directly uses the corresponding byte offsets. This avoids repeated `idx = B - p` and parity checks. If only one parity exists, all values have that parity and a simpler loop is used.
- **Memory:** Parity splitting halves the integer size compared with one full convolution. Input packed bytearrays are about `1.25 MB` each, product bytearrays about `2.5 MB` each. Large temporaries are deleted as soon as possible. The NumPy path uses more memory but is usually faster when available.
- **Edge cases:** `N < 3` prints 0. Values include 1 and 10^6. Odd/even maximum values are handled by the byte-offset formulas. If one parity is empty, its product is skipped.
