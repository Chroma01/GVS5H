Use prefix sums \(S_j = \sum_{i=1}^j A_i \pmod{998244353}\), so each subarray sum is \(S_r - S_{l-1}\). Expand \((S_r - S_{l-1})^K\) with the binomial theorem, reducing the problem to maintaining sums of powers of previous prefix sums. Since \(K \le 10\), we can keep an array `power_sums[p] = \sum_{i<j} S_i^p` for \(0 \le p \le K\) and update it in \(O(K)\) per prefix. This gives an overall \(O(NK)\) solution, easily fast enough for \(N \le 2\times 10^5\).
