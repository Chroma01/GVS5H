Process the queries offline in increasing order of `X`. Maintain a Fenwick tree over positions that stores the best LIS length ending at each position using only already activated elements, i.e. elements with value at most the current `X`. When activating elements of a fixed value, first compute all their DP values from the current tree, then apply their updates together, so equal values cannot be chained. For a query `(R, X)`, after all elements with value `<= X` are active, the answer is the prefix maximum up to `R`. This yields an `O((N + Q) log N)` solution.
