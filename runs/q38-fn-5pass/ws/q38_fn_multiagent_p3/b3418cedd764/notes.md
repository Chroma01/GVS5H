- **Graph model:** The constraints define a functional graph with edges `i -> A_i`. Around every directed cycle, inequalities force all cycle nodes to have the same value. Removing cycle nodes leaves rooted trees directed toward cycles, where each child value is at most its parent value.
- **DP recurrence:** For a non-cycle node `u`, let `f_u[v]` be the number of valid assignments in its non-cycle subtree when `x_u = v`. For each child `c`, the child may take any value `t <= v`, so `f_u[v] = product_c prefix_f_c[v]`, where `prefix_f_c[v] = sum_{t=1}^v f_c[t]`.
- **Cycle contribution:** For a cycle `C`, all nodes share a value `v`. If `f_u[v]` is the attached-tree count for cycle node `u`, the component contribution is `sum_{v=1}^M product_{u in C} f_u[v]`. Independent components multiply.
- **Kahn processing:** `indeg` counts incoming edges, i.e. children in the reversed forest. Nodes with indegree zero are leaves. Processing them and decrementing their parent gives a bottom-up order. After pruning, nodes with indegree positive are exactly cycle nodes.
- **Memory optimization:** Instead of storing DP arrays for all nodes, `acc[u]` stores the partial product of processed child prefix arrays. When a node is finalized, its prefix array is immediately merged into its parent accumulator and the child accumulator is cleared. If the parent accumulator already exists, prefix computation and multiplication are combined in one loop.
- **Leaf handling:** A leaf has `f[v] = 1`, so its prefix array is `[0, 1, ..., M]`. If it is the first child of its parent, a copy of this base array is used; otherwise the parent accumulator is multiplied elementwise by `v`.
- **Cycle accumulator:** Cycle nodes are never finalized by Kahn pruning, so their `acc` arrays remain as `f_u` for attached trees. If a cycle node has no non-cycle children, its `f_u[v]` is identically `1`.
- **Modulo details:** All additions and multiplications are modulo `998244353`. Prefix sums use one conditional subtraction because each stored value is already reduced and `M < MOD`.
- **Pitfalls:** Self-loops are cycles of length one and must not be processed as tree nodes. Cycle incoming edges must not be included in attached-tree products; Kahn pruning naturally excludes them because cycle nodes are not processed. Recursive DFS is avoided to prevent recursion-depth issues.
- **Complexity:** Time is `O(NM)`, with at most a few passes over length-`M` arrays per node. Memory is much less than storing all DP arrays simultaneously in typical cases, and worst-case remains acceptable for `N, M <= 2025`.
