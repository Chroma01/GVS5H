The game is equivalent to building a complete bipartite graph on all N vertices, where each move adds one edge without creating an odd cycle. The total number of moves is `final_edges - M`, where `final_edges = A*(N-A)` for some final bipartition size A. Players influence A by choosing orientations when merging connected components. Analyze the game as an impartial game on the connected components: each component has a bipartition `(a_i, b_i)` and `r_i = a_i*b_i - e_i` missing internal edges. Derive a parity/Grundy invariant that determines the winner from the multiset of component types and M. Implement a linear-time algorithm to compute the necessary component statistics and output the winner.
