Compute prefix sums of `nums` and `cost` so each subarray cost can be evaluated in O(1). Use dynamic programming where `dp[i][r]` is the minimum cost to partition the first `r` elements into exactly `i` subarrays. The transition over the previous cut can be rewritten as a line-query problem: for fixed `i`, minimize `dp[i-1][l] - (prefixNums[r] + k*i) * prefixCost[l]`. Because prefix sums are strictly increasing, the slopes and query points are monotonic, allowing a monotonic convex hull trick to optimize the DP to O(n^2) total time. Finally, return the minimum `dp[i][n]` over all valid numbers of subarrays.
