The feasibility is governed by parity: each red move flips the checkerboard color, so R must be even; if there are no red pieces, blue moves also force B even. These conditions are sufficient. For R>0, build a simple orthogonal red cycle with a distinguished adjacent red edge, then replace that edge by a simple diagonal blue path of length B, choosing the path shape according to B parity. Handle R=0 and B=0 as separate pure blue/red cycles, and shift all constructed coordinates into the valid board range.
