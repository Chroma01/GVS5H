The remaining Snowflake Tree is determined by a center c, a nonempty set of its chosen neighbors, and a positive integer y retained leaves attached to each chosen neighbor. For a fixed center c and y, the best kept size is 1 + (y+1)*k, where k is the number of neighbors v of c with at least y available non-center neighbors. Thus the answer is N minus the maximum such kept size over all centers and positive y. The main work is computing this maximum efficiently using neighbor degrees.
