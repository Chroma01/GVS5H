Process queries offline in increasing order of `R`, maintaining the standard LIS DP for the prefix `A[1..R]` in a Fenwick tree over compressed values. For each new element `A_i`, compute its LIS-ending length as `1 + max dp[j]` over previous values strictly smaller than `A_i`, then update the Fenwick tree at `A_i`. For a query `(R, X)`, after processing up to `R`, the answer is the maximum DP value among values `<= X`, because any increasing subsequence ending with a value `<= X` automatically uses only values `<= X`. This gives an `O((N+Q) log N)` solution.
