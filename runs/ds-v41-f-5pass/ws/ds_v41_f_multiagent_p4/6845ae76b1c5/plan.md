We need to answer K queries, each asking the sum of absolute differences between prefixes of two arrays A and B. The constraints N≤1e5, K≤1e4 suggest an offline approach with precomputation. We can divide A and B into blocks of size S≈250. Precompute for every pair of blocks the sum of |A_i - B_j|. This gives a 2D prefix sum to answer the "full blocks × full blocks" part in O(1). The remaining partial blocks are handled offline: for each query, the partial A elements interacting with B prefix Y, and partial B elements interacting with A prefix fullA*S. We process these with Fenwick trees while sweeping Y and X, using the identity |a-b| = a*count(b≤a) - sum(b≤a) + sum(b>a) - a*count(b>a). This yields O(N^2/S + K*S log N) time, which is efficient for the given limits.
