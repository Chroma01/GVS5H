- **Reformulation:** Choosing edges of weight 1 maximizes the minimum number of chosen edges over all directed 1-to-N paths. Choosing exactly K edges is equivalent to choosing at most K edges for feasibility, because changing more edges from 0 to 1 cannot decrease any path weight.
- **Potential certificate:** For a target distance D, a set S of edges works iff every 1-to-N path contains at least D edges of S. This is equivalent to the existence of integer labels h(v) in {0,...,D} with h(1)=0, h(N)=D, and h(v) <= h(u)+1 for every edge u->v, such that the number of edges with h(v)=h(u)+1 is at most K. Given S, capped shortest distances from 1 using S as unit weights give such labels, and every +1 transition edge must belong to S. Given labels, choosing exactly the +1 transition edges certifies distance at least D because along any path the label increases by at most 1 per edge and must increase by D total.
- **Layered min-cut:** Use boolean variables x_{v,l} = [h(v) >= l]. Source side means True. Force h(N)=D by INF edges source -> (N,l). Force h(1)=0 by INF edges (1,l) -> sink. Enforce monotonicity x_{v,l+1} => x_{v,l} with INF edges (v,l+1) -> (v,l). Enforce h(v) <= h(u)+1 with INF edges (v,l) -> (u,l-1) for l>=2. Count +1 transitions for original edge u->v with capacity-1 edges (v,l) -> (u,l) for all l; this edge is cut exactly when x_{v,l}=True and x_{u,l}=False.
- **INF and flow limit:** Since only feasibility with at most K edges matters, INF=K+1 is enough. Any invalid cut cuts at least one INF edge and has capacity >K. Run max flow with limit K+1; feasible iff max flow <=K.
- **Upper bound and search:** The answer is at most K and at most the unweighted shortest path length L from 1 to N. Binary search D in [0, min(K,L)]. D=0 is always feasible.
- **Implementation details:** Vertices are 0-indexed. Node id for (v,l) is v*D+(l-1). Multi-edges are kept as separate unit-capacity counting edges, so each parallel edge is counted separately. BFS computes L. Dinic is used with recursive DFS and a recursion limit increase.
- **Edge cases:** Parallel edges can force answer 0 if K is smaller than the number of parallel shortest paths. Irrelevant vertices or cycles do not break the potential formulation. If K=M, the answer becomes L. If no positive D is feasible, output 0.
- **Complexity:** D <= min(K,N-1) <= 29. Each feasibility test has O(ND) nodes and O(ND+MD) edges, at most a few thousand edges. Binary search uses O(log N) tests, easily fast enough in Python.
