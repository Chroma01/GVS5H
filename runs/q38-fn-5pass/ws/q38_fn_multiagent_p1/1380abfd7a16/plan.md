Reconstruct the final array in reverse order. When element i was inserted, it became the P_i-th element among the i elements present at that time, so if we remove elements from N down to 1, element i must occupy the P_i-th currently empty position in the final array. Maintain a Fenwick tree over N slots where each empty slot has value 1, and support finding the index of the k-th empty slot. For i from N down to 1, place i at the P_i-th empty slot and mark that slot as occupied. This gives O(N log N) time and O(N) memory, suitable for N up to 5×10^5.
