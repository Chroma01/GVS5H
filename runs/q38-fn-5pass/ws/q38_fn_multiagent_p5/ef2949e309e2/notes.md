- **Validation:** The implementation matches all provided examples. A brute-force checker that enumerates every 5-index subsequence, counts frequencies, and verifies that the third selected value is the unique mode agrees on small random arrays; no counting formula changes were needed.
- **Core pivot idea:** Fix the middle selected index `k` with value `x`. Choose two indices from the left of `k` and two from the right. Let `a` and `b` be the number of additional `x` values chosen on the left and right. The middle value is the unique mode iff `1+a+b` is strictly larger than every other selected value's frequency.
- **Case split:** If `a+b >= 2`, then `x` appears at least three times and the other selected values total at most two, so `x` is always the unique mode. If `a+b = 1`, then `x` appears exactly twice and the three non-`x` selected values must be pairwise distinct. If `a+b = 0`, `x` appears once and cannot be the unique mode.
- **Counting `a+b >= 2`:** For each side, count pairs by how many `x` values they contain: 2, 1, or 0. Add all combinations whose total extra `x` count is at least 2: `L2*(R2+R1+R0) + L1*(R2+R1) + L0*R2`.
- **Distinct non-x pair count:** For a side with `nonx` non-`x` elements, the number of unordered pairs of non-`x` indices with distinct values is `C(nonx, 2) - sum_{v != x} C(freq[v], 2)`. Maintain `left_dup` and `right_dup`, the sums of `C(freq[v], 2)`, incrementally so this value is computed in O(1) per pivot.
- **Excluding a specific value y:** If `D` is the distinct non-`x` pair count for a side, then the number of such pairs that also avoid value `y` is `D - freq[y] * (nonx - freq[y])`, because the subtracted term counts all distinct-value pairs containing one `y` and one other non-`x` value.
- **Exactly one extra x:** If the extra `x` is on the left, multiply by `lx`, choose a left non-`x` value `y`, and choose a right distinct non-`x` pair avoiding `y`. Sum over `y` present on the left. The case where the extra `x` is on the right is symmetric.
- **Pivot movement:** Initialize left with indices `0,1` and right with indices `3..n-1` for pivot `2`. After processing pivot `k`, move `nums[k]` into left and remove `nums[k+1]` from right, updating totals and duplicate-pair sums.
- **Complexity:** There are O(n) pivots. The always-valid case is O(1) per pivot. The exactly-one-extra case scans dictionary keys, O(distinct) per pivot, giving O(n^2) worst-case time and O(n) memory. This is safe for `n <= 1000`.
- **Edge cases:** `n = 5` has only pivot index 2. All equal values reduce to counting all C(n,5) subsequences. All distinct values return 0. Negative values are handled naturally by dictionary keys. Modulo is applied after each pivot contribution.
