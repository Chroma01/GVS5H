- **Core model:** Each operation defines a pair of original indices. A pair can be removed only after all indices between it have already been removed, so the pairs form a non-crossing matching. If N is odd, the final survivor splits the array into two independent even-length intervals; its 1-based index must be odd, equivalently its 0-based index is even.
- **Even interval value:** For an even interval of length 2k, the maximum score equals the sum of its k largest values minus the sum of its k smallest values. Upper bound: each pair contributes one larger and one smaller element, so the sum of larger elements is at most the sum of the k largest values, and the sum of smaller elements is at least the sum of the k smallest values. Achievability: mark the k largest values positive and the k smallest negative. Since every positive is at least every negative and the counts are equal, the current sequence always has adjacent opposite signs; remove such a pair repeatedly. The total score is exactly the difference of the two marked sums.
- **Prefix computation:** Scan left to right. Maintain low as a max-heap stored with negative values, containing the smallest floor(i/2) elements, and high as a min-heap containing the largest ceil(i/2) elements, along with their sums. Insert x into high if high is empty or x >= high[0], otherwise into low. Rebalance so len(high) is either len(low) or len(low)+1, moving the minimum of high to low or the maximum of low to high as needed. For every even i, pref[i] = sum(high) - sum(low).
- **Suffix computation:** Run the same routine on reversed(A). If suff[j] is the value for the first j elements of the reversed array, it is the value for the last j elements of the original array.
- **Combination:** If N is even, the answer is pref[N]. If N is odd, try every survivor position p with 0-based even index. The left part has length p and the right part has length N-p-1, both even, so the answer is max(pref[p] + suff[N-p-1]).
- **Complexity and edge cases:** Time O(N log N), memory O(N). Python integers handle sums up to about 1.5e14. Duplicates are safe because equal values may be split between the two halves. The loop includes survivor positions at both ends, and pref[0] and suff[0] are zero.
