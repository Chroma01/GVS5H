Model each possible palindrome path by its two endpoints. Use a multi-source BFS on the N*N state graph where state (u,v) means a palindrome path from u to v. Initialize (i,i) with distance 0 and every directed edge (i,j) with distance 1; from a state (u,v), add two edges by choosing a letter c, an incoming edge x->u labeled c, and an outgoing edge v->y labeled c, reaching (x,y). The first time a state is reached gives the shortest palindrome length for that pair, and unreachable states remain -1. Precompute incoming/outgoing lists by letter (or bitsets) to make the worst-case transitions practical for N=100.
