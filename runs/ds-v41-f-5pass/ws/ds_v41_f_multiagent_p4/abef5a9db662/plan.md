Maintain an array `dp[x]` for all possible initial ratings `x` up to the maximum constraint, where `dp[x]` is the rating after processing the contests so far. Initially `dp[x] = x`. Because each contest maps ratings monotonically, `dp` stays nondecreasing, so for each contest `[L_i, R_i]` the initial ratings that get incremented form one contiguous interval of indices. Locate that interval by finding the first `x` with `dp[x] >= L_i` and the last `x` with `dp[x] <= R_i`, then add 1 to that range. Use a lazy segment tree with range-add and max/min information to support these searches and updates efficiently. Finally, answer each query `X` by reading `dp[X]`.
