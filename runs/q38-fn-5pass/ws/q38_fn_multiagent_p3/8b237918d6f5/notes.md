- **Reduction:** For target distance D, it is enough to ask whether at most K edges can make every 1-to-N path contain at least D chosen edges. If c <= K works, pad to exactly K; increasing weights cannot lower any path weight.
- **Potential dual:** D is feasible iff there are integer potentials p_v in [0,D] with p_1=0, p_N=D, and p_v <= p_u+1 for every edge u->v. Given p, choose edges with p_v=p_u+1. Along any 1-to-N path the potential rises by D and each edge rises by at most 1, so at least D chosen edges appear. Conversely, from a chosen set S take p_v=min(D, minimum number of S-edges on a path from 1 to v); then p_N=D, constraints hold, and only S-edges can have p_v=p_u+1. Thus the minimum number of edges needed for D equals the minimum possible count of +1 edges over such potentials.
- **Threshold min-cut:** Use binary variables x_{v,i}=1 iff p_v>=i, with source side meaning 1. Add INF edge (v,i)->(v,i-1) for monotonicity. For each original edge u->v and i>=2 add INF edge (v,i)->(u,i-1) to enforce p_v<=p_u+1. For each original edge and i=1..D add capacity-1 edge (v,i)->(u,i); under the constraints this is cut exactly once when p_v=p_u+1. Force p_1=0 with (1,i)->sink INF and p_N=D with source->(N,i) INF. The min s-t cut value is the minimum number of +1 edges.
- **INF and flow limit:** Since we only compare with K, setting INF=K+1 and stopping max-flow at K+1 is sufficient: any cut using an INF edge costs >K, while a valid cut of value <=K uses none. This keeps capacities small and allows early exit.
- **Search bounds:** D cannot exceed K (only K selected edges total) nor the unweighted shortest path length L (that path has L edges). Feasibility is monotone decreasing in D, so binary search on [0, min(K,L)]. D=0 is always feasible.
- **Implementation notes:** Dinic with recursive DFS and a raised recursion limit. Multi-edges are kept as separate capacity-1 edges, so multiplicities are counted. BFS computes L on the original directed graph. If the graph were unreachable, output 0, though the statement guarantees reachability. Edge directions in the cut are critical: cost edges go from head to tail, implications go from higher level of head to lower level of tail.
