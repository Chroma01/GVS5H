- **Model:** Valid colorings are Ferrers diagrams. If `a_r` is the number of black cells in row `r`, the row and column conditions are equivalent to `0 <= a_N <= ... <= a_1 <= N`. A fixed black cell `(x, y)` forces `a_x >= y`, and a fixed white cell `(x, y)` forces `a_x <= y - 1`.
- **Dominance condition:** A fixed white cell `(xw, yw)` and a fixed black cell `(xb, yb)` are incompatible exactly when `xw <= xb` and `yw <= yb`. Necessity follows from monotonicity of `a_r`. Sufficiency follows by constructing `a_r = min(N, min_{white cells with xw <= r}(yw - 1))`; if no forbidden pair exists, every black cell at row `r` has `y <= a_r`.
- **Chosen algorithm:** Sort fixed cells by row ascending, with white cells before black cells in the same row. Sweep top to bottom while maintaining `min_white`, the smallest column among all white cells already seen. For each black cell at column `y`, if `min_white <= y`, then some white cell is above or in the same row and not to the right, so output `No`. Otherwise update `min_white` for white cells. If the sweep finishes, output `Yes`.
- **Same-row ordering:** White-before-black is essential. A white cell left of a black cell in the same row is impossible and must be detected. A black cell left of a white cell in the same row is allowed. Sorting by `(row, order, column)` with `order = 0` for `W` and `order = 1` for `B` handles this correctly.
- **Edge cases:** A white cell in column 1 sets `min_white = 1`, making any black cell at column at least 1 below or in the same row impossible. A black cell before any white cell is locally okay. Having no whites or no blacks yields `Yes`. The value of `N` is only an implicit upper bound and does not need to be used directly; a large sentinel for `min_white` is sufficient.
- **Complexity:** Sorting dominates the runtime, giving `O(M log M)` time and `O(M)` memory, which is safe for `M <= 2e5`.
- **Implementation status:** The program reads stdin, applies the dominance sweep, and prints `Yes` or `No`.
