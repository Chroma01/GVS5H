The cost of each operation equals the weighted sum S = Σ A_k C_k after the chosen bit is flipped, so flipping a 1 to 0 subtracts its C_i from S, while flipping a 0 to 1 adds its C_i to S. Only indices where A_i != B_i need to be flipped: those with A_i=1,B_i=0 must become 0, and those with A_i=0,B_i=1 must become 1. An exchange argument shows all 1→0 flips should be done before all 0→1 flips, with 1→0 flips ordered by decreasing C_i and 0→1 flips ordered by increasing C_i. Simulate this optimal order by updating S and accumulating the post-flip sum as cost. Use 64-bit integers because the total cost can exceed 32-bit range.
