- **Core structure:** Each chosen operation covers either its interval or the complement. A solution of cost 1, 2, or 3 is enough when M >= 3; otherwise only cost 1 or 2 can work.
- **Cost 1:** Exists iff some interval is [1, N], using type 1. This is checked first.
- **Cost 2 structures:** Two non-zero operations can cover all positions only as: two type-1 intervals whose union is [1, N]; two type-2 operations on disjoint intervals; or type 1 on an interval containing another interval used as type 2.
- **Ordering:** After cost 1, run the sorted sweep for disjoint/containment pairs before the two type-1 endpoint check. This makes sample 1 report the mixed type-2/type-1 solution rather than a two type-1 solution.
- **Sweep grouping:** Sort by L ascending and R descending. Process equal-L intervals as a group. Keep min R and max R only from strictly earlier L groups. For the current group, first test disjointness using the earlier min R, then test containment against the earlier max R for every interval in the group. Only if no earlier-group containment exists and the group has at least two intervals, use the first two intervals in the group as a same-L containment pair. Update the earlier min/max after all checks for the group.
- **Why grouping works:** Disjoint intervals cannot have the same L. Containment with a smaller L is caught by the earlier max R. Containment with equal L is caught by the group size. Checking earlier groups before same-L pairs prevents a same-L interval with larger R from hiding a previous container, which is needed for the sample output.
- **Two type-1 check:** If the sweep finds no cost 2, check whether an interval starting at 1 and an interval ending at N overlap or touch. Keeping the maximum R among L=1 intervals and the minimum L among R=N intervals is sufficient; they cover all integer positions when max_R + 1 >= min_L. A full interval would already have returned cost 1.
- **Fallback cost 3:** If no cost 1 or 2 exists and M >= 3, take p with maximum L and q with minimum R. If p != q, type 2 on p and q covers everything outside [max_L, min_R]. Any third interval contains that intersection, so type 1 on it completes coverage. If p == q, that interval is contained in every other interval, giving a cost-2 mixed solution when M >= 2.
- **Impossible cases:** With M < 3, if neither cost 1 nor cost 2 is found, output -1. The cost-2 checks cover all possible two-operation structures.
- **Complexity:** O(M log M) time for sorting and O(M) memory. N is used only for endpoint comparisons.
