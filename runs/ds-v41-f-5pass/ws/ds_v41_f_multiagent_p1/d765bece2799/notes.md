- **Problem shape:** answer = (sum of subarray minimums) + (sum of subarray maximums), restricted to subarrays of length at most k. The two passes are fully independent.
- **Core method:** per-element contribution. For each i find a dominance span `left_count = i - P` and `right_count = N - i` where P/N are the tie-broken nearest barriers. Contribution = `nums[i] * pairs(left_count, right_count)`.
- **Tie-breaking (avoids double counting):** attribute every subarray to its *rightmost* minimum / *rightmost* maximum. Min pass: `prev_less` = nearest left index with `nums[j] < nums[i]` (pop while `>=`), `next_le` = nearest right index with `nums[j] <= nums[i]` (pop while `>`). Max pass: mirror with strict `>` on the left (pop while `<=`) and `>=` on the right (pop while `<`). Both stacks are O(n).
- **Bounded-pair count (the k cap):** with `a` left choices and `b` right choices, let `u in [0,a-1]`, `v in [0,b-1]`; a valid subarray needs `u+v+1 <= k`, i.e. `u+v <= cap` where `cap=k-1`. Set `A=a-1, B=b-1`. Define `tri(t) = 0 if t<0 else (t+1)(t+2)/2` (nonneg pairs with sum <= t). Then `pairs = tri(cap) - tri(cap-A-1) - tri(cap-B-1) + tri(cap-A-B-2)`. This is exact for all regimes (cap small, cap huge, degenerate A/B=0). Verified by hand on [1,2,3]k=2 -> 20, [1,-3,1]k=2 -> -6, and many duplicate/negative cases.
- **Why inclusion-exclusion works:** `tri(cap)` counts all nonneg `(u,v)` with `u+v<=cap`; subtract the two violated-bound copies via the shift substitution `u'=u-A-1` etc.; add back the double-violated region.
- **Complexity:** O(n) time, O(n) memory, n up to 80000 — well within limits. Python big ints handle the ~O(n^2 * value) magnitude safely.
- **Edge cases covered:** k=1 (only single elements), k>=n (tri cap large -> full product a*b), all-equal arrays (min and max both attribute to rightmost, each subarray counted once each), strictly monotonic arrays, negatives (no special handling needed).
- **Stress test:** main block compares against O(n*k) brute force on 2000 random arrays (n<=9, values in [-4,4], random k). All passed. Also asserts the two provided examples.
