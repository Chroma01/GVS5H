Solve by viewing each 1 as needing to be moved into a final contiguous block whose length equals the number of 1s. If the original 1 positions are p[1..K], then for a target block starting at l, the j-th 1 should end at l+j-1, so the cost is sum |p[j] - (l+j-1)|. Rewrite this as sum |(p[j]-j) - (l-1)|, which is minimized by choosing l-1 as a median of the values p[j]-j. The answer is therefore the sum of absolute deviations from that median, computable in O(N) after collecting the positions of 1s.
