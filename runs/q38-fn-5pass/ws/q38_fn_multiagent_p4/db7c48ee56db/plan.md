Use the complement symmetry of XOR: if we know the XOR of all N elements, then the XOR of any K chosen elements equals total_xor XOR the XOR of the N-K excluded elements. Let M = min(K, N-K), so we only need to enumerate subsets of size M, and the constraint guarantees C(N, M) <= 10^6. If K <= N-K, maximize the XOR of each M-subset directly; otherwise, maximize total_xor XOR subset_xor for each excluded M-subset. Enumerate combinations on the fly without storing all subsets, and handle M = 0 separately.
