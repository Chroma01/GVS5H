- **Problem restatement:** Delete minimum vertices so remaining tree is a snowflake: one center c, x blue neighbors of c, and each blue vertex has exactly y leaves. Both x and y must be positive.
- **Selection condition:** For fixed center c and fixed y, a neighbor v of c can be blue iff deg(v)-1 >= y, because v needs y neighbors other than c to become leaves. All such neighbors can be chosen simultaneously; their leaf sets are disjoint in a tree. Maximum kept size for c,y is 1 + (y+1)*cnt_c(y), where cnt_c(y) is the number of neighbors of c with deg(neighbor)-1 >= y. Answer is N minus the maximum kept size.
- **Global sweep:** Let cap(v)=deg(v)-1. Iterate y from max cap down to 1. Active vertices are those with cap >= y. For each center c, cnt[c] counts active neighbors. When activating v, increment cnt[c] for every neighbor c of v. max_cnt is the maximum cnt[c] over all centers. Since the active set only grows as y decreases, max_cnt never decreases and can be updated on increments.
- **Evaluation:** At each y, if max_cnt > 0, evaluate kept = 1 + (y+1)*max_cnt. This automatically enforces x >= 1; y >= 1 is enforced by the loop range.
- **Complexity:** Each vertex is activated once, and its adjacency list is scanned once, so total time is O(N). Memory is O(N).
- **Edge cases:** The center may originally be a leaf; this is handled because cnt[c] is updated for every neighbor of an active vertex. Kept leaves may have other original edges, since any unwanted vertices can be deleted. The guard max_cap <= 0 is not needed under the given constraints but prevents invalid bucket access.
- **Sample checks:** Sample 1 gives max kept 7, answer 1. Sample 2 gives max kept 3, answer 0. Sample 3 gives max kept 7, answer 3.
