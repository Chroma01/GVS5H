- **Core model:** A valid permutation must alternate odd/even parity. Once a prefix is fixed, the next required parity is forced, and the number of completions depends only on the remaining counts of odd and even numbers, not on their exact values.
- **Counting completions:** If the next parity is odd, the remaining positions require `ceil(m/2)` odd slots and `floor(m/2)` even slots, where `m` is the number of remaining elements. If the next parity is even, these requirements swap. If the remaining odd/even counts do not exactly match those slot counts, the block size is zero. Otherwise the block size is `odd_remaining! * even_remaining!`.
- **Lexicographic unranking:** Build the answer position by position. At each position, try unused numbers from smallest to largest. For each compatible candidate, compute how many valid permutations have the current prefix plus that candidate. If `k` is larger than that block, subtract the block and continue; otherwise fix that candidate and proceed.
- **Capping counts:** Since `k <= 10^15`, all combinatorial counts are capped at `k + 1`. If an actual count is at least `k + 1`, the capped value is still larger than any current `k`, so the greedy choice remains correct. If an actual count is less than `k`, it is represented exactly.
- **Total validation:** For even `n`, both parity patterns are possible, giving `2 * odd_count! * even_count!`. For odd `n`, only the pattern starting and ending with odd is possible, giving `odd_count! * even_count!`. If the capped total is less than `k`, return an empty list.
- **Edge cases:** `n = 1` has exactly one permutation. For odd `n`, starting with an even number yields zero completions and is naturally skipped by the count function. For even `n`, both starting parities are possible and are interleaved correctly by numeric candidate order.
- **Complexity:** Precomputation is `O(n)`. Construction tries at most `n` candidates for each of `n` positions, with `O(1)` counting, so total time is `O(n^2)` and space is `O(n)`, easily within `n <= 100`.
