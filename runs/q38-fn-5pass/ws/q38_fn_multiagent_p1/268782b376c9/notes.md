A brute-force BFS/enumeration verifier for small `n` (up to 4) and small `m` (up to 8) over small point values was checked against the current solution; no mismatches or failing cases were found. The verifier enumerates all valid walks up to `m`, computes visit counts and scores, and compares the maximum minimum score with the binary-search feasibility result.
- **Reduction:** For target score `x > 0`, index `i` needs `r_i = ceil(x / points[i])` visits. If `m < n`, some index is unvisited, so the answer is `0`. Total visits equal the number of moves, so `sum(r_i) <= m` is a necessary condition.
- **Fixed ending position `t`:** After the forced first move to `0`, a walk ending at `t` must cross edges left of `t` an odd number of times and edges right of `t` an even number of times. The minimal base walk is `-1 -> 0 -> ... -> n-1 -> ... -> t`, using `base(t) = 2n - 1 - t` moves.
- **Base visits:** For ending at `t`, base visits are: `1` for `i < t`, `2` for `t <= i < n-1`, and `1` for `i = n-1`.
- **Extra moves:** Any extra movement can be decomposed into pairs of traversals on edges. One pair on edge `j` adds one visit to both endpoints `j` and `j+1`. For fixed `t`, deficits are `d_i = max(0, r_i - base_visit_i)`.
- **Deficit cover dual:** Minimum extra pairs needed to cover deficits is the minimum `sum y_j` with `y_{i-1} + y_i >= d_i` and boundary variables treated as zero. Its dual is a maximum-weight independent set on the path with vertex weights `d_i`. Total moves for ending at `t` is `base(t) + 2 * MWIS(d)`.
- **Weights by `t`:** Define `A_i = max(0, r_i - 1)`, `B_i = max(0, r_i - 2)` for `i < n-1`, and `C = max(0, r_{n-1} - 1)`. For ending at `t < n-1`, weights are `A` before `t`, `B` from `t` to `n-2`, and `C` at the last index. For `t = n-1`, weights are `A` before the last index and `C` at the last index.
- **All `t` in O(n):** Compute prefix DP on `A[0..n-2]` with states whether the last prefix vertex is chosen. Compute suffix DP on `B[0..n-2] + C` with states whether the first suffix vertex is chosen. Combine at boundary `t-1 / t` as `max(pref0 + max(suff0, suff1), pref1 + suff0)`. `t=0` uses suffix only.
- **Binary search:** Feasibility is monotone. Upper bound used is `min(min(points) * (m - n + 1), max(points) * m // n)`. The first term bounds visits to the minimum-point index; the second bounds the minimum by average total score.
- **Implementation details:** `can(x)` first checks the necessary condition `sum r_i <= m`. It reuses arrays across binary-search calls. `x = 0` is trivially feasible.
- **Edge cases:** `n = 2`, `t = 0`, `t = n-1`, clipping `B` and `C` at zero, and `m < n` are handled explicitly. Parity is naturally handled because extra moves are added in pairs.
- **Complexity:** Each feasibility check is `O(n)`, and binary search runs over at most about 50 values, so the solution is comfortably within limits for `n <= 5 * 10^4`.
