Use combinatorial unranking over lexicographic order. Precompute factorials capped above 10^15 so counts never overflow, and compute the total number of alternating permutations; return an empty list if k exceeds it. Build the answer position by position: at each step, try unused numbers in increasing order, keep only those whose parity can still lead to a valid alternating sequence, count how many completions each choice allows, and subtract those counts from k until the correct choice is found. The completion count for a valid choice is the product of factorials of the remaining odd and even counts, because once parity positions are fixed, odd and even numbers can be permuted independently.
