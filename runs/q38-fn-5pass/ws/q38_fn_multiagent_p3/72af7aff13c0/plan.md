Transpose the grid if needed so that the number of rows is the smaller dimension K = min(H, W), hence K <= sqrt(200000) ≈ 447, and process the larger dimension as columns. Maintain prefix DP vectors L[c] (values entering column c) and suffix DP vectors S[c] (sums from cells in column c to the sink), with a boundary vector S[N] where only the last row is 1. Because updates happen at a cursor that moves one cell at a time, keep the current column’s “after-column” vector D = L[c+1] and suffix S[c] lazily: after moving right D may be stale, after moving left S[c] may be stale, otherwise both are correct. For an update at (r,c), compute the prefix-excluding value using L[c][r] and D[r-1] (computing D up to r if stale) and the suffix-excluding value using S[c][r+1] and S[c+1][r] (computing S below r if stale), update the answer by (new-old)*prefix*suffix, then recompute D from r downward and S from r upward. This gives O(HW) preprocessing, O(HW) memory, and O(K) work per query, avoiding division and handling zeros safely.
