Use sqrt decomposition on the prefix indices. Partition A and B into blocks of size about 700, precompute the absolute-difference sum for every pair of full blocks, and build a 2D prefix sum over these block-pair values. Also precompute, for every element, its total absolute difference to all elements in each prefix of full blocks of the opposite sequence, storing these snapshots compactly as 64-bit arrays. For each query, combine the full-block prefix answer, add partial-A vs full-B and partial-B vs full-A contributions from the precomputed element arrays, and compute the remaining partial-partial contribution by sorting the two short slices and using a two-pointer scan (or direct loops for tiny slices). This gives roughly O(N^2/B + K B log B) time and O(N^2/B) memory, which is feasible with B around 700.
