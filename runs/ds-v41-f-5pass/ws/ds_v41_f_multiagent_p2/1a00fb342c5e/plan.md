Model the constraints as a graph with N vertices and M edges, where each edge (x, y, z) enforces A_x XOR A_y = z. Use DFS/DSU with parity to check if the graph is consistent and to compute relative XOR values p[v] within each connected component. Because XOR acts independently on each bit, optimize each bit separately per component: choose the root's bit (0 or 1) that minimizes the number of vertices with a 1 in that bit. Combine the chosen bits for all components to obtain the final A_i, or output -1 if a contradiction is found. This approach runs in O((N + M) * 31) time.
