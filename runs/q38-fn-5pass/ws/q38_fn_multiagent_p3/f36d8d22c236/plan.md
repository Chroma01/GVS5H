Treat each distinct character in S as a token whose final character is forced by T; if one source character is forced to two different targets, output -1. Operations only merge current tokens, so tokens with different final targets can never be merged, reducing the problem to a functional graph on 26 letters with edges from a used character to its forced target. Count non-self edges, and count directed cycles whose every node has indegree 1 (isolated cycles), because each such cycle needs one extra operation to use a temporary empty letter. A temporary empty letter is available if some letter is unused in S or some target letter has indegree at least 2 from distinct source letters. If isolated cycles exist but no buffer is available, output -1; otherwise output non-self edges plus isolated cycles.
