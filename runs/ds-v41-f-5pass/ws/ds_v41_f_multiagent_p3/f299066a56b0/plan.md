We need to maximize the number of non-overlapping pairs where the top mochi is at most half the bottom mochi. Since the sizes are sorted, binary search on the number of pairs K. For a fixed K, the best strategy is to use the K smallest mochi as tops and the K largest as bottoms, paired in sorted order. Feasibility holds exactly when for every i from 0 to K-1, 2*A[i] <= A[N-K+i]. Binary search the largest feasible K in the range [0, N//2].
