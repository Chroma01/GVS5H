- **Problem restated:** partition all NK vertices of a tree into N vertex-disjoint paths each with exactly K vertices. Output Yes/No.
- **Forced-edge theorem (key result):** Removing any edge splits the tree into sides of size s and NK-s. Since paths are disjoint, at most one path crosses the edge; a path crossing uses vertices on both sides (1..K-1 on each), giving a residue contradiction if s ≡ 0 (mod K). Hence edge is used by some decomposition iff s mod K != 0, and it is forced. Therefore the used-edge set is exactly the forced set, independent of decomposition.
- **Why forced edges must all be used:** if s not divisible by K, vertices in that side cannot be covered by internal K-paths alone, so at least one path crosses; at most one crosses => exactly one uses the edge.
- **Why non-forced edges cannot be used:** if s divisible by K and a path crosses, it contributes t (1<=t<=K-1) vertices to that side, so t ≡ 0 mod K, contradiction.
- **Component-size invariant:** remove a connected component C of the forced subgraph; each remaining piece attaches to C by exactly one edge (tree), that edge is non-forced, so each piece has size ≡ 0 mod K. Thus |C| ≡ NK ≡ 0 mod K, i.e. every component size is a positive multiple of K.
- **Degree criterion is sufficient (and necessary):** In a decomposition each vertex has at most 2 used (forced) edges. Conversely, if every vertex has forced degree <= 2, the forced subgraph in a tree is a disjoint union of paths. Rooting a path component v1..vm and noting each hanging subtree is ≡ 0 mod K, we get sz[v_{i+1}] ≡ (m-i) mod K; forcing every internal edge requires no m-i divisible by K for i=1..m-1. If m = jK (j>=2), i = m-K gives m-i = K, contradiction. So each component has exactly K vertices => valid decomposition.
- **Algorithm:** read N,K; m=N*K. If m==1 answer Yes. Build adjacency. BFS from node 0 recording parent and order (no recursion). Compute subtree sizes by reverse-order accumulation. For each vertex count forced incident edges = (#children c with sz[c] % K != 0) + (1 if non-root and sz[v] % K != 0). If any count > 2 print No, else Yes.
- **K=1:** every sz mod 1 == 0, so all forced degrees are 0 <= 2, giving Yes automatically (N=NK singleton paths). No special case needed.
- **Complexity:** O(NK) time and memory; iterative BFS avoids recursion-depth issues for NK up to 2e5.
- **Verification:** Sample 1 (3,2) gives all degrees <= 2 -> Yes; Sample 2 (3,2) vertex 3 has forced degree 3 -> No.
- **Pitfalls avoided:** recursion; correct residue direction (root choice irrelevant since m divisible by K); distinguishing children via parent[w]==u; ensuring the parent edge is only counted for the original-rooted parent relationship.
