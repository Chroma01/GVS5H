Count the frequencies of the 26 lowercase letters. For a candidate final frequency `f`, each letter is either absent (`0`) or present exactly `f` times, giving a binary choice per letter. Start from the delete/insert baseline cost `sum |cnt[i] - f*y[i]|`; changing a character more than one step is never better than deleting and inserting, so only adjacent changes `i -> i+1` can reduce cost, each saving one operation by matching a surplus at `i` with a deficit at `i+1`. This yields a chain cost depending only on adjacent binary choices, which can be minimized with a 2-state DP over the 26 letters. Enumerate `f` from `1` to the maximum initial frequency and take the minimum total cost.
