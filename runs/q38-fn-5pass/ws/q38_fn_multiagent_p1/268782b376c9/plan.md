Binary search the answer x. For a candidate x, each index i needs r_i = ceil(x / points[i]) visits; x = 0 is always feasible. Model any valid walk by edge traversal counts: if the walk ends at t, edges left of t must be traversed an odd number of times (minimum 1) and edges right of t an even number of times (minimum 2), with extra traversals added in pairs. For a fixed t, the minimum moves can be written as 2n - 1 - t plus twice a maximum-weight independent set on a path, where the weights are r_i - 1 before t, r_i - 2 from t to n-2, and r_{n-1} - 1 for the last index, all clipped at 0. Compute this independent-set value for every possible t in O(n) using prefix DP for the “high” weights and suffix DP for the “low” weights, then combine at the boundary. The candidate is feasible iff the minimum moves over all t is at most m.
