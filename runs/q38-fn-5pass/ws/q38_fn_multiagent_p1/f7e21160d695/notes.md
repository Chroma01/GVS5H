- **Core observation:** f(x, y) is the smallest threshold t such that x and y are connected using only edges of weight at most t. Processing edges in increasing weight with DSU gives exactly these bottleneck thresholds.
- **Matching view:** Treat each occurrence in A as a +1 token and each occurrence in B as a -1 token. For any threshold, the maximum number of pairs with cost at most that threshold is the sum over current connected components of min(number of A tokens, number of B tokens). Minimizing the total sum is achieved by maximizing these counts at every threshold, which the hierarchical DSU process does.
- **Balance invariant:** After all edges below the current weight are processed, each DSU component has already matched as many opposite tokens as possible internally, so only its net balance b = count_A - count_B remains. If two components with balances b1 and b2 merge at weight w, the increase in matchable pairs is (|b1| + |b2| - |b1 + b2|) / 2. This equals min(|b1|, |b2|) when the signs differ, and 0 otherwise. Add w times this increase.
- **Equal weights:** Sequential unions at the same weight are safe. For any connected group of components joined by edges of one weight, the total number of newly matchable pairs equals min(total positive surplus, total negative surplus), independent of union order. Union by size does not affect this total.
- **Implementation details:** Use zero-indexed vertices. Build edges as tuples (w, u, v), initialize balance from A and B, sort edges, and maintain DSU arrays parent, size, and balance. On each successful union, add the weighted match count when balances have opposite signs, then merge balances. Python integers safely handle the maximum answer around 2e14.
- **Edge cases:** Duplicate vertices in A or B are handled naturally by counts. Zero-balance components contribute no matches. If a vertex appeared in both sequences, net cancellation would correspond to zero-cost matches, though the statement guarantees this does not happen. The graph is connected, so the final balance is zero and all tokens are matched.
- **Complexity:** Sorting dominates: O(M log M) time, plus nearly linear DSU work O((N + M) alpha(N)). Memory is O(N + M).
