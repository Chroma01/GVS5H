We will model the required transformations as a directed functional graph where each letter present in S has an edge to its unique target letter from T. If any letter in S maps to multiple different targets, the answer is immediately -1. For a valid mapping, the minimum operations equal the number of non-self edges plus one extra operation for each cycle of length greater than one, provided a temporary letter is available. A temporary letter exists if some alphabet letter is unused by S, or if a self-loop letter has an incoming edge from a different letter. We will compute the edge count, detect cycles, and verify the temporary-letter condition to decide between the computed value and -1.
