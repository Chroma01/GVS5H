Sort A, B, and C in non-increasing order; the expression is monotone in each selected element because all values are positive. The top values then lie in a monotone 3D grid, so the K-th largest can be found by best-first expansion from the best triple (1,1,1). Use a max-heap keyed by the triple value, and for each popped triple push its immediate successors (i+1,j,k), (i,j+1,k), (i,j,k+1). A visited set prevents duplicate states. Stop after K pops and output that value; complexity is O(K log K) time and O(K) memory.
