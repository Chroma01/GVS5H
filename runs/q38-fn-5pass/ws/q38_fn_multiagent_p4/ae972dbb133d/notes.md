- **Model:** Use binary variables for whether a segment endpoint exists on each torus edge. Let `h[i][j]` be the left edge of cell `(i,j)` and `v[i][j]` its top edge. The right edge is `h[i][j+1]`, and the bottom edge is `v[i+1][j]`, with indices modulo `W` and `H`.
- **Tile constraints:** Type A forces exactly one horizontal endpoint and exactly one vertical endpoint, so `h[i][j] xor h[i][j+1] = 1` and `v[i][j] xor v[i+1][j] = 1`, with no coupling between horizontal and vertical choices. Type B forces opposite endpoints, so horizontal edges are equal, vertical edges are equal, and `h[i][j] xor v[i][j] = 1`.
- **Parity checks:** Around each row, horizontal variables flip exactly at A cells, so each row must contain an even number of A tiles. Around each column, vertical variables flip exactly at A cells, so each column must contain an even number of A tiles. If either check fails, the answer is 0.
- **Reduction:** If parity checks pass, horizontal variables in row `i` are determined by one free bit `r_i`: `h[i][j] = r_i xor P[i][j]`, where `P[i][j]` is the parity of A cells to the left of `(i,j)`. Vertical variables in column `j` are determined by one free bit `c_j`: `v[i][j] = c_j xor Q[i][j]`, where `Q[i][j]` is the parity of A cells above `(i,j)`.
- **B constraints:** Each B cell adds one XOR constraint `r_i xor c_j = 1 xor P[i][j] xor Q[i][j]`. A cells add no coupling between row and column bits.
- **Counting:** Build a parity DSU on `H` row vertices and `W` column vertices. For every B cell, union row `i` and column `H+j` with the computed label. If a contradiction appears, answer 0. Otherwise each connected component contributes one free bit, so the answer is `2^(number of components) mod 998244353`. Isolated row/column vertices are included by initializing components to `H+W`.
- **Implementation:** Two passes over stored rows. The first pass computes row parity, column parity, and flags for all-A/all-B cases. The second pass maintains a row prefix parity and a column prefix array. For B cells it computes the label and performs an inline parity DSU union. All-A uses `2^(H+W)`; all-B uses `2` because the complete bipartite B graph is connected under the constraints.
- **Pitfalls:** Prefix parities must be taken before the current cell. Wrap-around parity must be checked before building constraints. DSU parity direction and same-root checks must use xor-to-root values. Isolated vertices must be counted. Labels depend on both row and column prefixes, not just the current tile.
- **Complexity:** `O(sum HW alpha(H+W))` time and `O(HW + H + W)` memory, within the limits.
