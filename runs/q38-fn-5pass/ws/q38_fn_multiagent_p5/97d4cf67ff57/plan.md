Root the tree arbitrarily and process vertices in postorder. For each vertex, compute a small DP for connected selected subtrees inside its rooted subtree that include it, distinguishing whether the vertex is open to its parent or is the highest selected vertex. If the vertex has a selected parent, it may use exactly 0 or 3 selected children; if it is the highest selected vertex, it may use exactly 1 or 4 selected children. Merge children with a knapsack over selected-child count 0..4 and a boolean flag for whether a degree-4 vertex has appeared, using each child either skipped, taken as a degree-1 leaf, or taken as an open degree-4 subtree. Update the answer from valid highest-vertex states with the flag set, and output -1 if none exists.
