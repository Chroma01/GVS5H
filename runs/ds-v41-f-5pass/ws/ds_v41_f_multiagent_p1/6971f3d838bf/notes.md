- **Problem model:** At most one operation: pick x, delete all its occurrences, but array must stay non-empty. Return max subarray sum (non-empty subarray) over all resulting arrays. n ≤ 1e5, |nums| ≤ 1e6, sums up to 1e11 -> Python ints are fine.
- **Only negatives matter:** Deleting a positive or zero can never beat the no-deletion Kadane baseline. Candidates are distinct negative values with count_v < n. If count_v == n, deletion empties the array, so skip. Always include the baseline.
- **Deletion = joining v-free blocks:** Deleting v yields concatenation of maximal v-free blocks. A deleted-array subarray spanning ≥2 blocks equals a suffix of the first block, all middle blocks in full, and a prefix of the last block. Single-block subarrays are subarrays of the original, hence ≤ baseline.
- **Block statistics via prefix sums:** P[0..n], P[i] = sum nums[0..i-1]. For block [l,r): c = P[r]-P[l], pre = max(P[l+1..r]) - P[l], suf = P[r] - min(P[l..r-1]). Iterative segment tree over P answers range max/min in O(log n). Both ranges are non-empty.
- **Spanning pass:** Per value v, walk blocks left to right with cum = sum of c of previous blocks and Q = max over previous blocks i of (suf_i - cum_{i+1}). For block j: candidate = Q + cum + pre_j (only if a previous block exists). Then update Q = max(Q, suf_j - (cum + c_j)), cum += c_j. Use None to mark "no previous block".
- **Complexity:** Total blocks across all values ≤ n + #distinct ≤ 2n, each handled with O(log n) queries -> O(n log n) time, O(n) extra space.
- **Correctness checks:** [-3,2,-2,-1,3,-2,3] baseline 4, v=-2 -> 7, answer 7. [1,2,3,4] -> 10. [-1,-1000,50,-1,50] baseline 99, v=-1 -> 100, answer 100. All-non-positive [-5,-1,-5] -> -1. [-5,-5] -> -5 (count_v == n, skip).
- **Edge cases:** n == 1 -> baseline only. All elements equal -> count_v == n skip. Consecutive equal negatives produce empty blocks, dropped by p > start. No-deletion baseline always included.
- **Disproven / superseded ideas:** The per-value score W_v = -m_v + k*|v| with m_v = min prefix before first occurrence is incorrect. The simultaneous per-value DP g_v(i) = max(g_v(i-1),0)+nums[i]+|v|*[nums[i]==v] is correct in principle but the clamp-at-zero makes global sharing hard; the block/segment-tree formulation avoids that nonlinearity.

Includes examples, edge cases (n=1, all-same, all-non-positive), and 20000 random arrays n<=9, values in [-4,4]. The script prints PASS/FAIL with first mismatching input and both outputs.
