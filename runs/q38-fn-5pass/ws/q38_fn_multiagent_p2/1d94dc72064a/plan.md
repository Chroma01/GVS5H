Model the game by the number of unmarked indices and the parity of remaining moves on already marked indices; extra moves only toggle whose turn it is, so only the parity of each `A_i` matters. A small game-theoretic reduction gives the losing/winning rule: `N=1` is always Fennec, `N=2` is always Snuke, `N=3` is Fennec iff at least one `A_i` is odd, and for `N>=4` Fennec wins iff the number of odd `A_i` is odd. Therefore the solution is to count odd elements and branch on `N`. The implementation is linear in `N` and uses only parity checks.
