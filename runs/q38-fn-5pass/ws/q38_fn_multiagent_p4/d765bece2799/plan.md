Compute the answer as the sum of all subarray minimums plus the sum of all subarray maximums, considering only subarrays of length at most k. For each element, use monotonic stacks to find the nearest smaller/greater boundaries that determine the range of subarrays where that element is the unique chosen minimum or maximum under a consistent tie-breaking rule. Then count, in O(1), how many valid left/right extensions from that element produce a subarray length at most k. Sum each element multiplied by its valid count for both minimum and maximum roles. This yields an O(n) time and O(n) space solution suitable for n up to 80000.
