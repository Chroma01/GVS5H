Model each row by the number of black cells in that row, say `a_x`; the row condition means cell `(x, y)` is black exactly when `y <= a_x`. The column condition is equivalent to requiring `a_x` to be nonincreasing as `x` increases. A black cell `(x, y)` imposes `a_x >= y`, while a white cell `(x, y)` imposes `a_x < y`. Therefore a conflict exists exactly when some black cell is not strictly above and to the left of a white cell, i.e. `x_black >= x_white` and `y_black >= y_white`. Since `N` is huge but only `M` cells are fixed, check this dominance condition efficiently with a sweep over rows.
