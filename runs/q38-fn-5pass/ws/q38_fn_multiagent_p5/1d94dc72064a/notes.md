- **Final rule:** For N=1 Fennec wins. For N=2 Snuke wins. For N=3 Fennec wins iff at least one A_i is odd. For N>=4 Fennec wins iff the number of odd A_i is odd.
- **Pass-token view:** Define c_i = A_i - 1. Opening an unopened index consumes one of its tokens and creates c_i pass tokens. A pass consumes one created token. Let k be the number of unopened indices, p the number of available pass tokens, and o the number of unopened indices with odd c_i. The game ends exactly when k becomes 0, and the player making that move wins.
- **Small k:** k=1 is always winning because the player can open the last index. For k=2, the outcome depends only on p parity: even p is losing, odd p is winning. For k=3, even p is winning iff some remaining c_i is even, and odd p is winning iff some remaining c_i is odd.
- **Base k=4:** Using the k=3 rules, for k=4 even p is winning iff o is odd, and odd p is winning iff o is even.
- **Induction for k>=4:** The invariant is: even p is winning iff o parity differs from k parity; odd p is winning iff o parity equals k parity. If the condition holds, there is an opening move that gives the opponent a losing state. If it fails, every opening gives the opponent a winning state, and a pass when p>0 also gives the opponent a winning state; when p=0 no pass exists. This propagates from the k=4 base case.
- **Initial state:** Initially p=0 and k=N. For N>=4, Fennec wins iff o parity differs from N parity. Since o counts even A_i and odd_count = N - o, this is equivalent to odd_count being odd. For N=3, the k=3 rule gives Fennec iff some c_i is even, i.e. some A_i is odd.
- **Implementation:** Scan A once, count odd values, and apply the four-case rule. Time complexity is O(N), and extra space is O(1).
