Use diagonal dynamic programming instead of brute-force extending every start. For each diagonal direction, precompute the longest alternating run of `2,0,2,0,...` starting at each cell if the starting value is `0` or `2`. Then treat each cell as a possible turn point: combine the longest valid prefix that starts at a `1` and reaches the turn cell along one diagonal direction with the precomputed alternating run continuing clockwise from that turn cell. Process directions one at a time to keep memory usage low, and separately account for straight segments and single-cell `1` segments.
