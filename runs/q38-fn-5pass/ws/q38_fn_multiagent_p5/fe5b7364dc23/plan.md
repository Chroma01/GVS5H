Use prefix sums to rewrite each subarray sum as P_r - P_{l-1}, where P_i is the prefix sum up to i. Expand (P_r - P_{l-1})^K with the binomial theorem, so the total sum can be accumulated by maintaining, for each power j = 0..K, the sum of P_t^j over all previous prefix indices t. Iterate r from 1 to N, update the answer using the stored power sums, then add P_r^j to the stored sums for the next step. This gives an O(NK) solution, which is fast enough since K <= 10.
