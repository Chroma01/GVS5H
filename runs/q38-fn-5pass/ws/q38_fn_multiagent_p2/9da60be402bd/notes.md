- **State model:** A palindrome path from `u` to `v` can be peeled by removing its first and last edges. Those two edges must have the same label, and the remaining path is again a palindrome from some `a` to `b`. Therefore the natural state is an ordered pair `(u, v)` meaning “shortest palindrome-labeled path from `u` to `v`”.
- **Bases:** Empty paths give distance `0` for every `(i, i)`. Every single edge gives distance `1` for its endpoints. A self-loop on a diagonal does not overwrite distance `0`, but its edge bits are still kept because it can be used as an outer edge in longer palindromes.
- **Transitions:** From a known palindrome state `(u, v)`, for each label `c`, every incoming edge `p -> u` labeled `c` and every outgoing edge `v -> q` labeled `c` creates a longer palindrome `p -> ... -> q` with length `dist[u][v] + 2`.
- **BFS ordering:** All distance-0 states are enqueued before all distance-1 states. Since every transition adds exactly `2`, ordinary FIFO BFS preserves nondecreasing distance order. This is important because a state can have both even and odd palindrome lengths, but the first discovery is the shortest.
- **Single distance per pair is sufficient:** If a pair has a shorter palindrome of one parity and a longer palindrome of the other parity, the shorter one dominates. Any outer extension depends only on the endpoints and the added matching labels, so applying the same extension to the shorter inner palindrome gives a strictly shorter full palindrome.
- **Bitset representation:** For each vertex and label, store predecessor and successor bitsets. `row_unvis[p]` stores which `q` values are still undiscovered in row `p`. This avoids enumerating the full Cartesian product of predecessors and successors.
- **Transition enumeration:** For a popped state `(u, v)`, iterate labels with incoming edges to `u`. If `succ = out_bits[v][c]` is nonzero, iterate over predecessor bits `p` in `in_bits[u][c]`. Then `newbits = succ & row_unvis[p]` gives all newly discovered `q` values for that `p` in one bit operation. Enumerate only those newly discovered bits to assign distances and enqueue states.
- **Complexity:** For each popped state, the number of predecessor-bit iterations is at most the indegree of `u`, which is at most `N`. With `N^2` states, total outer iterations are `O(N^3)`, at most about `10^6` for `N=100`. Each pair state is discovered once, so enumerating newly discovered bits is `O(N^2)`. Memory is `O(N^2 + 26N)`.
- **Implementation details:** Use a flat state index `u*N+v` and a flat distance array. Input is read as bytes; `'-'` is ASCII 45 and lowercase letters are ASCII 97 through 122. Sources are marked while parsing, with diagonals first and edges second, preserving queue order. The BFS stops early once all states are discovered.
- **Pitfalls:** Do not iterate over all `(p, q)` pairs directly; batch `q` values using `row_unvis[p]`. Clear `row_unvis[p]` before enumerating `newbits` to prevent duplicate discoveries. Keep self-loop edge bits even though diagonal distance remains `0`.
