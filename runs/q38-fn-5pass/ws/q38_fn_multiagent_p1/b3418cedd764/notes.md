- **Graph model:** Each constraint is an edge i -> A_i, forming a functional graph. Every component has one directed cycle with in-trees feeding into cycle nodes. Around a directed cycle, inequalities force all cycle nodes to have the same value; a self-loop is a length-one cycle with one common value.
- **Tree DP:** For a non-cycle node v, define f_v[c] as the number of assignments in the subtree rooted at v (reverse edges, excluding cycle nodes) with x_v <= c. If x_v is fixed to t, each child u independently contributes f_u[t], so exact_v[t] = product f_u[t]. Then f_v[c] = sum_{t=1}^c exact_v[t]. A leaf has f[c] = c.
- **Cycle handling:** For a cycle C, if the common cycle value is c, each cycle node v contributes e_v[c] = product over its non-cycle children u of f_u[c]. The component contribution is sum_{c=1}^M product_{v in C} e_v[c]. Important: e_v is not prefix-summed; prefixing would count cycle root values <= c instead of exactly c.
- **Algorithm:** Identify non-cycle nodes using indegree-zero queue removal. The removal order is children before parents. Build children lists containing only edges from non-cycle nodes. Process this order to compute f arrays. Then traverse each unvisited cycle, multiply child f arrays into e_v for each cycle node, multiply e_v arrays over the cycle, sum over c, and multiply component results modulo 998244353.
- **Implementation details:** Use 0-indexing and arrays of length M+1; index 0 is unused/zero. Share one immutable leaf array for all leaves. For the first child of a node, reuse its DP list if it is not the shared leaf, otherwise copy it; this moves arrays upward and reduces allocations. Set consumed child entries to None. Keep values below mod and use one subtraction after additions.
- **Complexity and edge cases:** Time O(NM), memory O(NM) worst-case but array reuse often lowers it; N,M <= 2025 makes this safe. Handles self-loops, all-cycle components (contribution M), M=1, multiple components, and nodes with many children. Samples 1 and 2 match; sample 3 follows the same DP.
