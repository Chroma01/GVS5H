- **Core reduction:** For a fixed element x, if S is the set of elements placed after x, then the number of permutations with exactly S after x is |S|! (N-1-|S|)!, and x is shifted by product_{y in S} 10^{digits(y)}. Thus the multiplier for x depends only on the digit length of x.
- **Generating function:** Let q_d = 10^d mod M and cnt_d be the count of numbers with digit length d. Define P(z)=prod_d (1+q_d z)^{cnt_d}. Its coefficient p_k is the elementary symmetric sum of products of weights over all k-element subsets. For an element of length d, the needed coefficients are those of E^{(d)}(z)=P(z)/(1+q_d z). The answer is sum_d sumVal_d * sum_{k=0}^{N-1} k!(N-1-k)! [z^k]E^{(d)}.
- **Computing P coefficients:** Since N <= 2e5, D <= 6. Let Q(z)=prod_d (1+q_d z) and R(z)=sum_d cnt_d q_d Q(z)/(1+q_d z). From QP'=RP, for n>=1: n p_n = sum_{i=0}^{min(D-1,n-1)} R_i p_{n-1-i} - sum_{i=1}^{min(D,n-1)} Q_i (n-i) p_{n-i}, with p_0=1. This gives O(ND) time using modular inverses of 1..N.
- **Polynomial Q and R:** Q is built by multiplying D linear factors. For each d, the quotient H=Q/(1+q_d z) is obtained by synthetic division: H_0=1 and H_i=Q_i-q_d H_{i-1}. Then R_i accumulates cnt_d q_d H_i.
- **Division and accumulation:** For each digit length d, recover coefficients of E^{(d)} iteratively: e_0=1 and e_k=p_k-q_d e_{k-1}. Precompute weight[k]=fact[k]fact[N-1-k] mod M. Accumulate total_d = sum weight[k]e_k. The unmodded total stays around 2e23, so it is safe to reduce only after the loop.
- **Digit grouping:** Counts and value sums are computed by ranges [10^{d-1}, min(N,10^d-1)]. sumVal_d is the arithmetic progression sum modulo M.
- **Validation:** Hand-checked for N=1,2,3 and the all-one-digit identity. The recurrence was also checked on small artificial mixed-weight polynomials. Complexity is O(ND) time and O(N) memory, with D<=6.
