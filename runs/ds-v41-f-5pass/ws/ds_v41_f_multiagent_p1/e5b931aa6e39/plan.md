Use the identity x^3 - y^3 = (x-y)(x^2+xy+y^2). Let d = x-y > 0; then d divides N and d is at most the cube root of N, so only about 10^6 values need checking. For each divisor d of N, set M = N/d and solve 3y^2 + 3dy + d^2 = M as a quadratic in y. A valid positive integer y exists iff the discriminant is a nonnegative perfect square and y = (-3d + sqrt(D))/6 is a positive integer. Then x = y+d; if no d works, output -1.
