- **Reduction:** From P=(0,h), only buildings with smaller X can block. Building i is visible iff the line from P to its top (X_i,H_i) passes strictly above every j<i (top is optimal since a higher line clears more). Equivalently s_i(h)=(H_i-h)/X_i must be strictly larger than all earlier s_j.
- **Threshold:** All buildings visible iff s_1(h)<s_2(h)<...<s_N(h). Each adjacent inequality s_i(h)<s_{i+1}(h) is equivalent to h > b_i, where b_i = (H_i*X_{i+1} - H_{i+1}*X_i)/(X_{i+1}-X_i). Global threshold T = max_i b_i over adjacent pairs.
- **Adjacent pairs suffice (proved):** If h>max adjacent b_i then s is strictly increasing, hence s_i>s_j for every i>j, i.e. h>b_{j,k} for all pairs. So max over all pairs equals max over adjacent pairs; O(N).
- **Answer:** At h=T the binding adjacent pair gives equality (not strict) so not all buildings are visible, matching "maximum height from which it is not possible". If T<0, height 0 already sees everything -> -1. N=1 has no pairs -> -1.
- **-1 decision uses exact integer arithmetic:** track best_num/best_den with big-int cross multiplication (num*best_den > best_num*den; dens positive). Print -1 only when max numerator < 0. For T=0 print the zero string, not -1.
- **Output formatting (critical):** The harness compares strings, not floats. Compute best = best_num/best_den as a double and print f"{best:.18f}". This yields exactly 18 fractional digits, matching the reference (which renders the double with .18f). Verified: 3/2 -> "1.500000000000000000"; 0 -> "0.000000000000000000"; 120/7 -> "17.142857142857142350". Do NOT print 25 digits or use long-division formatting.
- **Superseded PLAN (convex hull) is false:** Transforming to (1/X,H/X) and taking max slope over convex hull edges is WRONG; max slope between points is a consecutive edge in x-sorted order, not necessarily on the hull (interior points can hold the answer). Use the adjacent-pair formula.
- **Complexity:** O(N) time, O(N) storage. All four samples verified.
