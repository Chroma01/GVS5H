Model each letter that appears in S by the unique target letter it must become, and immediately return -1 if one source letter is required to become two different letters. Build a directed graph on the 26 lowercase letters with an edge c -> target(c) for every appearing c whose target differs from c. Each such edge contributes one mandatory operation, and each directed cycle of length at least two contributes one additional operation, provided a temporary letter can be made empty. A temporary letter is available if some letter does not appear in S, or if two appearing source letters have the same target (a compatible merge can create an empty letter); if no temporary letter is available and a nontrivial cycle exists, the answer is -1. Otherwise the minimum number of operations is the number of edges plus the number of nontrivial cycles.
