Maintain forward DP column vectors `F[c][r]` (sums from `(1,1)` to `(r,c)`) and backward DP column vectors `R[c][r]` (sums from `(r,c)` to `(H,W)`), with the invariant that all `F` columns up to the current column are fresh and all `R` columns from the current column onward are fresh. A horizontal move refreshes only the newly entered column (`F` when moving right, `R` when moving left) in `O(H)`. A point update at `(r,c)` changes the answer by `(new-old) * L * R_excl`, where `L` and `R_excl` are path sums excluding that cell and can be read from neighboring `F`/`R` values without division; then recompute the affected suffix of `F[c]` and prefix of `R[c]` in `O(H)`. This gives `O(HW + Q*min(H,W))` time, suitable for the constraints.
