Root the tree arbitrarily and process it bottom-up. For each subtree, keep only one state: `0` if it can be fully decomposed, or a length `x` in `1..K-1` if it has a unique open path segment of `x` vertices ending at the subtree root that must be extended to its parent. At a node, every nonzero child state must connect through the node, so there can be at most two such children; two must form exactly a `K`-vertex path with the node, one either completes at the node or is extended by one, and zero starts a new length-1 segment. The whole tree is decomposable iff the root ends in state `0`, with `K=1` handled trivially as always possible.
