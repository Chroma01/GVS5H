- **Operation model:** A and B are exact inverses: the reversible rewrite `0^X 1^Y <-> 1^Y 0^X` on any length-(X+Y) window. Ones never cross ones and zeros never cross zeros, and total counts of 0/1 are preserved.
- **Necessary invariants (proved):** A moves a block of exactly Y ones each by X, so the ordered list of `1`-positions modulo X is fixed; symmetrically the ordered list of `0`-positions modulo Y is fixed. The pair `(ones mod X, zeros mod Y)` (ordered, 1-indexed positions) is the signature.
- **Main solution / criterion:** S reaches T iff both ordered residue lists are equal. Equal residues force equal counts, so no separate count check is needed. For Y=1 this is the prefix-sum-mod-X invariant (completeness provable by pushing X-chips between adjacent gaps). Implemented in O(N).
- **Extra invariant found:** every move shifts the total one-position sum P1 by exactly ±XY, so `P1 mod XY` is also invariant. The signature determines `P1 mod lcm(X,Y)` (P1 ≡ Σ(one residues) mod X and ≡ C − Σ(zero residues) mod Y, with C=N(N+1)/2). Hence a hidden extra constraint could only exist when `g = gcd(X,Y) > 1`. This is the key theoretical risk; validation targets it by always including balanced (X=Y) pairs.
- **Realization branching:** a signature can have several realizations — model reconstruction as a grid path interleaving the one-parity and zero-parity sequences against the fixed position parities. Empirically all realizations of one signature are joined by the operations (e.g. `0011<->1100`, `111000<->100110`), so signature == component. No counterexample found for g>1.
- **Special case X+Y>N:** no window fits, so answer is exactly `S == T`; handled before the residue test.
- **Frozen states:** strings with no `0^X 1^Y` nor `1^Y 0^X` (e.g. count_ones<Y, count_zeros<X, or no two adjacent equal runs of the needed type) have no moves; the residue signature is injective on them, so no false `Yes`.
- **Sample checks:** Sample1 `N=9 X=2 Y=1`: ones mod 2 = `[0,1,0,1]` for both S,T -> Yes. Sample2 `N=1 X=1 Y=1`: X+Y>N and `"0"!="1"` -> No.
- **Validation program:** DSU over all `2^N` masks (bit p = char p). For each window emit edges for pattern `patA=((1<<Y)-1)<<X` and its reverse `resA=(1<<Y)-1`. Then assert the component<->signature relation is a bijection both ways; on violation print `(kind, N, X, Y, S, T)`. Union by rank + path halving, O(2^N·N) per (X,Y).
- **Expected result:** no mismatch for all N=1..12 and every (X,Y) with X+Y<=N, plus spot checks at N=13..15, so the program prints exactly `VALIDATED N<=12 all (X,Y)`. This confirms the residue criterion and the shipped main solution.
- **Complexity:** main solution O(N) time / O(N) memory; validation exponential but bounded (N<=15) with a 12-pair spot-check budget.
