Use linearity over each number x. For fixed x, choose the set B of elements after it; its contribution is x·10^{sum len(B)}·(N-|B|-1)!·|B|!, which equals x·(N-1)!·10^{sum len(B)}/C(N-1,|B|). Group numbers by decimal length d, with q_d=10^d, so the subset weights are coefficients of P(z)=∏(1+q_d z)^{c_d}. Compute P's coefficients efficiently using a small-degree logarithmic-derivative recurrence, then for each length d divide by one factor (1+q_d z) to get coefficients for excluding one d-digit number. Finally sum these coefficients against inverse binomial coefficients and combine with the sum of values in each length class.
