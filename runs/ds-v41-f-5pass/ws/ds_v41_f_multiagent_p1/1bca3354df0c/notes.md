- **Task:** Independent brute-force minimax verifier for the odd-cycle-avoiding edge-addition game; compares TRUE win/lose (memoized minimax) against the current candidate formula over all component multisets with N in {1,2,3,4,5,6,8}.
- **Abstract model:** Component `(a,b,f)`, `a<=b`, size `a+b`, edges `a*b-f`, `f` = missing cross edges; valid `0<=f<=(a-1)(b-1)`; isolated = `(0,1,0)`. Moves: decrement `f` (if `f>0`), or merge two components with orientation `(a1+a2,b1+b2)` / `(a1+b2,b1+a2)`, new `f=A*B-(e1+e2+1)`, reject if `f<0`. Terminal = single component with `f==0`. Merges and inner moves preserve total size, so every state has the same vertex count.
- **Key identity:** every move adds exactly one edge, so total moves `L = E_final - M`, and the final graph is a complete bipartite `K_{a,N-a}` with `E_final=a(N-a)`. If N is odd, `a(N-a)` is always even, hence `L` parity is fixed = `M` parity, so Aoki wins iff `M` is odd (proved; matches all odd brute cases). If N is even, `a(N-a) ≡ a (mod 2)`, so only the parity of the final part size matters.
- **Formula currently under test:** `W = (M + base + o//2 + corr) % 2`, `corr=1` iff `k>0` and `(o//2 + e_count)` even, where `o` = #odd-size comps, `k` = #odd-size comps with size>1, `base` = #even-size comps with both parts odd, `e_count` = #even-size comps with both parts even.
- **Disproof of the corr formula (hand-verified):** `{(2,3,1),(0,1,0)}` (N=6, M=5): true `W=1` because merging in orientation `(2,4)` yields the single component `(2,4,2)` with `f=2` (even => losing for opponent); the corr formula returns `0`. Second witness `{P3,K22,I}` (N=8, M=6): true `W=1` (merge P3 with I -> `{star4,K22}`, a losing state); corr formula returns `0`. So the verifier is expected to print mismatches.
- **Better candidate rule, matching every hand-checked state:** for N even, `W = 1` if `k>0`, else `W = (M + base + o//2) % 2`. Checked on P3+I, P3+3I, P3+P3, `(2,3,f)+I` for `f=0,1,2`, star5+I, `{P3,K2,I}`, `{P3,K22,I}`, `{P3,P4,I}`, `{P3,star4,I}`, `{K2,K2,I,I}`, `{K2,I,I,I,I}`, and all N=4 states — all consistent.
- **o=0 case is provably simple:** with no odd-size components the final part-size parity is forced to `base mod 2`, so `W=(M+base)%2` (matches K2+K2, star4, P4, K22, P4+K2, K22+K2, etc.). The `o//2` term only enters through isolated-vertex counts when `k=0`.
- **Why k>0 plausibly forces Aoki win:** an odd-size component with size>1 has parts of different parity and at least one edge, giving the first player both a tempo and a parity choice; all observed `k>0` states are N-positions. Still needs the exhaustive N=8 run to be certain.
- **Verifier mechanics:** memoized minimax keyed on the sorted component tuple; all multisets generated by non-decreasing component-type index (types sorted by size). N<=8 stays within a few thousand states, so it runs quickly in Python. Output is one line per mismatch, or the exact phrase `No mismatches up to N=8`.
