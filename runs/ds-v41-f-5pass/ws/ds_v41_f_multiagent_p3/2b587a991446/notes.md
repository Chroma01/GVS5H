- **Problem model:** state = ordered pair (posA,posB), posA!=posB; answer = BFS distance (S,T)->(T,S). Direct BFS over N^2 is impossible for N=2e5, so use a structural formula.
- **Answer shape:** ans = 2*D + extra where D=dist(S,T); each token must move >=D, so extra>=0. D determined by BFS from S and T (ds,dt). A vertex is on-corridor iff ds+dt==D.
- **Impossible iff graph is a path.** A path preserves order so S,T never swap. Non-path always swappable: a cycle or a degree>=3 vertex provides a "passing" gadget. Formula returns INF only when every case fails, which happens exactly for paths (blocks are size-2, no off-corridor neighbours).
- **Three passing constructions (take min of extras):**
  - **case2, extra 2:** some internal corridor vertex v (v!=S,T) has an off-corridor neighbour w (ds[w]+dt[w]>D). Park A at w while B passes through v, then A returns: +2.
  - **case3, extra 4*(L+1):** an endpoint E has an off-corridor region; BFS from E over off-corridor vertices finds nearest u at distance L with >=2 off-corridor neighbours (excluding BFS parent). Both tokens round-trip to u and park in its two branches: A costs 2L+2, B costs 2L+2. Verified on star-centre (L=0 -> 4), path-then-branch (L=2 -> 12), T-on-triangle.
  - **case1, extra = cyc - 2*dist_in:** a biconnected block on the block-cut-tree corridor between node_of(S) and node_of(T). entry/exit are S/T or adjacent cut vertices; din=ds[exit]-ds[entry] equals intra-block distance; cyc = shortest cycle through entry and exit = min total length of two internally-vertex-disjoint paths (min-cost flow, 2 units, vertex caps 1 except entry/exit=2). This covers long cycles: C_n adjacent gives n-2, sample1 triangle gives 1, two disjoint shortest paths give 0.
- **Why case1 dominates when case3 "over-counts":** if the off-corridor branch region connects both S and T, the created cycle lies in a corridor block, so case1 fires with a smaller value; hence case3's formula only needs to be exact when the branch attaches to a single endpoint (then dist(T,u)=dist(S,u)+D and 4(L+1) is exact).
- **BCT details:** node_of(x) = cut-node if x in >=2 blocks else its unique block. Path S->T in BCT; skip cut nodes; for block path[i], entry = S if i==0 else cut_vert[path[i-1]], exit = T if i==K else cut_vert[path[i+1]]. entry==exit (dead-end) and blocks of size<3 are skipped.
- **Validated by hand against the exact configuration BFS:** samples (3, -1, 4), star leaves (6), star centre/T-triangle/S-triangle (6), bowtie (5), C4 adjacent (4) & opposite (4), C5 adjacent (5), triangle at internal cut vertex (6), pendant triangle chains. All matched.
- **Implementation:** iterative Tarjan low-link (blocks = biconnected edge sets), iterative BCT path, MCMF per path block via Dijkstra+potentials (initial costs 0/1 so Johnson potentials start at 0). Total O((N+M) log N).
