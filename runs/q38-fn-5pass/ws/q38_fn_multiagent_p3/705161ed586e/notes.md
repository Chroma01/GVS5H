- **Switched approach:** The prefix DP with ranks is conceptually correct, but sorting 78 rank keys per position is avoidable. Implemented suffix DP plus greedy reconstruction as the final solution.
- **State:** `dp[i][c*3 + l]` for `l=0,1,2` representing current run length 1, 2, or at least 3 before position `i`. At `i=n`, only length-at-least-3 states have cost 0.
- **Recurrence:** If current length is 1 or 2, the next target character must equal the current run character. If length is at least 3, either continue the same character or start a new run with any different character. For the latter, the minimum over all different characters is obtained from the top two values of `dist[caption[i]][x] + dp[i+1][x,1]`, excluding the current character.
- **Initial choice:** There is no state before position 0. The optimal total cost is `min_x dist[caption[0]][x] + dp[1][x,1]`.
- **Lexicographic reconstruction:** Starting from the smallest feasible first character, at each position scan target characters from `'a'` to `'z'`. Pick the first allowed transition whose immediate cost plus the stored suffix DP value equals the current DP value. This greedily fixes the earliest character possible among all minimum-cost completions, hence the lexicographically smallest answer.
- **Complexity and memory:** Time is `O(n * 26)` for DP and another `O(n * 26)` worst-case for greedy. A flat `array('i')` stores `(n+1)*78` int32 values, about 15.6 MB for `n=50000`, avoiding Python-int list memory.
- **Edge cases:** Lengths 1 and 2 return empty. For `n >= 3`, an all-one-character caption is always feasible. The DP naturally rejects endings with run length 1 or 2 because `dp[n]` is finite only for length 3. Unreachable entries may become slightly larger than `INF`; they are ignored by comparisons initialized to `INF` and cannot match a finite greedy target.
- **Checks:** Samples pass: `"cdcd" -> "cccc"`, `"aca" -> "aaa"`, `"bc" -> ""`. Additional checks include all same characters, n=3 median tie, n=4 one-run tie (`"abab" -> "aaaa"`), and split-run case (`"aaabbb" -> "aaabbb"`).
