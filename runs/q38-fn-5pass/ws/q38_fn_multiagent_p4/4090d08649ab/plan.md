The key observation is that one operation can erase exactly one maximal consecutive block of values that are currently present, so `f(L,R)` equals the number of connected components of the distinct value set in `A[L..R]`. A component starts at value `x` iff `x` appears in the subarray and `x-1` does not appear, so the required sum becomes `sum_x` of the number of subarrays containing at least one `x` and no `x-1`. For each `x`, split the array into maximal segments that avoid `x-1`, then count subarrays inside each segment that contain at least one `x` using total subarrays minus subarrays lying in gaps between occurrences of `x`. Since the total sizes of all position lists and predecessor position lists are `O(N)`, this gives a linear-time solution after building positions.
