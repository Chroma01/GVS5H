Sort A, B, and C in non-increasing order; because all entries are positive, the expression is monotone non-increasing when any index is increased. Therefore the maximum is at (0,0,0), and the top K triples can be generated by best-first search over the 3D index grid, pushing the three immediate successors of each popped triple. Use a max-heap keyed by the computed value and a visited set to avoid duplicates; after K pops, the last popped value is the K-th largest. Truncate each sorted array to min(N,K) because any index beyond K is dominated by at least K smaller-index choices. This gives O(N log N + K log K) time and O(K) heap/visited memory, suitable for K <= 5e5.
