- **Output of the harness:** running `python prog.py --validate` (same as `python prog.py < /dev/null`) prints exactly: `sample 1: got=16 expected=16 [OK]`, `sample 2: got=0 expected=0 [OK]`, `sample 3: got=2867 expected=2867 [OK]`, `exhaustive N<=4 done, mismatches = 0`, `random tests done, mismatches = 0`, `ALL TESTS PASSED`. Fast solver matches the brute-force Dijkstra reference on samples, all N≤4 with C∈{1,2,3}, and 3000 random N≤10 cases (C ties, wide and narrow ranges).
- **Problem model:** one operation flips a bit then pays S = Σ A_k C_k of the state after the flip, so total cost = Σ_k C_k·t_k with t_k = number of post-operation states where bit k = 1.
- **Index classes:** R = {A=1,B=0} flip down once; S = {A=0,B=1} flip up once; P = {A=1,B=1} may be flipped down then up (chosen subset Q ⊆ P); A=B=0 never touched. Index flipped at most twice (every touched index appears once in the down phase and/or once in the up phase).
- **Ordering (exchange proof):** all downs precede all ups; swapping an adjacent (up, down) to (down, up) keeps the end state and lowers cost by C_up + C_down > 0. Downs in decreasing C, ups in increasing C.
- **Base formula:** Total(Q) = PairMin(D) + W_U + PairMin(U) + M·W_{P\Q} with D = R∪Q, U = S∪Q, M = |D|+|U| = n+m+2|Q|. Checked by simulation: R=[5,9],S=[4],P=[2] gives 15 (path 7+2+6), not 16.
- **Expanded form:** Total(Q) = Const' + 2·PairMin(Q) + Σ_{q∈Q} g(q) + 2k·W_P − (n+m+2k−1)·W_Q, Const' = PR+PS+W_S+(n+m)W_P, g(c) = Σ_{r∈R}min(r,c) + Σ_{s∈S}min(c,s), n=|R|, m=|S|, k=|Q|. (The +2k·W_P term is essential; omitting it is the classic algebra slip.)
- **Optimal Q is a descending prefix:** replacing a chosen x by an unchosen y>x changes F by at most 2(k−1)(y−x) + (n+m)(y−x) − (n+m+2k−1)(y−x) = −(y−x) < 0. Only prefixes of P sorted descending need checking.
- **Per-prefix closed form in code:** top k values c_1 ≥ … ≥ c_k; a(c) = g(c) − (n+m+1)c + 2W_P; total_k = Const' + Σa(c_i) + 2T_k − 2k·S_k where T_k = Σ i·c_i, S_k = Σ c_i. Algebraically identical to the expanded form.
- **Computation:** PR = Σ_i R_asc[i]·(n−1−i) (analogously PS, equals pairwise minima); g(c) via bisect_right + prefix sums. O(N log N), Python big ints (answer ≤ ~4·10^16, safely above 32-bit).
- **Edge cases:** P empty → answer = Const'; A == B → 0; (1)→(0) gives 0; (0)→(1) gives C. Ties in C do not matter.
- **Pitfall:** must allow temporary flips of A=B=1 indices (restricting flips to mismatch positions is wrong); do not interleave down and up phases.
