The game can be treated as a normal-play impartial game where the only relevant information is which indices are untouched and the parity of the number of already-available extra moves. First prove that the exact values of A_i beyond their parity do not change the winner, reducing the state to counts of odd/even untouched piles and a pass parity. Then derive the winning rule by handling small N separately and proving a parity-count rule for larger N, ideally by induction on N. The final implementation only needs to count odd A_i and apply the derived rule in O(N) time.
