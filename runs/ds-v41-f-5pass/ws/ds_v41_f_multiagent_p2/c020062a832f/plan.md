We need all M inversion counts, so we avoid recomputation by observing the transition from shift k to k+1: only elements whose current value is M-1 wrap to 0, while all others increment. This changes inversions only between that wrapping value class and all other elements. For each value v, precompute the net inversion change when the entire class {i | A_i = v} wraps, using occurrence positions. Then sweep k=0..M-1, starting from the k=0 inversion count and accumulating these deltas. The initial count is computed with a Fenwick tree in O(N log M), and all deltas can be obtained in O(N+M).
