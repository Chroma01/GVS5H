Use a max Cartesian tree (with a fixed tie-breaking rule) so each node represents a contiguous segment whose maximum is that slime. For a node u, any start that can absorb the whole left/right child segment can absorb u exactly when that child's total sum is strictly greater than A_u; after absorbing u it can then absorb the rest of u's segment. The start at u itself can absorb its whole segment iff it has no child or at least one adjacent boundary slime inside the segment is strictly smaller than A_u. Process the tree bottom-up, propagating sets of starting indices that have conquered the current node; when a set cannot propagate to the parent, assign the current node's subtree sum as the final answer for all indices in that set. Maintain these sets as linked lists and merge them in O(1) per edge, giving an O(N) algorithm.
