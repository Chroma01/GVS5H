Model the constraints as an undirected graph with vertices 1..N and edges (X_i, Y_i) labeled Z_i, meaning A_X xor A_Y = Z. For each connected component, assign tentative values by traversing edges: if a vertex has value v, a neighbor connected by label z must have value v xor z. If a cycle forces a different value, no good sequence exists. Once consistent, every solution in a component is obtained by XORing all tentative values in that component with one common constant C. Choose C independently per component by minimizing the sum bitwise: for each bit, set C's bit to make the majority of resulting bits zero.
