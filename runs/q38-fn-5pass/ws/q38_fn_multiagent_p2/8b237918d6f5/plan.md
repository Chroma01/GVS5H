The distance after choosing edges is the minimum, over all 1-N paths, of how many chosen edges the path uses. For a target D, it is enough to ask whether at most K edges can be chosen so that every path contains at least D chosen edges; if so, extra edges can be added to reach exactly K. Such a set exists iff there are integer potentials d_v in [0,D] with d_1=0, d_N=D, and d_v <= d_u+1 for every edge u->v, and the number of edges with d_v=d_u+1 is at most K. Minimizing that number for fixed D can be reduced to a minimum s-t cut using binary variables y_{v,i}=1 iff d_v>=i, with nesting/implication infinite edges and unit-cost edges for y_{v,i}=1,y_{u,i}=0. Test D from 0 up to the unweighted shortest path length, or binary search, and output the largest feasible D.
