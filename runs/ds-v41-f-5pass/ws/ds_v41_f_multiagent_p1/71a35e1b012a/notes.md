- **Reduction:** assign each index a type in {0,1,2}. Position j stays 0 iff j lies in every type-2 interval and in no type-1 interval. So a choice is valid iff intersection(type-2 intervals) is contained in union(type-1 intervals). Cost = count of nonzero types.
- **Optimal cost set:** optimum is always in {-1,1,2,3}. For M>=3 it is never -1 (case D always yields a valid cost-3 assignment). For M<=2 only costs 1 and 2 are reachable.
- **Cost 1:** exactly when some interval equals [1,N] (use it as op1). A lone op2 can never work, since its "intersection" is itself and the type-1 union is empty. Take the smallest such index.
- **Cost 2 has exactly three shapes,** all checked:
  - case A {op1=p, op2=q}: need I_q subset of I_p (single type-2 intersection equals I_q). Tried first, because sample 1 expects the containment solution.
  - case B {op1, op1}: union must be [1,N]; some interval must have L=1 and some have R=N.
  - case C {op2, op2}: intersection empty = disjoint pair; valid with no type-1.
- **Case A detection:** contains[p] = exists q!=p with L_q>=L_p and R_q<=R_p. Computed O(M log M): sort by L desc, walk equal-L groups, merge whole group into running (minR, count) before evaluating members; contains[p] iff R_p>minR or (R_p==minR and count>=2). Then pick first p with contains, then first matching q. Exact, no false negatives.
- **Case B greedy:** a = L=1 interval with max R (bestR1); b = R=N interval with min L (bestLN). Valid iff a!=b and bestR1+1>=bestLN. Safe: any real covering pair (I_u has L=1, I_v has R=N, R_u>=L_v-1) forces bestR1>=R_u and bestLN<=L_v, so the test passes. a==b only if a [1,N] interval exists, already handled as cost 1.
- **Case C greedy:** p=argmin R, q=argmax L; valid iff p!=q and R[p]<L[q]. Two intervals intersect iff R[p]>=L[q]; any disjoint pair (R_u<L_v) implies minR<=R_u<L_v<=maxL, so R[p]<L[q] detects it. If no pair exists, p==q or R[p]>=L[q] correctly reports failure.
- **Case D (cost 3):** reached only after cost 1 and A,B,C all fail. Let i*=argmax L, j*=argmin R. If i*==j* then that interval is contained in every other, so case A would have fired; hence i*!=j*, and a free index k exists for M>=3. Intersection(I_i*, I_j*) = [L_i*, R_j*], and since L_i* is the global max L and R_j* the global min R, [L_i*,R_j*] is contained in every I_k (in particular the chosen k). So set op[i*]=op[j*]=2, op[k]=1. Valid and cost 3, hence optimal.
- **Why no case is missed:** all cost-2 selections are {1,1}->B, {1,2}->A, {2,2}->C (enumerated exhaustively). Cost 3 for M>=3 always exists via D, so the answer never exceeds 3.
- **Brute-force cross-check:** enumerating all {0,1,2}^M assignments for every small case (N in 1..5, M in 1..4 and targeted hand cases) agrees with this program on both K and validity of the printed ops. Specifically confirmed: samples 1-4; M=1 (only [1,N] gives 1, else -1); N=1 (always cost 1); duplicates ([1,2],[1,2],N=3 -> 2 via A); nested ([1,5],[2,3],N=6 -> 2 via A, since [1,6] absent); infeasible M=2 ([1,3],[2,4] and [2,3],[3,4] -> -1); and the M>=3 forced-cost-3 path (N=7, [2,5],[3,6],[4,7] -> 3, D: ops [2,1,2]). No mismatch found.
- **Complexity:** O(M log M) from one sort; N only used in bound comparisons; M up to 2e5, N up to 1e6.
- **Output:** first line K, second line M space-separated op types.
