- **Core reduction:** For a subarray, only the set S of distinct values matters. One operation can erase exactly an integer interval contained in S, so the minimum number of operations is the number of maximal consecutive blocks in S. Equivalently, f(L,R) = |S| - count of adjacent value pairs x,x+1 both present in A[L..R].
- **Sweep invariant:** Sweep right endpoint i from 1 to N. Maintain last[v] = last position <= i where value v appears, or 0 if absent. For fixed i, the number of left endpoints L such that value v appears in A[L..i] is last[v]. Therefore the total distinct-value contribution over all subarrays ending at i is D = sum_v last[v].
- **Adjacent-pair contribution:** For fixed i, the number of left endpoints L such that both x and x+1 appear in A[L..i] is min(last[x], last[x+1]). Hence the total adjacent-pair contribution over all subarrays ending at i is P = sum_{x=1}^{N-1} min(last[x], last[x+1]). The contribution of all subarrays ending at i is D - P.
- **Update rule:** When processing position i with value x, let old = last[x]. D increases by i - old. Only pairs (x-1,x) and (x,x+1) can change. For a neighbor value with last position y, min(y, last[x]) changes from min(y, old) to y because y < i. Thus P increases by max(0, y - old) for each existing neighbor. This avoids explicit min calls and keeps the update O(1).
- **Correctness intuition:** The sweep counts, for each right endpoint, the sum of component counts over all left endpoints by linearity. Distinct values and adjacent co-occurrences are counted independently, and their difference is exactly the number of connected components of the present value set.
- **Complexity:** Time O(N), memory O(N). The answer can be around N^3, so Python integers are appropriate.
- **Edge cases:** Values are 1-indexed and bounded by N. Boundary values x=1 and x=N affect only one adjacent pair. If N=1, P remains zero and the answer is 1. Absent values have last position 0, which naturally contributes zero to both D and P.
- **Implementation details:** Read all input at once. Use a last array of size N+2 to safely access x+1. Iterate i from 1 to N so that last positions directly equal the number of valid left endpoints.
