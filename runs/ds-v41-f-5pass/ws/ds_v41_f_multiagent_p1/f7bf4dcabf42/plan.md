Use dynamic programming over the standard LCS frontier for the fixed string S. Since N≤10, the LCS DP row can be encoded by a bitmask indicating which prefix lengths increase, giving at most 2^N states. For each state and each of the 26 next letters, compute the next frontier by applying the LCS recurrence, precomputing all transitions. Then run M steps accumulating counts, and sum counts by final LCS value k. This gives all answers in O(M·2^N·26·N) modulo 998244353.
