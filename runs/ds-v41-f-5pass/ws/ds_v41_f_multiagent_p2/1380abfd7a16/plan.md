Process the insertions in reverse: when handling value i, all larger values have already been removed/placed, so i must occupy the P_i-th currently empty slot in the final array. This lets us reconstruct the answer by repeatedly finding the P_i-th free position for i = N down to 1. A Fenwick tree over the N positions supports selecting the k-th free slot and marking it occupied in O(log N). The total complexity is O(N log N), which fits N up to 5×10^5. Validate the invariant against brute force on small cases and both samples.
