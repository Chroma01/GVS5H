The minimum cost is at most 3. Cost 1 is possible iff some interval is [1,N]. Cost 2 is possible exactly when either two intervals are disjoint (use operation 2 on both), or, after excluding disjoint pairs, some interval starts at 1 and another ends at N (use operation 1 on both), or one interval contains another (use operation 1 on the container and operation 2 on the contained interval). If none of these holds and M >= 3, all intervals pairwise intersect; take an interval with minimum L and one with maximum R as operation 1, and any third interval as operation 2, which covers the whole sequence. If M < 3 and no cost <= 2 solution exists, the answer is -1.
