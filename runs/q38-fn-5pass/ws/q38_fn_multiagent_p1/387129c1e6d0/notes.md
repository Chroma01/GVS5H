- **Approach:** Simulate Santa's path once. Each move is an inclusive axis-aligned segment. Horizontal moves are stored by their fixed y-coordinate as x-intervals; vertical moves are stored by their fixed x-coordinate as y-intervals.
- **Merging:** For every line, sort its intervals by left endpoint and merge them into disjoint intervals. Because all house coordinates are integers, intervals that are adjacent in integer space, where next_l <= current_r + 1, can be merged without changing the set of integer points covered. Each merged line is stored as two parallel lists: starts and ends.
- **Counting:** For each house, first check horizontal coverage using its y-coordinate. Binary search the starts list for the last interval whose start is <= house_x. If that interval's end is >= house_x, the house is covered; count it and skip the vertical check. Otherwise check vertical coverage similarly using its x-coordinate. This guarantees each distinct house is counted at most once.
- **Complexity:** Simulation is O(M). Sorting all segment lists costs O(M log M) in the worst case. Each house performs at most two binary searches, giving O(N log M) counting time. Overall time is O((N + M) log(N + M)), and memory is O(N + M).
- **Pitfalls:** Final coordinates can exceed 32-bit range, but Python integers handle this naturally. Segment endpoints are inclusive. Houses at intersections of horizontal and vertical coverage must not be double-counted. Naively checking every house against every segment is too slow. Merging adjacent intervals is safe only because houses have integer coordinates; if only overlapping intervals were merged, correctness would still hold, but there could be more intervals.
- **Implementation details:** Input is parsed with sys.stdin.buffer.read().split(), and direction tokens are compared as bytes. Houses are stored in two lists hx and hy to reduce tuple overhead. The raw token list is deleted after parsing to free memory. defaultdict(list) collects raw intervals. The merge function replaces each raw interval list with a tuple of starts and ends. bisect_right is used on the starts list to find the candidate interval.
