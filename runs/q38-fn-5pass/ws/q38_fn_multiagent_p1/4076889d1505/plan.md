Factor each N into prime powers and construct a coprime local modulus for each prime power that contains an element of exactly that order. For an odd prime p^e, use modulus p^{e+1} and residue 1+p; for 2^e, use modulus 4 with residue 3 when e=1, and modulus 2^{e+2} with residue 5 when e>=2. Combine all local congruences with CRT to obtain one global A modulo M, whose order is the lcm of the local orders, hence exactly N. The product of the local moduli is at most about N^2, so it fits within 1e18 for N <= 1e9. Handle N=1 separately by outputting any pair with M=1.
