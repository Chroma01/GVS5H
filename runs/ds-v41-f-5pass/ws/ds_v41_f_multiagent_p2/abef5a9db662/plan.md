Model each possible initial rating X as an entry F[X] equal to its current rating after processed contests, so F is nondecreasing. For a contest [L,R], the entries that increase form a contiguous index range [a,b] where F[a] >= L and F[b] <= R. Maintain F under range add +1 on [a,b] using a lazy segment tree that supports finding first value >= L and last value <= R. After all contests, answer each query by point-querying F[X]. Complexity is O((N+Q) log M) with M = 500000.
