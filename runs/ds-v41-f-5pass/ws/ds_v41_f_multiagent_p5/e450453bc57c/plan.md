Precompute the minimum operation cost for every possible length-x window to make all its elements equal; this equals the sum of absolute deviations from the window median. Then reduce the problem to choosing k non-overlapping windows with minimum total cost. Because k ≤ 15 and n ≤ 10^5, use dynamic programming over positions and number of chosen windows, with prefix minima to avoid quadratic transitions. The final answer is the minimum cost for exactly k non-overlapping windows, since extra windows can be dropped and costs are nonnegative.
