- **Problem restated:** permutation P of 1..N; operation swaps adjacent P_i,P_{i+1} at cost i; find min total cost to reach sorted order.
- **Winning approach (largest-first greedy):** For k = N down to 1, place value k at its final position k. Because all larger values are already frozen at the far right, values 1..k occupy positions 1..k in their original relative order. So k sits at rank p_k among 1..k; it must bubble right past the k−p_k smaller values after it, paying at indices p_k, p_k+1, ..., k−1. Total = sum_{i=p_k}^{k-1} i = (p_k + (k−1))·(k−p_k)/2.
- **Computing p_k:** p_k = 1 + (#values < k whose original position is left of pos[k]). With a Fenwick tree inserting pos[1], pos[2], ... in increasing value order, c = query(pos[k]−1), p_k = c+1.
- **Final formula:** answer = Σ_{k=1..N} (p_k + k−1)·(k−p_k)/2 with p_k = c_k+1. O(N log N).
- **Verified on samples:** [3,2,1]→4, [2,4,1,3,5]→6, [1,2]→0.
- **Optimality proof (induction on N):** The maximum N only ever moves right (moving it left would create an inversion needing undo), so its swaps are forced at indices pos[N], pos[N]+1, ..., N−1 — cost is fixed regardless of schedule. Splitting any valid sequence into N-swaps and others: projecting the "others" onto values 1..N−1 (delete N's position) maps each same-side swap at actual index i to a subproblem swap at index ≤ i, and the projection sorts the subsequence (N's relative order is irrelevant to 1..N−1). Hence rest-cost ≥ optimal subproblem cost, and moving N first then solving the subproblem attains it. Induction grounds the greedy.
- **Why other greeds fail:** smallest-first / left-to-right fixing is not optimal ([3,2,1] costs 5 vs optimum 4); per-inversion fixed costs are wrong because a pair's crossing index varies with configuration.
- **Pitfalls:** don't double count (each inverted pair crosses once in optimum); answer fits well within 64-bit (~4e15 worst case) but Python ints are safe anyway; ensure the arithmetic-series factor is (k−p_k) terms.
- **Implementation notes:** Fenwick stores counts of inserted positions; query prefix up to pos[k]−1 before inserting pos[k]. Read all tokens from stdin buffer for speed.
