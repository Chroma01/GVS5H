The smoke generated at time g is at P[t] - P[g] after t winds, where P[t] is the cumulative wind displacement after t steps. A new generation happens exactly when P[t] has not appeared before, because the origin is occupied iff some earlier generated smoke has P[g] = P[t]. Therefore, smoke is at (R,C) at time t iff P[t] - (R,C) appeared among P[0..t-1]. We can process the string left to right, maintaining a hash set of seen prefix positions, checking the shifted position before inserting the current prefix. This yields O(N) time and O(N) memory.
