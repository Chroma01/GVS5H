- **Goal:** S = sum over all completions B of A (zeros replaced by an element of F_p^*) of B^p, modulo p.
- **Character sum (core lemma):** for t >= 0, sum_{x in F_p^*} x^t = -1 (mod p) if (p-1) divides t, else 0. This includes t = 0 (sum of 1 over p-1 elements = p-1 ≡ -1).
- **Walk expansion:** (B^p)_{i,j} = sum over walks i=v0->...->vp=j of prod B_{v_{k-1},v_k} (p steps). Interchanging with per-zero sums factorises the answer: S_{i,j} = sum over walks of (prod of fixed entries) * prod over zero entries z of (sum_x x^{t_z}), where t_z = usage count of z. So each used-zero factor is -1 iff (p-1)|t_z, else 0.
- **Structure of surviving walks (p>2):** total steps p; each zero's usage is a multiple of p-1. Since 2(p-1) > p, at most one zero is used and it must be used exactly p-1 times; every other step is a fixed nonzero entry. Each of the K zeros contributes a factor -1 (used p-1 times or 0 times), giving the global factor (-1)^K.
- **Main term:** walks using no zero edge -> M^p where M = A with zeros set to 0.
- **Self-loop correction:** zero at (u,u) used p-1 times, plus one fixed step. Connectivity forces the fixed step to be the first step (walk i,u,u,...,u -> adds column u of M) or the last step (walk u,...,u,j -> adds row u of M). A fixed step strictly in the middle would have to be (u,u), i.e. the same zero entry, impossible. So add row u and column u of M to C (M[u][u]=0 so the diagonal entries are harmless).
- **Non self-loop correction:** zero at (i,j), i≠j, used p-1 times. Consecutive uses of (i,j) force j=i, so the p-1 uses must be split into blocks separated by fixed steps. With only one fixed step allowed, this needs p-1 <= 2, i.e. p=3. Then the unique walk is i->j->i->j, using fixed edge (j,i). So for p=3 only: C[i][j] += M[j][i]. (If (j,i) is itself zero, M[j][i]=0, correctly killing the term.)
- **Final formula (p>2):** S = (-1)^K (M^p + C) mod p. For K odd multiply by p-1.
- **p==2 case (separate):** the only replacement value is 1, and all entries lie in {0,1}, so B is the all-ones matrix; B^2 has every entry N, so the answer is N mod 2 in every cell. The general formula does not apply because p-1=1 makes every usage count a valid multiple.
- **Complexity:** binary exponentiation of an N x N matrix, O(N^3 log p). N<=100, p<=1e9 -> at most ~30 squarings plus ~15 multiplies.
- **Implementation speed:** pure Python matmul uses the ikj order, skips zero entries and defers the modulo to the end of each row. When numpy is available, use the low/high 15-bit split so each int64 `dot` has entries < N*2^30 < 2^63; combine four products and reduce mod p. This keeps int64 from overflowing while staying fast (BLAS-free int matmul).
- **Verification:** checked against all three samples. Sample 1 gives M^3=[[0,1],[0,2]], C=[[0,1],[1,0]], sign +1 -> [[0,2],[1,2]]. Sample 2 -> N%2=1 everywhere. Sample 3 (p=13, K=7): M^13=[[5,12,3,8],[12,12,5,3],[5,7,9,0],[2,4,12,4]], C has row/col contributions from the three diagonal zeros; (-1)*(M^13+C) = [[8,0,6,5],[11,1,8,5],[8,0,4,12],[8,0,1,9]], matching. Also brute-force verified p=3/p=5 cases with one or two zeros.
- **Edge cases:** N=1 behaves consistently; multiple diagonal zeros simply accumulate row/column contributions; a zero at (i,j) with (j,i) also zero contributes nothing via M[j][i]=0.
