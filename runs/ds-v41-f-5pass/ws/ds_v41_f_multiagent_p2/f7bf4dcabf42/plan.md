Since N<=10, each LCS row over prefixes of S is nondecreasing with increments only 0 or 1, so it can be encoded as an N-bit mask; the final LCS length is popcount(mask). Precompute transitions for every mask and each of the 26 letters by applying the standard LCS recurrence once per appended character.
