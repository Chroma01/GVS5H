- **Core formula:** For a fixed element x, if S is the set of elements placed after it, its contribution over all permutations is x * 10^{sum of digit lengths in S} * |S|! * (N-1-|S|)!. Group elements by digit length d. Let c_d be the count, w_d = 10^d mod MOD, and P(t)=prod_d (1+w_d t)^{c_d}. For elements of length d, we need coefficients of H_d(t)=P(t)/(1+w_d t). The answer is sum_d (sum of values with length d) * sum_k h_{d,k} * k! * (N-1-k)!.
- **State recurrence:** Let a_k be coefficients of P and h_{d,k} coefficients of H_d. From the logarithmic derivative, P'(t)=sum_d c_d w_d H_d(t). Comparing coefficient of t^{k-1} gives k a_k = sum_d c_d w_d h_{d,k-1}. Also, since P=(1+w_d t)H_d, h_{d,k}=a_k-w_d h_{d,k-1}. Initialize h_{d,0}=1. For k=1..N-1, compute a_k from current h values, then update all h values and accumulate their weighted sum.
- **Weight recurrence:** Define W_k=k!(N-1-k)!. W_0=(N-1)!, and W_k=W_{k-1}*k/(N-k) modulo MOD. Modular inverses up to N are precomputed in linear time.
- **Digit grouping:** For N<=2e5 there are at most six digit lengths. Counts and value sums are computed by decimal ranges, avoiding a per-number loop. Only digit lengths actually present are processed.
- **Complexity:** Time O(DN) with D<=6, memory O(N) for inverses plus O(D) for states. This is easily fast enough for N=2e5.
- **Checks:** N=1 gives 1. N=2 gives 33. Sample N=3 gives 1332. For all one-digit N, the formula reduces to (N-1)! * (10^N-1)/9 * sum(1..N), matching direct positional counting.
