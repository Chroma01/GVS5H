The minimum operations for a subarray equals the number of contiguous value-blocks among the distinct values appearing in it, because one operation can erase exactly one such block and blocks separated by missing values cannot be erased together. Therefore the required sum can be rewritten as the sum over values v of the number of subarrays in which v appears and v-1 does not appear, with v=1 having no forbidden predecessor. For each v, split the array into maximal intervals that contain no occurrence of v-1; inside each interval, count subarrays containing at least one occurrence of v using the positions of v. Process all v by merging the sorted position lists of v and v-1, giving O(N) total work since each position is touched only a constant number of times. Store positions for all values, accumulate the counts in a large integer, and output the total.
