The goal is to maximize the number of kept vertices, since the answer is `N - max_kept`. A Snowflake Tree is fully determined by choosing a center vertex `v`, choosing some neighbors of `v` as middle vertices, and choosing `y` leaves for each chosen middle vertex. For a fixed center `v`, a neighbor `u` can serve as a middle vertex with `y` leaves iff `deg(u) - 1 >= y`, because its other neighbors can be used as leaves. Thus for each center, sort the values `deg(u) - 1` over its neighbors in descending order; if the `k`-th largest value is `c`, the best choice using `k` middle vertices is `y = c`, giving `1 + k * (c + 1)` kept vertices. Compute this maximum over all centers and output `N - max_kept`.
