Transform each pair price into a color-assignment problem: in an optimal pairing, label each pair by one of X/Y/Z attaining the maximum, so every chosen cake gets a color and each color is used an even number of times; conversely, any even-color assignment can be paired within each color with total price at least the assigned sum. Thus the problem becomes choosing exactly 2K cakes and assigning them colors with even color counts, maximizing the sum of the chosen attribute values. Use Lagrangian relaxation on the number of pairs: penalize each pair by C, which is equivalent to giving each selected cake option value `2*attribute - C`, and compute the best adjusted value for each of the 8 color-parity masks by DP over cakes. The value as a function of pair count is concave (it is the maximum-weight matching cardinality value), so binary searching C and keeping the maximum selected count among tied adjusted optima recovers the exact value for K pairs. Finally, convert the doubled adjusted value back to the original answer.
