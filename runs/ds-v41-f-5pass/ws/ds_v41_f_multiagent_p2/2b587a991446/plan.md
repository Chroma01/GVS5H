The problem is equivalent to finding the shortest path between configurations (S,T) and (T,S) in the configuration graph of ordered pairs of distinct vertices. Direct BFS on the N^2 states is too slow. Instead, the minimum number of moves is determined by the shortest cycle containing S and T if one exists; otherwise, the graph is a tree and we must use a branch (a vertex of degree ≥3) to let the pieces pass. If the graph is a simple path, the task is impossible and we output -1. For a general graph, compute BFS distances from S and T, then evaluate candidate values over edges or vertices to capture either the cycle length or the extra cost of using a branch/cycle attached to the S-T path.
