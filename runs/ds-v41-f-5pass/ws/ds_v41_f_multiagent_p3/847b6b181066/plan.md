Transform the smoke dynamics into a prefix-displacement problem: after t winds, the origin has moved to a cumulative displacement P_t, and smoke at a query cell (R,C) exists at time t+0.5 exactly when P_t - (R,C) was some earlier prefix position P_k for 0 <= k <= t. Maintain the set of all prefix positions seen so far while scanning the wind string. For each time t, update the current prefix position, test whether the required earlier position is in the set, then insert the current position. Emit 1 or 0 for each t and concatenate the results. This yields an O(N) algorithm with O(N) memory.
