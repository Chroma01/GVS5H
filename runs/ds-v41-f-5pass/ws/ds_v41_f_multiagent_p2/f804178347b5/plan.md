Model the repeated majority operation as a full ternary tree of height N, where each internal node applies majority to its three children and each leaf is an original character. Use bottom-up dynamic programming: for every node store the minimum number of flips inside its subtree needed to force that node’s output to be 0 and to be 1. Starting from the leaves, repeatedly combine each consecutive triple of child DP pairs into their parent DP pair until the root is reached. The answer is the root cost for the opposite of its original value; since one root target cost is always 0, this can also be obtained as the maximum of the two root DP costs.
