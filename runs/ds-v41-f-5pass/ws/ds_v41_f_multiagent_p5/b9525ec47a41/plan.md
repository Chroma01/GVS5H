Model each edge orientation as a binary variable: one per cycle edge and one per star edge indicated by s_i=1. Express every indegree d_i in terms of these variables, yielding prefix-sum constraints on the cycle and a pairing between d_i and d_N for positions where s_i=1. Characterize exactly which indegree vectors are achievable, including duplicate vectors caused by global cycle reversal and star-variable choices. Reduce the count to an O(N) dynamic program or automaton over the binary string s, then verify it against brute force for small N.
