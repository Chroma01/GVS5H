Compute the inversion count for k=0 using a Fenwick tree over the values 0..M-1. Observe that increasing k by 1 only changes elements currently equal to M-1: they wrap from the largest value to the smallest, while all other elements increase together and preserve their relative order. For the set W of positions whose A_i equals M-1-k, the total change in inversions is sum over p in W of (2*p - N - 1), because pairs inside W cancel and pairs with non-W elements are gained before p and lost after p. Precompute positions grouped by A_i value, then update answers iteratively for k=0..M-2. Use 64-bit integers for all inversion counts.
