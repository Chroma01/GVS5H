Convert the tile condition into binary variables on grid edges: a type-A cell must have exactly one vertical and one horizontal incident edge selected, while a type-B cell must have either both vertical or both horizontal incident edges selected. This gives xor constraints on horizontal edges along each row and vertical edges along each column, so a solution exists only if every row and every column contains an even number of A cells. When these parity conditions hold, all horizontal edges are determined by one free bit per row and all vertical edges by one free bit per column. Each B cell then imposes one xor equation between its row bit and column bit, with label computed from prefix parities of A cells to its left and above. Count satisfying assignments of these bipartite xor equations with a weighted DSU; if consistent, each connected component contributes a factor 2, otherwise the answer is 0.
