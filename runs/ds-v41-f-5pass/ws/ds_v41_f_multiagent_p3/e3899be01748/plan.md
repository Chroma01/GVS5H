Use dynamic programming over ending positions, maintaining for each modulus m in 1..9 the counts of residues of all substrings ending at the previous position. When extending by digit x, update each residue r to (r*10+x) mod m and add the new one-digit substring x. For positions where x>0, the number of valid substrings ending there is the count of residue 0 for modulus x; add it to the answer. This naturally handles leading zeros because residues track the true numeric value modulo m. Complexity is O(n * sum_{m=1..9} m) = O(45n), which is safe for n up to 10^5.
