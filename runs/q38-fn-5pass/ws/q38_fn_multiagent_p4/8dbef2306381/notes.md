- **Core idea:** Compress the row into maximal safe segments. Inside one safe segment, a jump of length `A` preserves the residue modulo `A`, so once the earliest reachable square of a residue is known, every later square with that residue is reachable.
- **Safe segments:** Merge bad intervals that overlap or touch (`L <= previous_R + 1`). The remaining intervals are safe segments. Square 1 and square N are guaranteed safe.
- **Residue closure:** Precompute shortest total jump lengths between residues modulo `A` using steps `A..B` with Floyd-Warshall (`A <= 20`). For a segment, if residue `u` is first reachable at square `s`, then residue `v` is first reachable at `s + dist[u][v]`, provided this is not past the segment end. Taking the minimum over initial entry residues gives the earliest reachable square for every residue in the segment.
- **Why shortest residue distance is enough:** Any path from an entry to a target residue has total length at least the shortest residue-graph distance. If that shortest distance fits inside the segment, all intermediate positions are also inside the segment because all jumps are positive. If it does not fit, no longer path can fit.
- **Segment processing:** Process safe segments left to right. `entries[i][r]` stores the earliest reachable landing square in segment `i` with residue `r`. After closing a segment, all possible jumps from it to later safe squares are considered.
- **Outgoing jumps:** A jump from segment `[l, r]` to a square outside it must start in `[max(l, r-B+1), r]` and land within `r+1..r+B`. For each reachable `x` in that window and each jump length `d` that crosses `r`, map `x+d` to its safe segment using a small offset table and update that future segment's entry array.
- **Skipping segments:** The offset table advances through segment endpoints, so a jump can land in a later segment while skipping short safe segments or multiple bad blocks, as long as the landing square is within `B`.
- **Final answer:** The last safe segment ends at `N`. If its earliest reachable square with residue `N mod A` is at most `N`, then `N` is reachable by repeatedly adding `A` inside the last safe segment. Otherwise it is not.
- **Complexity:** Let `S <= M+1 <= 20001`. Precomputation is `O(A^3)`. Each segment does `O(A^2)` closure and `O(B^2)` outgoing checks, with `A,B <= 20`, so total is easily within limits. Memory is `O(S*A)`.
- **Edge cases handled:** `M=0`, `A=B`, `A=1`, very short safe segments, jumps skipping several bad blocks and safe gaps, touching bad intervals, and segments that are reachable but cannot exit.
- **Sample checks:** Manual checks give sample 1 `Yes`, sample 2 `No`, sample 3 `Yes`.
