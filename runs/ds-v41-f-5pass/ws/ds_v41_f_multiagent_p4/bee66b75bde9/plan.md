Reduce the grid conditions to choosing a nonincreasing row-threshold sequence: row r has a_r black cells in its prefix, and column validity is automatic exactly when a_1 >= a_2 >= ... >= a_N. Each black cell at (X,Y) gives a_X >= Y, while each white cell gives a_X < Y, so each row gets a lower bound L and upper bound U. Since N can be huge but only M rows are constrained, process only constrained rows sorted by descending row index. Maintain the maximum lower bound seen among rows at or below the current row and verify it never exceeds the current row's upper bound. Also catch same-row black/white conflicts directly.
