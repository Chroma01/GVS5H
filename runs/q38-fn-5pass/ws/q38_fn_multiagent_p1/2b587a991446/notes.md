- **Model:** The swap is possible only if the two tokens can exchange their order along the S-T route. In the block-cut tree this can happen either inside a non-bridge biconnected block on the S-T block-cut path, or at an articulation vertex on that path using an incident edge from a side block.
- **Block-cut tree:** Iterative Tarjan partitions edges into vertex-biconnected components. Block nodes are connected to their member vertices. The unique tree path from S to T identifies all relevant blocks and articulation vertices.
- **Vertex candidates:** For a vertex v on the S-T block-cut path, count original incident edges whose component is not on the path. If v is internal and count >= 1, candidate is `2*dS[v]+2*dT[v]+2`. If v is S or T and count >= 2, candidate is `2*dS[v]+2*dT[v]+4`. These correspond to parking one token in a side edge while the other passes through v.
- **Block candidates:** For each non-bridge block on the path, let p and q be its two neighboring vertex nodes on the path. The minimum internal passing cost is the shortest cycle through p and q inside that block. Candidate is `cycle_len + 2*min(dS[p]+dT[q], dS[q]+dT[p])`.
- **Shortest cycle through p,q:** Computed by a two-unit min-cost flow on the vertex-split graph. p and q have vertex capacity 2, all other vertices capacity 1; original edges are directed arcs of cost 1. The first shortest path is found by BFS. Potentials are BFS distances from p. The second augmenting path is found with Dial's algorithm because all reduced costs are 0, 1, or 2. Result is `2*dist1 + reduced_second_distance`.
- **Residual details:** The first path stores the directed edge direction used. In the second search, the used directed arc is unavailable, its reverse is available with reduced cost 0, and the opposite directed arc of the same undirected edge remains available. Vertex arcs for used internal vertices are unavailable forward but available backward; p and q retain one forward capacity.
- **Complexity:** Tarjan, tree BFS, global BFS, and vertex scans are linear. Only blocks on the S-T block-cut path are processed; their edge sets are disjoint, so total Suurballe work is near-linear, with Dial giving linear behavior per processed block after local adjacency construction.
- **Early exit:** The absolute minimum answer is 3, so the solver returns immediately when a candidate of 3 is found.
