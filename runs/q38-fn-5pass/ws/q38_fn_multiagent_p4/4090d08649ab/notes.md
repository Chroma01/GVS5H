- **Core identity:** For a fixed subarray, only the set of distinct values matters. An operation can erase a consecutive value interval only if every value in that interval is currently present, so it cannot cross a missing value. The minimum number of operations equals the number of connected components of the distinct-value set under adjacency of consecutive integers.
- **Vertex-edge formula:** For a present-value set S, the number of components is |S| minus the number of adjacent pairs (x, x+1) that are both in S. Summing this over all subarrays gives the required answer.
- **Last occurrence sweep:** For a fixed right endpoint R, let last[x] be the last position <= R where x appears, or 0 if absent. A subarray [L, R] contains x iff L <= last[x], so the number of such L is last[x]. It contains both x and x+1 iff L <= min(last[x], last[x+1]). Thus the contribution of endpoint R is sum_x last[x] - sum_{x=1}^{N-1} min(last[x], last[x+1]).
- **Dynamic maintenance:** When processing A[R] = v, only last[v] changes, from old to R. The first sum increases by R - old. The second sum is affected only by pairs (v-1, v) and (v, v+1). Subtract their old minima, update last[v] = R, then add their new minima. Since R is larger than all previous last values, the new minima are simply last[v-1] and last[v+1] when those neighbors exist.
- **Boundaries:** For v = 1, pair (0, 1) is not part of the adjacent-pair sum. For v = N, pair (N, N+1) is not part of the sum. The implementation skips these nonexistent pairs.
- **Complexity:** The sweep is O(N) time and O(N) memory. Python integers safely handle the answer, whose maximum is O(N^3) and fits in 64-bit for N <= 3e5.
- **Edge cases:** N = 1 has no adjacent pairs. Absent values are represented by last[x] = 0 and contribute zero. Repeated values update last[v] correctly and only affect neighboring pair terms.
- **Verification:** The method matches the samples. It also gives N(N+1)/2 for all-equal arrays and for arrays whose values form one consecutive component in every subarray, such as strictly increasing or decreasing permutations.
