Model each state as (current vertex, current edge orientation), giving a 2-layer graph with nonnegative edge costs. Normal moves cost 1 and stay in the same orientation layer, while reversing all edges costs X and switches layers at the current vertex. Then the problem becomes a shortest path from vertex 1 in the original layer to vertex N in either layer. Use Dijkstra’s algorithm because all transition costs are nonnegative and N, M are up to 2×10^5. Use 64-bit integers for distances since the answer may exceed 32-bit range.
