The key is to characterize each number x by the minimum number c(x) of divisions by 4 needed to reach 0, which is floor(log_4 x)+1. Each operation advances exactly two array elements by one such division, so for a query the minimum operations is max(max c(x), ceil(sum c(x)/2)). Since c(x) is constant on intervals [4^{k-1}, 4^k - 1], range sums can be computed quickly using a prefix function over O(log_4 r) intervals. The maximum c(x) in [l,r] is simply c(r), because c is nondecreasing. Then process each query in O(log r) time and sum the results.
