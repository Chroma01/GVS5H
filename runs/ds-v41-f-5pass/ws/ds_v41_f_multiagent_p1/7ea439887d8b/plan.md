Model the process as shortest paths in a two-layer state graph: one layer for normal edge orientation and one for reversed orientation. From the normal layer, original directed edges cost 1 and switching to the reversed layer costs X; from the reversed layer, the original edges traversed backwards cost 1 and switching back costs X. Run Dijkstra from vertex 1 in the normal layer, then take the minimum distance to vertex N across both layers. Use 64-bit arithmetic because path costs can exceed 32-bit limits. The complexity is O((N+M) log N), which fits the constraints.
