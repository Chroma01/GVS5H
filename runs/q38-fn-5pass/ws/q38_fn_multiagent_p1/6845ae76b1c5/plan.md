Use square-root decomposition on the A prefix. Maintain an array base[Y] for the full A blocks already processed, and compute each whole A block’s contribution to every B prefix Y in O(N) by sweeping sorted B values against the sorted values of that block. For the remaining partial A part of each query, keep only the shorter of the prefix part or the complementary suffix part (with a sign), create one subquery per A element in that short part, and answer all subqueries offline by sorting them by A value and sweeping B values with two Fenwick trees over B indices to get count/sum of B_j <= v in prefix Y. Combine base[Y], possibly the current block contribution, and the signed partial sum to get each answer. Choose a block size around 450–500 for the maximum constraints, giving roughly O(N^2/S + K S log N) time and O(N + K S) memory.
