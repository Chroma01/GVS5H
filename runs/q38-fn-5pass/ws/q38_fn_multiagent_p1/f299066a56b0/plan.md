Use a greedy two-pointer matching strategy on the sorted size array. Treat the smaller pointer as the candidate for the top mochi and the larger pointer as the candidate for the bottom mochi. Whenever the top size is at most half of the bottom size, form one kagamimochi and advance both pointers; otherwise, advance the bottom pointer to find a sufficiently large bottom. This greedy choice is optimal because using the smallest possible top with the smallest possible valid bottom leaves the largest remaining mochi available for future pairs. The algorithm runs in O(N) time and O(1) extra space.
