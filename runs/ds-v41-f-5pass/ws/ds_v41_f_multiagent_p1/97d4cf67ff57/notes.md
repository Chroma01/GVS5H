- **Problem restated:** Find a connected subgraph of tree T where every vertex has subgraph-degree 1 or 4 and at least one vertex has degree 4; maximize vertex count, else -1.
- **Key simplification:** Any alkane has a degree-4 vertex. Root the selected subgraph at such a vertex r. Then r uses exactly 4 incident selected edges; every non-root internal selected vertex has 1 parent edge + exactly 3 child edges (degree 4); every leaf has just its parent edge (degree 1). This removes the need to track a "has degree-4 vertex" flag entirely.
- **Branch definition:** For directed edge (u,v), let B(u,v) = max size of a valid branch on v's side that uses edge (u,v) and is rooted at v. A branch root is either a leaf (0 children, size 1) or has exactly 3 child branches (size 1 + sum). So B(u,v) = max(1, 1 + top-3 sum of B(v,w) over neighbors w of v with w != u), where the non-leaf option requires v to have at least 3 neighbors besides u. B(u,v) is always defined and >= 1.
- **Answer formula:** For each vertex r with deg(r) >= 4, candidate = 1 + sum of the 4 largest B(r,w) over neighbors w. Answer = max candidate; -1 if no vertex has degree >= 4. Correctness: rooting any optimal alkane at one of its degree-4 vertices shows its size is bounded by such a candidate, and each candidate is realizable.
- **Two-pass DP:** Root host tree at 0. down[v] = B(parent(v), v) computed in reverse BFS/DFS order using top-3 of children's down. up[v] = B(v, parent(v)) computed in forward order via rerooting. For vertex v, its incident branch values are {down[w] : w child} plus {up[v] if v not root}; then top-4 gives the candidate and top-3 excluding a specific child gives up[child].
- **Exclusion trick:** Keep entries sorted descending with tags (child id, or -1 for parent edge). Since only one entry has a given tag, taking the first 3 entries whose tag != c yields the top-3 excluding c (top-4 suffices to recover top-3 after removing one element). up[child] = 1 + that sum if 3 exist, else 1.
- **Complexity:** O(N log N) time (sorting per-vertex adjacency branch lists), O(N) memory. N up to 2e5 handled.
- **Implementation notes:** Fully iterative (no recursion) to avoid stack overflow. down/up for the root are unused placeholders. Verified against samples: sample1 = 8 (root vertex 2, branch to 3 worth 4), sample2 = -1 (max degree 3), sample3 = 11 (root vertex 9 or 1).
