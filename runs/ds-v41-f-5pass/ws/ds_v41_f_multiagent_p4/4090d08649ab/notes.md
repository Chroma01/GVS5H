- **Reduction:** For a subarray, let S be its set of distinct values. Split S into maximal runs of consecutive integers. One operation can erase exactly the values inside a single maximal run (choose l,r = run endpoints; every integer in between is present, and runs cannot be merged across a gap). So f(L,R) = number of maximal runs = number of values v present such that v-1 is absent, with v-1=0 treated as never present. Equivalently v contributes iff v occurs and v-1 does not.
- **Sum over v:** total = sum over v of (number of subarrays containing v but not v-1). For v=1 the forbidden value 0 never occurs, so no restriction from below.
- **Fixed-R formula:** define last[v] = last position of value v in A[1..R], last[0]=0. For fixed R, v contributes for start L iff last[v-1] < L <= last[v], giving max(0, last[v]-last[v-1]) values of L. Summing over all v gives sum over L of f(L,R).
- **Incremental sweep:** iterate R=1..N with x=A[R]. Only contribution(x) and contribution(x+1) depend on last[x], so only those change. Subtract their old contributions (using old last values), set last[x]=R, add their new contributions, then ans += S. Skip x+1 when x+1>N (contribution of N+1 is always 0 anyway). Total O(N) time, O(N) space.
- **Bounds:** answer <= ~N^3/2 ≈ 1.35e16 for N=3e5, fits in 64-bit; Python ints are safer regardless.
- **Edge cases:** value 0 sentinel last[0]=0 handles v=1; values never appearing have last=0 and contribute 0; multiple occurrences of a value in one subarray are counted once by the interval-of-L argument, naturally avoiding overcount.
- **Verification:** sweep reproduced f-sums for sample 1 (R sums 1,3,5,7 -> total 16) and sample 2 (1,3,5,6,8 -> total 23); sample 3 expected 129.
- **Implementation detail:** index arrays of size N+2 so last[x+1] with x+1=N+1 is safe even if guarded; read all input at once with sys.stdin.buffer.
