Compute prefix distinct counts `L[i]` for the first `i` elements and suffix distinct counts `R[i]` for the suffix starting at `i`. For each possible right split `j`, the answer candidate is `max_{i<j} (L[i] + distinct(A[i+1..j]) + R[j+1])`. Sweep `j` from left to right while maintaining a segment tree over candidate left splits `i`, where each leaf stores `L[i] + distinct(A[i+1..j])` for the current `j`. When `A[j]` is added to the middle segment, increment by 1 exactly those starts `i` whose current middle segment did not already contain `A[j]`, i.e. `i` in `[last[A[j]], j-1]` using 1-based indexing with `last=0` mapped to `1`. After each update, query the maximum active leaf and add `R[j+1]` to update the global answer.
