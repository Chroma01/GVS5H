Model the operations as choosing a flip bit for each row and each column, so the final value of cell (i,j) is A_{i,j} xor row_i xor col_j. Since W <= 18, enumerate all column-flip masks, but avoid O(H * 2^W) by counting frequencies of each row pattern. For a fixed column mask, each row pattern p contributes min(popcount(p xor mask), W - popcount(p xor mask)) ones, so the total is an XOR convolution of the row-pattern frequency array with the cost function f(mask) = min(popcount(mask), W - popcount(mask)). Compute this convolution for all masks using a fast Walsh-Hadamard transform in O(W * 2^W), then take the minimum resulting total.
