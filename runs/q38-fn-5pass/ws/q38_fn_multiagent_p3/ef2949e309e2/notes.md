- **Condition:** For a fixed middle index with value x, choose two indices before and two after. Let s be the number of x's among those four side elements. The middle value is a unique mode iff s >= 2, or s == 1 and the three non-x side values are pairwise distinct. s == 0 is always invalid.
- **Sweep structure:** Sweep the middle index. Maintain counts for the left side and right side. Before processing index k, remove nums[k] from the right side; after processing, add it to the left side. This keeps left as indices < k and right as indices > k.
- **Distinct-pair maintenance:** For each side, maintain the number of index pairs with different values. When adding value v to a side of current size s and current count c[v], new distinct pairs are s - c[v]. When removing value v before decrementing its count, removed distinct pairs are s - c[v]. This supports O(1) updates.
- **At least two side x's:** For current x, let Lx and Rx be counts on left/right, and l, r be side sizes. Total choices are C(l,2) * C(r,2). Subtract zero side-x: C(l-Lx,2) * C(r-Rx,2). Subtract exactly one side-x: Lx*(l-Lx)*C(r-Rx,2) + C(l-Lx,2)*Rx*(r-Rx). The remainder is valid regardless of duplicates among non-x values.
- **Exactly one side x on the left:** Choose one left x and one left non-x value y. The right pair must have zero x, two distinct values, and neither value may equal y. Let D_R_excl_x = right_distinct - Rx*(r-Rx), the number of right distinct non-x pairs. For a value y, invalid right pairs containing y are ry*(right_non_x-ry). Summing over y gives bad_left. Contribution is Lx * (D_R_excl_x * left_non_x - bad_left).
- **Exactly one side x on the right:** Symmetric. Use D_L_excl_x = left_distinct - Lx*left_non_x and bad_right = sum over right values y of ry*ly*(left_non_x-ly). Contribution is Rx * (D_L_excl_x * right_non_x - bad_right).
- **Implementation details:** Use dictionaries for counts and a precomputed C(i,2) array. Skip a middle index entirely when Lx == 0 and Rx == 0. Skip the bad-sum loops when the corresponding non-x side size is zero. Iterate over left items for bad_left and right items for bad_right; total work is O(n^2) in the worst case for n <= 1000. Keep intermediate counts exact and apply modulo to the accumulated answer.
- **Verification:** Sample tests pass. Targeted edge cases checked: n=5 all equal and all distinct, s=0 invalid, s=1 valid only when the three non-x side values are distinct, s>=2 valid, duplicates across the single non-x side value and the opposite pair, multiple indices of the same value, negative values, and the all-equal Vandermonde sum. No counting failures found.
- **Complexity:** O(n^2) time and O(d) memory, where d is the number of distinct values.
