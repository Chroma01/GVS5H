Model each tile rotation as choosing which two of its four edge-midpoints are connected: Type A chooses an adjacent pair, Type B chooses an opposite pair. The torus no-dead-end condition is exactly equality of the two half-edge indicators across every shared cell boundary, including wrap-around boundaries. Thus the problem becomes counting assignments of local edge-incidence patterns that are globally consistent on the H×W torus. The solution should reduce these local constraints to binary variables and identify global parity/cycle constraints, allowing an O(HW) count per test case. Finally, handle the large T and total HW limits with fast input and modular exponentiation.
