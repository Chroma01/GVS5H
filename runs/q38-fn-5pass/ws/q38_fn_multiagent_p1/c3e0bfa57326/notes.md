- **Model:** A valid parenthesis sequence is a rooted ordered forest: each matching pair is a node, direct children are pairs immediately inside it, and top-level pairs are children of an artificial root.
- **Operation effect:** Any valid substring is exactly a contiguous block of siblings. Reverse-and-swap mirrors that block: it reverses the sibling order and recursively mirrors each subtree. Therefore the unordered rooted forest shape is invariant.
- **Reachability:** Mirroring a two-sibling block and then mirroring each resulting sibling swaps the two siblings while restoring their internal embeddings. Hence arbitrary sibling permutations are reachable. Single-subtree mirrors plus induction allow arbitrary independent embeddings of every subtree. Thus reachable strings are exactly all plane embeddings of the original unordered forest.
- **Canonical types:** Assign each node an unordered type ID by sorting its children's type IDs into a tuple and interning tuples. Leaves have the empty tuple. Process nodes in reverse creation order because parents are created before children.
- **Counting DP:** For a type with child multiset counts c_t and total m children, the number of distinct ordered embeddings is f = m! * product(invfact[c_t] * f[t]^c_t) modulo 998244353. The same formula applied to the artificial root's children gives the answer.
- **Implementation details:** Parse S with a stack, store children lists, precompute factorials and inverse factorials up to the number of nodes, compute type IDs and embedding counts, then evaluate the multinomial formula for root_children. The solution is iterative and avoids recursion.
- **Correctness safeguards:** Child strings are primitive valid sequences, so concatenations have unique primitive decomposition; this prevents overcounting from commuting child strings. The artificial root must be included to count top-level reorderings. Factorials are far below the modulus, so modular inverses exist.
- **Complexity:** O(N log N) time from sorting child type lists and O(N) memory. With N <= 5000 this is easily safe.
