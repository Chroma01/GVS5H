- **Problem shape:** Every valid special path is a downward ancestor->descendant segment with all-distinct nums values. For a fixed endpoint node v, the longest valid path ending at v uses the shallowest legal start depth L_v, because all edge lengths are positive (a deeper start strictly shortens the segment). So one candidate per node suffices.
- **Incremental start depth:** Maintain `last[value] -> depth` for the current root-to-v path. On entering v: `L_v = max(L_parent, last[nums[v]] + 1)`. The parent's L already guarantees distinctness over `[L_parent, parent]`; the only newly violated constraint is a repeat of `nums[v]` at depth `last[nums[v]]`, so start must be strictly deeper than it.
- **Length / count:** `length = dist[v] - distAtDepth[L_v]`, `count = depth[v] - L_v + 1`. Keep `distAtDepth[d]` as an array: set `distAtDepth[depth] = dist` on enter (before evaluating). Any index `< depth` refers to a genuine ancestor still on the path, so its stored value is current. Using `L_v` as a depth index (not node id) is essential.
- **Tie-break:** Track global `(max length, then min node count)`. Initialize to `(0, 1)` because a single node is a valid path with length 0 and 1 node; Example 2 confirms answer `[0,1]`.
- **Backtracking:** Store `old = last.get(val)` in the enter frame; on the matching exit frame restore `last[val] = old` (or delete if it was absent). Push the exit frame *before* children so LIFO processes all children first. Each node's own value is restored last within its subtree because children exit before their parent.
- **Iterative DFS:** n up to 5e4, so avoid recursion. Use an explicit stack of `(node, parent, L, dist, depth, phase, old)` frames and pass `L_v` down as the children's `L_parent`.
- **Rooting:** Input is an undirected tree; build adjacency both ways and skip `parent` when expanding, effectively rooting at node 0.
- **Edge weights:** All `length_i >= 1` and positive, so the monotonicity argument (minimal L = maximal length per endpoint) holds; do not rely on it if weights could be zero/negative.
- **Complexity:** O(n) time and O(n) space.
- **Hand check Example 1 (`[6,2]`):** Node 0 L=0 len 0 cnt 1 (best (0,1)); node 1 val 1 L=0 len 2 cnt 2 (2,2); node 2 val 2 L=1 len 3 cnt 2 (3,2); node 5 val 1 L=2 len 6 cnt 2 -> (6,2); node 3 val 1 repeats node1 so L=2 len 0; node 4 val 3 L=0 len 6 cnt 3 -> ties length but count 3 > 2, keeps (6,2). Final `[6,2]`.
- **Hand check Example 2 (`[0,1]`):** Node 0 len 0 cnt 1; node 1 val 2 repeats node0 so L=1, length 8-8=0 cnt 1. Final `[0,1]`.
