- **Model:** Each move advances by i in [A,B] and must land on a good square. Bad squares are the union of the given disjoint sorted intervals. Square 1 and N are always good (L>1, R<N).
- **A == B:** The step is forced, so the only candidate positions are 1, 1+A, 1+2A, .... Answer Yes iff (N-1) % A == 0 and no interval [l,r] contains a value 1+kA. The smallest such value is pos = 1 + ceil((l-1)/A)*A; blocked if pos <= r. Verified on all samples and hand cases.
- **Merging (A < B):** Merge intervals with next l <= prev r + 1 into maximal contiguous bad runs. A run of length >= B is uncrossable (crossing jump would need length+1 > B), so print No. This also bounds total simulated bad cells by M*(B-1) <= 3.8e5. Merging before the check is essential; adjacent intervals can combine to length >= B.
- **Saturation in a long good run:** Since A < B, the coin set [A,B] contains both A and A+1, whose numerical semigroup has conductor C0 = A^2 - A. So from any reachable x, every x+s with s >= C0 is reachable (all intervening cells are good inside the run). Hence any window of B consecutive reachable cells becomes FULL and stays FULL; conversely a zero window stays zero.
- **Sliding window DP:** mask bit t = reachable(cur - t). Good transition: nb = 1 if (mask & RM) else 0, then mask = ((mask<<1)|nb) & FULL, where RM = bits A-1..B-1 (RM = (1<<B)-(1<<(A-1))); for A=1 this equals FULL. Bad transition: mask = (mask<<1) & FULL (forces 0). RM correctly captures sources x+1-i for i in [A,B]. Direct jumps over bad runs are handled automatically because old bits persist in the window.
- **Early completion:** After the DP generates a reachable cell at position x with `remaining` cells left in the run, if remaining >= C0+B-1 the window at the run end (hi-B+1 >= x+C0) is entirely reachable, so set mask = FULL and skip. This makes per-run work O(B + (C0+B)) even for runs up to 1e12 long. Stopping at mask==0 is also valid (good transition keeps 0).
- **Complexity:** O(M * (C0 + 2B) + total bad cells) = O(M*(A^2+B)), trivial for the limits (max ~7.6e6 operations for A<B, B<=20, M=2e4).
- **Stress test:** Ran a brute-force BFS/DP comparison on many random small cases (N<=60, A<=B<=20, random disjoint sorted intervals with 1<L<=R<N). Included targeted edge cases: A==B, A=1, A=B=20, adjacent intervals with L=r+1, bad-run length exactly B-1 (crossable) and exactly B (No), M=0, N=2, and multi-hop jumps skipping whole good segments. Result: zero mismatches. Max N=1e12, M=2e4 runs in well under 1 second.
- **Pitfalls avoided:** not simulating 1e12 good cells; not treating adjacent intervals as separate (would wrongly allow crossing a long contiguous wall); A==B handled separately because no saturation applies.
