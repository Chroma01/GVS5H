Model each smoke particle by the time it was generated at the origin; after winds 1 through t, a particle generated at time k is at prefix displacement P_t - P_k. Since generating extra smoke at an already occupied origin does not change the set of occupied cells, we can treat a particle as generated at every time k = 0..t. Thus, target cell (R,C) is occupied at time t iff some earlier prefix P_k equals P_t - (R,C). Compute prefix displacements online while maintaining a set of seen prefix positions, and answer each time with a membership test. This gives O(N) time and O(N) memory.
