- **Core model:** Represent the sorted configuration by its consecutive gaps `d_j = x_{j+1} - x_j` for `1 <= j <= N-1`. The objective depends only on the sorted coordinates, so gaps are the natural state.
- **Operation effect:** For four consecutive sorted pieces with gaps `d_i, d_{i+1}, d_{i+2}`, reflecting the two middle pieces about the midpoint of the outer two reverses these three gaps. The new gaps are `d_{i+2}, d_{i+1}, d_i`, which is equivalent to swapping `d_i` and `d_{i+2}` while leaving `d_{i+1}` fixed.
- **Reachability:** The operation swaps gaps whose indices have the same parity. For every adjacent pair inside the odd-indexed gap subsequence, there is a valid operation swapping them; similarly for the even-indexed subsequence. Therefore any permutation of odd-indexed gaps and any permutation of even-indexed gaps is reachable independently.
- **Invariant leftmost coordinate:** The leftmost piece never moves to the right of the current leftmost piece, and no operation can create a new smaller coordinate. Thus the minimum coordinate remains `X_1`.
- **Sum formula:** If the final sorted gaps are `g_j`, then the sum of coordinates is `N * X_1 + sum_{j=1}^{N-1} (N-j) * g_j`. Gap `g_j` contributes to all pieces to its right, giving weight `N-j`.
- **Greedy assignment:** For each parity class, the available weights are positive and strictly decreasing as the gap position increases. To minimize the weighted sum, assign smaller gaps to larger weights and larger gaps to smaller weights. Hence sort each parity class ascending and place them into the original parity positions from left to right.
- **Implementation:** Compute gaps, split by 1-based gap parity, sort each list ascending, then add contributions using the corresponding weights. Python integers safely handle the large coordinate and sum bounds.
- **Complexity:** Computing gaps is `O(N)`, sorting the two parity classes is `O(N log N)`, and the final summation is `O(N)`. Memory usage is `O(N)`.
- **Edge cases:** `N = 4` has one odd-pair swap and one even gap. Equal gaps are handled naturally. Half-integer midpoints are avoided entirely by working with integer gaps.
