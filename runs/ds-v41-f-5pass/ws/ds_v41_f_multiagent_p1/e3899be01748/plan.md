The target is counting substrings by their last non-zero digit, so we can process each ending position and test divisibility against that digit only. Because the relevant divisor is at most 9, maintain for each divisor d=1..9 the modulo-d value of every substring ending at the current position, updating these values incrementally when a new digit arrives. Count a substring whenever its ending digit d is non-zero and its tracked value modulo d is 0. This yields an O(9n) or O(n) algorithm, independent of substring length. The main risks are handling leading zeros correctly and avoiding O(n^2) substring enumeration.
