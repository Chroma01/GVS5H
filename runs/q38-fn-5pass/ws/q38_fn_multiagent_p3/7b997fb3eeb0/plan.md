For a query interval of length \(m\), \(K\) pairs are possible iff the \(K\) smallest mochi in the interval can be paired with the \(K\) largest mochi, i.e. for every \(t=0,\dots,K-1\), \(2A[L+t] \le A[R-K+1+t]\). Precompute `nxt[i]`, the first index with \(A[\text{nxt}[i]] \ge 2A[i]\), and define \(D[i]=\text{nxt}[i]-i\). Then the feasibility condition for \(K\) becomes \(\max(D[L..L+K-1]) \le m-K\). This predicate is monotone in \(K\), so each query can be answered by binary searching \(K\) in \([0,\lfloor m/2\rfloor]\) using a range-maximum query on \(D\). Use two pointers for `nxt`, a sparse table for \(O(1)\) RMQ, and \(O(\log N)\) per query.
