- **Model:** From start K the reachable set is a contiguous interval [l,r] containing K; absorbing an adjacent value strictly smaller than the current sum grows it by one. Sums only grow, so the maximal reachable interval is unique and order-independent; Answer(K) = its total sum.
- **Cartesian tree (leftmost-max):** Build the max Cartesian tree with tie-break keeping the leftmost maximum (pop the stack only on strict `<`). Node p spans [lo[p],hi[p]]; subtree sum W(p)=P[hi]-P[lo-1].
- **Segment formula (avoids building the tree):** subtree(p) = [L,R] with L = (nearest j<p having A[j] >= A[p]) + 1 (or 1), R = (nearest j>p having A[j] > A[p]) - 1 (or n). The `>=` on the left and `>` on the right is exactly the leftmost-max tie-break. Both computed with monotonic stacks in O(N).
- **Neighbours are ancestors:** L-1 is the nearest left value >= A[p] (an ancestor), R+1 is the nearest right value > A[p] (an ancestor). Their segments contain p's segment.
- **Start reachability:** If lo<K then K-1 lies in K's left subtree with A[K-1] < A[K], so K absorbs it, sum > A[K], and every remaining subtree element (all <= A[K]) is absorbable: whole subtree reachable. If lo==K and A[K+1] < A[K], K absorbs right and the rest of the subtree follows. If lo==K and A[K+1] > A[K], K is a leaf, so reach=K gives A[K]. Only the equal-right case needs an override.
- **Stuck override:** If lo[K]==K and A[K+1]==A[K], then A[K-1] >= A[K] (lo==K) and A[K+1]==A[K], so no strictly smaller neighbour exists: Answer(K)=A[K].
- **Jump rule:** From node p, if A[lo-1] < W(p) move to node lo-1, elif A[hi+1] < W(p) move to node hi+1, else stop. After p absorbs its whole segment (sum W), the target u=lo-1 is absorbable since A[u] < W; the new sum W+A[u] > A[u] >= every element of seg(u), so p absorbs all of seg(u) and lands exactly on the state (seg(u), W(seg(u))) that u itself represents. Hence reach(p)=reach(u), and path compression makes the total work linear. Every jump strictly enlarges the interval, so no cycles.
- **Answer:** answer(K)=W(seg(reach(K))) with the stuck override applied first.
- **Complexity:** O(N) time / O(N) memory; sums up to ~5e14 fit Python ints; N=5e5 fine.
- **Optimization:** Merged `done` array into `reach` (0 = not done). Used local variable bindings. Output via `' '.join(map(str, out))`. No recursion. No cycle guard needed.
- **Benchmark (theoretical):** N=5e5. Reading ~0.1s, prefix sums ~0.05s, lo/hi monotonic stacks ~0.1s each, jump loop ~0.1s amortized (each node added to a path at most once), output building + join ~0.15s. Total ~0.6–1.0s PyPy, ~1.5–2.5s CPython. Memory ~110MB (A, P, lo, hi, reach, out). Output is space-separated with trailing newline. No recursion depth issues.
- **Verification:** Earlier exhaustive search (n<=6 over {1,2,3}, n=7 over {1,2}), adversarial duplicate/equal-block arrays, and 8000 random small-range arrays all matched a BFS-over-intervals brute force. Direct segment formula proven equivalent to the tree-based one (checked on [4,13,2,3,2,6], [2,2], [1,3,2], [5,5,1], [7,5,5,1], [5,5,5]). Samples reproduced: `4 30 2 13 2 13` and `22 47 235 10 31 235 2 235 5 235 6 235`.
- **Submission shape:** Single-mode program (stdin -> stdout); no stress/brute code, no dual-mode/isatty branch.
