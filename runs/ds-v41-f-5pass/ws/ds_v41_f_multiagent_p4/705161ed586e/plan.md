Model the result as consecutive runs, each of length at least 3, where changing a position to a target character costs alphabet distance. Use suffix DP with state `(index, current run character, current run length capped at 3)` to store the minimum remaining operations. Optimize transitions by precomputing, for each index, the best and second-best costs over all possible next characters, so switching run character is O(1). After finding the global minimum, reconstruct greedily from left to right, choosing the smallest character that still permits an optimal remaining cost. If the initial state is impossible, return an empty string.
