The initial graph is bipartite, so each connected component has a fixed bipartition up to swapping the two sides. A legal move either adds a missing edge between opposite sides inside one component, or adds an edge between two components and merges them with one of two relative orientations; the game ends exactly at a complete bipartite graph. If N is odd, every complete bipartite graph has an even number of edges, so the winner is determined only by the parity of M. If N is even, the parity of the final color-class size determines the parity of the total number of moves, and the game can be reduced to a small impartial game on component types: isolated vertices, odd non-isolated components, and even components whose two color classes are both even or both odd. Compute these component statistics in O(N), then apply the parity/game-theoretic condition for the N-even case.
