Build a trie of all words and count how many words pass through each prefix node. For a fixed removal i, a prefix is usable iff its count minus whether word i has that prefix is at least k, so answer[i] is the maximum depth among usable prefixes. Separate prefixes with count >= k+1, which are usable for every removal, from prefixes with count == k, which are usable only for removals of words outside that prefix’s subtree. Lexicographically sort words so every trie subtree becomes a contiguous index interval, then process count==k prefixes as range-max updates on the complement of their interval. Finally combine the global count>=k+1 best with point queries for each original word, handling k=1 and cases with fewer than k remaining words.
