Process queries offline by increasing R, maintaining the best strictly increasing subsequence lengths that end at each compressed value. When adding A_i, compute 1 plus the maximum length among all ending values strictly less than A_i, then update the value A_i with this length using a Fenwick tree for prefix maximum. For a query (R, X), after processing the prefix up to R, map X to the largest compressed value <= X and take the Fenwick prefix maximum. This gives O((N+Q) log N) time and O(N+Q) memory. Verify strictness (use < A_i, not <=), duplicate values, and X mapping carefully.
