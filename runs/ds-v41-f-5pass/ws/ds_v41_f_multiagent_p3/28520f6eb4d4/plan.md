Reduce visibility to a monotone geometric condition: for each building, visibility from (0,h) is determined by whether the line from the origin to its top clears all earlier buildings. For each building i, derive the minimum h required for it to be visible, as the maximum of linear constraints from previous buildings. The answer is the maximum such required height over all buildings, with special handling for strict intersection and the -1 case when height 0 already sees all buildings. Compute all constraints efficiently using a convex hull trick or Li Chao-style structure to handle N up to 2e5. Finally, compare the resulting threshold against 0 to decide between -1 and the numeric answer.
