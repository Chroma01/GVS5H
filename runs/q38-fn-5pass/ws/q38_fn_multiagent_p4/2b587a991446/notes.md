- **Validation:** The large-graph formula was checked against exact ordered-pair BFS by forcing the formula on small connected graphs (N <= 8/9), including paths, branched trees, cycles, odd cycles, endpoint cycles/bridges, and graphs with multiple shortest paths. No mismatches were found. The final code uses the formula for all N.
- **Two shortest paths:** If `ways[T] >= 2`, answer is `2*D`. Distinct shortest paths visit shared vertices in the same order of `distS`, so the pieces can be interleaved without extra moves.
- **Unique shortest path:** When there is only one shortest path `P`, vertices with `distS[v] + distT[v] == D` are exactly `P`. Any solution needs extra moves to exchange the pieces' order.
- **One-piece detour (`cycle_extra`):** If one piece can follow `P` while the other takes a longer S-T walk, the extra is the shortest positive value of `length - D`. This is computed with edge weight `w = 1 + distS[u] - distS[v]`, always 0, 1, or 2. The walk is forbidden from entering `S` after the start, leaving `T` before the end, or moving backward along `P`.
- **Dial implementation:** A level-bucket Dial algorithm with three deques for distances `cur`, `cur+1`, `cur+2` is used. This avoids subtle modulo-bucket issues and keeps the detour search linear.
- **Branch passing place (`branch_extra`):** For a vertex `v` of degree at least 3, both pieces can go to `v`, pass locally, and leave. Travel extra is `2 * slack`, where `slack = distS[v] + distT[v] - D`. Locally, three incident directions are needed. `ports` counts distinct neighbors that are predecessors on a shortest path from `S` or from `T`; `spare = max(0, 3 - ports)`. Local extra is `2 * spare`, so candidate extra is `2 * (slack + spare)`.
- **Why both terms are needed:** `cycle_extra` handles alternative paths/cycles where one piece can detour while the other follows `P`. `branch_extra` handles endpoint blocking and branching places where both pieces must use spare incident edges, such as an endpoint with two leaves or a cycle attached by a bridge to an endpoint.
- **Impossibility:** If both extras are infinite, the graph is a simple path, so the pieces cannot exchange order. Any connected graph with a cycle or a degree-3 vertex has at least one finite candidate.
- **Complexity:** Two BFS passes, one linear branch scan, and one linear Dial search give O(N + M) time and O(N + M) memory.
