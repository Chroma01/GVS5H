The goal is to find the largest target distance d such that we can mark at most K edges with weight 1 and force every path from 1 to N to use at least d marked edges. For a fixed d, model each vertex as having a level in 0..d, where level(v) is the minimum number of marked edges needed to reach v; this yields a minimum-cut formulation. In the cut network, level(v) >= k is represented by node (v,k) being on the source side, and the cut cost counts edges where level(v) = level(u)+1. If this minimum cost is at most K, then d is feasible, because extra marked edges can only increase distances. Iterate or binary-search d from 0 to N-1 and output the maximum feasible value.
