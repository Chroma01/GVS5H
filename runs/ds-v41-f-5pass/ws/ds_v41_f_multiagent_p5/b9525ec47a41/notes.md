- **Model:** cycle edge i oriented by x_i (1 if i->i+1), star edge i by u_i (present only if s_i=1, else 0). For i<N: d_i = 1 + x_{i-1} - x_i + u_i, with x_{-1}=x_{N-1}. Sum of in-degrees = |E| = N + K (K = number of 1s), so d_N = N + K - sum_{i<N} d_i is forced. Counting distinct full sequences = counting distinct prefixes (d_0..d_{N-1}).
- **NFA:** state = x_{i-1}. Transition c -> c' allowed on label d when d = 1 + c - c' + u (u in {0,1} if s_i=1 else u=0). A prefix is achievable iff some walk starts and ends at the same state (cycle closure).
- **Determinization:** track relation R = (S0, S1), S_p = set of reachable current states from start state p. Start = identity A=({0},{1}). Update S_p' = union_{c in S_p} T_c(label). Accepted iff R has a diagonal (0,0) or (1,1). DFA is deterministic, so a simple DP over states counts distinct accepted prefixes exactly (coefficient 2 encodes two label choices reaching one state, e.g. H'=...2H).
- **Reachable states (12):** A=({0},{1}) B=({1},{}) C=({},{0}) E=({0,1},{1}) F=({0},{0,1}) G=({0},{}) H=({0,1},{}) I=({},{1}) J=({},{0,1}) K=({0},{0}) L=({0,1},{0,1}) M=({1},{1}). Accepting: all but B,C.
- **Symmetry collapse to 7 vars:** transitions are invariant under B<->C, E<->F, G<->I, H<->J, K<->M; initial state A is fixed; each swapped pair is both-accepting or both-rejecting. Hence dp[B]=dp[C]=b, dp[E]=dp[F]=e, dp[G]=dp[I]=g, dp[H]=dp[J]=h, dp[K]=dp[M]=k, dp[A]=a, dp[L]=l forever.
- **Transitions s=0:** a'=a, b'=a+b+e+g+h, e'=e, g'=b+g+h, h'=h, k'=e+2k+l, l'=l.
- **Transitions s=1:** a'=0, b'=a+b+e+g+h, e'=a+e, g'=b+g+h, h'=b+g+2h, k'=e+2k+l, l'=2(e+k+l).

- **Complexity/perf:** O(N) time, O(1) memory. Hot loop avoids tuple construction for unchanged vars, iterates the bytes object directly, tests parity via `ch & 1`, and takes modulo only every 64 iterations (values grow at most ~factor 5 per step, so <~150-bit ints).
