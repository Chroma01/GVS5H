The game is an impartial combinatorial game equivalent to activating piles and using leftover tokens as pass moves. The key is to determine the winner by analyzing the parity of the number of odd-valued piles (which give even pass pools) and the special cases for small N. Derive the winning condition: for N=1 Fennec always wins; N=2 Snuke always wins; N=3 Snuke wins only if all A_i are even; for N≥4 Fennec wins if the count of odd A_i is odd, otherwise Snuke wins. Implement a simple O(N) scan to count odd A_i and apply the condition, then verify against the provided samples.
