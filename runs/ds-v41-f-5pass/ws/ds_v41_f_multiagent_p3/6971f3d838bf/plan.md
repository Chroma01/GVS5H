Compute the original maximum subarray sum M; if M <= 0, return M because deleting non-positive values cannot increase the maximum. Otherwise, deleting value x is equivalent to zeroing all its occurrences, and any positive-sum subarray in the zeroed array must contain a surviving positive element, so it maps to a valid result. Process each distinct value by temporarily zeroing its occurrences, querying the global max subarray sum, and restoring the original values. Use a segment tree that maintains sum, max prefix, max suffix, and max subarray for each segment to support point updates and global queries in O(log n). Total complexity is O(n log n) time and O(n) space, and the final answer is the maximum of M and all queried values.
