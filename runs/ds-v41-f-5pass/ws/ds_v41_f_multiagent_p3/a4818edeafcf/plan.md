Precompute the number of distinct values in every prefix and suffix so the first and third subarray contributions are O(1) lookups. Sweep the second split position j from left to right while maintaining, for every possible first split i, the value prefix_distinct[i] + distinct_count(i+1..j) in a range-add/range-max data structure. When j advances, use the previous occurrence of A_j to update exactly the range of i values whose middle segment gains a new distinct value. For each valid j, query the best i < j, add the precomputed suffix contribution for j+1, and update the global answer. This yields an O(N log N) algorithm suitable for N up to 3e5.
