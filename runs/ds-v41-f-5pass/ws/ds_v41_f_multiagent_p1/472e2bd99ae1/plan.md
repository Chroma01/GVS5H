Sort the three sequences in descending order so that the expression A_i B_j + B_j C_k + C_k A_i is non-increasing as any index increases. Use a best-first search with a max-heap over triples (i,j,k), starting from (0,0,0). Because the function is monotone in each coordinate, the top K values can be generated by repeatedly extracting the maximum and pushing its three successors (i+1,j,k), (i,j+1,k), (i,j,k+1). Maintain a visited set to prevent duplicate states. Pop K times; the K-th popped value is the answer.
