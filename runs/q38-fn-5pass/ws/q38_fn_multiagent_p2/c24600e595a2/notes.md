- **Structure:** Positions with A_i=B_i=0 are never flipped. Positions with A_i=1,B_i=0 are flipped exactly once as 1->0. Positions with A_i=0,B_i=1 are flipped exactly once as 0->1. Only positions with A_i=B_i=1 may be flipped twice, as 1->0 then 0->1. Any redundant on/off pair can be removed to reduce cost, and adjacent swaps of a 0->1 flip before a 1->0 flip strictly reduce cost, so an optimal schedule is V-shaped: all 1->0 flips first, then all 0->1 flips.
- **Phase ordering:** In the down phase, larger C should be flipped earlier, so D plus removed common 1s are sorted descending. In the up phase, smaller C should be flipped earlier, so P plus removed common 1s are sorted ascending.
- **Cost for fixed removed set:** Let D be 1->0 costs, P be 0->1 costs, R be removed common 1s, and K\R be kept common 1s. With M=|D|+|P|+2|R|, cost is F_down(D∪R)+F_up(P∪R)+M*sum(K\R), where F_down is sum of (rank-1)*c in descending order and F_up is sum of (U-rank+1)*c in ascending order.
- **Prefix property:** Sort common 1s by cost. If a lower-cost common 1 is removed while a higher-cost one is kept, swapping them is never worse. The marginal cost of removing a common 1 of cost x, with other removed set fixed, can be written as a nonincreasing function of x, so the optimal removed set is a suffix of common 1s sorted by cost, equivalently the kept set is a prefix of low-cost common 1s.
- **Incremental scan:** Sort K descending and move common 1s from kept to removed one by one. Maintain removed count r, total_ops M, and kept_sum. For current x, all previously removed common 1s have cost at least x.
- **Down insertion delta:** Maintain pD = number of D elements >= x and sumD_less = sum of D elements < x. Since previous removed common 1s all contribute x, add_down = (pD + r) * x + sumD_less.
- **Up insertion delta:** Maintain pP = number of P elements <= x and sumP_le = their sum. Previous removed common 1s all contribute x, so add_up = sumP_le + (u - pP + r + 1) * x.
- **Cost update:** Before moving x, current = down_cost + up_cost + M*kept_sum. After moving x, delta = add_down + add_up + 2*kept_sum - (M+2)*x. Then kept_sum -= x, M += 2, r += 1. Take the minimum over all prefixes, including the empty removed set.
- **Pointer tie handling:** For D, advance while D[pD] >= x so equal costs are counted as greater-or-equal. For P, advance while P[pP-1] > x so equal costs are counted as less-or-equal. Equal-cost choices do not affect the total cost.
- **Edge cases:** Empty D, P, or K are handled naturally. If A=B already, initial M=0 and answer is 0. If only D exists, the answer can be 0 for one flip or the weighted inversion cost for multiple flips. Values can be around 10^17, so Python integers are safe.
- **Complexity:** Sorting dominates: O(N log N) time and O(N) memory. The scan itself is O(N) because the D and P pointers only move monotonically.
