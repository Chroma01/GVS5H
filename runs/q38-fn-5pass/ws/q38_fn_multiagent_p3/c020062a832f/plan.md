Compute the inversion number for k=0 using a Fenwick tree over the values 0..M-1. For each step from k to k+1, all values increase by 1 modulo M, so only pairs where exactly one element wraps from M-1 to 0 change their inversion status. The wrapping elements at this transition are exactly those with A_i = M-1-k. Precompute, for each residue value, the net change in inversion count caused by moving all positions with that value from M-1 to 0, using their sorted positions and counts of non-wrapping elements before/after them. Then sweep k from 0 to M-1, updating the answer with the precomputed delta and printing each result.
