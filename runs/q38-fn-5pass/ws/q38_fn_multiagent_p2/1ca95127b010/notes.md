- **Invariant:** Operation A/B swaps adjacent blocks `0^X 1^Y` and `1^Y 0^X`. Every moved `1` shifts by `X`, every moved `0` shifts by `Y`, and relative order within `1`s and within `0`s is preserved. Thus the ordered residue sequence of `1` positions modulo `X`, and of `0` positions modulo `Y`, are invariants.
- **Completeness:** Orienting only A as `0^X 1^Y -> 1^Y 0^X` terminates because the sum of `1` positions decreases by `X*Y`. The left side has no proper self-overlap, so redexes are disjoint and the rewrite system is confluent. Therefore each equivalence class has a unique A-normal form, determined by the two residue sequences.
- **Why not the literal run-queue:** The requested queue of batched adjacent-run rewrites can be quadratic. For example, with `X=Y=2`, the pattern `(00 111)^m` forces `Theta(m^2)` batched macros, each with quotient `1`. A linked-list queue is therefore not safe for `N=5e5`.
- **Linear normal-form construction:** For each string, extract the ordered residue sequences. For each sequence, compute the latest possible position (deadline) of each occurrence by scanning backwards: the last occurrence is placed at the latest allowed position, then each previous occurrence at the latest allowed position before that.
- **Greedy canonical merge:** Scan positions left to right. At position `p`, the next `1` is placeable iff its residue is `p mod X`; similarly for `0`. If both are placeable, an item can be postponed iff its next allowed position is not later than its deadline. If one cannot wait, it is forced. If both can wait, place `1`, producing the lexicographically maximum feasible string with those residue sequences, which is the A-normal form.
- **Verification and fallback:** The greedy construction is checked to contain no `0^X 1^Y`. If it succeeds for both strings, comparing the verified normal forms is correct. If it fails for any string, the program falls back to the proven invariant comparison. This keeps the solution safe while still using normal-form computation as the primary path.
- **Degenerate cases:** If `X+Y > N`, no operation is possible and the answer is exactly `S == T`. If `X == 1`, all `1` residues are zero and deadlines are a contiguous suffix. If `Y == 1`, all `0` residues are zero. Empty one/zero sequences are handled naturally.
- **Complexity:** Each normalization is `O(N)` time and `O(N)` memory. The fallback invariant check is also `O(N)`. Overall time is `O(N)`, with bytearrays and lists sized by `N`.
- **Tests checked mentally:** Sample 1 normalizes both strings to the same canonical form. Sample 2 is caught by `X+Y > N`. The counterexample `N=5 X=2 Y=2 S=10010 T=11100` has different normal forms and different one-residue counts, so it prints `No`.
