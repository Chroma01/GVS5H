Process the string left to right while maintaining, for each possible last digit d from 1 to 9, the counts of all suffixes ending at the current position grouped by their value modulo d. When reading a new digit x, update these modulo counts by extending every existing suffix with x and adding the new one-digit suffix starting at the current position. If x is nonzero, add the count of suffixes whose remainder modulo x is 0 to the answer, because those substrings are divisible by their last digit. This avoids constructing substring values and runs in O(9 * 10 * n) time.
