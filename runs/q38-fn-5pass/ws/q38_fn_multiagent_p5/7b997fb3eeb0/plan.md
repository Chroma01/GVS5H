For any interval, if K pairs are possible, then the K smallest mochi in that interval can be used as tops and the K largest as bottoms. Define f[i] as the first index j with A[j] >= 2*A[i], and h[i] = f[i] - i. For a query [L, R] with length len, K is feasible iff max(h[L..L+K-1]) + K <= len. This predicate is monotone in K, so binary search the answer up to floor(len/2). Use a sparse table for O(1) range-maximum queries on h, giving O((N+Q)logN) total time.
