- **Problem reduction:** Red balls move only along permutation P, blue balls only along Q. Each color is confined to its permutation cycle. If any red ball is outside the P-cycle containing X, or any blue ball is outside the Q-cycle containing X, the answer is -1.
- **One-color mandatory sequence:** Order the relevant cycle as X = c0, c1, ..., c_{L-1}, where c_{i+1} = perm[c_i]. Balls already at X need no operation. If there is a ball at some c_i with i > 0, let s be the smallest such i. Any successful schedule must contain c_s, c_{s+1}, ..., c_{L-1} in this order, because the ball at c_s must traverse every successor to reach X. Operating each of these boxes once in this order is sufficient. Thus the mandatory sequence for a color is the suffix of its cycle starting at the closest occupied box after X. Operating X is never useful: it only moves balls out of X and cannot shorten the mandatory suffix.
- **Two colors:** Any global schedule must contain both mandatory sequences as subsequences. Conversely, any common supersequence of the two mandatory sequences is feasible. For each color separately, the embedded mandatory subsequence moves all balls of that color to X. Operations outside that color's mandatory suffix either have no balls of that color or are harmless extra forward moves. Therefore the minimum number of operations is the shortest common supersequence length of the two mandatory sequences.
- **LCS computation:** For two sequences with distinct elements, SCS length = len(R) + len(B) - LCS(R, B). Compute LCS by mapping each box in one sequence to its position, scanning the other sequence, and taking the length of a strictly increasing subsequence of the mapped positions. Use bisect_left for strict LIS. Mapping the longer sequence and scanning the shorter one reduces the number of bisect operations.
- **Implementation details:** Use 0-indexing. Traverse each cycle by repeatedly applying the permutation until returning to X. Mark cycle vertices with a bytearray and scan all boxes to detect balls outside the cycle. Build the suffix by finding the first occupied vertex after X. If either color is impossible, print -1. If one mandatory sequence is empty, the answer is the length of the other.
- **Complexity:** Cycle construction and outside checks are O(N). LCS via LIS is O(N log N). Memory is O(N).
- **Edge cases:** Cycle length one; balls only at X; no balls at all; identical required sequences; opposite order causing repeated operations; boxes containing both colors; self-loops outside X causing impossibility.
