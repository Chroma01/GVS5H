Use the fact that a gcd value g is achievable for position i if and only if g divides A_i and at least K elements of A are multiples of g. First build a frequency array of the input values, then sieve over multiples to compute cnt[g], the number of array elements divisible by g, for every g up to max(A). Next compute best[x], the largest divisor d of x with cnt[d] >= K, by scanning d in increasing order and assigning d to all multiples x whenever cnt[d] is large enough. Finally, answer each position i as best[A_i]. Special-case K=1 and K=N to avoid unnecessary work and keep the solution efficient for the maximum constraints.
