Precompute prefix and suffix arrays counting distinct values for every prefix and suffix. The answer for split positions (i,j) is prefix[i] + distinct(A[i+1..j]) + suffix[j+1], so process possible right-middle endpoint j and maintain the best value of prefix[i] + distinct(A[i+1..j]) over valid i. When extending j by one element, the middle distinct count increases by 1 exactly for left boundaries whose interval did not already contain A[j]; this set of boundaries forms a contiguous range based on the previous occurrence of A[j]. Use a lazy segment tree supporting range add and range maximum query to maintain these values efficiently. Iterate j from 1 to N-1 and combine the best valid middle value with suffix[j+1].
