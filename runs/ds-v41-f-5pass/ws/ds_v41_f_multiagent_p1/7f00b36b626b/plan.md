Recognize any value > threshold cannot have lcm <= threshold with any other value, so such nodes are isolated components. For values <= threshold (at most 2e5), build a DSU and exploit that two small values are connected iff they share a common multiple k <= threshold; all present divisors of k form a clique. Enumerate each small value d and add it to buckets for its multiples k <= threshold, so each bucket k contains exactly the present divisors of k. Union all entries in every nonempty bucket, then count DSU roots among small values plus the number of isolated large values. This runs in O(T log T) time and O(T log T) bucket storage.
