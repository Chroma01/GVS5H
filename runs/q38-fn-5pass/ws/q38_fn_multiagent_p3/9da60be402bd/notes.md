- **State model:** A palindrome path is represented only by its endpoints `(u, v)`. If a palindrome from `u` to `v` is extended by the same label `c` on both sides, using an edge `x -> u` labeled `c` and an edge `v -> y` labeled `c`, the result is a palindrome from `x` to `y` with length increased by 2. Conversely, any palindrome of length at least 2 can be peeled this way, so these transitions are complete.
- **Base cases:** Empty paths give distance 0 for `(i, i)`. Every directed edge gives distance 1 for its endpoints. All other answers are obtained by repeated extensions.
- **BFS ordering:** All transitions have cost 2. The queue is initialized with all distance-0 states first, then all distance-1 states. This keeps the deque nondecreasing by distance, so the first time a state is enqueued is its shortest palindrome length. States already initialized with 0 or 1 are never overwritten by longer extensions.
- **Optimal substructure:** Only the shortest distance for each endpoint pair is needed. If a shortest outer palindrome used a non-shortest inner palindrome, replacing the inner part with the shortest palindrome between the same endpoints would produce a shorter valid outer palindrome.
- **Bitset optimization:** There are only `N^2` states. For each first endpoint `x`, `unvisited[x]` is a bitmask of second endpoints `y` not yet reached. For a transition from `(u, v)`, for each letter `c` we take the predecessor list `pred[u][c]` and the successor mask `succ_mask[v][c]`. For each `x` in the predecessor list, `m = unvisited[x] & succ_mask[v][c]` gives exactly the newly reachable `y` values. We clear all bits in `m` at once and enqueue only those states, so each state is enumerated once.
- **Complexity:** Each processed state iterates over incoming edges of its first endpoint. Over all states this is at most `N * M <= N^3 = 10^6` for `N=100`, plus `O(N^2)` bit enumerations and `O(26 N^2)` small overhead. Memory is `O(N^2)` for distances and masks.
- **Implementation details:** Vertices are 0-indexed. Distances are stored in a flat list of length `N*N`. `pred[j][c]` stores sources of edges into `j` with label `c`; `succ_mask[i][c]` is a bitmask of targets of edges out of `i` with label `c`. `pred_nonempty` avoids scanning empty letter lists. Queue entries are encoded as `u*N+v`. Output prints the flat distance array row by row.
- **Edge cases:** Self-loops are initialized as distance 1, but diagonal states already have distance 0, so the empty path remains the answer. Unreachable states stay `-1`. The empty path is explicitly handled by the diagonal initialization.
- **Sample behavior:** The algorithm reproduces the samples: length-2 palindromes come from diagonal states, length-3 from edge states, and longer examples such as `abba` are built by two extensions.
