Binary search the maximum feasible minimum score. For a candidate score x, each position i needs r_i = ceil(x / points[i]) visits, so define extra demand d_i = r_i - 1 beyond the mandatory first visit. If the walk stops at index t, it must sweep to n-1 and optionally return to t, costing 2n-1-t base moves and giving one free extra visit to every index t..n-2; the remaining extra demands are covered by back-and-forth pairs on edges, and the minimum number of such pairs equals a maximum-weight independent set on the path of adjusted demands. Compute this independent-set value for every possible t in O(n) using prefix DP on original demands and suffix DP on demands reduced by one on the returned suffix, then accept x if any t gives total moves <= m. Search x over [0, max(points)*m+1).
