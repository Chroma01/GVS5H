- **Core representation:** Represent a configuration by the sorted coordinates and the gaps `g_k = x_{k+1} - x_k` for `k = 1..N-1`. The leftmost coordinate `x_1` is invariant under every operation.
- **Effect of one operation:** For four consecutive pieces with coordinates `a < b < c < d` and gaps `p = b-a`, `q = c-b`, `r = d-c`, the midpoint is `M = (a+d)/2`. Reflecting `b` and `c` gives `b' = a+d-b` and `c' = a+d-c`. The new sorted order is `a, c', b', d`, so the three gaps become `r, q, p`. Thus the operation swaps gaps `g_i` and `g_{i+2}` and leaves all other gaps unchanged.
- **Reachability:** Since an operation swaps gaps whose indices differ by 2, each gap can only move within its own index parity class. For odd-indexed gaps, operations with odd `i` swap adjacent elements in the odd-gap subsequence; for even-indexed gaps, operations with even `i` swap adjacent elements in the even-gap subsequence. Adjacent swaps generate all permutations, so any permutation within the odd gaps and any permutation within the even gaps is reachable independently.
- **Objective function:** The sum of coordinates can be written as `sum(x_j) = N*x_1 + sum_{k=1}^{N-1} (N-k) * g_k`. The weights `N-k` are strictly decreasing as `k` increases.
- **Optimization:** The total sum separates into odd-indexed gap terms and even-indexed gap terms. In each parity class, the weights are decreasing with gap index. By the rearrangement inequality, the minimum is obtained by sorting that parity class's gaps ascending and assigning the smallest gap to the largest weight, i.e. to the smallest index in that parity class.
- **Implementation details:** Use 0-based gap indices. `gaps[0::2]` contains 1-indexed odd positions, and `gaps[1::2]` contains 1-indexed even positions. After sorting each list ascending, multiply the `j`-th odd gap by weight `N - (2*j + 1)` and the `j`-th even gap by weight `N - (2*j + 2)`.
- **Complexity:** Computing gaps is `O(N)`, sorting the two parity classes is `O(N log N)`, and the final summation is `O(N)`. Python integers safely handle values up to roughly `2e17` and beyond.
- **Edge cases:** For `N = 4`, one parity class may have length 1 and the other length 2; the same formula works. All gaps are positive because coordinates are distinct, and the problem guarantees distinctness after operations, so no collision handling is needed.
