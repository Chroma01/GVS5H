Process the insertions in reverse: in the final array, element `i` must occupy the `P_i`-th currently empty position when positions of elements `i+1, ..., N` have already been fixed. Maintain a Fenwick tree over `N` positions where each empty position has value `1` and each filled position has value `0`. For `i = N, N-1, ..., 1`, find the position of the `P_i`-th empty slot, place `i` there, and mark that slot as filled. This gives the final array in `O(N log N)` time and `O(N)` memory.
