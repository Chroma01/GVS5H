The problem reduces to checking if a subarray of persons contains any conflicting pair. Two persons conflict exactly when they have the same direction and their intervals cross (a_i < a_j < b_i < b_j or vice versa), or when they share a left or right endpoint (a_i = a_j or b_i = b_j). For each person j, we can find the maximum index i < j that conflicts with j using simple arrays for shared endpoints and 2D range-maximum queries for the two crossing patterns. Precomputing a prefix maximum of these values allows each query [L, R] to be answered in O(1) by checking if the prefix maximum up to R is at least L. The 2D queries can be handled offline with a segment tree over a where each node maintains a Fenwick tree over b to answer maximum index in a rectangle.
