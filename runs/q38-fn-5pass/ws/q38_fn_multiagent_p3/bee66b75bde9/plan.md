The valid colorings are exactly Ferrers diagrams: if `a_r` is the number of black cells in row `r`, then `0 <= a_r <= N` and `a_1 >= a_2 >= ... >= a_N`. Each fixed black cell `(x, y)` imposes the lower bound `a_x >= y`, and each fixed white cell `(x, y)` imposes the upper bound `a_x <= y - 1`. Therefore, the problem reduces to checking whether there exists a nonincreasing sequence satisfying interval bounds on the at most `M` constrained rows. This can be done by aggregating bounds per row and sweeping rows from top to bottom while maintaining the smallest upper bound seen so far. If any row’s lower bound exceeds the minimum upper bound available from itself and all rows above it, the answer is `No`; otherwise it is `Yes`.
