- **Game model:** There are N mandatory activation moves. When index i is first chosen, it adds p_i = A_i - 1 pass tokens to a shared pool. Pass moves consume one token and flip the turn. The last activated index's remaining tokens are never usable because the game ends immediately. Thus the game is: players alternate either activating an unused index (removing it from U and adding p_i to pool P) or, if P > 0, consuming one pass token (P -> P - 1). Terminal is U empty.
- **Parity reduction:** Only the parity of P matters. Replace p_i by b_i = p_i mod 2. Then b_i = 0 if A_i is odd, b_i = 1 if A_i is even. State can be described by (c, z, P) where c = number of even A_i (b = 1), z = number of odd A_i (b = 0), and P is the parity of the pass pool. Moves: remove a 0-bit (c unchanged, z -> z-1, P unchanged); remove a 1-bit (c -> c-1, z unchanged, P -> 1-P); if P = 1, can pass to P = 0. Terminal c = z = 0 is losing.
- **Outcome formulas:** N = 1: always Fennec. N = 2: always Snuke. N = 3: Fennec iff z > 0 (at least one odd A_i). For all N >= 4: Fennec iff z is odd (number of odd A_i is odd), Snuke otherwise. The N = 3 case is exceptional because when z = 2, Fennec still wins, whereas the N >= 4 rule would give Snuke.
- **Inductive proof sketch:** Base N = 4 satisfies W(c,z,0) = (z odd) and W(c,z,1) = (z even). Assume these hold for N. For N+1, W(c,z,0) = (z>0 and not W(c,z-1,0)) or (c>0 and not W(c-1,z,1)). Both negations reduce to (z odd), so W(c,z,0) = (z odd) whenever c+z >= 4. Similarly W(c,z,1) = (z even). Thus the pattern persists for every N >= 4.
- **Complexity:** O(N) time, O(1) extra space. N up to 2e5 and A_i up to 1e9 are handled easily.
- **Samples and edge cases verified:** (3, 1 9 2) -> Fennec; (2, 25 29) -> Snuke; (6, 1 9 2 25 2 9) -> Snuke; (1, 2) -> Fennec; (3, 2 2 2) -> Snuke; (4, 2 2 2 2) -> Snuke; (4, 1 1 1 1) -> Snuke; (5, 1 1 1 1 1) -> Fennec.
