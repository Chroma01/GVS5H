Because each food contributes to exactly one vitamin, checking whether a target value T can be achieved decomposes by vitamin: the minimum calories needed is the sum of the minimum calories needed to obtain at least T of vitamin 1, vitamin 2, and vitamin 3 separately. For each vitamin group, precompute a 0/1 knapsack DP over calories: dp[c] = maximum vitamin amount obtainable using at most c calories. Then for any T, the minimum calories for that vitamin is the smallest c with dp[c] >= T, found by binary search/bisect. Binary search the maximum T such that the sum of these three minimum calorie values is at most X. This avoids a 3-dimensional DP and handles large vitamin amounts because the DP dimension is only X <= 5000.
