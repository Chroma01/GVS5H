Represent each row as a W-bit integer and treat flip operations as XOR masks. If we fix a column-flip mask, each row can independently be flipped to minimize its ones, contributing min(popcount(row XOR mask), W - popcount(row XOR mask)). Since W ≤ 18, enumerate all column masks efficiently by grouping identical rows into a frequency array f and using XOR convolution with a precomputed cost array g. Fast Walsh-Hadamard Transform computes all mask totals in O(W 2^W), then the answer is the minimum over all column-flip masks.
