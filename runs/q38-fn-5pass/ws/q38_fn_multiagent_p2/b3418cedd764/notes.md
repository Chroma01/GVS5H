- **Graph reduction:** Each node has one outgoing edge `i -> A_i`, so every weak component has exactly one directed cycle. The inequalities around a directed cycle force all cycle values to be equal. Removing cycle edges leaves rooted in-trees where each child value is at most its parent value.
- **DP definition:** For a non-cycle node `u`, let `F_u[v]` be the number of assignments in its subtree with `x_u <= v`. If `G_u[t]` is the product of `F_child[t]` over non-cycle children, then `F_u[v] = sum_{t=1}^v G_u[t]`. A leaf has `G_u[t] = 1`, hence `F_u[v] = v`. For a cycle node `c`, when the common cycle value is fixed to `v`, its attached-tree contribution is `H_c[v] = product F_child[v]`; this is not prefix-summed.
- **Cycle peeling and on-the-fly DP:** Use an indegree queue to remove indegree-zero nodes. When a node is popped, all its non-cycle children have already been processed and multiplied into `acc[u]`. If `acc[u]` is `None`, the node is a leaf; otherwise `acc[u]` is `G_u` and is prefix-summed in-place to become `F_u`. Then `F_u` is multiplied into `acc[A[u]]`. Decrement the parent indegree; if it becomes zero, the parent is non-cycle and is queued. Cycle nodes are never popped because their cycle predecessor keeps indegree positive.
- **Accumulator ownership:** `acc[x]` stores the product of processed child prefix arrays. For a leaf, if the parent accumulator is empty, assign a copy of `base = [0, 1, ..., M]`; otherwise multiply by `v`. For an internal node, after prefixing, transfer the list to the parent if the parent accumulator is empty, otherwise multiply into it and let the local list be freed. Set `acc[u] = None` when taking ownership to avoid stale references.
- **Combining cycles:** After the queue empties, nodes with `indeg > 0` are cycle nodes. Traverse each unvisited cycle. For each cycle node, multiply its `H` array (`acc[c]`, or implicit all-ones if `None`) into a product array over `v = 1..M`. The component count is `sum_v product[v]`; if no attached tree arrays exist, this is simply `M`. Multiply all component counts modulo `998244353`.
- **Modulo and speed:** Prefix sums use one conditional subtraction because both terms are already reduced. Multiplications use `% MOD`. With `N, M <= 2025`, the total number of Python loop iterations is `O(NM)` and is small enough. Arrays of length `M+1` are reused/transferred to keep memory reasonable.
- **Pitfalls checked:** Do not use a prefix array for a cycle node's own fixed-value contribution. A self-loop with no children must contribute `M`, not `M(M+1)/2`. Cycle predecessor edges must be excluded from tree products. The shared `base` array must be copied before being used as an accumulator.
