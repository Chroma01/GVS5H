- **Problem model:** f(x,y) is the minimax (bottleneck) path value = smallest t such that x,y are connected using only edges with weight <= t. Equivalently the weight at which their components first merge in Kruskal's algorithm, i.e. the LCA weight in a Kruskal reconstruction tree (KRT).
- **Goal:** min over permutations of B of sum f(A_i, B_i). This is a minimum-cost bipartite matching where cost has a nested-ultrametric structure.
- **Chosen solution (iterative DSU surplus):** Sort all edges by weight ascending. Keep DSU. Each component tracks net surplus = (#unmatched A) - (#unmatched B), after all internal (cheaper) matches are done, so every component has surplus of a single color (or 0). When merging comps with surpluses su, sv at weight w: match min(|su|,|sv|) opposite-color pairs at cost w (only if signs differ), add matched*w to answer, set new surplus = su+sv.
- **Why greedy works:** At a merge of weight w, cross pairs get f = w, the smallest weight at which they can possibly meet; any pair left unmatched must be matched at >= w later. Maximizing matches at the current smallest weight is optimal (exchange argument on the merge tree). Equal weights cause no issue: matches at the same w always cost w regardless of tie order.
- **Guarantee use:** A and B are disjoint vertex sets (A_i != B_j), so initial surplus per vertex is unambiguous; total A count = total B count = K, so final surplus is 0.
- **Verified:** Sample 1 -> 8 (matches at weights 1,2,5 giving 1+2+5); Sample 2 -> 3 (matches at 1 and 2).
- **Complexity:** O(M log M) sorting + near-linear DSU with path compression + union by size. Fits N,M <= 2e5. Answer uses Python big ints (no overflow).
- **Implementation gotchas:** find() is iterative (no recursion). Skip edges whose endpoints are already in the same component. Update surplus of the new root only.
- **Superseded ideas:** Kruskal reconstruction tree + recursive surplus DP, and virtual-tree compression over A∪B vertices. The direct DSU-by-weight surplus tracking is simpler, iterative, and sufficient; no KRT needed.
