- **Problem model:** shortest path (counted in edges) from i to j whose label string is a palindrome; -1 if none exists. The empty string is a palindrome, so every diagonal is 0.
- **Inside-out BFS state:** a pair (u,v) means we have an inner palindromic path from u to v of the recorded length. Bases: (i,i) with length 0 (empty) and every edge i->j with length 1 (one char). Transition (u,v) -> (p,q) with cost +2 when some edge p->u and some edge v->q carry the same label c (prepend and append c).
- **Correctness:** any palindrome with >=2 chars equals c + (shorter palindrome) + c, and the middle of a palindrome is itself a palindrome. This induction generates exactly the palindromic-reachable pairs, and BFS first-discovery yields the minimum length.
- **Ordering / queuing:** every transition adds 2, and the only initial levels are 0 and 1. Enqueue all diagonals (level 0) then all edges (level 1); a plain FIFO deque then processes levels 0,1,2,3,... in order, so Dijkstra is unnecessary. The diagonal 0 must never be overwritten by a self-loop edge.
- **Bitset optimization:** store succ[c][v] as a bitmask of right endpoints and keep vis[p] as a bitmask of q already discovered for left endpoint p. From (u,v), for each label c iterate only p in pred[c][u] and compute `new = succ[c][v] & ~vis[p]`. Cost sums to N * E <= N^3 p-iterations plus O(N^2) bit extractions; fast for N<=100. The naive Cartesian product per state is up to O(N^4) and too slow in Python.
- **Orientation gotcha:** p is a predecessor of u (`p->u`) and q is a successor of v (`v->q`); swapping them silently breaks correctness.
- **Verification sample 1:** (1,4)=4 comes from "abba": base (2,2) empty, wrap 'b' with edges 1->2 and 2->3 giving (1,3)="bb", then wrap 'a' with edges 1->1 and 3->4 giving (1,4)="abba".
- **Verification sample 2:** (5,3)=5 is "tsust": base edge 4->1 'u', wrap 's' (4->4, 1->2) giving (4,2)="sus", then wrap 't' (5->4, 2->3). Matches (4,2)=3 and (5,3)=5.
- **Implementation details:** read with sys.stdin.buffer (each '-' is byte 45); map letters to 0..25; precompute per-u list of non-empty (label, predecessor-list) buckets to skip the 26-label scan when possible.
- **Edge cases:** N=1 prints 0; self-loops leave the diagonal at 0; unreached pairs stay -1.
