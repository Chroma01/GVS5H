- **Reverse reconstruction:** Process values from N down to 1. After values greater than i have been placed, the still-empty final positions are exactly the positions occupied by values 1..i in the array after insertion i. Therefore value i belongs to the P_i-th empty position from the left.
- **Fenwick tree:** Maintain a BIT over final positions with 1 for empty and 0 for filled. Initialize all positions as empty; for a BIT over an all-ones array, tree[i] can be set to i & -i in O(N). Each reverse step finds the k-th one, writes i there, and adds -1 at that position.
- **k-th one search:** Use binary lifting on the BIT. Start idx=0 and step as the largest power of two not exceeding N. For each step, candidate nxt=idx+step; if nxt is within N and tree[nxt] < k, move idx to nxt and subtract tree[nxt] from k. The target zero-based index is idx, so answer[idx]=i and the BIT update starts at idx+1.
- **Input and output:** Read all integers at once with sys.stdin.buffer.read().split() and map to int. Keep the whole list vals so P_i is vals[i] without creating a separate P slice. Use local variable aliases for the BIT, answer, vals, and N inside the loop. Join the answer list for output.
- **Complexity:** Each of N reverse steps does one O(log N) k-th search and one O(log N) BIT update, so total time is O(N log N) and memory is O(N), suitable for N=500000.
- **Pitfalls:** P_i is 1-indexed; the BIT is 1-indexed, while the answer array is 0-indexed. The binary-lifting step must be the largest power of two <= N, and the candidate index must be checked against N unless the tree is padded to a power of two. P_i is always valid because exactly i positions are empty at reverse step i. Avoid direct forward insertion because shifting a Python list is O(N) per operation.
- **Alternatives:** An implicit treap or rope can simulate forward insertions in O(N log N) expected time, but it has larger constants and more implementation risk in Python. Sqrt decomposition or block popcount structures can also support select/remove, but a Fenwick tree is simpler and fast enough.
