- **Core reduction:** Every point lies on the square boundary, so map it to a clockwise perimeter coordinate on a circle of circumference P = 4*side. For any d <= side, Manhattan distance >= d is equivalent to circular distance >= d. Circular distance is always >= Manhattan distance; if Manhattan distance < d <= side, the two points cannot be on opposite edges, so they are on the same or adjacent edges and circular distance equals Manhattan distance.
- **Upper bound:** Choosing k points creates k clockwise gaps summing to P. The minimum pairwise circular distance is the minimum gap, so it is at most floor(P/k). Since k >= 4, floor(P/k) <= side, so binary search on d never exits the valid reduction range. Set hi = P // k.
- **Perimeter mapping:** Bottom (x,0) -> x; right (side,y) -> side + y; top (x,side) -> 3*side - x; left (0,y) -> 4*side - y, checked in that order so corners get consistent values 0, side, 2*side, 3*side. Sort the resulting t values.
- **Feasibility check for d:** Build doubled array t2 = t + [v + P]. Using two pointers, build nxt[i] = first j > i with t2[j] >= t2[i] + d, or 2n if none. For every start i in [0, n), greedily take k-1 jumps. Accept if the final index is valid and t2[cur] - t2[i] <= P - d, which means the wrap-around gap is also at least d.
- **Why all starts suffice:** If a valid selection exists, choose any selected point as the start. Greedy earliest choices are never later than the corresponding points of that valid selection, so the final wrap gap remains >= d. Conversely, any accepted start directly yields k points with all consecutive and wrap gaps >= d.
- **Complexity:** O(n log n + log(P/k) * (n + n*k)) time and O(n) memory. With n <= 15000 and k <= 25, the inner work is about 10-12 million jumps in the worst case.
- **Implementation pitfalls:** Handle d = 0 separately. In the two-pointer build, enforce j > i by setting j = i + 1 when needed. Use <= for the wrap check, not <. The upper bound P//k is essential: searching above side would break the Manhattan/perimeter equivalence.
- **Sample tests verdict:** The implementation returns 2, 1, and 1 for the three provided examples, matching the expected outputs.
