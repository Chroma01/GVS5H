- **Core idea:** Count all monotone paths in the full rectangle, then subtract invalid paths. Invalid paths either start inside the forbidden rectangle F, or start outside and first enter F.
- **Full rectangle endpoint count:** For a point (x,y), the number of monotone paths ending there from any start in the full rectangle is f(x,y)=C(x+y+2,x+1)-1. Define P(X,Y)=sum_{a=0..X} sum_{b=0..Y} C(a+b+2,a+1). Hockey-stick gives P(X,Y)=C(X+Y+4,X+2)-X-Y-4 for X,Y>=0, and P=0 if either index is negative. Total full paths = P(W,H)-(W+1)(H+1).
- **Starts inside F:** Paths starting at (x,y) to any end equal g(x,y)=C(W-x+H-y+2,W-x+1)-1. With a=W-x and b=H-y, the sum over F is the rectangle sum of C(a+b+2,a+1) for a in [W-R,W-L] and b in [H-U,H-D], obtained by inclusion-exclusion from P, minus the area of F.
- **First entry from outside:** For an invalid path starting outside, let p be its first forbidden point. The previous point q is either (L-1,y) on the left side or (x,D-1) on the bottom side. Prefixes to q are unrestricted because q.x<L or q.y<D, so they are counted by f(q). Suffixes from p are unrestricted in the full rectangle, counted by g(p). Add sum_{y=D..U} f(L-1,y)g(L,y) if L>0, and sum_{x=L..R} f(x,D-1)g(x,D) if D>0. The corner (L,D) appears in both sums but corresponds to different last steps, so it is not double counted. If L=0 or D=0, the corresponding side is absent.
- **Boundary evaluation:** The two boundary sums have lengths at most H+1 and W+1, so scan them linearly. Precompute factorials and inverse factorials up to W+H+4. Since W+H+4<MOD, ordinary binomials modulo MOD are O(1). In the scans, use symmetric binomial forms with constant inverse-factorial factors and update n and complementary indices by +/-1.
- **Answer:** total - inside - left - bottom modulo 998244353.
- **Edge cases:** The formulas handle forbidden rectangles touching borders, zero width or height, and single allowed points. Negative indices in P are treated as zero. Complexity is O(W+H) time and O(W+H) memory.
