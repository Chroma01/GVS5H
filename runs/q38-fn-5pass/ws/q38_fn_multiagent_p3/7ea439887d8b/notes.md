- **Core model:** The only relevant history is the parity of the number of global reversals. Use states `(vertex, parity)`, where `parity = 0` means original directions are active and `parity = 1` means all edges are reversed. There are `2N` states.
- **Transitions:** For each original edge `u -> v`: in parity 0, `(u, 0) -> (v, 0)` costs 1; in parity 1, the reversed graph has `v -> u`, so `(v, 1) -> (u, 1)` costs 1. At every vertex, toggling orientation costs `X`: `(v, 0) <-> (v, 1)`.
- **Algorithm:** Run Dijkstra from `(1, 0)` because all operation costs are positive. The answer is the minimum distance to `(N, 0)` and `(N, 1)`. Early exit is valid when any state with vertex `N` is popped, since Dijkstra pops states in nondecreasing distance order.
- **Implementation details:** Use 0-indexed vertices and a flat state index `2 * vertex + parity`. Store original adjacency `adj` and incoming adjacency `radj`; `radj[v]` contains original predecessors `u` for edges `u -> v`, which are exactly the moves available from `(v, 1)`. Distances are Python integers, and `INF = 10**30` is safely above the maximum possible answer.
- **Complexity:** Building adjacency takes `O(N + M)`. Dijkstra performs `O(N + M)` relaxations and heap operations, giving `O((N + M) log N)` time and `O(N + M)` memory.
- **Pitfalls:** The final parity may be either 0 or 1, so both target states must be considered. In the reversed layer, use incoming edges of the original graph, not outgoing edges. Plain BFS is only correct when `X = 1`; otherwise use Dijkstra. The answer can exceed 32-bit range. Avoid explicitly constructing the expanded graph; generate transitions implicitly. Duplicate edges and self-loops are harmless.
