Use prefix sums to express each subarray cost in O(1), then formulate a dynamic program over the number of subarrays and the prefix length. For a fixed number of subarrays, the transition can be rewritten as a line-query problem, so optimize it with a convex hull trick or Li Chao tree to avoid the naive cubic DP. Keep only the previous DP layer to save memory, and take the minimum over all valid numbers of subarrays for the final answer.
