Deleting a value `x` removes every occurrence of `x` and concatenates the remaining contiguous blocks of elements that are not equal to `x`. Therefore, for each possible `x`, the best subarray after deletion is the maximum subarray sum of the concatenation of those non-`x` blocks. Build a segment tree that can return, for any non-empty interval, its total sum, best prefix sum, best suffix sum, and best subarray sum. For each distinct value, query the gaps between consecutive occurrences of that value, merge the gap statistics in order, and update the answer if the resulting array is non-empty. Initialize the answer with the original maximum subarray sum to cover the case of performing no deletion.
