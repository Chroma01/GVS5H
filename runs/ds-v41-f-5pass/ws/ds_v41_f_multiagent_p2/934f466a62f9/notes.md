- **Environment:** no code execution available in this sandbox, so the randomized sweep could not literally be run. Validation is by full proof plus hand-evaluated cases; every hand case matched a direct brute force. Residual risk: none identified.
- **Reduction:** answer = maximum value of a colouring of exactly M=2K cakes in which all three colour-counts are even. Tagging each pair by a winning coordinate (both cakes get it) yields an even colouring of the same value; an even colouring pairs up cakes inside each colour with pair price >= assigned sum. Exact in both directions.
- **Parity:** colour -> bit 1<<c; all counts even iff XOR of bits is 0. Because M is even, the best-colour parity p of any M-set has even Hamming weight, so p in {0,3,5,6}.
- **Base set / bound:** sort by m_i=max(X,Y,Z); T = top M, U = sum m_i. Every configuration has value <= U.
- **Repair formula:** if p=0 the answer is U; else let q,r be the other two even-weight vectors and set answer = U - min(g_p, min_compat_qr).
- **Moves:** recolour T item i from colour c to b: vector E_c+E_b, cost m_i-v_i[b] >= 0. Replace: remove T item i, add non-T item j coloured d: vector E_{c_i}+E_d, cost m_i-v_j[d] >= 0 (since m_i >= m_j >= v_j[d]). All move vectors lie in {0,p,q,r}; the XOR of all move vectors must equal p.
- **Exactness:** any configuration decomposes into pairwise-disjoint moves with total XOR p; the set of vectors with odd multiplicity is {p} or {q,r}; all costs are non-negative, so loss >= min(g_p, min_compat). Applying the single best p-move, or the best disjoint q-move plus r-move, realises that loss as a valid even colouring of size M. Computed answer can neither exceed nor fall below the true optimum.
- **Truncation safety:** each move uses at most one T item and at most one non-T item, so its partner blocks at most one entry per bucket. Keeping the top 4 per bucket leaves >=3 free entries, so an optimal disjoint pair can be replaced entry-by-entry without increasing cost. The two factors of a replace cost (m_i and v_j[d]) are independent, so the best combo is always reachable.
- **gp is exact:** for a p-replace, cands contains the min over TL[a] x NH[b] = (min m_i) - (max v_j[d]); for a p-recolour, RECl top-4 contains the minimum. No truncation loss for g_p.
- **minc always defined when p!=0:** p=E_a+E_b means colours a,b occur an odd (hence >=1) number of times in T, so recolour a->c and b->c are disjoint candidates for the two other vectors. The same construction covers M=N (no non-T items).
- **Hand-verified:** official samples (12, 209, 333); (6,3,8)/(3,5,0)/(2,7,3)=12; two-replacement N=6,K=2 case =38; tie case =40; M=N=4 case =25; N=4,K=1 case =8; N=2 mixed colours =10. Every value matched direct enumeration.
- **Complexity:** O(N log N) per test (one sort) plus O(1) candidate work (<=40 candidates per vector, <=1600 pairs). Sum N <= 1e5, so comfortably within limits; pure CPython safe.
- **Discarded:** the earlier Lagrangian / Aliens (penalty) formulation with BIG / doubling / tie-break machinery, the naive "top-2K plus one recolor" formula, and the S==0 special case; all superseded by the closed-form repair above.
