Model each row as a W-bit mask. Since row and column flips commute and are involutions, choose a column-flip mask c; then each row can be optionally flipped, contributing min(popcount(row xor c), W - popcount(row xor c)) ones. Count frequencies of all row masks, then compute the sum over all masks for every possible c as an XOR convolution with a kernel depending only on Hamming distance. Use a Fast Walsh-Hadamard Transform over size 2^W to evaluate all column masks efficiently, and take the minimum resulting total.
