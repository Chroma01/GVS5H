A connected alkane subgraph has a unique highest vertex; at that vertex the parent edge is absent, so it must choose either 1 or 4 child edges, while any non-highest vertex with a parent edge present must choose either 0 or 3 child edges to make its subgraph degree 1 or 4. For each vertex, compute the best size of a connected valid-degree subgraph inside its subtree that includes the vertex, separately for parent-edge absent/present and for whether a degree-4 vertex has appeared. Combine child branches by selecting a small number (0..4) of child edges and maximizing total vertices while tracking the degree-4 flag. The answer is the best parent-edge-absent state with the flag true over all vertices, or -1 if none.
