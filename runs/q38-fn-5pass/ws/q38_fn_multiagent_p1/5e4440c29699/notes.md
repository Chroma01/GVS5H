- **Core decomposition:** The allowed town is the full rectangle `[0..W] x [0..H]` minus the inclusive forbidden rectangle `[L..R] x [D..U]`. Count all monotone paths with allowed start/end in the full grid, then subtract paths that visit the forbidden rectangle.
- **Full rectangle helper:** For fixed endpoint `(a,b)`, the number of monotone paths from any start in `[0..a] x [0..b]` is `paths_to(a,b) = C(a+b+2, a+1) - 1`.
- **Total full-grid paths:** Summing `paths_to(i,j)` over all endpoints gives `total_paths(w,h) = C(w+h+4, w+2) - w - h - 4 - (w+1)(h+1)`. This same function is also the 2D prefix sum of `paths_to`.
- **Allowed endpoints:** Use inclusion-exclusion over start/end inside the forbidden rectangle: `allowed = total(W,H) - start_bad - end_bad + both_bad`. `start_bad` is a rectangle sum of `paths_to(W-x,H-y)` over forbidden starts; `end_bad` is a rectangle sum of `paths_to(x,y)` over forbidden ends; `both_bad = total_paths(R-L, U-D)`.
- **Invalid paths by first entry:** A path that first enters the forbidden rectangle can enter only from the left side `(L-1,y) -> (L,y)` or bottom side `(x,D-1) -> (x,D)`. The corner is intentionally counted in both sums because the last step direction distinguishes disjoint path sets.
- **Left-side contribution:** For `L > 0`, sum over `y=D..U` of `paths_to(L-1,y) * (paths_to(W-L,H-y) - paths_to(R-L,U-y))`. The second factor counts suffixes from the first forbidden point to any allowed endpoint.
- **Bottom-side contribution:** For `D > 0`, sum over `x=L..R` of `paths_to(x,D-1) * (paths_to(W-x,H-D) - paths_to(R-x,U-D))`.
- **Efficient boundary sums:** Precompute factorials and inverse factorials up to `W+H+5`. Compute closed-form endpoint counts and initial boundary binomials. Then evaluate the two boundary sums in `O((U-D)+(R-L))` using binomial recurrences.
- **Inverse table trick:** After all `C(n,k)` calls are done, convert the factorial list in-place into a shifted modular inverse table: `inv[i-1] = i^{-1}` via `fact[i-1] * invfact[i] % MOD`. This avoids a third large list and avoids per-step `pow`.
- **Recurrences used:** Left side maintains `C(L+y+1,L)`, `C(W-L+H-y+2,W-L+1)`, `C(R-L+U-y+2,R-L+1)`. Bottom side maintains `C(x+D+1,x+1)`, `C(W-x+H-D+2,W-x+1)`, `C(R-x+U-D+2,R-x+1)`. Updates use fixed lower or decreasing top/bottom identities.
- **Edge cases:** If `L=0` or `D=0`, the corresponding first-entry side is absent. Zero width/height forbidden rectangles are handled naturally. If a forbidden entry point has no allowed reachable endpoint, its suffix factor becomes zero. Negative rectangle ranges in prefix sums return zero.
- **Complexity:** Time `O(W+H)`, memory `O(W+H)` modulo `998244353`.
