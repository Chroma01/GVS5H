- **Problem model:** A valid coloring is exactly a nonincreasing sequence L_1 >= L_2 >= ... >= L_N with 0 <= L_r <= N, where row r has its leftmost L_r cells black. Column condition is automatic from monotonicity, so row and column views are conjugates of one another.
- **Marked cells as bounds:** A black cell (r,c) requires L_r >= c. A white cell (r,c) requires L_r <= c-1. Multiple marks in a row combine to a lower bound (max black col) and upper bound (min white col minus 1).
- **Dominance characterization:** The configuration is satisfiable iff there is NO pair with a black cell (r,c) and a white cell (r',c') satisfying r' <= r and c' <= c. Proof of necessity: L_r >= c and monotonicity give L_{r'} >= c for r' <= r, but the white forces L_{r'} <= c'-1 < c when c' <= c, a contradiction. Proof of sufficiency: take L_r = max{ c : black at (r'',c), r'' >= r } (0 if none); this is nonincreasing, covers all black cells, and any white (r',c') is uncovered because no black below-right of it has col >= c'.
- **Geometric view:** Each black cell forces its top-left rectangle [1..r] x [1..c] to be black; each white cell forces its bottom-right rectangle [r'..N] x [c'..N] to be white. These overlap iff r' <= r and c' <= c. If no overlap, the union of the black-forced rectangles is itself a valid Ferrers shape that avoids all white cells, so it witnesses a solution.
- **Algorithm:** Sort the M points by (row, type, col) with white before black in the same row (type 0 = white, 1 = black) so that r' <= r includes equal rows. Sweep keeping the minimum column among whites seen. For each black (r,c), if the running minimum white column <= c, print No; else Yes at the end. O(M log M) time, O(M) memory, independent of N up to 1e9.
- **Same-row handling:** Whites must be processed before blacks within one row, otherwise a white and black in the same row (where r'=r so r' <= r holds) could be missed or falsely pass. The sort key (row, type) guarantees this ordering.
- **Reading input:** Compare the color token against bytes b'B' / b'W' since stdin is read as bytes via split(); avoids decode.
- **Validation:** Sample 1 -> Yes, sample 2 -> No (white (1,2) dominates black (2,2)), sample 3 -> Yes, sample 4 -> No. N=1 cases: single black or single white both give Yes, matching expectations.
- **Edge cases:** No whites for a given black -> never fails. No blacks -> always Yes. M can equal 1 (just one mark) -> Yes. Duplicate cells disallowed by constraints so no tie-breaking issues beyond color.
