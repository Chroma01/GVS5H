This is a minimization problem over the longest run length after at most numOps flips, so binary search on the answer length L is the natural approach. For a fixed L, determine the minimum flips needed to ensure no run of identical characters exceeds L in either original string or its complement, since the final string can be seen as matching one of two alternating patterns or being partitioned greedily. Compare the computed required flips against numOps to decide feasibility. Then binary search the smallest feasible L from 1 to n. The solution should run comfortably within n <= 1000.
