Treat the required values as a deterministic phase sequence: a segment may begin only at a 1, after which values must alternate 2,0,2,0 along a diagonal. Compute, for every cell and diagonal direction, the longest valid straight continuation for the two post-start phases (2 and 0), and also the longest valid segment that starts at a 1 and ends at the cell from each direction. Then evaluate every possible turn cell by combining the best incoming straight length with the outgoing straight length in the clockwise diagonal direction, subtracting the shared turn cell. Also keep the best no-turn straight length, and return 0 only if no 1 exists. This yields O(nm) time and linear grid-sized memory if directional arrays are reused or stored compactly.
