Count all monotone paths whose start and end are blocks while ignoring the forbidden rectangle, then subtract exactly the paths that enter the forbidden rectangle. Full-grid path counts and rectangle sums can be evaluated with hockey-stick identities using precomputed factorials modulo 998244353. A path that enters the forbidden rectangle has a unique first entry on its bottom or left side, so invalid paths can be counted by summing prefixes to the adjacent outside point times continuations from the entry point to allowed endpoints. The remaining boundary sums are O(W+H), which is feasible for the constraints.
