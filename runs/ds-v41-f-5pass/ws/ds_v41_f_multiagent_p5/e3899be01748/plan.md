Reduce the divisibility condition for a substring ending in digit d>0 using value = 10Q + d, where Q is the prefix before the last digit; this requires (d/gcd(10,d)) | Q. Since d is only 1 through 9, the needed moduli are limited to {1,2,3,4,7,9}. For each such modulus m, compute how many suffixes ending at every position are divisible by m using a rolling remainder-count DP over suffixes. Then for each nonzero digit position, add one for the single-digit substring plus the precomputed count of valid Q suffixes ending just before it. This yields an O(n * sum of moduli) solution, comfortably within 10^5.
