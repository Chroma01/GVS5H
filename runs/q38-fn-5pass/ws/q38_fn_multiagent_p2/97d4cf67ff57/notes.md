- **State:** dp[u] is the best contribution from the subtree of u when the edge from u to its parent is selected. It either uses u as a leaf of size 1, or makes u have selected degree 4 by attaching three child-side branches. If u has fewer than three children, only the leaf contribution is possible.
- **Recurrence:** For each child v, dp[v] already represents the best leaf or valid degree-4 branch on that side. The choices are independent and additive, so if u has at least three children, dp[u] = 1 + sum of the three largest dp[v]; otherwise dp[u] = 1.
- **Final answer:** Any alkane has a unique vertex closest to the root. If that top vertex has degree 4, it combines four child contributions, giving 1 + sum of the four largest child dp values. If it has degree 1, it combines one child contribution, and that contribution must be a real degree-4 branch, so the largest child dp value must be greater than 1. The maximum over all vertices is the answer; if no candidate exists, output -1.
- **Correctness:** For a fixed highest vertex, the selected branches lie in disjoint child subtrees, so maximizing each branch independently is optimal. The recurrence constructs exactly the allowed branch shapes: a branch attached to a parent either stops at a leaf or has a degree-4 root with three such branches. The final candidates construct valid alkanes because the top vertex has degree 4 or 1 and every child contribution is either a leaf or a valid branch containing a degree-4 vertex.
- **Implementation:** Build adjacency lists, root at 0, and obtain parent and preorder iteratively with a stack. Process reversed preorder as postorder. For each node, maintain the four largest child dp values in four variables while scanning neighbors, avoiding sorting. Total time is linear and memory is linear.
- **Edge cases:** A single vertex or any tree without a possible degree-4 structure leaves ans as -1. The root's dp value is not used as a branch because the root has no parent, but the root is still evaluated as a possible top vertex. dp value 1 means leaf contribution; any value greater than 1 means a valid branch. Equal child values are handled correctly by the top-four update starting from zeros.
