- **Problem model:** Shortest path from i to j whose edge-label string is a palindrome. Empty path allowed, so dist[i][i]=0. Single edge u->v is a palindrome of length 1.
- **State definition:** A pair (u,v) represents the inner subpath remaining after stripping matched outer characters. dist[u][v] is the shortest palindromic path length from u to v.
- **Transitions:** From (u,v) with distance d, pick a letter c. For every predecessor x of u with edge x->u labeled c, and every successor y of v with edge v->y labeled c, we get a palindrome from x to y of length d+2: x->u + (palindrome u->v) + v->y. Update dist[x][y] = d+2.
- **Base cases:** (i,i) distance 0; direct edge u->v distance 1.
- **BFS order:** All edge weights in the state graph are +2. Initialize a FIFO queue with all 0-distance states first, then all 1-distance states. Since all generated states get d+2, the queue remains nondecreasing in distance. First assignment to a state is the shortest.
- **Bitset acceleration:** Precompute pred[c][u] = bitmask of x with edge x->u labeled c; succ[c][v] = bitmask of y with edge v->y labeled c. For popped (u,v), for each c, let sm=succ[c][v], pm=pred[c][u]. If both nonempty, iterate x bits in pm. Compute new = sm & ~row_mask[x]; iterate y bits in new to assign dist[x][y]=d+2 and update row_mask[x].
- **Complexity:** Iterating x across all popped states costs at most sum over states of indeg(u) <= N*E <= N^3 = 1e6 for N=100. Iterating y bits total at most N^2 because each state is discovered once. 26 loops per state add a small constant. Very fast in Python.
- **Pitfalls:** Do not restrict to simple paths; revisits are allowed. Diagonal answers are always 0 (even if self-loop exists). Direct edge answers are 1. Use row_mask to avoid adding a state twice. Ensure queue order puts all 0-distance states before 1-distance states. Output -1 for INF.
- **Correctness:** Every palindromic path of length >=2 has matching outer edges, so it can be reduced to a shorter palindromic inner path. The BFS explores all such reductions in increasing length order, hence finds the shortest.
