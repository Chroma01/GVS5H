- **Model:** Classify each i. Moff = (A=1,B=0), flipped 1->0 once. Mon = (A=0,B=1), flipped 0->1 once. Opt = (A=1,B=1), either untouched or flipped off then later on (2 flips). Ignore = (A=0,B=0), never flip. Because every C>0, more flips of any index never reduce total weight, so these minimal counts are optimal.
- **Normalization:** Using total = sum over operations of weight-after, algebra gives total = T*S0 + sum_j (T-j+1)*delta_j, delta=+C for on, -C for off. An adjacent on/off swap reduces total by (C_on+C_off)>0, so all off events precede all on events. Rearrangement: off block sorted by decreasing C, on block by increasing C. S0 = sum of C over A=1 (Moff and all Opt).
- **Per-index form:** total = sum_k C_k * t_k where t_k = #ops after which k is 1. For chosen subsets this yields the delta formula; verified hand-matched on multiple cases.
- **Base cost (x=0):** K0 = pair_min(Moff) + pair_min(Mon) + sum(Mon) + SO*a, a=m+n, SO=sum(Opt). pair_min(list) sorts ascending and sums lst[i]*(len-1-i) = sum over pairs of the smaller value; it equals the descending-order identity sum_i D_i*(i-1) used for the off block.
- **Opt choice:** For a fixed number x of Opts to flip, choosing the x largest C is optimal (turning off a bigger weight saves more; exchange argument). So only prefixes of Opts sorted descending matter; take the min over x=0..|Opt| via an incremental sweep.
- **Mandatory helper:** mandatory = sorted(Moff+Mon). g(v) = pref[bisect_right(mandatory,v)] + v*(a - that count) = sum over mandatory of min(mand, v). beta(v) = g(v) + 2*SO - (a+1)*v.
- **Incremental step:** sweep Opts in descending value; cur starts at K0. For next (v,beta): cur += beta - 2*chosen_sum; chosen_sum += v; best=min(best,cur). chosen_sum is the sum of already-added (larger) Opts. This reproduces cost of choosing the x largest.
- **Verification:** All three samples reproduced: 16, 0, 2867. Sample 3 computed by hand through the full pipeline (K0=3300, betas -92/-47/128 -> cur 3208,3017,2867). Also cross-checked by full brute-force enumeration of orderings on ~6 small custom cases (mixes of Moff/Mon/Opt, ties, empty mandatory); all matched exactly.
- **Ties/edge cases:** ties in C across categories are fine; bisect_right counts mandatory equal to v, and tie order among equal options does not change cost. Empty mandatory -> g=0. Empty Opt -> answer K0. All A=B=1 (a=0) -> K0=0, base stays best. Use Python big ints; sums fit easily but no overflow concerns.
- **Complexity:** O(N log N) for sorts + O(|Opt| log a) bisects; O(N) memory. Fits N<=2e5.
