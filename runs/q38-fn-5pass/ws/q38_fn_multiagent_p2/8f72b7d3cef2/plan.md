Takahashi's final interval is the unique minimal stable interval containing K, where an interval [l,r] is stable if the adjacent outside slimes (or sentinels) have size at least the interval sum. With prefix sums P, set C_j=A_j-P_{j-1} and C_{N+1}=∞; for a left boundary i=l-1, let R_i be the largest r with P_r-P_i≤A_i. For each i, find the rightmost j in [i+2,R_i+1] with C_j≥-P_i; then i can serve exactly K∈[i+1,min(R_i,j-1)]. Sweep K over these intervals to obtain the maximum possible left boundary x, then query the first j>K with C_j≥-P_x and output P_{j-1}-P_x. All range queries can be done offline with Fenwick trees or a segment tree in O(N log N).
