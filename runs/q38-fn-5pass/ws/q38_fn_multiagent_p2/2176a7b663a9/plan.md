The graph is the disjointness graph of intervals, so edges exist exactly when one interval lies completely to the left of the other. Because all vertex weights are positive, any shortest weighted path can be made induced by shortcutting chords, and an interval-disjointness graph has no induced path on five vertices; hence it suffices to consider paths of at most three edges. If the queried intervals are disjoint, the direct edge is always optimal. If they overlap, a two-edge path uses a vertex completely left of both intervals or completely right of both, while the only three-edge path that can improve on this uses a vertex right of the endpoint with smaller L and a vertex left of the endpoint with larger L. Precompute prefix minima by right endpoint and suffix minima by left endpoint, then evaluate these constant candidates for each query.
