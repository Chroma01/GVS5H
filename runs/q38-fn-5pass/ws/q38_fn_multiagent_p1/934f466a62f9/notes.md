- **Reduction:** A pair priced by max of three attribute sums can be represented by assigning both cakes of the pair the attribute attaining that maximum. Thus the problem is equivalent to choosing exactly 2K cakes, coloring each chosen cake with one of three colors, maximizing the sum of chosen color values, and requiring every color count to be even. Even color counts are sufficient because cakes of the same color can be paired arbitrarily, and the pair price is at least the assigned color sum.
- **Unconstrained upper bound:** For each cake let M_i = max(X_i,Y_i,Z_i). Any feasible solution has value at most the sum of the largest 2K values of M_i. Take those cakes as a base set B and assign each an arbitrary maximum color. Let U be the sum of M_i over B and let mask be the parity mask of base colors. If mask is zero, U is attainable and optimal.
- **Exchange proof:** Compare any feasible solution with the base configuration. Kept recolored cakes give recolor operations; removed base cakes paired with added outside cakes give swap operations. Each operation has nonnegative loss and toggles two colors. The total parity change of all operations is the base defect mask. Since the defect has weight two and the three non-zero two-color changes form a 2-dimensional GF(2) set, some subset of at most two operations already has the defect parity and loss no larger than the whole repair. Therefore an optimal repair needs only one operation of the defect change, or one operation of each of the other two changes.
- **Operation losses:** A recolor of selected cake i from base color a to target b has loss M_i - v_i[b]. A swap removing selected cake i of base color a and adding unselected cake j with target color b has loss M_i - v_j[b]. Nonnegativity follows because every selected M_i is at least every unselected M_j, and v_j[b] <= M_j.
- **Candidate sufficiency:** For a single operation, the best operation of each directed type is enough. For two operations, each operation uses at most one selected cake and at most one added cake, so conflicts involve at most one selected cake and at most one added cake. Keeping the top 5 selected cakes by smallest M for each base color, top 5 selected cakes by smallest recolor loss for each ordered color pair, and top 5 unselected cakes by largest value for each target color is more than enough to replace any needed operation while avoiding the other operation's resources. TOP=5 is deliberately larger than the theoretical minimum of 2.
- **Compatibility:** When combining two operations, they must use distinct selected cakes. If both are swaps, they must also use distinct added cakes. Recolors have added id -1 and do not conflict on added cakes.
- **Search:** Generate all candidate recolor and swap operations, deduplicate by (change, selected, added), and group by change mask. Check all single operations with the defect change, then all compatible pairs between the two other change groups. The answer is U minus the minimum loss.
- **Ties and zero loss:** Ties in M_i at the selection boundary and ties among maximum attributes are handled by the exchange proof. Arbitrary base colors among tied maxima are safe because zero-loss recolors are included in the candidate lists.
- **Edge cases:** If N = 2K, there are no unselected cakes, so only recolors are generated. If a needed color is absent from a candidate list, the corresponding operation is simply unavailable. The defect mask is always either zero or one of 3, 5, 6 because 2K is even.
- **Complexity:** Sorting by M dominates, O(N log N) per test case and O(sum N log N) overall. Candidate generation and pair checks are bounded by a small constant per test case (at most a few hundred operations and a few thousand pair checks).
