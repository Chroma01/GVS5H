For each integer x, define cost c(x) = floor(log_4(x)) + 1, the number of times x must be selected to become zero. For a query [l, r], let total = sum(c(x)) over all x in the range and mx = max(c(x)). Each operation can select two elements, and one element can be selected at most once per operation, so the minimum operations is max(ceil(total / 2), mx), which is achievable by pairing the largest remaining costs. Since r <= 10^9, c(x) <= 15, so we can compute total and mx by counting how many numbers in [l, r] fall into each cost bucket using powers of 4.
