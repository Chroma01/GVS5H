- **Problem restatement:** build lexicographically smallest word of length L = n+m-1 where each start i with str1[i]=='T' forces window [i, i+m-1] == str2, and 'F' forces it != str2; return "" if impossible.
- **Key insight (window completion):** window starting at i is finished exactly when character at p = i+m-1 is placed. It equals str2 iff KMP state after placing p is exactly m.
- **KMP automaton:** state = length of longest prefix of str2 that is a suffix of text so far, values 0..m. Transition `nxt[s][c]` via standard fallback (while j>0 and str2[j]!=c: j=pi[j-1]; if str2[j]==c: j++). For state m use the border: `nxt[m][c] = nxt[pi[m-1]][c]` (cannot extend past m; longest proper border is pi[m-1]). This special-casing is required and correct for repeating patterns like "aa".
- **Precomputed masks:** `full[s]` = bitmask of all states reachable from s by any char; `nonm[s]` = same but excluding state m. Chars are just 26, so masks are cheap.
- **Backward DP:** `dp[L]` = all states (no constraints remain). For p from L-1 down to 0, with i = p-(m-1) (valid iff p>=m-1): if str1[i]=='T', state s feasible iff full[s] has bit m AND dp[p+1] has bit m (only states whose char can complete a match); if 'F', feasible iff `nonm[s] & dp[p+1]` nonzero; if p<m-1 (no constraint yet) feasible iff `full[s] & dp[p+1]` nonzero.
- **Lexicographic greedy:** start state 0 at p=0; at each p try 'a'..'z', take first c whose resulting state t satisfies the local constraint ('T' => t==m, 'F' => t!=m) and has bit t set in dp[p+1]. Greedy is valid because dp feasibility of the future depends only on the KMP state.
- **Impossibility:** answer exists iff bit 0 is set in dp[0]; else return "".
- **Correctness argument:** the KMP state fully summarizes all information about the already-emitted suffix relevant to any window that has started but not yet ended; windows starting later are entirely future. Hence dp captures exactly the completable states, and greedy picks the smallest feasible char.
- **Complexity:** automaton build O(26 * m * (amortized m)) worst ~ O(26*m^2); DP O(L*m); reconstruction O(L*26). L<=10499, m<=500 -> easily within limits.
- **Edge cases verified by hand:** m=1 (border 0, states 0/1), conflicting overlapping T (e.g. "TT"/"ab" -> ""), repeated-pattern T ("TT"/"aa" -> "aaa"), F-only ("F"/"d" -> "a"), overlapping T+F example 1 -> "ababa", example 2 -> "".
- **Pitfalls avoided:** must keep state m as distinct for constraint checks but alias its transitions to the border state; must require t==m for 'T' (not just any state with a full match possible), and t!=m for 'F'.
