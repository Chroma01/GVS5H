Compute the minimum cost to make every length-x window equal by converting it to its median, using a sliding-window median structure over compressed values. This produces an array `cost[i]` for each possible window start `i`. Then solve a weighted interval selection problem: choose `k` non-overlapping windows of length `x` with minimum total cost. Since all windows have the same length, a previous chosen window ending before start `i` must have start at most `i - x`, so dynamic programming with prefix minima can compute the answer in `O(k * n)` after the costs are known.
