Reduce each query to a 2D maximum: if dp[i] is the length of the longest strictly increasing subsequence ending at position i, then the answer is max dp[i] over i<=R and A_i<=X. Compute dp[i] in one left-to-right pass using a max-Fenwick tree over compressed A values: dp[i] = 1 + max dp[j] for A_j < A_i. Process positions and queries by increasing R: before inserting A_i compute dp[i], then insert dp[i], then answer all queries with R=i. For each query, map X to the largest compressed A value <= X and take the Fenwick prefix maximum. This gives O((N+Q) log N) time.
