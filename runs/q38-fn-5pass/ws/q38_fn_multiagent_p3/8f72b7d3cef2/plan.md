Process slime sizes in increasing order while maintaining DSU components of already active slimes, i.e. slimes with sizes smaller than the current value. For an active component adjacent to a slime of current size x, x is the smallest possible outside boundary; if the component’s total size is <= x, no slime inside it can ever exceed x, so every still-unassigned position in that component has answer equal to the component sum. If the component sum is > x, the current-size slime can absorb it, so the component must be merged with the current-size slimes. For the current equal-size batch, a slime with no adjacent active component cannot absorb any smaller slime and gets answer x; otherwise it remains unassigned. Activate the whole equal-size batch, union it with neighboring active components, and finally assign the sums of all remaining components as answers.
