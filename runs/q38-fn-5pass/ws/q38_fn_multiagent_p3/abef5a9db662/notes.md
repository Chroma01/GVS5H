- **Core model:** Let `A[x]` be the current rating for initial rating `x` after processing some contests. Initially `A[x] = x` for `x = 1..500000`. Each contest adds 1 exactly to the contiguous block of `x` where `L <= A[x] <= R`, because `A` remains nondecreasing.
- **Monotonicity invariant:** If `A` is nondecreasing and we add 1 to a contiguous block `[l, r]`, monotonicity is preserved. At the right boundary, if `r < M`, then `A[r+1] > R >= A[r]`, so `A[r+1] >= A[r] + 1`; at the left boundary, `A[l-1] < L <= A[l]`, so increasing `A[l]` cannot break order.
- **Difference array:** Maintain `D[i] = A[i] - A[i-1]` with `A[0] = 0`. Since `A` is nondecreasing, all `D[i]` for `1..M` are nonnegative. A range add `[l, r]` becomes `D[l] += 1` and, if `r < M`, `D[r+1] -= 1`. The decrement is safe because `r` being the last index with `A[r] <= R` implies `D[r+1] >= 1`.
- **Fenwick lower_bound:** The Fenwick tree stores `D`. Since `D` is nonnegative, Fenwick lower_bound finds the smallest index whose prefix sum is at least a target. For a contest `[L, R]`, `l = lower_bound(L)` and `pos = lower_bound(R + 1)`. Then `r = pos - 1`. If `pos = M + 1`, all current ratings are `<= R`, so `r = M`.
- **Boundary handling:** Use inclusive bounds by searching for `R + 1`. If `l > r`, no initial rating is affected. If `r == M`, skip the decrement at `M + 1` because it is outside the maintained domain and would otherwise make the stored difference array negative.
- **Final queries:** After all contests, convert `D` into final `A` by one prefix-sum pass over `1..M`. Then each query `X` is answered in O(1) as `A[X]`. This is still a prefix-sum answer but avoids O(Q log M) point queries.
- **Complexity:** Initialization is O(M). Each contest does two lower_bounds and up to two Fenwick updates, O(log M). Finalization is O(M), queries are O(Q). With `M = 500000`, this is comfortably within limits.
- **Implementation details:** `M` is fixed at 500000. The Fenwick tree is initialized directly with `bit[i] = i & -i` because the initial difference array is all ones. The lower_bound starting step is the highest power of two not exceeding `M`. Input is read in bulk for speed.
