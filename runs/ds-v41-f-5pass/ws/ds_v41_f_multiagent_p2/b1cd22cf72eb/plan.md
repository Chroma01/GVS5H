Maximizing the number of saved tooth units is equivalent to maximizing the common sum H, since the cost is total(U+D) - N*H. For a fixed H, the final upper length at position i must lie in the interval [max(0,H-D_i), min(U_i,H)]. The remaining requirement is whether an X-Lipschitz sequence can be chosen from these intervals. This feasibility is monotone in H, so binary search the largest feasible H. Check feasibility in O(N) by propagating the reachable interval left-to-right.
