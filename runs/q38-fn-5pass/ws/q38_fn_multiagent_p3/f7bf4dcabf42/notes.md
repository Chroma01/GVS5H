- **Core idea:** Count all length-M strings T by simulating the LCS DP row between fixed S and growing T. Since N <= 10, the whole DP row can be compressed into a bitmask, giving a small deterministic automaton.
- **State representation:** For a processed prefix of T, let dp[j] = LCS(S[:j], T). The sequence dp[0..N] is nondecreasing and adjacent differences are only 0 or 1. Store bit i as dp[i+1] - dp[i]. The popcount of the mask is dp[N], the current LCS length.
- **Transition correctness:** When appending character c to T, the new LCS row satisfies new[0] = 0 and new[j] = max(new[j-1], old[j], old[j-1] + 1 if S[j-1] == c). This is the standard LCS recurrence. The implementation reconstructs old[j] from the mask and computes the next mask on the fly.
- **Automaton DP:** Start from mask 0 with count 1. For each of M characters, move counts through precomputed transitions. Each transition has a multiplicity equal to the number of lowercase letters producing that next mask. All counts are kept modulo 998244353.
- **Aggregation:** After M steps, sum counts of masks by popcount. The sum for popcount k is the number of strings whose LCS with S is exactly k.
- **Complexity:** Precomputation is O(2^N * 26 * N). DP is O(M * 2^N * D), where D <= 26 is the number of distinct next masks per state. With N <= 10 and M <= 100 this is easily fast enough.
- **Edge cases:** Repeated characters in S are handled naturally by the LCS recurrence. Invalid masks may be precomputed but are unreachable from mask 0, which is harmless. N=1 and M=1 work without special cases.
- **Implementation notes:** Input is parsed with split. Character transitions are aggregated into tuples of (next_mask, count) to reduce DP operations. Popcounts are precomputed for all masks. The final answer is printed as N+1 space-separated integers.
