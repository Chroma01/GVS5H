Compute the inversion count for k = 0 using a Fenwick tree over values 0..M-1 while scanning A from left to right. For each transition from k to k+1, only elements whose current value is M-1 wrap to 0; all other elements increase by 1 and do not change relative order. Precompute, for each original value v, the count and sum of 1-based positions where A_i = v, so the inversion-count change caused by wrapping value v can be computed in O(1) after O(N) preprocessing. Apply these updates for k = 0..M-2, store all answers, and print them. Use 64-bit integers because inversion counts can be as large as about 2e10.
