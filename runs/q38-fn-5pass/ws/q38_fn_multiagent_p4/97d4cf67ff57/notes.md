- **Reduction to internal vertices:** In any alkane tree, let K be the number of degree-4 vertices. If L is the number of degree-1 vertices, handshaking gives 4K + L = 2(K + L - 1), so L = 2K + 2 and total vertices = 3K + 2. Thus maximizing the alkane size is equivalent to maximizing K.
- **Internal set characterization:** The degree-4 vertices of an alkane form a connected set S. Each vertex in S must have original degree at least 4, and its number of neighbors inside S is at most 4. Conversely, any connected set S of original-degree-at-least-4 vertices with induced degree at most 4 can be extended to an alkane: for each u in S, attach 4 - deg_S(u) unused neighbors as leaves. Because the original graph is a tree, these outside neighbors are distinct for different internal vertices and no extra edges appear among selected leaves.
- **DP state:** Root the tree arbitrarily. For an eligible vertex u, down[u] is the maximum size of a connected eligible subset in u's rooted subtree that contains u, assuming the edge to u's parent is selected. Then u may include at most 3 child branches, so down[u] = 1 + sum of the largest three down[v] over eligible children v.
- **Complete internal set:** If the highest vertex of the internal set is u, the parent edge is not selected, so u may include up to 4 child branches. best[u] = 1 + sum of the largest four down[v] over eligible children v. The maximum K is max best[u] over eligible u.
- **Ineligible vertices:** They cannot be internal vertices, but they can always be used as leaves. They are ignored in the DP except that they break connectivity between eligible components.
- **Implementation details:** Use iterative DFS to build parent and preorder, then process reversed order for postorder. Maintain only the top four child down values with scalar variables to avoid sorting. Complexity is O(N) time and O(N) memory.
- **Edge cases:** If no vertex has original degree at least 4, output -1. A single eligible vertex gives K = 1 and answer 5. Eligible vertices separated by ineligible vertices cannot be connected internally.
