Handle `K = 1` as trivially `Yes`. For `K > 1`, root the tree arbitrarily and compute every subtree size modulo `K`. An edge to a child is forced to be used in the decomposition exactly when that child's subtree size is nonzero modulo `K`, because otherwise that subtree could not be partitioned into whole `K`-vertex paths. Count for each vertex how many forced edges are incident to it: the parent edge if its own residue is nonzero, plus child edges with nonzero residue. If any vertex has more than two forced incident edges, answer `No`; otherwise answer `Yes`, because the forced edges then form disjoint paths and the modulo residues force each such path to contain exactly `K` vertices.
