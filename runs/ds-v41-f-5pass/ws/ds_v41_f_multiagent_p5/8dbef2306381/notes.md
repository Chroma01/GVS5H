- **Problem shape:** 1-D reachability with jumps in [A,B] (B<=20) over N up to 1e12; bad squares are a union of M sorted disjoint intervals. Start 1 (always good), target N (always good since R_i<N).
- **Impassable wall:** If any bad interval has length R-L+1 >= B, answer is immediately No. Any jump from p<=L-1 lands at p+k <= L-1+B <= R, so the wall cannot be crossed (multiple jumps cannot help because the intermediate landing is always inside [L,R]). This check runs O(M).
- **Sliding B-bit mask DP:** After processing position p, bit k of `mask` = reachability of square p-k. Transition for the next position: new bit0 = 1 iff (mask & RMASK) != 0, where RMASK = bits A-1..B-1 (= full ^ ((1<<(A-1))-1)); then shift left by 1, mask off to B bits. Bad square => new bit0 = 0. Window width B suffices because positions more than B-1 behind cannot reach any future square.
- **Initialization:** mask = 1 (square 1 reachable; bits for positions <=0 stay 0).
- **Good run transform T:** A<B: T(mask)=((mask<<1)|b)&full with b=1 if mask&RMASK. A==B: only bit A-1 matters, so b = old bit B-1 and T is exactly a cyclic left rotation of the B bits; T^len = rotate by len%B.
- **Convergence shortcut (A<B):** full is the only nonzero fixed point, and any nonzero mask reaches full. Proof: from a reachable q inside the current good run, all q+d with d >= A^2-A are reachable (Frobenius for steps A,A+1 since A+1<=B). The first reachable run position q0 = p0+step (step in [A,B], p0 <= L-1 before the preceding wall) has offset k0 <= B-2 from the run start (<=B-1 for the first run). Window [current-B+1, current] becomes full once current >= q0 + A^2-A + B-1, giving at most ~A^2-A+2B-1 steps. C = A^2+2B+10 is a safe cap. If length<=C simulate exactly; if length>C the result is full (or 0 if the run is unreachable).
- **Safety detail:** inside the capped loop, return early on mask==full OR mask==0. If a run is unreachable the mask shifts to 0 within B steps, so we must not blindly return full. Blindly returning full when length>C would be wrong otherwise.
- **Processing order:** advance first good run (length L0-2, squares 2..L0-1), then for each interval i: shift mask by block length (bad squares), then advance the next good run (length L_{i+1}-1-R_i, or N-R_last for the final one, squares R_i+1..). Bad shift by bl = (mask<<bl)&full; if mask becomes 0 the answer is No (nothing in window can propagate).
- **Adjacent intervals:** given R_i < L_{i+1}, gaps can be 0; two adjacent blocks combine naturally (good run length 0, consecutive shifts) and a combined length >= B yields mask 0 => No, even though the upfront check only inspects single intervals.
- **Answer:** Yes iff final mask & 1 (bit0 = reachability of N).
- **Edge cases verified:** M=0 (single run of length N-1); A==B==1 (only step 1, any block kills it); A==B rotation samples (N=2,3); B>N (shortcut never fires since length<=N-1<B<C); small steps A=1 (RMASK=full, fills in B-1 steps). Samples: 1->Yes, 2->No (len 21>=B=8), 3->Yes.
- **Complexity:** O(M * C) <= ~8.5e6 elementary bit ops, plus O(M) input; memory O(M).
