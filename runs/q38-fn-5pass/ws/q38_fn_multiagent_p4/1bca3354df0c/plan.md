For even \(N\), first remove the pass counter and analyze the merge-only game on complete bipartite components: a merge creating \(w\) new missing edges is an SG move to \(g(\text{new})\oplus(w\bmod 2)\), and the full SG value is \(g\oplus(K\bmod 2)\). In this reduced game only four component types matter (isolated odd, non-isolated odd, even-even, even-odd), and its SG value depends only on small residues of their counts. Derive/prove this finite lookup table, then output Aoki iff the final SG value is nonzero.
