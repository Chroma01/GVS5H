- **Core reduction:** For a fixed subarray, let S be its set of distinct values. One operation can erase any value interval [l,r] completely contained in the current S. Thus the minimum number of operations equals the number of maximal contiguous runs of S. A run is identified by its minimum value x, so f(L,R) = number of x such that x is present in the subarray and x-1 is absent.
- **Answer transformation:** Therefore the total answer is sum over x of the number of subarrays [L,R] containing at least one x and containing no x-1. For x=1, value 0 is treated as always absent.
- **First-occurrence counting:** For each occurrence i of value x, count subarrays where i is the first occurrence of x and no x-1 appears anywhere. Let prev_same be the previous occurrence of x, prev_minus the previous occurrence of x-1, and next_minus the next occurrence of x-1 after i. Then L must satisfy L > max(prev_same, prev_minus), and R must satisfy R < next_minus. The number of such subarrays is (i - max(prev_same, prev_minus)) * (next_minus - i). Summing this over all indices counts every valid subarray exactly once, at its first occurrence of x.
- **Sentinels:** Use 1-indexed positions. Set prev_same = 0 and prev_minus = 0 when no such occurrence exists. For x = 1, always prev_minus = 0 and next_minus = N+1. Set next_minus = N+1 when no later occurrence of x-1 exists.
- **Implementation:** Two linear passes. First, scan right to left maintaining last_next[value] to compute next_minus[i] for every i. Second, scan left to right maintaining last[value] to get prev_same and prev_minus, accumulate the contribution, then update last[x] = i.
- **Complexity:** O(N) time and O(N) memory. Values are bounded by N, so arrays of size N+2 are sufficient. Python integers handle the potentially large result.
- **Verification:** Sample outputs are 16, 23, and 129. Manual checks for small arrays such as [1], [2,1], and the samples agree with the formula.
