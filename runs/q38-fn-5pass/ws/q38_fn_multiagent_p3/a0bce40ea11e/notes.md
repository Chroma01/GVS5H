- **Core cancellation:** Write B = A + sum x_z E_z over zero cells. Expand B^p into words of length p. For odd p, sum_{x in F_p^*} x^c is -1 if c=0 or c=p-1, otherwise 0. Since word length is p, only the all-A word and words using exactly one zero-cell elementary matrix p-1 times and A once survive. Every surviving coefficient is (-1)^K, where K is the number of zero cells.
- **Diagonal corrections:** For a zero diagonal cell E=E_ii, the surviving sum is sum_{t=0}^{p-1} E^t A E^{p-1-t}. Because A_ii=0, all middle terms vanish, leaving AE+EA. This adds column i of A and row i of A to the answer before the global sign.
- **Off-diagonal corrections:** For a zero off-diagonal cell E=E_ij, E^2=0. The only possible nonzero word with p-1 copies of E and one A is EAE, which exists only when p=3. It contributes A_ji to position (i,j). No off-diagonal correction exists for odd p>3.
- **Small primes:** For p=2, every zero is replaced by 1 and every nonzero entry is already 1, so B is the all-ones matrix and B^2 has every entry N mod 2. For p=1, all outputs are 0 modulo 1. If A is all zero for odd p, the formula gives the zero matrix, so an early return is safe.
- **Matrix power:** The remaining term A^p is computed by binary exponentiation modulo p. Multiplication accumulates without immediate modular reduction; entries are bounded by about N(p-1)^2, which is safe for Python integers. When a left entry equals p-1, subtracting the corresponding row keeps intermediate integers smaller while preserving the result modulo p.
- **Performance strategy:** PyPy uses manual row accumulation and skips zero entries in the left matrix. CPython fallback uses dense dot products with operator.mul when the left matrix is dense, and manual sparse multiplication otherwise. An optional NumPy path is used for larger N when available: uint64 blocked matrix multiplication is performed with block sizes chosen so each block sum fits signed 64-bit arithmetic, followed by modulo reduction after each block. Any NumPy failure falls back to pure Python.
- **Implementation details:** K is counted from zero entries. Diagonal corrections are applied by scanning diagonal zeros. For p=3, off-diagonal transpose corrections are applied by scanning zero off-diagonal cells. Finally, entries are reduced modulo p and negated if K is odd.
- **Validation:** The formula matches the samples. Small brute-force checks for N=1 and N=2 with p=3 confirm the global sign, diagonal row/column corrections, and the special off-diagonal transpose correction.
