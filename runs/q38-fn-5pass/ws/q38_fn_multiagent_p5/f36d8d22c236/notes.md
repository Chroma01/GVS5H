- **Mapping:** For each character appearing in S, all its positions force the same target character in T. If one source character is forced to two different targets, the answer is -1. Only distinct source letters matter; multiple occurrences are collapsed into one class.
- **Graph model:** Build a directed edge `c -> f(c)` for every source letter `c` appearing in S where `f(c) != c`. Let `E` be the number of such non-self edges. Letters not appearing in S have no outgoing edge and can serve as initially empty labels.
- **Acyclic edges:** Edges not belonging to a directed cycle can always be performed in exactly one operation each. Process them from sinks or cycle-adjacent nodes outward. These operations may also create an empty label that can later be reused.
- **Cycle cost:** A directed cycle usually needs one extra operation to rotate labels. However, if a cycle vertex has an incoming edge from outside the cycle, the extra cost disappears. The outside source can be used as a carrier for the cycle predecessor, creating an empty label and completing the cycle using only the required edges.
- **Bad cycles:** Only closed cycles add one operation. A cycle is closed/bad iff every vertex in it has original indegree exactly 1 among non-self edges, meaning no outside letter targets any cycle vertex.
- **Cycle detection:** Compute indegrees from non-self edges. Use Kahn pruning: queue letters with an outgoing edge and current indegree 0, remove them, and decrement the target's indegree. Remaining letters with outgoing edges are exactly cycle vertices. Traverse each remaining cycle and classify it by the original indegrees.
- **Impossibility:** If a bad cycle exists and no temporary empty label can ever be created, the task is impossible. This happens exactly when both S and T contain all 26 letters. Then the mapping is a permutation, every nontrivial cycle is closed, and any effective operation would merge two currently present letters, permanently reducing the number of distinct letters below 26, while the final string needs all 26 distinct letters.
- **Temporary label existence:** If S misses some letter, that letter is initially empty. If S contains all 26 but T misses some letter, that missing letter is present initially and has a non-self edge; processing an appropriate outside edge creates an empty label. Thus a bad cycle is possible unless the all-26 permutation case above occurs.
- **Answer:** If impossible, print -1. Otherwise print `E + number_of_bad_cycles`.
- **Complexity:** The algorithm is O(N + 26) time and O(1) additional graph memory beyond the input strings.
- **Useful checks:** `a->b, b->a, c->a` has a good cycle and costs 3 (`b->c`, `a->b`, `c->a`). `a->b, b->a` with any empty letter costs 3. A closed cycle with all 26 letters present in both S and T is impossible.
