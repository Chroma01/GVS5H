The minimax distance f(x, y) is the smallest edge-weight threshold at which x and y become connected when edges are added in nondecreasing order, so Kruskal-style DSU processing captures all relevant distances. Treat each occurrence in A as +1 surplus and each occurrence in B as -1 surplus; within a DSU component, opposite surpluses can already be matched at costs no larger than the current edge. When two components merge at weight w, any remaining opposite surpluses must be matched at cost w, and matching them greedily is optimal because future edges are not cheaper. Maintain only the net surplus per component and accumulate w times the number of newly matched opposite pairs. This yields O(M log M) time and O(N) memory.
