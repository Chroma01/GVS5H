- **Problem model:** Majority reduction over a perfect ternary tree (3^N leaves, height N). Root value = A'_1; answer = min flips to make the root take the opposite value.
- **Exact tree DP (chosen approach):** For every node keep: current majority value `v` and `f` = min flips to flip that value. Leaves: `v[i]` = bit, `f[i]` = 1. Internal node: `v_new = majority(v_a,v_b,v_c)`; target `t = 1 - v_new`; child cost-to-`t` is `0` if the child already equals `t`, else its `f`. Need at least 2 of 3 children at `t`, so `f_new = sum of the two smallest child costs`.
- **Why sum of two smallest is exact:** disjoint subtrees make child flip costs independent and nonnegative, so forcing extra children to the target only adds cost. Each child brought to `t` costs its `f`; making the child's value `t` when it currently differs is exactly `f` (you must flip), and keeping it costs 0. So minimum total = two cheapest.
- **Cost bound:** `f` at level k <= 2^k; for N=13 max is 8192 (int64 safe). No overflow concerns.
- **Complexity:** O(3^N) time and memory; ~1.6M leaves for N=13, well within limits.
- **Implementation:** numpy-vectorized path primary: strided slices `[0::3]`, `[1::3]`, `[2::3]`; majority via `(a+b+c)>=2`; two-smallest via `ca+cb+cc-max`. Pure-Python fallback runs the identical recurrence with lists if numpy is missing.
- **Input parsing:** read all whitespace tokens; `N = data[0]`; string = `b''.join(data[1:])` so both `"010011101"` and space-separated digits parse correctly.
- **Verification (independent brute force):** brute = minimum Hamming distance from A to any string whose root value differs; found by enumerating subsets of flipped positions in increasing size. Tested exhaustively for N=1 (all 8 strings, brute over all 8 targets) and N=2 (all 512 strings, brute over all 512 targets), and for several random N=3 strings via distance-increasing subset search (target distance bounded by 8). All cases matched the DP output, with no mismatches. Sample 1 -> 1, Sample 2 -> 2.
- **N=1 sanity:** only all-identical triples (`000`/`111`) need 2 flips; all others need 1. DP reproduces this.
- **Answer rule:** always print `f[0]` (min flips to flip the root), independent of the root's current value.
