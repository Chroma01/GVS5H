- **Reduction:** Row and column flips commute and are involutions. For a fixed column-flip mask `c`, each row mask `r` can be flipped independently, contributing `min(popcount(r xor c), W - popcount(r xor c))`. The task is to minimize this sum over all `c`.
- **Frequency aggregation:** There are only `2^W` possible row masks (`W <= 18`). Count frequencies of row masks. The objective becomes an XOR convolution between the frequency array and the kernel `k[d] = min(popcount(d), W - popcount(d))`.
- **FWHT convolution:** Using the unnormalized Fast Walsh-Hadamard Transform, `FWHT(freq * k) = FWHT(freq) * FWHT(k)`. After pointwise multiplication, applying FWHT again and dividing by `N = 2^W` gives all column-mask costs.
- **Kernel transform optimization:** Instead of building the full kernel array and transforming it, compute its Walsh transform directly. Since `k` depends only on Hamming weight, its transform depends only on the weight `s` of the queried mask. For weight `s`, the transform is a Krawtchouk sum: `sum_t cost[t] * sum_j (-1)^j C(s, j) C(W-s, t-j)`. This saves one full FWHT and one large array.
- **Implementation details:** Parse row strings with `int(s, 2)`. Use a list of length `1 << W`. After the first FWHT, multiply each transformed frequency by `walsh_kernel[popcount(mask)]`, then inverse FWHT. Because all final values are exact multiples of `N`, `min(freq) // N` gives the answer.
- **Complexity:** Time is `O(W * 2^W + W^3)`, dominated by two FWHT passes. For `W = 18`, this is about `4.7` million butterflies. Memory is `O(2^W)`.
- **Edge cases:** `W = 1` always yields answer `0`; single-row inputs can always be made zero by choosing the column mask equal to the row mask; leading zeros in row strings are handled correctly by `int(s, 2)`.
