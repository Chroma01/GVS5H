Model each diagonal direction as one of four moves and precompute, for every cell, direction, and expected sequence parity, the maximum straight continuation length that follows the required 2,0,2,0,... pattern. Then evaluate every possible starting cell whose value is 1 by extending straight in each initial direction, optionally making one clockwise 90-degree diagonal turn, and continuing with the next required parity. Track the maximum total length, including segments with no turn, and return 0 if no valid segment exists. The solution should run in O(n*m) time with O(n*m) memory.
