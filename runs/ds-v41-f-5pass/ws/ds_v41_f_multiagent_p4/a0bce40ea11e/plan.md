We derive a formula for S = sum over all fillings of B^p mod p. For a zero variable x in F_p^*, the sum of x^e over allowed values is -1 if (p-1)|e and 0 otherwise. Since B^p has total degree p, for p>2 each zero entry must appear either 0 or p-1 times in a contributing monomial. Thus S = (-1)^K (C+T), where C is A^p mod p with zeros treated as 0, and T collects walks using one zero edge p-1 times and one fixed edge once. For p>3 only zero loops contribute; for p=3 non-loop zero edges also contribute via their reverse fixed edge. Handle p=2 separately.
