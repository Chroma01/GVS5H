A 400 number is exactly the square of an integer whose prime factorization contains exactly two distinct primes, because all prime exponents in the 400 number must be positive even integers. Since A ≤ 10^12, the square root is at most 10^6, so we can precompute all integers up to the maximum query square root that have exactly two distinct prime factors. A sieve counting distinct prime factors for every number up to that limit is sufficient. Then store the squares of those integers in sorted order and answer each query with a binary search for the largest square not exceeding A.
