- **Approach:** Let P_i be prefix sums modulo MOD. The required sum is over all pairs 0 <= i < j <= N of (P_j - P_i)^K. For a fixed j, expand by the binomial theorem: sum_{q=0}^K C(K,q) * P_j^{K-q} * (-1)^q * S_q, where S_q is the sum of P_i^q over previous prefixes i < j.
- **Processing order:** For each new prefix P_j, first add its contribution using the current S array, then update S with P_j^q. Updating before the contribution would incorrectly include pairs with i = j.
- **Initialization:** The empty prefix P_0 = 0 is included. Therefore S[0] = 1 because P_0^0 = 1, and S[q] = 0 for q > 0. The power array always sets pwr[0] = 1, correctly handling 0^0.
- **Implementation details:** Precompute binomial coefficients up to K using Pascal's triangle. Store coeff[q] = C(K,q) * (-1)^q modulo MOD. For each prefix, compute powers up to K, accumulate the contribution, and update S[q] with a conditional subtraction since both S[q] and pwr[q] are already reduced modulo MOD.
- **Complexity:** Time O(NK), memory O(K). With K <= 10 and N <= 2e5, this is easily fast enough in Python.
- **Correctness checks:** Sample 1 gives 75. A zero prefix with K = 10 contributes zero because all positive powers are zero and the relevant lower moments are zero before the first update. Repeated prefix values are counted correctly because S stores counts and moments of all previous prefixes, not just distinct values.
- **Potential pitfalls:** Keep S[0] as the count of previous prefixes. Use modulo arithmetic for negative binomial coefficients. Do not include the current prefix in S before computing its contribution.
