The problem requires determining reachability from square 1 to N with jumps in [A,B] avoiding bad intervals. Since N is up to 1e12 but B <= 20, we can model reachability with a bitmask of the last B positions. First, note that any bad interval of length >= B completely blocks passage, so we can immediately output No if such an interval exists. Otherwise, all bad intervals are short (total bad squares O(M*B)), allowing us to process the line by alternating between long good segments (where the bitmask transition is deterministic) and short bad segments. For good segments, we precompute the functional graph of the bitmask transition and use cycle detection plus binary lifting to fast-forward any length. Then we simulate the sequence of good and bad segments to obtain the final bitmask at position N, and check if N is reachable.
