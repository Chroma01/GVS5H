The problem reduces to checking if a subset of persons imposes consistent constraints on a potential function P over towns. Each person i defines an interval [l_i, r_i] (min and max of S_i, T_i), a direction d_i (+1 if S_i < T_i, else -1), equality P[l_i]=P[r_i], and for all x in (l_i, r_i), P[x] > P[l_i] if d_i=+1, or P[x] < P[l_i] if d_i=-1. A set of persons is feasible iff no two persons conflict. Conflicts occur in four cases: (1) same interval with opposite directions; (2) shared left endpoint with different right endpoint; (3) shared right endpoint with different left endpoint; (4) crossing intervals (l_i < l_j < r_i < r_j) with the same direction. Since feasibility is monotonic, for each i we compute next_conflict[i] = smallest j > i that conflicts with i. Then a query [L,R] is valid iff min_{i in [L,R]} next_conflict[i] > R. We compute next_conflict[i] by handling the four cases separately: (1)-(3) via grouping and scanning; (4) via two sweep lines (one per direction) using a segment tree over l that stores active (r, index) sorted by r, querying for i with l_i < l_j and r_i in (l_j, r_j), and removing found i. Finally, build a range-minimum segment tree over next_conflict and answer queries.
