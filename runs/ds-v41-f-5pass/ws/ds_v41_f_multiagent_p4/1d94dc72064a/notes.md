- **Game reduction:** The first time index i is chosen it becomes activated (added to S); all later choices of an activated index are pure pass moves drawn from a shared pool P of leftover tokens. Activating i adds reward r_i = A_i - 1 to P. Game ends, and the actor wins, exactly when the last unactivated index is activated.
- **State:** (m = number of unactivated indices, P = available pass tokens, E = number of even rewards). Note r_i is even iff A_i is odd, so E = (count of odd A_i).
- **Normal play:** m=0 is a loss for the mover (game already over); m=1 is an immediate win for the mover (activate and win). At m>=1 there is always an activation move.
- **Base m=2:** activating hands opponent m=1 (a win), so nobody activates voluntarily; players only pass. Mover wins iff P is odd (P=0 forces a losing activation).
- **Base m=3:** mover wins iff some remaining reward has the same parity as P. (Activating with r ≡ P makes P+r even, giving opponent an even-P m=2 loss; if no such reward and P>0, passing flips P so opponent gets a matching reward; if P=0 and all rewards odd, mover is stuck losing.)
- **Base m=4:** mover wins iff (E + P) is odd. Derivation: activation wins when the opponent's resulting m=3 state has no reward matching its P; passing complements parity. Solving the small recursion f(P)=A(P) or not f(P-1) yields f(P) = (E+P) odd.
- **Induction m>=5:** Assume (E+P) odd decides all states with 4 <= m' < m. In state (m,P,E): pass -> opponent (m,P-1,E); even activation -> (m-1,P,E-1); odd activation -> (m-1,P+1,E). Each option makes the opponent win iff (E+P) is even, and loses iff (E+P) is odd. Hence mover wins iff (E+P) odd for all m>=4.
- **Initial condition:** P=0, m=N. So: N=1 -> Fennec; N=2 -> Snuke; N=3 -> Fennec iff E>=1 (i.e. at least one A_i odd); N>=4 -> Fennec iff E odd, i.e. count of odd A_i is odd.
- **Verification:** Sample 1 (N=3, has odd) -> Fennec; Sample 2 (N=2) -> Snuke; Sample 3 (N=6, four odds, even) -> Snuke. All match. Small-case brute force (N<=4, A_i<=3) agrees with the derived rule, e.g. N=3 A=(2,2,2) Snuke, A=(1,1,2) Fennec; N=4 A=(1,1,1,1) Snuke (c=4 even), A=(1,1,1,2) Fennec (c=3 odd).
- **Complexity:** O(N) time, O(1) extra space beyond input; just count odd A_i.
