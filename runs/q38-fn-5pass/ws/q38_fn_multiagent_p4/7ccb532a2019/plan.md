Count the frequencies of the 26 lowercase letters. For a fixed target frequency f, every letter is either absent in the final string (target count 0) or present (target count f). The cost for a chosen set of present letters is the baseline delete/insert cost sum |c_i - target_i| minus the number of useful adjacent changes, where a change from i to i+1 saves one operation only when it replaces a deletion at i and an insertion at i+1, i.e. min(excess_i, deficit_{i+1}). This cost couples only adjacent letters, so a two-state DP (present/absent) over the alphabet computes the best set for that f. Enumerate f from 1 to len(s) and take the minimum. Validate the formula against examples and small brute-force cases.
