Group foods by vitamin type and solve three independent 0/1 knapsack problems with calorie capacity X. For each vitamin, compute the maximum amount of that vitamin obtainable using at most c calories for every c from 0 to X. Then a target value K is feasible exactly when the minimum calories needed to obtain at least K units of each vitamin sum to at most X. Binary search the maximum feasible K, using the precomputed DP arrays to test feasibility quickly.
