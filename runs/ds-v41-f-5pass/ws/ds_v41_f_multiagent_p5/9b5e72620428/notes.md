- **Reduction:** Fix common sum S. A is permutable, so only multisets matter; B order irrelevant (only its known multiset + count of -1). Feasible for S iff countA[v] = countB[S-v] for all v. Known values force lower bounds; existence of a nonneg integer function f (=countA) with sum N, f[v] ≥ cntA[v], f[S-v] ≥ cntB[v] is possible iff sum_v max(cntA[v], cntB[S-v]) ≤ N.
- **Core condition:** sum_v max(cntA[v], cntB[S-v]) = KA + KB − M(S), where M(S) = sum_v min(cntA[v], cntB[S-v]) is the maximum number of known-known pairs. So S works iff S ≥ max known A, S ≥ max known B, and M(S) ≥ K = KA + KB − N.
- **Trivial Yes:** K ≤ 0 (i.e. unknowns uA+uB ≥ N) always feasible: pick S = max(maxA, maxB); then sum max ≤ KA+KB ≤ N. Covers all -1 input too (K = −N).
- **Finiteness of S:** If K > 0, M(S) > 0 needs a matched known-known pair, so S = v + w for a known A value v and known B value w. Also S ≥ thresh = max(maxA, maxB) is required (else some known value exceeds S and cannot pair with a nonneg complement).
- **Accumulation trick:** M(S) = sum over all pairs (v,w) of known values with v+w=S of min(cntA[v], cntB[w]). Each pair contributes to exactly one sum, so iterating once over distinct known A × distinct known B gives all M(S) in O(dA·dB) ≤ O(N²); no O(N³) per-S recomputation.
- **Implementation details:** Frequency maps cntA, cntB via dict. Sort distinct B values; for each distinct A value v only consider w ≥ thresh−v (bisect). Accumulate acc[v+w] += min(ca, cb). Print Yes iff any acc[S] ≥ K. K = KA+KB−N > 0 guarantees both maps nonempty.
- **Pitfalls avoided:** don't assume M(S) monotone in S; use min(ca,cb) not product; aggregate pairs per sum automatically; enforce S ≥ thresh; handle K ≤ 0 before candidate generation.
- **Verification:** Samples 1 (Yes, S=4 and S=5 both give M=2 ≥ K=2), 2 (No, max M=2 < K=3), 3 (No, max M=1 < K=2) all match. Edge checks: all -1 → Yes; A=[1,0],B=[0,0] → No; A=[2,2],B=[1,1] → Yes (S=3); K=0 cases → Yes.
- **Complexity:** Time O(dA·dB + N) ≤ O(N²) ≈ 4·10⁶ pair additions; memory O(#distinct achievable sums) ≤ O(N²) dict entries.
