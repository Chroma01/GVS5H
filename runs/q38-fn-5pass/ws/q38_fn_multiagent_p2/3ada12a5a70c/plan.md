Map each boundary point to one of two monotone chains: chain 0 = bottom + right, chain 1 = left + top, using `u = x + y` as the chain coordinate and `v = x - y` for cross-chain checks. On the same chain, Manhattan distance is exactly `|u_i - u_j|`; on different chains it is `max(|u_i-u_j|, |v_i-v_j|)`. For a candidate distance `d`, any feasible set sorted by `u` can contain at most one chosen point per chain inside any interval of length `d`, so when scanning points by `u`, a new point only needs to be checked against the last chosen point on each chain (the last two chosen points). Binary search `d`, and for each `d` run a DP over selected count and compressed last-two-chain states, using two-pointers/dominance pruning to keep the state count near `O(n*k)`.
