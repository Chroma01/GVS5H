Model any valid alkane subgraph as a connected induced subtree S of T, since omitting an edge between selected vertices would disconnect the tree. Root T arbitrarily and use DP: for each vertex v and whether its parent edge is selected, compute the best number of vertices in a connected part inside v's rooted subtree with v selected, a chosen number c of selected children, and a flag indicating whether a degree-4 vertex has appeared. The degree constraints force c=0 or 3 when the parent is selected, and c=1 or 4 when it is not; combine children with a small knapsack over these counts. The answer is the maximum valid state with parent not selected over all possible top vertices, or -1 if none exists.
