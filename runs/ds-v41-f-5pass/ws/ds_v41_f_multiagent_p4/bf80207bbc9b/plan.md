Model the final state as A_{i,j} XOR r_i XOR c_j, where r_i and c_j indicate whether row i and column j are flipped. For a fixed column-flip mask c, each row independently chooses r_i to minimize its contribution, giving min(popcount(a_i XOR c), W - popcount(a_i XOR c)). Since W ≤ 18 but H is large, count the frequency of each W-bit row pattern and compute the total cost for every possible c efficiently. The cost is an XOR convolution between the row-frequency array and the function f(mask)=min(popcount(mask), W-popcount(mask)), computable with a Fast Walsh-Hadamard Transform in O(W 2^W). Finally, take the minimum cost over all 2^W column masks.
