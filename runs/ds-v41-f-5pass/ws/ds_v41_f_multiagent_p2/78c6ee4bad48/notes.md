- **Operation on gaps:** With sorted positions and local gaps d1=(x_{i+1}-x_i), d2, d3, applying the operation at i puts the three gaps in exactly reversed order: (d1,d2,d3) -> (d3,d2,d1). Equivalently it swaps the gaps at global positions i and i+2 while the middle gap is unchanged. Derivation: M = x_i + (d1+d2+d3)/2, new positions x_i, a+d3, a+d2+d3, a+d1+d2+d3 (a=x_i), so new sorted gaps are d3, d2, d1.
- **Invariant/permutation group:** Positions i and i+2 have the same parity, so each operation is an adjacent transposition inside the odd-gap subsequence (i odd) or the even-gap subsequence (i even). Adjacent transpositions generate all permutations, so the reachable set is exactly all permutations of the odd gaps, jointly with all permutations of the even gaps, independently.
- **Fixed first coordinate:** Only pieces i+1, i+2 move, and their new coordinates are a+d3 and a+d2+d3 with a>=x_1 and d>0, so the leftmost coordinate x_1 never changes and never becomes second-smallest.
- **Objective:** sum = N*x_1 + sum_{j=1}^{N-1} (N-j) * d_j; gap j has weight w_j = N-j. Weight strictly decreases with j, so the largest weight sits at j=1.
- **Minimization:** Rearrangement inequality within each parity class. Sort odd gaps ascending and place them at positions j=1,3,5,...; sort even gaps ascending and place at j=2,4,6,.... Assigning smallest gap to largest weight is optimal, and any permutation within a class is reachable.
- **Complexity:** O(N log N) time (two sorts), O(N) memory; all arithmetic fits in Python big ints (sum <= ~N * X_max * N order ~ 1e12*2e5*... well within Python).
- **Verification Sample 1:** N=4, X=[1,5,7,10], gaps [4,2,3]; odd sorted [3,4], even [2]; sum = 4*1 + 3*3 + 2*2 + 1*4 = 21. Matches.
- **Verification Sample 2:** N=6, X=[0,1,6,10,14,16], gaps [1,5,4,4,2]; odd sorted [1,2,4], even sorted [4,5]; weights 5,4,3,2,1 -> 5*1+4*4+3*2+2*5+1*4 = 41. Matches.
- **Pitfalls avoided:** no floating point (integer gap swaps only); correct 1-based gap indexing (odd class = gaps[0::2]); do not mix parity classes.
