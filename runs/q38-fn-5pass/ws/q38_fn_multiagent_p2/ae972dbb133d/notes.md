- **Edge-variable model:** Put one binary variable on each shared grid edge, meaning whether a line endpoint exists there. For cell (i,j), let top/bottom be horizontal shared edges and left/right be vertical shared edges. A tile requires top xor bottom = 1 and left xor right = 1. A B tile requires top = bottom, left = right, and top xor left = 1. These conditions are also sufficient to determine the unique tile orientation.
- **Row/column separation:** The top/bottom equations involve only horizontal edge variables in one column, and the left/right equations involve only vertical edge variables in one row. Around each column cycle, the xor of all A indicators must be 0; around each row cycle, the xor of all A indicators must be 0. Thus every row and column must contain an even number of A tiles.
- **Parameterization:** If a column has even A parity, all its horizontal edge variables are determined by one free bit x_j, the top edge of row 0 in that column. If a row has even A parity, all its vertical edge variables are determined by one free bit y_i, the left edge of column 0 in that row. For cell (i,j), top = x_j xor (xor of A tiles above i in column j), and left = y_i xor (xor of A tiles left of j in row i).
- **B constraints:** For every B tile, top xor left = 1. Therefore x_j xor y_i = 1 xor column_prefix_xor xor row_prefix_xor. These are parity equations between one row variable and one column variable.
- **Counting:** Use a parity DSU on H+W variables. Each successful union of different components reduces the number of free components by one. A contradictory equation makes the answer 0. If consistent, each DSU component has one independent binary choice, so the answer is 2^(number of DSU components) modulo 998244353.
- **Implementation details:** Read all tokens once. For each test case, first scan rows to check row parity and column parity, and detect whether any B exists. If parity fails, output 0. If there are no B tiles, output 2^(H+W). Otherwise, scan again, maintaining column prefix xor and current row prefix xor, and add DSU constraints only for B cells.
- **DSU parity convention:** parity[x] stores value[x] xor value[parent[x]]. find returns root and value[x] xor value[root]. To enforce value[a] xor value[b] = w, if roots differ, attach one root under the other with parity child = pa xor pb xor w. Path halving is used in find for speed.
- **Pitfalls:** Use torus prefixes carefully: for row 0 the top prefix is 0, and for column 0 the left prefix is 0. Isolated row or column variables still contribute a factor of 2. Duplicate B constraints are fine if they impose the same parity, but conflicting duplicate constraints must yield 0. Keep total work linear in sum H*W plus sum H+W.
