Model the shortest palindrome path as a shortest path problem on pairs of vertices `(u, v)`, where `dist[u][v]` is the length of the shortest palindrome-labeled path from `u` to `v`. Initialize every `(u, u)` to `0` and every single edge `(u, v)` to `1`, then expand a known palindrome from `u` to `v` by adding one incoming edge to `u` and one outgoing edge from `v` with the same label, increasing the length by `2`. Use multi-source BFS over the `N^2` pair states, grouping edges by label so only matching added edges are considered. The final answer for `(i, j)` is `dist[i][j]`, or `-1` if it remains unreachable.
