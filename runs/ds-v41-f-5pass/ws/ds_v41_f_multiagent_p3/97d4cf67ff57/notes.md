- **Problem restatement:** Choose a connected subgraph (automatically a subtree) of T where every used vertex has degree 1 or 4, with at least one degree-4 vertex. Maximise the number of used vertices, or -1.
- **Key reduction:** Any alkane contains a degree-4 vertex. Root the alkane at one such vertex. Then it has exactly 4 branches; each branch is a directed edge message independent of the others. So we can compute for every directed edge (u,v) the best branch size hanging off u when the edge u-v is included, and then for every vertex v take the 4 largest incoming messages.
- **Branch message definition:** msg[u->v] = max(1, 1 + sum of the 3 largest msg[x->u] over neighbours x != v). The 1 is u as a leaf; the second case makes u a degree-4 vertex with exactly 3 chosen children. msg is always >= 1.
- **Bottom-up (down):** For each non-root u, down[u] = msg[u->parent[u]]. Compute as max(1, 1 + top3 of down[children]) if u has >=3 children, else 1.
- **Top-down (up):** For a vertex p and child c, up[c] = msg[p->c] = max(1, 1 + top3 of {up[p] (if p non-root)} ∪ {down[x] : x child of p, x != c}). Build a list of incoming messages to p, sort descending, keep only the top 4 (sufficient because we exclude at most one element), then for each child c pick the first 3 entries whose index != c.
- **Final answer:** For each vertex v, collect all incoming messages (up[v] if v has parent, plus down[c] for every child c). If at least 4 messages exist, candidate = 1 + sum of the 4 largest. Take the maximum. If no vertex has >=4 messages (degree >= 4), print -1.
- **Correctness:** Any alkane can be rooted at one of its degree-4 vertices, and its four branches are exactly captured by the messages. Conversely, any combination of 4 messages at v produces a valid alkane whose top vertex v has degree 4. Hence the maximum over all v is the answer.
- **Complexity:** O(N log N) due to sorting incoming lists (total elements O(N)), O(N) memory. Iterative BFS avoids recursion limits.
- **Edge cases:** N < 5 => -1. No vertex of degree >= 4 => -1. A single branch message is always at least 1, so any vertex with degree >= 4 yields a valid alkane of size >= 5.
- **Pitfall avoided:** The naive "max(1, 1+top3)" for a leaf-top vertex can overcount if the top is a leaf and its only child is a leaf; the directed-edge rerooting formulation eliminates this because every alkane has a degree-4 root.
