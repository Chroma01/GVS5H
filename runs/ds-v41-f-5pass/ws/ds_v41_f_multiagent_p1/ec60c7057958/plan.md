Model the lexicographic construction as an unranking problem over alternating permutations. Because adjacency only depends on parity, the number of completions from any partial prefix depends only on how many odd and even numbers remain and which parity is required next. Compute these counts with memoized DP, capping values above k to avoid overflow. Then build the answer position by position: for each position, try unused numbers of the allowed parity in increasing order, subtract their completion counts from k until the correct branch is found. If total valid permutations are fewer than k, return an empty list.
