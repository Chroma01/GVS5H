- **Core idea:** Count substrings by their unique non-zero last digit `d`. For each `d` from 1 to 9 that appears in `s`, scan the string and track remainders modulo `d` of all substrings ending at the current position.
- **DP invariant:** Before processing position `i` for divisor `d`, `cnt[r]` is the number of substrings ending at `i - 1` whose value is congruent to `r` modulo `d`. Appending digit `c` maps each old remainder `r` to `(10 * r + c) % d`, and the new one-digit substring contributes remainder `c % d`.
- **Counting condition:** If the current digit equals `d`, every substring ending here has last digit `d`, so add `nxt[0]` to the answer. Substrings ending in zero are never counted because `d` is never zero.
- **Correctness:** Each valid substring has exactly one non-zero last digit `d` and is considered exactly once, in the pass for `d` at its ending position. The recurrence builds the decimal value including leading zeros, so leading-zero substrings are handled naturally.
- **Complexity:** Let `P` be the number of distinct non-zero digits in `s`. The inner work is `n * sum(d for d in present) <= 45n`. For `n <= 10^5`, this is at most about 4.5 million remainder updates, plus small list allocations. Memory is `O(n)` for the digit list and `O(1)` for remainder arrays.
- **Implementation details:** The transition table `_TRANS[d][c]` precomputes the remainder mapping for each divisor and appended digit. The input is converted once to integer digits. A boolean `present` array avoids passes for digits that never appear. The test harness is guarded by `__main__`, so normal class usage is unaffected.
- **Testing verdict:** The included tests run the three provided examples and report sample tests pass. They also check all-zero strings, single digits, leading-zero cases, small repeated strings, and long repeated patterns: 100000 ones, 100000 nines, and 50000 repetitions of `"10"`.
- **Expected long-pattern values:** For 100000 ones, every substring is divisible by 1, giving `n * (n + 1) // 2`. For 100000 nines, every substring of repeated nines is divisible by 9, giving the same value. For `"10"` repeated `m` times, only substrings ending at a one contribute, and the counts at the `m` ones are `1, 3, 5, ..., 2m - 1`, summing to `m * m`.
- **Edge cases checked:** All-zero inputs return 0; a single non-zero digit returns 1; strings such as `"0001"`, `"01"`, `"10"`, `"12"`, `"111"`, and `"999"` match brute force or direct reasoning.
- **Brute-force validation:** The harness exhaustively compares the DP against a direct `O(n^2)` counter for all digit strings of length 1 through 4, covering leading zeros and all last-digit cases.
- **Alternatives considered:** A prefix-remainder method with a common modulus such as `lcm(1..9)` is awkward because 10 is not invertible modulo many digits. Divisibility rules are uneven, especially for 7, so the uniform small-modulus DP is simpler and fast enough.
