Binary search the answer `x` and for each candidate compute the minimum number of moves needed to ensure every `gameScore[i] >= x`. For a fixed `x`, required visits per index are `r_i = ceil(x / points[i])`; extra moves correspond to bouncing along adjacent edges. The minimum extra bounces for a chosen final index equals a maximum-weight independent set on a path with weights derived from `r_i`. Compute these MWIS values for all possible final indices using prefix and suffix DP, then check whether the best total move count is at most `m`. This yields an `O(n log(max(points) * m))` feasibility check.
