The shortest palindrome having S as a prefix is obtained by appending the fewest characters to the end of S. This is equivalent to finding the longest suffix of S that is already a palindrome; if its length is L, append the reverse of the first n-L characters. The longest palindromic suffix can be found in linear time using the KMP prefix function on S + '#' + reverse(S), where the final prefix-function value gives L. The separator must be a character not appearing in S, such as '#', since S contains only uppercase letters. This yields an O(n) time and O(n) memory solution suitable for n up to 500000.
