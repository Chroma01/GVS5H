- **Core reduction:** Because every operation changes all current occurrences of one letter together, two positions with the same initial character can never be separated. Therefore each character appearing in `S` must map to exactly one character in `T`; otherwise the answer is `-1`.
- **Functional graph:** After the forced mapping is built, consider only letters appearing in `S`. Each active letter has one outgoing edge to its required final letter. Fixed points need no operation. Every active non-fixed letter must be used as the source `x` at least once, giving the lower bound `base`.
- **Acyclic parts:** If the graph has no directed cycle among non-fixed active letters, `base` operations are sufficient. Process letters in reverse topological order, moving a letter only after its target label is empty or already contains piles with the same final target.
- **Non-closed cycles:** A directed cycle of length at least 2 with an incoming edge from outside does not need an extra operation. If `u -> v1` enters the cycle `v1 -> v2 -> ... -> vk -> v1`, then `vk` and `u` both finally need label `v1`, so `vk -> u` safely uses `u` as a temporary label. The cycle can then be rotated and `u -> v1` finishes it, all within `base`.
- **Closed cycles:** A cycle is closed if every node in it has original indegree exactly 1 from non-self active edges. Such a cycle has no outside pile with the same final target as any of its nodes. The first pile leaving the cycle must move to an empty label, and that pile must move again later, so each closed cycle adds exactly one operation beyond `base`.
- **Temporary availability:** A closed cycle is feasible if some empty label can be obtained. This is immediate if a letter is absent from `S`. If all 26 letters appear in `S` but the mapping is not injective, some letter is absent from `T`; it is active, non-fixed, and can be emptied using only its required base operation, after which it can serve as a temporary label.
- **Impossibility:** If all 26 letters appear in `S` and the mapping is injective, it is a permutation. If a nontrivial cycle exists, every letter is occupied and all final targets are distinct, so any nontrivial operation would merge piles with different final targets and make separation impossible. Hence output `-1` exactly when a closed cycle exists, all letters appear in `S`, and the mapping is injective.
- **Implementation details:** Build `to[c]` for active letters and detect conflicts. Count `base` as active letters with `to[c] != c`. Count indegrees only from non-self active edges. Detect directed cycles of length at least 2 in the active functional graph. A cycle is closed when all its nodes have indegree 1. Check injectivity by seeing whether any target is used by two active sources.
- **Pitfalls:** Self-loops are fixed points and are not counted as cycles. Inactive letters have no outgoing edges and cannot be cycle nodes, but they can be empty temporary labels. The extra operation is needed only for closed cycles, not for every cycle. Reusing one temporary label for multiple closed cycles still costs one extra operation per closed cycle.
