The key observation is that a 400 number must be a perfect square of an integer with exactly two distinct prime factors. Since A ≤ 10^12, the square root is at most 10^6, so we can precompute all valid 400 numbers up to 10^12 by sieving primes up to 10^6, checking each integer for exactly two distinct prime factors, and squaring it. Sort the resulting list, then for each query binary search for the largest value not exceeding A. This yields O(10^6 log log 10^6 + Q log N) time, which is efficient.
