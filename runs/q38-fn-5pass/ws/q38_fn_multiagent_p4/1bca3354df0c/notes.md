- **Component state:** Because the graph is always bipartite, a component is summarized by bipartition side sizes up to swap. Types are `I` isolated `(1,0)`, `O` non-isolated odd total `(odd, even)`, `Q` even total with both sides odd `(odd, odd)`, `E` even total with both sides even `(even, even)`.
- **Pass parity:** Let `K = sum(a_i*b_i - M_i)`. Only `K mod 2` matters. Since only `Q` has odd `a_i*b_i`, `K mod 2 = (#Q mod 2) xor (M mod 2)`. If `g(S)` is the SG class of the merge-only game with move labels `delta mod 2`, the full SG value is `g(S) xor (K mod 2)`.
- **Corrected merge deltas:** For `I+O` and `O+O`, the `E` result has delta `1` and the `Q` result has delta `0`. Full corrected table: `II->Q d0`; `IO->E d1`, `IO->Q d0`; `IQ->O d0`; `IE->O d1`; `OO->E d1`, `OO->Q d0`; `OQ->O d0`; `OE->O d1`; `QQ->E d1`; `QE->Q d1`; `EE->E d1`.
- **Odd N:** Every terminal connected complete bipartite graph has an even number of edges, so all plays have parity `M mod 2`. Aoki wins iff `M` is odd.
- **No-isolated closed form:** If `i == 0`, the structural class is independent of `e` and equals: `0` if `o == 0`; `2` if `o == 2`; otherwise `q & 1`. This was proved by induction on total components and replaces older unsafe fast paths.
- **DP class recurrence:** The DP stores only class `0`, `1`, or `>=2`. A child class `2` never contributes option values `0` or `1`. Child class `0/1` toggles with delta. Current class is `2` if both option bits appear, `1` if only option `0` appears, else `0`.
- **Periodic DP:** Exact truncated DP is computed for total components up to `B`. Period search tries independent coordinate periods `P` with threshold `T`, requiring the capped window `[T, T+P-1]^4` to have total size at most `B`. Primary run uses `B=80` and tries `(P,T)=(4,16)` first; fallback uses `B=96` and `(4,20)`. If no candidate verifies, a conservative fallback `(8,16)` on `B=96` is used, but the verified path is expected to succeed.
- **Exact use when small:** If the actual total component count is at most the computed `B`, the DP value is used directly without periodic capping.
- **Fast paths kept:** Only odd `N`, single component, and the proven `i == 0` closed form. Previous fast paths for only isolated or only non-isolated odd components were removed because they depended on the old incorrect deltas.
- **Complexity:** Graph processing is `O(N+M)`. DP primary has about `1.9M` states and `43MB` bytearray; fallback about `3.9M` states and `88MB`. Memory is freed before DP when possible.
