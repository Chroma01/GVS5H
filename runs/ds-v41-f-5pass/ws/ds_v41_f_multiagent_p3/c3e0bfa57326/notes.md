- **Model:** Represent a valid parenthesis sequence as an unordered rooted forest. Each matched pair is a node; its children are the balanced blocks directly inside it. Top-level blocks are roots.
- **Operation:** Every contiguous balanced substring is a consecutive block of siblings at some node. The operation reverses that block and applies R(x)=reverse-and-flip to each selected child. R is an involution and is available by operating on the whole child node.
- **Reachability:** To swap adjacent siblings A B, operate on the block A B to get R(B) R(A), then apply R separately to each child to cancel and obtain B A. Hence arbitrary permutations of siblings at every node are reachable. Since R effects can be canceled, reachable strings are exactly all plane embeddings of the original unordered forest.
- **Counting:** Canonicalize rooted unordered trees bottom-up. For a node, let its child isomorphism classes have multiplicities m_c and total k. If dp[c] is the number of distinct strings for class c, then dp[node] = k! / prod(m_c!) * prod(dp[c]^m_c) mod 998244353. Apply the same multinomial formula to the top-level roots.
- **Canonicalization:** Process nodes in reverse creation order because children always have larger indices than their parent. Key = sorted tuple of child class IDs; map each key to a new class ID. Leaves have key () and dp=1.
- **Implementation:** Parse with a stack, storing child lists. Precompute factorials and inverse factorials up to M=N/2. Use pow for dp[c]^m. The solution is iterative, avoiding recursion depth issues. Complexity O(N log N) from sorting children, easily within N<=5000.
- **Edge cases:** Identical siblings are handled by the multinomial coefficient. Distinct root classes allow root permutations. Leaves contribute 1. Empty forest (not in constraints) is handled naturally by fact[0]=1.
