Use the fact that one grid dimension is small (≤447) by transposing so H ≤ W. Maintain prefix DP vectors v[w][h] for every column w and suffix DP vectors u[w][h] for every column w. When the token moves horizontally, recompute the full vector for the new column in the direction of movement; when it moves vertically, only update the affected rows in the current column. For each cell update at (r,w), the change in the total path sum is (new−old)·L·R, where L is the sum of prefix paths to the two predecessors and R is the sum of suffix paths from the two successors. These are obtained in O(1) from v and u. Each operation takes O(H) time, giving O(Q·H) total, which is fast because H ≤ √(HW) ≤ 447.
