Use prefix sums \(P_i = \sum_{j=1}^i A_j\), so each subarray sum is \(P_r - P_{l-1}\). Expand \((P_r - P_t)^K\) with the binomial theorem and maintain, for all powers \(0 \le j \le K\), the sum of \(P_t^j\) over all previous prefix indices \(t < r\). For each new prefix \(P_r\), compute its contribution to the answer in \(O(K)\) time using these maintained power sums, then update the maintained sums with \(P_r\). This gives an \(O(NK)\) solution, which is easily fast enough since \(K \le 10\).
