Sort or mark the given distinct integers in a boolean array of size up to 1,000,000. A fine triplet is a 3-term arithmetic progression, so for each middle value B we need the number of pairs A, C in S with A + C = 2B and A < B < C. Use convolution of the indicator array with itself to count ordered pairs (A, C) for every possible sum. For each B in S, subtract the self-pair (B, B) and divide by 2 to get the number of valid triplets centered at B, then sum these counts.
