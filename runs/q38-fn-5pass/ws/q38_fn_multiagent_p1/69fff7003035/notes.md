- **Core formula:** For a fixed value x, if S is exactly the set of elements after x, the number of permutations with that suffix set is |S|!(N-1-|S|)!, and the decimal shift is product_{y in S} 10^{len(y)}. Therefore the factor contributed by any x of digit length d is sum_k q_k k!(N-1-k)!, where Q_d(t)=product_e (1+10^e t)^{c_e-delta_{e,d}}. The final answer is sum_d V_d * factor_d, with V_d the sum of values having digit length d.
- **Full polynomial:** Build P(t)=product_active (1+w_d t)^{c_d}, where w_d=10^d mod MOD. Its coefficients are needed because Q_d=P/(1+w_d t). Since there are at most six digit lengths for N<=2e5, all polynomial operations are small-degree except coefficient extraction.
- **Coefficient recurrence:** Use logarithmic derivative. Let R(t)=product_active(1+w_d t) and B(t)=sum_d c_d w_d product_{e!=d}(1+w_e t). Then R P' = B P. With p_0=1, coefficient t^n gives (n+1)p_{n+1}=sum_i b_i p_{n-i}-sum_{i>=1} r_i(n-i+1)p_{n-i+1}. The implementation pads R to length 7 and B to length 6, handles n<6 separately, and unrolls the main loop for speed.
- **Synthetic division:** For active d, Q=P/(1+w_d t). If Q=sum q_k t^k, then q_0=1 and q_k=p_k-w_d q_{k-1}. This is done modulo MOD for each active digit length.
- **Factorial weights:** Precompute W_k=k!(N-1-k)! modulo MOD. Instead of storing factorials, compute W_0=(N-1)! and iterate W_{k+1}=W_k*(k+1)/(N-1-k) using modular inverses.
- **Digit groups:** N<=200000 gives digit lengths 1 through 6. Counts and value sums are computed by arithmetic progression per interval [10^{d-1}, min(N,10^d-1)].
- **Edge cases:** N=1 works directly: P=1+10t, Q=1, W_0=1, answer=1. Missing digit lengths are excluded from active R/B; padded zero coefficients keep the unrolled recurrence valid. The small-n loop prevents negative list indices.
- **Complexity:** O(N) time and O(N) memory. The coefficient recurrence is O(N) with a small constant, and synthetic division is repeated for at most six active digit lengths.
- **Checks:** N=3 gives P=(1+10t)^3, Q=1+20t+100t^2, weights 2,1,2, factor 222, value sum 6, answer 1332. N=2 and all-one-digit cases match direct positional counting.
