The key is to transform the minimax path values f(x,y) into a tree-query structure by first building a minimum spanning tree, since any minimax path can be realized in an MST. Then represent MST path-max queries with a Kruskal reconstruction tree so that f(x,y) becomes the value stored at the LCA of x and y. The remaining challenge is to solve the resulting minimum-cost perfect matching between the A and B multisets under this LCA cost. The work should split naturally into graph preprocessing, structural characterization of the matching, efficient implementation, and validation against brute force.
