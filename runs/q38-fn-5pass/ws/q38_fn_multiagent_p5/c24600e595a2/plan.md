In an optimal sequence, all flips that change 1 to 0 can be moved before all flips that change 0 to 1; within the first phase sort by decreasing C, and within the second phase sort by increasing C. The only useful extra flips are temporary off/on pairs for indices with A_i = B_i = 1; an exchange argument shows that if a smaller-C index is temporarily turned off while a larger-C such index is not, swapping them reduces cost, so the optimal temporary set is a prefix of these indices sorted by decreasing C. For a fixed prefix, the canonical sequence cost can be maintained incrementally when adding the next temporary index: its insertion positions among removals/additions determine its own contribution, remaining constant 1-indices gain two operations, and required removals/additions affected by the insertion add their weights. Scanning all prefixes and taking the minimum yields the answer.
