Let d = x - y. Then x^3 - y^3 = d(3y^2 + 3dy + d^2), so d must divide N and, because y is positive, d^3 < N. Therefore d is at most about 10^6, so we can iterate all possible d. For each divisor d, solve the quadratic 3y^2 + 3dy + d^2 = N/d using its discriminant D = 12(N/d) - 3d^2. If D is a perfect square and the resulting y is a positive integer, output x = y + d and y; otherwise output -1.
