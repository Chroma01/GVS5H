The operation for a value `x` simply concatenates the maximal contiguous blocks of `nums` that do not contain `x`. If we can query the maximum-subarray monoid `(sum, best_prefix, best_suffix, best_subarray)` for any block, then the best sum after deleting `x` is obtained by merging those block monoids in left-to-right order. Build a segment tree over `nums` to answer such block queries, and collect the positions of each distinct value. For every value that does not occur in every position, scan its occurrence positions, query each non-empty gap, merge the gap nodes, and update the answer; also keep the original array's max subarray as the no-deletion case.
