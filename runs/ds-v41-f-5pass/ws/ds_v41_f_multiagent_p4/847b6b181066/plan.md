Track the displaced position of a smoke particle born at the campfire using prefix sums of the wind movements. A particle born at time b reaches (R,C) at time t+0.5 exactly when P[t] - P[b] = (R,C), so the answer at time t depends on whether P[t] - (R,C) has appeared as a prefix before. New smoke is generated exactly when the current prefix position appears for the first time, but for existence at (R,C) it is enough to know whether P[t] - (R,C) has appeared among earlier prefixes. Thus we can scan left-to-right, maintaining the set of seen prefix positions and checking before inserting the current one. This gives an O(N) time and O(N) memory solution.
