- **Core model:** Each row is a black prefix, so let `a_x` be the number of black cells in row `x`. The column condition is equivalent to `a_x` being nonincreasing as `x` increases. A black cell `(x, y)` requires `a_x >= y`; a white cell `(x, y)` requires `a_x < y`.
- **Conflict characterization:** A fixed black cell `(xb, yb)` and fixed white cell `(xw, yw)` are incompatible exactly when `xb >= xw` and `yb >= yw`. In that case, monotonicity forces `a_xw >= a_xb >= yb`, while the white cell forces `a_xw <= yw - 1`, impossible if `yb >= yw`.
- **Sufficiency:** If no such incompatible pair exists, define `a_x = max y` among black cells in rows `r >= x`, or `0` if none. This sequence is nonincreasing, satisfies all black constraints, and for any white cell `(xw, yw)`, every black cell in rows `r >= xw` has `y < yw`, so `a_xw <= yw - 1`. Thus the condition is both necessary and sufficient.
- **Implemented sweep:** Sort fixed cells by row descending. For equal rows, process black cells before white cells. Maintain `max_black_col`, the maximum column among black cells already seen, i.e. in the current row or lower rows. When processing a white cell `(x, y)`, if `y <= max_black_col`, there exists a black cell with row `>= x` and column `>= y`, so print `No`. Otherwise continue and print `Yes`.
- **Complexity:** Sorting dominates, giving `O(M log M)` time and `O(M)` memory, well within `M <= 2e5`.
- **Edge cases handled:** Same-row black/white conflicts are caught because black cells are processed first in that row. Same-column conflicts are caught because the comparison is non-strict: `y <= max_black_col`. Rows with no fixed cells need no explicit processing. `N` is only read and not used in the sweep.
- **Sample verification:** Manual traces match all provided samples. Sample 1: bottom black `(4,1)` gives max `1`; white `(3,2)` has `2 > 1`; top black updates max; result `Yes`. Sample 2: black `(2,2)` gives max `2`; white `(1,2)` has `2 <= 2`; result `No`. Sample 3: white `(1,1)` with max `0`; result `Yes`. Sample 4: black `(1814,712)` gives max `712`; white `(1789,211)` has `211 <= 712`; result `No`.
