- **Core model:** Each constraint `A_X xor A_Y = Z` is an undirected edge with XOR weight. In one connected component, fixing one vertex value determines every other vertex by path XOR.
- **Consistency check:** Iterative DFS/BFS assigns tentative values `val[v]` with the component root set to `0`. For an edge `u-v` weight `w`, the required value of `v` is `val[u] xor w`. If `v` is unassigned, assign it; if already assigned and different, output `-1`.
- **Self-loops and parallel edges:** A self-loop with nonzero weight is detected because the required value differs from the current value. A zero self-loop is harmless. Parallel edges are checked by the same consistency rule.
- **Component freedom:** If `val` is one valid assignment for a component, every valid assignment is `val[v] xor C` for one constant `C`. Different connected components are independent, so each component can be optimized separately.
- **Bitwise minimization:** The component sum decomposes by bits: `sum = Σ_b 2^b * (# ones in bit b)`. For a bit, if `cnt` tentative values have bit `1`, choosing `C_b = 0` gives `cnt` ones, while `C_b = 1` gives `size - cnt` ones. Choose `C_b = 1` only when `cnt > size - cnt`. Ties may be broken arbitrarily; the code keeps `0`.
- **Bit range:** Tentative values are XORs of input `Z` values, so no bit above `max_z.bit_length()` can be `1`. Higher bits have zero ones and optimal shift bit `0`. The code uses at least one bit to avoid an empty range when all `Z` are zero.
- **Implementation details:** Use adjacency list, iterative stack, and `val = [-1] * N` as an unvisited sentinel. Collect component nodes to apply the chosen shift after computing bit counts. Isolated vertices with no adjacency are set directly to `0`. Self-loops are stored once.
- **Complexity:** Time is `O(N + M + N * B)`, where `B <= 30` under the given constraints. Memory is `O(N + M)`.
- **Pitfalls handled:** Avoid recursion depth issues, detect contradictions early, handle isolated vertices, self-loops, multiple edges, and tie cases in bitwise majority.
