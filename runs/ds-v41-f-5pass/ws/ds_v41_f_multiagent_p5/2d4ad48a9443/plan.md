Reverse the array so the target condition changes from making subarrays non-decreasing to making them non-increasing using only increments; the required operation count is preserved under reversal. For a non-increasing subarray, the minimum cost equals the sum of its suffix maxima minus its elements. Maintain this cost for a sliding window using a monotonic deque of suffix-max groups, where each group stores a value and how many positions share that suffix maximum. Expand the right end, update the deque and cost, then shrink from the left while the cost exceeds k. Each valid window ending at r contributes r - l + 1 subarrays, giving an O(n) solution.
