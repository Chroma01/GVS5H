Build a trie over all word occurrences, storing for each prefix node the number of words having that prefix and mapping each occurrence to a leaf position via DFS Euler order. A prefix node with count `c >= k + 1` is valid after removing any word, so its depth is a global baseline answer. A prefix node with count `c == k` is valid only for removals of words outside its subtree, so it should update all occurrence positions outside its Euler interval with its depth. Use a range-max update / point-query structure over the Euler order to apply these “outside subtree” updates efficiently. Finally, for each original index, answer is the maximum of the global baseline and its point query, except when `len(words) - 1 < k`, in which case all answers are `0`.
