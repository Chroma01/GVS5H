Binary search on the target minimum score T. For a fixed T, compute required visits per index c_i = ceil(T / points[i]). Reduce the feasibility check to finding the minimum number of moves on a line starting from -1 to achieve at least c_i visits at each index. This is equivalent to minimizing 2*sum(k_i) + sum(b_i) where b_i is a non-decreasing 0/1 sequence (representing a final backtrack), which can be solved via the maximum weight independent set (MWIS) on a path. Use forward and backward DP to evaluate all possible backtrack start points in O(n) per check. Binary search over T in [0, max(points)*m].
