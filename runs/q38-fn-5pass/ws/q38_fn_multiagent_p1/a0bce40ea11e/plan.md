For p=2 there is only one completion (zeros become 1), so output its square modulo 2. For odd p, expand B^p as a polynomial in the K zero variables over F_p; summing each variable over F_p^* keeps only monomials whose exponents are multiples of p-1. Since total degree is at most p and p>2, only the constant term and monomials x_e^{p-1} for a single zero variable survive, each with factor (-1)^K. Thus the answer is (-1)^K times A^p plus, for each zero (r,c), the coefficient of x^{p-1} in (A+xE_{r,c})^p. That coefficient is sparse: diagonal zeros add column r and row r (excluding the diagonal), and off-diagonal zeros contribute only when p=3, adding A_{c,r} to (r,c). Compute A^p by fast modular matrix exponentiation and accumulate these sparse corrections.
