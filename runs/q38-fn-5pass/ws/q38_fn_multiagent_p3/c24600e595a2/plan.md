First prove that any optimal sequence can be rearranged so all flips changing `1` to `0` occur before all flips changing `0` to `1`, because swapping an earlier addition with a later removal strictly reduces cost. Then removals should be performed in decreasing `C`, and additions in increasing `C`. The only bits that may be flipped twice are common ones with `A_i = B_i = 1`; required `1 -> 0` bits are always removed and required `0 -> 1` bits are always added. By an exchange argument, if a common `1` with smaller `C` is removed, then removing a common `1` with larger `C` instead is never worse, so the optimal set of removed common `1`s is a prefix when common `1`s are sorted by decreasing `C`. Therefore evaluate the total cost for every prefix size, starting from no optional removals and updating the cost when the next common `1` is moved from kept to removed, and take the minimum.
