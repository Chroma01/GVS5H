- **Validation examples:** n=4,k=6 yields [3,4,1,2]; n=3,k=2 yields [3,2,1]; n=2,k=3 yields []. Hand enumeration for n=4 all k=1..8 matches the given order; n=5 total is 12 and k=12 gives [5,4,3,2,1]; n=6 total is 72 and k=72 gives [6,5,4,3,2,1].
- **Small edges:** n=1: k=1 returns [1], k>1 returns []; n=2: k=1 returns [1,2], k=2 returns [2,1], k>2 returns []; n=3: only odd-start patterns are valid, k=1 returns [1,2,3], k=2 returns [3,2,1], k>2 returns [].
- **Odd/even n:** For odd n, even first candidates have zero completions because the remaining parity counts cannot fill the forced alternating slots. For even n, both odd-start and even-start patterns contribute valid blocks. The completion count depends only on remaining odd/even counts and the next required parity.
- **Out-of-range handling:** If total valid permutations are fewer than the initial k, then every block size is below CAP and therefore exact. The greedy loop subtracts all exact block sizes and eventually finds no candidate, returning []. This covers n=2,k=3 and n=21,k=10^15, where total is 11!*10! < 10^15.
- **Saturation correctness:** CAP is the initial k. A block is computed exactly whenever its true size is below CAP: if any factorial component were capped, that component would already be at least CAP, making the product at least CAP. If the true block size is at least CAP, the capped count is CAP, which is always at least the current rank because the current rank never exceeds CAP. Therefore capped counts never cause a wrong skip or wrong choice.
- **Large n/k:** For n=100,k=10^15, factorials saturate around 18!, and the algorithm still runs in O(n^2). It keeps choosing the smallest possible next value while the corresponding block size is at least the remaining rank, then skips exact smaller blocks. For n=23,k=10^15, the first block is capped and chosen; deeper blocks such as 11!*10! are below CAP and subtracted exactly.
- **Complexity:** Factorial precomputation is O(n). Construction tries at most n candidates for each of n positions, so time is O(n^2) and space is O(n), easily fine for n=100.
