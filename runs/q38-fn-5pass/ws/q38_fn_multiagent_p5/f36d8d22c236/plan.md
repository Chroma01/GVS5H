Treat each lowercase letter as a vertex and build a partial mapping from every character appearing in S to the character it must become in T. If one source character is required to become two different targets, output -1. For the resulting functional graph, each non-self edge normally costs one operation; a directed cycle of length at least two costs one extra operation only when every vertex in that cycle has indegree 1, meaning no outside letter also targets it. If such a bad cycle exists but no temporary letter can be created—equivalently S and T both contain all 26 letters, making the mapping a permutation—then the transformation is impossible. Otherwise the minimum number of operations is the number of non-self edges plus the number of bad cycles.
