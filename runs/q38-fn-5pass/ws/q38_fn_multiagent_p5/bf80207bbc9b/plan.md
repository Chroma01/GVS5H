Represent each row as a bitmask of length W, and note that choosing column flips corresponds to XORing every row mask with a chosen column mask. For a fixed column mask, each row can then be flipped independently, so its contribution is the smaller of the number of 1s in the resulting mask and the number of 0s. Since many rows may share the same mask, aggregate rows by frequency and compute the total cost for every possible column mask. Use a Fast Walsh-Hadamard Transform to compute all these XOR-convolution costs efficiently in O(W * 2^W), then take the minimum.
