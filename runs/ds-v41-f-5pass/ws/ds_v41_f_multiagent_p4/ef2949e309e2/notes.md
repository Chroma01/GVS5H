- **Problem shape:** count index-subsets of size 5 whose median-index value x = seq[2] is the strict unique mode. Partition by the middle index p: pick 2 indices from L=nums[:p] and 2 from R=nums[p+1:]. Each valid subset counted once (unique median index). Counts index-subsets, not value-sequences (Example 1: 6 = C(6,5)).
- **Split by k = #x among the 4 side picks (x total freq = 1+k):** k=0 -> x freq 1, cannot beat anything and all-1-freq is a 5-way tie -> invalid. k=1 -> x freq 2, valid iff the 3 non-x values are pairwise distinct. k>=2 -> x freq >= 3 while any other value <= 2 -> always valid.
- **Case A (k>=2):** sum over six (a,b) with a+b>=2 of wL_a * wR_b, where side weights are w0=C(nonx,2), w1=sideX*nonx, w2=C(sideX,2).
- **Case B (k=1):** the lone x is on one side. B1 (x left)=leftX * sum_{v!=x} cntL[v]*(TR - cntR[v]*(nonxR-cntR[v])). B2 is the mirror. TR = unordered pairs of non-x elements in R with distinct values = (lenR^2 - sumsqR)/2 - rightX*(lenR-rightX). The inner subtraction removes pairs touching v, leaving two right values that are non-x, not v, and distinct from each other.
- **Incremental bookkeeping:** maintain cntL/cntR and sumsqL/sumsqR (sum of squared counts). Advance p: remove nums[p] from R (sumsqR += 1-2*c), process, then add nums[p] to L (sumsqL += 2*c+1). All O(1) to read; B loops cost O(V) per p.
- **Complexity:** O(n*V) time, O(V) memory with V<=n<=1000 (~10^6 ops). sumsq/2 is always exact (even non-negative).
