Model the problem by considering, for each floor level, the connected components of blocks whose building height is at least that floor; walkways are free inside a component, while stairs change the floor level. For two blocks, let B be the highest floor at which they are connected, i.e. the maximum bottleneck path value over the grid using building heights. This B can be obtained from a maximum spanning tree of the grid where each edge weight is min(F_u, F_v), because the minimum edge weight on the tree path equals the maximum possible bottleneck between the two blocks. For a query from floor Y to floor Z, if min(Y, Z) <= B then the answer is simply |Y - Z|; otherwise the path must descend to B, cross, and ascend, giving Y + Z - 2B. Preprocess the maximum spanning tree with binary lifting to answer bottleneck queries in O(log N) time.
