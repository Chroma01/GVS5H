Use a reverse-construction approach: process insertions from N down to 1, treating positions as empty slots. When inserting value i in reverse, it belongs at the P_i-th currently empty slot among all N positions. Maintain empty slots with a Fenwick tree supporting order-statistic queries to find the k-th empty position efficiently. Assign i to that position and mark it occupied. Finally, output the constructed array in position order. This avoids O(N^2) simulation and runs in O(N log N).
