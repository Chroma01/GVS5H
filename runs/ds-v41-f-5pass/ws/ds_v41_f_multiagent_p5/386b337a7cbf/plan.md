Process the array left-to-right while tracking the parity of the number of selected elements, since that determines whether the next chosen value is added or subtracted in the alternating sum. Use DP where each state is indexed by parity and current product, storing a bitset of achievable alternating sums. Taking a value x multiplies the product by x, flips parity, and shifts the sum bitset by +x for even parity or -x for odd parity, capping products at limit. Keep empty and non-empty subsequences conceptually separate so k=0 is not satisfied by the empty subsequence. At the end, scan products from limit down and return the first product whose sum bitset contains k, otherwise return -1.
