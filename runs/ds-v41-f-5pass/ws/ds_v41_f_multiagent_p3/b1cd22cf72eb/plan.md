Model the final state by choosing a common sum H and final upper lengths A_i; the final lower lengths are forced as H-A_i. The total cost is exactly sum(U_i+D_i) - N·H, so the task is to maximize H subject to A_i ∈ [max(0,H-D_i), min(U_i,H)] and |A_i-A_{i+1}|≤X. For a fixed H, feasibility can be checked in O(N) by maintaining the interval of possible A_i values from left to right. Feasibility is monotone downward in H, so binary search the maximum feasible H. Finally, output the cost using 64-bit arithmetic.
