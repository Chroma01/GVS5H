The core difficulty is counting distinct in-degree vectors of orientations, not orientations themselves, on a cycle plus a star centered at vertex N. First reduce each edge orientation to choosing which endpoint receives an in-edge; the resulting vector must satisfy local capacity/flow constraints on the cycle and star. Derive a characterization of valid vectors using prefix/suffix balance conditions around the cycle, then use generating functions or DP to count them without overcounting identical vectors. Finally implement an O(N) or O(N log N) algorithm modulo 998244353 and validate against brute force for small N and the samples.
