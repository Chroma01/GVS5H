- **Problem model:** Edge iff lcm(a, b) <= threshold. Since lcm(a, b) >= max(a, b), every nums value greater than threshold has no incident edge and is an isolated component.
- **Core equivalence:** For values <= threshold, a and b are adjacent iff they both divide some L <= threshold, namely L = lcm(a, b). So the graph is exactly the union of cliques formed by the present divisors of each L = 1..threshold.
- **Algorithm:** Split nums into `present` (values <= threshold) and `isolated` count. Give each present value a DSU index. Maintain `rep[L]`, the first present divisor of L seen. For each present value d, iterate its multiples L = d, 2d, ... <= threshold: if `rep[L]` is empty, set it to d's DSU index; otherwise union d with `rep[L]`. This connects all present divisors of each L using the first divisor as anchor.
- **Counting:** Answer = number of DSU roots among present values + isolated count. If `present` is empty, return n.
- **Correctness:** If lcm(a,b) <= threshold, then L = lcm(a,b) is enumerated and both a and b divide L, so the algorithm unions them. Conversely, if two present values both divide L <= threshold, their lcm divides L, hence is <= threshold, so they are truly adjacent. Thus DSU components exactly match graph components.
- **Complexity:** Time O(sum over present d of threshold/d + m alpha(m)) = O(threshold log threshold), space O(threshold + m). With threshold <= 2e5 and m <= 1e5, comfortably within limits.
- **Edge cases:** n = 1; all values > threshold returns n; value 1 present connects to every present value, handled by an optional shortcut; duplicates are not in constraints but present enumeration would still handle them naturally.
- **Verification:** Example 1 `nums = [2,4,8,3,9], threshold = 5` gives present `[2,4,3]`, isolated 2, DSU roots `{2,4}` and `{3}`, so answer 4. Example 2 threshold 10 adds 12 as isolated and unions all present values, so answer 2. Actual outputs: 4 and 2.
- **Implementation details:** No value-to-index dictionary is needed; enumerate `present` directly. `rep` stores DSU indices, not values, avoiding an extra map. DSU uses path halving and union by rank.
