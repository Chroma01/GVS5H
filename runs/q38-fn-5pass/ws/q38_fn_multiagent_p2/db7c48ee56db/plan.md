Because \(\binom{N}{K} \le 10^6\), directly enumerating the smaller side is feasible: enumerate either the \(K\) chosen elements or the \(N-K\) excluded elements, whichever is smaller. If enumerating chosen elements, compute the XOR of each combination; if enumerating excluded elements, compute \(\text{total\_xor} \oplus \text{xor(excluded)}\). Track the maximum candidate over all combinations. Handle the edge case \(K=N\) separately by returning the XOR of all elements.
