The total grinding cost equals the original total tooth length minus `N * H`, so minimizing cost is equivalent to maximizing the common sum `H`. For a fixed `H`, each upper tooth length `U_i'` must lie in the interval `[max(0, H - D_i), min(U_i, H)]`, and adjacent chosen upper lengths must differ by at most `X`. Feasibility for a fixed `H` can be checked in linear time by propagating the reachable interval of the current upper tooth length from left to right. Feasibility is monotone: if some `H` is feasible, any smaller `H` is also feasible by capping the chosen upper lengths. Therefore, binary search the maximum feasible `H` up to `min_i(U_i + D_i)`, then compute the answer.
