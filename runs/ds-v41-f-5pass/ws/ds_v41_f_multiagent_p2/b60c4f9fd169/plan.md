Use Levenshtein edit distance with insertions, deletions, and substitutions, since the target condition is exactly edit distance at most K. Because K <= 20 but strings can be length 500000, a full O(|S||T|) DP is impossible; instead compute a banded DP restricted to states within K edits of the main diagonal. First reject immediately if the length difference exceeds K. Then process the strings with rolling DP rows, capping values above K and pruning unreachable cells. This yields O((|S|+|T|)K) time and O(K) memory.
