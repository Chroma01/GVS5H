- **Layer characterization:** For a connected graph, BFS layers from vertex 1 are unique. If layer sizes are `a_0=1, a_1, ..., a_L`, then edges are allowed only within a layer or between consecutive layers; edges between nonconsecutive layers would shorten some distance. Every vertex in layer `i>0` must have at least one neighbor in layer `i-1`. The required condition is exactly that total even-layer vertices and odd-layer vertices are both `N/2`, with the root counted as even.
- **Fixed layer sequence count:** For a fixed ordered layer-size sequence, label assignments contribute a product of binomial choices, equivalently `(N-1)! / prod a_i!`. A new layer of size `a` contributes within-layer edges `(1+x)^{C(a,2)}` and cross edges from previous layer size `p` as `((1+x)^p - 1)^a`, because each new vertex chooses a nonempty subset of the previous layer.
- **DP state:** State `(e, o, p, par)` where `e` and `o` are used even/odd-distance vertices, `p` is the last layer size, and `par` is the parity of the last layer. Future transitions depend only on these values: next layer parity is forced, label choice depends on `N-e-o`, and edge factor depends on `p` and new size `a`.
- **Transition:** From `(e,o,p,par)`, add a positive layer size `a` of the opposite parity, not exceeding the remaining count for that parity. Multiply by `C(N-e-o, a)` and by `WA[p,a] = (1+x)^{C(a,2)} ((1+x)^p - 1)^a`.
- **Dead-state pruning:** If a partial state has unused vertices but the next parity is already full, it can never finish because BFS layers must alternate and have positive size. Such transitions/states are skipped. This is safe and reduces states/transitions.
- **Evaluation strategy:** The final answer is the coefficient polynomial `F(x)`. Instead of polynomial DP, evaluate `F(x)` at `x=0,1,...,E` modulo `P`. For each evaluation point, all factors become scalars, so the DP is a small scalar automaton. `F(0)=0` for `N>=2`, so `x=0` need not be run.
- **Complexity:** For `N=30`, reachable non-dead states are only a few thousand and transitions are about `2.8e4`. With `E<=435`, total inner updates are roughly `1.2e7`, which is feasible in Python. Interpolation is `O(E^2)`.
- **Interpolation:** Newton forward differences over points `0..E` give `F(x)=sum diff[k] binom(x,k)`. Since `P` is prime and `P>E`, all needed inverses exist and interpolation points are distinct. Convert binomial basis to ordinary powers using recurrence `binom(x,k)=binom(x,k-1)*(x-(k-1))/k`.
- **Implementation details:** Precompute binomials and `C(a,2)`. Precompute states and transitions once. For each `x`, compute powers `(1+x)^t`, then flat `WA[p,a]`. DP arrays are grouped by used vertex count and processed in increasing used count. Transitions are stored as tuples `(next_state, pa_index, label_factor)`; `WA` is flat with index `p*(N+1)+a`.
- **Pitfalls:** Do not forbid within-layer edges; they are allowed and affect edge count but not BFS distances. Do not allow edges between nonconsecutive layers. Coverage of each new vertex by the previous layer is essential for connectedness and exact distances. The root is fixed and counted as even. Coefficients below `N-1` and above the true maximum balanced BFS edge count are zero; interpolation over `0..E` recovers them modulo `P`.
