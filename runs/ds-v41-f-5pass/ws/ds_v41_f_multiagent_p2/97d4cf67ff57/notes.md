- **Reduction to induced subgraph:** In a tree, any connected subgraph on vertex set S must contain all edges of T[S]: T[S] is a forest with |S|-k edges (k components); a connected spanning subgraph needs |S|-1 edges, forcing k=1 and the subgraph to be exactly T[S]. Hence we want a connected induced subtree with all degrees in {1,4} and at least one degree 4.
- **Structure of an alkane:** Root at a leaf L. Its unique neighbour R must have degree 4 (otherwise the component is a single edge with no degree-4 vertex). Delete L and root at R: R has exactly 3 children, every other internal vertex has exactly 3 children, and leaves have 0 children. So an alkane is a full ternary tree hanging off R, with one extra leaf L attached to R.
- **Directed-edge DP:** h(v,p) = max size of a valid full-ternary branch rooted at v whose parent is p (component of v after deleting edge (v,p)). Recurrence: h(v,p) = 1 if v has fewer than 3 neighbours besides p, else 1 + (sum of the three largest h(c,v) over c in N(v)\{p}). Taking the internal option is never worse than being a leaf because every h >= 1, so no max(1, ...) branch is needed. Note every h is congruent to 1 mod 3, so all valid sizes are congruent to 2 mod 3 (5, 8, 11, ...).
- **Rerooting passes:** Root T at 0 and get a BFS order (iterative). Bottom-up: down[v] = h(v, parent[v]) using children's down values, keep the three largest. Top-down: up[v] = h(parent[v], v). For each vertex u gather the neighbour values val[n'->u]: parent term up[u] plus child terms down[c]; keep the top 4 values with their source so that for any child c the top 3 of all neighbours except c is obtained in O(1) by skipping the entry with src == c. Set up[c] = 1 + top3 if deg(u)-1 >= 3, else 1.
- **Final answer:** For each vertex R with deg(R) >= 4, the best alkane using R as the neighbour of a leaf is: choose the smallest-valued neighbour as leaf L (contributes 1) and the three largest values among all neighbours of R as internal children. Candidate = 2 + (sum of the 3 largest val[n->R]). No explicit exclusion is needed because the minimum is never among the global top 3 when deg >= 4. Answer = max candidate, or -1 if none.
- **When is it -1:** A star K_{1,4} is a valid alkane, so a candidate exists iff some vertex has degree >= 4. Thus the answer is -1 exactly when the maximum degree of T is < 4. Still handle n < 5 up front.
- **Correctness of the construction:** Selected vertices form a connected induced subtree (each selected vertex's parent is selected, unchosen neighbours stay unselected), so induced degrees match the intended degrees exactly. Branches hanging from distinct neighbours of R are disjoint, so no overlap. Every alkane yields a candidate of at least its size by taking one of its leaves, and every candidate is a valid alkane, so the maximum candidate equals the optimum.
- **Complexity:** O(N log N) time from the small sorts (each vertex sorts its adjacency / top-4) and O(N) memory; iterative BFS avoids recursion limit problems for N up to 2*10^5.
- **Pitfalls avoided:** no quadratic knapsack over children (internal vertices need exactly 3 children, so top-3 suffices); top-4 with sources handles exclusion in O(1); the dp values are always valid (never negative infinity) because any vertex can always be a leaf.
