Convert each person into a directed interval constraint using prefix potentials: if \(S<T\), the two endpoint potentials must be equal and all interior potentials must be strictly larger; if \(S>T\), endpoints are equal and interiors are strictly smaller. The key structural fact is that a set of constraints is feasible iff it contains no pairwise conflict: same-direction intervals must be disjoint/touching or strictly nested, while opposite-direction intervals must not share a left endpoint or a right endpoint. This makes feasibility monotone, so we can compute for every left index \(L\) the smallest right index \(F[L]\) that makes \([L,F[L]]\) infeasible by a sliding window that always maintains a feasible set. When adding a new interval, check conflicts against the current feasible window using endpoint occupancy arrays and, for same-direction intervals, a segment tree over left endpoints storing right endpoints (to find the rightmost covering interval and the maximum right endpoint inside the new interval). Finally, answer each query \([L,R]\) as Yes exactly when \(R < F[L]\).
