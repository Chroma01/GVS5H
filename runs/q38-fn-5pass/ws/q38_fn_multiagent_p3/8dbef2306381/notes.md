- **Core model:** Merge bad intervals, including adjacent intervals, into continuous bad blocks. If a merged bad block has length at least B, it is impossible to cross because the closest safe squares on its two sides are distance len+1 > B apart. Safe segments are the maximal safe intervals between bad blocks.
- **Distance oracle:** Inside one safe segment, a distance d is possible iff it is a sum of jumps in [A, B]. Compute the minimum representable sum for each residue modulo A using Dijkstra on residues with steps A+1..B; step A is only a self-loop modulo A. Then d is possible iff d >= min_dist[d % A]. Empty sum makes d=0 possible, which is needed when an entry position is also an exit position.
- **Boundary states:** Any first landing in a safe segment (or square 1) lies in its first B positions. Any last position before leaving a segment, or N itself, lies in its last B positions. Store reachable entry offsets as a bitmask per segment.
- **Internal propagation:** For segment [s, e], let first_len = min(B, len), last_start = max(s, e-B+1), L = e-last_start+1, base = last_start-s. For entry offset i and exit offset j, distance = base + j - i. Build an integer can_bits where bit (delta+B) is set iff base+delta is representable. For each reachable entry i, exits |= (can_bits >> (B-i)) & ((1<<L)-1). This marks all exits reachable from any entry.
- **Cross-segment jumps:** A landing after the segment end is y = e + delta, 1 <= delta <= B. For fixed delta and last-window length L, exit offset j can reach y iff A <= delta + L - 1 - j <= B. This interval of j is precomputed as trans_masks[L][delta]. Scan delta, find the segment containing y with a moving pointer, and if exits intersects the interval mask, set the landing offset y-start in that future segment's reach mask. This considers all one-jump moves, including jumps that skip several short safe segments.
- **Processing order:** Segments are processed left to right. All transitions go to strictly later segments, so reach masks are complete when a segment is processed. If the last segment has N reachable as an exit, answer Yes; otherwise No.
- **Complexity:** O(M log M + M*B) time and O(M) memory, with B <= 20. Dijkstra is on at most 20 residues.
- **Edge cases handled:** M=0, A=B, A=1, B=1, short segments where first and last windows overlap, distance 0, adjacent bad intervals, bad blocks too long, N reached by direct landing or by internal jumps, and jumps that skip intermediate safe segments.
