Because all values are positive, sorting A, B, and C in non-increasing order makes the expression non-increasing when any index increases. Therefore the triples form a monotone 3D grid whose largest values can be enumerated by best-first search starting from (0,0,0). Use a max-heap for the frontier and a visited set to avoid pushing the same triple multiple times. Each popped state generates its three coordinate-increment neighbors, and since K <= 5e5, O(K log K) heap operations are feasible. The K-th popped value is the K-th largest value, counting duplicates.
