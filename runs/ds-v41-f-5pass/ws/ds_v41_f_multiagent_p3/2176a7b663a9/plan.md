Model the disjointness graph as a bipartite chain graph by splitting each interval into two nodes (L and R) and exploiting that edges exist iff R_i < L_j. Prove the diameter of any connected component is at most 3 edges, so every valid query answer is either a direct edge (2 vertices), a 3-vertex path via one common neighbor, or a 4-vertex path via two intermediates. Precompute prefix minima over R and suffix minima over L to answer direct and 3-vertex cases in O(1). For the 4-vertex cases (both intermediates on the same side), reduce to offline 2D dominance range-minimum queries over (L, R) pairs, which can be solved with a sweep and a Fenwick/segment tree. Handle disconnected components by checking connectivity during the same preprocessing.
