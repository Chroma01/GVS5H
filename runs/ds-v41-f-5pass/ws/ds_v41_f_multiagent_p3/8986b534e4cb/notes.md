- **Model:** Let f(x) = sum of road strengths up to town x (f(1)=0). For person with a=min(S,T), b=max(S,T): f(a)=f(b); each interior a<x<b needs f(x)>f(a) if S<T (sign +) else f(x)<f(a) if S>T (sign -).
- **Ground truth:** All difference-constraint edges have weight -1, so feasibility after contracting equalities f(a)=f(b) fails iff the directed graph has a cycle. Brute force = union-find + cycle detection.
- **Conflict catalogue:** a set is feasible iff it contains no conflicting pair, where pairs conflict for (i) same a any signs, (ii) same b any signs, (iii) same-sign proper crossing a_i<a_j<b_i<b_j or a_j<a_i<b_j<b_i. Same-a always conflicts because the smaller b lies strictly inside the larger interval and needs f(b)>f(a) (or <) contradicting f(b)=f(a); same for same-b. Mixed-sign crossings and arbitrary nestings are feasible. Verified exhaustively N<=6 and random N<=9: 0 false-feasible, 0 false-conflict.
- **Query reduction:** next[i] = min j>i conflicting with i. [L,R] is feasible iff boundary[L] = min_{i>=L} next[i] > R (positions i>R contribute next[i]>i>R, so the suffix minimum is safe). boundary is non-decreasing in L.
- **next_same:** right-to-left last occurrence of each a-value and b-value, take the min of the two (covers same a/b, any sign, including the (x,y)/(y,x) duplicate-endpoint case).
- **Crossing via reflection:** a single routine finds type1 a_i<a_j<b_i<b_j. Type2 a_j<a_i<b_j<b_i equals type1 under (a,b)->(N+1-b, N+1-a); positions stay in [1,N], sign preserved. Run twice and take elementwise min.
- **Type1 routine:** scan j=1..M. One segment tree per sign over b-position, each leaf = min packed a_i*K+i (K=M+1) among active persons at that b; one min-heap per (sign,b). Query range [a_j+1, b_j-1]; while the returned packed < a_j*K, that i satisfies a_i<a_j<b_i<b_j, set next[i]=j and permanently remove it (pop heap top, refresh leaf). Because packed<aj*K iff a_i<a_j strictly and indices are unique, no ties.
- **Why no stale handling needed:** in the single reflected routine each person lives in exactly one (sign,b) heap; the query always returns a heap top, so removal always pops the true top; each person removed at most once per call. The earlier two-tree stale branch is impossible and was dropped.
- **Complexity:** O((M+Q) + M log N) per routine pair; two routines total. Segment trees of length 2*pow2(N) (~1.05e6 each) and heaps arrays 2*(N+1) keep memory well under 1GB.
- **Hot-loop optimizations:** query and leaf-refresh inlined (no function-call overhead); early-break point update; local heappush/heappop bindings; per-sign tree/heap selected once per j.
- **Correctness evidence:** both samples reproduced by hand (sample1 boundary=[_,4,4,4] answers Yes/No; sample2 boundary=[_,4,6,6,6,INF,INF] answers No/Yes/Yes). Earlier rounds: fast next[]/boundary[]/answers matched an O(M^2) replica and brute force over 6000 random cases with all mismatch counters 0.
