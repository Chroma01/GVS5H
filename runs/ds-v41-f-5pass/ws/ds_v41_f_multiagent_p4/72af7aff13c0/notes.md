- **Approach:** Rectangle recomputation DP. Maintain flat arrays `A` and `dp` of size `H*W`. Initial DP is computed in O(HW) using `dp[h][w] = A[h][w] * (dp[h-1][w] + dp[h][w-1])`, with special case `dp[0][0] = A[0][0]`. For each query, move the position, update `A`, and if the value changed, recompute only the rectangle `[sh..H-1] x [sw..W-1]` in increasing `h` then `w` order. The special case `(0,0)` requires setting `dp[0] = A[0]` and recomputing the whole grid.
- **Correctness:** The rectangle recomputation correctly updates all cells whose DP value depends on the changed cell. Cells outside the rectangle have unchanged DP values and are used as immutable boundaries. The special case for `(0,0)` is necessary because the standard recurrence would yield 0 for the start cell.
- **Complexity:** Initial DP O(HW). Each query up to O(HW) in the worst case, making the overall worst-case O(Q*HW). This is not asymptotically optimal for the given constraints but matches the requested baseline solver without matrix/segment-tree techniques.
