- **Core idea:** The unknown string has length up to 100 over 26 letters, but the fixed string S has length at most 10. After processing any prefix of the unknown string, its entire effect on the LCS with S can be summarized by the LCS DP row against all prefixes of S.
- **State encoding:** For a processed prefix T, let dp[j] be LCS(T, S[:j]) for j=0..N. The row starts at dp[0]=0 and satisfies dp[j]-dp[j-1] in {0,1}. Encode these N differences as an N-bit mask. The popcount of the mask equals dp[N], the current LCS length.
- **Transition construction:** For each mask and each lowercase letter, reconstruct the old DP row from the mask, append the letter using the standard LCS row recurrence, and convert the new row back to a mask. Using the explicit recurrence avoids subtle bit-formula mistakes.
- **Recurrence used:** If the appended character matches S[j-1], new[j] = max(old[j], new[j-1], old[j-1]+1); otherwise new[j] = max(old[j], new[j-1]). This is safe even for unreachable monotone rows.
- **Counting DP:** Start with the empty prefix state mask 0 having count 1. For each of M positions, transition to all 26 next states, adding counts modulo 998244353. Each path corresponds to exactly one candidate string.
- **Final aggregation:** After M steps, sum the counts of all states whose popcount is k. This gives the number of strings whose LCS with S is exactly k.
- **Complexity:** Precomputation is O(2^N * 26 * N). The length DP is O(M * 2^N * 26). With N<=10 and M<=100 this is tiny. Memory is O(2^N * 26).
- **Verification:** For S="ab", M=2, the automaton yields 576, 99, 1. For S="aaa", M=4, it matches the binomial distribution over the number of 'a' characters capped at 3: 390625, 62500, 3750, 101.
- **Implementation details:** Popcounts are precomputed to avoid relying on newer Python methods. Modulo additions are kept below 2*MOD before subtracting once. Repeated letters in S are handled naturally because transitions are computed per letter and counted separately.
