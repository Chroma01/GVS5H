- **Problem shape:** Arrangements are exactly the k-subsets of the m*n cells (pieces identical, ≤1 per cell), so total = sum over k-subsets of sum over unordered cell pairs of Manhattan distance.
- **Linearity trick:** A fixed unordered pair of cells is contained in C(N-2, k-2) arrangements, where N = m*n. So answer = C(N-2, k-2) * S, with S = sum of Manhattan distances over all unordered cell pairs. This factors the huge arrangement count out.
- **Row/column separation:** Manhattan = |dr| + |dc|, so S decomposes independently. Sum of |dr| over all cell pairs = n^2 * (sum of |i-j| over unordered row pairs), because each row pair allows n choices of column per cell. Symmetrically columns contribute m^2 * (sum of |i-j| over unordered column pairs).
- **Closed forms:** sum_{i<j}(j-i) over 0..t-1 = t(t^2-1)/6. So S = n^2 * m(m^2-1)/6 + m^2 * n(n^2-1)/6. This is O(1); no pair enumeration needed.
- **Binomial computation:** N <= 1e5 so precompute factorials and inverse factorials mod 1e9+7, then C(a,b) = fact[a]*inv_fact[b]*inv_fact[a-b]. Use Fermat inverse via pow(x, MOD-2). Also need inv6 = pow(6, MOD-2) for the /6 divisions.
- **Modular division:** Never do integer //6 on the raw product then reduce; instead multiply by inv6 mod MOD (the true integer m(m^2-1)/6 is what we want, but working mod with inv6 is equivalent since 6 is invertible mod the prime).
- **Edge cases handled:** k=2 gives C(N-2,0)=1; k=N gives C(N-2,N-2)=1. One-dimensional boards: if m=1 the row term is 0, if n=1 the column term is 0 — both fall out of t(t^2-1) naturally. N>=2 is guaranteed so N-2>=0 is safe.
- **Verification:** (m,n,k)=(2,2,2): binom=C(2,0)=1, S=4+4=8 → 8. (1,4,3): binom=C(2,1)=2, S=0+10=10 → 20. Both examples match. Extra checks: (1,2,2)→1; (3,1,2)→4; (2,2,4)→8 (all cells, 4 edges + 2 diagonals = 4+4=8); (2,3,2): direct pair enumeration gives S=25 (8 same-row + 17 cross-row), formula n^2*1 + m^2*4 = 9+16=25, binom=1 → 25.
- **Complexity:** O(N) time/memory for factorial tables, well within limits (N<=1e5). Could be reduced to O(min(...)) but unnecessary.
