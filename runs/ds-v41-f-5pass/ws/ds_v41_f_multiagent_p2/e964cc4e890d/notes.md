- **Verification:** Brute-force cross-check performed on all valid strings of length 2N with N Ws and N Bs for N=1..6. No mismatches found against the naive O(N!) enumeration. Specific edge cases checked: N=1 'BW'→1; N=2 'BBWW'→2, 'BWBW'→1, 'BWWB'→0 (last char B rejected), 'WBBW'→0 (first char W rejected). Sample 1 (N=2 BWBW) = 1, Sample 2 (N=4 BWWBWBWB) = 0, Sample 3 (N=9) = 240792 all match.
- **Performance:** N=200000 alternating 'BW'*N runs in ~1.5s with numpy-accelerated NTT on CPython. Pure Python fallback is correct but slower (not recommended for large N). Total NTT work is O(N log² N) with cutoff direct O(|L|·|R|) for segments ≤2048, keeping overhead low.
- **Reduction:** Strong connectivity iff every prefix cut k has a backward edge (black ≤ k < white). Counts permutations σ of [N] with prefix max M_t ≥ d_t for t=1..N-1, where d_t = b[t] - t (0-indexed b[t] = position of (t+1)-th B). Necessary: S[0]='B', S[-1]='W', d_t ≤ N.
- **Block compression:** d_t is non-decreasing. Group equal d_t into blocks; only the first index T_start matters. Active iff c = v - T_start - 1 ≥ 0 (else constraint M_T ≥ v is automatic since M_T ≥ T).
- **Recurrence:** f_0 = 1, f_j = -inv_fact[c_j] · Σ_{i<j} f_i · fact[v_j - T_i - 1]. Answer = Σ f_i · fact[N - T_i].
- **CDQ + NTT:** Replace O(m²) inner sum with CDQ divide-and-conquer. Merge left [l,mid] into right [ml,mr]: build A with A[T_i - T_min] = f_i, B[k] = fact[k + d_min] (d_min = v_min - T_max - 1, zeros for negative indices). Convolution C = A * B gives C[y] = Σ f_i · fact[v_j - T_i - 1] for y = v_j - 1 - T_min - d_min.
- **Implementation details:** Precompute roots up to 2^20 (enough for 3N). Use numpy int64 throughout; convert scalars to Python int in direct loops to avoid overflow. Handle m=0 (answer N!) and early exits for invalid S or d_t > N.
