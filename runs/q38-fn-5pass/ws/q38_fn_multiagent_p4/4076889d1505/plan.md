Use the direct construction \(A = N + 1\) and \(M = N^2\). By the binomial theorem, \((1+N)^n \equiv 1 + nN \pmod{N^2}\), so \(A^n - 1\) is divisible by \(M\) exactly when \(N \mid n\), making the smallest such \(n\) equal to \(N\). The bounds hold because \(N \le 10^9\), so \(M \le 10^{18}\) and \(A \le 10^9+1\). For \(N=1\), this gives \(M=1\), which is valid. The solution is therefore \(O(T)\) and requires only integer arithmetic.
