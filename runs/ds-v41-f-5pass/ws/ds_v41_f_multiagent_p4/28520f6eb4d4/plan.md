Model visibility from (0,h) using the slope from the viewpoint to each building’s top: s_i(h) = (H_i - h)/X_i. All buildings are visible iff these slopes are strictly increasing, i.e. s_i(h) > s_{i-1}(h) for every adjacent pair. Each adjacent inequality becomes h > T_i, where T_i = (H_{i-1}X_i - H_iX_{i-1})/(X_i - X_{i-1}). Thus all buildings are visible exactly when h is greater than the maximum adjacent threshold. If that maximum is negative, height 0 already sees all buildings and the answer is -1; otherwise the answer is that maximum threshold.
