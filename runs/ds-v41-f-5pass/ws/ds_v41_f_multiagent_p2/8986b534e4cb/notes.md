- **Model:** With prefix sums A (A_1 free), person (S,T) gives A_S = A_T plus strict inequalities on every interior town x: A_x > A_S if S<T, A_x < A_S if S>T. Feasibility = acyclicity of the strict-inequality digraph after contracting equalities. The old union-find+toposort reference matched this exactly.
- **Pairwise criterion (now proven, not just tested):** a set is feasible iff no two persons conflict, where i,j conflict iff (a) same left town L, (b) same right town R, or (c) proper crossing L_i<L_j<R_i<R_j (or symmetric) with equal sign. Opposite-sign crossings, nestings, and disjointness are always compatible.
- **Why (c):** in a conflict-free set no town is an endpoint of two persons, so components are single persons' endpoint pairs. Any directed cycle, traced edge by edge, must be either all-+ or all-- (an edge type B followed by F would force one person to be both signs), and then the required containments form a cyclic strict-nesting chain, which forces a same-sign proper crossing. Hence every cycle implies a pairwise conflict, so no-cycle == pairwise clean.
- **Why (a):** sharing an endpoint town u makes A_u equal to one person's interior requirement on the other person's interval, contradicting a strict inequality. Holds regardless of the two signs.
- **Coordinates:** use l = min(S,T)-1, r = max(S,T)-1 (0-based towns); the criteria translate identically. |S-T|>1 guarantees r-l>=2 so the query window (l_j+1, r_j-1) is non-empty.
- **Sweep (per sign, input order):** structure A (over r, leaf heap stores (l,idx); segment tree stores min l) pops every earlier i with r_i in (l_j,r_j) and l_i<l_j, setting nextA[i]=j. Structure B (over l, heap stores (-r,idx); segtree max r) pops earlier i with l_i in (l_j,r_j) and r_i>r_j, setting nextB[i]=j. Each i pops once => O(M log N). Range decomposition into canonical nodes then a small descent stack (int-only) does the finding; ancestors are repaired after each pop so pruning stays valid.
- **Query reduction:** next_conflict[i] = min(nextA[i], nextB[i], next_end[i]) is the smallest j>i conflicting with i (next_end from a right-to-left dict pass over l and r). Query [L,R] is No iff min(next_conflict[L-1..R-1]) <= R-1, answered with a range-min segment tree. All 1-based -> 0-based handling verified on both samples.
- **Verified:** exhaustive person-set check vs exact feasibility for N=3,4,5 and 3000 random cases (N<=8, all subsets and all [L,R]); both samples reproduce. The earlier "pairwise criterion unproven" risk is now closed by the cycle/sign argument.
- **Performance:** per sign, two segment trees of size 2*2^ceil(log2 N) and dict-of-heaps (only present coordinates). Pops total O(M), so overall O((N+M+Q) log N). Peak memory bounded by one `process` call at a time (~tens of MB). Heaps are C-level heapq; DFS stacks hold plain ints.
